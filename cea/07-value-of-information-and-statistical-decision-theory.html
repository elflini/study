7.1 급여 결정기관이 내려야 할 두 개의 개념적으로 다른 결정

신약의 경제성 평가 결과를 검토하는 급여 결정기관은 적어도 두 가지 결정을 내려야 한다. 첫 번째는 현재의 근거를 바탕으로 신약을 급여할 것인지에 관한 결정이다. 두 번째는 현재의 불확실성을 줄이기 위해 추가 연구를 수행할 가치가 있는지에 관한 결정이다.

이 두 결정은 서로 관련되어 있지만 동일하지 않다. 현재 근거하에서 신약의 기대순편익이 가장 크다면 신약을 급여하는 것이 기대가치 관점에서 합리적일 수 있다. 그러나 그 결론의 불확실성이 크고, 잘못된 결정의 손실이 크다면 추가 연구도 가치 있을 수 있다. 반대로 불확실성이 존재하더라도 현재 최적 결정이 거의 바뀌지 않거나 잘못된 결정의 손실이 작다면 추가 연구의 가치는 낮을 수 있다.

두 결정은 서로 다른 확률변수를 대상으로 한다. 현재의 급여 결정은 이미 확보된 자료 \(y\)가 주어졌을 때 전략별 사후 기대순편익을 비교한다. 반면 추가 연구 결정은 아직 관찰되지 않은 미래 자료 \(X\)가 가져올 의사결정 개선분을 연구 수행 전에 평균한다. 따라서 전자는 사후 의사결정이고, 후자는 사전예측적 또는 사전사후(preposterior) 의사결정이다.

현재 채택할 전략을 \(a\)라고 하면 채택 결정은 다음과 같이 표현할 수 있다.

\[ a^*(y)=\arg\max_{a\in\mathcal{D}} \mathbb{E}_{\theta\mid y}\{NB(a,\theta;\lambda)\}. \]

추가 연구 설계를 \(\eta\in\mathcal{R}\)라고 하면 연구 결정은 미래 자료의 분포까지 평균한 순가치로 표현한다.

\[ \eta^*(y)=\arg\max_{\eta\in\mathcal{R}} \left[ Population\ EVSI(\eta;\lambda)-Cost(\eta)-Cost_{delay}(\eta) \right]. \]

여기서 \(Cost_{delay}(\eta)\)는 연구가 완료될 때까지 현재의 비최적 전략을 사용하거나 유망한 기술의 접근을 미루면서 발생하는 기대 기회비용이다. 실제 정책에서는 연구비뿐 아니라 도입비용, 연구 수행기간, 기술의 시장수명, 후속 기술의 등장 가능성, 결정의 가역성도 함께 고려해야 한다.

현재 급여 결정과 연구 결정이 분리되어 있다는 사실은 “불확실성이 크므로 급여하지 않는다”는 결론이 자동으로 성립하지 않음을 의미한다. 현재 기대순편익이 가장 큰 전략은 불확실성이 존재해도 채택할 수 있으며, 추가 연구의 필요성은 그 불확실성이 만들어내는 기대손실과 연구비용을 별도로 비교하여 판단한다.

결정 핵심 질문 판단 기준 대표 산출물
급여 여부 결정 현재 자료하에서 어떤 치료전략을 선택할 것인가? 기대순편익 최대화 기대비용, 기대 QALY, INB, ICER
추가 연구 결정 불확실성을 줄이기 위해 연구를 수행할 것인가? 정보가치와 연구비용 비교 EVPI, EVPPI, EVSI, ENBS
Note핵심 메시지

경제성 평가의 첫 번째 질문은 “지금 어떤 전략을 선택할 것인가?”이다. 두 번째 질문은 “더 많은 정보를 얻는 데 얼마까지 지불할 가치가 있는가?”이다. 첫 번째 질문은 기대순편익 최대화 문제이고, 두 번째 질문은 정보의 가치와 연구비용을 비교하는 문제이다.

가능한 정책 해석은 네 가지 조합으로 정리할 수 있다.

현재 최적 결정 추가 연구 가치 가능한 정책 해석
급여 낮음 급여 결정 후 추가 연구 필요성 낮음
급여 높음 급여하되 조건부 근거 생성 또는 사후자료 수집 고려
비급여 낮음 비급여 결정 후 추가 연구 우선순위 낮음
비급여 높음 제한적 사용, 조건부 급여, 추가 임상시험, 가격협상 고려

이 구조는 경제성 평가가 단순한 채택 또는 비채택 판단을 넘어 연구 우선순위 설정, 조건부 급여, 위험분담제, 가격협상과 연결될 수 있음을 보여준다. 따라서 경제성 평가 결과를 해석할 때는 비용효과성의 중심 추정값뿐 아니라 불확실성이 의사결정에 미치는 영향도 함께 평가해야 한다.

위 그림은 급여와 연구가 하나의 연속된 순차적 의사결정임을 보여준다. 첫 단계에서는 현재 정보로 기대가치가 가장 큰 전략을 선택하고, 두 번째 단계에서는 추가 정보가 첫 단계의 오류를 줄이는 가치가 연구비와 지연비용을 초과하는지 평가한다. 두 단계의 기준을 혼합하면 통계적으로 불확실하다는 이유만으로 기대가치가 높은 기술의 채택을 지연하거나, 반대로 추가 연구의 가치가 거의 없는 상황에서 관행적으로 대규모 연구를 요구할 수 있다.

결정의 가역성과 연구 시점

현재 결정을 나중에 쉽게 변경할 수 있는지 여부도 연구가치에 영향을 준다. 가격이나 급여범위를 신속히 재조정할 수 있는 가역적 결정에서는 현재 최선 전략을 채택하면서 연구를 병행하는 정책이 가능하다. 반면 대규모 설비 투자, 임상경로의 고착, 경쟁기술의 퇴출처럼 결정이 사실상 비가역적이면 잘못된 초기 채택의 장기 비용이 커질 수 있다.

연구의 가치도 시간에 따라 감소할 수 있다. 연구 결과가 도출되기 전에 대상 기술이 대체되거나 특허가 만료되면 정보가 영향을 미칠 수 있는 환자 수가 줄어든다. 따라서 모집단 정보가치는 단순한 환자 수뿐 아니라 정보가 실제 의사결정을 바꿀 수 있는 유효기간을 반영해야 한다.

7.2 신약 경제성 평가에서 발생하는 기회손실

의사결정은 항상 불확실성하에서 이루어진다. 신약이 실제로 비용효과적인지 완벽하게 알 수 없기 때문에 현재 자료하에서 선택한 전략이 사후적으로 최선이 아닐 수 있다. 이때 잘못된 선택으로 인해 잃는 순편익을 기회손실(opportunity loss) 또는 후회(regret)라고 한다.

가능한 치료전략의 집합을 \(\mathcal{D}\)라고 하자. 불확실한 모수 벡터를 \(\theta\), 지불의사금액을 \(\lambda\)라고 할 때 전략 \(d \in \mathcal{D}\)의 순편익은 다음과 같이 쓸 수 있다.

\[ NB(d,\theta;\lambda)=\lambda Q(d,\theta)-C(d,\theta). \]

여기서 \(Q(d,\theta)\)는 전략 \(d\)의 QALY이고, \(C(d,\theta)\)는 비용이다. 만약 실제 모수 \(\theta\)를 알고 있다면 선택해야 할 전략은 다음과 같다.

\[ d^*(\theta)=\arg\max_{d \in \mathcal{D}} NB(d,\theta;\lambda). \]

그러나 실제 의사결정 시점에는 \(\theta\)를 알 수 없다. 현재 자료 \(y\)에 근거하여 사후분포 또는 PSA 분포 \(p(\theta \mid y)\)를 구성하고, 기대순편익이 가장 큰 전략을 선택한다.

\[ d^*(y)=\arg\max_{d \in \mathcal{D}} \mathbb{E}_{\theta \mid y}\{NB(d,\theta;\lambda)\}. \]

특정 \(\theta\)에서 전략 \(d\)를 선택했을 때의 기회손실은 다음과 같이 정의한다.

\[ OL(d,\theta;\lambda)=\max_{d' \in \mathcal{D}} NB(d',\theta;\lambda)-NB(d,\theta;\lambda). \]

기회손실은 항상 0 이상이다.

\[ OL(d,\theta;\lambda) \ge 0. \]

모든 전략의 순편익에 동일한 상수 \(k(\theta)\)를 더해도 전략 간 차이와 기회손실은 변하지 않는다.

\[ OL(d,\theta;\lambda) = \max_{d'}\{NB(d',\theta;\lambda)+k(\theta)\} -\{NB(d,\theta;\lambda)+k(\theta)\}. \]

따라서 가치정보분석에서는 기준 전략의 순편익을 0으로 놓거나 증분순편익만 사용해도 동일한 의사결정을 얻는다. 이 위치 불변성은 여러 전략의 절대 순편익보다 전략 간 차이에 계산을 집중할 수 있게 한다.

현재 자료하에서 전략 \(d\)를 선택할 때의 사후 기대 기회손실은 다음과 같다.

\[ \rho(d\mid y) = \mathbb{E}_{\theta\mid y}\{OL(d,\theta;\lambda)\}. \]

현재 최적 전략은 이 기대 기회손실을 최소화하는 전략과 같다.

\[ \arg\min_d \rho(d\mid y) = \arg\max_d \mathbb{E}_{\theta\mid y}\{NB(d,\theta;\lambda)\}. \]

이 등식은 순편익 최대화와 후회 최소화가 서로 다른 분석이 아니라 같은 의사결정을 두 가지 방식으로 표현한 것임을 보여준다.

선택한 전략이 해당 \(\theta\)에서 최선이면 기회손실은 0이다. 반대로 선택한 전략이 최선이 아니면, 실제 최선 전략을 선택했을 때 얻을 수 있었던 순편익과 실제 선택한 전략의 순편익 차이가 기회손실이 된다.

Important기회손실의 의미

기회손실은 현재 선택한 전략이 실제 모수하에서 최선이 아니었을 때 잃게 되는 기대가치이다. 정보의 가치는 이 기회손실을 줄이는 가치로 해석할 수 있다.

예제: 두 치료전략의 기회손실

기존 치료와 신약이 있고 지불의사금액이 QALY당 30,000,000원이라고 하자. 특정 모수 \(\theta\)에서 두 전략의 비용과 QALY가 다음과 같다고 하자.

전략 비용 QALY 순편익
기존 치료 20,000,000원 1.80 34,000,000원
신약 35,000,000원 2.40 37,000,000원

순편익은 다음과 같이 계산된다.

\[ NB_0=30{,}000{,}000 \times 1.80-20{,}000{,}000=34{,}000{,}000, \]

\[ NB_1=30{,}000{,}000 \times 2.40-35{,}000{,}000=37{,}000{,}000. \]

위 예에서는 두 전략에 공통으로 발생하는 비용이나 건강결과는 순편익 차이에 영향을 주지 않는다. 신약과 기존 치료의 증분순편익은 3,000,000원이며, 이는 기존 치료를 잘못 선택했을 때의 기회손실과 정확히 같다.

이 경우 실제 최선 전략은 신약이다. 만약 의사결정자가 기존 치료를 선택했다면 기회손실은 다음과 같다.

\[ OL(0,\theta)=37{,}000{,}000-34{,}000{,}000=3{,}000{,}000. \]

반대로 신약을 선택했다면 기회손실은 0이다.

7.3 신약의 급여 결정을 내리는 데 통계적 가설검정이 부적절한 이유

임상시험에서는 치료효과의 존재 여부를 평가하기 위해 통계적 가설검정이 널리 사용된다. 예를 들어 새로운 항암제가 기존 치료보다 생존기간을 연장하는지 평가하기 위해 다음과 같은 귀무가설을 설정할 수 있다.

\[ H_0:\Delta Q=0. \]

생존분석에서는 위험비에 대해 다음과 같은 가설을 설정할 수 있다.

\[ H_0:HR=1. \]

그러나 급여 의사결정의 질문은 치료효과가 0인지 여부가 아니다. 급여 의사결정의 핵심 질문은 다음이다.

\[ \lambda\Delta Q-\Delta C>0 \quad ? \]

즉, 신약의 증분 QALY에 지불의사금액을 곱한 가치가 증분비용보다 큰지를 판단하는 문제이다. 증분순편익은 다음과 같이 정의한다.

\[ INB(\lambda)=\lambda\Delta Q-\Delta C. \]

현재 자료 \(y\)에 기반한 급여 결정은 기대증분순편익을 기준으로 할 수 있다.

\[ \mathbb{E}\{INB(\lambda) \mid y\}>0. \]

통계적 가설검정이 급여 결정에 부적절한 이유는 다음과 같다. 첫째, p-value는 비용을 고려하지 않는다. 둘째, p-value는 효과 크기의 사회적 가치를 반영하지 않는다. 셋째, p-value는 잘못된 결정으로 인한 기회손실을 직접적으로 알려주지 않는다. 넷째, 급여 결정은 이분법적 가설검정보다 기대가치 극대화 문제에 가깝다.

가설검정의 임계값은 사전에 정한 제1종 오류확률 \(\alpha\)에 의해 결정된다. 그러나 의사결정의 최적 임계값은 잘못된 채택과 잘못된 비채택이 초래하는 손실에 의해 결정된다. 두 오류의 손실이 같다는 보장은 없으며, 환자 수와 가격, 치료효과의 크기에 따라 손실은 크게 달라진다. 따라서 \(p<0.05\)라는 규칙은 경제적 손실함수와 일반적으로 일치하지 않는다.

증분 QALY가 양수인지 검정하는 문제와 신약이 비용효과적인지 판단하는 문제의 경계도 다르다. 증분비용이 \(\Delta C>0\)일 때 비용효과성의 효과 임계값은 다음과 같다.

\[ \Delta Q>\frac{\Delta C}{\lambda}. \]

즉, 비용효과성은 \(\Delta Q=0\)이 아니라 \(\Delta Q=\Delta C/\lambda\)를 경계로 한다. 가격이 높거나 지불의사금액이 낮을수록 요구되는 최소 건강효과가 커진다.

신뢰구간 역시 의사결정 불확실성을 충분히 요약하지 못한다. 증분효과와 증분비용의 결합분포, 두 변수의 공분산, 지불의사금액을 함께 고려해야 증분순편익 분포를 얻을 수 있다. 경제성 평가에서는 다음 확률과 기대값이 서로 다른 정보를 제공한다.

\[ P\{INB(\lambda)>0\mid y\}, \qquad \mathbb{E}\{INB(\lambda)\mid y\}, \qquad \mathbb{E}\{OL\mid y\}. \]

첫 번째는 신약이 비용효과적일 확률, 두 번째는 현재 선택을 결정하는 평균 가치, 세 번째는 불확실성을 제거할 때 회피할 수 있는 기대손실이다.

Warning통계적 유의성과 비용효과성은 다르다

치료효과가 통계적으로 유의하다고 해서 반드시 비용효과적인 것은 아니다. 반대로 통계적으로 유의하지 않더라도 기대순편익이 양수라면 현재 근거하에서 신약을 선택하는 것이 기대가치 관점에서 합리적일 수 있다.

그림의 왼쪽 경로는 표준오차와 귀무가설을 중심으로 증거의 강도를 평가하고, 오른쪽 경로는 가능한 결과마다 비용과 건강가치를 결합하여 행동의 기대결과를 평가한다. 두 접근은 목적이 다르므로 임상적 유의성, 통계적 유의성, 비용효과성을 동일한 판정으로 해석해서는 안 된다.

효과는 유의하지만 비용효과적이지 않은 경우

신약이 기존 치료보다 평균 QALY를 0.10 증가시키고, 그 차이가 통계적으로 유의하다고 하자. 그러나 추가 비용이 20,000,000원이고 지불의사금액이 QALY당 50,000,000원이라면 증분순편익은 다음과 같다.

\[ INB=50{,}000{,}000 \times 0.10-20{,}000{,}000=-15{,}000{,}000. \]

이 경우 효과는 존재할 수 있지만, 현재 가격에서는 비용효과적이지 않다.

효과가 유의하지 않지만 기대순편익이 양수인 경우

반대로 표본수가 작아 증분 QALY의 신뢰구간이 0을 포함하더라도, 평균 증분 QALY가 0.30이고 추가 비용이 8,000,000원이라면 지불의사금액 50,000,000원에서 증분순편익은 다음과 같다.

\[ INB=50{,}000{,}000 \times 0.30-8{,}000{,}000=7{,}000{,}000. \]

이 경우 불확실성은 크지만 현재 자료하의 기대가치 기준으로는 신약을 선택하는 것이 합리적일 수 있다. 이때 중요한 추가 질문은 불확실성이 얼마나 큰지, 그리고 추가 연구의 가치가 연구비용보다 큰지이다.

7.4 통계적 의사결정론에 대한 개요

통계적 의사결정론은 불확실성하에서 최적의 행동을 선택하기 위한 수리적 틀이다. 경제성 평가에서 의사결정론은 다음 네 가지 요소로 구성된다.

의사결정론에서는 자료의 생성과정, 미지의 상태, 가능한 행동, 행동의 결과를 명시적으로 분리한다. 통계모형은 \(p(y\mid\theta)\)를 통해 자료가 상태 \(\theta\)에 관해 제공하는 정보를 나타내지만, 통계모형만으로 어떤 행동을 선택할지는 결정되지 않는다. 행동의 선택에는 결과의 가치를 나타내는 순편익 또는 손실함수가 추가로 필요하다.

  1. 가능한 의사결정 또는 치료전략의 집합 \(\mathcal{D}\)
  2. 불확실한 상태 또는 모수 \(\theta\)
  3. 각 결정과 상태에서의 가치 함수 \(NB(d,\theta)\) 또는 손실함수 \(L(d,\theta)\)
  4. 기대가치를 최대화하거나 기대손실을 최소화하는 의사결정 규칙

그림에서 자료모형은 관찰자료와 불확실한 모수를 연결하고, 가치모형은 모수와 정책결과를 연결한다. 최종 의사결정은 두 모형을 결합한 기대순편익을 비교하여 얻는다. 통계적 추정이 정확하더라도 가치모형이 잘못 설정되면 의사결정은 잘못될 수 있으며, 반대로 임상적 불확실성이 커도 잘못된 결정의 손실이 작으면 현재 정책은 안정적일 수 있다.

순편익의 선형성과 위험중립성

표준 순편익

\[ NB=\lambda Q-C \]

는 비용과 QALY의 선형 결합이다. 이 표현은 집단 수준에서 동일한 QALY 증가에 동일한 사회적 가치를 부여하고, 불확실한 순편익에 대해서는 기대값으로 행동을 선택하는 위험중립적 의사결정을 전제로 한다. 정책결정자가 예산 초과 위험이나 심각한 하방위험에 특별한 가중치를 둔다면 비선형 효용함수 \(U(NB)\)를 사용할 수 있다.

\[ d^*(y)=\arg\max_d \mathbb{E}_{\theta\mid y}[U\{NB(d,\theta)\}]. \]

다만 비선형 효용을 사용하면 QALY당 일정한 지불의사금액에 기반한 표준 순편익 해석이 달라지므로, 위험회피의 근거와 함수 형태를 명확히 제시해야 한다.

예산제약이 있는 포트폴리오 의사결정

개별 기술의 채택을 독립적으로 평가하는 순편익 규칙은 예산이 유연하거나 기회비용이 \(\lambda\)에 적절히 반영되었다는 가정에 의존한다. 여러 기술을 동시에 선택하면서 총예산 \(B\)를 초과할 수 없다면 의사결정은 다음의 포트폴리오 최적화 문제가 된다.

\[ \max_{x_1,\ldots,x_J} \sum_{j=1}^{J}x_j\,\mathbb{E}(Q_j) \quad\text{subject to}\quad \sum_{j=1}^{J}x_j\,\mathbb{E}(C_j)\le B, \]

여기서 \(x_j\in\{0,1\}\)는 기술 \(j\)의 채택 여부이다. 고정된 \(\lambda\)를 이용한 순편익은 이러한 제약문제의 라그랑주 표현으로 볼 수 있다. 따라서 \(\lambda\)는 단순한 사회적 선호값뿐 아니라 제한된 의료자원에서 발생하는 건강의 기회비용과 연결된다.

Bayes action

자료 \(y\)가 관찰된 뒤, 모수 불확실성을 \(p(\theta \mid y)\)로 표현한다고 하자. 전략 \(d\)의 사후 기대순편익은 다음과 같다.

\[ \mathbb{E}_{\theta \mid y}\{NB(d,\theta;\lambda)\} = \int NB(d,\theta;\lambda)p(\theta \mid y)d\theta. \]

기대순편익을 최대화하는 Bayes action은 다음과 같다.

\[ d^*(y)=\arg\max_{d \in \mathcal{D}} \mathbb{E}_{\theta \mid y}\{NB(d,\theta;\lambda)\}. \]

두 전략만 비교할 때 기존 치료를 \(d=0\), 신약을 \(d=1\)이라고 하자. 증분순편익을 \(INB(\theta;\lambda)=NB_1(\theta;\lambda)-NB_0(\theta;\lambda)\)로 정의하면 신약 선택 규칙은 다음과 같이 단순화된다.

\[ \text{신약 선택} \quad \Longleftrightarrow \quad \mathbb{E}_{\theta \mid y}\{INB(\theta;\lambda)\}>0. \]

손실함수와 위험함수

의사결정론은 손실함수로도 표현할 수 있다. 특정 전략 \(d\)와 모수 \(\theta\)에서의 손실을 \(L(d,\theta)\)라고 하자. 자료 \(y\)가 주어진 뒤 기대손실을 최소화하는 전략은 다음과 같다.

\[ d^*(y)=\arg\min_{d \in \mathcal{D}} \mathbb{E}_{\theta \mid y}\{L(d,\theta)\}. \]

경제성 평가에서는 손실함수를 기회손실로 정의할 수 있다.

\[ L(d,\theta)=OL(d,\theta;\lambda). \]

기회손실은 완벽한 상태정보가 있을 때 선택할 전략을 기준으로 정규화된 손실이다. 일반적인 손실함수와 달리 최선 전략의 손실이 각 \(\theta\)에서 0이 되므로, 서로 다른 모수 상태에서 손실을 비교하기 쉽다. 그러나 건강불평등, 예산초과, 실행 가능성처럼 순편익에 포함되지 않은 정책목표가 있다면 손실함수에 별도의 항을 추가해야 한다.

이 경우 기대손실을 최소화하는 것과 기대순편익을 최대화하는 것은 동일한 의사결정 규칙을 제공한다.

빈도론적 의사결정론에서는 의사결정 규칙 \(\delta(Y)\)의 위험함수를 다음과 같이 정의한다.

\[ R(\theta,\delta)=\mathbb{E}_{Y \mid \theta}\{L(\delta(Y),\theta)\}. \]

베이지안 의사결정론에서는 사전분포 또는 사후분포에 대해 위험함수를 평균한다. 현재 자료가 주어진 상황에서는 다음과 같은 사후 기대손실 또는 사후 기대순편익이 직접적인 의사결정 기준이 된다.

\[ \mathbb{E}_{\theta \mid y}\{L(d,\theta)\}, \qquad \mathbb{E}_{\theta \mid y}\{NB(d,\theta)\}. \]

경제성 평가는 현재 관찰된 근거하에서의 정책 선택을 다루기 때문에, 베이지안 의사결정론과 매우 자연스럽게 연결된다. 다만 실제 PSA가 반드시 엄밀한 베이지안 사후분포에서 생성되어야 하는 것은 아니다. 빈도론적 추정량의 표준오차와 공분산을 이용해 구성한 모수 불확실성 분포도 의사결정론적 계산에 사용할 수 있다.

7.5 완벽한 정보의 기대가치

완벽한 정보의 기대가치(expected value of perfect information, EVPI)는 현재의 불확실성을 완전히 제거할 수 있다면 기대가치가 얼마나 증가하는지를 나타낸다. EVPI는 추가 연구가 가질 수 있는 가치의 이론적 상한이다. 어떤 실제 연구도 모든 불확실성을 완벽히 제거할 수는 없기 때문이다.

현재 자료 \(y\)가 주어졌다고 하자. 현재 정보하에서의 최적 기대순편익은 다음과 같다.

\[ \max_{d \in \mathcal{D}} \mathbb{E}_{\theta \mid y}\{NB(d,\theta;\lambda)\}. \]

완벽한 정보가 있다면 각 \(\theta\)마다 실제로 순편익이 가장 큰 전략을 선택할 수 있다. 따라서 완벽한 정보하에서의 기대순편익은 다음과 같다.

\[ \mathbb{E}_{\theta \mid y}\left[\max_{d \in \mathcal{D}}NB(d,\theta;\lambda)\right]. \]

개인당 EVPI는 두 값의 차이이다.

\[ EVPI(\lambda)= \mathbb{E}_{\theta \mid y}\left[\max_{d \in \mathcal{D}}NB(d,\theta;\lambda)\right] - \max_{d \in \mathcal{D}} \mathbb{E}_{\theta \mid y}\{NB(d,\theta;\lambda)\}. \]

EVPI는 항상 0 이상이다.

\[ EVPI(\lambda) \ge 0. \]

EVPI가 음수가 될 수 없는 이유는 완벽한 정보를 얻은 뒤에도 현재 전략을 그대로 선택할 수 있기 때문이다. 정보는 선택 가능한 행동의 집합을 줄이지 않으므로, 합리적인 의사결정자에게 정보의 기대가치는 비음수가 된다. 이는 정보가 선택 가능한 행동을 제한하지 않는다는 성질을 반영한다.

정보집합을 \(\mathcal{I}_1\subseteq\mathcal{I}_2\)라고 하면 더 풍부한 정보가 제공하는 기대가치는 작아질 수 없다.

\[ V(\mathcal{I}_2)\ge V(\mathcal{I}_1), \]

여기서

\[ V(\mathcal{I})= \mathbb{E}_{\mathcal{I}} \left[ \max_d \mathbb{E}\{NB(d,\theta)\mid\mathcal{I}\} \right] \]

이다. EVPI는 현재 정보와 완벽한 정보 사이의 가치 차이이다.

이는 최댓값 함수의 볼록성으로도 이해할 수 있다. 일반적으로 확률변수 \(X_d\)들에 대해 다음 부등식이 성립한다.

\[ \mathbb{E}\{\max_d X_d\} \ge \max_d \mathbb{E}(X_d). \]

EVPI는 불확실성의 분산 그 자체가 아니다. 모든 모수가 크게 변하더라도 각 PSA 표본에서 동일한 전략이 항상 최적이면 EVPI는 0이다. 반대로 전체 분산이 비교적 작아도 기대순편익이 의사결정 경계에 위치하고 작은 변화로 최적 전략이 바뀌면 EVPI가 커질 수 있다.

EVPI는 현재 선택한 Bayes action의 기대 기회손실과 같다. 현재 정보하에서 선택한 전략을 \(d^*(y)\)라고 하면 다음이 성립한다.

\[ \begin{aligned} \mathbb{E}_{\theta \mid y}\{OL(d^*(y),\theta;\lambda)\} &=\mathbb{E}_{\theta \mid y}\left[\max_{d \in \mathcal{D}}NB(d,\theta;\lambda)-NB(d^*(y),\theta;\lambda)\right] \\ &=\mathbb{E}_{\theta \mid y}\left[\max_{d \in \mathcal{D}}NB(d,\theta;\lambda)\right] -\max_{d \in \mathcal{D}} \mathbb{E}_{\theta \mid y}\{NB(d,\theta;\lambda)\} \\ &=EVPI(\lambda). \end{aligned} \]

그림의 첫 번째 항은 각 모수 표본에서 가장 높은 순편익을 선택한 뒤 평균한 값이고, 두 번째 항은 전략별 순편익을 먼저 평균한 뒤 가장 높은 전략을 선택한 값이다. 두 연산의 순서가 다르며, 최댓값의 비선형성 때문에 일반적으로 두 값은 같지 않다. 그 차이가 현재 정보에서 피할 수 없는 기대 후회이다.

두 전략 비교에서의 EVPI

기존 치료와 신약만 비교한다고 하자. 기준 전략의 순편익을 0으로 두고, 신약의 증분순편익을 다음과 같이 정의한다.

\[ X=INB(\theta;\lambda)=NB_1(\theta;\lambda)-NB_0(\theta;\lambda). \]

그러면 두 전략 비교에서 EVPI는 다음과 같이 쓸 수 있다.

\[ EVPI(\lambda)=\mathbb{E}\{\max(X,0) \mid y\}-\max\{\mathbb{E}(X \mid y),0\}. \]

현재 정보하에서 신약을 선택하는 경우, 즉 \(\mathbb{E}(X \mid y)>0\)이면 잘못된 결정은 실제로 \(X<0\)일 때 발생한다. 이때 EVPI는 다음과 같다.

\[ EVPI(\lambda)=\mathbb{E}\{(-X)_+ \mid y\}, \]

여기서 \(a_+=\max(a,0)\)이다. 반대로 현재 정보하에서 기존 치료를 선택하는 경우, 즉 \(\mathbb{E}(X \mid y)<0\)이면 EVPI는 다음과 같다.

\[ EVPI(\lambda)=\mathbb{E}\{X_+ \mid y\}. \]

두 전략에서 EVPI는 “잘못된 결정의 확률”과 “잘못되었을 때의 평균 손실”의 곱으로도 분해할 수 있다. 현재 신약을 선택한다면

\[ EVPI = P(X<0\mid y)\, \mathbb{E}(-X\mid X<0,y), \]

현재 기존 치료를 선택한다면

\[ EVPI = P(X>0\mid y)\, \mathbb{E}(X\mid X>0,y). \]

따라서 잘못될 확률이 같더라도 오류가 발생했을 때 손실의 크기가 다르면 EVPI는 달라진다. 이 점이 CEAC만으로 추가 연구의 가치를 판단할 수 없는 핵심 이유이다.

정규분포 증분순편익에서의 닫힌형 표현

증분순편익이 정규분포를 따른다고 근사할 수 있다고 하자.

\[ X \sim N(\mu,\sigma^2). \]

\(z=\mu/\sigma\)라고 하고, \(\phi(\cdot)\)와 \(\Phi(\cdot)\)를 표준정규분포의 밀도함수와 누적분포함수라고 하자. 양의 부분의 기대값은 다음 적분에서 유도된다.

\[ \mathbb{E}(X_+) = \int_0^{\infty}x\, \frac{1}{\sigma}\phi\left(\frac{x-\mu}{\sigma}\right)dx. \]

변수변환 \(u=(x-\mu)/\sigma\)를 적용하면 다음이 성립한다.

\[ \mathbb{E}(X_+)=\sigma\phi(z)+\mu\Phi(z). \]

또한 다음도 성립한다.

\[ \mathbb{E}\{(-X)_+\}=\sigma\phi(z)-\mu\Phi(-z). \]

따라서 \(\mu>0\)이면 \(EVPI=\sigma\phi(z)-\mu\Phi(-z)\)이고, \(\mu<0\)이면 \(EVPI=\sigma\phi(z)+\mu\Phi(z)\)이다. 이 식은 EVPI가 단순히 불확실성의 크기 \(\sigma\)만으로 결정되지 않음을 보여준다. 평균 증분순편익 \(\mu\)가 0에 가까워 의사결정 경계 근처에 있을수록 EVPI가 커질 수 있다.

특히 \(\mu=0\)이면 현재 두 전략의 기대가치가 같고

\[ EVPI=\frac{\sigma}{\sqrt{2\pi}} \]

가 된다. 고정된 \(\sigma\)에서 \(|\mu|/\sigma\)가 커질수록 현재 최적 전략이 실제로 최적일 가능성이 높아지고 EVPI는 0으로 감소한다. 정규근사는 해석에 유용하지만, INB 분포가 비대칭이거나 다봉형이면 PSA 표본을 직접 사용하는 것이 더 안전하다.

그림에서 0의 왼쪽 면적은 신약이 비용효과적이지 않을 확률을 나타내지만, EVPI는 그 면적만 사용하지 않는다. 0에서 멀리 떨어진 음의 INB에는 더 큰 기회손실이 부여되므로, 음의 영역에 있는 각 값의 거리까지 함께 적분한다.

PSA 표본을 이용한 EVPI 계산

PSA 또는 베이지안 사후표본이 \(s=1,\ldots,S\)개 있다고 하자. 표본 \(s\)에서 전략 \(d\)의 순편익을 \(NB_d^{(s)}\)라고 하면 EVPI의 Monte Carlo 추정량은 다음과 같다.

\[ \widehat{EVPI}(\lambda)= \frac{1}{S}\sum_{s=1}^{S}\max_{d \in \mathcal{D}}NB_d^{(s)} - \max_{d \in \mathcal{D}}\left\{\frac{1}{S}\sum_{s=1}^{S}NB_d^{(s)}\right\}. \]

두 전략 비교에서는 다음처럼 계산할 수 있다.

\[ \widehat{EVPI}(\lambda)= \frac{1}{S}\sum_{s=1}^{S}\max\{INB^{(s)}(\lambda),0\} - \max\left\{\frac{1}{S}\sum_{s=1}^{S}INB^{(s)}(\lambda),0\right\}. \]

이 추정량에도 Monte Carlo 오차가 존재한다. 첫 번째 항과 두 번째 항은 동일한 PSA 표본에서 계산되므로 독립이 아니며, 단순히 두 표준오차를 더해서는 안 된다. PSA를 여러 묶음으로 반복하거나 비모수 부트스트랩으로 PSA 행을 재표집하여 EVPI 추정량의 Monte Carlo 표준오차를 평가할 수 있다.

유한한 표본에서 최댓값 연산은 상향편향을 만들 수 있다. 특히 여러 전략의 기대순편익이 비슷하고 \(S\)가 작을 때

\[ \max_d\left\{\frac{1}{S}\sum_s NB_d^{(s)}\right\} \]

는 실제 최대 기대순편익을 다소 과대평가할 수 있다. 첫 번째 항은 표본평균이므로 이러한 편향이 상대적으로 작아, 전체 EVPI 추정량은 유한 표본에서 작게 편향될 수 있다. 따라서 EVPI 곡선이 불안정하면 PSA 표본수를 늘리고, 누적 표본수에 따른 EVPI의 수렴을 확인해야 한다. EVPPI와 EVSI의 중첩 시뮬레이션에서는 내부 반복수와 외부 반복수 모두에 따른 오차를 별도로 점검해야 한다.

EVPI는 지불의사금액 \(\lambda\)에 따라 달라진다. 두 전략의 기대순편익이 비슷해지는 영역에서는 의사결정이 바뀔 가능성과 잘못된 선택의 기대 손실이 커져 EVPI가 커질 수 있다. 반대로 한 전략이 거의 모든 표본에서 명확히 우월한 영역에서는 EVPI가 낮다.

위 곡선의 정점은 추가 연구가 가장 필요하다고 단정하는 지점이 아니라, 해당 \(\lambda\)에서 완벽한 정보가 가질 수 있는 개인당 최대 가치를 나타낸다. 실제 연구가치인 EVSI는 EVPI보다 작고, 연구비와 결과 도출까지의 지연을 고려하면 순가치는 더 작아진다.

모집단 EVPI

개인당 EVPI는 한 명의 환자에게 완벽한 정보를 제공할 때 증가하는 기대가치이다. 정책 의사결정에서는 해당 결정의 영향을 받는 전체 환자집단을 고려해야 한다. 이를 모집단 EVPI(population EVPI)라고 한다.

연도 \(t=0,1,\ldots,T-1\)에서 의사결정의 영향을 받는 환자 수를 \(N_t\), 실제 기술 이용률을 \(u_t\), 연 할인율을 \(r\)이라고 하자. 개인당 EVPI가 모든 연도에서 동일하다고 가정하면 모집단 EVPI는 다음과 같다.

\[ Population\ EVPI(\lambda) = EVPI(\lambda) \sum_{t=0}^{T-1}\frac{N_tu_t}{(1+r)^t}. \]

이용률을 명시하지 않고 모든 대상 환자가 의사결정의 영향을 받는다고 가정하면 \(u_t=1\)이 되어 다음의 단순식이 얻어진다.

\[ Population\ EVPI(\lambda)=EVPI(\lambda)\sum_{t=0}^{T-1}\frac{N_t}{(1+r)^t}. \]

추가 연구의 결과가 \(L\)년 뒤에 이용 가능하다면 연구가 영향을 줄 수 있는 환자는 보통 \(t=L\) 이후의 환자이다. 따라서 연구와 관련된 정보가치에는 다음과 같은 유효 모집단을 사용할 수 있다.

\[ N_{eff}(L)= \sum_{t=L}^{T-1}\frac{N_tu_t}{(1+r)^t}. \]

연구기간이 길어질수록 \(N_{eff}(L)\)가 감소하므로 동일한 개인당 EVSI라도 모집단 EVSI는 낮아진다. 또한 유병 환자와 신규 발생 환자를 모두 포함하는지, 기술의 특허·시장수명과 분석기간이 일치하는지, 현재 환자가 연구 결과의 혜택을 받을 수 있는지를 명확히 해야 한다.

대상 환자 수가 매년 동일하게 \(N\)이면 다음과 같이 단순화된다.

\[ Population\ EVPI(\lambda)=EVPI(\lambda)N\sum_{t=0}^{T-1}\frac{1}{(1+r)^t}. \]

그림에서 각 연도의 막대는 단순한 환자 수가 아니라 할인과 기술 이용률을 반영한 유효 환자 수로 해석해야 한다. 먼 미래의 환자는 할인 때문에 현재 가치가 작고, 연구 결과가 나오기 전의 환자는 EVSI 계산에서 정보의 혜택을 받지 못할 수 있다.

모집단 EVPI는 추가 연구의 사회적 최대 가치를 평가할 때 중요하다. 개인당 EVPI가 작아도 대상 환자 수가 매우 많으면 모집단 EVPI는 클 수 있다. 반대로 개인당 EVPI가 크더라도 대상 환자 수가 매우 적으면 추가 연구의 총 가치는 제한적일 수 있다.

7.6 통계적 의사결정론

이 절에서는 앞서 다룬 개념을 경제성 평가 실무에서 어떻게 사용하는지 정리한다. 경제성 평가에서 의사결정론적 계산은 다음 흐름을 따른다.

이 흐름은 PSA 표본 생성에서 끝나지 않는다. 먼저 각 전략의 평균 순편익으로 현재의 최적 전략을 결정하고, 그 다음 PSA 표본별 최적 전략과 현재 전략의 차이를 이용해 기대 기회손실을 계산한다. 이후 정보의 범위를 전체 모수, 특정 모수군, 실제 연구자료로 단계적으로 제한하면서 EVPI, EVPPI, EVSI를 계산한다.

그림의 각 화살표는 단순한 계산 순서뿐 아니라 조건부 기대값의 수준이 달라짐을 의미한다. EVPI는 \(\theta\)를 완전히 알게 되는 경우, EVPPI는 \(\phi\)만 알게 되는 경우, EVSI는 미래 표본자료 \(X\)를 관찰하는 경우의 기대값을 사용한다.

CEAC와 EVPI의 차이

비용효과수용곡선(cost-effectiveness acceptability curve, CEAC)은 특정 지불의사금액에서 전략이 비용효과적일 확률을 보여준다. 두 전략 비교에서는 다음과 같다.

\[ CEAC(\lambda)=P\{INB(\theta;\lambda)>0 \mid y\}. \]

CEAC는 의사결정 불확실성의 확률적 표현이다. 그러나 최적 의사결정은 이 확률 자체가 아니라 기대순편익에 의해 결정된다. 예를 들어 비용효과적일 확률이 0.60이어도 비용효과적인 경우의 이득이 매우 크고 그렇지 않은 경우의 손실이 작으면 기대순편익이 클 수 있다. 반대로 비용효과적일 확률이 0.80이어도 잘못된 결정의 손실이 매우 크다면 추가 정보의 가치가 클 수 있다.

EVPI는 비용효과적일 확률이 아니라 잘못된 의사결정으로 인한 기대 기회손실의 크기를 측정한다.

여러 전략을 비교할 때는 비용효과수용경계(cost-effectiveness acceptability frontier, CEAF)도 구분해야 한다. 지불의사금액 \(\lambda\)에서 평균 순편익이 가장 큰 전략을

\[ d^*(\lambda)=\arg\max_d \mathbb{E}\{NB_d(\lambda)\} \]

라고 하면 CEAF는 그 현재 최적 전략이 PSA 표본에서도 실제 최적일 확률이다.

\[ CEAF(\lambda) = P\left[d^*(\lambda) = \arg\max_d NB_d(\theta;\lambda) \mid y\right]. \]

개별 CEAC가 가장 높은 전략과 평균 순편익이 가장 높은 전략이 항상 같지는 않다. CEAF는 기대가치 기준으로 선택된 전략의 결정 불확실성을 보여주지만, 역시 오류의 크기를 반영하지 않으므로 EVPI를 대체하지 못한다.

Warning비용효과적일 확률과 의사결정

\(P(INB>0 \mid y)\)는 의사결정 불확실성을 보여주는 유용한 지표이다. 하지만 최적 의사결정은 확률 자체가 아니라 기대순편익 \(\mathbb{E}(INB \mid y)\)에 의해 결정된다. EVPI는 이 불확실성이 의사결정 가치에 얼마나 중요한지를 측정한다.

EVPPI

EVPI는 모든 불확실성을 완벽히 제거할 때의 가치이다. 하지만 실제 추가 연구는 특정 모수 또는 특정 모수군의 불확실성만 줄인다. 예를 들어 장기 생존효과, 효용값, 비용, 이상반응 발생확률, 하위군 치료효과 중 일부만 더 정확히 알 수 있다.

모수 벡터를 \(\theta=(\phi,\psi)\)로 나누자. 여기서 \(\phi\)는 추가 정보를 얻고 싶은 관심 모수군이고, \(\psi\)는 나머지 모수이다. 완벽한 부분정보의 기대가치(expected value of partial perfect information, EVPPI)는 다음과 같이 정의된다.

\[ EVPPI(\phi;\lambda)= \mathbb{E}_{\phi \mid y}\left[ \max_{d \in \mathcal{D}} \mathbb{E}_{\psi \mid \phi,y}\{NB(d,\phi,\psi;\lambda)\} \right] - \max_{d \in \mathcal{D}} \mathbb{E}_{\theta \mid y}\{NB(d,\theta;\lambda)\}. \]

EVPPI는 “\(\phi\)만 완벽하게 알게 되면 기대순편익이 얼마나 증가하는가?”라는 질문에 답한다. 따라서 어떤 불확실성을 줄이는 연구가 우선순위가 높은지 판단하는 데 사용된다.

계산을 명확히 하기 위해 전략별 조건부 기대순편익 함수를 다음과 같이 정의할 수 있다.

\[ m_d(\phi) = \mathbb{E}_{\psi\mid\phi,y} \{NB(d,\phi,\psi;\lambda)\}. \]

그러면 EVPPI의 첫 번째 항은 \(\phi\)가 주어질 때 가장 큰 \(m_d(\phi)\)를 선택한 뒤 \(\phi\)에 대해 평균한 값이다.

\[ \mathbb{E}_{\phi\mid y}\{\max_d m_d(\phi)\}. \]

\(\psi\)와 \(\phi\)가 상관되어 있다면 \(p(\psi\mid\phi,y)\)를 사용해야 한다. 두 모수군을 독립으로 가정해 주변분포에서 따로 표집하면 조건부 평균이 왜곡되어 EVPPI가 과대 또는 과소평가될 수 있다.

EVPPI는 모수의 통계적 불확실성이 큰지를 묻는 지표가 아니라 그 모수의 불확실성이 최적 전략의 선택에 영향을 주는지를 묻는다. 추정 표준오차가 큰 모수라도 모든 전략에 비슷하게 작용하면 EVPPI는 작을 수 있다. 반대로 분산이 작아도 전략 간 순편익 차이에 직접 작용하는 모수는 높은 EVPPI를 가질 수 있다.

그림의 내부 기대값은 관심 모수 \(\phi\)가 알려진 뒤에도 남아 있는 \(\psi\)의 불확실성을 평균하는 단계이다. 따라서 EVPPI는 \(\phi\) 이외의 모수를 고정하는 분석이 아니라, 나머지 불확실성을 그대로 유지하면서 \(\phi\)에 관한 정보만 완벽해지는 상황을 평가한다.

EVPPI는 항상 EVPI보다 작거나 같다.

\[ 0 \le EVPPI(\phi;\lambda) \le EVPI(\lambda). \]

관심 정보집합이 중첩되어 \(\phi_1\subseteq\phi_2\)이면 정보의 단조성에 의해 다음 관계가 성립한다.

\[ EVPPI(\phi_1;\lambda) \le EVPPI(\phi_2;\lambda). \]

그러나 서로 겹치지 않는 두 모수군의 EVPPI는 일반적으로 가산적이지 않다.

\[ EVPPI(\phi_1,\phi_2) \ne EVPPI(\phi_1)+EVPPI(\phi_2). \]

두 모수군 사이의 상관성과 의사결정함수의 비선형성 때문에 공동 정보의 가치에는 상호작용이 존재할 수 있다.

관심 모수군 \(\phi\)가 전체 모수 \(\theta\)와 같으면 EVPPI는 EVPI가 된다. 반대로 \(\phi\)의 불확실성이 의사결정에 거의 영향을 주지 않으면 EVPPI는 0에 가깝다.

직접적인 중첩 Monte Carlo 계산은 계산량이 매우 클 수 있다. 실무에서는 일반화가법모형, Gaussian process, 회귀 기반 메타모형, 비모수 회귀를 이용해 \(m_d(\phi)\)를 추정한다. 이때 회귀모형의 예측오차가 EVPPI에 영향을 주므로 교차검증, 잔차 진단, 반복 계산에 따른 안정성을 확인해야 한다. 단순 구간화 방법은 교육적으로 유용하지만, 연속 모수가 여러 개이거나 관계가 비선형이면 구간 수에 민감할 수 있다.

EVSI와 연구 설계

EVPPI는 특정 모수군을 완벽히 알게 되는 가상의 상황을 다룬다. 실제 연구는 완벽한 정보를 제공하지 않고 표본자료를 추가로 제공한다. 표본정보의 기대가치(expected value of sample information, EVSI)는 특정 연구 설계가 제공할 표본자료가 의사결정의 기대가치를 얼마나 증가시키는지를 나타낸다.

연구 설계를 \(\eta\), 미래 자료를 \(x\)라고 하자. 현재 자료 \(y\)가 있고, 추가 연구를 수행하면 \(x\)가 관찰된다. 이때 EVSI는 다음과 같이 정의된다.

미래 자료의 사전예측분포는 모수 불확실성과 표본변동을 모두 적분한다.

\[ p(x\mid y,\eta) = \int p(x\mid\theta,\eta) \,p(\theta\mid y)d\theta. \]

각 가능한 미래 자료 \(x\)에 대해 사후분포 \(p(\theta\mid y,x,\eta)\)를 갱신하고 최적 전략을 다시 선택한 뒤, 그 개선분을 \(p(x\mid y,\eta)\)에 대해 평균한 것이 EVSI이다. 이 때문에 EVSI를 사전사후 분석이라고 부른다.

\[ EVSI(\eta;\lambda)= \mathbb{E}_{x \mid y,\eta}\left[ \max_{d \in \mathcal{D}} \mathbb{E}_{\theta \mid y,x,\eta}\{NB(d,\theta;\lambda)\} \right] - \max_{d \in \mathcal{D}} \mathbb{E}_{\theta \mid y}\{NB(d,\theta;\lambda)\}. \]

연구 수행 여부는 EVSI 자체가 아니라 연구비용을 뺀 순가치로 판단해야 한다. 모집단 EVSI를 \(Population\ EVSI(\eta;\lambda)\), 연구비용을 \(Cost(\eta)\)라고 하면 표본정보의 기대순가치(expected net benefit of sampling, ENBS)는 다음과 같다.

\[ ENBS(\eta;\lambda)=Population\ EVSI(\eta;\lambda)-Cost(\eta). \]

\(ENBS>0\)이면 해당 연구 설계는 기대가치 관점에서 수행할 가치가 있다. 여러 연구 설계가 가능하면 \(ENBS\)가 가장 큰 설계를 선택할 수 있다.

실제 연구가 특정 모수군 \(\phi\)에만 직접적인 정보를 제공한다면 다음 포함관계가 성립한다.

\[ 0\le EVSI(\eta;\lambda) \le EVPPI(\phi;\lambda) \le EVPI(\lambda). \]

표본수가 증가하면 일반적으로 EVSI는 증가하지만 한계증가분은 감소하며, 무한히 큰 표본에서도 해당 연구가 구조적 불확실성이나 측정오류를 제거하지 못하면 관련 EVPPI에 도달하지 못할 수 있다.

연구 지연과 대상 환자 감소를 명시하면 모집단 ENBS는 다음과 같이 표현할 수 있다.

\[ ENBS(\eta) = EVSI_{person}(\eta) \sum_{t=L(\eta)}^{T-1} \frac{N_tu_t}{(1+r)^t} - C_{fixed}(\eta) - C_{variable}(\eta) - OC_{delay}(\eta). \]

여기서 \(L(\eta)\)는 결과가 정책에 반영될 때까지의 기간이고, \(OC_{delay}\)는 연구기간 중 발생하는 채택 또는 비채택의 기회비용이다. 표본수를 늘리면 개인당 EVSI는 증가하지만 연구비와 연구기간도 증가할 수 있으므로, ENBS는 중간 표본수에서 최대가 될 수 있다.

그림에서 EVSI 곡선은 정보량 증가에 따라 상승하지만 완벽한 정보의 가치보다 높아질 수 없다. 연구비용이 표본수와 함께 증가하므로 두 곡선의 차이인 ENBS가 최대가 되는 표본수가 기대가치 관점의 최적 설계가 된다. 단, 윤리적 표본수, 검정력, 추적기간, 실행 가능성은 별도의 제약조건으로 함께 고려해야 한다.

EVSI와 전통적 표본수 계산의 차이

전통적 표본수 계산은 주어진 유의수준과 검정력에서 특정 효과를 검출하는 데 필요한 표본수를 구한다. EVSI 기반 설계는 가능한 연구결과가 실제 정책을 얼마나 바꾸고 그 변화가 얼마의 순편익을 만드는지를 평가한다. 따라서 효과가 통계적으로 검출되더라도 정책이 바뀌지 않는 연구는 EVSI가 작을 수 있고, 반대로 비교적 작은 연구가 의사결정 경계의 불확실성을 크게 줄이면 높은 ENBS를 가질 수 있다.

EVSI는 임상시험에만 적용되지 않는다. 장기 추적연구, 질병등록자료, 실제임상자료, 효용 연구, 자원사용 조사, 가격 또는 위험분담 자료도 의사결정모형의 특정 불확실성을 줄일 수 있다. 연구설계 \(\eta\)에는 표본수뿐 아니라 추적기간, 측정빈도, 비교군, 대상 환자군, 결과변수와 분석방법이 포함된다.

조건부 급여와 정보의 가치

정보의 가치 분석은 조건부 급여 또는 위험분담제와도 연결된다. 현재 기대순편익이 양수이면 신약을 급여하는 것이 합리적일 수 있지만, EVPI 또는 EVSI가 크다면 근거 생성과 연계한 급여가 더 적절할 수 있다. 이 경우 정책 질문은 다음처럼 바뀐다.

  • 현재 신약을 급여할 것인가?
  • 급여한다면 어떤 환자군에 제한할 것인가?
  • 추가 자료 수집을 조건으로 할 것인가?
  • 추가 연구의 설계와 기간은 어떻게 정할 것인가?
  • 연구가 진행되는 동안 발생하는 기회비용과 환자 접근성은 어떻게 균형을 맞출 것인가?

VOI 분석은 이러한 질문에 정량적인 구조를 제공한다. 다만 VOI 결과는 연구 수행 가능성, 윤리성, 시간 지연, 예산 영향, 제도적 수용 가능성과 함께 해석해야 한다.

조건부 정책은 크게 두 형태로 구분할 수 있다. 근거생성과 함께 채택(approval with research)은 연구기간에도 신약 접근을 허용하고 추가 자료를 수집한다. 연구에서만 사용(only in research)은 연구 참여자에게만 기술을 허용하거나 결과가 나올 때까지 일반 채택을 보류한다. 두 정책의 차이는 연구기간 중 환자가 받는 치료와 발생하는 기회비용이다.

현재 신약의 기대순편익이 양수이고 결정이 가역적이라면 채택과 연구를 병행하는 전략이 자연스러울 수 있다. 그러나 채택 후 환자 모집이 어려워지거나 가격과 임상관행이 고착되어 결정이 비가역적이면 연구에서만 사용하거나 제한적 급여를 고려할 수 있다. 반대로 현재 신약의 기대순편익이 음수여도 EVSI와 ENBS가 크다면 연구 자체는 가치가 있을 수 있다.

가격협상도 정보가치와 상호작용한다. 가격 인하로 평균 INB가 의사결정 경계에서 멀어지면 현재 결정의 오류 가능성과 EVPI가 감소할 수 있다. 따라서 가격, 급여조건, 연구설계는 순차적으로 독립 결정하기보다 공동 정책대안으로 비교하는 것이 바람직하다.

compute_metrics <- function(lambda, delta_q, delta_c) {
  inb <- lambda * delta_q - delta_c
  current_value <- max(mean(inb), 0)
  perfect_value <- mean(pmax(inb, 0))
  data.frame(
    lambda = lambda,
    mean_inb = mean(inb),
    ceac = mean(inb > 0),
    evpi = perfect_value - current_value
  )
}

evppi_binning <- function(phi, inb, n_bins = 20) {
  breaks <- unique(quantile(phi, probs = seq(0, 1, length.out = n_bins + 1),
                            na.rm = TRUE))
  group <- cut(phi, breaks = breaks, include.lowest = TRUE, labels = FALSE)
  cond_mean <- ave(inb, group, FUN = mean)
  mean(pmax(cond_mean, 0)) - max(mean(inb), 0)
}

expected_positive_normal <- function(mu, sd) {
  if (sd <= 0) return(max(mu, 0))
  z <- mu / sd
  sd * dnorm(z) + mu * pnorm(z)
}

evsi_normal_normal <- function(n, mu0, tau, sigma) {
  var_preposterior_mean <- tau^4 / (tau^2 + sigma^2 / n)
  sd_preposterior_mean <- sqrt(var_preposterior_mean)
  expected_value_after_study <- expected_positive_normal(mu0, sd_preposterior_mean)
  expected_value_after_study - max(mu0, 0)
}

## 급여 결정기관이 내려야 할 두 개의 개념적으로 다른 결정 {#sec-two-decisions}

신약의 경제성 평가 결과를 검토하는 급여 결정기관은 적어도 두 가지 결정을 내려야 한다. 첫 번째는 **현재의 근거를 바탕으로 신약을 급여할 것인지**에 관한 결정이다. 두 번째는 **현재의 불확실성을 줄이기 위해 추가 연구를 수행할 가치가 있는지**에 관한 결정이다.

이 두 결정은 서로 관련되어 있지만 동일하지 않다. 현재 근거하에서 신약의 기대순편익이 가장 크다면 신약을 급여하는 것이 기대가치 관점에서 합리적일 수 있다. 그러나 그 결론의 불확실성이 크고, 잘못된 결정의 손실이 크다면 추가 연구도 가치 있을 수 있다. 반대로 불확실성이 존재하더라도 현재 최적 결정이 거의 바뀌지 않거나 잘못된 결정의 손실이 작다면 추가 연구의 가치는 낮을 수 있다.

두 결정은 서로 다른 확률변수를 대상으로 한다. 현재의 급여 결정은 이미 확보된 자료 $y$가 주어졌을 때 전략별 **사후 기대순편익**을 비교한다. 반면 추가 연구 결정은 아직 관찰되지 않은 미래 자료 $X$가 가져올 의사결정 개선분을 연구 수행 전에 평균한다. 따라서 전자는 사후 의사결정이고, 후자는 **사전예측적 또는 사전사후(preposterior) 의사결정**이다.

현재 채택할 전략을 $a$라고 하면 채택 결정은 다음과 같이 표현할 수 있다.

$$
a^*(y)=\arg\max_{a\in\mathcal{D}}
\mathbb{E}_{\theta\mid y}\{NB(a,\theta;\lambda)\}.
$$

추가 연구 설계를 $\eta\in\mathcal{R}$라고 하면 연구 결정은 미래 자료의 분포까지 평균한 순가치로 표현한다.

$$
\eta^*(y)=\arg\max_{\eta\in\mathcal{R}}
\left[
Population\ EVSI(\eta;\lambda)-Cost(\eta)-Cost_{delay}(\eta)
\right].
$$

여기서 $Cost_{delay}(\eta)$는 연구가 완료될 때까지 현재의 비최적 전략을 사용하거나 유망한 기술의 접근을 미루면서 발생하는 기대 기회비용이다. 실제 정책에서는 연구비뿐 아니라 도입비용, 연구 수행기간, 기술의 시장수명, 후속 기술의 등장 가능성, 결정의 가역성도 함께 고려해야 한다.

현재 급여 결정과 연구 결정이 분리되어 있다는 사실은 “불확실성이 크므로 급여하지 않는다”는 결론이 자동으로 성립하지 않음을 의미한다. 현재 기대순편익이 가장 큰 전략은 불확실성이 존재해도 채택할 수 있으며, 추가 연구의 필요성은 그 불확실성이 만들어내는 기대손실과 연구비용을 별도로 비교하여 판단한다.

| 결정 | 핵심 질문 | 판단 기준 | 대표 산출물 |
|---|---|---|---|
| 급여 여부 결정 | 현재 자료하에서 어떤 치료전략을 선택할 것인가? | 기대순편익 최대화 | 기대비용, 기대 QALY, INB, ICER |
| 추가 연구 결정 | 불확실성을 줄이기 위해 연구를 수행할 것인가? | 정보가치와 연구비용 비교 | EVPI, EVPPI, EVSI, ENBS |

::: {.callout-note title="핵심 메시지"}
경제성 평가의 첫 번째 질문은 “지금 어떤 전략을 선택할 것인가?”이다. 두 번째 질문은 “더 많은 정보를 얻는 데 얼마까지 지불할 가치가 있는가?”이다. 첫 번째 질문은 기대순편익 최대화 문제이고, 두 번째 질문은 정보의 가치와 연구비용을 비교하는 문제이다.
:::

가능한 정책 해석은 네 가지 조합으로 정리할 수 있다.

| 현재 최적 결정 | 추가 연구 가치 | 가능한 정책 해석 |
|---|---|---|
| 급여 | 낮음 | 급여 결정 후 추가 연구 필요성 낮음 |
| 급여 | 높음 | 급여하되 조건부 근거 생성 또는 사후자료 수집 고려 |
| 비급여 | 낮음 | 비급여 결정 후 추가 연구 우선순위 낮음 |
| 비급여 | 높음 | 제한적 사용, 조건부 급여, 추가 임상시험, 가격협상 고려 |

![급여 여부 결정과 추가 연구 결정의 개념적 구분](figures/ch07/fig-ch07-two-decisions.png){fig-align="center" width="92%"}

이 구조는 경제성 평가가 단순한 채택 또는 비채택 판단을 넘어 연구 우선순위 설정, 조건부 급여, 위험분담제, 가격협상과 연결될 수 있음을 보여준다. 따라서 경제성 평가 결과를 해석할 때는 비용효과성의 중심 추정값뿐 아니라 불확실성이 의사결정에 미치는 영향도 함께 평가해야 한다.

위 그림은 급여와 연구가 하나의 연속된 순차적 의사결정임을 보여준다. 첫 단계에서는 현재 정보로 기대가치가 가장 큰 전략을 선택하고, 두 번째 단계에서는 추가 정보가 첫 단계의 오류를 줄이는 가치가 연구비와 지연비용을 초과하는지 평가한다. 두 단계의 기준을 혼합하면 통계적으로 불확실하다는 이유만으로 기대가치가 높은 기술의 채택을 지연하거나, 반대로 추가 연구의 가치가 거의 없는 상황에서 관행적으로 대규모 연구를 요구할 수 있다.

### 결정의 가역성과 연구 시점 {.unnumbered}

현재 결정을 나중에 쉽게 변경할 수 있는지 여부도 연구가치에 영향을 준다. 가격이나 급여범위를 신속히 재조정할 수 있는 **가역적 결정**에서는 현재 최선 전략을 채택하면서 연구를 병행하는 정책이 가능하다. 반면 대규모 설비 투자, 임상경로의 고착, 경쟁기술의 퇴출처럼 결정이 사실상 비가역적이면 잘못된 초기 채택의 장기 비용이 커질 수 있다.

연구의 가치도 시간에 따라 감소할 수 있다. 연구 결과가 도출되기 전에 대상 기술이 대체되거나 특허가 만료되면 정보가 영향을 미칠 수 있는 환자 수가 줄어든다. 따라서 모집단 정보가치는 단순한 환자 수뿐 아니라 **정보가 실제 의사결정을 바꿀 수 있는 유효기간**을 반영해야 한다.

## 신약 경제성 평가에서 발생하는 기회손실 {#sec-opportunity-loss}

의사결정은 항상 불확실성하에서 이루어진다. 신약이 실제로 비용효과적인지 완벽하게 알 수 없기 때문에 현재 자료하에서 선택한 전략이 사후적으로 최선이 아닐 수 있다. 이때 잘못된 선택으로 인해 잃는 순편익을 **기회손실(opportunity loss)** 또는 **후회(regret)**라고 한다.

가능한 치료전략의 집합을 $\mathcal{D}$라고 하자. 불확실한 모수 벡터를 $\theta$, 지불의사금액을 $\lambda$라고 할 때 전략 $d \in \mathcal{D}$의 순편익은 다음과 같이 쓸 수 있다.

$$
NB(d,\theta;\lambda)=\lambda Q(d,\theta)-C(d,\theta).
$$

여기서 $Q(d,\theta)$는 전략 $d$의 QALY이고, $C(d,\theta)$는 비용이다. 만약 실제 모수 $\theta$를 알고 있다면 선택해야 할 전략은 다음과 같다.

$$
d^*(\theta)=\arg\max_{d \in \mathcal{D}} NB(d,\theta;\lambda).
$$

그러나 실제 의사결정 시점에는 $\theta$를 알 수 없다. 현재 자료 $y$에 근거하여 사후분포 또는 PSA 분포 $p(\theta \mid y)$를 구성하고, 기대순편익이 가장 큰 전략을 선택한다.

$$
d^*(y)=\arg\max_{d \in \mathcal{D}} \mathbb{E}_{\theta \mid y}\{NB(d,\theta;\lambda)\}.
$$

특정 $\theta$에서 전략 $d$를 선택했을 때의 기회손실은 다음과 같이 정의한다.

$$
OL(d,\theta;\lambda)=\max_{d' \in \mathcal{D}} NB(d',\theta;\lambda)-NB(d,\theta;\lambda).
$$

기회손실은 항상 0 이상이다.

$$
OL(d,\theta;\lambda) \ge 0.
$$

모든 전략의 순편익에 동일한 상수 $k(\theta)$를 더해도 전략 간 차이와 기회손실은 변하지 않는다.

$$
OL(d,\theta;\lambda)
=
\max_{d'}\{NB(d',\theta;\lambda)+k(\theta)\}
-\{NB(d,\theta;\lambda)+k(\theta)\}.
$$

따라서 가치정보분석에서는 기준 전략의 순편익을 0으로 놓거나 증분순편익만 사용해도 동일한 의사결정을 얻는다. 이 **위치 불변성**은 여러 전략의 절대 순편익보다 전략 간 차이에 계산을 집중할 수 있게 한다.

현재 자료하에서 전략 $d$를 선택할 때의 사후 기대 기회손실은 다음과 같다.

$$
\rho(d\mid y)
=
\mathbb{E}_{\theta\mid y}\{OL(d,\theta;\lambda)\}.
$$

현재 최적 전략은 이 기대 기회손실을 최소화하는 전략과 같다.

$$
\arg\min_d \rho(d\mid y)
=
\arg\max_d \mathbb{E}_{\theta\mid y}\{NB(d,\theta;\lambda)\}.
$$

이 등식은 순편익 최대화와 후회 최소화가 서로 다른 분석이 아니라 같은 의사결정을 두 가지 방식으로 표현한 것임을 보여준다.

선택한 전략이 해당 $\theta$에서 최선이면 기회손실은 0이다. 반대로 선택한 전략이 최선이 아니면, 실제 최선 전략을 선택했을 때 얻을 수 있었던 순편익과 실제 선택한 전략의 순편익 차이가 기회손실이 된다.

![기회손실은 선택한 전략과 실제 최선 전략의 순편익 차이이다.](figures/ch07/fig-ch07-opportunity-loss.png){fig-align="center" width="88%"}

::: {.callout-important title="기회손실의 의미"}
기회손실은 현재 선택한 전략이 실제 모수하에서 최선이 아니었을 때 잃게 되는 기대가치이다. 정보의 가치는 이 기회손실을 줄이는 가치로 해석할 수 있다.
:::

### 예제: 두 치료전략의 기회손실 {.unnumbered}

기존 치료와 신약이 있고 지불의사금액이 QALY당 30,000,000원이라고 하자. 특정 모수 $\theta$에서 두 전략의 비용과 QALY가 다음과 같다고 하자.

| 전략 | 비용 | QALY | 순편익 |
|---|---:|---:|---:|
| 기존 치료 | 20,000,000원 | 1.80 | 34,000,000원 |
| 신약 | 35,000,000원 | 2.40 | 37,000,000원 |

순편익은 다음과 같이 계산된다.

$$
NB_0=30{,}000{,}000 \times 1.80-20{,}000{,}000=34{,}000{,}000,
$$

$$
NB_1=30{,}000{,}000 \times 2.40-35{,}000{,}000=37{,}000{,}000.
$$

위 예에서는 두 전략에 공통으로 발생하는 비용이나 건강결과는 순편익 차이에 영향을 주지 않는다. 신약과 기존 치료의 증분순편익은 3,000,000원이며, 이는 기존 치료를 잘못 선택했을 때의 기회손실과 정확히 같다.

이 경우 실제 최선 전략은 신약이다. 만약 의사결정자가 기존 치료를 선택했다면 기회손실은 다음과 같다.

$$
OL(0,\theta)=37{,}000{,}000-34{,}000{,}000=3{,}000{,}000.
$$

반대로 신약을 선택했다면 기회손실은 0이다.

## 신약의 급여 결정을 내리는 데 통계적 가설검정이 부적절한 이유 {#sec-hypothesis-testing-not-enough}

임상시험에서는 치료효과의 존재 여부를 평가하기 위해 통계적 가설검정이 널리 사용된다. 예를 들어 새로운 항암제가 기존 치료보다 생존기간을 연장하는지 평가하기 위해 다음과 같은 귀무가설을 설정할 수 있다.

$$
H_0:\Delta Q=0.
$$

생존분석에서는 위험비에 대해 다음과 같은 가설을 설정할 수 있다.

$$
H_0:HR=1.
$$

그러나 급여 의사결정의 질문은 치료효과가 0인지 여부가 아니다. 급여 의사결정의 핵심 질문은 다음이다.

$$
\lambda\Delta Q-\Delta C>0 \quad ?
$$

즉, 신약의 증분 QALY에 지불의사금액을 곱한 가치가 증분비용보다 큰지를 판단하는 문제이다. 증분순편익은 다음과 같이 정의한다.

$$
INB(\lambda)=\lambda\Delta Q-\Delta C.
$$

현재 자료 $y$에 기반한 급여 결정은 기대증분순편익을 기준으로 할 수 있다.

$$
\mathbb{E}\{INB(\lambda) \mid y\}>0.
$$

통계적 가설검정이 급여 결정에 부적절한 이유는 다음과 같다. 첫째, p-value는 비용을 고려하지 않는다. 둘째, p-value는 효과 크기의 사회적 가치를 반영하지 않는다. 셋째, p-value는 잘못된 결정으로 인한 기회손실을 직접적으로 알려주지 않는다. 넷째, 급여 결정은 이분법적 가설검정보다 기대가치 극대화 문제에 가깝다.

가설검정의 임계값은 사전에 정한 제1종 오류확률 $\alpha$에 의해 결정된다. 그러나 의사결정의 최적 임계값은 잘못된 채택과 잘못된 비채택이 초래하는 손실에 의해 결정된다. 두 오류의 손실이 같다는 보장은 없으며, 환자 수와 가격, 치료효과의 크기에 따라 손실은 크게 달라진다. 따라서 $p<0.05$라는 규칙은 경제적 손실함수와 일반적으로 일치하지 않는다.

증분 QALY가 양수인지 검정하는 문제와 신약이 비용효과적인지 판단하는 문제의 경계도 다르다. 증분비용이 $\Delta C>0$일 때 비용효과성의 효과 임계값은 다음과 같다.

$$
\Delta Q>\frac{\Delta C}{\lambda}.
$$

즉, 비용효과성은 $\Delta Q=0$이 아니라 $\Delta Q=\Delta C/\lambda$를 경계로 한다. 가격이 높거나 지불의사금액이 낮을수록 요구되는 최소 건강효과가 커진다.

신뢰구간 역시 의사결정 불확실성을 충분히 요약하지 못한다. 증분효과와 증분비용의 결합분포, 두 변수의 공분산, 지불의사금액을 함께 고려해야 증분순편익 분포를 얻을 수 있다. 경제성 평가에서는 다음 확률과 기대값이 서로 다른 정보를 제공한다.

$$
P\{INB(\lambda)>0\mid y\},
\qquad
\mathbb{E}\{INB(\lambda)\mid y\},
\qquad
\mathbb{E}\{OL\mid y\}.
$$

첫 번째는 신약이 비용효과적일 확률, 두 번째는 현재 선택을 결정하는 평균 가치, 세 번째는 불확실성을 제거할 때 회피할 수 있는 기대손실이다.

![통계적 가설검정과 경제성 평가 의사결정의 차이](figures/ch07/fig-ch07-testing-vs-decision.png){fig-align="center" width="92%"}

::: {.callout-warning title="통계적 유의성과 비용효과성은 다르다"}
치료효과가 통계적으로 유의하다고 해서 반드시 비용효과적인 것은 아니다. 반대로 통계적으로 유의하지 않더라도 기대순편익이 양수라면 현재 근거하에서 신약을 선택하는 것이 기대가치 관점에서 합리적일 수 있다.

그림의 왼쪽 경로는 표준오차와 귀무가설을 중심으로 증거의 강도를 평가하고, 오른쪽 경로는 가능한 결과마다 비용과 건강가치를 결합하여 행동의 기대결과를 평가한다. 두 접근은 목적이 다르므로 임상적 유의성, 통계적 유의성, 비용효과성을 동일한 판정으로 해석해서는 안 된다.
:::

### 효과는 유의하지만 비용효과적이지 않은 경우 {.unnumbered}

신약이 기존 치료보다 평균 QALY를 0.10 증가시키고, 그 차이가 통계적으로 유의하다고 하자. 그러나 추가 비용이 20,000,000원이고 지불의사금액이 QALY당 50,000,000원이라면 증분순편익은 다음과 같다.

$$
INB=50{,}000{,}000 \times 0.10-20{,}000{,}000=-15{,}000{,}000.
$$

이 경우 효과는 존재할 수 있지만, 현재 가격에서는 비용효과적이지 않다.

### 효과가 유의하지 않지만 기대순편익이 양수인 경우 {.unnumbered}

반대로 표본수가 작아 증분 QALY의 신뢰구간이 0을 포함하더라도, 평균 증분 QALY가 0.30이고 추가 비용이 8,000,000원이라면 지불의사금액 50,000,000원에서 증분순편익은 다음과 같다.

$$
INB=50{,}000{,}000 \times 0.30-8{,}000{,}000=7{,}000{,}000.
$$

이 경우 불확실성은 크지만 현재 자료하의 기대가치 기준으로는 신약을 선택하는 것이 합리적일 수 있다. 이때 중요한 추가 질문은 불확실성이 얼마나 큰지, 그리고 추가 연구의 가치가 연구비용보다 큰지이다.

## 통계적 의사결정론에 대한 개요 {#sec-decision-theory-overview}

통계적 의사결정론은 불확실성하에서 최적의 행동을 선택하기 위한 수리적 틀이다. 경제성 평가에서 의사결정론은 다음 네 가지 요소로 구성된다.

의사결정론에서는 자료의 생성과정, 미지의 상태, 가능한 행동, 행동의 결과를 명시적으로 분리한다. 통계모형은 $p(y\mid\theta)$를 통해 자료가 상태 $\theta$에 관해 제공하는 정보를 나타내지만, 통계모형만으로 어떤 행동을 선택할지는 결정되지 않는다. 행동의 선택에는 결과의 가치를 나타내는 순편익 또는 손실함수가 추가로 필요하다.

1. 가능한 의사결정 또는 치료전략의 집합 $\mathcal{D}$
2. 불확실한 상태 또는 모수 $\theta$
3. 각 결정과 상태에서의 가치 함수 $NB(d,\theta)$ 또는 손실함수 $L(d,\theta)$
4. 기대가치를 최대화하거나 기대손실을 최소화하는 의사결정 규칙

![통계적 의사결정론의 구성요소](figures/ch07/fig-ch07-decision-theory-objects.png){fig-align="center" width="92%"}

그림에서 자료모형은 관찰자료와 불확실한 모수를 연결하고, 가치모형은 모수와 정책결과를 연결한다. 최종 의사결정은 두 모형을 결합한 기대순편익을 비교하여 얻는다. 통계적 추정이 정확하더라도 가치모형이 잘못 설정되면 의사결정은 잘못될 수 있으며, 반대로 임상적 불확실성이 커도 잘못된 결정의 손실이 작으면 현재 정책은 안정적일 수 있다.

### 순편익의 선형성과 위험중립성 {.unnumbered}

표준 순편익

$$
NB=\lambda Q-C
$$

는 비용과 QALY의 선형 결합이다. 이 표현은 집단 수준에서 동일한 QALY 증가에 동일한 사회적 가치를 부여하고, 불확실한 순편익에 대해서는 기대값으로 행동을 선택하는 **위험중립적 의사결정**을 전제로 한다. 정책결정자가 예산 초과 위험이나 심각한 하방위험에 특별한 가중치를 둔다면 비선형 효용함수 $U(NB)$를 사용할 수 있다.

$$
d^*(y)=\arg\max_d
\mathbb{E}_{\theta\mid y}[U\{NB(d,\theta)\}].
$$

다만 비선형 효용을 사용하면 QALY당 일정한 지불의사금액에 기반한 표준 순편익 해석이 달라지므로, 위험회피의 근거와 함수 형태를 명확히 제시해야 한다.

### 예산제약이 있는 포트폴리오 의사결정 {.unnumbered}

개별 기술의 채택을 독립적으로 평가하는 순편익 규칙은 예산이 유연하거나 기회비용이 $\lambda$에 적절히 반영되었다는 가정에 의존한다. 여러 기술을 동시에 선택하면서 총예산 $B$를 초과할 수 없다면 의사결정은 다음의 포트폴리오 최적화 문제가 된다.

$$
\max_{x_1,\ldots,x_J}
\sum_{j=1}^{J}x_j\,\mathbb{E}(Q_j)
\quad\text{subject to}\quad
\sum_{j=1}^{J}x_j\,\mathbb{E}(C_j)\le B,
$$

여기서 $x_j\in\{0,1\}$는 기술 $j$의 채택 여부이다. 고정된 $\lambda$를 이용한 순편익은 이러한 제약문제의 라그랑주 표현으로 볼 수 있다. 따라서 $\lambda$는 단순한 사회적 선호값뿐 아니라 제한된 의료자원에서 발생하는 건강의 기회비용과 연결된다.

### Bayes action {.unnumbered}

자료 $y$가 관찰된 뒤, 모수 불확실성을 $p(\theta \mid y)$로 표현한다고 하자. 전략 $d$의 사후 기대순편익은 다음과 같다.

$$
\mathbb{E}_{\theta \mid y}\{NB(d,\theta;\lambda)\}
=
\int NB(d,\theta;\lambda)p(\theta \mid y)d\theta.
$$

기대순편익을 최대화하는 Bayes action은 다음과 같다.

$$
d^*(y)=\arg\max_{d \in \mathcal{D}} \mathbb{E}_{\theta \mid y}\{NB(d,\theta;\lambda)\}.
$$

두 전략만 비교할 때 기존 치료를 $d=0$, 신약을 $d=1$이라고 하자. 증분순편익을 $INB(\theta;\lambda)=NB_1(\theta;\lambda)-NB_0(\theta;\lambda)$로 정의하면 신약 선택 규칙은 다음과 같이 단순화된다.

$$
\text{신약 선택} \quad \Longleftrightarrow \quad
\mathbb{E}_{\theta \mid y}\{INB(\theta;\lambda)\}>0.
$$

### 손실함수와 위험함수 {.unnumbered}

의사결정론은 손실함수로도 표현할 수 있다. 특정 전략 $d$와 모수 $\theta$에서의 손실을 $L(d,\theta)$라고 하자. 자료 $y$가 주어진 뒤 기대손실을 최소화하는 전략은 다음과 같다.

$$
d^*(y)=\arg\min_{d \in \mathcal{D}} \mathbb{E}_{\theta \mid y}\{L(d,\theta)\}.
$$

경제성 평가에서는 손실함수를 기회손실로 정의할 수 있다.

$$
L(d,\theta)=OL(d,\theta;\lambda).
$$

기회손실은 완벽한 상태정보가 있을 때 선택할 전략을 기준으로 정규화된 손실이다. 일반적인 손실함수와 달리 최선 전략의 손실이 각 $\theta$에서 0이 되므로, 서로 다른 모수 상태에서 손실을 비교하기 쉽다. 그러나 건강불평등, 예산초과, 실행 가능성처럼 순편익에 포함되지 않은 정책목표가 있다면 손실함수에 별도의 항을 추가해야 한다.

이 경우 기대손실을 최소화하는 것과 기대순편익을 최대화하는 것은 동일한 의사결정 규칙을 제공한다.

빈도론적 의사결정론에서는 의사결정 규칙 $\delta(Y)$의 위험함수를 다음과 같이 정의한다.

$$
R(\theta,\delta)=\mathbb{E}_{Y \mid \theta}\{L(\delta(Y),\theta)\}.
$$

베이지안 의사결정론에서는 사전분포 또는 사후분포에 대해 위험함수를 평균한다. 현재 자료가 주어진 상황에서는 다음과 같은 사후 기대손실 또는 사후 기대순편익이 직접적인 의사결정 기준이 된다.

$$
\mathbb{E}_{\theta \mid y}\{L(d,\theta)\}, \qquad
\mathbb{E}_{\theta \mid y}\{NB(d,\theta)\}.
$$

경제성 평가는 현재 관찰된 근거하에서의 정책 선택을 다루기 때문에, 베이지안 의사결정론과 매우 자연스럽게 연결된다. 다만 실제 PSA가 반드시 엄밀한 베이지안 사후분포에서 생성되어야 하는 것은 아니다. 빈도론적 추정량의 표준오차와 공분산을 이용해 구성한 모수 불확실성 분포도 의사결정론적 계산에 사용할 수 있다.

## 완벽한 정보의 기대가치 {#sec-evpi}

완벽한 정보의 기대가치(expected value of perfect information, EVPI)는 현재의 불확실성을 완전히 제거할 수 있다면 기대가치가 얼마나 증가하는지를 나타낸다. EVPI는 추가 연구가 가질 수 있는 가치의 이론적 상한이다. 어떤 실제 연구도 모든 불확실성을 완벽히 제거할 수는 없기 때문이다.

현재 자료 $y$가 주어졌다고 하자. 현재 정보하에서의 최적 기대순편익은 다음과 같다.

$$
\max_{d \in \mathcal{D}} \mathbb{E}_{\theta \mid y}\{NB(d,\theta;\lambda)\}.
$$

완벽한 정보가 있다면 각 $\theta$마다 실제로 순편익이 가장 큰 전략을 선택할 수 있다. 따라서 완벽한 정보하에서의 기대순편익은 다음과 같다.

$$
\mathbb{E}_{\theta \mid y}\left[\max_{d \in \mathcal{D}}NB(d,\theta;\lambda)\right].
$$

개인당 EVPI는 두 값의 차이이다.

$$
EVPI(\lambda)=
\mathbb{E}_{\theta \mid y}\left[\max_{d \in \mathcal{D}}NB(d,\theta;\lambda)\right]
-
\max_{d \in \mathcal{D}} \mathbb{E}_{\theta \mid y}\{NB(d,\theta;\lambda)\}.
$$

EVPI는 항상 0 이상이다.

$$
EVPI(\lambda) \ge 0.
$$

EVPI가 음수가 될 수 없는 이유는 완벽한 정보를 얻은 뒤에도 현재 전략을 그대로 선택할 수 있기 때문이다. 정보는 선택 가능한 행동의 집합을 줄이지 않으므로, 합리적인 의사결정자에게 정보의 기대가치는 비음수가 된다. 이는 정보가 선택 가능한 행동을 제한하지 않는다는 성질을 반영한다.

정보집합을 $\mathcal{I}_1\subseteq\mathcal{I}_2$라고 하면 더 풍부한 정보가 제공하는 기대가치는 작아질 수 없다.

$$
V(\mathcal{I}_2)\ge V(\mathcal{I}_1),
$$

여기서

$$
V(\mathcal{I})=
\mathbb{E}_{\mathcal{I}}
\left[
\max_d \mathbb{E}\{NB(d,\theta)\mid\mathcal{I}\}
\right]
$$

이다. EVPI는 현재 정보와 완벽한 정보 사이의 가치 차이이다.

이는 최댓값 함수의 볼록성으로도 이해할 수 있다. 일반적으로 확률변수 $X_d$들에 대해 다음 부등식이 성립한다.

$$
\mathbb{E}\{\max_d X_d\} \ge \max_d \mathbb{E}(X_d).
$$

EVPI는 불확실성의 분산 그 자체가 아니다. 모든 모수가 크게 변하더라도 각 PSA 표본에서 동일한 전략이 항상 최적이면 EVPI는 0이다. 반대로 전체 분산이 비교적 작아도 기대순편익이 의사결정 경계에 위치하고 작은 변화로 최적 전략이 바뀌면 EVPI가 커질 수 있다.

EVPI는 현재 선택한 Bayes action의 기대 기회손실과 같다. 현재 정보하에서 선택한 전략을 $d^*(y)$라고 하면 다음이 성립한다.

$$
\begin{aligned}
\mathbb{E}_{\theta \mid y}\{OL(d^*(y),\theta;\lambda)\}
&=\mathbb{E}_{\theta \mid y}\left[\max_{d \in \mathcal{D}}NB(d,\theta;\lambda)-NB(d^*(y),\theta;\lambda)\right] \\
&=\mathbb{E}_{\theta \mid y}\left[\max_{d \in \mathcal{D}}NB(d,\theta;\lambda)\right]
-\max_{d \in \mathcal{D}} \mathbb{E}_{\theta \mid y}\{NB(d,\theta;\lambda)\} \\
&=EVPI(\lambda).
\end{aligned}
$$

![EVPI는 완벽한 정보하 기대순편익과 현재 정보하 최적 기대순편익의 차이이다.](figures/ch07/fig-ch07-evpi-decomposition.png){fig-align="center" width="82%"}

그림의 첫 번째 항은 각 모수 표본에서 가장 높은 순편익을 선택한 뒤 평균한 값이고, 두 번째 항은 전략별 순편익을 먼저 평균한 뒤 가장 높은 전략을 선택한 값이다. 두 연산의 순서가 다르며, 최댓값의 비선형성 때문에 일반적으로 두 값은 같지 않다. 그 차이가 현재 정보에서 피할 수 없는 기대 후회이다.

### 두 전략 비교에서의 EVPI {.unnumbered}

기존 치료와 신약만 비교한다고 하자. 기준 전략의 순편익을 0으로 두고, 신약의 증분순편익을 다음과 같이 정의한다.

$$
X=INB(\theta;\lambda)=NB_1(\theta;\lambda)-NB_0(\theta;\lambda).
$$

그러면 두 전략 비교에서 EVPI는 다음과 같이 쓸 수 있다.

$$
EVPI(\lambda)=\mathbb{E}\{\max(X,0) \mid y\}-\max\{\mathbb{E}(X \mid y),0\}.
$$

현재 정보하에서 신약을 선택하는 경우, 즉 $\mathbb{E}(X \mid y)>0$이면 잘못된 결정은 실제로 $X<0$일 때 발생한다. 이때 EVPI는 다음과 같다.

$$
EVPI(\lambda)=\mathbb{E}\{(-X)_+ \mid y\},
$$

여기서 $a_+=\max(a,0)$이다. 반대로 현재 정보하에서 기존 치료를 선택하는 경우, 즉 $\mathbb{E}(X \mid y)<0$이면 EVPI는 다음과 같다.

$$
EVPI(\lambda)=\mathbb{E}\{X_+ \mid y\}.
$$

두 전략에서 EVPI는 “잘못된 결정의 확률”과 “잘못되었을 때의 평균 손실”의 곱으로도 분해할 수 있다. 현재 신약을 선택한다면

$$
EVPI
=
P(X<0\mid y)\,
\mathbb{E}(-X\mid X<0,y),
$$

현재 기존 치료를 선택한다면

$$
EVPI
=
P(X>0\mid y)\,
\mathbb{E}(X\mid X>0,y).
$$

따라서 잘못될 확률이 같더라도 오류가 발생했을 때 손실의 크기가 다르면 EVPI는 달라진다. 이 점이 CEAC만으로 추가 연구의 가치를 판단할 수 없는 핵심 이유이다.

### 정규분포 증분순편익에서의 닫힌형 표현 {.unnumbered}

증분순편익이 정규분포를 따른다고 근사할 수 있다고 하자.

$$
X \sim N(\mu,\sigma^2).
$$

$z=\mu/\sigma$라고 하고, $\phi(\cdot)$와 $\Phi(\cdot)$를 표준정규분포의 밀도함수와 누적분포함수라고 하자. 양의 부분의 기대값은 다음 적분에서 유도된다.

$$
\mathbb{E}(X_+)
=
\int_0^{\infty}x\,
\frac{1}{\sigma}\phi\left(\frac{x-\mu}{\sigma}\right)dx.
$$

변수변환 $u=(x-\mu)/\sigma$를 적용하면 다음이 성립한다.

$$
\mathbb{E}(X_+)=\sigma\phi(z)+\mu\Phi(z).
$$

또한 다음도 성립한다.

$$
\mathbb{E}\{(-X)_+\}=\sigma\phi(z)-\mu\Phi(-z).
$$

따라서 $\mu>0$이면 $EVPI=\sigma\phi(z)-\mu\Phi(-z)$이고, $\mu<0$이면 $EVPI=\sigma\phi(z)+\mu\Phi(z)$이다. 이 식은 EVPI가 단순히 불확실성의 크기 $\sigma$만으로 결정되지 않음을 보여준다. 평균 증분순편익 $\mu$가 0에 가까워 의사결정 경계 근처에 있을수록 EVPI가 커질 수 있다.

특히 $\mu=0$이면 현재 두 전략의 기대가치가 같고

$$
EVPI=\frac{\sigma}{\sqrt{2\pi}}
$$

가 된다. 고정된 $\sigma$에서 $|\mu|/\sigma$가 커질수록 현재 최적 전략이 실제로 최적일 가능성이 높아지고 EVPI는 0으로 감소한다. 정규근사는 해석에 유용하지만, INB 분포가 비대칭이거나 다봉형이면 PSA 표본을 직접 사용하는 것이 더 안전하다.

![증분순편익 분포와 의사결정 불확실성](figures/ch07/fig-ch07-inb-distribution.png){fig-align="center" width="82%"}

그림에서 0의 왼쪽 면적은 신약이 비용효과적이지 않을 확률을 나타내지만, EVPI는 그 면적만 사용하지 않는다. 0에서 멀리 떨어진 음의 INB에는 더 큰 기회손실이 부여되므로, 음의 영역에 있는 각 값의 거리까지 함께 적분한다.

### PSA 표본을 이용한 EVPI 계산 {.unnumbered}

PSA 또는 베이지안 사후표본이 $s=1,\ldots,S$개 있다고 하자. 표본 $s$에서 전략 $d$의 순편익을 $NB_d^{(s)}$라고 하면 EVPI의 Monte Carlo 추정량은 다음과 같다.

$$
\widehat{EVPI}(\lambda)=
\frac{1}{S}\sum_{s=1}^{S}\max_{d \in \mathcal{D}}NB_d^{(s)}
-
\max_{d \in \mathcal{D}}\left\{\frac{1}{S}\sum_{s=1}^{S}NB_d^{(s)}\right\}.
$$

두 전략 비교에서는 다음처럼 계산할 수 있다.

$$
\widehat{EVPI}(\lambda)=
\frac{1}{S}\sum_{s=1}^{S}\max\{INB^{(s)}(\lambda),0\}
-
\max\left\{\frac{1}{S}\sum_{s=1}^{S}INB^{(s)}(\lambda),0\right\}.
$$

이 추정량에도 Monte Carlo 오차가 존재한다. 첫 번째 항과 두 번째 항은 동일한 PSA 표본에서 계산되므로 독립이 아니며, 단순히 두 표준오차를 더해서는 안 된다. PSA를 여러 묶음으로 반복하거나 비모수 부트스트랩으로 PSA 행을 재표집하여 EVPI 추정량의 Monte Carlo 표준오차를 평가할 수 있다.

유한한 표본에서 최댓값 연산은 상향편향을 만들 수 있다. 특히 여러 전략의 기대순편익이 비슷하고 $S$가 작을 때

$$
\max_d\left\{\frac{1}{S}\sum_s NB_d^{(s)}\right\}
$$

는 실제 최대 기대순편익을 다소 과대평가할 수 있다. 첫 번째 항은 표본평균이므로 이러한 편향이 상대적으로 작아, 전체 EVPI 추정량은 유한 표본에서 작게 편향될 수 있다. 따라서 EVPI 곡선이 불안정하면 PSA 표본수를 늘리고, 누적 표본수에 따른 EVPI의 수렴을 확인해야 한다. EVPPI와 EVSI의 중첩 시뮬레이션에서는 내부 반복수와 외부 반복수 모두에 따른 오차를 별도로 점검해야 한다.

![지불의사금액에 따른 개인당 EVPI 예시](figures/ch07/fig-ch07-evpi-curve.png){fig-align="center" width="82%"}

EVPI는 지불의사금액 $\lambda$에 따라 달라진다. 두 전략의 기대순편익이 비슷해지는 영역에서는 의사결정이 바뀔 가능성과 잘못된 선택의 기대 손실이 커져 EVPI가 커질 수 있다. 반대로 한 전략이 거의 모든 표본에서 명확히 우월한 영역에서는 EVPI가 낮다.

위 곡선의 정점은 추가 연구가 가장 필요하다고 단정하는 지점이 아니라, 해당 $\lambda$에서 완벽한 정보가 가질 수 있는 개인당 최대 가치를 나타낸다. 실제 연구가치인 EVSI는 EVPI보다 작고, 연구비와 결과 도출까지의 지연을 고려하면 순가치는 더 작아진다.

### 모집단 EVPI {.unnumbered}

개인당 EVPI는 한 명의 환자에게 완벽한 정보를 제공할 때 증가하는 기대가치이다. 정책 의사결정에서는 해당 결정의 영향을 받는 전체 환자집단을 고려해야 한다. 이를 모집단 EVPI(population EVPI)라고 한다.

연도 $t=0,1,\ldots,T-1$에서 의사결정의 영향을 받는 환자 수를 $N_t$, 실제 기술 이용률을 $u_t$, 연 할인율을 $r$이라고 하자. 개인당 EVPI가 모든 연도에서 동일하다고 가정하면 모집단 EVPI는 다음과 같다.

$$
Population\ EVPI(\lambda)
=
EVPI(\lambda)
\sum_{t=0}^{T-1}\frac{N_tu_t}{(1+r)^t}.
$$

이용률을 명시하지 않고 모든 대상 환자가 의사결정의 영향을 받는다고 가정하면 $u_t=1$이 되어 다음의 단순식이 얻어진다.

$$
Population\ EVPI(\lambda)=EVPI(\lambda)\sum_{t=0}^{T-1}\frac{N_t}{(1+r)^t}.
$$

추가 연구의 결과가 $L$년 뒤에 이용 가능하다면 연구가 영향을 줄 수 있는 환자는 보통 $t=L$ 이후의 환자이다. 따라서 연구와 관련된 정보가치에는 다음과 같은 유효 모집단을 사용할 수 있다.

$$
N_{eff}(L)=
\sum_{t=L}^{T-1}\frac{N_tu_t}{(1+r)^t}.
$$

연구기간이 길어질수록 $N_{eff}(L)$가 감소하므로 동일한 개인당 EVSI라도 모집단 EVSI는 낮아진다. 또한 유병 환자와 신규 발생 환자를 모두 포함하는지, 기술의 특허·시장수명과 분석기간이 일치하는지, 현재 환자가 연구 결과의 혜택을 받을 수 있는지를 명확히 해야 한다.

대상 환자 수가 매년 동일하게 $N$이면 다음과 같이 단순화된다.

$$
Population\ EVPI(\lambda)=EVPI(\lambda)N\sum_{t=0}^{T-1}\frac{1}{(1+r)^t}.
$$

![모집단 EVPI 계산에 사용되는 할인된 대상 환자 수](figures/ch07/fig-ch07-population-evpi.png){fig-align="center" width="82%"}

그림에서 각 연도의 막대는 단순한 환자 수가 아니라 할인과 기술 이용률을 반영한 유효 환자 수로 해석해야 한다. 먼 미래의 환자는 할인 때문에 현재 가치가 작고, 연구 결과가 나오기 전의 환자는 EVSI 계산에서 정보의 혜택을 받지 못할 수 있다.

모집단 EVPI는 추가 연구의 사회적 최대 가치를 평가할 때 중요하다. 개인당 EVPI가 작아도 대상 환자 수가 매우 많으면 모집단 EVPI는 클 수 있다. 반대로 개인당 EVPI가 크더라도 대상 환자 수가 매우 적으면 추가 연구의 총 가치는 제한적일 수 있다.

## 통계적 의사결정론 {#sec-statistical-decision-theory}

이 절에서는 앞서 다룬 개념을 경제성 평가 실무에서 어떻게 사용하는지 정리한다. 경제성 평가에서 의사결정론적 계산은 다음 흐름을 따른다.

이 흐름은 PSA 표본 생성에서 끝나지 않는다. 먼저 각 전략의 평균 순편익으로 현재의 최적 전략을 결정하고, 그 다음 PSA 표본별 최적 전략과 현재 전략의 차이를 이용해 기대 기회손실을 계산한다. 이후 정보의 범위를 전체 모수, 특정 모수군, 실제 연구자료로 단계적으로 제한하면서 EVPI, EVPPI, EVSI를 계산한다.

![경제성 평가에서 의사결정론 적용 절차](figures/ch07/fig-ch07-decision-flow.png){fig-align="center" width="92%"}

그림의 각 화살표는 단순한 계산 순서뿐 아니라 조건부 기대값의 수준이 달라짐을 의미한다. EVPI는 $\theta$를 완전히 알게 되는 경우, EVPPI는 $\phi$만 알게 되는 경우, EVSI는 미래 표본자료 $X$를 관찰하는 경우의 기대값을 사용한다.

### CEAC와 EVPI의 차이 {.unnumbered}

비용효과수용곡선(cost-effectiveness acceptability curve, CEAC)은 특정 지불의사금액에서 전략이 비용효과적일 확률을 보여준다. 두 전략 비교에서는 다음과 같다.

$$
CEAC(\lambda)=P\{INB(\theta;\lambda)>0 \mid y\}.
$$

CEAC는 의사결정 불확실성의 확률적 표현이다. 그러나 최적 의사결정은 이 확률 자체가 아니라 기대순편익에 의해 결정된다. 예를 들어 비용효과적일 확률이 0.60이어도 비용효과적인 경우의 이득이 매우 크고 그렇지 않은 경우의 손실이 작으면 기대순편익이 클 수 있다. 반대로 비용효과적일 확률이 0.80이어도 잘못된 결정의 손실이 매우 크다면 추가 정보의 가치가 클 수 있다.

EVPI는 비용효과적일 확률이 아니라 잘못된 의사결정으로 인한 기대 기회손실의 크기를 측정한다.

여러 전략을 비교할 때는 **비용효과수용경계(cost-effectiveness acceptability frontier, CEAF)**도 구분해야 한다. 지불의사금액 $\lambda$에서 평균 순편익이 가장 큰 전략을

$$
d^*(\lambda)=\arg\max_d \mathbb{E}\{NB_d(\lambda)\}
$$

라고 하면 CEAF는 그 현재 최적 전략이 PSA 표본에서도 실제 최적일 확률이다.

$$
CEAF(\lambda)
=
P\left[d^*(\lambda)
=
\arg\max_d NB_d(\theta;\lambda)
\mid y\right].
$$

개별 CEAC가 가장 높은 전략과 평균 순편익이 가장 높은 전략이 항상 같지는 않다. CEAF는 기대가치 기준으로 선택된 전략의 결정 불확실성을 보여주지만, 역시 오류의 크기를 반영하지 않으므로 EVPI를 대체하지 못한다.

| 지표 | 질문 | 수식 | 해석 |
|---|---|---|---|
| CEAC | 신약이 비용효과적일 확률은 얼마인가? | $P(INB>0 \mid y)$ | 불확실성의 확률적 표현 |
| EVPI | 불확실성을 제거하면 기대가치가 얼마나 증가하는가? | $\mathbb{E}\{\max_d NB_d\}-\max_d\mathbb{E}(NB_d)$ | 추가 정보의 최대 가치 |

![CEAC와 EVPI의 개념적 차이](figures/ch07/fig-ch07-ceac-evpi.png){fig-align="center" width="82%"}

그림에서 CEAC의 세로축은 사건의 확률이고 EVPI의 세로축은 화폐 단위의 기대손실이다. 따라서 두 곡선은 척도와 정책질문이 다르며, 한 곡선의 높이를 다른 곡선의 높이로 직접 해석할 수 없다.

::: {.callout-warning title="비용효과적일 확률과 의사결정"}
$P(INB>0 \mid y)$는 의사결정 불확실성을 보여주는 유용한 지표이다. 하지만 최적 의사결정은 확률 자체가 아니라 기대순편익 $\mathbb{E}(INB \mid y)$에 의해 결정된다. EVPI는 이 불확실성이 의사결정 가치에 얼마나 중요한지를 측정한다.
:::

### EVPPI {.unnumbered}

EVPI는 모든 불확실성을 완벽히 제거할 때의 가치이다. 하지만 실제 추가 연구는 특정 모수 또는 특정 모수군의 불확실성만 줄인다. 예를 들어 장기 생존효과, 효용값, 비용, 이상반응 발생확률, 하위군 치료효과 중 일부만 더 정확히 알 수 있다.

모수 벡터를 $\theta=(\phi,\psi)$로 나누자. 여기서 $\phi$는 추가 정보를 얻고 싶은 관심 모수군이고, $\psi$는 나머지 모수이다. 완벽한 부분정보의 기대가치(expected value of partial perfect information, EVPPI)는 다음과 같이 정의된다.

$$
EVPPI(\phi;\lambda)=
\mathbb{E}_{\phi \mid y}\left[
\max_{d \in \mathcal{D}}
\mathbb{E}_{\psi \mid \phi,y}\{NB(d,\phi,\psi;\lambda)\}
\right]
-
\max_{d \in \mathcal{D}}
\mathbb{E}_{\theta \mid y}\{NB(d,\theta;\lambda)\}.
$$

EVPPI는 “$\phi$만 완벽하게 알게 되면 기대순편익이 얼마나 증가하는가?”라는 질문에 답한다. 따라서 어떤 불확실성을 줄이는 연구가 우선순위가 높은지 판단하는 데 사용된다.

계산을 명확히 하기 위해 전략별 조건부 기대순편익 함수를 다음과 같이 정의할 수 있다.

$$
m_d(\phi)
=
\mathbb{E}_{\psi\mid\phi,y}
\{NB(d,\phi,\psi;\lambda)\}.
$$

그러면 EVPPI의 첫 번째 항은 $\phi$가 주어질 때 가장 큰 $m_d(\phi)$를 선택한 뒤 $\phi$에 대해 평균한 값이다.

$$
\mathbb{E}_{\phi\mid y}\{\max_d m_d(\phi)\}.
$$

$\psi$와 $\phi$가 상관되어 있다면 $p(\psi\mid\phi,y)$를 사용해야 한다. 두 모수군을 독립으로 가정해 주변분포에서 따로 표집하면 조건부 평균이 왜곡되어 EVPPI가 과대 또는 과소평가될 수 있다.

EVPPI는 모수의 통계적 불확실성이 큰지를 묻는 지표가 아니라 그 모수의 불확실성이 **최적 전략의 선택에 영향을 주는지**를 묻는다. 추정 표준오차가 큰 모수라도 모든 전략에 비슷하게 작용하면 EVPPI는 작을 수 있다. 반대로 분산이 작아도 전략 간 순편익 차이에 직접 작용하는 모수는 높은 EVPPI를 가질 수 있다.

![EVPPI는 특정 모수군의 불확실성만 제거하는 정보가치이다.](figures/ch07/fig-ch07-evppi-concept.png){fig-align="center" width="90%"}

그림의 내부 기대값은 관심 모수 $\phi$가 알려진 뒤에도 남아 있는 $\psi$의 불확실성을 평균하는 단계이다. 따라서 EVPPI는 $\phi$ 이외의 모수를 고정하는 분석이 아니라, 나머지 불확실성을 그대로 유지하면서 $\phi$에 관한 정보만 완벽해지는 상황을 평가한다.

EVPPI는 항상 EVPI보다 작거나 같다.

$$
0 \le EVPPI(\phi;\lambda) \le EVPI(\lambda).
$$

관심 정보집합이 중첩되어 $\phi_1\subseteq\phi_2$이면 정보의 단조성에 의해 다음 관계가 성립한다.

$$
EVPPI(\phi_1;\lambda)
\le
EVPPI(\phi_2;\lambda).
$$

그러나 서로 겹치지 않는 두 모수군의 EVPPI는 일반적으로 가산적이지 않다.

$$
EVPPI(\phi_1,\phi_2)
\ne
EVPPI(\phi_1)+EVPPI(\phi_2).
$$

두 모수군 사이의 상관성과 의사결정함수의 비선형성 때문에 공동 정보의 가치에는 상호작용이 존재할 수 있다.

관심 모수군 $\phi$가 전체 모수 $\theta$와 같으면 EVPPI는 EVPI가 된다. 반대로 $\phi$의 불확실성이 의사결정에 거의 영향을 주지 않으면 EVPPI는 0에 가깝다.

직접적인 중첩 Monte Carlo 계산은 계산량이 매우 클 수 있다. 실무에서는 일반화가법모형, Gaussian process, 회귀 기반 메타모형, 비모수 회귀를 이용해 $m_d(\phi)$를 추정한다. 이때 회귀모형의 예측오차가 EVPPI에 영향을 주므로 교차검증, 잔차 진단, 반복 계산에 따른 안정성을 확인해야 한다. 단순 구간화 방법은 교육적으로 유용하지만, 연속 모수가 여러 개이거나 관계가 비선형이면 구간 수에 민감할 수 있다.

### EVSI와 연구 설계 {.unnumbered}

EVPPI는 특정 모수군을 완벽히 알게 되는 가상의 상황을 다룬다. 실제 연구는 완벽한 정보를 제공하지 않고 표본자료를 추가로 제공한다. 표본정보의 기대가치(expected value of sample information, EVSI)는 특정 연구 설계가 제공할 표본자료가 의사결정의 기대가치를 얼마나 증가시키는지를 나타낸다.

연구 설계를 $\eta$, 미래 자료를 $x$라고 하자. 현재 자료 $y$가 있고, 추가 연구를 수행하면 $x$가 관찰된다. 이때 EVSI는 다음과 같이 정의된다.

미래 자료의 사전예측분포는 모수 불확실성과 표본변동을 모두 적분한다.

$$
p(x\mid y,\eta)
=
\int p(x\mid\theta,\eta)
\,p(\theta\mid y)d\theta.
$$

각 가능한 미래 자료 $x$에 대해 사후분포 $p(\theta\mid y,x,\eta)$를 갱신하고 최적 전략을 다시 선택한 뒤, 그 개선분을 $p(x\mid y,\eta)$에 대해 평균한 것이 EVSI이다. 이 때문에 EVSI를 **사전사후 분석**이라고 부른다.

$$
EVSI(\eta;\lambda)=
\mathbb{E}_{x \mid y,\eta}\left[
\max_{d \in \mathcal{D}}
\mathbb{E}_{\theta \mid y,x,\eta}\{NB(d,\theta;\lambda)\}
\right]
-
\max_{d \in \mathcal{D}}
\mathbb{E}_{\theta \mid y}\{NB(d,\theta;\lambda)\}.
$$

연구 수행 여부는 EVSI 자체가 아니라 연구비용을 뺀 순가치로 판단해야 한다. 모집단 EVSI를 $Population\ EVSI(\eta;\lambda)$, 연구비용을 $Cost(\eta)$라고 하면 표본정보의 기대순가치(expected net benefit of sampling, ENBS)는 다음과 같다.

$$
ENBS(\eta;\lambda)=Population\ EVSI(\eta;\lambda)-Cost(\eta).
$$

$ENBS>0$이면 해당 연구 설계는 기대가치 관점에서 수행할 가치가 있다. 여러 연구 설계가 가능하면 $ENBS$가 가장 큰 설계를 선택할 수 있다.

실제 연구가 특정 모수군 $\phi$에만 직접적인 정보를 제공한다면 다음 포함관계가 성립한다.

$$
0\le EVSI(\eta;\lambda)
\le EVPPI(\phi;\lambda)
\le EVPI(\lambda).
$$

표본수가 증가하면 일반적으로 EVSI는 증가하지만 한계증가분은 감소하며, 무한히 큰 표본에서도 해당 연구가 구조적 불확실성이나 측정오류를 제거하지 못하면 관련 EVPPI에 도달하지 못할 수 있다.

연구 지연과 대상 환자 감소를 명시하면 모집단 ENBS는 다음과 같이 표현할 수 있다.

$$
ENBS(\eta)
=
EVSI_{person}(\eta)
\sum_{t=L(\eta)}^{T-1}
\frac{N_tu_t}{(1+r)^t}
-
C_{fixed}(\eta)
-
C_{variable}(\eta)
-
OC_{delay}(\eta).
$$

여기서 $L(\eta)$는 결과가 정책에 반영될 때까지의 기간이고, $OC_{delay}$는 연구기간 중 발생하는 채택 또는 비채택의 기회비용이다. 표본수를 늘리면 개인당 EVSI는 증가하지만 연구비와 연구기간도 증가할 수 있으므로, ENBS는 중간 표본수에서 최대가 될 수 있다.

![연구비용을 고려한 EVSI 기반 연구 의사결정](figures/ch07/fig-ch07-evsi-net-benefit.png){fig-align="center" width="82%"}

그림에서 EVSI 곡선은 정보량 증가에 따라 상승하지만 완벽한 정보의 가치보다 높아질 수 없다. 연구비용이 표본수와 함께 증가하므로 두 곡선의 차이인 ENBS가 최대가 되는 표본수가 기대가치 관점의 최적 설계가 된다. 단, 윤리적 표본수, 검정력, 추적기간, 실행 가능성은 별도의 제약조건으로 함께 고려해야 한다.

### EVSI와 전통적 표본수 계산의 차이 {.unnumbered}

전통적 표본수 계산은 주어진 유의수준과 검정력에서 특정 효과를 검출하는 데 필요한 표본수를 구한다. EVSI 기반 설계는 가능한 연구결과가 실제 정책을 얼마나 바꾸고 그 변화가 얼마의 순편익을 만드는지를 평가한다. 따라서 효과가 통계적으로 검출되더라도 정책이 바뀌지 않는 연구는 EVSI가 작을 수 있고, 반대로 비교적 작은 연구가 의사결정 경계의 불확실성을 크게 줄이면 높은 ENBS를 가질 수 있다.

EVSI는 임상시험에만 적용되지 않는다. 장기 추적연구, 질병등록자료, 실제임상자료, 효용 연구, 자원사용 조사, 가격 또는 위험분담 자료도 의사결정모형의 특정 불확실성을 줄일 수 있다. 연구설계 $\eta$에는 표본수뿐 아니라 추적기간, 측정빈도, 비교군, 대상 환자군, 결과변수와 분석방법이 포함된다.

### 조건부 급여와 정보의 가치 {.unnumbered}

정보의 가치 분석은 조건부 급여 또는 위험분담제와도 연결된다. 현재 기대순편익이 양수이면 신약을 급여하는 것이 합리적일 수 있지만, EVPI 또는 EVSI가 크다면 근거 생성과 연계한 급여가 더 적절할 수 있다. 이 경우 정책 질문은 다음처럼 바뀐다.

- 현재 신약을 급여할 것인가?
- 급여한다면 어떤 환자군에 제한할 것인가?
- 추가 자료 수집을 조건으로 할 것인가?
- 추가 연구의 설계와 기간은 어떻게 정할 것인가?
- 연구가 진행되는 동안 발생하는 기회비용과 환자 접근성은 어떻게 균형을 맞출 것인가?

VOI 분석은 이러한 질문에 정량적인 구조를 제공한다. 다만 VOI 결과는 연구 수행 가능성, 윤리성, 시간 지연, 예산 영향, 제도적 수용 가능성과 함께 해석해야 한다.

조건부 정책은 크게 두 형태로 구분할 수 있다. **근거생성과 함께 채택(approval with research)**은 연구기간에도 신약 접근을 허용하고 추가 자료를 수집한다. **연구에서만 사용(only in research)**은 연구 참여자에게만 기술을 허용하거나 결과가 나올 때까지 일반 채택을 보류한다. 두 정책의 차이는 연구기간 중 환자가 받는 치료와 발생하는 기회비용이다.

현재 신약의 기대순편익이 양수이고 결정이 가역적이라면 채택과 연구를 병행하는 전략이 자연스러울 수 있다. 그러나 채택 후 환자 모집이 어려워지거나 가격과 임상관행이 고착되어 결정이 비가역적이면 연구에서만 사용하거나 제한적 급여를 고려할 수 있다. 반대로 현재 신약의 기대순편익이 음수여도 EVSI와 ENBS가 크다면 연구 자체는 가치가 있을 수 있다.

가격협상도 정보가치와 상호작용한다. 가격 인하로 평균 INB가 의사결정 경계에서 멀어지면 현재 결정의 오류 가능성과 EVPI가 감소할 수 있다. 따라서 가격, 급여조건, 연구설계는 순차적으로 독립 결정하기보다 공동 정책대안으로 비교하는 것이 바람직하다.

rmvnorm_base <- function(n, mean, sigma) {
  z <- matrix(rnorm(n * length(mean)), ncol = length(mean))
  sweep(z %*% chol(sigma), 2, mean, FUN = "+")

evppi_binning <- function(phi, inb, n_bins = 20) {
  breaks <- unique(quantile(phi, probs = seq(0, 1, length.out = n_bins + 1),
                            na.rm = TRUE))
  group <- cut(phi, breaks = breaks, include.lowest = TRUE, labels = FALSE)
  cond_mean <- ave(inb, group, FUN = mean)
  mean(pmax(cond_mean, 0)) - max(mean(inb), 0)
}

expected_positive_normal <- function(mu, sd) {
  if (sd <= 0) return(max(mu, 0))
  z <- mu / sd
  sd * dnorm(z) + mu * pnorm(z)
}

evsi_normal_normal <- function(n, mu0, tau, sigma) {
  var_preposterior_mean <- tau^4 / (tau^2 + sigma^2 / n)
  sd_preposterior_mean <- sqrt(var_preposterior_mean)
  expected_value_after_study <- expected_positive_normal(mu0, sd_preposterior_mean)
  expected_value_after_study - max(mu0, 0)
}

n_grid <- c(10, 20, 50, 100, 200, 500, 1000, 2000)
mu0 <- mean(psa$inb)
tau <- sd(psa$inb)
sigma_sampling <- 36000000

person_evsi <- sapply(n_grid, evsi_normal_normal,
                      mu0 = mu0, tau = tau, sigma = sigma_sampling)

## 핵심 수식 정리 {.unnumbered #sec-ch7-key-equations}

| 개념 | 수식 |
|---|---|
| 순편익 | $NB(d,\theta;\lambda)=\lambda Q(d,\theta)-C(d,\theta)$ |
| 증분순편익 | $INB(\lambda)=\lambda\Delta Q-\Delta C$ |
| 현재 정보하 최적 의사결정 | $d^*(y)=\arg\max_{d \in \mathcal{D}}\mathbb{E}_{\theta \mid y}\{NB(d,\theta;\lambda)\}$ |
| 기회손실 | $OL(d,\theta;\lambda)=\max_{d'}NB(d',\theta;\lambda)-NB(d,\theta;\lambda)$ |
| EVPI | $EVPI=\mathbb{E}_{\theta \mid y}[\max_d NB(d,\theta;\lambda)]-\max_d\mathbb{E}_{\theta \mid y}\{NB(d,\theta;\lambda)\}$ |
| 두 전략 EVPI | $EVPI=\mathbb{E}\{\max(INB,0) \mid y\}-\max\{\mathbb{E}(INB \mid y),0\}$ |
| 모집단 EVPI | $Population\ EVPI=EVPI\sum_{t=0}^{T-1}N_tu_t/(1+r)^t$ |
| EVPPI | $EVPPI(\phi)=\mathbb{E}_{\phi \mid y}[\max_d\mathbb{E}_{\psi \mid \phi,y}\{NB(d,\phi,\psi)\}]-\max_d\mathbb{E}_{\theta \mid y}\{NB(d,\theta)\}$ |
| EVSI | $EVSI(\eta)=\mathbb{E}_{x \mid y,\eta}[\max_d\mathbb{E}_{\theta \mid y,x,\eta}\{NB(d,\theta)\}]-\max_d\mathbb{E}_{\theta \mid y}\{NB(d,\theta)\}$ |
| ENBS | $ENBS(\eta)=Population\ EVSI(\eta)-Cost(\eta)$ |
| CEAF | $P[d^*(\lambda)=\arg\max_d NB_d(\theta;\lambda)\mid y]$ |
| 지연 반영 ENBS | $EVSI_{person}(\eta)\sum_{t=L(\eta)}^{T-1}N_tu_t/(1+r)^t-Cost(\eta)-OC_{delay}(\eta)$ |
