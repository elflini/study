Note이 장의 핵심 질문

생존분석의 목적은 단순히 “몇 명이 사망했는가?”를 계산하는 것이 아니다. 생존분석의 핵심은 “시간이 지남에 따라 사건이 발생할 확률 구조가 어떻게 변하는가?”를 추정하는 것이다. 경제성 평가에서는 이 확률 구조가 기대 생존기간, 기대 QALY, 상태 점유율, 전이확률, 장기 외삽의 출발점이 된다.

8.1 생존자료의 시간축과 관찰과정

생존분석에서는 사건의 종류뿐 아니라 시간의 출발점(time origin), 사건을 관찰하는 시간척도, 관찰이 시작되고 종료되는 규칙을 함께 정의해야 한다. 동일한 환자자료라도 무작위배정일, 치료 시작일, 진단일 또는 수술일 중 어느 시점을 시간 0으로 선택하는지에 따라 추정되는 생존분포가 달라질 수 있다. 따라서 시간 원점은 임상적 질문과 경제성 평가 모형의 상태 정의에 맞아야 한다.

환자 \(i\)가 시간 \(t\)까지 사건을 경험했는지를 나타내는 계수과정(counting process)을

\[ N_i(t)=I(T_i^*\le t,\delta_i=1) \]

로 정의할 수 있다. 또한 시간 \(t\) 직전에 환자가 관찰 중이며 아직 사건을 경험하지 않아 위험집합에 포함되는지를

\[ Y_i(t)=I(L_i<t\le T_i) \]

로 나타낼 수 있다. 여기서 \(L_i\)는 환자가 위험집합에 진입한 시점이다. 모든 환자가 시간 0부터 관찰된다면 \(L_i=0\)이지만, 코호트 진입이 늦은 자료에서는 \(L_i>0\)일 수 있다. 이 표현을 사용하면 순간 사건 발생률은 작은 시간 간격 \(dt\)에 대해 다음과 같이 이해할 수 있다.

\[ E\{dN_i(t)\mid \mathcal{F}_{t^-}\}=Y_i(t)h_i(t)dt. \]

즉, 환자가 위험집합에 있을 때만 사건이 발생할 수 있으며, 사건 발생의 순간적 평균은 위험함수에 의해 결정된다. Kaplan-Meier 추정량과 Cox 모형은 서로 다른 형태를 가지지만 모두 이 위험집합의 순차적 비교를 이용한다.

8.1.1 사건, 중도절단, 절단의 구분

생존자료의 불완전한 관찰은 한 가지 형태만 있는 것이 아니다.

  • 우측 중도절단(right censoring)은 사건시간이 어떤 시점보다 크다는 정보만 관찰되는 경우이다.
  • 좌측 중도절단(left censoring)은 사건이 관찰 시작 전 어느 시점에 이미 발생했다는 정보만 있는 경우이다.
  • 구간 중도절단(interval censoring)은 사건이 두 검사 시점 사이에서 발생했다는 것만 아는 경우이다.
  • 좌측 절단(left truncation)은 특정 시점까지 사건 없이 생존한 사람만 표본에 들어올 수 있는 관찰 구조이다.

중도절단은 표본에 포함된 환자의 사건시간을 불완전하게 관찰하는 문제인 반면, 절단은 환자가 표본에 포함될 가능성 자체가 사건시간에 의존하는 문제이다. 좌측 절단이 있는 자료에서는 시간 \(t\)의 위험집합을 단순히 \(T_i\ge t\)인 환자로 정의하면 안 되고, \(L_i<t\le T_i\)인 환자로 정의해야 한다. 이를 무시하면 오래 생존한 환자가 과대표집되는 불멸시간 또는 생존자 선택 편향이 발생할 수 있다.

8.2 중도절단

8.2.1 생존시간 자료의 기본 구조

생존시간 자료는 어떤 기준 시점에서 사건이 발생할 때까지의 시간을 관찰한 자료이다. 여기서 사건(event)은 반드시 사망만을 의미하지 않는다. 연구 목적에 따라 사건은 질병 진행, 재발, 입원, 치료 중단, 이상반응 발생 등으로 정의될 수 있다.

평가변수 사건의 예 경제성 평가에서의 사용
OS 사망 생존기간, 사망 상태 점유율
PFS 질병 진행 또는 사망 무진행 상태 점유율
EFS 재발, 진행, 2차 암, 사망 등 질환별 모형 상태 정의
TTD 치료 중단 약제비, 투약기간, 치료중단율
입원까지의 시간 첫 입원 사건 비용, 입원 관련 효용 감소

환자 \(i\)의 실제 사건 발생시간을 \(T_i^*\)라고 하자. 실제 연구에서는 모든 환자에게서 \(T_i^*\)를 완전히 관찰할 수 없다. 연구 종료 시점까지 사건이 발생하지 않거나, 추적에서 탈락하거나, 다른 치료로 전환되거나, 행정적 자료 추적이 중단될 수 있다. 이러한 상황을 중도절단(censoring)이라고 한다.

환자 \(i\)의 중도절단시간을 \(C_i\)라고 하면 실제로 관찰되는 시간은 다음과 같다.

\[ T_i = \min(T_i^*, C_i). \]

사건 관찰 여부를 나타내는 지시변수는 다음과 같이 정의한다.

\[ \delta_i = I(T_i^* \le C_i) = \begin{cases} 1, & \text{사건이 관찰됨}, \\ 0, & \text{중도절단됨}. \end{cases} \]

따라서 생존자료에서 환자 \(i\)의 관찰값은 보통 다음 쌍으로 표현된다.

\[ (T_i,\delta_i), \qquad i=1,\ldots,n. \]

공변량 \(X_i\)가 함께 관찰되는 경우 분석자료는 \((T_i,\delta_i,X_i)\)로 표현된다. Cox 모형이나 모수적 생존모형은 이 공변량을 이용하여 치료효과, 예후인자, 효과변경인자를 모델링한다.

그림에서 사건이 관찰된 환자는 사건 시점까지 위험집합에 남아 있다가 해당 시점에 사건 수에 기여한다. 중도절단된 환자는 중도절단 시점 직전까지 위험집합에 기여하지만 그 이후에는 분석에서 빠진다. 중도절단 표시가 생존곡선을 직접 낮추지 않는 이유는 중도절단 자체가 사건이 아니기 때문이다.

8.2.2 중도절단의 직관적 의미

중도절단된 환자는 사건이 발생하지 않은 환자와 동일하지 않다. 예를 들어 어떤 환자가 18개월까지 생존한 뒤 연구가 종료되어 더 이상 관찰되지 않았다고 하자. 이 환자에게서 우리가 아는 정보는 “사건이 발생하지 않았다”가 아니라 “적어도 18개월까지는 사건이 발생하지 않았다”이다.

이 차이는 매우 중요하다. 중도절단 환자를 단순히 사건 미발생자로 처리하면 장기 생존을 과대평가할 수 있다. 반대로 중도절단 시점에 사건이 발생한 것으로 처리하면 생존을 과소평가한다. 생존분석은 중도절단된 환자가 제공하는 부분 정보를 적절히 사용하여 생존함수를 추정한다.

Warning중도절단 해석 시 주의점

중도절단은 사건이 발생하지 않았다는 뜻이 아니다. 중도절단은 “관찰 가능한 기간 안에서는 사건이 확인되지 않았다”는 뜻이다. 따라서 중도절단된 환자는 중도절단 시점까지는 위험집합에 포함되지만 그 이후에는 위험집합에서 제외된다.

8.2.3 독립적 중도절단 가정

Kaplan-Meier 추정량과 Cox 비례위험모형 같은 표준 생존분석 방법은 일반적으로 독립적 중도절단(independent censoring)을 가정한다. 이는 중도절단 시간이 사건 발생시간에 대한 추가 정보를 제공하지 않는다는 의미이다. 공변량 \(X_i\)가 주어진 조건에서 다음과 같이 표현할 수 있다.

\[ T_i^* \perp C_i \mid X_i. \]

직관적으로 말하면, 같은 시점까지 사건 없이 생존한 환자들 중에서 중도절단된 환자와 계속 추적된 환자의 이후 사건 위험이 같다고 가정하는 것이다. 이 가정이 위반되면 생존함수 추정에 편향이 발생한다. 예를 들어 상태가 악화된 환자가 추적에서 더 자주 탈락한다면 관찰자료만으로 추정한 생존곡선은 실제보다 낙관적일 수 있다.

중도절단은 다음과 같이 구분할 수 있다.

유형 설명 독립성 위반 가능성
행정적 중도절단 연구 종료일 때문에 추적이 끝남 보통 낮음
무작위 탈락 이사, 연락 두절 등 상황에 따라 다름
질병 악화로 인한 탈락 상태 악화 후 추적 중단 높음
치료 교차 또는 구조치료 사건 위험과 관련된 치료 변경 높음

경제성 평가에서는 생존곡선의 꼬리 부분이 장기 비용과 장기 효과에 큰 영향을 미친다. 따라서 추적기간이 짧고 중도절단이 많을수록 장기 외삽의 불확실성은 커진다. 특히 OS 자료가 성숙하지 않은 상태에서 경제성 평가를 수행하는 경우 number at risk, 중도절단 패턴, 추적기간의 성숙도, 교차투여 또는 후속치료의 영향을 함께 검토해야 한다.

8.2.4 독립적 중도절단의 식별 의미

독립적 중도절단은 단순한 기술적 가정이 아니라 관찰되지 않은 사건시간 분포를 식별하기 위한 조건이다. 공변량 \(X\)로 충분히 조건화한 뒤 중도절단이 독립적이라면, 계속 관찰된 환자의 이후 사건 경험을 이용하여 중도절단된 환자의 반사실적 이후 경과를 대표할 수 있다. 반대로 건강상태 악화, 치료효과 부족, 독성 또는 의료접근성 저하가 탈락과 사건위험을 동시에 높인다면 표준 Kaplan-Meier 곡선과 Cox 모형은 편향될 수 있다.

중도절단 과정에 영향을 주는 공변량 \(Z(t)\)가 관찰되어 있다면 역중도절단확률가중(inverse probability of censoring weighting, IPCW)을 고려할 수 있다. 시간 \(t\)까지 중도절단되지 않을 조건부 확률을

\[ G(t\mid Z)=P(C\ge t\mid Z) \]

라고 하면, 관찰이 계속된 환자에게 대략 \(1/G(t\mid Z)\)의 가중치를 부여한다. 중도절단될 가능성이 높은 특성을 가진 환자 중 계속 관찰된 소수의 환자가 유사한 환자들을 더 많이 대표하도록 하는 원리이다. 그러나 IPCW 역시 중도절단 모형이 올바르게 지정되고 관련 예측변수가 충분히 관찰되었다는 가정에 의존한다.

8.2.5 경쟁사건은 중도절단이 아니다

관심 사건이 아닌 다른 사건이 이후 관심 사건의 발생을 불가능하게 만들면 이를 경쟁사건(competing event)이라고 한다. 예를 들어 질병 진행을 관심 사건으로 볼 때 진행 전 사망은 단순한 추적중단이 아니라 이후 진행을 불가능하게 만드는 경쟁사건이다. 이를 독립적 중도절단으로 처리한 Kaplan-Meier의 \(1-\widehat S(t)\)는 현실의 진행 누적발생확률이 아니라 경쟁사건이 제거된 가상세계의 확률을 추정한다. 실제 누적발생확률이 필요하다면 원인별 위험과 전체 생존을 결합한 누적발생함수를 사용해야 한다.

8.3 생존시간의 분포를 표현하는 다섯 가지 함수

생존시간 \(T\)는 \(0\)보다 큰 값을 가지는 연속형 확률변수로 생각할 수 있다.

\[ T \ge 0. \]

생존시간의 확률분포는 여러 함수로 표현할 수 있다. 경제성 평가에서 특히 중요한 함수는 다음 다섯 가지이다.

  1. 확률밀도함수 \(f(t)\)
  2. 누적분포함수 \(F(t)\)
  3. 생존함수 \(S(t)\)
  4. 위험함수 \(h(t)\)
  5. 누적위험함수 \(H(t)\)

이 다섯 함수는 서로 다른 방식으로 생존시간의 분포를 표현하지만 수학적으로는 서로 연결되어 있다.

그림의 다섯 함수는 서로 독립된 결과가 아니라 동일한 생존시간 분포를 서로 다른 관점에서 표현한 것이다. \(F(t)\)와 \(S(t)\)는 누적확률을, \(f(t)\)는 사건시간의 국소적 분포를, \(h(t)\)는 아직 사건이 발생하지 않은 환자의 조건부 순간위험을, \(H(t)\)는 그 위험의 누적량을 보여준다.

8.3.1 확률밀도함수와 누적분포함수

확률밀도함수 \(f(t)\)는 사건이 시간 \(t\) 근처에서 발생할 상대적 가능성을 나타낸다.

\[ f(t)=\frac{dF(t)}{dt}. \]

연속형 생존시간에서는 특정한 한 시점 \(t\)에서 사건이 정확히 발생할 확률은 0이다. 따라서 \(f(t)\) 자체를 확률로 해석하면 안 된다. 대신 짧은 구간 \([t,t+dt)\)에서 사건이 발생할 확률은 대략 다음과 같다.

\[ P(t \le T < t+dt) \approx f(t)dt. \]

누적분포함수 \(F(t)\)는 시간 \(t\)까지 사건이 발생할 확률이다.

\[ F(t)=P(T\le t). \]

예를 들어 \(F(12)=0.30\)이라면 12개월 이내 사건 발생확률이 30%라는 의미이다.

8.3.2 생존함수

생존함수 \(S(t)\)는 시간 \(t\)를 초과하여 사건 없이 생존할 확률이다.

\[ S(t)=P(T>t). \]

누적분포함수와 생존함수는 다음 관계를 가진다.

\[ S(t)=1-F(t). \]

경제성 평가에서 생존함수는 매우 중요하다. 생존함수의 면적은 평균 생존시간과 연결되고, 분할생존모형에서는 생존함수가 건강상태 점유확률을 결정한다. 예를 들어 전체생존함수 \(S_{OS}(t)\)와 무진행생존함수 \(S_{PFS}(t)\)가 주어졌을 때 상태 점유확률은 다음과 같다.

\[ P(\text{PF at }t)=S_{PFS}(t), \]

\[ P(\text{PD at }t)=S_{OS}(t)-S_{PFS}(t), \]

\[ P(\text{Dead at }t)=1-S_{OS}(t). \]

이 관계가 성립하려면 모든 시점에서 \(S_{OS}(t)\ge S_{PFS}(t)\)이어야 한다. 실제 모형 적합 또는 외삽 과정에서 이 논리적 제약이 깨지면 상태 점유확률이 음수가 될 수 있으므로 반드시 점검해야 한다.

그림의 세 영역은 동일한 시점의 주변 생존확률 차이로 정의된다. 이 계산은 각 환자가 실제로 어떤 경로로 진행했는지를 직접 모형화하지 않고도 상태 점유율을 얻는 장점이 있다. 반면 PFS와 OS의 결합 경로, 진행 후 사망시간, 치료중단과 진행의 순서는 두 주변 생존곡선만으로 식별되지 않는다. 비용이나 효용이 사건 경로와 체류기간에 민감하다면 이 구조적 한계를 별도로 검토해야 한다.

8.3.3 위험함수와 누적위험함수

위험함수 \(h(t)\)는 시간 \(t\) 직전까지 사건 없이 생존한 환자가 바로 다음 순간에 사건을 경험할 순간 위험을 의미한다.

\[ h(t)=\lim_{\Delta t\to 0} \frac{P(t\le T<t+\Delta t \mid T\ge t)}{\Delta t}. \]

위험함수는 조건부 사건 발생률로 이해할 수 있다. 전체 모집단 중 사건이 발생할 확률이 아니라, 시간 \(t\)까지 아직 사건을 경험하지 않은 환자들 중에서 사건이 발생할 순간적 경향을 나타낸다. 위험함수는 생존함수와 확률밀도함수로 다음과 같이 표현된다.

\[ h(t)=\frac{f(t)}{S(t)}. \]

누적위험함수 \(H(t)\)는 시간 0부터 \(t\)까지 위험함수를 누적한 값이다.

\[ H(t)=\int_0^t h(u)du. \]

생존함수와 누적위험함수는 다음 관계를 가진다.

위험함수와 생존함수의 관계는 조건부 확률에서 직접 유도할 수 있다. 작은 시간 간격 \(\Delta t\)에서

\[ P(T\ge t+\Delta t\mid T\ge t) =\frac{S(t+\Delta t)}{S(t)} \approx 1-h(t)\Delta t. \]

양변을 정리하고 \(\Delta t\to0\)으로 보내면 다음 미분방정식을 얻는다.

\[ \frac{dS(t)}{dt}=-h(t)S(t). \]

초기조건 \(S(0)=1\)을 적용하여 적분하면

\[ \log S(t)=-\int_0^t h(u)du=-H(t), \]

따라서

\[ S(t)=\exp\{-H(t)\}, \]

\[ H(t)=-\log S(t). \]

누적위험 \(H(t)\)는 확률이 아니므로 1보다 클 수 있다. 다만 \(H(t)\)가 증가할수록 \(S(t)=\exp\{-H(t)\}\)는 감소한다. 이 관계 때문에 위험함수의 작은 차이가 장기간 누적되면 생존곡선과 평균 생존기간에 큰 차이를 만들 수 있다.

그림에서 동일한 단기 생존적합도를 보이는 모형이라도 위험함수가 일정한지, 증가하는지, 감소하는지에 따라 관찰기간 이후의 생존확률이 크게 달라질 수 있다. 따라서 장기 외삽에서는 생존곡선의 적합도뿐 아니라 위험함수의 임상적 개연성과 장기 형태를 함께 평가해야 한다.

Important위험은 확률이 아니다

위험함수 \(h(t)\)는 순간 사건 발생률이며 단위 시간당 값이다. 따라서 \(h(t)\)는 1보다 클 수 있다. 반면 특정 기간의 사건 발생확률은 항상 0과 1 사이에 있어야 한다. 위험률을 전이확률로 바꾸려면 주기 길이를 고려해야 한다.

8.3.4 다섯 함수의 관계

생존시간 분포를 표현하는 함수들의 핵심 관계는 다음과 같다.

\[ F(t)=P(T\le t), \qquad S(t)=1-F(t), \]

\[ f(t)=\frac{dF(t)}{dt}=-\frac{dS(t)}{dt}, \]

\[ h(t)=\frac{f(t)}{S(t)}=-\frac{d}{dt}\log S(t), \]

\[ H(t)=\int_0^t h(u)du=-\log S(t), \]

\[ S(t)=\exp\{-H(t)\}. \]

이 관계는 생존분석의 거의 모든 모형에서 반복적으로 사용된다. 예를 들어 Weibull 모형을 shape-scale 모수화로 쓰면 생존함수와 위험함수는 다음과 같다.

\[ S(t)=\exp\left[-\left(\frac{t}{\lambda}\right)^k\right], \]

\[ h(t)=\frac{k}{\lambda}\left(\frac{t}{\lambda}\right)^{k-1}. \]

여기서 \(k\)는 shape 모수이고 \(\lambda\)는 scale 모수이다. \(k=1\)이면 위험함수는 일정하고, \(k>1\)이면 위험은 시간에 따라 증가하며, \(0<k<1\)이면 위험은 시간에 따라 감소한다.

8.3.5 생존분포의 분위수와 적률

생존시간의 \(p\) 분위수 \(t_p\)는 \(F(t_p)=p\), 또는 동등하게 \(S(t_p)=1-p\)를 만족하는 시간이다. 중앙생존기간은 \(p=0.5\)인 특별한 경우이다. Weibull 분포에서는

\[ t_p=\lambda\{-\log(1-p)\}^{1/k} \]

로 계산할 수 있다. 중앙생존기간은 관찰자료의 절반이 사건을 경험해야 안정적으로 추정되지만, 평균 생존시간은 분포의 꼬리 전체에 의존한다. 경제성 평가에서 평균 생존기간과 QALY가 필요한 이유 때문에 중앙값만으로 장기 효과를 대체할 수 없다.

비음수 생존시간의 고차 적률도 생존함수로 표현할 수 있다.

\[ E(T^r)=r\int_0^\infty t^{r-1}S(t)dt, \qquad r>0. \]

\(r=1\)이면 평균 생존시간 식이 되고, \(r=2\)이면 생존시간의 분산을 계산하는 데 사용할 수 있다. 이 결과는 생존함수가 단순한 시점별 확률을 넘어 생존시간 분포 전체의 요약량을 결정한다는 점을 보여준다.

Note모수화 확인

Weibull, log-normal, generalized gamma와 같은 분포는 소프트웨어마다 scale, rate, shape의 정의가 다를 수 있다. 동일한 모수 이름이라도 생존함수와 위험함수의 수식이 달라질 수 있으므로 경제성 평가 코드를 구현할 때는 사용한 소프트웨어의 모수화를 명시하고, 특정 시점의 생존확률과 위험률을 수작업으로 검산하는 것이 필요하다.

8.4 생존분석의 목표

생존분석의 목표는 연구 목적과 경제성 평가 모형의 필요에 따라 달라진다. 분석 전에 사건 정의, 시간 원점, 분석 인구집단, 중간사건 처리, 효과척도, 제한시점과 요약방법을 함께 명시해야 한다. 이러한 요소가 생존분석의 estimand를 구성한다. 동일한 임상시험에서도 치료정책 estimand, 치료순응 estimand 또는 가상의 교차투여 제거 estimand는 서로 다른 생존곡선과 경제성 평가 결과를 만들 수 있다.

크게 네 가지 목표로 정리할 수 있다.

8.4.1 생존경험의 기술

첫 번째 목표는 특정 치료군 또는 환자집단의 생존경험을 기술하는 것이다. Kaplan-Meier 곡선, 중앙생존기간, 특정 시점 생존율, 제한평균 생존시간이 대표적인 기술적 요약값이다.

중앙생존기간 \(m\)은 생존확률이 0.5가 되는 시간이다.

\[ S(m)=0.5. \]

단, 추적기간 동안 생존곡선이 0.5 아래로 내려가지 않으면 중앙생존기간은 관찰자료만으로 추정할 수 없다. 이 경우 중앙생존기간이 “도달하지 않음”으로 보고될 수 있지만, 경제성 평가에서는 평균 생존기간과 QALY 추정이 여전히 필요하다.

8.4.2 치료군 간 생존 차이 비교

두 번째 목표는 치료군 간 생존 차이를 비교하는 것이다. 임상시험에서는 log-rank 검정과 Cox 비례위험모형이 자주 사용된다. 그러나 경제성 평가에서는 단순히 \(p\)-value가 유의한지보다 치료군 간 생존곡선 차이가 기대 QALY와 비용에 어느 정도 영향을 미치는지가 더 중요하다.

치료군 1과 치료군 0의 제한평균 생존시간 차이는 다음과 같이 정의할 수 있다.

\[ \Delta RMST(\tau)=\int_0^\tau \{S_1(t)-S_0(t)\}dt. \]

이 값은 제한시점 \(\tau\)까지의 평균 생존기간 차이로 해석할 수 있으며, 위험비보다 절대효과에 가까운 척도이다.

RMST 차이는 생존곡선이 교차하거나 치료효과가 시간에 따라 변할 때에도 정의할 수 있다. 다만 \(\tau\)가 달라지면 효과의 크기와 해석도 달라지므로 제한시점은 자료를 본 뒤 가장 유리한 시점을 선택하기보다 임상적 의사결정 시점과 두 군의 공통 추적가능기간을 고려하여 사전에 정하는 것이 바람직하다.

위험비는 순간위험의 상대적 비교이고 RMST 차이는 일정 기간 동안 얻은 평균 생존시간의 절대 차이이다. 두 지표는 서로 대체관계가 아니며, 비례위험이 성립하더라도 기준위험이 다르면 동일한 위험비가 서로 다른 RMST 차이를 만들 수 있다.

8.4.3 공변량을 보정한 치료효과 추정

세 번째 목표는 공변량을 보정한 치료효과를 추정하는 것이다. 예를 들어 다음과 같은 Cox 모형을 사용할 수 있다.

\[ h(t\mid A,X)=h_0(t)\exp(\beta_A A+X^\top\gamma), \]

여기서 \(A\)는 치료군 지시변수, \(X\)는 공변량 벡터이다. 치료효과는 보통 \(\exp(\beta_A)\)로 표현되는 위험비로 요약된다. 무작위배정 임상시험에서는 공변량 보정이 정밀도를 높일 수 있고, 관찰연구에서는 교란 조정을 위해 필요하다.

8.4.4 경제성 평가 모델 입력값 생성

네 번째 목표는 경제성 평가 모형의 입력값을 생성하는 것이다. 생존분석 결과는 다음과 같이 모형에 연결된다.

생존분석 산출물 경제성 평가에서의 사용
\(S_{OS}(t)\) 생존상태, 사망상태 점유율
\(S_{PFS}(t)\) 무진행 상태 점유율
\(h(t)\) 순간 전이강도, 주기별 전이확률
\(RMST(\tau)\) 제한기간 평균 생존기간
\(\int_0^\tau u(t)S(t)dt\) 기대 QALY
위험비 \(HR\) 상대효과, 간접비교, 메타분석 입력값

그림의 흐름에서 통계적 추정량은 그대로 경제성 평가 결과가 되는 것이 아니라, 상태 정의·분석기간·할인·효용·비용과 결합되어 모형 입력값으로 변환된다. 따라서 임상분석에서 적절한 효과척도와 경제성 평가에서 필요한 입력값이 반드시 일치하는 것은 아니다.

8.4.5 평균 생존시간과 생존곡선 아래 면적

비음수 생존시간 \(T\)의 평균은 생존함수의 면적으로 표현할 수 있다. 이 관계는 지시함수의 기댓값을 이용하여 유도할 수 있다. 모든 \(T\ge0\)에 대해

\[ T=\int_0^\infty I(T>t)dt \]

이므로 적분과 기댓값의 순서를 바꾸면

\[ \mathbb{E}(T) =\int_0^\infty E\{I(T>t)\}dt =\int_0^\infty P(T>t)dt =\int_0^\infty S(t)dt. \]

분석기간을 \(\tau\)로 제한하면 제한평균 생존시간(restricted mean survival time, RMST)은 다음과 같다.

\[ RMST(\tau)=\mathbb{E}\{\min(T,\tau)\}=\int_0^\tau S(t)dt. \]

이 식은 경제성 평가에서 매우 중요하다. 생존곡선 아래 면적은 기대 생존기간이고, 여기에 시간에 따른 효용값을 곱하면 기대 QALY가 된다.

\[ Q(\tau)=\int_0^\tau u(t)S(t)dt. \]

효용이 상태에 따라 달라지는 분할생존모형에서는 다음과 같이 표현할 수 있다.

\[ Q(\tau)=\int_0^\tau \{u_{PF}S_{PFS}(t)+u_{PD}[S_{OS}(t)-S_{PFS}(t)]\}dt. \]

효과 할인율이 연속시간 기준 \(r_E\)이고 효용이 시간에 따라 변한다면 일반적인 기대 QALY는

\[ Q(\tau)=\int_0^\tau e^{-r_Et}\sum_{s=1}^K u_s(t)P\{X(t)=s\}dt \]

로 표현할 수 있다. 여기서 \(X(t)\)는 시간 \(t\)의 건강상태이다. 이 식은 생존분석 결과가 경제성 평가에 연결될 때 상태 점유확률, 상태별 효용, 시간가변 효용과 할인이 동시에 고려되어야 함을 보여준다.

그림의 음영 면적은 제한시점까지의 기대 생존시간이다. 두 치료군의 음영 면적 차이는 해당 기간의 평균 생존이득이며, 생존곡선이 교차하더라도 양의 영역과 음의 영역을 모두 반영한 순효과를 제공한다.

8.5 Kaplan-Meier 곡선

8.5.1 Kaplan-Meier 추정량의 개념

Kaplan-Meier 추정량은 중도절단이 있는 생존자료에서 생존함수 \(S(t)\)를 비모수적으로 추정하는 방법이다. 핵심 아이디어는 전체 생존확률을 각 사건 시점에서의 조건부 생존확률의 곱으로 표현하는 것이다.

사건이 발생한 서로 다른 시점을 \(t_1<t_2<\cdots<t_K\)라고 하자. 시점 \(t_j\) 직전에 위험집합에 있는 환자 수를 \(n_j\), 시점 \(t_j\)에서 사건이 발생한 환자 수를 \(d_j\)라고 하자. 그러면 \(t_j\)를 통과할 조건부 생존확률은 다음과 같이 추정된다.

\[ 1-\frac{d_j}{n_j}. \]

연쇄확률법칙에 따르면 \(t_k\) 이후까지 생존할 확률은 각 사건시점을 순서대로 통과할 조건부 확률의 곱으로 쓸 수 있다.

\[ P(T>t_k)=\prod_{j=1}^k P(T>t_j\mid T\ge t_j). \]

각 조건부 생존확률을 위험집합에서 관찰된 비율 \((n_j-d_j)/n_j\)로 대체하면 Kaplan-Meier 추정량을 얻는다.

\[ \widehat{S}_{KM}(t)=\prod_{t_j\le t}\left(1-\frac{d_j}{n_j}\right). \]

중도절단은 사건 시점이 아니므로 생존확률을 직접 낮추지 않는다. 대신 중도절단 시점 이후의 위험집합 크기 \(n_j\)를 줄인다. 즉, 중도절단 환자는 중도절단 시점까지는 생존함수 추정에 정보를 제공하지만 그 이후에는 위험집합에서 제외된다.

그림에서 계단의 수직 하강은 사건 발생을 나타내고, 수평 구간은 다음 사건 전까지 추정 생존확률이 유지됨을 나타낸다. 중도절단 표시는 해당 환자가 그 시점까지 생존했다는 정보를 제공하지만 곡선을 직접 하강시키지는 않는다.

8.5.2 Greenwood 분산과 신뢰구간

Kaplan-Meier 추정량의 분산은 Greenwood 공식으로 근사할 수 있다.

\[ \widehat{\operatorname{Var}}\{\widehat{S}_{KM}(t)\} =\widehat{S}_{KM}(t)^2 \sum_{t_j\le t}\frac{d_j}{n_j(n_j-d_j)}. \]

생존확률이 0과 1 사이에 있어야 하므로 실제 신뢰구간은 단순 정규근사보다 로그-로그 변환을 이용하는 경우가 많다. 로그-로그 변환은 다음과 같다.

\[ g\{S(t)\}=\log[-\log\{S(t)\}]. \]

생존곡선의 꼬리 부분에서는 \(n_j\)가 작아지고 분산이 커진다. 따라서 꼬리 부분에서 Kaplan-Meier 곡선을 그대로 장기 외삽의 근거로 사용하는 것은 위험할 수 있다.

로그-로그 변환을 이용한 대략적인 \(100(1-\alpha)\%\) 신뢰구간은 변환척도에서

\[ \log[-\log\{\widehat S(t)\}] \pm z_{1-\alpha/2} \frac{\sqrt{\widehat{\operatorname{Var}}\{\widehat S(t)\}}} {\widehat S(t)|\log\widehat S(t)|} \]

을 구한 뒤 원래 생존확률 척도로 역변환한다. 이 방식은 신뢰구간이 0과 1의 범위를 벗어나는 문제를 줄인다.

8.5.3 Nelson-Aalen 누적위험 추정량

Kaplan-Meier가 생존함수를 직접 추정한다면 Nelson-Aalen 추정량은 누적위험함수를 다음과 같이 추정한다.

\[ \widehat H_{NA}(t)=\sum_{t_j\le t}\frac{d_j}{n_j}. \]

이에 대응하는 생존함수는 \(\exp\{-\widehat H_{NA}(t)\}\)로 얻을 수 있다. 사건비율 \(d_j/n_j\)가 작을 때

\[ -\log\left(1-\frac{d_j}{n_j}\right)\approx \frac{d_j}{n_j} \]

이므로 Kaplan-Meier와 Nelson-Aalen 기반 생존추정량은 서로 가깝다. 누적위험 그림은 위험이 시간에 따라 얼마나 빠르게 누적되는지 확인하고 모수적 위험함수의 형태를 평가하는 데 유용하다.

8.5.4 Number at risk의 중요성

Kaplan-Meier 그림에는 보통 각 시점의 number at risk가 함께 제시된다. 이는 해당 시점 직전까지 사건도 중도절단도 경험하지 않아 여전히 위험집합에 남아 있는 환자 수이다.

그림에서 후반 시점의 생존확률이 높아 보이더라도 위험집합이 매우 작다면 그 값은 소수 환자의 경과에 의해 결정될 수 있다. 따라서 꼬리의 평탄한 모양을 치료효과의 지속이나 완치분율의 근거로 곧바로 해석해서는 안 된다.

Number at risk가 매우 작아진 구간의 생존곡선은 소수 환자의 사건 여부에 크게 흔들릴 수 있다. 경제성 평가에서 생존외삽을 수행할 때는 KM 곡선의 마지막 부분만 보고 장기 생존을 판단해서는 안 된다. 관찰기간, 사건 수, 중도절단 수, 위험집합 크기, 임상적 자연사 정보를 함께 고려해야 한다.

8.5.5 Kaplan-Meier 곡선과 제한평균 생존시간

Kaplan-Meier 곡선이 계단함수이므로 제한평균 생존시간은 각 구간의 직사각형 면적 합으로 계산할 수 있다. 사건 시점과 제한시점을 합친 시간 구간을 \(0=s_0<s_1<\cdots<s_M=\tau\)라고 하면 다음과 같다.

\[ \widehat{RMST}(\tau)=\sum_{m=0}^{M-1}\widehat{S}_{KM}(s_m)(s_{m+1}-s_m). \]

RMST는 비례위험 가정에 의존하지 않는 절대효과 척도라는 장점이 있다. 다만 제한시점 \(\tau\)를 사전에 합리적으로 정해야 하며, 두 군 모두 충분한 추적자료가 있는 기간 안에서 해석하는 것이 바람직하다.

8.5.6 군 간 비교와 log-rank 검정

두 군의 생존곡선이 동일하다는 귀무가설은 log-rank 검정으로 평가할 수 있다. 각 사건 시점 \(t_j\)에서 전체 위험집합 크기를 \(n_j\), 치료군 위험집합 크기를 \(n_{1j}\), 전체 사건 수를 \(d_j\)라고 하면 귀무가설 아래 치료군의 기대 사건 수는

\[ e_{1j}=d_j\frac{n_{1j}}{n_j} \]

이다. 전체 관찰 사건 수와 기대 사건 수의 차이를 시점 전체에 걸쳐 합한 통계량을 그 분산으로 표준화하면 근사적인 카이제곱 검정통계량을 얻는다.

Log-rank 검정은 대체로 모든 사건시점에 동일한 가중을 주며 비례위험 대립가설에서 효율적이다. 생존곡선이 교차하거나 효과가 특정 시기에만 나타나면 검정력이 낮아지거나 임상적으로 중요한 차이를 충분히 표현하지 못할 수 있다. 또한 유의확률은 효과크기를 직접 나타내지 않으므로 위험비, 시점별 생존차이, RMST 차이와 함께 해석해야 한다.

8.5.7 Kaplan-Meier 곡선의 한계

Kaplan-Meier 곡선은 관찰자료 안에서 생존경험을 기술하는 데 강력하지만 경제성 평가에서는 다음 한계가 있다.

  1. 관찰된 마지막 시점 이후 생존확률을 제공하지 않는다.
  2. 중도절단이 많은 꼬리 부분의 불확실성이 크다.
  3. 공변량 보정 또는 표준화가 직접적으로 어렵다.
  4. 주기별 전이확률을 부드럽게 계산하기 어렵다.
  5. 장기 분석기간의 평균 생존기간과 QALY 추정에는 외삽이 필요하다.

따라서 경제성 평가에서는 KM 곡선을 생존외삽 모형의 적합도와 타당성을 평가하는 기준 자료로 사용하고, 분석기간 전체에 필요한 생존함수는 9장과 10장에서 다루는 모수적 또는 유연한 생존모형으로 추정하는 경우가 많다.

8.6 Cox 비례위험모형

8.6.1 Cox 모형의 기본 형태

Cox 비례위험모형은 공변량이 위험함수에 곱셈적으로 작용한다고 가정한다. 환자 \(i\)의 공변량 벡터를 \(X_i\)라고 하면 다음과 같이 쓸 수 있다.

\[ h(t\mid X_i)=h_0(t)\exp(X_i^\top\beta). \]

여기서 \(h_0(t)\)는 기준 위험함수이고, \(\beta\)는 회귀계수 벡터이다. Cox 모형의 중요한 특징은 \(h_0(t)\)의 구체적인 형태를 모수적으로 지정하지 않아도 \(\beta\)를 추정할 수 있다는 점이다. 따라서 Cox 모형은 준모수적(semi-parametric) 모형이다.

치료군 지시변수 \(A_i\)만 포함한 경우 모형은 다음과 같다.

\[ h(t\mid A_i)=h_0(t)\exp(\beta A_i). \]

치료군이 \(A_i=1\), 대조군이 \(A_i=0\)이라면 위험비는 다음과 같다.

\[ HR=\frac{h(t\mid A_i=1)}{h(t\mid A_i=0)}=\exp(\beta). \]

8.6.2 위험비의 올바른 해석

위험비가 0.70이라는 것은 모든 시점에서 치료군의 순간 위험이 대조군의 70%라는 의미이다. 이는 사건 발생확률이 30% 감소했다는 뜻이 아니다. 위험은 조건부 순간 사건 발생률이고, 누적 사건확률은 생존함수 전체에 의해 결정된다.

비례위험 가정하에서 치료군 생존함수는 대조군 기준 생존함수로부터 다음과 같이 표현할 수 있다.

\[ S_1(t)=\{S_0(t)\}^{HR}. \]

따라서 특정 시점의 대조군 사건확률 \(p_0(t)=1-S_0(t)\)에 위험비 \(HR\)을 적용한 치료군 사건확률은 다음과 같다.

\[ p_1(t)=1-\{1-p_0(t)\}^{HR}. \]

위 식은 위험비를 사건확률에 직접 곱하는 것이 잘못될 수 있음을 보여준다.

그림은 동일한 위험비라도 기준 생존곡선의 수준과 추적시점에 따라 절대 생존확률 차이가 달라짐을 보여준다. 따라서 위험비만으로 QALY 이득을 결정할 수 없으며, 대조군 기준위험과 치료효과가 함께 생존함수에 적용되어야 한다.

Warning위험비 해석 시 주의점

위험비 \(HR=0.70\)은 “사건확률이 30% 감소한다”는 뜻이 아니다. 비례위험 가정하에서는 대조군 생존함수 \(S_0(t)\)에 대해 치료군 생존함수가 \(S_1(t)=S_0(t)^{HR}\)로 변환된다. 따라서 절대 사건확률 감소는 기준 위험, 추적기간, 생존곡선의 형태에 따라 달라진다.

8.6.3 부분가능도

Cox 모형은 기준 위험함수 \(h_0(t)\)를 직접 모수화하지 않고 부분가능도(partial likelihood)를 이용하여 \(\beta\)를 추정한다. 사건이 발생한 환자 \(i\)의 사건 시점 \(T_i\)에서 위험집합을 \(R(T_i)\)라고 하자. 위험집합은 시점 \(T_i\) 직전까지 아직 사건도 중도절단도 경험하지 않은 환자들의 집합이다.

동시 사건이 없다고 단순화하면 부분가능도는 다음과 같다.

\[ L_p(\beta)=\prod_{i:\delta_i=1} \frac{\exp(X_i^\top\beta)}{\sum_{\ell\in R(T_i)}\exp(X_\ell^\top\beta)}. \]

로그 부분가능도는 다음과 같다.

\[ \ell_p(\beta)=\sum_{i:\delta_i=1} \left[X_i^\top\beta- \log\left\{\sum_{\ell\in R(T_i)}\exp(X_\ell^\top\beta)\right\}\right]. \]

이 식은 각 사건 시점에서 “위험집합에 있던 환자들 중 실제 사건이 발생한 환자가 누구였는가”에 대한 조건부 확률을 곱한 것으로 해석할 수 있다.

부분가능도는 사건이 발생한 순서와 사건시점의 위험집합 비교에서 회귀계수 정보를 추출한다. 기준위험함수의 구체적 형태가 소거되기 때문에 회귀계수 추정에는 편리하지만, 절대 생존확률을 계산하려면 이후 기준 누적위험함수를 별도로 추정해야 한다.

실제 자료에서는 동일한 시점에 여러 사건이 기록될 수 있다. 이를 동시 사건(ties)이라고 하며 Breslow 근사, Efron 근사 또는 exact 방법으로 처리한다. 사건시점이 반올림되어 동시 사건이 많을 때는 처리방법에 따라 추정치가 달라질 수 있으므로 사용한 방법을 명시해야 한다.

8.6.4 기준 누적위험과 생존함수 추정

Cox 모형에서 \(\widehat{\beta}\)를 추정한 뒤 기준 누적위험함수는 Breslow 추정량으로 추정할 수 있다.

\[ \widehat{H}_0(t)=\sum_{t_j\le t}\frac{d_j}{\sum_{\ell\in R(t_j)}\exp(X_\ell^\top\widehat{\beta})}. \]

이에 대응하는 기준 생존함수는 다음과 같다.

\[ \widehat{S}_0(t)=\exp\{-\widehat{H}_0(t)\}. \]

공변량 \(X\)를 가진 환자의 생존함수는 다음과 같이 추정된다.

\[ \widehat{S}(t\mid X)=\widehat{S}_0(t)^{\exp(X^\top\widehat{\beta})}. \]

이 식을 사용하면 공변량 패턴별 조건부 생존곡선을 구할 수 있다. Cox 회귀계수의 위험비는 다른 공변량을 고정한 조건부 효과이며, 목표 모집단 전체의 주변 생존곡선이나 주변 위험비와 일반적으로 동일하지 않다. 특히 위험비는 비축약적(non-collapsible)이므로 교란이 없더라도 공변량 보정 전후의 위험비가 달라질 수 있다.

경제성 평가에서는 특정 환자군의 평균 생존곡선이 필요하므로 개별 환자의 예측 생존곡선을 목표 모집단 분포에 대해 평균하는 표준화가 필요할 수 있다.

\[ \widehat{S}_{\text{std}}(t)=\frac{1}{N}\sum_{i=1}^N \widehat{S}(t\mid X_i). \]

8.6.5 비례위험 가정

Cox 모형의 핵심 가정은 위험비가 시간에 따라 일정하다는 것이다. 두 공변량 값 \(X_a\)와 \(X_b\)를 가진 환자의 위험비는 다음과 같다.

\[ \frac{h(t\mid X_a)}{h(t\mid X_b)} =\exp\{(X_a-X_b)^\top\beta\}, \]

이 값은 \(t\)에 의존하지 않는다. 즉, 치료효과가 추적기간 전체에서 동일한 상대적 크기로 유지된다고 가정한다.

비례위험 가정은 다음과 같은 방법으로 점검할 수 있다.

  1. log-minus-log 생존곡선이 대체로 평행한지 확인한다.
  2. Schoenfeld 잔차와 시간의 관련성을 확인한다.
  3. 시간-치료 상호작용 항을 포함하여 치료효과가 시간에 따라 변하는지 평가한다.
  4. 초기와 후기 구간의 위험비가 크게 다른지 확인한다.
  5. 임상적 기전과 후속치료 패턴이 일정한 위험비를 지지하는지 검토한다.

공변량 \(X_k\)에 대한 Schoenfeld 잔차는 사건이 발생한 환자의 공변량과 해당 사건시점 위험집합의 위험가중 평균 공변량 차이로 이해할 수 있다.

\[ r_{jk}=X_{jk}- \frac{\sum_{\ell\in R(t_j)}X_{\ell k}\exp(X_\ell^\top\widehat\beta)} {\sum_{\ell\in R(t_j)}\exp(X_\ell^\top\widehat\beta)}. \]

비례위험 가정이 성립하면 이 잔차에 체계적인 시간추세가 없어야 한다. 잔차검정의 유의성은 표본크기에 영향을 받으므로 검정결과뿐 아니라 잔차그림, 효과크기의 시간변화와 임상적 해석을 함께 평가해야 한다.

그림에서 두 log-minus-log 곡선이 평행하면 두 군의 누적위험이 거의 비례한다는 시각적 근거가 된다. 그러나 곡선의 교차나 체계적인 간격 변화는 위험비가 시간에 따라 변할 가능성을 시사한다. 시각적 평행성만으로 가정을 확정할 수 없으며 잔차검정과 임상적 맥락을 함께 고려해야 한다.

비례위험 가정이 명백히 위반되는 경우 하나의 Cox 위험비만을 경제성 평가의 장기 치료효과로 사용하는 것은 부적절할 수 있다. 이 경우 9장과 10장에서 다루는 독립 모수모형, 시간-의존 치료효과, piecewise 모형, mixture 모형, landmark 모형 등을 고려해야 한다.

시간가변 치료효과는 다음과 같이 표현할 수 있다.

\[ h(t\mid A,X)=h_0(t)\exp\{\beta_A(t)A+X^\top\gamma\}. \]

예를 들어 \(\beta_A(t)=\beta_1\) for \(t\le c\)이고 \(\beta_A(t)=\beta_2\) for \(t>c\)인 구간별 모형은 초기와 후기 치료효과를 분리한다. 더욱 유연하게는 \(A\times g(t)\) 상호작용이나 spline 함수를 사용할 수 있다. 비례위험 위반이 확인되면 하나의 평균 위험비를 보고하는 것보다 시간별 위험비, 생존확률 차이 또는 RMST 차이를 함께 제시하는 것이 해석에 유리하다.

8.6.6 시간의존 공변량

추적 중 변하는 바이오마커, 치료노출, 이상반응 또는 후속치료를 공변량으로 포함할 때는

\[ h_i(t)=h_0(t)\exp\{X_i(t)^\top\beta\} \]

와 같은 시간의존 Cox 모형을 사용할 수 있다. 이때 \(X_i(t)\)는 시간 \(t\) 직전에 알려진 값이어야 한다. 사건 이후의 정보나 미래에 결정되는 노출을 현재 공변량으로 사용하면 불멸시간 편향이 발생할 수 있다. 또한 치료 후 변수는 매개변수이거나 시간의존 교란변수일 수 있으므로 그 계수를 단순한 인과적 치료효과로 해석해서는 안 된다.

8.7 생존함수와 전이확률

마코프모형에서는 각 주기 동안 한 상태에서 다른 상태로 이동할 확률이 필요하다. 생존함수는 주기별 사건 발생확률로 변환할 수 있다. 사건이 하나이고 생존함수 \(S(t)\)가 주어진 경우, 시간 \(t\)까지 사건이 없었던 환자가 다음 \(\Delta\) 기간 안에 사건을 경험할 조건부 확률은 다음과 같다.

\[ P(t<T\le t+\Delta \mid T>t) =1-\frac{S(t+\Delta)}{S(t)}. \]

위 식은 경제성 평가에서 매우 자주 사용된다. 예를 들어 1개월 주기의 마코프모형에서 생존함수로부터 월별 진행확률이나 사망확률을 계산할 때 이 식을 적용한다.

그림의 분자는 주기 종료시점까지 사건 없이 생존할 확률이고, 분모는 주기 시작시점까지 생존할 확률이다. 두 값의 비는 주기 시작 시점에 생존한 조건에서 주기 종료까지 계속 생존할 조건부 확률이며, 이를 1에서 빼면 해당 주기의 사건확률이 된다.

위험함수가 주기 안에서 일정하다고 가정할 수 있다면 위험률 \(r\)과 주기 길이 \(\Delta\)로부터 전이확률을 계산할 수 있다.

\[ p=1-\exp(-r\Delta). \]

시간에 따라 위험이 변하면 누적위험을 이용해야 한다.

\[ p(t,\Delta)=1-\exp\left[-\int_t^{t+\Delta}h(u)du\right]. \]

경쟁위험이 있는 경우에는 단순히 원인별 위험을 각각 \(1-\exp(-h_k\Delta)\)로 변환한 뒤 더하는 방식이 정확하지 않다. 한 원인의 사건이 발생하면 동일한 주기 안에서 다른 원인의 사건은 더 이상 발생할 수 없기 때문에 전체 이탈위험을 먼저 고려해야 한다.

원인별 위험이 주기 안에서 상수라고 하면 전체 위험은

\[ h_\cdot=\sum_{k=1}^K h_k \]

이고, 주기 \(\Delta\) 동안 원인 \(k\)로 전이할 정확한 확률은

\[ p_k(\Delta)=\frac{h_k}{h_\cdot}\left\{1-\exp(-h_\cdot\Delta)\right\}. \]

따라서 모든 원인별 전이확률의 합은 전체 사건확률 \(1-\exp(-h_\cdot\Delta)\)와 일치한다.

시간에 따라 원인별 위험이 변하는 경우 원인 \(k\)의 누적발생함수는 다음과 같다.

\[ F_k(t)=\int_0^t S(u)h_k(u)du, \]

여기서 전체 생존함수는 \(S(t)=\exp[-\int_0^t \sum_k h_k(u)du]\)이다. 상태 전이모형에서 경쟁위험은 5장과 9장에서 다시 다룬다.

8.7.1 다상태모형의 전이행렬

여러 건강상태 사이의 전이강도를 동시에 다룰 때는 생성행렬 \(Q(t)\)를 사용한다. 비대각 원소 \(q_{rs}(t)\)는 상태 \(r\)에서 상태 \(s\)로 이동하는 순간 전이강도이고, 대각 원소는

\[ q_{rr}(t)=-\sum_{s\ne r}q_{rs}(t) \]

로 정의된다. 시간동질 모형에서 주기 길이 \(\Delta\)의 전이확률 행렬은

\[ P(\Delta)=\exp\{Q\Delta\} \]

이다. 행렬지수는 동일한 주기 안에서 가능한 경쟁 전이와 연속적인 다단계 이동을 일관되게 반영한다. 각 전이강도를 독립적으로 확률로 바꾸면 행의 합이 1을 넘거나 경쟁관계가 잘못 반영될 수 있다.

주기가 충분히 짧으면 \(P(\Delta)\approx I+Q\Delta\)라는 1차 근사를 사용할 수 있지만, 위험이 높거나 주기가 길면 근사오차가 커진다. 따라서 주기 길이 민감도 분석 또는 행렬지수를 이용한 정확한 변환이 필요하다.

8.8 분석방법 선택의 이론적 기준

생존분석 방법은 단순히 자료 형식에 따라 선택하는 것이 아니라 필요한 estimand와 가정에 따라 선택해야 한다. 관찰기간 내 생존경험을 기술하려면 Kaplan-Meier와 RMST가 적합하고, 공변량을 조건으로 한 상대위험을 추정하려면 Cox 모형이 유용하다. 절대 생존확률의 장기 예측이 목적이라면 기준위험의 형태와 외삽 가정을 명시하는 모수적 또는 유연한 모형이 필요하다. 경쟁위험에서는 누적발생함수, 반복사건에서는 사건과정 모형, 여러 상태의 이동을 다루려면 다상태모형이 필요하다.

어떤 모형도 관찰자료가 제공하지 않는 장기 정보를 자동으로 만들어내지는 않는다. 외삽 결과는 관찰자료, 모형의 함수형 가정, 외부 근거와 임상적 판단의 결합으로 이해해야 한다. 따라서 통계적 적합도와 함께 구조적 타당성, 장기 위험형태, 외부자료와의 일치, 경제성 평가 결과에 대한 민감도를 평가해야 한다.

km_fit <- function(time, status) {
  event_times <- sort(unique(time[status == 1]))
  out <- data.frame(time = 0, n_risk = length(time), events = 0, survival = 1)
  s <- 1
  for (tt in event_times) {
    n_risk <- sum(time >= tt)
    d <- sum(time == tt & status == 1)
    s <- s * (1 - d / n_risk)
    out <- rbind(out, data.frame(time = tt, n_risk = n_risk, events = d, survival = s))
  }
  rownames(out) <- NULL
  out
}

rmst_from_km <- function(km, tau) {
  times <- c(km$time, tau)
  times <- sort(unique(times[times <= tau]))
  if (max(times) < tau) times <- c(times, tau)
  area <- 0
  for (j in seq_len(length(times) - 1)) {
    t0 <- times[j]
    t1 <- times[j + 1]
    s0 <- km$survival[max(which(km$time <= t0))]
    area <- area + s0 * (t1 - t0)
  }
  area
}

Cox 부분가능도 직접 최적화

다음 코드는 치료군 지시변수 하나만 포함한 Cox 모형의 부분가능도를 직접 최대화한다. 동시 사건 처리는 단순화하였다.

Code 
cox_binary <- function(time, status, x) {
  ord <- order(time)
  time <- time[ord]
  status <- status[ord]
  x <- x[ord]
  event_index <- which(status == 1)

  neg_log_pl <- function(beta) {
    xb <- beta * x
    total <- 0
    for (i in event_index) {
      risk_set <- which(time >= time[i])
      total <- total + xb[i] - log(sum(exp(xb[risk_set])))
    }
    -total
  }

  fit <- optim(par = 0, fn = neg_log_pl, hessian = TRUE)
  beta <- fit$par[1]

## 생존자료의 시간축과 관찰과정

생존분석에서는 사건의 종류뿐 아니라 **시간의 출발점(time origin)**, 사건을 관찰하는 시간척도, 관찰이 시작되고 종료되는 규칙을 함께 정의해야 한다. 동일한 환자자료라도 무작위배정일, 치료 시작일, 진단일 또는 수술일 중 어느 시점을 시간 0으로 선택하는지에 따라 추정되는 생존분포가 달라질 수 있다. 따라서 시간 원점은 임상적 질문과 경제성 평가 모형의 상태 정의에 맞아야 한다.

환자 $i$가 시간 $t$까지 사건을 경험했는지를 나타내는 계수과정(counting process)을

$$
N_i(t)=I(T_i^*\le t,\delta_i=1)
$$

로 정의할 수 있다. 또한 시간 $t$ 직전에 환자가 관찰 중이며 아직 사건을 경험하지 않아 위험집합에 포함되는지를

$$
Y_i(t)=I(L_i<t\le T_i)
$$

로 나타낼 수 있다. 여기서 $L_i$는 환자가 위험집합에 진입한 시점이다. 모든 환자가 시간 0부터 관찰된다면 $L_i=0$이지만, 코호트 진입이 늦은 자료에서는 $L_i>0$일 수 있다. 이 표현을 사용하면 순간 사건 발생률은 작은 시간 간격 $dt$에 대해 다음과 같이 이해할 수 있다.

$$
E\{dN_i(t)\mid \mathcal{F}_{t^-}\}=Y_i(t)h_i(t)dt.
$$

즉, 환자가 위험집합에 있을 때만 사건이 발생할 수 있으며, 사건 발생의 순간적 평균은 위험함수에 의해 결정된다. Kaplan-Meier 추정량과 Cox 모형은 서로 다른 형태를 가지지만 모두 이 위험집합의 순차적 비교를 이용한다.

### 사건, 중도절단, 절단의 구분

생존자료의 불완전한 관찰은 한 가지 형태만 있는 것이 아니다.

- **우측 중도절단(right censoring)**은 사건시간이 어떤 시점보다 크다는 정보만 관찰되는 경우이다.
- **좌측 중도절단(left censoring)**은 사건이 관찰 시작 전 어느 시점에 이미 발생했다는 정보만 있는 경우이다.
- **구간 중도절단(interval censoring)**은 사건이 두 검사 시점 사이에서 발생했다는 것만 아는 경우이다.
- **좌측 절단(left truncation)**은 특정 시점까지 사건 없이 생존한 사람만 표본에 들어올 수 있는 관찰 구조이다.

중도절단은 표본에 포함된 환자의 사건시간을 불완전하게 관찰하는 문제인 반면, 절단은 환자가 표본에 포함될 가능성 자체가 사건시간에 의존하는 문제이다. 좌측 절단이 있는 자료에서는 시간 $t$의 위험집합을 단순히 $T_i\ge t$인 환자로 정의하면 안 되고, $L_i<t\le T_i$인 환자로 정의해야 한다. 이를 무시하면 오래 생존한 환자가 과대표집되는 불멸시간 또는 생존자 선택 편향이 발생할 수 있다.

## 중도절단 {#sec-censoring}

### 생존시간 자료의 기본 구조

생존시간 자료는 어떤 기준 시점에서 사건이 발생할 때까지의 시간을 관찰한 자료이다. 여기서 사건(event)은 반드시 사망만을 의미하지 않는다. 연구 목적에 따라 사건은 질병 진행, 재발, 입원, 치료 중단, 이상반응 발생 등으로 정의될 수 있다.

| 평가변수 | 사건의 예 | 경제성 평가에서의 사용 |
|---|---|---|
| OS | 사망 | 생존기간, 사망 상태 점유율 |
| PFS | 질병 진행 또는 사망 | 무진행 상태 점유율 |
| EFS | 재발, 진행, 2차 암, 사망 등 | 질환별 모형 상태 정의 |
| TTD | 치료 중단 | 약제비, 투약기간, 치료중단율 |
| 입원까지의 시간 | 첫 입원 | 사건 비용, 입원 관련 효용 감소 |

환자 $i$의 실제 사건 발생시간을 $T_i^*$라고 하자. 실제 연구에서는 모든 환자에게서 $T_i^*$를 완전히 관찰할 수 없다. 연구 종료 시점까지 사건이 발생하지 않거나, 추적에서 탈락하거나, 다른 치료로 전환되거나, 행정적 자료 추적이 중단될 수 있다. 이러한 상황을 중도절단(censoring)이라고 한다.

환자 $i$의 중도절단시간을 $C_i$라고 하면 실제로 관찰되는 시간은 다음과 같다.

$$
T_i = \min(T_i^*, C_i).
$$

사건 관찰 여부를 나타내는 지시변수는 다음과 같이 정의한다.

$$
\delta_i = I(T_i^* \le C_i)
=
\begin{cases}
1, & \text{사건이 관찰됨}, \\
0, & \text{중도절단됨}.
\end{cases}
$$

따라서 생존자료에서 환자 $i$의 관찰값은 보통 다음 쌍으로 표현된다.

$$
(T_i,\delta_i), \qquad i=1,\ldots,n.
$$

공변량 $X_i$가 함께 관찰되는 경우 분석자료는 $(T_i,\delta_i,X_i)$로 표현된다. Cox 모형이나 모수적 생존모형은 이 공변량을 이용하여 치료효과, 예후인자, 효과변경인자를 모델링한다.

![생존자료에서 사건과 중도절단의 개념](figures/ch08/fig-ch08-censoring-timeline.png){fig-align="center" width="90%"}


그림에서 사건이 관찰된 환자는 사건 시점까지 위험집합에 남아 있다가 해당 시점에 사건 수에 기여한다. 중도절단된 환자는 중도절단 시점 직전까지 위험집합에 기여하지만 그 이후에는 분석에서 빠진다. 중도절단 표시가 생존곡선을 직접 낮추지 않는 이유는 중도절단 자체가 사건이 아니기 때문이다.

### 중도절단의 직관적 의미

중도절단된 환자는 사건이 발생하지 않은 환자와 동일하지 않다. 예를 들어 어떤 환자가 18개월까지 생존한 뒤 연구가 종료되어 더 이상 관찰되지 않았다고 하자. 이 환자에게서 우리가 아는 정보는 “사건이 발생하지 않았다”가 아니라 “적어도 18개월까지는 사건이 발생하지 않았다”이다.

이 차이는 매우 중요하다. 중도절단 환자를 단순히 사건 미발생자로 처리하면 장기 생존을 과대평가할 수 있다. 반대로 중도절단 시점에 사건이 발생한 것으로 처리하면 생존을 과소평가한다. 생존분석은 중도절단된 환자가 제공하는 부분 정보를 적절히 사용하여 생존함수를 추정한다.

::: {.callout-warning title="중도절단 해석 시 주의점"}
중도절단은 사건이 발생하지 않았다는 뜻이 아니다. 중도절단은 “관찰 가능한 기간 안에서는 사건이 확인되지 않았다”는 뜻이다. 따라서 중도절단된 환자는 중도절단 시점까지는 위험집합에 포함되지만 그 이후에는 위험집합에서 제외된다.
:::

### 독립적 중도절단 가정

Kaplan-Meier 추정량과 Cox 비례위험모형 같은 표준 생존분석 방법은 일반적으로 독립적 중도절단(independent censoring)을 가정한다. 이는 중도절단 시간이 사건 발생시간에 대한 추가 정보를 제공하지 않는다는 의미이다. 공변량 $X_i$가 주어진 조건에서 다음과 같이 표현할 수 있다.

$$
T_i^* \perp C_i \mid X_i.
$$

직관적으로 말하면, 같은 시점까지 사건 없이 생존한 환자들 중에서 중도절단된 환자와 계속 추적된 환자의 이후 사건 위험이 같다고 가정하는 것이다. 이 가정이 위반되면 생존함수 추정에 편향이 발생한다. 예를 들어 상태가 악화된 환자가 추적에서 더 자주 탈락한다면 관찰자료만으로 추정한 생존곡선은 실제보다 낙관적일 수 있다.

중도절단은 다음과 같이 구분할 수 있다.

| 유형 | 설명 | 독립성 위반 가능성 |
|---|---|---|
| 행정적 중도절단 | 연구 종료일 때문에 추적이 끝남 | 보통 낮음 |
| 무작위 탈락 | 이사, 연락 두절 등 | 상황에 따라 다름 |
| 질병 악화로 인한 탈락 | 상태 악화 후 추적 중단 | 높음 |
| 치료 교차 또는 구조치료 | 사건 위험과 관련된 치료 변경 | 높음 |

경제성 평가에서는 생존곡선의 꼬리 부분이 장기 비용과 장기 효과에 큰 영향을 미친다. 따라서 추적기간이 짧고 중도절단이 많을수록 장기 외삽의 불확실성은 커진다. 특히 OS 자료가 성숙하지 않은 상태에서 경제성 평가를 수행하는 경우 number at risk, 중도절단 패턴, 추적기간의 성숙도, 교차투여 또는 후속치료의 영향을 함께 검토해야 한다.


### 독립적 중도절단의 식별 의미

독립적 중도절단은 단순한 기술적 가정이 아니라 관찰되지 않은 사건시간 분포를 식별하기 위한 조건이다. 공변량 $X$로 충분히 조건화한 뒤 중도절단이 독립적이라면, 계속 관찰된 환자의 이후 사건 경험을 이용하여 중도절단된 환자의 반사실적 이후 경과를 대표할 수 있다. 반대로 건강상태 악화, 치료효과 부족, 독성 또는 의료접근성 저하가 탈락과 사건위험을 동시에 높인다면 표준 Kaplan-Meier 곡선과 Cox 모형은 편향될 수 있다.

중도절단 과정에 영향을 주는 공변량 $Z(t)$가 관찰되어 있다면 역중도절단확률가중(inverse probability of censoring weighting, IPCW)을 고려할 수 있다. 시간 $t$까지 중도절단되지 않을 조건부 확률을

$$
G(t\mid Z)=P(C\ge t\mid Z)
$$

라고 하면, 관찰이 계속된 환자에게 대략 $1/G(t\mid Z)$의 가중치를 부여한다. 중도절단될 가능성이 높은 특성을 가진 환자 중 계속 관찰된 소수의 환자가 유사한 환자들을 더 많이 대표하도록 하는 원리이다. 그러나 IPCW 역시 중도절단 모형이 올바르게 지정되고 관련 예측변수가 충분히 관찰되었다는 가정에 의존한다.

### 경쟁사건은 중도절단이 아니다

관심 사건이 아닌 다른 사건이 이후 관심 사건의 발생을 불가능하게 만들면 이를 경쟁사건(competing event)이라고 한다. 예를 들어 질병 진행을 관심 사건으로 볼 때 진행 전 사망은 단순한 추적중단이 아니라 이후 진행을 불가능하게 만드는 경쟁사건이다. 이를 독립적 중도절단으로 처리한 Kaplan-Meier의 $1-\widehat S(t)$는 현실의 진행 누적발생확률이 아니라 경쟁사건이 제거된 가상세계의 확률을 추정한다. 실제 누적발생확률이 필요하다면 원인별 위험과 전체 생존을 결합한 누적발생함수를 사용해야 한다.

## 생존시간의 분포를 표현하는 다섯 가지 함수 {#sec-five-survival-functions}

생존시간 $T$는 $0$보다 큰 값을 가지는 연속형 확률변수로 생각할 수 있다.

$$
T \ge 0.
$$

생존시간의 확률분포는 여러 함수로 표현할 수 있다. 경제성 평가에서 특히 중요한 함수는 다음 다섯 가지이다.

1. 확률밀도함수 $f(t)$
2. 누적분포함수 $F(t)$
3. 생존함수 $S(t)$
4. 위험함수 $h(t)$
5. 누적위험함수 $H(t)$

이 다섯 함수는 서로 다른 방식으로 생존시간의 분포를 표현하지만 수학적으로는 서로 연결되어 있다.

![생존시간 분포를 표현하는 다섯 가지 함수](figures/ch08/fig-ch08-five-functions.png){fig-align="center" width="95%"}


그림의 다섯 함수는 서로 독립된 결과가 아니라 동일한 생존시간 분포를 서로 다른 관점에서 표현한 것이다. $F(t)$와 $S(t)$는 누적확률을, $f(t)$는 사건시간의 국소적 분포를, $h(t)$는 아직 사건이 발생하지 않은 환자의 조건부 순간위험을, $H(t)$는 그 위험의 누적량을 보여준다.

### 확률밀도함수와 누적분포함수

확률밀도함수 $f(t)$는 사건이 시간 $t$ 근처에서 발생할 상대적 가능성을 나타낸다.

$$
f(t)=\frac{dF(t)}{dt}.
$$

연속형 생존시간에서는 특정한 한 시점 $t$에서 사건이 정확히 발생할 확률은 0이다. 따라서 $f(t)$ 자체를 확률로 해석하면 안 된다. 대신 짧은 구간 $[t,t+dt)$에서 사건이 발생할 확률은 대략 다음과 같다.

$$
P(t \le T < t+dt) \approx f(t)dt.
$$

누적분포함수 $F(t)$는 시간 $t$까지 사건이 발생할 확률이다.

$$
F(t)=P(T\le t).
$$

예를 들어 $F(12)=0.30$이라면 12개월 이내 사건 발생확률이 30%라는 의미이다.

### 생존함수

생존함수 $S(t)$는 시간 $t$를 초과하여 사건 없이 생존할 확률이다.

$$
S(t)=P(T>t).
$$

누적분포함수와 생존함수는 다음 관계를 가진다.

$$
S(t)=1-F(t).
$$

경제성 평가에서 생존함수는 매우 중요하다. 생존함수의 면적은 평균 생존시간과 연결되고, 분할생존모형에서는 생존함수가 건강상태 점유확률을 결정한다. 예를 들어 전체생존함수 $S_{OS}(t)$와 무진행생존함수 $S_{PFS}(t)$가 주어졌을 때 상태 점유확률은 다음과 같다.

$$
P(\text{PF at }t)=S_{PFS}(t),
$$

$$
P(\text{PD at }t)=S_{OS}(t)-S_{PFS}(t),
$$

$$
P(\text{Dead at }t)=1-S_{OS}(t).
$$

이 관계가 성립하려면 모든 시점에서 $S_{OS}(t)\ge S_{PFS}(t)$이어야 한다. 실제 모형 적합 또는 외삽 과정에서 이 논리적 제약이 깨지면 상태 점유확률이 음수가 될 수 있으므로 반드시 점검해야 한다.

![PFS와 OS 생존함수에서 분할생존모형의 상태 점유율을 계산한다.](figures/ch08/fig-ch08-partitioned-states.png){fig-align="center" width="90%"}


그림의 세 영역은 동일한 시점의 주변 생존확률 차이로 정의된다. 이 계산은 각 환자가 실제로 어떤 경로로 진행했는지를 직접 모형화하지 않고도 상태 점유율을 얻는 장점이 있다. 반면 PFS와 OS의 결합 경로, 진행 후 사망시간, 치료중단과 진행의 순서는 두 주변 생존곡선만으로 식별되지 않는다. 비용이나 효용이 사건 경로와 체류기간에 민감하다면 이 구조적 한계를 별도로 검토해야 한다.

### 위험함수와 누적위험함수

위험함수 $h(t)$는 시간 $t$ 직전까지 사건 없이 생존한 환자가 바로 다음 순간에 사건을 경험할 순간 위험을 의미한다.

$$
h(t)=\lim_{\Delta t\to 0}
\frac{P(t\le T<t+\Delta t \mid T\ge t)}{\Delta t}.
$$

위험함수는 조건부 사건 발생률로 이해할 수 있다. 전체 모집단 중 사건이 발생할 확률이 아니라, 시간 $t$까지 아직 사건을 경험하지 않은 환자들 중에서 사건이 발생할 순간적 경향을 나타낸다. 위험함수는 생존함수와 확률밀도함수로 다음과 같이 표현된다.

$$
h(t)=\frac{f(t)}{S(t)}.
$$

누적위험함수 $H(t)$는 시간 0부터 $t$까지 위험함수를 누적한 값이다.

$$
H(t)=\int_0^t h(u)du.
$$

생존함수와 누적위험함수는 다음 관계를 가진다.

위험함수와 생존함수의 관계는 조건부 확률에서 직접 유도할 수 있다. 작은 시간 간격 $\Delta t$에서

$$
P(T\ge t+\Delta t\mid T\ge t)
=\frac{S(t+\Delta t)}{S(t)}
\approx 1-h(t)\Delta t.
$$

양변을 정리하고 $\Delta t\to0$으로 보내면 다음 미분방정식을 얻는다.

$$
\frac{dS(t)}{dt}=-h(t)S(t).
$$

초기조건 $S(0)=1$을 적용하여 적분하면

$$
\log S(t)=-\int_0^t h(u)du=-H(t),
$$

따라서

$$
S(t)=\exp\{-H(t)\},
$$

$$
H(t)=-\log S(t).
$$

누적위험 $H(t)$는 확률이 아니므로 1보다 클 수 있다. 다만 $H(t)$가 증가할수록 $S(t)=\exp\{-H(t)\}$는 감소한다. 이 관계 때문에 위험함수의 작은 차이가 장기간 누적되면 생존곡선과 평균 생존기간에 큰 차이를 만들 수 있다.

![위험함수의 모양은 장기 외삽 결과에 큰 영향을 준다.](figures/ch08/fig-ch08-hazard-shapes.png){fig-align="center" width="90%"}


그림에서 동일한 단기 생존적합도를 보이는 모형이라도 위험함수가 일정한지, 증가하는지, 감소하는지에 따라 관찰기간 이후의 생존확률이 크게 달라질 수 있다. 따라서 장기 외삽에서는 생존곡선의 적합도뿐 아니라 위험함수의 임상적 개연성과 장기 형태를 함께 평가해야 한다.

::: {.callout-important title="위험은 확률이 아니다"}
위험함수 $h(t)$는 순간 사건 발생률이며 단위 시간당 값이다. 따라서 $h(t)$는 1보다 클 수 있다. 반면 특정 기간의 사건 발생확률은 항상 0과 1 사이에 있어야 한다. 위험률을 전이확률로 바꾸려면 주기 길이를 고려해야 한다.
:::

### 다섯 함수의 관계

생존시간 분포를 표현하는 함수들의 핵심 관계는 다음과 같다.

$$
F(t)=P(T\le t), \qquad S(t)=1-F(t),
$$

$$
f(t)=\frac{dF(t)}{dt}=-\frac{dS(t)}{dt},
$$

$$
h(t)=\frac{f(t)}{S(t)}=-\frac{d}{dt}\log S(t),
$$

$$
H(t)=\int_0^t h(u)du=-\log S(t),
$$

$$
S(t)=\exp\{-H(t)\}.
$$

이 관계는 생존분석의 거의 모든 모형에서 반복적으로 사용된다. 예를 들어 Weibull 모형을 shape-scale 모수화로 쓰면 생존함수와 위험함수는 다음과 같다.

$$
S(t)=\exp\left[-\left(\frac{t}{\lambda}\right)^k\right],
$$

$$
h(t)=\frac{k}{\lambda}\left(\frac{t}{\lambda}\right)^{k-1}.
$$

여기서 $k$는 shape 모수이고 $\lambda$는 scale 모수이다. $k=1$이면 위험함수는 일정하고, $k>1$이면 위험은 시간에 따라 증가하며, $0<k<1$이면 위험은 시간에 따라 감소한다.


### 생존분포의 분위수와 적률

생존시간의 $p$ 분위수 $t_p$는 $F(t_p)=p$, 또는 동등하게 $S(t_p)=1-p$를 만족하는 시간이다. 중앙생존기간은 $p=0.5$인 특별한 경우이다. Weibull 분포에서는

$$
t_p=\lambda\{-\log(1-p)\}^{1/k}
$$

로 계산할 수 있다. 중앙생존기간은 관찰자료의 절반이 사건을 경험해야 안정적으로 추정되지만, 평균 생존시간은 분포의 꼬리 전체에 의존한다. 경제성 평가에서 평균 생존기간과 QALY가 필요한 이유 때문에 중앙값만으로 장기 효과를 대체할 수 없다.

비음수 생존시간의 고차 적률도 생존함수로 표현할 수 있다.

$$
E(T^r)=r\int_0^\infty t^{r-1}S(t)dt, \qquad r>0.
$$

$r=1$이면 평균 생존시간 식이 되고, $r=2$이면 생존시간의 분산을 계산하는 데 사용할 수 있다. 이 결과는 생존함수가 단순한 시점별 확률을 넘어 생존시간 분포 전체의 요약량을 결정한다는 점을 보여준다.

::: {.callout-note title="모수화 확인"}
Weibull, log-normal, generalized gamma와 같은 분포는 소프트웨어마다 scale, rate, shape의 정의가 다를 수 있다. 동일한 모수 이름이라도 생존함수와 위험함수의 수식이 달라질 수 있으므로 경제성 평가 코드를 구현할 때는 사용한 소프트웨어의 모수화를 명시하고, 특정 시점의 생존확률과 위험률을 수작업으로 검산하는 것이 필요하다.
:::

## 생존분석의 목표 {#sec-goals-survival-analysis}

생존분석의 목표는 연구 목적과 경제성 평가 모형의 필요에 따라 달라진다. 분석 전에 사건 정의, 시간 원점, 분석 인구집단, 중간사건 처리, 효과척도, 제한시점과 요약방법을 함께 명시해야 한다. 이러한 요소가 생존분석의 estimand를 구성한다. 동일한 임상시험에서도 치료정책 estimand, 치료순응 estimand 또는 가상의 교차투여 제거 estimand는 서로 다른 생존곡선과 경제성 평가 결과를 만들 수 있다.

크게 네 가지 목표로 정리할 수 있다.

### 생존경험의 기술

첫 번째 목표는 특정 치료군 또는 환자집단의 생존경험을 기술하는 것이다. Kaplan-Meier 곡선, 중앙생존기간, 특정 시점 생존율, 제한평균 생존시간이 대표적인 기술적 요약값이다.

중앙생존기간 $m$은 생존확률이 0.5가 되는 시간이다.

$$
S(m)=0.5.
$$

단, 추적기간 동안 생존곡선이 0.5 아래로 내려가지 않으면 중앙생존기간은 관찰자료만으로 추정할 수 없다. 이 경우 중앙생존기간이 “도달하지 않음”으로 보고될 수 있지만, 경제성 평가에서는 평균 생존기간과 QALY 추정이 여전히 필요하다.

### 치료군 간 생존 차이 비교

두 번째 목표는 치료군 간 생존 차이를 비교하는 것이다. 임상시험에서는 log-rank 검정과 Cox 비례위험모형이 자주 사용된다. 그러나 경제성 평가에서는 단순히 $p$-value가 유의한지보다 치료군 간 생존곡선 차이가 기대 QALY와 비용에 어느 정도 영향을 미치는지가 더 중요하다.

치료군 1과 치료군 0의 제한평균 생존시간 차이는 다음과 같이 정의할 수 있다.

$$
\Delta RMST(\tau)=\int_0^\tau \{S_1(t)-S_0(t)\}dt.
$$

이 값은 제한시점 $\tau$까지의 평균 생존기간 차이로 해석할 수 있으며, 위험비보다 절대효과에 가까운 척도이다.

RMST 차이는 생존곡선이 교차하거나 치료효과가 시간에 따라 변할 때에도 정의할 수 있다. 다만 $\tau$가 달라지면 효과의 크기와 해석도 달라지므로 제한시점은 자료를 본 뒤 가장 유리한 시점을 선택하기보다 임상적 의사결정 시점과 두 군의 공통 추적가능기간을 고려하여 사전에 정하는 것이 바람직하다.

위험비는 순간위험의 상대적 비교이고 RMST 차이는 일정 기간 동안 얻은 평균 생존시간의 절대 차이이다. 두 지표는 서로 대체관계가 아니며, 비례위험이 성립하더라도 기준위험이 다르면 동일한 위험비가 서로 다른 RMST 차이를 만들 수 있다.

### 공변량을 보정한 치료효과 추정

세 번째 목표는 공변량을 보정한 치료효과를 추정하는 것이다. 예를 들어 다음과 같은 Cox 모형을 사용할 수 있다.

$$
h(t\mid A,X)=h_0(t)\exp(\beta_A A+X^\top\gamma),
$$

여기서 $A$는 치료군 지시변수, $X$는 공변량 벡터이다. 치료효과는 보통 $\exp(\beta_A)$로 표현되는 위험비로 요약된다. 무작위배정 임상시험에서는 공변량 보정이 정밀도를 높일 수 있고, 관찰연구에서는 교란 조정을 위해 필요하다.

### 경제성 평가 모델 입력값 생성

네 번째 목표는 경제성 평가 모형의 입력값을 생성하는 것이다. 생존분석 결과는 다음과 같이 모형에 연결된다.

| 생존분석 산출물 | 경제성 평가에서의 사용 |
|---|---|
| $S_{OS}(t)$ | 생존상태, 사망상태 점유율 |
| $S_{PFS}(t)$ | 무진행 상태 점유율 |
| $h(t)$ | 순간 전이강도, 주기별 전이확률 |
| $RMST(\tau)$ | 제한기간 평균 생존기간 |
| $\int_0^\tau u(t)S(t)dt$ | 기대 QALY |
| 위험비 $HR$ | 상대효과, 간접비교, 메타분석 입력값 |

그림의 흐름에서 통계적 추정량은 그대로 경제성 평가 결과가 되는 것이 아니라, 상태 정의·분석기간·할인·효용·비용과 결합되어 모형 입력값으로 변환된다. 따라서 임상분석에서 적절한 효과척도와 경제성 평가에서 필요한 입력값이 반드시 일치하는 것은 아니다.

### 평균 생존시간과 생존곡선 아래 면적

비음수 생존시간 $T$의 평균은 생존함수의 면적으로 표현할 수 있다. 이 관계는 지시함수의 기댓값을 이용하여 유도할 수 있다. 모든 $T\ge0$에 대해

$$
T=\int_0^\infty I(T>t)dt
$$

이므로 적분과 기댓값의 순서를 바꾸면

$$
\mathbb{E}(T)
=\int_0^\infty E\{I(T>t)\}dt
=\int_0^\infty P(T>t)dt
=\int_0^\infty S(t)dt.
$$

분석기간을 $\tau$로 제한하면 제한평균 생존시간(restricted mean survival time, RMST)은 다음과 같다.

$$
RMST(\tau)=\mathbb{E}\{\min(T,\tau)\}=\int_0^\tau S(t)dt.
$$

이 식은 경제성 평가에서 매우 중요하다. 생존곡선 아래 면적은 기대 생존기간이고, 여기에 시간에 따른 효용값을 곱하면 기대 QALY가 된다.

$$
Q(\tau)=\int_0^\tau u(t)S(t)dt.
$$

효용이 상태에 따라 달라지는 분할생존모형에서는 다음과 같이 표현할 수 있다.

$$
Q(\tau)=\int_0^\tau \{u_{PF}S_{PFS}(t)+u_{PD}[S_{OS}(t)-S_{PFS}(t)]\}dt.
$$


효과 할인율이 연속시간 기준 $r_E$이고 효용이 시간에 따라 변한다면 일반적인 기대 QALY는

$$
Q(\tau)=\int_0^\tau e^{-r_Et}\sum_{s=1}^K u_s(t)P\{X(t)=s\}dt
$$

로 표현할 수 있다. 여기서 $X(t)$는 시간 $t$의 건강상태이다. 이 식은 생존분석 결과가 경제성 평가에 연결될 때 상태 점유확률, 상태별 효용, 시간가변 효용과 할인이 동시에 고려되어야 함을 보여준다.

![제한평균 생존시간은 생존곡선 아래 면적이다.](figures/ch08/fig-ch08-rmst-area.png){fig-align="center" width="90%"}


그림의 음영 면적은 제한시점까지의 기대 생존시간이다. 두 치료군의 음영 면적 차이는 해당 기간의 평균 생존이득이며, 생존곡선이 교차하더라도 양의 영역과 음의 영역을 모두 반영한 순효과를 제공한다.

## Kaplan-Meier 곡선 {#sec-kaplan-meier}

### Kaplan-Meier 추정량의 개념

Kaplan-Meier 추정량은 중도절단이 있는 생존자료에서 생존함수 $S(t)$를 비모수적으로 추정하는 방법이다. 핵심 아이디어는 전체 생존확률을 각 사건 시점에서의 조건부 생존확률의 곱으로 표현하는 것이다.

사건이 발생한 서로 다른 시점을 $t_1<t_2<\cdots<t_K$라고 하자. 시점 $t_j$ 직전에 위험집합에 있는 환자 수를 $n_j$, 시점 $t_j$에서 사건이 발생한 환자 수를 $d_j$라고 하자. 그러면 $t_j$를 통과할 조건부 생존확률은 다음과 같이 추정된다.

$$
1-\frac{d_j}{n_j}.
$$

연쇄확률법칙에 따르면 $t_k$ 이후까지 생존할 확률은 각 사건시점을 순서대로 통과할 조건부 확률의 곱으로 쓸 수 있다.

$$
P(T>t_k)=\prod_{j=1}^k P(T>t_j\mid T\ge t_j).
$$

각 조건부 생존확률을 위험집합에서 관찰된 비율 $(n_j-d_j)/n_j$로 대체하면 Kaplan-Meier 추정량을 얻는다.

$$
\widehat{S}_{KM}(t)=\prod_{t_j\le t}\left(1-\frac{d_j}{n_j}\right).
$$

중도절단은 사건 시점이 아니므로 생존확률을 직접 낮추지 않는다. 대신 중도절단 시점 이후의 위험집합 크기 $n_j$를 줄인다. 즉, 중도절단 환자는 중도절단 시점까지는 생존함수 추정에 정보를 제공하지만 그 이후에는 위험집합에서 제외된다.

![Kaplan-Meier 곡선은 사건 시점에서만 계단식으로 감소하고 중도절단 시점은 표시된다.](figures/ch08/fig-ch08-km-step-censoring.png){fig-align="center" width="90%"}


그림에서 계단의 수직 하강은 사건 발생을 나타내고, 수평 구간은 다음 사건 전까지 추정 생존확률이 유지됨을 나타낸다. 중도절단 표시는 해당 환자가 그 시점까지 생존했다는 정보를 제공하지만 곡선을 직접 하강시키지는 않는다.

### Greenwood 분산과 신뢰구간

Kaplan-Meier 추정량의 분산은 Greenwood 공식으로 근사할 수 있다.

$$
\widehat{\operatorname{Var}}\{\widehat{S}_{KM}(t)\}
=\widehat{S}_{KM}(t)^2
\sum_{t_j\le t}\frac{d_j}{n_j(n_j-d_j)}.
$$

생존확률이 0과 1 사이에 있어야 하므로 실제 신뢰구간은 단순 정규근사보다 로그-로그 변환을 이용하는 경우가 많다. 로그-로그 변환은 다음과 같다.

$$
g\{S(t)\}=\log[-\log\{S(t)\}].
$$

생존곡선의 꼬리 부분에서는 $n_j$가 작아지고 분산이 커진다. 따라서 꼬리 부분에서 Kaplan-Meier 곡선을 그대로 장기 외삽의 근거로 사용하는 것은 위험할 수 있다.


로그-로그 변환을 이용한 대략적인 $100(1-\alpha)\%$ 신뢰구간은 변환척도에서

$$
\log[-\log\{\widehat S(t)\}]
\pm z_{1-\alpha/2}
\frac{\sqrt{\widehat{\operatorname{Var}}\{\widehat S(t)\}}}
{\widehat S(t)|\log\widehat S(t)|}
$$

을 구한 뒤 원래 생존확률 척도로 역변환한다. 이 방식은 신뢰구간이 0과 1의 범위를 벗어나는 문제를 줄인다.

### Nelson-Aalen 누적위험 추정량

Kaplan-Meier가 생존함수를 직접 추정한다면 Nelson-Aalen 추정량은 누적위험함수를 다음과 같이 추정한다.

$$
\widehat H_{NA}(t)=\sum_{t_j\le t}\frac{d_j}{n_j}.
$$

이에 대응하는 생존함수는 $\exp\{-\widehat H_{NA}(t)\}$로 얻을 수 있다. 사건비율 $d_j/n_j$가 작을 때

$$
-\log\left(1-\frac{d_j}{n_j}\right)\approx \frac{d_j}{n_j}
$$

이므로 Kaplan-Meier와 Nelson-Aalen 기반 생존추정량은 서로 가깝다. 누적위험 그림은 위험이 시간에 따라 얼마나 빠르게 누적되는지 확인하고 모수적 위험함수의 형태를 평가하는 데 유용하다.

### Number at risk의 중요성

Kaplan-Meier 그림에는 보통 각 시점의 number at risk가 함께 제시된다. 이는 해당 시점 직전까지 사건도 중도절단도 경험하지 않아 여전히 위험집합에 남아 있는 환자 수이다.

![Number at risk는 꼬리 부분 생존곡선의 신뢰도를 판단하는 핵심 정보이다.](figures/ch08/fig-ch08-number-at-risk.png){fig-align="center" width="90%"}


그림에서 후반 시점의 생존확률이 높아 보이더라도 위험집합이 매우 작다면 그 값은 소수 환자의 경과에 의해 결정될 수 있다. 따라서 꼬리의 평탄한 모양을 치료효과의 지속이나 완치분율의 근거로 곧바로 해석해서는 안 된다.

Number at risk가 매우 작아진 구간의 생존곡선은 소수 환자의 사건 여부에 크게 흔들릴 수 있다. 경제성 평가에서 생존외삽을 수행할 때는 KM 곡선의 마지막 부분만 보고 장기 생존을 판단해서는 안 된다. 관찰기간, 사건 수, 중도절단 수, 위험집합 크기, 임상적 자연사 정보를 함께 고려해야 한다.

### Kaplan-Meier 곡선과 제한평균 생존시간

Kaplan-Meier 곡선이 계단함수이므로 제한평균 생존시간은 각 구간의 직사각형 면적 합으로 계산할 수 있다. 사건 시점과 제한시점을 합친 시간 구간을 $0=s_0<s_1<\cdots<s_M=\tau$라고 하면 다음과 같다.

$$
\widehat{RMST}(\tau)=\sum_{m=0}^{M-1}\widehat{S}_{KM}(s_m)(s_{m+1}-s_m).
$$

RMST는 비례위험 가정에 의존하지 않는 절대효과 척도라는 장점이 있다. 다만 제한시점 $\tau$를 사전에 합리적으로 정해야 하며, 두 군 모두 충분한 추적자료가 있는 기간 안에서 해석하는 것이 바람직하다.

### 군 간 비교와 log-rank 검정

두 군의 생존곡선이 동일하다는 귀무가설은 log-rank 검정으로 평가할 수 있다. 각 사건 시점 $t_j$에서 전체 위험집합 크기를 $n_j$, 치료군 위험집합 크기를 $n_{1j}$, 전체 사건 수를 $d_j$라고 하면 귀무가설 아래 치료군의 기대 사건 수는

$$
e_{1j}=d_j\frac{n_{1j}}{n_j}
$$

이다. 전체 관찰 사건 수와 기대 사건 수의 차이를 시점 전체에 걸쳐 합한 통계량을 그 분산으로 표준화하면 근사적인 카이제곱 검정통계량을 얻는다.

Log-rank 검정은 대체로 모든 사건시점에 동일한 가중을 주며 비례위험 대립가설에서 효율적이다. 생존곡선이 교차하거나 효과가 특정 시기에만 나타나면 검정력이 낮아지거나 임상적으로 중요한 차이를 충분히 표현하지 못할 수 있다. 또한 유의확률은 효과크기를 직접 나타내지 않으므로 위험비, 시점별 생존차이, RMST 차이와 함께 해석해야 한다.

### Kaplan-Meier 곡선의 한계

Kaplan-Meier 곡선은 관찰자료 안에서 생존경험을 기술하는 데 강력하지만 경제성 평가에서는 다음 한계가 있다.

1. 관찰된 마지막 시점 이후 생존확률을 제공하지 않는다.
2. 중도절단이 많은 꼬리 부분의 불확실성이 크다.
3. 공변량 보정 또는 표준화가 직접적으로 어렵다.
4. 주기별 전이확률을 부드럽게 계산하기 어렵다.
5. 장기 분석기간의 평균 생존기간과 QALY 추정에는 외삽이 필요하다.

따라서 경제성 평가에서는 KM 곡선을 생존외삽 모형의 적합도와 타당성을 평가하는 기준 자료로 사용하고, 분석기간 전체에 필요한 생존함수는 9장과 10장에서 다루는 모수적 또는 유연한 생존모형으로 추정하는 경우가 많다.

## Cox 비례위험모형 {#sec-cox-model}

### Cox 모형의 기본 형태

Cox 비례위험모형은 공변량이 위험함수에 곱셈적으로 작용한다고 가정한다. 환자 $i$의 공변량 벡터를 $X_i$라고 하면 다음과 같이 쓸 수 있다.

$$
h(t\mid X_i)=h_0(t)\exp(X_i^\top\beta).
$$

여기서 $h_0(t)$는 기준 위험함수이고, $\beta$는 회귀계수 벡터이다. Cox 모형의 중요한 특징은 $h_0(t)$의 구체적인 형태를 모수적으로 지정하지 않아도 $\beta$를 추정할 수 있다는 점이다. 따라서 Cox 모형은 준모수적(semi-parametric) 모형이다.

치료군 지시변수 $A_i$만 포함한 경우 모형은 다음과 같다.

$$
h(t\mid A_i)=h_0(t)\exp(\beta A_i).
$$

치료군이 $A_i=1$, 대조군이 $A_i=0$이라면 위험비는 다음과 같다.

$$
HR=\frac{h(t\mid A_i=1)}{h(t\mid A_i=0)}=\exp(\beta).
$$

### 위험비의 올바른 해석

위험비가 0.70이라는 것은 모든 시점에서 치료군의 순간 위험이 대조군의 70%라는 의미이다. 이는 사건 발생확률이 30% 감소했다는 뜻이 아니다. 위험은 조건부 순간 사건 발생률이고, 누적 사건확률은 생존함수 전체에 의해 결정된다.

비례위험 가정하에서 치료군 생존함수는 대조군 기준 생존함수로부터 다음과 같이 표현할 수 있다.

$$
S_1(t)=\{S_0(t)\}^{HR}.
$$

따라서 특정 시점의 대조군 사건확률 $p_0(t)=1-S_0(t)$에 위험비 $HR$을 적용한 치료군 사건확률은 다음과 같다.

$$
p_1(t)=1-\{1-p_0(t)\}^{HR}.
$$

위 식은 위험비를 사건확률에 직접 곱하는 것이 잘못될 수 있음을 보여준다.

![Cox 비례위험모형에서 위험비는 생존함수 전체를 통해 사건확률로 변환된다.](figures/ch08/fig-ch08-cox-ph-survival.png){fig-align="center" width="90%"}


그림은 동일한 위험비라도 기준 생존곡선의 수준과 추적시점에 따라 절대 생존확률 차이가 달라짐을 보여준다. 따라서 위험비만으로 QALY 이득을 결정할 수 없으며, 대조군 기준위험과 치료효과가 함께 생존함수에 적용되어야 한다.

::: {.callout-warning title="위험비 해석 시 주의점"}
위험비 $HR=0.70$은 “사건확률이 30% 감소한다”는 뜻이 아니다. 비례위험 가정하에서는 대조군 생존함수 $S_0(t)$에 대해 치료군 생존함수가 $S_1(t)=S_0(t)^{HR}$로 변환된다. 따라서 절대 사건확률 감소는 기준 위험, 추적기간, 생존곡선의 형태에 따라 달라진다.
:::

### 부분가능도

Cox 모형은 기준 위험함수 $h_0(t)$를 직접 모수화하지 않고 부분가능도(partial likelihood)를 이용하여 $\beta$를 추정한다. 사건이 발생한 환자 $i$의 사건 시점 $T_i$에서 위험집합을 $R(T_i)$라고 하자. 위험집합은 시점 $T_i$ 직전까지 아직 사건도 중도절단도 경험하지 않은 환자들의 집합이다.

동시 사건이 없다고 단순화하면 부분가능도는 다음과 같다.

$$
L_p(\beta)=\prod_{i:\delta_i=1}
\frac{\exp(X_i^\top\beta)}{\sum_{\ell\in R(T_i)}\exp(X_\ell^\top\beta)}.
$$

로그 부분가능도는 다음과 같다.

$$
\ell_p(\beta)=\sum_{i:\delta_i=1}
\left[X_i^\top\beta-
\log\left\{\sum_{\ell\in R(T_i)}\exp(X_\ell^\top\beta)\right\}\right].
$$

이 식은 각 사건 시점에서 “위험집합에 있던 환자들 중 실제 사건이 발생한 환자가 누구였는가”에 대한 조건부 확률을 곱한 것으로 해석할 수 있다.


부분가능도는 사건이 발생한 순서와 사건시점의 위험집합 비교에서 회귀계수 정보를 추출한다. 기준위험함수의 구체적 형태가 소거되기 때문에 회귀계수 추정에는 편리하지만, 절대 생존확률을 계산하려면 이후 기준 누적위험함수를 별도로 추정해야 한다.

실제 자료에서는 동일한 시점에 여러 사건이 기록될 수 있다. 이를 동시 사건(ties)이라고 하며 Breslow 근사, Efron 근사 또는 exact 방법으로 처리한다. 사건시점이 반올림되어 동시 사건이 많을 때는 처리방법에 따라 추정치가 달라질 수 있으므로 사용한 방법을 명시해야 한다.

### 기준 누적위험과 생존함수 추정

Cox 모형에서 $\widehat{\beta}$를 추정한 뒤 기준 누적위험함수는 Breslow 추정량으로 추정할 수 있다.

$$
\widehat{H}_0(t)=\sum_{t_j\le t}\frac{d_j}{\sum_{\ell\in R(t_j)}\exp(X_\ell^\top\widehat{\beta})}.
$$

이에 대응하는 기준 생존함수는 다음과 같다.

$$
\widehat{S}_0(t)=\exp\{-\widehat{H}_0(t)\}.
$$

공변량 $X$를 가진 환자의 생존함수는 다음과 같이 추정된다.

$$
\widehat{S}(t\mid X)=\widehat{S}_0(t)^{\exp(X^\top\widehat{\beta})}.
$$

이 식을 사용하면 공변량 패턴별 조건부 생존곡선을 구할 수 있다. Cox 회귀계수의 위험비는 다른 공변량을 고정한 조건부 효과이며, 목표 모집단 전체의 주변 생존곡선이나 주변 위험비와 일반적으로 동일하지 않다. 특히 위험비는 비축약적(non-collapsible)이므로 교란이 없더라도 공변량 보정 전후의 위험비가 달라질 수 있다.

경제성 평가에서는 특정 환자군의 평균 생존곡선이 필요하므로 개별 환자의 예측 생존곡선을 목표 모집단 분포에 대해 평균하는 표준화가 필요할 수 있다.

$$
\widehat{S}_{\text{std}}(t)=\frac{1}{N}\sum_{i=1}^N \widehat{S}(t\mid X_i).
$$

### 비례위험 가정

Cox 모형의 핵심 가정은 위험비가 시간에 따라 일정하다는 것이다. 두 공변량 값 $X_a$와 $X_b$를 가진 환자의 위험비는 다음과 같다.

$$
\frac{h(t\mid X_a)}{h(t\mid X_b)}
=\exp\{(X_a-X_b)^\top\beta\},
$$

이 값은 $t$에 의존하지 않는다. 즉, 치료효과가 추적기간 전체에서 동일한 상대적 크기로 유지된다고 가정한다.

비례위험 가정은 다음과 같은 방법으로 점검할 수 있다.

1. log-minus-log 생존곡선이 대체로 평행한지 확인한다.
2. Schoenfeld 잔차와 시간의 관련성을 확인한다.
3. 시간-치료 상호작용 항을 포함하여 치료효과가 시간에 따라 변하는지 평가한다.
4. 초기와 후기 구간의 위험비가 크게 다른지 확인한다.
5. 임상적 기전과 후속치료 패턴이 일정한 위험비를 지지하는지 검토한다.


공변량 $X_k$에 대한 Schoenfeld 잔차는 사건이 발생한 환자의 공변량과 해당 사건시점 위험집합의 위험가중 평균 공변량 차이로 이해할 수 있다.

$$
r_{jk}=X_{jk}-
\frac{\sum_{\ell\in R(t_j)}X_{\ell k}\exp(X_\ell^\top\widehat\beta)}
{\sum_{\ell\in R(t_j)}\exp(X_\ell^\top\widehat\beta)}.
$$

비례위험 가정이 성립하면 이 잔차에 체계적인 시간추세가 없어야 한다. 잔차검정의 유의성은 표본크기에 영향을 받으므로 검정결과뿐 아니라 잔차그림, 효과크기의 시간변화와 임상적 해석을 함께 평가해야 한다.

![비례위험 가정하에서 log-minus-log 곡선은 대체로 평행한 형태를 보인다.](figures/ch08/fig-ch08-log-minus-log.png){fig-align="center" width="90%"}


그림에서 두 log-minus-log 곡선이 평행하면 두 군의 누적위험이 거의 비례한다는 시각적 근거가 된다. 그러나 곡선의 교차나 체계적인 간격 변화는 위험비가 시간에 따라 변할 가능성을 시사한다. 시각적 평행성만으로 가정을 확정할 수 없으며 잔차검정과 임상적 맥락을 함께 고려해야 한다.

비례위험 가정이 명백히 위반되는 경우 하나의 Cox 위험비만을 경제성 평가의 장기 치료효과로 사용하는 것은 부적절할 수 있다. 이 경우 9장과 10장에서 다루는 독립 모수모형, 시간-의존 치료효과, piecewise 모형, mixture 모형, landmark 모형 등을 고려해야 한다.


시간가변 치료효과는 다음과 같이 표현할 수 있다.

$$
h(t\mid A,X)=h_0(t)\exp\{\beta_A(t)A+X^\top\gamma\}.
$$

예를 들어 $\beta_A(t)=\beta_1$ for $t\le c$이고 $\beta_A(t)=\beta_2$ for $t>c$인 구간별 모형은 초기와 후기 치료효과를 분리한다. 더욱 유연하게는 $A\times g(t)$ 상호작용이나 spline 함수를 사용할 수 있다. 비례위험 위반이 확인되면 하나의 평균 위험비를 보고하는 것보다 시간별 위험비, 생존확률 차이 또는 RMST 차이를 함께 제시하는 것이 해석에 유리하다.

### 시간의존 공변량

추적 중 변하는 바이오마커, 치료노출, 이상반응 또는 후속치료를 공변량으로 포함할 때는

$$
h_i(t)=h_0(t)\exp\{X_i(t)^\top\beta\}
$$

와 같은 시간의존 Cox 모형을 사용할 수 있다. 이때 $X_i(t)$는 시간 $t$ 직전에 알려진 값이어야 한다. 사건 이후의 정보나 미래에 결정되는 노출을 현재 공변량으로 사용하면 불멸시간 편향이 발생할 수 있다. 또한 치료 후 변수는 매개변수이거나 시간의존 교란변수일 수 있으므로 그 계수를 단순한 인과적 치료효과로 해석해서는 안 된다.

## 생존함수와 전이확률 {#sec-survival-transition-probability}

마코프모형에서는 각 주기 동안 한 상태에서 다른 상태로 이동할 확률이 필요하다. 생존함수는 주기별 사건 발생확률로 변환할 수 있다. 사건이 하나이고 생존함수 $S(t)$가 주어진 경우, 시간 $t$까지 사건이 없었던 환자가 다음 $\Delta$ 기간 안에 사건을 경험할 조건부 확률은 다음과 같다.

$$
P(t<T\le t+\Delta \mid T>t)
=1-\frac{S(t+\Delta)}{S(t)}.
$$

위 식은 경제성 평가에서 매우 자주 사용된다. 예를 들어 1개월 주기의 마코프모형에서 생존함수로부터 월별 진행확률이나 사망확률을 계산할 때 이 식을 적용한다.

![생존함수에서 주기별 전이확률을 계산하는 방법](figures/ch08/fig-ch08-transition-probability.png){fig-align="center" width="90%"}


그림의 분자는 주기 종료시점까지 사건 없이 생존할 확률이고, 분모는 주기 시작시점까지 생존할 확률이다. 두 값의 비는 주기 시작 시점에 생존한 조건에서 주기 종료까지 계속 생존할 조건부 확률이며, 이를 1에서 빼면 해당 주기의 사건확률이 된다.

위험함수가 주기 안에서 일정하다고 가정할 수 있다면 위험률 $r$과 주기 길이 $\Delta$로부터 전이확률을 계산할 수 있다.

$$
p=1-\exp(-r\Delta).
$$

시간에 따라 위험이 변하면 누적위험을 이용해야 한다.

$$
p(t,\Delta)=1-\exp\left[-\int_t^{t+\Delta}h(u)du\right].
$$

경쟁위험이 있는 경우에는 단순히 원인별 위험을 각각 $1-\exp(-h_k\Delta)$로 변환한 뒤 더하는 방식이 정확하지 않다. 한 원인의 사건이 발생하면 동일한 주기 안에서 다른 원인의 사건은 더 이상 발생할 수 없기 때문에 전체 이탈위험을 먼저 고려해야 한다.

원인별 위험이 주기 안에서 상수라고 하면 전체 위험은

$$
h_\cdot=\sum_{k=1}^K h_k
$$

이고, 주기 $\Delta$ 동안 원인 $k$로 전이할 정확한 확률은

$$
p_k(\Delta)=\frac{h_k}{h_\cdot}\left\{1-\exp(-h_\cdot\Delta)\right\}.
$$

따라서 모든 원인별 전이확률의 합은 전체 사건확률 $1-\exp(-h_\cdot\Delta)$와 일치한다.

시간에 따라 원인별 위험이 변하는 경우 원인 $k$의 누적발생함수는 다음과 같다.

$$
F_k(t)=\int_0^t S(u)h_k(u)du,
$$

여기서 전체 생존함수는 $S(t)=\exp[-\int_0^t \sum_k h_k(u)du]$이다. 상태 전이모형에서 경쟁위험은 5장과 9장에서 다시 다룬다.


### 다상태모형의 전이행렬

여러 건강상태 사이의 전이강도를 동시에 다룰 때는 생성행렬 $Q(t)$를 사용한다. 비대각 원소 $q_{rs}(t)$는 상태 $r$에서 상태 $s$로 이동하는 순간 전이강도이고, 대각 원소는

$$
q_{rr}(t)=-\sum_{s\ne r}q_{rs}(t)
$$

로 정의된다. 시간동질 모형에서 주기 길이 $\Delta$의 전이확률 행렬은

$$
P(\Delta)=\exp\{Q\Delta\}
$$

이다. 행렬지수는 동일한 주기 안에서 가능한 경쟁 전이와 연속적인 다단계 이동을 일관되게 반영한다. 각 전이강도를 독립적으로 확률로 바꾸면 행의 합이 1을 넘거나 경쟁관계가 잘못 반영될 수 있다.

주기가 충분히 짧으면 $P(\Delta)\approx I+Q\Delta$라는 1차 근사를 사용할 수 있지만, 위험이 높거나 주기가 길면 근사오차가 커진다. 따라서 주기 길이 민감도 분석 또는 행렬지수를 이용한 정확한 변환이 필요하다.

## 분석방법 선택의 이론적 기준

생존분석 방법은 단순히 자료 형식에 따라 선택하는 것이 아니라 필요한 estimand와 가정에 따라 선택해야 한다. 관찰기간 내 생존경험을 기술하려면 Kaplan-Meier와 RMST가 적합하고, 공변량을 조건으로 한 상대위험을 추정하려면 Cox 모형이 유용하다. 절대 생존확률의 장기 예측이 목적이라면 기준위험의 형태와 외삽 가정을 명시하는 모수적 또는 유연한 모형이 필요하다. 경쟁위험에서는 누적발생함수, 반복사건에서는 사건과정 모형, 여러 상태의 이동을 다루려면 다상태모형이 필요하다.

어떤 모형도 관찰자료가 제공하지 않는 장기 정보를 자동으로 만들어내지는 않는다. 외삽 결과는 관찰자료, 모형의 함수형 가정, 외부 근거와 임상적 판단의 결합으로 이해해야 한다. 따라서 통계적 적합도와 함께 구조적 타당성, 장기 위험형태, 외부자료와의 일치, 경제성 평가 결과에 대한 민감도를 평가해야 한다.

```{r}
km_fit <- function(time, status) {
  event_times <- sort(unique(time[status == 1]))
  out <- data.frame(time = 0, n_risk = length(time), events = 0, survival = 1)
  s <- 1
  for (tt in event_times) {
    n_risk <- sum(time >= tt)
    d <- sum(time == tt & status == 1)
    s <- s * (1 - d / n_risk)
    out <- rbind(out, data.frame(time = tt, n_risk = n_risk, events = d, survival = s))
  }
  rownames(out) <- NULL
  out
}
```

```{r}
rmst_from_km <- function(km, tau) {
  times <- c(km$time, tau)
  times <- sort(unique(times[times <= tau]))
  if (max(times) < tau) times <- c(times, tau)
  area <- 0
  for (j in seq_len(length(times) - 1)) {
    t0 <- times[j]
    t1 <- times[j + 1]
    s0 <- km$survival[max(which(km$time <= t0))]
    area <- area + s0 * (t1 - t0)
  }
  area
}
```

```{r}
cox_binary <- function(time, status, x) {
  ord <- order(time)
  time <- time[ord]
  status <- status[ord]
  x <- x[ord]
  event_index <- which(status == 1)

  neg_log_pl <- function(beta) {
    xb <- beta * x
    total <- 0
    for (i in event_index) {
      risk_set <- which(time >= time[i])
      total <- total + xb[i] - log(sum(exp(xb[risk_set])))
    }
    -total
  }

  fit <- optim(par = 0, fn = neg_log_pl, hessian = TRUE)
  beta <- fit$par[1]
  se <- sqrt(1 / fit$hessian[1, 1])

  data.frame(
    beta = beta,
    SE = se,
    HR = exp(beta),
    lower95 = exp(beta - 1.96 * se),
    upper95 = exp(beta + 1.96 * se)
  )
}

cox_binary(dat$time, dat$status, dat$trt)
```

## 핵심 수식 정리 {.unnumbered}

|---|---|
| 관찰 생존시간 | $T_i=\min(T_i^*,C_i)$ |
| 사건 지시변수 | $\delta_i=I(T_i^*\le C_i)$ |
| 생존함수 | $S(t)=P(T>t)$ |
| 누적분포함수 | $F(t)=P(T\le t)=1-S(t)$ |
| 위험함수 | $h(t)=f(t)/S(t)$ |
| 누적위험함수 | $H(t)=\int_0^t h(u)du$ |
| 생존함수와 누적위험 | $S(t)=\exp\{-H(t)\}$ |
| 평균 생존시간 | $\mathbb{E}(T)=\int_0^\infty S(t)dt$ |
| 제한평균 생존시간 | $RMST(\tau)=\int_0^\tau S(t)dt$ |
| 기대 QALY | $Q(\tau)=\int_0^\tau u(t)S(t)dt$ |
| Kaplan-Meier 추정량 | $\widehat{S}_{KM}(t)=\prod_{t_j\le t}(1-d_j/n_j)$ |
| Greenwood 분산 | $\widehat{S}(t)^2\sum_{t_j\le t}d_j/[n_j(n_j-d_j)]$ |

| 위험비 | $HR=\exp(\beta)$ |
| PH하 생존함수 변환 | $S_1(t)=S_0(t)^{HR}$ |
| 생존함수 기반 전이확률 | $p(t,\Delta)=1-S(t+\Delta)/S(t)$ |
| 상수 위험률 전이확률 | $p=1-\exp(-r\Delta)$ |
