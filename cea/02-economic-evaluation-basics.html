2.1 분석 대상 인구집단과 급여 대상 인구집단

경제성 평가에서 가장 먼저 명확히 해야 할 질문은 “누구에게 이 치료를 사용할 것인가?”이다. 의약품의 가치는 치료가 적용되는 환자집단에 따라 크게 달라진다. 동일한 신약이라도 질병의 중증도, 이전 치료 경험, 바이오마커 상태, 동반질환, 연령, 예후, 치료 순서에 따라 기대효과와 비용효과성이 달라질 수 있다.

경제성 평가에서는 적어도 세 종류의 인구집단을 구분하는 것이 좋다.

구분 의미 경제성 평가에서의 역할
임상시험 대상 인구집단 실제 임상시험에 등록된 환자집단 근거가 직접 관찰된 집단
분석 대상 인구집단 경제성 평가 모델이 직접 대상으로 삼는 집단 기대비용과 기대효과가 정의되는 집단
급여 대상 인구집단 의사결정기관이 실제 급여 적용을 검토하는 집단 정책 결정이 적용되는 집단

세 집단은 반드시 일치하지 않는다. 임상시험은 엄격한 선정기준과 제외기준을 적용하므로 실제 진료환경의 환자보다 더 균질한 집단을 포함하는 경우가 많다. 반면 급여 대상 인구집단은 실제 임상현장에서 해당 약제를 사용할 가능성이 있는 더 넓은 환자집단일 수 있다.

예를 들어 어떤 항암제가 다음과 같은 임상시험에서 효과를 보였다고 하자.

  • 성인 환자
  • ECOG 수행상태 0 또는 1
  • 특정 유전자 변이 양성
  • 이전 치료 1회 이하
  • 주요 장기 기능이 충분히 보존된 환자

하지만 실제 급여 검토에서는 다음과 같은 질문이 제기될 수 있다.

  • 수행상태가 2인 환자에게도 적용할 것인가?
  • 이전 치료를 2회 이상 받은 환자에게도 급여할 것인가?
  • 고령 환자에게도 동일한 상대효과를 기대할 수 있는가?
  • 동반질환이 많은 환자에게도 이상반응 비용과 치료효과가 동일한가?
  • 임상시험의 대조군이 국내 실제 진료의 대체 치료전략과 일치하는가?

따라서 경제성 평가는 임상시험 참여자에게서 관찰된 평균 치료효과를 단순히 계산하는 작업이 아니다. 실제 급여 대상 환자집단에서 기대되는 효과, 비용, 불확실성을 평가해야 한다.

Important실무적 핵심

경제성 평가의 결과는 분석 대상 인구집단의 정의에 민감하다. 분석 대상 인구집단이 지나치게 좁으면 실제 급여 의사결정에 적용하기 어렵고, 지나치게 넓으면 임상근거의 적용 가능성이 약해질 수 있다.

2.1.1 분석 대상 인구집단 정의의 수식적 표현

치료전략을 \(j \in \{0,1\}\)이라고 하자. 여기서 \(j=0\)은 기존 치료, \(j=1\)은 신약 치료를 의미한다. 환자의 기저 특성 벡터를 \(X\)라고 하고, 분석 대상 인구집단을 \(\mathcal{P}\)라고 하자. 치료전략 \(j\)에서의 비용 확률변수를 \(C_j\), 건강결과 확률변수를 \(H_j\)라고 하면 분석 대상 인구집단에서의 기대비용과 기대효과는 다음과 같이 정의할 수 있다.

\[ \mu_{C,j}(\mathcal{P}) = \mathbb{E}(C_j \mid X \in \mathcal{P}), \]

\[ \mu_{H,j}(\mathcal{P}) = \mathbb{E}(H_j \mid X \in \mathcal{P}). \]

이때 \(H_j\)는 분석 목적에 따라 생존연수, 재발 방지 건수, QALY 등으로 정의될 수 있다. 비용효용분석에서는 보통 \(H_j=Q_j\)로 두고 \(Q_j\)를 QALY라고 해석한다.

분석 대상 인구집단이 달라지면 기대값도 달라진다.

\[ \mathbb{E}(C_j \mid X \in \mathcal{P}_1) \neq \mathbb{E}(C_j \mid X \in \mathcal{P}_2) \]

일반적으로 \(\mathcal{P}_1\)과 \(\mathcal{P}_2\)의 예후, 중증도, 이상반응 위험, 치료 중단율, 의료자원 사용 양상이 다르면 위의 부등식은 자연스럽게 발생한다. 따라서 인구집단의 정의는 단순한 서술 요소가 아니라 기대비용과 기대효과를 결정하는 수학적 조건이다.

위 그림에서 겹치는 영역은 임상근거가 급여 대상에 직접 적용될 가능성이 높은 환자군을 나타낸다. 겹치지 않는 급여 대상 영역은 임상시험에서 충분히 대표되지 않았을 수 있으므로, 실제사용자료나 외부 연구를 통한 보완이 필요하다. 반대로 임상시험에 포함되었지만 실제 급여 범위에서 제외되는 환자는 경제성 평가의 최종 평균값에 포함하지 않아야 한다.

2.1.2 표준화와 외적 타당도

임상시험 표본의 특성 분포가 급여 대상 인구집단의 특성 분포와 다르면, 임상시험에서 관찰한 평균 효과를 그대로 적용하기 어렵다. 이때 조건부 기대값을 이용하여 목표 모집단으로 표준화할 수 있다.

임상시험 자료에서 \(X=x\)인 환자의 치료전략 \(j\)에 대한 조건부 기대효과가 \(m_j(x)=\mathbb{E}(H_j \mid X=x)\)라고 하자. 급여 대상 인구집단의 특성 분포를 \(F^*(x)\)라고 하면, 목표 모집단에서의 평균 효과는 다음과 같이 표현할 수 있다.

\[ \mu_{H,j}^{*} = \int m_j(x)\,dF^*(x). \]

비용도 같은 방식으로 표준화할 수 있다.

\[ \mu_{C,j}^{*} = \int \mathbb{E}(C_j \mid X=x)\,dF^*(x). \]

이 수식은 회귀분석, MAIC, 표준화, 실제사용자료 기반 보정분석이 모두 “목표 모집단에서의 기대값”을 추정하기 위한 도구임을 보여준다.

2.1.3 치료효과 이질성과 목표 estimand

분석 대상 인구집단을 정의할 때는 단순히 포함기준을 나열하는 것만으로 충분하지 않다. 어떤 환자 특성이 치료효과, 비용 또는 삶의 질을 변화시키는지 함께 고려해야 한다. 환자의 기저 특성에 따라 치료효과가 달라지는 현상을 치료효과 이질성 또는 효과수정이라고 한다.

환자 특성이 \(X=x\)일 때 치료전략 1과 0의 조건부 평균 치료효과를 다음과 같이 정의하자.

\[ \tau_H(x) =\mathbb{E}(H_1-H_0\mid X=x). \]

목표 모집단에서의 평균 치료효과는 조건부 효과를 목표 모집단의 특성 분포에 대해 평균한 값이다.

\[ \Delta H^{*} =\int \tau_H(x)\,dF^{*}(x). \]

따라서 임상시험과 급여 대상 인구집단의 특성 분포가 다르더라도 모든 환자에서 치료효과가 일정하다면 일반화 문제가 크지 않을 수 있다. 반대로 치료효과가 연령, 중증도, 바이오마커 또는 이전 치료에 따라 달라진다면 두 집단의 구성 차이가 경제성 평가 결과에 직접 영향을 준다.

비용의 증분도 같은 방식으로 정의할 수 있다.

\[ \Delta C^{*} =\int \left[ \mathbb{E}(C_1\mid X=x)-\mathbb{E}(C_0\mid X=x) \right]dF^{*}(x). \]

이때 목표 모집단의 ICER는 환자별 ICER의 평균이 아니라, 목표 모집단에서 먼저 평균한 증분비용과 증분효과의 비율이다.

\[ ICER^{*} =\frac{\Delta C^{*}}{\Delta H^{*}}. \]

일반적으로 다음 두 값은 같지 않다.

\[ \mathbb{E}\left( \frac{C_1-C_0}{H_1-H_0} \right) \neq \frac{\mathbb{E}(C_1-C_0)} {\mathbb{E}(H_1-H_0)}. \]

경제성 평가는 집단 수준의 자원배분 문제이므로 오른쪽의 비율을 사용한다.

2.1.4 외적 타당도를 위한 기본 조건

임상시험 결과를 다른 모집단으로 일반화하려면 몇 가지 조건이 필요하다. 첫째, 동일한 치료전략이 두 자료원에서 같은 의미를 가져야 한다. 둘째, 치료효과에 영향을 주면서 임상시험 참여 여부와도 관련된 환자 특성이 충분히 측정되어야 한다. 셋째, 목표 모집단의 모든 주요 환자 유형이 임상시험 자료에서도 어느 정도 관찰되어야 한다.

임상시험 참여 여부를 \(S\)로 나타내고 \(S=1\)을 임상시험 참여, \(S=0\)을 목표 모집단이라고 하자. 대표적인 일반화 조건은 다음과 같이 표현할 수 있다.

\[ (H_1,H_0)\perp S\mid X. \]

이는 \(X\)를 조건으로 하면 잠재적 건강결과의 분포가 임상시험 참여 여부와 독립이라는 의미이다. 또한 양의성 조건은 다음과 같다.

\[ 0<P(S=1\mid X=x)<1 \]

목표 모집단에서 실제로 존재하는 환자 특성 \(x\)에 대해 임상시험 참여 가능성이 0이면, 해당 환자 유형의 효과는 자료만으로 직접 일반화하기 어렵다. 이 경우 모형 외삽이나 추가 자료가 필요하며 불확실성이 커진다.

2.2 분석 기간

경제성 평가에서 분석 기간은 비용과 효과를 어느 시점까지 누적하여 평가할 것인지를 의미한다. 분석 기간은 경제성 평가 결과에 큰 영향을 미친다. 특히 신약의 비용은 치료 초기에 집중되지만 효과는 장기간에 걸쳐 발생하거나, 예방적 치료처럼 현재 비용을 지불하고 미래 사건을 줄이는 경우 분석 기간의 선택이 핵심 문제가 된다.

분석 기간은 다음 두 질문과 연결된다.

  1. 치료전략 간 중요한 비용과 효과의 차이가 언제까지 발생하는가?
  2. 의사결정자가 고려해야 할 시간 범위는 어디까지인가?

분석 기간은 크게 다음과 같이 구분할 수 있다.

분석 기간 설명 적절한 상황
임상시험 추적기간 임상시험에서 실제 관찰된 기간만 분석 단기 효과와 비용이 대부분 관찰되는 경우
고정 기간 1년, 5년, 10년 등 특정 기간까지 분석 정책적으로 정해진 기간 또는 질병 특성이 제한적인 경우
생애기간 대상 환자가 사망할 때까지 분석 생존, 장기 합병증, 만성질환, 예방 효과가 중요한 경우

경제성 평가에서는 분석 기간이 충분히 길어야 한다. 치료전략 간 비용과 효과의 중요한 차이가 더 이상 의미 있게 발생하지 않는 시점까지 분석하는 것이 원칙이다. 그러나 분석 기간이 길수록 장기 외삽 가정의 영향이 커지므로, 장기 결과의 불확실성을 민감도 분석으로 평가해야 한다.

2.2.1 누적 기대비용과 기대효과

시간 \(t\)에서 치료전략 \(j\)의 비용 발생률을 \(c_j(t)\), 건강결과 발생률을 \(h_j(t)\)라고 하자. 분석 기간을 \(\tau\)라고 하고, 비용 할인율을 \(r_C\), 효과 할인율을 \(r_H\)라고 하면 할인된 누적 기대비용과 누적 기대효과는 다음과 같이 표현할 수 있다.

\[ C_j(\tau;r_C) = \int_0^{\tau} c_j(t)(1+r_C)^{-t}\,dt, \]

\[ H_j(\tau;r_H) = \int_0^{\tau} h_j(t)(1+r_H)^{-t}\,dt. \]

증분비용과 증분효과는 분석 기간의 함수이다.

\[ \Delta C(\tau)=C_1(\tau;r_C)-C_0(\tau;r_C), \]

\[ \Delta H(\tau)=H_1(\tau;r_H)-H_0(\tau;r_H). \]

따라서 ICER도 분석 기간에 따라 달라진다.

\[ ICER(\tau)=\frac{\Delta C(\tau)}{\Delta H(\tau)}, \qquad \Delta H(\tau)\neq 0. \]

위 그림은 치료 초기에 비용 차이가 크게 발생하고 건강효과 차이는 시간이 지나면서 누적될 수 있음을 보여준다. 특정 시점의 ICER는 두 누적곡선의 차이를 이용하여 계산되므로, 분석 기간이 달라지면 같은 치료라도 다른 ICER가 산출될 수 있다.

Note분석 기간의 중요성

비용은 치료 초기에 집중되고 효과는 장기간에 걸쳐 발생하는 치료에서는 분석 기간이 짧으면 비용효과성이 불리하게 평가될 수 있다. 반대로 장기 효과가 불확실한 상황에서 과도하게 긴 분석 기간을 사용하면 효과가 과대평가될 수 있다.

2.2.2 이산 시간 모형에서의 표현

마코프모델과 같은 이산 시간 모형에서는 분석 기간을 \(K\)개의 주기로 나누어 표현한다. \(k\)번째 주기의 대표 시점을 \(t_k\), 주기 길이를 \(\Delta_k\)라고 하자. 치료전략 \(j\)에서 \(k\)번째 주기의 비용을 \(c_{jk}\), 건강효과를 \(h_{jk}\)라고 하면 다음과 같이 계산한다.

\[ C_j = \sum_{k=1}^{K}\frac{c_{jk}}{(1+r_C)^{t_k}}, \]

\[ H_j = \sum_{k=1}^{K}\frac{h_{jk}}{(1+r_H)^{t_k}}. \]

주기 초 또는 주기 말 값을 그대로 사용하면 누적값이 과대 또는 과소 추정될 수 있다. 그래서 상태 전이 모형에서는 반주기 보정 또는 더 짧은 주기 길이를 사용하여 연속 시간 과정을 근사한다. 이 문제는 4장과 5장에서 더 자세히 다룬다.

2.2.3 분석 기간의 절단과 장기 외삽

분석 기간이 짧으면 이후에 발생할 비용과 효과가 계산에서 제외된다. 이를 분석 기간에 의한 절단이라고 볼 수 있다. 생애기간 기대효과를 \(H_j(\infty)\)라고 할 때, 분석 기간 \(\tau\)를 사용하여 제외되는 기대효과는 다음과 같다.

\[ B_{H,j}(\tau) =H_j(\infty)-H_j(\tau) =\int_{\tau}^{\infty}h_j(t)(1+r_H)^{-t}\,dt. \]

두 전략의 비교에서 중요한 것은 각 전략의 절단량 자체보다 증분 절단량이다.

\[ B_{\Delta H}(\tau) =\Delta H(\infty)-\Delta H(\tau). \]

치료효과가 장기간 유지되는 전략에서는 \(B_{\Delta H}(\tau)\)가 클 수 있다. 반면 치료효과가 빠르게 소실되거나 두 전략의 생존곡선이 장기적으로 수렴하면 충분히 긴 시점 이후의 증분효과는 작아진다.

생애기간 분석은 문자 그대로 무한한 시간까지 계산한다는 뜻이라기보다, 이후의 추가 비용과 효과가 의사결정에 영향을 주지 않을 정도로 충분히 긴 기간을 사용한다는 뜻이다. 실제 모형에서는 다음 조건을 확인하는 것이 중요하다.

\[ \left|\Delta H(\tau+\delta)-\Delta H(\tau)\right|<\varepsilon_H, \]

\[ \left|\Delta C(\tau+\delta)-\Delta C(\tau)\right|<\varepsilon_C. \]

즉, 분석 기간을 조금 더 늘려도 증분비용과 증분효과가 거의 변하지 않는다면 분석 기간이 충분히 길다고 볼 수 있다.

2.2.4 할인식의 해석

연간 할인율이 \(r\)일 때 \(t\)년 후 1단위의 현재가치는 \((1+r)^{-t}\)이다. 연속 할인율 \(\rho\)를 사용하면 할인인자는 다음과 같이 쓸 수 있다.

\[ e^{-\rho t}. \]

두 표현이 같은 현재가치를 갖도록 하려면 다음 관계가 성립한다.

\[ \rho=\log(1+r). \]

할인은 단순한 계산기법이 아니라 현재와 미래의 가치가 동일하지 않다는 사회적 시간선호를 반영한다. 비용과 건강효과에 서로 다른 할인율을 적용하면 장기적으로 발생하는 효과와 비용의 상대적 가치가 달라지므로, 분석 결과의 해석도 달라진다.

반주기 보정은 각 주기의 사건과 비용이 주기 말에만 발생한다고 보는 근사를 완화한다. 주기 길이가 1년이고 사건이 주기 내에서 대략 균등하게 발생한다면 대표 시점을 \(t_k=k-0.5\)로 두어 다음과 같이 계산할 수 있다.

\[ H_j \approx \sum_{k=1}^{K} \frac{h_{jk}}{(1+r_H)^{k-0.5}}. \]

주기 길이가 충분히 짧아지면 반주기 보정의 영향은 작아진다.

2.3 비용효과분석과 비용효용분석

경제성 평가는 치료전략의 비용과 결과를 함께 비교하는 분석이다. 그중 의약품 가치 평가에서 가장 자주 사용되는 형태는 비용효과분석과 비용효용분석이다.

2.3.1 비용효과분석

비용효과분석은 효과를 자연 단위로 측정한다. 예를 들어 다음과 같은 결과지표가 사용될 수 있다.

  • 생존연수
  • 재발 방지 건수
  • 심근경색 예방 건수
  • 입원 감소 건수
  • 혈압 감소량
  • HbA1c 감소량

비용효과분석에서 치료전략 \(1\)과 \(0\)의 증분비용효과비는 다음과 같다.

\[ ICER_H = \frac{C_1-C_0}{H_1-H_0}. \]

여기서 \(H_j\)는 자연 단위의 건강결과이다. 예를 들어 \(H_j\)가 생존연수라면 단위는 원/생존연수이고, 재발 방지 건수라면 원/재발 방지 건수이다.

2.3.2 비용효용분석

비용효용분석은 효과를 QALY로 측정한다. QALY는 생존기간과 건강관련 삶의 질을 결합한 지표이다. 가장 단순한 경우 효용가중치 \(u\)인 건강상태로 \(L\)년을 생존하면 QALY는 다음과 같다.

\[ Q = L u. \]

예를 들어 어떤 환자가 효용가중치 \(0.8\)의 건강상태로 \(2\)년을 생존했다면 QALY는 다음과 같다.

\[ Q=2\times0.8=1.6. \]

비용효용분석의 ICER는 다음과 같이 정의된다.

\[ ICER_Q=\frac{C_1-C_0}{Q_1-Q_0}. \]

비용효용분석의 장점은 서로 다른 질병 영역과 치료기술을 공통 척도에서 비교할 수 있다는 점이다. 예를 들어 항암제, 심혈관질환 치료제, 희귀질환 치료제의 결과를 모두 QALY 증가당 비용으로 비교할 수 있다.

2.3.3 경제성 평가의 비교 원리

비용효과분석과 비용효용분석의 핵심은 한 치료전략의 비용이나 효과를 단독으로 평가하는 것이 아니라, 현실적으로 대체 가능한 전략과의 증분 비교를 수행하는 데 있다. 어떤 전략의 평균 비용이 낮다는 사실만으로는 경제성이 있다고 말할 수 없으며, 효과의 차이를 함께 고려해야 한다.

치료전략 \(j\)의 비용과 효과를 확률변수 \((C_j,H_j)\)로 나타내면 경제성 평가의 기본 대상은 다음의 결합된 증분결과이다.

\[ (\Delta C,\Delta H) =(C_1-C_0,\ H_1-H_0). \]

비용과 효과는 독립적이지 않을 수 있다. 예를 들어 생존기간이 긴 환자는 약제비와 추적관리 비용이 더 많이 발생하는 동시에 QALY도 더 크게 얻을 수 있다. 따라서 불확실성 분석에서는 두 결과의 공분산을 함께 고려해야 한다.

\[ \operatorname{Cov}(\Delta C,\Delta H)\neq0. \]

이 공분산은 비용효과평면의 점 구름 방향, 증분순편익의 분산, 신뢰구간과 비용효과수용곡선에 영향을 준다.

2.3.4 평균 결과에 근거한 평가

경제성 평가는 일반적으로 환자별 ICER를 계산한 뒤 평균하지 않는다. 각 전략에서 기대비용과 기대효과를 먼저 구하고, 그 차이를 계산한다.

\[ \Delta C =\mathbb{E}(C_1)-\mathbb{E}(C_0), \]

\[ \Delta H =\mathbb{E}(H_1)-\mathbb{E}(H_0). \]

이 원칙은 비용과 효과가 비선형적이거나 환자 간 이질성이 큰 경우 특히 중요하다. 집단 수준의 총자원과 총건강결과를 비교하려는 목적과도 일치한다.

구분 비용효과분석 비용효용분석
효과 단위 자연 단위 QALY
예 원/생존연수, 원/재발 방지 원/QALY
장점 임상적으로 직관적 질병 간 비교 가능

의약품 급여 의사결정에서는 비용효용분석이 특히 중요하다. QALY는 다양한 질병과 치료기술을 하나의 공통 결과지표로 비교할 수 있게 해 주기 때문이다.

2.4 ICER

ICER는 incremental cost-effectiveness ratio의 약자로, 증분비용효과비라고 번역한다. ICER는 신약이 기존 치료에 비해 추가로 필요한 비용을 추가 효과로 나눈 값이다.

기존 치료를 \(0\), 신약을 \(1\)이라고 하자. 각 치료전략의 기대비용을 \(C_0\), \(C_1\), 기대효과를 \(H_0\), \(H_1\)이라고 하면 증분비용과 증분효과는 다음과 같다.

\[ \Delta C = C_1-C_0, \]

\[ \Delta H = H_1-H_0. \]

ICER는 다음과 같이 정의된다.

\[ ICER = \frac{\Delta C}{\Delta H} = \frac{C_1-C_0}{H_1-H_0}, \qquad \Delta H\neq 0. \]

비용효용분석에서는 \(H_j=Q_j\)이므로 다음과 같이 쓴다.

\[ ICER_Q=\frac{\Delta C}{\Delta Q}. \]

ICER는 “효과 1단위를 추가로 얻기 위해 필요한 추가 비용”을 의미한다. 비용효용분석에서는 보통 QALY 1단위 증가당 추가 비용으로 해석한다.

예제: ICER 계산

기존 치료와 신약의 기대비용과 기대 QALY가 다음과 같다고 하자.

치료전략 기대비용 기대 QALY
기존 치료 20,000,000원 2.40
신약 32,000,000원 2.90

증분비용은 다음과 같다.

\[ \Delta C = 32{,}000{,}000-20{,}000{,}000=12{,}000{,}000. \]

증분효과는 다음과 같다.

\[ \Delta Q = 2.90-2.40=0.50. \]

따라서 ICER는 다음과 같다.

\[ ICER = \frac{12{,}000{,}000}{0.50} =24{,}000{,}000\ \text{원/QALY}. \]

이 값은 신약을 사용할 경우 QALY 1단위를 추가로 얻기 위해 평균적으로 2,400만 원의 추가 비용이 필요하다는 의미이다.

음수 양수 북서 사분면 덜 효과적이고 더 비쌈. 신약이 열등함
음수 음수 남서 사분면 덜 효과적이고 더 저렴함. 절감 비용과 손실 효과 비교 필요

신약이 더 효과적이고 더 저렴한 경우는 우월전략이라고 하며, 신약이 덜 효과적이고 더 비싼 경우는 열등전략이라고 한다. 이 경우에는 ICER를 계산하더라도 의사결정에 큰 의미가 없다.

WarningICER의 주의점

ICER는 비율이므로 증분효과가 0에 가까울 때 매우 불안정해진다. 또한 \(\Delta C\)와 \(\Delta H\)의 부호에 따라 같은 숫자라도 해석이 완전히 달라질 수 있다. 따라서 ICER는 반드시 비용효과평면과 함께 해석하는 것이 좋다.

2.4.2 강한 열등성과 확장 열등성

비교 대안이 세 개 이상이면 단순히 각 대안의 ICER를 계산하는 것만으로 충분하지 않다. 먼저 비용과 효과를 기준으로 열등전략을 제거해야 한다.

치료전략 \(a\)와 \(b\)에 대해 다음이 성립하면 \(a\)는 \(b\)에 의해 강하게 열등하다.

\[ C_a \geq C_b, \qquad H_a \leq H_b, \]

그리고 두 부등식 중 적어도 하나가 엄격한 부등식이면 \(a\)는 더 비싸면서 덜 효과적인 전략이다.

확장 열등성은 어떤 전략의 ICER가 더 효과적인 전략 조합의 ICER보다 큰 경우를 말한다. 즉, 한 전략이 강하게 열등하지는 않더라도 효율적 경계선 위에 있지 않으면 의사결정 후보에서 제외될 수 있다. 다중 대안 비교에서 ICER는 효과가 낮은 전략에서 높은 전략으로 정렬한 뒤, 열등전략과 확장 열등전략을 제거한 후 계산해야 한다.

2.4.3 ICER의 기하학적 해석

비용효과평면에서 기존 치료를 원점으로 두면 신약은 \((\Delta H,\Delta C)\)라는 한 점으로 표현된다. 이때 ICER는 원점과 해당 점을 연결한 직선의 기울기이다.

\[ ICER=\frac{\Delta C}{\Delta H}. \]

따라서 ICER는 비용과 효과의 절대적 크기를 각각 보여주는 값이 아니라 두 변화량의 상대적 기울기이다. 서로 매우 다른 증분비용과 증분효과의 조합도 같은 ICER를 가질 수 있다. 예를 들어 다음 두 경우의 ICER는 동일하다.

\[ \frac{1{,}000{,}000}{0.05} = \frac{20{,}000{,}000}{1.0} =20{,}000{,}000\ \text{원/QALY}. \]

하지만 두 경우는 예산영향, 임상적 중요성, 불확실성 측면에서 동일하지 않다. 따라서 ICER 외에 증분비용과 증분효과 자체를 함께 제시해야 한다.

2.4.4 ICER의 통계적 불안정성

ICER 추정량을 다음과 같이 쓰자.

\[ \widehat{ICER} =\frac{\widehat{\Delta C}}{\widehat{\Delta H}}. \]

분모인 \(\widehat{\Delta H}\)가 0에 가까우면 작은 표본 변동도 비율을 크게 변화시킨다. 또한 증분효과의 신뢰구간이 0을 포함하면 ICER의 분포는 매우 비대칭적이거나 두 구간으로 분리될 수 있다. 이런 상황에서 평균과 표준오차에 기반한 대칭적 신뢰구간은 적절하지 않을 수 있다.

델타방법을 적용하면 대략적인 분산은 다음과 같다.

\[ \operatorname{Var}(\widehat{ICER}) \approx \frac{V_C}{\Delta H^2} + \frac{\Delta C^2V_H}{\Delta H^4} - 2\frac{\Delta C V_{CH}}{\Delta H^3}, \]

여기서 \(V_C=\operatorname{Var}(\widehat{\Delta C})\), \(V_H=\operatorname{Var}(\widehat{\Delta H})\), \(V_{CH}=\operatorname{Cov}(\widehat{\Delta C},\widehat{\Delta H})\)이다. 이 근사는 \(\Delta H\)가 0에서 충분히 멀고 표본이 큰 경우에만 안정적이다. 실제 경제성 평가에서는 부트스트랩 비용효과평면이나 순편익 접근법이 더 자주 사용된다.

2.4.5 효율적 경계선과 확장 열등성의 수식적 의미

효과가 증가하는 순서로 전략을 정렬하여 \(H_1<H_2<\cdots<H_J\)라고 하자. 인접한 전략의 ICER는 다음과 같다.

\[ ICER_{j,j+1} =\frac{C_{j+1}-C_j}{H_{j+1}-H_j}. \]

효율적 경계선 위의 전략에서는 효과가 증가할수록 인접 ICER가 감소하지 않아야 한다.

\[ ICER_{1,2} \leq ICER_{2,3} \leq \cdots \leq ICER_{J-1,J}. \]

어떤 중간 전략 때문에 이 순서가 깨지면 그 전략은 다른 두 전략의 혼합보다 비효율적이며 확장 열등으로 판단한다. 확장 열등전략을 제거한 뒤 인접 ICER를 다시 계산해야 한다.

2.5 경제성평가에서 사용되는 결과지표

경제성 평가에서 사용하는 결과지표는 분석의 목적과 질병 특성에 따라 달라진다. 일반적으로 결과지표는 다음 세 범주로 나눌 수 있다.

  1. 임상적 결과지표
  2. 생존 관련 결과지표
  3. 효용 기반 결과지표

2.5.1 임상적 결과지표

임상적 결과지표는 특정 임상 사건이나 생물학적 변화를 측정한다. 예를 들어 혈압 감소, HbA1c 감소, LDL 콜레스테롤 감소, 종양 반응률, 재발 방지 건수, 입원 예방 건수, 이상반응 감소 건수 등이 있다.

이러한 지표는 임상적으로 직관적이지만, 서로 다른 질병 영역 사이에서 비교하기 어렵다. 예를 들어 “입원 1건 예방”과 “무진행 생존기간 1개월 증가”를 동일한 의사결정 척도에서 비교하기는 어렵다.

2.5.2 생존 관련 결과지표

생존 관련 결과지표는 특히 항암제 경제성 평가에서 중요하다. 대표적으로 전체생존기간, 무진행생존기간, 사건 없는 생존기간, 생존연수, 생애기간 생존연수가 있다.

생존함수를 \(S(t)=P(T>t)\)라고 하면 평균 생존시간은 다음과 같다.

\[ \mathbb{E}(T)=\int_0^{\infty} S(t)\,dt. \]

분석 기간을 \(\tau\)로 제한하면 restricted mean survival time은 다음과 같이 정의된다.

\[ RMST(\tau)=\int_0^{\tau}S(t)\,dt. \]

두 치료전략의 제한평균 생존시간 차이는 다음과 같다.

\[ \Delta RMST(\tau) =\int_0^{\tau}\{S_1(t)-S_0(t)\}\,dt. \]

이 값은 생존곡선의 차이를 시간 전체에 걸쳐 누적한 값이므로, 특정 시점의 생존율 차이나 위험비와는 다른 정보를 제공한다.

위험비는 순간적인 위험률의 상대적 크기를 요약하지만, 경제성 평가에서 필요한 생존연수는 생존곡선 아래 면적에 의해 결정된다. 비례위험 가정이 성립하지 않거나 생존곡선이 교차하는 경우 하나의 위험비만으로 장기 생존이득을 충분히 설명하기 어렵다.

두 전략의 위험비가 동일하더라도 기저 위험과 추적기간이 다르면 절대 생존이득은 달라질 수 있다. 경제성 평가에서는 상대효과뿐 아니라 다음과 같은 절대적 시간 척도가 중요하다.

\[ \Delta RMST(\tau) =\int_0^\tau S_1(t)\,dt - \int_0^\tau S_0(t)\,dt. \]

이 값은 분석 기간 \(\tau\) 동안 신약이 평균적으로 제공하는 추가 생존시간으로 직접 해석할 수 있다.

2.5.3 대리지표와 최종 건강결과

임상시험에서는 종양반응률, 무진행생존기간, 검사수치와 같은 대리지표가 측정되는 경우가 많다. 그러나 경제성 평가의 최종 결과는 대개 생존연수 또는 QALY이다. 따라서 대리지표를 최종 결과로 연결하는 추가 모형이 필요할 수 있다.

대리지표를 \(Z\), 최종 건강결과를 \(H\)라고 하면 다음과 같은 예측관계를 사용할 수 있다.

\[ \mathbb{E}(H\mid Z,X)=g(Z,X;\beta). \]

하지만 \(Z\)가 치료효과를 완전히 대리하지 못하면, 대리지표에 대한 효과를 최종 건강결과로 전환하는 과정에서 구조적 불확실성이 발생한다. 통계적으로 강한 연관성이 있다는 사실만으로 대리지표가 인과적으로 유효하다고 단정할 수는 없다.

2.5.4 효용 기반 결과지표

효용 기반 결과지표의 대표적인 예는 QALY이다. QALY는 생존기간과 건강관련 삶의 질을 통합한다. 시간 \(t\)에서의 효용가중치를 \(u(t)\), 생존시간을 \(T\)라고 하면 분석 기간 \(\tau\)까지의 QALY는 다음과 같이 표현할 수 있다.

\[ Q(\tau)=\int_0^{\tau}u(t)I(T>t)\,dt, \]

여기서 \(I(T>t)\)는 시간 \(t\)에 생존해 있으면 1, 아니면 0인 지시함수이다. 기대 QALY는 다음과 같다.

\[ \mathbb{E}\{Q(\tau)\} =\int_0^{\tau}\mathbb{E}\{u(t)I(T>t)\}\,dt. \]

효용가중치가 생존 여부와 독립적으로 외부에서 정해진 함수라면 단순히 다음과 같이 쓸 수 있다.

\[ \mathbb{E}\{Q(\tau)\} =\int_0^{\tau}u(t)S(t)\,dt. \]

다만 실제 분석에서는 건강상태, 이상반응, 치료 중단, 진행 여부에 따라 효용이 달라지므로 상태 기반 계산이 더 일반적이다.

효용가중치는 보통 완전한 건강을 1, 사망을 0으로 두는 척도에서 정의한다. 일부 건강상태는 사망보다 선호되지 않을 수 있으므로 음의 효용값도 가능하다. 따라서 효용가중치는 단순한 만족도 점수가 아니라 불확실한 건강상태에 대한 선호를 반영하는 가치척도이다.

2.5.5 QALY가 사용하는 주요 가정

QALY는 서로 다른 시점의 건강상태를 하나의 면적으로 합산한다. 이 계산에는 몇 가지 이론적 가정이 포함된다.

첫째, 동일한 건강상태에서 생존기간이 두 배가 되면 QALY도 두 배가 된다는 기간에 대한 선형성을 가정한다.

\[ Q(L,u)=Lu. \]

둘째, 한 시점의 효용이 다른 시점의 효용과 독립적으로 합산될 수 있다는 가법성을 가정한다.

\[ Q =\sum_{k=1}^{K}u_k\Delta_k. \]

셋째, 건강상태의 가치가 언제 경험되는지에 따라 달라지는 시간선호는 별도의 할인으로 처리한다. 이러한 가정이 현실의 선호와 완전히 일치하는 것은 아니지만, 서로 다른 질병과 치료를 공통 척도에서 비교할 수 있게 한다.

QALY는 개인의 모든 복지나 사회적 가치를 포괄하는 지표는 아니다. 치료의 희귀성, 중증도, 건강불평등, 보호자 부담, 생산성, 혁신 가치와 같은 요소는 QALY만으로 충분히 반영되지 않을 수 있다.

Note결과지표 선택의 원칙

경제성 평가의 결과지표는 의사결정자가 비교하고자 하는 가치의 단위와 일치해야 한다. 질병 간 자원배분 의사결정에서는 QALY와 같은 공통 지표가 유용하다.

2.6 QALY의 추정

QALY는 quality-adjusted life year의 약자로, 질보정생존연수라고 번역한다. QALY는 생존기간과 삶의 질을 하나의 지표로 결합한다. 이 절에서는 QALY를 추정하는 세 가지 기본 방식을 정리한다.

2.6.1 구간별 효용가중치 기반 계산

실제 환자의 건강상태는 시간에 따라 변한다. 따라서 효용도 시간에 따라 변할 수 있다. 시간을 \(K\)개의 구간으로 나누고, \(k\)번째 구간의 효용가중치를 \(u_k\), 구간 길이를 \(\Delta_k\)라고 하면 QALY는 다음과 같이 근사할 수 있다.

\[ Q \approx \sum_{k=1}^{K}u_k\Delta_k. \]

할인을 적용하면 다음과 같다.

\[ Q^{disc} \approx \sum_{k=1}^{K}\frac{u_k\Delta_k}{(1+r_Q)^{t_k}}, \]

여기서 \(r_Q\)는 효과 할인율이고, \(t_k\)는 해당 구간의 대표 시점이다.

위 그림에서 가로축의 시간과 세로축의 효용가중치가 만드는 면적이 QALY이다. 효용이 동일하더라도 지속기간이 길면 면적이 커지고, 생존기간이 동일하더라도 건강상태의 효용이 낮으면 면적이 작아진다. 따라서 QALY는 생존과 삶의 질을 곱한 단순값이라기보다 시간에 따라 변화하는 효용의 누적 면적으로 이해하는 것이 정확하다.

2.6.2 상태 기반 QALY 추정

마코프모델에서는 각 건강상태에 효용가중치를 부여하고, 각 주기마다 환자가 특정 상태에 머무는 비율을 이용하여 QALY를 계산한다. 건강상태를 \(s=1,\ldots,S\), 주기를 \(k=1,\ldots,K\)라고 하자. 치료전략 \(j\)에서 주기 \(k\)에 건강상태 \(s\)에 있는 비율을 \(p_{jsk}\), 해당 상태의 효용을 \(u_s\), 주기 길이를 \(\Delta_k\)라고 하면 QALY는 다음과 같다.

\[ Q_j = \sum_{k=1}^{K}\sum_{s=1}^{S} \frac{p_{jsk}u_s\Delta_k}{(1+r_Q)^{t_k}}. \]

이상반응이 특정 주기에 추가적인 효용 감소를 유발한다면, 이상반응 효용 감소량을 \(d_a\), 이상반응 발생확률을 \(p_{jak}\)라고 두고 다음처럼 반영할 수 있다.

\[ Q_j = \sum_{k=1}^{K}\sum_{s=1}^{S} \frac{p_{jsk}u_s\Delta_k}{(1+r_Q)^{t_k}} - \sum_{k=1}^{K}\sum_{a=1}^{A} \frac{p_{jak}d_a}{(1+r_Q)^{t_k}}. \]

첫 번째 항은 건강상태에서 얻는 QALY이고, 두 번째 항은 이상반응으로 인한 QALY 손실이다.

2.6.3 생존곡선 기반 QALY 추정

항암제 경제성 평가에서는 생존곡선을 이용하여 QALY를 추정하는 경우가 많다. 무진행 상태의 효용을 \(u_{PF}\), 진행 상태의 효용을 \(u_{PD}\)라고 하자. 무진행생존함수를 \(S_{PFS}(t)\), 전체생존함수를 \(S_{OS}(t)\)라고 하면 시점 \(t\)에서 각 상태의 비율은 다음과 같이 표현할 수 있다.

\[ P(PF\ \text{at}\ t)=S_{PFS}(t), \]

\[ P(PD\ \text{at}\ t)=S_{OS}(t)-S_{PFS}(t), \]

\[ P(Death\ \text{at}\ t)=1-S_{OS}(t). \]

따라서 분석 기간 \(\tau\)까지의 QALY는 다음과 같이 계산할 수 있다.

\[ Q =\int_0^{\tau} \left[ u_{PF}S_{PFS}(t) +u_{PD}\{S_{OS}(t)-S_{PFS}(t)\} \right](1+r_Q)^{-t}\,dt. \]

이 수식은 분할생존모델에서 QALY를 계산하는 기본 구조이다. 단, 항상 \(S_{OS}(t)\geq S_{PFS}(t)\)가 성립해야 하며, 외삽 과정에서 두 곡선이 교차하지 않도록 확인해야 한다.

2.6.4 효용곡선 면적의 수치적 근사

실제 자료에서는 효용이 연속적으로 관찰되지 않고 방문 시점에서만 측정되는 경우가 많다. 방문 시점 \(t_0<t_1<\cdots<t_K\)에서 효용값 \(u_0,u_1,\ldots,u_K\)가 관찰되었다면 사다리꼴 공식을 이용하여 QALY를 근사할 수 있다.

\[ Q \approx \sum_{k=1}^{K} \frac{u_{k-1}+u_k}{2} (t_k-t_{k-1}). \]

이 계산은 두 측정시점 사이에서 효용이 선형적으로 변화한다고 가정한다. 측정 간격이 길거나 임상상태가 급격히 변하는 경우 이 가정에 따른 오차가 커질 수 있다.

2.6.5 이상반응 효용 감소의 단위

이상반응에 따른 효용 감소는 강도와 지속기간을 함께 고려해야 한다. 효용이 \(d_a\)만큼 감소하고 평균 지속기간이 \(L_a\)년이라면 1건의 이상반응에 따른 QALY 손실은 다음과 같다.

\[ D_a=d_aL_a. \]

발생확률이 \(p_a\)이면 기대 QALY 손실은 \(p_aD_a\)이다. 문헌에서 제시된 값이 순간적인 효용 감소인지, 이미 지속기간이 반영된 QALY 감소인지 구분하지 않으면 동일한 지속기간을 두 번 곱하는 오류가 발생할 수 있다.

여러 건강상태와 이상반응이 동시에 존재할 때 효용을 단순히 모두 더하거나 빼면 1보다 크거나 지나치게 낮은 값이 될 수 있다. 이 경우 가법모형, 최소값 모형, 곱셈모형 등 결합 규칙을 사전에 정의하고 민감도 분석을 수행하는 것이 필요하다.

2.7 비용

경제성 평가에서 비용은 어떤 관점에서 분석하느냐에 따라 포함 범위가 달라진다. 비용은 단순히 약제비만을 의미하지 않는다. 치료와 관련된 의료자원 사용, 이상반응 관리, 입원, 외래 방문, 검사, 수술, 장기요양, 환자 및 보호자의 시간 비용 등이 포함될 수 있다.

2.7.1 분석 관점

비용의 범위는 분석 관점에 따라 달라진다.

분석 관점 포함될 수 있는 비용
보건의료체계 관점 약제비, 진료비, 입원비, 검사비, 시술비
보험자 관점 급여자가 실제 부담하는 비용
사회적 관점 의료비, 교통비, 간병비, 생산성 손실 등
환자 관점 본인부담금, 교통비, 시간 비용 등

의사결정기관이 어떤 관점을 요구하는지에 따라 비용 항목을 선택해야 한다. 동일한 임상효과를 가진 치료라도 분석 관점에 따라 비용효과성이 달라질 수 있다.

2.7.2 비용의 구성

치료전략 \(j\)의 총 비용은 다음과 같이 구성할 수 있다.

\[ C_j = C_{drug,j}+C_{admin,j}+C_{monitor,j}+C_{AE,j} +C_{disease,j}+C_{terminal,j}. \]

각 항은 다음을 의미한다.

기호 의미
\(C_{drug,j}\) 약제비
\(C_{admin,j}\) 투약 및 처치 비용
\(C_{monitor,j}\) 모니터링 및 검사 비용
\(C_{AE,j}\) 이상반응 관리 비용
\(C_{disease,j}\) 질병 상태 관련 비용
\(C_{terminal,j}\) 말기 또는 사망 전 비용

자원 사용량과 단가를 분리하면 비용은 다음과 같이 표현할 수 있다.

\[ C_j=\sum_{m=1}^{M}R_{jm}a_m, \]

여기서 \(R_{jm}\)은 치료전략 \(j\)에서 자원 항목 \(m\)의 사용량이고, \(a_m\)은 해당 자원 항목의 단가이다. 이 표현은 비용 산출의 투명성을 높인다. 비용 차이가 자원 사용량의 차이에서 비롯되는지, 단가의 차이에서 비롯되는지를 분리해 볼 수 있기 때문이다.

2.7.3 비용 산정의 세 단계

비용 추정은 일반적으로 자원 항목의 식별, 사용량 측정, 단가 적용의 세 단계로 나눌 수 있다.

  1. 식별: 분석 관점과 관련된 자원 항목을 결정한다.
  2. 측정: 각 자원이 얼마나 사용되었는지 계산한다.
  3. 가치평가: 각 사용량에 적절한 단가를 적용한다.

환자 \(i\)의 비용을 자원 사용량 \(R_{im}\)과 단가 \(a_m\)의 곱으로 표현하면 다음과 같다.

\[ C_i=\sum_{m=1}^{M}R_{im}a_m. \]

집단의 평균 비용은 다음과 같다.

\[ \bar C=\frac{1}{N}\sum_{i=1}^{N}C_i. \]

미시비용산정은 자원 항목을 세부적으로 식별하여 사용량과 단가를 각각 측정하는 방식이다. 총액비용산정은 진료비 총액이나 포괄수가와 같은 집계된 비용을 사용한다. 미시비용산정은 투명성이 높지만 자료수집 부담이 크고, 총액비용산정은 실무적으로 간단하지만 비용 발생의 세부 원인을 분리하기 어렵다.

2.7.4 비용의 기준연도와 가격 조정

서로 다른 연도에 측정된 비용을 함께 사용할 때는 동일한 가격연도로 환산해야 한다. 기준연도의 물가지수를 \(I_{t^*}\), 원자료 연도의 물가지수를 \(I_t\)라고 하면 조정 비용은 다음과 같다.

\[ C_{t^*}=C_t\frac{I_{t^*}}{I_t}. \]

외국 통화 자료를 사용하는 경우에는 물가조정과 환율변환의 순서와 기준시점을 명확히 해야 한다. 시장환율은 구매력 차이를 완전히 반영하지 않을 수 있으므로 자료의 성격과 분석 목적에 따라 적절한 변환 방법을 선택한다.

2.7.5 시간에 따른 비용과 할인

비용은 시간에 따라 발생한다. 시점 \(t\)에서 치료전략 \(j\)의 비용 발생률을 \(c_j(t)\)라고 하면 분석 기간 \(\tau\) 동안의 할인 비용은 다음과 같다.

\[ C_j(\tau;r_C) =\int_0^{\tau}c_j(t)(1+r_C)^{-t}\,dt. \]

이산 시간 모형에서는 다음과 같이 표현할 수 있다.

\[ C_j =\sum_{k=1}^{K}\frac{c_{jk}}{(1+r_C)^{t_k}}, \]

여기서 \(c_{jk}\)는 \(k\)번째 주기에 발생한 비용이다.

Warning비용 추정의 주의점

비용자료는 대개 오른쪽으로 긴 꼬리를 가지며 일부 환자에게 매우 큰 비용이 발생한다. 따라서 비용 분석에서는 평균, 분산, 이상치, 분포 가정, 불확실성 처리가 중요하다.

위 그림에서 대부분의 환자는 비교적 낮거나 중간 수준의 비용을 보이지만 일부 환자에게 매우 큰 비용이 발생한다. 이 소수의 고비용 환자가 전체 평균과 예산에 큰 영향을 주기 때문에, 이상치를 단순히 제거하기보다는 발생 원인을 확인하고 분석 관점에 맞게 포함하는 것이 원칙이다.

2.7.6 평균 비용이 중요한 이유

경제성 평가에서는 보통 중앙값이 아니라 평균 비용을 사용한다. 의사결정자는 전체 대상 인구집단에서 발생하는 총비용을 고려하기 때문이다. 환자 수가 \(N\)명이고 1인당 기대비용이 \(\mu_C\)라면 총 기대비용은 다음과 같다.

\[ \mathbb{E}(\text{Total cost})=N\mu_C. \]

비용분포가 오른쪽으로 치우쳐 있으면 중앙값은 전형적인 환자의 비용을 잘 설명할 수 있지만, 총예산 영향을 설명하는 데는 평균이 더 직접적이다. 따라서 비용자료 분석에서는 평균 비용의 추정과 불확실성 평가가 핵심이다.

2.7.7 비용자료의 통계적 특성

비용자료는 0의 값이 많거나, 오른쪽 꼬리가 길거나, 추적 중 사망과 중도절단의 영향을 받는 경우가 많다. 이러한 특성 때문에 정규분포를 가정한 단순 분석이 항상 적절한 것은 아니다. 그러나 평균 비용은 중심극한정리에 의해 표본이 충분히 크면 근사적으로 정규분포를 따를 수 있으며, 비모수 부트스트랩을 이용하여 평균 비용 차이의 불확실성을 평가할 수도 있다.

비용과 생존기간 사이에는 구조적인 관계가 존재한다. 오래 생존한 환자는 치료와 추적관리를 더 오래 받기 때문에 비용이 커질 수 있다. 따라서 추적기간이 환자마다 다르거나 중도절단이 존재하면 단순히 관찰된 비용을 평균하는 방식은 편향될 수 있다.

환자 \(i\)의 관찰시간을 \(Y_i=\min(T_i,U_i)\)라고 하자. 여기서 \(T_i\)는 실제 추적 종료시간, \(U_i\)는 중도절단시간이다. \(T_i>U_i\)이면 이후 비용이 관찰되지 않는다. 이때 생존분석과 유사하게 역확률 중도절단 가중치 또는 구간별 비용 추정을 사용하여 누락된 장기 비용을 보정할 수 있다.

경제성 평가에서 비용의 평균과 효과의 평균은 별도로 추정되지만, 같은 환자에서 측정되므로 두 결과의 상관성을 유지한 분석이 필요하다. 환자 단위 부트스트랩에서는 비용과 효과의 쌍을 함께 재표본추출해야 한다.

2.8 비용효과평면

비용효과평면은 증분효과를 가로축, 증분비용을 세로축에 나타낸 그림이다. 이 평면은 ICER의 해석을 시각적으로 이해하는 데 매우 유용하다.

가로축은 다음을 나타낸다.

\[ \Delta H=H_1-H_0. \]

세로축은 다음을 나타낸다.

\[ \Delta C=C_1-C_0. \]

비용효과평면은 네 개의 사분면으로 나뉜다.

비용효과평면의 각 점은 하나의 증분비용과 증분효과 조합을 나타낸다. 점추정치만 표시할 수도 있지만, 부트스트랩이나 확률론적 민감도 분석에서 얻은 다수의 모의값을 표시하면 결합 불확실성을 확인할 수 있다.

모의 반복 \(m\)에서의 결과를 \((\Delta H^{(m)},\Delta C^{(m)})\)라고 하면, 사분면별 점의 비율은 다음과 같이 추정할 수 있다.

\[ \widehat P_{NE} =\frac{1}{M}\sum_{m=1}^{M} I\{\Delta H^{(m)}>0,\Delta C^{(m)}>0\}, \]

\[ \widehat P_{SE} =\frac{1}{M}\sum_{m=1}^{M} I\{\Delta H^{(m)}>0,\Delta C^{(m)}<0\}. \]

나머지 사분면도 같은 방식으로 계산할 수 있다. 이 비율은 신약이 우월하거나 열등할 가능성을 시각적 결과와 함께 정량적으로 설명한다.

사분면 \(\Delta H\) \(\Delta C\) 해석
북동 양수 양수 더 효과적이고 더 비쌈
남동 양수 음수 더 효과적이고 더 저렴함
북서 음수 양수 덜 효과적이고 더 비쌈
남서 음수 음수 덜 효과적이고 더 저렴함

북동 사분면에서는 신약이 더 효과적이지만 더 비싸기 때문에, 추가 효과가 추가 비용을 정당화할 수 있는지 판단해야 한다. 남동 사분면에서는 신약이 더 효과적이고 더 저렴하므로 일반적으로 신약이 우월하다. 북서 사분면에서는 신약이 덜 효과적이고 더 비싸므로 일반적으로 열등하다. 남서 사분면에서는 비용은 절감되지만 효과가 감소하므로 절감 비용이 효과 손실을 정당화할 수 있는지 판단해야 한다.

2.8.1 지불의사금액과 의사결정 경계선

지불의사금액을 \(\lambda\)라고 하자. \(\lambda\)는 효과 1단위, 보통 QALY 1단위에 대해 사회 또는 의사결정자가 지불할 의사가 있는 최대 금액이다.

신약이 비용효과적이기 위한 조건은 다음과 같다.

\[ \Delta C < \lambda \Delta H. \]

비용효과평면에서 \(\Delta C=\lambda\Delta H\)는 원점을 지나는 직선이다. 이 직선 아래에 있는 점은 순편익 기준에서 비용효과적인 것으로 해석할 수 있다.

기준선의 기울기는 \(\lambda\)이다. 지불의사금액이 커질수록 직선은 더 가파르게 회전하며, 추가 효과에 더 높은 금전적 가치를 부여하게 된다. 비용효과적 영역은 다음 부등식으로 정의된다.

\[ \lambda\Delta H-\Delta C>0. \]

이 조건은 모든 사분면에 일관되게 적용된다. 예를 들어 남서 사분면에서는 \(\Delta H<0\)이고 \(\Delta C<0\)이므로, 절감되는 비용이 손실되는 건강효과의 가치보다 큰지를 판단한다. 따라서 단순히 음의 ICER라는 이유만으로 비용효과적이거나 비용효과적이지 않다고 결론 내릴 수 없다.

점 구름이 여러 사분면에 걸쳐 있으면 ICER의 평균이나 신뢰구간보다 기준선 아래에 위치한 비율을 보는 것이 해석에 유리하다. 이 비율이 바로 특정 \(\lambda\)에서 비용효과적일 확률과 연결된다.

위 그림에서 한 점의 가로좌표는 증분효과, 세로좌표는 증분비용이다. 원점에서 점까지의 기울기는 ICER이며, 지불의사금액 기준선 아래에 있는 점은 \(\lambda\Delta H-\Delta C>0\)을 만족한다. 모의점이 기준선의 양쪽에 분포하면 비용효과성에 의사결정 불확실성이 존재한다.

Tip비용효과평면의 장점

ICER 하나만 제시하면 불확실성과 사분면의 의미를 충분히 전달하기 어렵다. 비용효과평면은 증분비용과 증분효과의 결합분포를 시각적으로 보여주기 때문에 확률론적 민감도 분석 결과를 해석하는 데 유용하다.

2.9 화폐단위로 정의된 순편익의 증분

ICER는 경제성 평가에서 널리 사용되지만 몇 가지 한계가 있다. 특히 증분효과가 0에 가까울 때 불안정하고, 사분면에 따라 해석이 복잡하다. 이를 보완하기 위해 순편익 접근법이 자주 사용된다.

지불의사금액을 \(\lambda\)라고 할 때 치료전략 \(j\)의 순편익은 다음과 같이 정의된다.

\[ NB_j(\lambda)=\lambda H_j-C_j. \]

여기서 \(H_j\)는 효과, \(C_j\)는 비용이다. 순편익은 효과를 화폐단위로 변환한 후 비용을 뺀 값이다. 신약 \(1\)과 기존 치료 \(0\)의 증분순편익은 다음과 같다.

\[ INB(\lambda)=NB_1(\lambda)-NB_0(\lambda). \]

이를 전개하면 다음과 같다.

\[ INB(\lambda) =\lambda(H_1-H_0)-(C_1-C_0) =\lambda\Delta H-\Delta C. \]

신약이 비용효과적이기 위한 조건은 다음과 같다.

\[ INB(\lambda)>0. \]

2.9.1 ICER와 INB의 관계

\(\Delta H>0\)일 때 ICER 기준은 다음과 같다.

\[ ICER < \lambda. \]

이는 다음과 동치이다.

\[ \frac{\Delta C}{\Delta H}<\lambda \quad\Longleftrightarrow\quad \Delta C<\lambda\Delta H \quad\Longleftrightarrow\quad INB(\lambda)>0. \]

따라서 \(\Delta H>0\)인 경우 ICER 기준과 INB 기준은 동일한 의사결정을 제공한다. 하지만 INB는 \(\Delta H\)가 0에 가까울 때도 안정적이고, 회귀분석이나 확률론적 분석에 적용하기 쉽다는 장점이 있다.

예제: INB 계산

앞서 신약의 증분비용이 1,200만 원, 증분효과가 0.5 QALY라고 하자. 지불의사금액이 QALY당 3,000만 원이라면 INB는 다음과 같다.

\[ INB=30{,}000{,}000\times0.5-12{,}000{,}000 =3{,}000{,}000. \]

INB가 양수이므로 이 기준에서 신약은 비용효과적인 것으로 해석된다.

위 그림에서 직선의 절편은 \(-\Delta C\)이고 기울기는 \(\Delta H\)이다. 증분효과가 양수이면 지불의사금액이 증가할수록 증분순편익이 증가한다. 직선이 0을 통과하는 지불의사금액은 증분효과가 양수인 경우 ICER와 같다.

\[ \lambda^* =\frac{\Delta C}{\Delta H}. \]

2.9.2 확률론적 해석

확률론적 민감도 분석에서는 \(\Delta C\)와 \(\Delta H\)가 불확실한 값이다. 따라서 INB도 확률변수가 된다.

\[ INB^{(m)}(\lambda)=\lambda\Delta H^{(m)}-\Delta C^{(m)}, \qquad m=1,\ldots,M. \]

신약이 비용효과적일 확률은 다음과 같이 추정할 수 있다.

\[ P\{INB(\lambda)>0\} \approx \frac{1}{M}\sum_{m=1}^{M} I\{INB^{(m)}(\lambda)>0\}. \]

이 값은 비용효과수용곡선의 기본이 된다. 다만 비용효과적일 확률이 높다는 사실이 곧바로 급여 결정을 의미하지는 않는다. 의사결정은 기대순편익, 예산영향, 형평성, 질병 중증도, 대체 치료 가능성 등을 함께 고려해야 한다.

2.9.3 INB의 표준오차

임상시험 기반 경제성 평가에서 \(\widehat{\Delta H}\)와 \(\widehat{\Delta C}\)를 추정했다고 하자. 두 추정량의 분산과 공분산을 각각 \(V_H\), \(V_C\), \(V_{HC}\)라고 하면 증분순편익 추정량의 분산은 다음과 같다.

\[ \operatorname{Var}\{\widehat{INB}(\lambda)\} =\lambda^2V_H+V_C-2\lambda V_{HC}. \]

이 식은 순편익 접근법이 통계적 추론에 편리한 이유를 보여준다. 비용과 효과의 결합 불확실성이 선형결합의 분산으로 표현되기 때문이다.

증분순편익의 표준오차는 다음과 같다.

\[ SE\{\widehat{INB}(\lambda)\} = \sqrt{ \lambda^2V_H+V_C-2\lambda V_{HC} }. \]

큰 표본 근사를 사용하면 다음과 같은 신뢰구간을 구성할 수 있다.

\[ \widehat{INB}(\lambda) \pm z_{1-\alpha/2} SE\{\widehat{INB}(\lambda)\}. \]

신뢰구간 전체가 0보다 크면 해당 지불의사금액에서 증분순편익이 양수라는 통계적 근거가 강하다고 해석할 수 있다. 그러나 경제성 평가의 최종 의사결정은 가설검정의 기각 여부보다는 기대순편익의 크기와 의사결정 오류의 결과를 중심으로 이루어진다.

2.9.4 여러 전략의 기대순편익

전략이 \(J\)개인 경우 각 전략의 기대순편익을 계산하여 가장 큰 전략을 선택한다.

\[ ENB_j(\lambda) =\lambda\mathbb{E}(H_j)-\mathbb{E}(C_j), \qquad j=1,\ldots,J. \]

최적 전략은 다음과 같다.

\[ j^*(\lambda) =\arg\max_j ENB_j(\lambda). \]

이 표현은 모든 전략을 공통 척도에서 직접 비교할 수 있으며, 열등성과 확장 열등성을 순편익 관점에서도 확인할 수 있게 한다.

2.9.5 비용효과수용곡선의 해석상 주의

비용효과수용곡선은 각 지불의사금액에서 특정 전략이 가장 비용효과적일 확률을 나타낸다. 확률이 가장 높다는 것은 불확실성 하에서 그 전략이 최적일 가능성이 가장 크다는 의미이지, 기대순편익의 차이가 크다는 의미는 아니다.

두 전략의 기대순편익 차이가 매우 작으면 한 전략이 비용효과적일 확률이 50%에 가까울 수 있다. 반대로 확률이 높더라도 잘못된 선택을 했을 때의 손실이 클 수 있다. 따라서 비용효과적 확률과 기대순편익의 크기를 함께 살펴보아야 한다.

Important순편익 접근법의 장점

순편익은 ICER와 동일한 의사결정 원리를 가지면서도 통계적으로 더 다루기 쉽다. 특히 회귀분석, 불확실성 분석, 비용효과수용곡선, 정보의 가치 분석에서 유용하다.

2.10 확증적 임상시험의 통계 분석과 경제성 평가 분석의 차이점

확증적 임상시험의 통계 분석과 경제성 평가 분석은 모두 임상자료를 사용하지만 목적과 사고방식이 다르다.

확증적 임상시험의 주요 목적은 치료효과의 존재를 검증하는 것이다. 예를 들어 신약이 기존 치료보다 주요 평가변수에서 우월한지, 비열등한지, 또는 통계적으로 유의한 차이를 보이는지가 핵심 질문이다.

반면 경제성 평가는 신약을 급여하거나 사용할 가치가 있는지를 평가한다. 따라서 치료효과뿐 아니라 비용, 삶의 질, 장기 결과, 불확실성, 대체 치료전략, 의사결정 기준을 함께 고려해야 한다.

2.10.1 가설검정과 의사결정의 차이

확증적 임상시험에서는 보통 귀무가설과 대립가설을 설정한다.

\[ H_0:\Delta H=0, \qquad H_1:\Delta H\neq0. \]

우월성 시험에서는 다음과 같이 설정할 수 있다.

\[ H_0:\Delta H\leq0, \qquad H_1:\Delta H>0. \]

하지만 경제성 평가의 의사결정 문제는 다음과 같이 표현하는 것이 더 자연스럽다.

\[ \text{Choose new drug if }\quad \mathbb{E}\{NB_1(\lambda)\}>\mathbb{E}\{NB_0(\lambda)\}. \]

동일하게 증분순편익으로 표현하면 다음과 같다.

\[ \text{Choose new drug if }\quad \mathbb{E}\{INB(\lambda)\}>0. \]

이 식은 경제성 평가가 통계적 유의성보다 기대순편익의 최대화에 초점을 둔다는 점을 보여준다.

2.10.2 분석 estimand의 차이

확증적 임상시험은 대개 사전에 정의된 임상 평가변수의 치료효과를 추정한다. 반면 경제성 평가는 동일한 환자집단에서 장기간 누적되는 비용과 건강효과의 평균을 추정해야 한다. 따라서 두 분석의 estimand가 다를 수 있다.

임상시험의 대표적인 효과 estimand를 다음과 같이 쓸 수 있다.

\[ \theta_H =\mathbb{E}(H_1-H_0). \]

경제성 평가의 의사결정 estimand는 비용을 결합한 다음 값이다.

\[ \theta_{NB}(\lambda) =\mathbb{E}\{\lambda(H_1-H_0)-(C_1-C_0)\}. \]

임상적 효과가 양수이더라도 비용 증가가 더 크면 \(\theta_{NB}(\lambda)\)는 음수가 될 수 있다. 반대로 효과의 불확실성이 크더라도 기대순편익이 양수이면 현재 근거에서 신약을 선택하는 것이 기대가치를 높일 수 있다.

2.10.3 임상시험 이후의 외삽과 자료결합

임상시험은 제한된 추적기간을 갖기 때문에 경제성 평가에서는 관찰기간 이후의 생존, 치료 지속, 이상반응, 자원 사용을 외삽해야 하는 경우가 많다. 임상시험 자료를 \(D_{trial}\), 외부 자료를 \(D_{ext}\)라고 하면 장기 모형의 모수는 두 자료원을 결합하여 추정할 수 있다.

\[ p(\theta\mid D_{trial},D_{ext}) \propto p(D_{trial},D_{ext}\mid\theta)p(\theta). \]

빈도주의 접근에서도 외부 생존자료, 역학자료, 실제사용자료를 이용하여 기준 위험과 장기 전이확률을 보완할 수 있다. 이 과정에서는 자료원 간 환자구성, 치료환경, 측정정의가 다를 수 있으므로 구조적 가정이 명확해야 한다.

2.10.4 결측과 중도절단의 의미

임상시험의 임상효과 분석에서는 결측과 중도절단이 주요 문제이지만, 경제성 평가에서는 비용과 효용의 누적값도 동시에 누락될 수 있다. 특히 사망은 단순한 결측이 아니라 건강결과 과정의 일부이며, 사망 이후 효용은 0이고 일반적인 의료비는 더 이상 발생하지 않지만 사망 직전 비용이 집중될 수 있다.

따라서 임상 평가변수에 사용한 결측처리 방법을 비용과 QALY에 그대로 적용하는 것은 적절하지 않을 수 있다. 비용, 효용, 생존의 상호의존성을 고려한 공동 분석 또는 적절한 가중·다중대치 방법이 필요하다.

위 그림은 임상시험의 결과가 경제성 평가의 중요한 입력자료이지만 그 자체가 급여 결론은 아니라는 점을 보여준다. 임상시험에서 추정한 상대효과는 장기 생존, 삶의 질, 비용, 실제 진료환경의 환자구성, 의사결정 기준과 결합되어야 최종 가치평가로 이어진다.

2.10.5 통계적 유의성과 비용효과성은 다르다

어떤 신약의 치료효과가 통계적으로 유의하더라도 비용효과적이지 않을 수 있다. 반대로 임상시험에서 통계적 유의성이 충분히 확보되지 않았더라도, 현재 자료와 비용 구조를 고려할 때 기대순편익이 양수일 수 있다. 이러한 차이는 두 분석이 서로 다른 질문에 답하기 때문이다.

  • 통계적 유의성: 관찰된 치료효과가 우연으로 설명되기 어려운가?
  • 비용효과성: 치료효과와 비용을 고려할 때 이 치료를 선택하는 것이 기대가치를 높이는가?
Note핵심 메시지

임상시험 분석은 근거의 존재를 평가하고, 경제성 평가는 의사결정의 가치를 평가한다. 두 분석은 상호보완적이지만 동일하지 않다.

## 분석 대상 인구집단과 급여 대상 인구집단 {#sec-target-population-reimbursement-population}

경제성 평가에서 가장 먼저 명확히 해야 할 질문은 “누구에게 이 치료를 사용할 것인가?”이다. 의약품의 가치는 치료가 적용되는 환자집단에 따라 크게 달라진다. 동일한 신약이라도 질병의 중증도, 이전 치료 경험, 바이오마커 상태, 동반질환, 연령, 예후, 치료 순서에 따라 기대효과와 비용효과성이 달라질 수 있다.

경제성 평가에서는 적어도 세 종류의 인구집단을 구분하는 것이 좋다.

| 구분 | 의미 | 경제성 평가에서의 역할 |
|---|---|---|
| 임상시험 대상 인구집단 | 실제 임상시험에 등록된 환자집단 | 근거가 직접 관찰된 집단 |
| 분석 대상 인구집단 | 경제성 평가 모델이 직접 대상으로 삼는 집단 | 기대비용과 기대효과가 정의되는 집단 |
| 급여 대상 인구집단 | 의사결정기관이 실제 급여 적용을 검토하는 집단 | 정책 결정이 적용되는 집단 |

세 집단은 반드시 일치하지 않는다. 임상시험은 엄격한 선정기준과 제외기준을 적용하므로 실제 진료환경의 환자보다 더 균질한 집단을 포함하는 경우가 많다. 반면 급여 대상 인구집단은 실제 임상현장에서 해당 약제를 사용할 가능성이 있는 더 넓은 환자집단일 수 있다.

예를 들어 어떤 항암제가 다음과 같은 임상시험에서 효과를 보였다고 하자.

- 성인 환자
- ECOG 수행상태 0 또는 1
- 특정 유전자 변이 양성
- 이전 치료 1회 이하
- 주요 장기 기능이 충분히 보존된 환자

하지만 실제 급여 검토에서는 다음과 같은 질문이 제기될 수 있다.

- 수행상태가 2인 환자에게도 적용할 것인가?
- 이전 치료를 2회 이상 받은 환자에게도 급여할 것인가?
- 고령 환자에게도 동일한 상대효과를 기대할 수 있는가?
- 동반질환이 많은 환자에게도 이상반응 비용과 치료효과가 동일한가?
- 임상시험의 대조군이 국내 실제 진료의 대체 치료전략과 일치하는가?

따라서 경제성 평가는 임상시험 참여자에게서 관찰된 평균 치료효과를 단순히 계산하는 작업이 아니다. 실제 급여 대상 환자집단에서 기대되는 효과, 비용, 불확실성을 평가해야 한다.

### 분석 대상 인구집단 정의의 수식적 표현

치료전략을 $j \in \{0,1\}$이라고 하자. 여기서 $j=0$은 기존 치료, $j=1$은 신약 치료를 의미한다. 환자의 기저 특성 벡터를 $X$라고 하고, 분석 대상 인구집단을 $\mathcal{P}$라고 하자. 치료전략 $j$에서의 비용 확률변수를 $C_j$, 건강결과 확률변수를 $H_j$라고 하면 분석 대상 인구집단에서의 기대비용과 기대효과는 다음과 같이 정의할 수 있다.

$$
\mu_{C,j}(\mathcal{P})
= \mathbb{E}(C_j \mid X \in \mathcal{P}),
$$

$$
\mu_{H,j}(\mathcal{P})
= \mathbb{E}(H_j \mid X \in \mathcal{P}).
$$

이때 $H_j$는 분석 목적에 따라 생존연수, 재발 방지 건수, QALY 등으로 정의될 수 있다. 비용효용분석에서는 보통 $H_j=Q_j$로 두고 $Q_j$를 QALY라고 해석한다.

분석 대상 인구집단이 달라지면 기대값도 달라진다.

$$
\mathbb{E}(C_j \mid X \in \mathcal{P}_1)
\neq
\mathbb{E}(C_j \mid X \in \mathcal{P}_2)
$$

일반적으로 $\mathcal{P}_1$과 $\mathcal{P}_2$의 예후, 중증도, 이상반응 위험, 치료 중단율, 의료자원 사용 양상이 다르면 위의 부등식은 자연스럽게 발생한다. 따라서 인구집단의 정의는 단순한 서술 요소가 아니라 기대비용과 기대효과를 결정하는 수학적 조건이다.

![분석 대상 인구집단과 급여 대상 인구집단은 부분적으로만 겹칠 수 있다.](figures/ch02/fig-ch02-population-overlap.png){width="92%"}


위 그림에서 겹치는 영역은 임상근거가 급여 대상에 직접 적용될 가능성이 높은 환자군을 나타낸다. 겹치지 않는 급여 대상 영역은 임상시험에서 충분히 대표되지 않았을 수 있으므로, 실제사용자료나 외부 연구를 통한 보완이 필요하다. 반대로 임상시험에 포함되었지만 실제 급여 범위에서 제외되는 환자는 경제성 평가의 최종 평균값에 포함하지 않아야 한다.

### 표준화와 외적 타당도

임상시험 표본의 특성 분포가 급여 대상 인구집단의 특성 분포와 다르면, 임상시험에서 관찰한 평균 효과를 그대로 적용하기 어렵다. 이때 조건부 기대값을 이용하여 목표 모집단으로 표준화할 수 있다.

임상시험 자료에서 $X=x$인 환자의 치료전략 $j$에 대한 조건부 기대효과가 $m_j(x)=\mathbb{E}(H_j \mid X=x)$라고 하자. 급여 대상 인구집단의 특성 분포를 $F^*(x)$라고 하면, 목표 모집단에서의 평균 효과는 다음과 같이 표현할 수 있다.

$$
\mu_{H,j}^{*}
= \int m_j(x)\,dF^*(x).
$$

비용도 같은 방식으로 표준화할 수 있다.

$$
\mu_{C,j}^{*}
= \int \mathbb{E}(C_j \mid X=x)\,dF^*(x).
$$

이 수식은 회귀분석, MAIC, 표준화, 실제사용자료 기반 보정분석이 모두 “목표 모집단에서의 기대값”을 추정하기 위한 도구임을 보여준다.


### 치료효과 이질성과 목표 estimand

분석 대상 인구집단을 정의할 때는 단순히 포함기준을 나열하는 것만으로 충분하지 않다. 어떤 환자 특성이 치료효과, 비용 또는 삶의 질을 변화시키는지 함께 고려해야 한다. 환자의 기저 특성에 따라 치료효과가 달라지는 현상을 **치료효과 이질성** 또는 **효과수정**이라고 한다.

환자 특성이 $X=x$일 때 치료전략 1과 0의 조건부 평균 치료효과를 다음과 같이 정의하자.

$$
\tau_H(x)
=\mathbb{E}(H_1-H_0\mid X=x).
$$

목표 모집단에서의 평균 치료효과는 조건부 효과를 목표 모집단의 특성 분포에 대해 평균한 값이다.

$$
\Delta H^{*}
=\int \tau_H(x)\,dF^{*}(x).
$$

따라서 임상시험과 급여 대상 인구집단의 특성 분포가 다르더라도 모든 환자에서 치료효과가 일정하다면 일반화 문제가 크지 않을 수 있다. 반대로 치료효과가 연령, 중증도, 바이오마커 또는 이전 치료에 따라 달라진다면 두 집단의 구성 차이가 경제성 평가 결과에 직접 영향을 준다.

비용의 증분도 같은 방식으로 정의할 수 있다.

$$
\Delta C^{*}
=\int
\left[
\mathbb{E}(C_1\mid X=x)-\mathbb{E}(C_0\mid X=x)
\right]dF^{*}(x).
$$

이때 목표 모집단의 ICER는 환자별 ICER의 평균이 아니라, 목표 모집단에서 먼저 평균한 증분비용과 증분효과의 비율이다.

$$
ICER^{*}
=\frac{\Delta C^{*}}{\Delta H^{*}}.
$$

일반적으로 다음 두 값은 같지 않다.

$$
\mathbb{E}\left(
\frac{C_1-C_0}{H_1-H_0}
\right)
\neq
\frac{\mathbb{E}(C_1-C_0)}
{\mathbb{E}(H_1-H_0)}.
$$

경제성 평가는 집단 수준의 자원배분 문제이므로 오른쪽의 비율을 사용한다.

### 외적 타당도를 위한 기본 조건

임상시험 결과를 다른 모집단으로 일반화하려면 몇 가지 조건이 필요하다. 첫째, 동일한 치료전략이 두 자료원에서 같은 의미를 가져야 한다. 둘째, 치료효과에 영향을 주면서 임상시험 참여 여부와도 관련된 환자 특성이 충분히 측정되어야 한다. 셋째, 목표 모집단의 모든 주요 환자 유형이 임상시험 자료에서도 어느 정도 관찰되어야 한다.

임상시험 참여 여부를 $S$로 나타내고 $S=1$을 임상시험 참여, $S=0$을 목표 모집단이라고 하자. 대표적인 일반화 조건은 다음과 같이 표현할 수 있다.

$$
(H_1,H_0)\perp S\mid X.
$$

이는 $X$를 조건으로 하면 잠재적 건강결과의 분포가 임상시험 참여 여부와 독립이라는 의미이다. 또한 양의성 조건은 다음과 같다.

$$
0<P(S=1\mid X=x)<1
$$

목표 모집단에서 실제로 존재하는 환자 특성 $x$에 대해 임상시험 참여 가능성이 0이면, 해당 환자 유형의 효과는 자료만으로 직접 일반화하기 어렵다. 이 경우 모형 외삽이나 추가 자료가 필요하며 불확실성이 커진다.

## 분석 기간 {#sec-time-horizon}

경제성 평가에서 분석 기간은 비용과 효과를 어느 시점까지 누적하여 평가할 것인지를 의미한다. 분석 기간은 경제성 평가 결과에 큰 영향을 미친다. 특히 신약의 비용은 치료 초기에 집중되지만 효과는 장기간에 걸쳐 발생하거나, 예방적 치료처럼 현재 비용을 지불하고 미래 사건을 줄이는 경우 분석 기간의 선택이 핵심 문제가 된다.

분석 기간은 다음 두 질문과 연결된다.

1. 치료전략 간 중요한 비용과 효과의 차이가 언제까지 발생하는가?
2. 의사결정자가 고려해야 할 시간 범위는 어디까지인가?

분석 기간은 크게 다음과 같이 구분할 수 있다.

| 분석 기간 | 설명 | 적절한 상황 |
|---|---|---|
| 임상시험 추적기간 | 임상시험에서 실제 관찰된 기간만 분석 | 단기 효과와 비용이 대부분 관찰되는 경우 |
| 고정 기간 | 1년, 5년, 10년 등 특정 기간까지 분석 | 정책적으로 정해진 기간 또는 질병 특성이 제한적인 경우 |
| 생애기간 | 대상 환자가 사망할 때까지 분석 | 생존, 장기 합병증, 만성질환, 예방 효과가 중요한 경우 |

경제성 평가에서는 분석 기간이 충분히 길어야 한다. 치료전략 간 비용과 효과의 중요한 차이가 더 이상 의미 있게 발생하지 않는 시점까지 분석하는 것이 원칙이다. 그러나 분석 기간이 길수록 장기 외삽 가정의 영향이 커지므로, 장기 결과의 불확실성을 민감도 분석으로 평가해야 한다.

### 누적 기대비용과 기대효과

시간 $t$에서 치료전략 $j$의 비용 발생률을 $c_j(t)$, 건강결과 발생률을 $h_j(t)$라고 하자. 분석 기간을 $\tau$라고 하고, 비용 할인율을 $r_C$, 효과 할인율을 $r_H$라고 하면 할인된 누적 기대비용과 누적 기대효과는 다음과 같이 표현할 수 있다.

$$
C_j(\tau;r_C)
= \int_0^{\tau} c_j(t)(1+r_C)^{-t}\,dt,
$$

$$
H_j(\tau;r_H)
= \int_0^{\tau} h_j(t)(1+r_H)^{-t}\,dt.
$$

증분비용과 증분효과는 분석 기간의 함수이다.

$$
\Delta C(\tau)=C_1(\tau;r_C)-C_0(\tau;r_C),
$$

$$
\Delta H(\tau)=H_1(\tau;r_H)-H_0(\tau;r_H).
$$

따라서 ICER도 분석 기간에 따라 달라진다.

$$
ICER(\tau)=\frac{\Delta C(\tau)}{\Delta H(\tau)},
\qquad \Delta H(\tau)\neq 0.
$$

![분석 기간이 길어지면 누적 비용과 누적 효과의 차이가 달라질 수 있다.](figures/ch02/fig-ch02-time-horizon.png){width="92%"}


위 그림은 치료 초기에 비용 차이가 크게 발생하고 건강효과 차이는 시간이 지나면서 누적될 수 있음을 보여준다. 특정 시점의 ICER는 두 누적곡선의 차이를 이용하여 계산되므로, 분석 기간이 달라지면 같은 치료라도 다른 ICER가 산출될 수 있다.

::: {.callout-note}
## 분석 기간의 중요성 {.unnumbered}

비용은 치료 초기에 집중되고 효과는 장기간에 걸쳐 발생하는 치료에서는 분석 기간이 짧으면 비용효과성이 불리하게 평가될 수 있다. 반대로 장기 효과가 불확실한 상황에서 과도하게 긴 분석 기간을 사용하면 효과가 과대평가될 수 있다.
:::

### 이산 시간 모형에서의 표현

마코프모델과 같은 이산 시간 모형에서는 분석 기간을 $K$개의 주기로 나누어 표현한다. $k$번째 주기의 대표 시점을 $t_k$, 주기 길이를 $\Delta_k$라고 하자. 치료전략 $j$에서 $k$번째 주기의 비용을 $c_{jk}$, 건강효과를 $h_{jk}$라고 하면 다음과 같이 계산한다.

$$
C_j = \sum_{k=1}^{K}\frac{c_{jk}}{(1+r_C)^{t_k}},
$$

$$
H_j = \sum_{k=1}^{K}\frac{h_{jk}}{(1+r_H)^{t_k}}.
$$

주기 초 또는 주기 말 값을 그대로 사용하면 누적값이 과대 또는 과소 추정될 수 있다. 그래서 상태 전이 모형에서는 반주기 보정 또는 더 짧은 주기 길이를 사용하여 연속 시간 과정을 근사한다. 이 문제는 4장과 5장에서 더 자세히 다룬다.


### 분석 기간의 절단과 장기 외삽

분석 기간이 짧으면 이후에 발생할 비용과 효과가 계산에서 제외된다. 이를 분석 기간에 의한 절단이라고 볼 수 있다. 생애기간 기대효과를 $H_j(\infty)$라고 할 때, 분석 기간 $\tau$를 사용하여 제외되는 기대효과는 다음과 같다.

$$
B_{H,j}(\tau)
=H_j(\infty)-H_j(\tau)
=\int_{\tau}^{\infty}h_j(t)(1+r_H)^{-t}\,dt.
$$

두 전략의 비교에서 중요한 것은 각 전략의 절단량 자체보다 증분 절단량이다.

$$
B_{\Delta H}(\tau)
=\Delta H(\infty)-\Delta H(\tau).
$$

치료효과가 장기간 유지되는 전략에서는 $B_{\Delta H}(\tau)$가 클 수 있다. 반면 치료효과가 빠르게 소실되거나 두 전략의 생존곡선이 장기적으로 수렴하면 충분히 긴 시점 이후의 증분효과는 작아진다.

생애기간 분석은 문자 그대로 무한한 시간까지 계산한다는 뜻이라기보다, 이후의 추가 비용과 효과가 의사결정에 영향을 주지 않을 정도로 충분히 긴 기간을 사용한다는 뜻이다. 실제 모형에서는 다음 조건을 확인하는 것이 중요하다.

$$
\left|\Delta H(\tau+\delta)-\Delta H(\tau)\right|<\varepsilon_H,
$$

$$
\left|\Delta C(\tau+\delta)-\Delta C(\tau)\right|<\varepsilon_C.
$$

즉, 분석 기간을 조금 더 늘려도 증분비용과 증분효과가 거의 변하지 않는다면 분석 기간이 충분히 길다고 볼 수 있다.

### 할인식의 해석

연간 할인율이 $r$일 때 $t$년 후 1단위의 현재가치는 $(1+r)^{-t}$이다. 연속 할인율 $\rho$를 사용하면 할인인자는 다음과 같이 쓸 수 있다.

$$
e^{-\rho t}.
$$

두 표현이 같은 현재가치를 갖도록 하려면 다음 관계가 성립한다.

$$
\rho=\log(1+r).
$$

할인은 단순한 계산기법이 아니라 현재와 미래의 가치가 동일하지 않다는 사회적 시간선호를 반영한다. 비용과 건강효과에 서로 다른 할인율을 적용하면 장기적으로 발생하는 효과와 비용의 상대적 가치가 달라지므로, 분석 결과의 해석도 달라진다.

반주기 보정은 각 주기의 사건과 비용이 주기 말에만 발생한다고 보는 근사를 완화한다. 주기 길이가 1년이고 사건이 주기 내에서 대략 균등하게 발생한다면 대표 시점을 $t_k=k-0.5$로 두어 다음과 같이 계산할 수 있다.

$$
H_j
\approx
\sum_{k=1}^{K}
\frac{h_{jk}}{(1+r_H)^{k-0.5}}.
$$

주기 길이가 충분히 짧아지면 반주기 보정의 영향은 작아진다.

## 비용효과분석과 비용효용분석 {#sec-cea-cua}

경제성 평가는 치료전략의 비용과 결과를 함께 비교하는 분석이다. 그중 의약품 가치 평가에서 가장 자주 사용되는 형태는 비용효과분석과 비용효용분석이다.

### 비용효과분석

비용효과분석은 효과를 자연 단위로 측정한다. 예를 들어 다음과 같은 결과지표가 사용될 수 있다.

- 생존연수
- 재발 방지 건수
- 심근경색 예방 건수
- 입원 감소 건수
- 혈압 감소량
- HbA1c 감소량

비용효과분석에서 치료전략 $1$과 $0$의 증분비용효과비는 다음과 같다.

$$
ICER_H = \frac{C_1-C_0}{H_1-H_0}.
$$

여기서 $H_j$는 자연 단위의 건강결과이다. 예를 들어 $H_j$가 생존연수라면 단위는 원/생존연수이고, 재발 방지 건수라면 원/재발 방지 건수이다.

### 비용효용분석

비용효용분석은 효과를 QALY로 측정한다. QALY는 생존기간과 건강관련 삶의 질을 결합한 지표이다. 가장 단순한 경우 효용가중치 $u$인 건강상태로 $L$년을 생존하면 QALY는 다음과 같다.

$$
Q = L u.
$$

예를 들어 어떤 환자가 효용가중치 $0.8$의 건강상태로 $2$년을 생존했다면 QALY는 다음과 같다.

$$
Q=2\times0.8=1.6.
$$

비용효용분석의 ICER는 다음과 같이 정의된다.

$$
ICER_Q=\frac{C_1-C_0}{Q_1-Q_0}.
$$

비용효용분석의 장점은 서로 다른 질병 영역과 치료기술을 공통 척도에서 비교할 수 있다는 점이다. 예를 들어 항암제, 심혈관질환 치료제, 희귀질환 치료제의 결과를 모두 QALY 증가당 비용으로 비교할 수 있다.


### 경제성 평가의 비교 원리

비용효과분석과 비용효용분석의 핵심은 한 치료전략의 비용이나 효과를 단독으로 평가하는 것이 아니라, 현실적으로 대체 가능한 전략과의 **증분 비교**를 수행하는 데 있다. 어떤 전략의 평균 비용이 낮다는 사실만으로는 경제성이 있다고 말할 수 없으며, 효과의 차이를 함께 고려해야 한다.

치료전략 $j$의 비용과 효과를 확률변수 $(C_j,H_j)$로 나타내면 경제성 평가의 기본 대상은 다음의 결합된 증분결과이다.

$$
(\Delta C,\Delta H)
=(C_1-C_0,\ H_1-H_0).
$$

비용과 효과는 독립적이지 않을 수 있다. 예를 들어 생존기간이 긴 환자는 약제비와 추적관리 비용이 더 많이 발생하는 동시에 QALY도 더 크게 얻을 수 있다. 따라서 불확실성 분석에서는 두 결과의 공분산을 함께 고려해야 한다.

$$
\operatorname{Cov}(\Delta C,\Delta H)\neq0.
$$

이 공분산은 비용효과평면의 점 구름 방향, 증분순편익의 분산, 신뢰구간과 비용효과수용곡선에 영향을 준다.

### 평균 결과에 근거한 평가

경제성 평가는 일반적으로 환자별 ICER를 계산한 뒤 평균하지 않는다. 각 전략에서 기대비용과 기대효과를 먼저 구하고, 그 차이를 계산한다.

$$
\Delta C
=\mathbb{E}(C_1)-\mathbb{E}(C_0),
$$

$$
\Delta H
=\mathbb{E}(H_1)-\mathbb{E}(H_0).
$$

이 원칙은 비용과 효과가 비선형적이거나 환자 간 이질성이 큰 경우 특히 중요하다. 집단 수준의 총자원과 총건강결과를 비교하려는 목적과도 일치한다.

| 구분 | 비용효과분석 | 비용효용분석 |
|---|---|---|
| 효과 단위 | 자연 단위 | QALY |
| 예 | 원/생존연수, 원/재발 방지 | 원/QALY |
| 장점 | 임상적으로 직관적 | 질병 간 비교 가능 |
| 제한점 | 질병 간 비교가 어려움 | 효용 측정과 가치판단이 필요함 |

::: {.callout-tip}
## 실무적 관점 {.unnumbered}

의약품 급여 의사결정에서는 비용효용분석이 특히 중요하다. QALY는 다양한 질병과 치료기술을 하나의 공통 결과지표로 비교할 수 있게 해 주기 때문이다.
:::

## ICER {#sec-icer}

ICER는 incremental cost-effectiveness ratio의 약자로, 증분비용효과비라고 번역한다. ICER는 신약이 기존 치료에 비해 추가로 필요한 비용을 추가 효과로 나눈 값이다.

기존 치료를 $0$, 신약을 $1$이라고 하자. 각 치료전략의 기대비용을 $C_0$, $C_1$, 기대효과를 $H_0$, $H_1$이라고 하면 증분비용과 증분효과는 다음과 같다.

$$
\Delta C = C_1-C_0,
$$

$$
\Delta H = H_1-H_0.
$$

ICER는 다음과 같이 정의된다.

$$
ICER = \frac{\Delta C}{\Delta H}
= \frac{C_1-C_0}{H_1-H_0},
\qquad \Delta H\neq 0.
$$

비용효용분석에서는 $H_j=Q_j$이므로 다음과 같이 쓴다.

$$
ICER_Q=\frac{\Delta C}{\Delta Q}.
$$

ICER는 “효과 1단위를 추가로 얻기 위해 필요한 추가 비용”을 의미한다. 비용효용분석에서는 보통 QALY 1단위 증가당 추가 비용으로 해석한다.

### 예제: ICER 계산 {.unnumbered}

기존 치료와 신약의 기대비용과 기대 QALY가 다음과 같다고 하자.

| 치료전략 | 기대비용 | 기대 QALY |
|---|---:|---:|
| 기존 치료 | 20,000,000원 | 2.40 |
| 신약 | 32,000,000원 | 2.90 |

증분비용은 다음과 같다.

$$
\Delta C = 32{,}000{,}000-20{,}000{,}000=12{,}000{,}000.
$$

증분효과는 다음과 같다.

$$
\Delta Q = 2.90-2.40=0.50.
$$

따라서 ICER는 다음과 같다.

$$
ICER = \frac{12{,}000{,}000}{0.50}
=24{,}000{,}000\ \text{원/QALY}.
$$

이 값은 신약을 사용할 경우 QALY 1단위를 추가로 얻기 위해 평균적으로 2,400만 원의 추가 비용이 필요하다는 의미이다.

### ICER 해석의 네 가지 경우

ICER는 $\Delta C$와 $\Delta H$의 부호에 따라 해석이 달라진다.

| 증분효과 $\Delta H$ | 증분비용 $\Delta C$ | 위치 | 해석 |
|---:|---:|---|---|
| 양수 | 양수 | 북동 사분면 | 더 효과적이고 더 비쌈. ICER와 기준값 비교 필요 |
| 양수 | 음수 | 남동 사분면 | 더 효과적이고 더 저렴함. 신약이 우월함 |
| 음수 | 양수 | 북서 사분면 | 덜 효과적이고 더 비쌈. 신약이 열등함 |
| 음수 | 음수 | 남서 사분면 | 덜 효과적이고 더 저렴함. 절감 비용과 손실 효과 비교 필요 |

신약이 더 효과적이고 더 저렴한 경우는 우월전략이라고 하며, 신약이 덜 효과적이고 더 비싼 경우는 열등전략이라고 한다. 이 경우에는 ICER를 계산하더라도 의사결정에 큰 의미가 없다.

::: {.callout-warning}
## ICER의 주의점 {.unnumbered}

ICER는 비율이므로 증분효과가 0에 가까울 때 매우 불안정해진다. 또한 $\Delta C$와 $\Delta H$의 부호에 따라 같은 숫자라도 해석이 완전히 달라질 수 있다. 따라서 ICER는 반드시 비용효과평면과 함께 해석하는 것이 좋다.
:::

### 강한 열등성과 확장 열등성

비교 대안이 세 개 이상이면 단순히 각 대안의 ICER를 계산하는 것만으로 충분하지 않다. 먼저 비용과 효과를 기준으로 열등전략을 제거해야 한다.

치료전략 $a$와 $b$에 대해 다음이 성립하면 $a$는 $b$에 의해 강하게 열등하다.

$$
C_a \geq C_b, \qquad H_a \leq H_b,
$$

그리고 두 부등식 중 적어도 하나가 엄격한 부등식이면 $a$는 더 비싸면서 덜 효과적인 전략이다.

확장 열등성은 어떤 전략의 ICER가 더 효과적인 전략 조합의 ICER보다 큰 경우를 말한다. 즉, 한 전략이 강하게 열등하지는 않더라도 효율적 경계선 위에 있지 않으면 의사결정 후보에서 제외될 수 있다. 다중 대안 비교에서 ICER는 효과가 낮은 전략에서 높은 전략으로 정렬한 뒤, 열등전략과 확장 열등전략을 제거한 후 계산해야 한다.


### ICER의 기하학적 해석

비용효과평면에서 기존 치료를 원점으로 두면 신약은 $(\Delta H,\Delta C)$라는 한 점으로 표현된다. 이때 ICER는 원점과 해당 점을 연결한 직선의 기울기이다.

$$
ICER=\frac{\Delta C}{\Delta H}.
$$

따라서 ICER는 비용과 효과의 절대적 크기를 각각 보여주는 값이 아니라 두 변화량의 상대적 기울기이다. 서로 매우 다른 증분비용과 증분효과의 조합도 같은 ICER를 가질 수 있다. 예를 들어 다음 두 경우의 ICER는 동일하다.

$$
\frac{1{,}000{,}000}{0.05}
=
\frac{20{,}000{,}000}{1.0}
=20{,}000{,}000\ \text{원/QALY}.
$$

하지만 두 경우는 예산영향, 임상적 중요성, 불확실성 측면에서 동일하지 않다. 따라서 ICER 외에 증분비용과 증분효과 자체를 함께 제시해야 한다.

### ICER의 통계적 불안정성

ICER 추정량을 다음과 같이 쓰자.

$$
\widehat{ICER}
=\frac{\widehat{\Delta C}}{\widehat{\Delta H}}.
$$

분모인 $\widehat{\Delta H}$가 0에 가까우면 작은 표본 변동도 비율을 크게 변화시킨다. 또한 증분효과의 신뢰구간이 0을 포함하면 ICER의 분포는 매우 비대칭적이거나 두 구간으로 분리될 수 있다. 이런 상황에서 평균과 표준오차에 기반한 대칭적 신뢰구간은 적절하지 않을 수 있다.

델타방법을 적용하면 대략적인 분산은 다음과 같다.

$$
\operatorname{Var}(\widehat{ICER})
\approx
\frac{V_C}{\Delta H^2}
+
\frac{\Delta C^2V_H}{\Delta H^4}
-
2\frac{\Delta C V_{CH}}{\Delta H^3},
$$

여기서 $V_C=\operatorname{Var}(\widehat{\Delta C})$, $V_H=\operatorname{Var}(\widehat{\Delta H})$, $V_{CH}=\operatorname{Cov}(\widehat{\Delta C},\widehat{\Delta H})$이다. 이 근사는 $\Delta H$가 0에서 충분히 멀고 표본이 큰 경우에만 안정적이다. 실제 경제성 평가에서는 부트스트랩 비용효과평면이나 순편익 접근법이 더 자주 사용된다.

### 효율적 경계선과 확장 열등성의 수식적 의미

효과가 증가하는 순서로 전략을 정렬하여 $H_1<H_2<\cdots<H_J$라고 하자. 인접한 전략의 ICER는 다음과 같다.

$$
ICER_{j,j+1}
=\frac{C_{j+1}-C_j}{H_{j+1}-H_j}.
$$

효율적 경계선 위의 전략에서는 효과가 증가할수록 인접 ICER가 감소하지 않아야 한다.

$$
ICER_{1,2}
\leq ICER_{2,3}
\leq \cdots
\leq ICER_{J-1,J}.
$$

어떤 중간 전략 때문에 이 순서가 깨지면 그 전략은 다른 두 전략의 혼합보다 비효율적이며 확장 열등으로 판단한다. 확장 열등전략을 제거한 뒤 인접 ICER를 다시 계산해야 한다.

## 경제성평가에서 사용되는 결과지표 {#sec-outcome-measures}

경제성 평가에서 사용하는 결과지표는 분석의 목적과 질병 특성에 따라 달라진다. 일반적으로 결과지표는 다음 세 범주로 나눌 수 있다.

1. 임상적 결과지표
2. 생존 관련 결과지표
3. 효용 기반 결과지표

### 임상적 결과지표

임상적 결과지표는 특정 임상 사건이나 생물학적 변화를 측정한다. 예를 들어 혈압 감소, HbA1c 감소, LDL 콜레스테롤 감소, 종양 반응률, 재발 방지 건수, 입원 예방 건수, 이상반응 감소 건수 등이 있다.

이러한 지표는 임상적으로 직관적이지만, 서로 다른 질병 영역 사이에서 비교하기 어렵다. 예를 들어 “입원 1건 예방”과 “무진행 생존기간 1개월 증가”를 동일한 의사결정 척도에서 비교하기는 어렵다.

### 생존 관련 결과지표

생존 관련 결과지표는 특히 항암제 경제성 평가에서 중요하다. 대표적으로 전체생존기간, 무진행생존기간, 사건 없는 생존기간, 생존연수, 생애기간 생존연수가 있다.

생존함수를 $S(t)=P(T>t)$라고 하면 평균 생존시간은 다음과 같다.

$$
\mathbb{E}(T)=\int_0^{\infty} S(t)\,dt.
$$

분석 기간을 $\tau$로 제한하면 restricted mean survival time은 다음과 같이 정의된다.

$$
RMST(\tau)=\int_0^{\tau}S(t)\,dt.
$$

두 치료전략의 제한평균 생존시간 차이는 다음과 같다.

$$
\Delta RMST(\tau)
=\int_0^{\tau}\{S_1(t)-S_0(t)\}\,dt.
$$

이 값은 생존곡선의 차이를 시간 전체에 걸쳐 누적한 값이므로, 특정 시점의 생존율 차이나 위험비와는 다른 정보를 제공한다.


위험비는 순간적인 위험률의 상대적 크기를 요약하지만, 경제성 평가에서 필요한 생존연수는 생존곡선 아래 면적에 의해 결정된다. 비례위험 가정이 성립하지 않거나 생존곡선이 교차하는 경우 하나의 위험비만으로 장기 생존이득을 충분히 설명하기 어렵다.

두 전략의 위험비가 동일하더라도 기저 위험과 추적기간이 다르면 절대 생존이득은 달라질 수 있다. 경제성 평가에서는 상대효과뿐 아니라 다음과 같은 절대적 시간 척도가 중요하다.

$$
\Delta RMST(\tau)
=\int_0^\tau S_1(t)\,dt
-
\int_0^\tau S_0(t)\,dt.
$$

이 값은 분석 기간 $\tau$ 동안 신약이 평균적으로 제공하는 추가 생존시간으로 직접 해석할 수 있다.

### 대리지표와 최종 건강결과

임상시험에서는 종양반응률, 무진행생존기간, 검사수치와 같은 대리지표가 측정되는 경우가 많다. 그러나 경제성 평가의 최종 결과는 대개 생존연수 또는 QALY이다. 따라서 대리지표를 최종 결과로 연결하는 추가 모형이 필요할 수 있다.

대리지표를 $Z$, 최종 건강결과를 $H$라고 하면 다음과 같은 예측관계를 사용할 수 있다.

$$
\mathbb{E}(H\mid Z,X)=g(Z,X;\beta).
$$

하지만 $Z$가 치료효과를 완전히 대리하지 못하면, 대리지표에 대한 효과를 최종 건강결과로 전환하는 과정에서 구조적 불확실성이 발생한다. 통계적으로 강한 연관성이 있다는 사실만으로 대리지표가 인과적으로 유효하다고 단정할 수는 없다.

### 효용 기반 결과지표

효용 기반 결과지표의 대표적인 예는 QALY이다. QALY는 생존기간과 건강관련 삶의 질을 통합한다. 시간 $t$에서의 효용가중치를 $u(t)$, 생존시간을 $T$라고 하면 분석 기간 $\tau$까지의 QALY는 다음과 같이 표현할 수 있다.

$$
Q(\tau)=\int_0^{\tau}u(t)I(T>t)\,dt,
$$

여기서 $I(T>t)$는 시간 $t$에 생존해 있으면 1, 아니면 0인 지시함수이다. 기대 QALY는 다음과 같다.

$$
\mathbb{E}\{Q(\tau)\}
=\int_0^{\tau}\mathbb{E}\{u(t)I(T>t)\}\,dt.
$$

효용가중치가 생존 여부와 독립적으로 외부에서 정해진 함수라면 단순히 다음과 같이 쓸 수 있다.

$$
\mathbb{E}\{Q(\tau)\}
=\int_0^{\tau}u(t)S(t)\,dt.
$$

다만 실제 분석에서는 건강상태, 이상반응, 치료 중단, 진행 여부에 따라 효용이 달라지므로 상태 기반 계산이 더 일반적이다.


효용가중치는 보통 완전한 건강을 1, 사망을 0으로 두는 척도에서 정의한다. 일부 건강상태는 사망보다 선호되지 않을 수 있으므로 음의 효용값도 가능하다. 따라서 효용가중치는 단순한 만족도 점수가 아니라 불확실한 건강상태에 대한 선호를 반영하는 가치척도이다.

### QALY가 사용하는 주요 가정

QALY는 서로 다른 시점의 건강상태를 하나의 면적으로 합산한다. 이 계산에는 몇 가지 이론적 가정이 포함된다.

첫째, 동일한 건강상태에서 생존기간이 두 배가 되면 QALY도 두 배가 된다는 기간에 대한 선형성을 가정한다.

$$
Q(L,u)=Lu.
$$

둘째, 한 시점의 효용이 다른 시점의 효용과 독립적으로 합산될 수 있다는 가법성을 가정한다.

$$
Q
=\sum_{k=1}^{K}u_k\Delta_k.
$$

셋째, 건강상태의 가치가 언제 경험되는지에 따라 달라지는 시간선호는 별도의 할인으로 처리한다. 이러한 가정이 현실의 선호와 완전히 일치하는 것은 아니지만, 서로 다른 질병과 치료를 공통 척도에서 비교할 수 있게 한다.

QALY는 개인의 모든 복지나 사회적 가치를 포괄하는 지표는 아니다. 치료의 희귀성, 중증도, 건강불평등, 보호자 부담, 생산성, 혁신 가치와 같은 요소는 QALY만으로 충분히 반영되지 않을 수 있다.

::: {.callout-note}
## 결과지표 선택의 원칙 {.unnumbered}

경제성 평가의 결과지표는 의사결정자가 비교하고자 하는 가치의 단위와 일치해야 한다. 질병 간 자원배분 의사결정에서는 QALY와 같은 공통 지표가 유용하다.
:::

## QALY의 추정 {#sec-qaly-estimation}

QALY는 quality-adjusted life year의 약자로, 질보정생존연수라고 번역한다. QALY는 생존기간과 삶의 질을 하나의 지표로 결합한다. 이 절에서는 QALY를 추정하는 세 가지 기본 방식을 정리한다.

### 구간별 효용가중치 기반 계산

실제 환자의 건강상태는 시간에 따라 변한다. 따라서 효용도 시간에 따라 변할 수 있다. 시간을 $K$개의 구간으로 나누고, $k$번째 구간의 효용가중치를 $u_k$, 구간 길이를 $\Delta_k$라고 하면 QALY는 다음과 같이 근사할 수 있다.

$$
Q \approx \sum_{k=1}^{K}u_k\Delta_k.
$$

할인을 적용하면 다음과 같다.

$$
Q^{disc}
\approx
\sum_{k=1}^{K}\frac{u_k\Delta_k}{(1+r_Q)^{t_k}},
$$

여기서 $r_Q$는 효과 할인율이고, $t_k$는 해당 구간의 대표 시점이다.

![QALY는 시간에 따른 효용가중치 곡선 아래 면적으로 해석할 수 있다.](figures/ch02/fig-ch02-qaly-area.png){width="88%"}


위 그림에서 가로축의 시간과 세로축의 효용가중치가 만드는 면적이 QALY이다. 효용이 동일하더라도 지속기간이 길면 면적이 커지고, 생존기간이 동일하더라도 건강상태의 효용이 낮으면 면적이 작아진다. 따라서 QALY는 생존과 삶의 질을 곱한 단순값이라기보다 시간에 따라 변화하는 효용의 누적 면적으로 이해하는 것이 정확하다.

### 상태 기반 QALY 추정

마코프모델에서는 각 건강상태에 효용가중치를 부여하고, 각 주기마다 환자가 특정 상태에 머무는 비율을 이용하여 QALY를 계산한다. 건강상태를 $s=1,\ldots,S$, 주기를 $k=1,\ldots,K$라고 하자. 치료전략 $j$에서 주기 $k$에 건강상태 $s$에 있는 비율을 $p_{jsk}$, 해당 상태의 효용을 $u_s$, 주기 길이를 $\Delta_k$라고 하면 QALY는 다음과 같다.

$$
Q_j
=
\sum_{k=1}^{K}\sum_{s=1}^{S}
\frac{p_{jsk}u_s\Delta_k}{(1+r_Q)^{t_k}}.
$$

이상반응이 특정 주기에 추가적인 효용 감소를 유발한다면, 이상반응 효용 감소량을 $d_a$, 이상반응 발생확률을 $p_{jak}$라고 두고 다음처럼 반영할 수 있다.

$$
Q_j
=
\sum_{k=1}^{K}\sum_{s=1}^{S}
\frac{p_{jsk}u_s\Delta_k}{(1+r_Q)^{t_k}}
-
\sum_{k=1}^{K}\sum_{a=1}^{A}
\frac{p_{jak}d_a}{(1+r_Q)^{t_k}}.
$$

첫 번째 항은 건강상태에서 얻는 QALY이고, 두 번째 항은 이상반응으로 인한 QALY 손실이다.

### 생존곡선 기반 QALY 추정

항암제 경제성 평가에서는 생존곡선을 이용하여 QALY를 추정하는 경우가 많다. 무진행 상태의 효용을 $u_{PF}$, 진행 상태의 효용을 $u_{PD}$라고 하자. 무진행생존함수를 $S_{PFS}(t)$, 전체생존함수를 $S_{OS}(t)$라고 하면 시점 $t$에서 각 상태의 비율은 다음과 같이 표현할 수 있다.

$$
P(PF\ \text{at}\ t)=S_{PFS}(t),
$$

$$
P(PD\ \text{at}\ t)=S_{OS}(t)-S_{PFS}(t),
$$

$$
P(Death\ \text{at}\ t)=1-S_{OS}(t).
$$

따라서 분석 기간 $\tau$까지의 QALY는 다음과 같이 계산할 수 있다.

$$
Q
=\int_0^{\tau}
\left[
 u_{PF}S_{PFS}(t)
 +u_{PD}\{S_{OS}(t)-S_{PFS}(t)\}
\right](1+r_Q)^{-t}\,dt.
$$

이 수식은 분할생존모델에서 QALY를 계산하는 기본 구조이다. 단, 항상 $S_{OS}(t)\geq S_{PFS}(t)$가 성립해야 하며, 외삽 과정에서 두 곡선이 교차하지 않도록 확인해야 한다.


### 효용곡선 면적의 수치적 근사

실제 자료에서는 효용이 연속적으로 관찰되지 않고 방문 시점에서만 측정되는 경우가 많다. 방문 시점 $t_0<t_1<\cdots<t_K$에서 효용값 $u_0,u_1,\ldots,u_K$가 관찰되었다면 사다리꼴 공식을 이용하여 QALY를 근사할 수 있다.

$$
Q
\approx
\sum_{k=1}^{K}
\frac{u_{k-1}+u_k}{2}
(t_k-t_{k-1}).
$$

이 계산은 두 측정시점 사이에서 효용이 선형적으로 변화한다고 가정한다. 측정 간격이 길거나 임상상태가 급격히 변하는 경우 이 가정에 따른 오차가 커질 수 있다.

### 이상반응 효용 감소의 단위

이상반응에 따른 효용 감소는 강도와 지속기간을 함께 고려해야 한다. 효용이 $d_a$만큼 감소하고 평균 지속기간이 $L_a$년이라면 1건의 이상반응에 따른 QALY 손실은 다음과 같다.

$$
D_a=d_aL_a.
$$

발생확률이 $p_a$이면 기대 QALY 손실은 $p_aD_a$이다. 문헌에서 제시된 값이 순간적인 효용 감소인지, 이미 지속기간이 반영된 QALY 감소인지 구분하지 않으면 동일한 지속기간을 두 번 곱하는 오류가 발생할 수 있다.

여러 건강상태와 이상반응이 동시에 존재할 때 효용을 단순히 모두 더하거나 빼면 1보다 크거나 지나치게 낮은 값이 될 수 있다. 이 경우 가법모형, 최소값 모형, 곱셈모형 등 결합 규칙을 사전에 정의하고 민감도 분석을 수행하는 것이 필요하다.

## 비용 {#sec-costs}

경제성 평가에서 비용은 어떤 관점에서 분석하느냐에 따라 포함 범위가 달라진다. 비용은 단순히 약제비만을 의미하지 않는다. 치료와 관련된 의료자원 사용, 이상반응 관리, 입원, 외래 방문, 검사, 수술, 장기요양, 환자 및 보호자의 시간 비용 등이 포함될 수 있다.

### 분석 관점

비용의 범위는 분석 관점에 따라 달라진다.

| 분석 관점 | 포함될 수 있는 비용 |
|---|---|
| 보건의료체계 관점 | 약제비, 진료비, 입원비, 검사비, 시술비 |
| 보험자 관점 | 급여자가 실제 부담하는 비용 |
| 사회적 관점 | 의료비, 교통비, 간병비, 생산성 손실 등 |
| 환자 관점 | 본인부담금, 교통비, 시간 비용 등 |

의사결정기관이 어떤 관점을 요구하는지에 따라 비용 항목을 선택해야 한다. 동일한 임상효과를 가진 치료라도 분석 관점에 따라 비용효과성이 달라질 수 있다.

### 비용의 구성

치료전략 $j$의 총 비용은 다음과 같이 구성할 수 있다.

$$
C_j
= C_{drug,j}+C_{admin,j}+C_{monitor,j}+C_{AE,j}
+C_{disease,j}+C_{terminal,j}.
$$

각 항은 다음을 의미한다.

| 기호 | 의미 |
|---|---|
| $C_{drug,j}$ | 약제비 |
| $C_{admin,j}$ | 투약 및 처치 비용 |
| $C_{monitor,j}$ | 모니터링 및 검사 비용 |
| $C_{AE,j}$ | 이상반응 관리 비용 |
| $C_{disease,j}$ | 질병 상태 관련 비용 |
| $C_{terminal,j}$ | 말기 또는 사망 전 비용 |

자원 사용량과 단가를 분리하면 비용은 다음과 같이 표현할 수 있다.

$$
C_j=\sum_{m=1}^{M}R_{jm}a_m,
$$

여기서 $R_{jm}$은 치료전략 $j$에서 자원 항목 $m$의 사용량이고, $a_m$은 해당 자원 항목의 단가이다. 이 표현은 비용 산출의 투명성을 높인다. 비용 차이가 자원 사용량의 차이에서 비롯되는지, 단가의 차이에서 비롯되는지를 분리해 볼 수 있기 때문이다.


### 비용 산정의 세 단계

비용 추정은 일반적으로 자원 항목의 식별, 사용량 측정, 단가 적용의 세 단계로 나눌 수 있다.

1. **식별**: 분석 관점과 관련된 자원 항목을 결정한다.
2. **측정**: 각 자원이 얼마나 사용되었는지 계산한다.
3. **가치평가**: 각 사용량에 적절한 단가를 적용한다.

환자 $i$의 비용을 자원 사용량 $R_{im}$과 단가 $a_m$의 곱으로 표현하면 다음과 같다.

$$
C_i=\sum_{m=1}^{M}R_{im}a_m.
$$

집단의 평균 비용은 다음과 같다.

$$
\bar C=\frac{1}{N}\sum_{i=1}^{N}C_i.
$$

미시비용산정은 자원 항목을 세부적으로 식별하여 사용량과 단가를 각각 측정하는 방식이다. 총액비용산정은 진료비 총액이나 포괄수가와 같은 집계된 비용을 사용한다. 미시비용산정은 투명성이 높지만 자료수집 부담이 크고, 총액비용산정은 실무적으로 간단하지만 비용 발생의 세부 원인을 분리하기 어렵다.

### 비용의 기준연도와 가격 조정

서로 다른 연도에 측정된 비용을 함께 사용할 때는 동일한 가격연도로 환산해야 한다. 기준연도의 물가지수를 $I_{t^*}$, 원자료 연도의 물가지수를 $I_t$라고 하면 조정 비용은 다음과 같다.

$$
C_{t^*}=C_t\frac{I_{t^*}}{I_t}.
$$

외국 통화 자료를 사용하는 경우에는 물가조정과 환율변환의 순서와 기준시점을 명확히 해야 한다. 시장환율은 구매력 차이를 완전히 반영하지 않을 수 있으므로 자료의 성격과 분석 목적에 따라 적절한 변환 방법을 선택한다.

### 시간에 따른 비용과 할인

비용은 시간에 따라 발생한다. 시점 $t$에서 치료전략 $j$의 비용 발생률을 $c_j(t)$라고 하면 분석 기간 $\tau$ 동안의 할인 비용은 다음과 같다.

$$
C_j(\tau;r_C)
=\int_0^{\tau}c_j(t)(1+r_C)^{-t}\,dt.
$$

이산 시간 모형에서는 다음과 같이 표현할 수 있다.

$$
C_j
=\sum_{k=1}^{K}\frac{c_{jk}}{(1+r_C)^{t_k}},
$$

여기서 $c_{jk}$는 $k$번째 주기에 발생한 비용이다.

위 그림에서 대부분의 환자는 비교적 낮거나 중간 수준의 비용을 보이지만 일부 환자에게 매우 큰 비용이 발생한다. 이 소수의 고비용 환자가 전체 평균과 예산에 큰 영향을 주기 때문에, 이상치를 단순히 제거하기보다는 발생 원인을 확인하고 분석 관점에 맞게 포함하는 것이 원칙이다.

### 평균 비용이 중요한 이유

경제성 평가에서는 보통 중앙값이 아니라 평균 비용을 사용한다. 의사결정자는 전체 대상 인구집단에서 발생하는 총비용을 고려하기 때문이다. 환자 수가 $N$명이고 1인당 기대비용이 $\mu_C$라면 총 기대비용은 다음과 같다.

$$
\mathbb{E}(\text{Total cost})=N\mu_C.
$$

비용분포가 오른쪽으로 치우쳐 있으면 중앙값은 전형적인 환자의 비용을 잘 설명할 수 있지만, 총예산 영향을 설명하는 데는 평균이 더 직접적이다. 따라서 비용자료 분석에서는 평균 비용의 추정과 불확실성 평가가 핵심이다.


### 비용자료의 통계적 특성

비용자료는 0의 값이 많거나, 오른쪽 꼬리가 길거나, 추적 중 사망과 중도절단의 영향을 받는 경우가 많다. 이러한 특성 때문에 정규분포를 가정한 단순 분석이 항상 적절한 것은 아니다. 그러나 평균 비용은 중심극한정리에 의해 표본이 충분히 크면 근사적으로 정규분포를 따를 수 있으며, 비모수 부트스트랩을 이용하여 평균 비용 차이의 불확실성을 평가할 수도 있다.

비용과 생존기간 사이에는 구조적인 관계가 존재한다. 오래 생존한 환자는 치료와 추적관리를 더 오래 받기 때문에 비용이 커질 수 있다. 따라서 추적기간이 환자마다 다르거나 중도절단이 존재하면 단순히 관찰된 비용을 평균하는 방식은 편향될 수 있다.

환자 $i$의 관찰시간을 $Y_i=\min(T_i,U_i)$라고 하자. 여기서 $T_i$는 실제 추적 종료시간, $U_i$는 중도절단시간이다. $T_i>U_i$이면 이후 비용이 관찰되지 않는다. 이때 생존분석과 유사하게 역확률 중도절단 가중치 또는 구간별 비용 추정을 사용하여 누락된 장기 비용을 보정할 수 있다.

경제성 평가에서 비용의 평균과 효과의 평균은 별도로 추정되지만, 같은 환자에서 측정되므로 두 결과의 상관성을 유지한 분석이 필요하다. 환자 단위 부트스트랩에서는 비용과 효과의 쌍을 함께 재표본추출해야 한다.

## 비용효과평면 {#sec-cost-effectiveness-plane}

비용효과평면은 증분효과를 가로축, 증분비용을 세로축에 나타낸 그림이다. 이 평면은 ICER의 해석을 시각적으로 이해하는 데 매우 유용하다.

가로축은 다음을 나타낸다.

$$
\Delta H=H_1-H_0.
$$

세로축은 다음을 나타낸다.

$$
\Delta C=C_1-C_0.
$$

비용효과평면은 네 개의 사분면으로 나뉜다.


비용효과평면의 각 점은 하나의 증분비용과 증분효과 조합을 나타낸다. 점추정치만 표시할 수도 있지만, 부트스트랩이나 확률론적 민감도 분석에서 얻은 다수의 모의값을 표시하면 결합 불확실성을 확인할 수 있다.

모의 반복 $m$에서의 결과를 $(\Delta H^{(m)},\Delta C^{(m)})$라고 하면, 사분면별 점의 비율은 다음과 같이 추정할 수 있다.

$$
\widehat P_{NE}
=\frac{1}{M}\sum_{m=1}^{M}
I\{\Delta H^{(m)}>0,\Delta C^{(m)}>0\},
$$

$$
\widehat P_{SE}
=\frac{1}{M}\sum_{m=1}^{M}
I\{\Delta H^{(m)}>0,\Delta C^{(m)}<0\}.
$$

나머지 사분면도 같은 방식으로 계산할 수 있다. 이 비율은 신약이 우월하거나 열등할 가능성을 시각적 결과와 함께 정량적으로 설명한다.

| 사분면 | $\Delta H$ | $\Delta C$ | 해석 |
|---|---:|---:|---|
| 북동 | 양수 | 양수 | 더 효과적이고 더 비쌈 |
| 남동 | 양수 | 음수 | 더 효과적이고 더 저렴함 |
| 북서 | 음수 | 양수 | 덜 효과적이고 더 비쌈 |
| 남서 | 음수 | 음수 | 덜 효과적이고 더 저렴함 |

북동 사분면에서는 신약이 더 효과적이지만 더 비싸기 때문에, 추가 효과가 추가 비용을 정당화할 수 있는지 판단해야 한다. 남동 사분면에서는 신약이 더 효과적이고 더 저렴하므로 일반적으로 신약이 우월하다. 북서 사분면에서는 신약이 덜 효과적이고 더 비싸므로 일반적으로 열등하다. 남서 사분면에서는 비용은 절감되지만 효과가 감소하므로 절감 비용이 효과 손실을 정당화할 수 있는지 판단해야 한다.

### 지불의사금액과 의사결정 경계선

지불의사금액을 $\lambda$라고 하자. $\lambda$는 효과 1단위, 보통 QALY 1단위에 대해 사회 또는 의사결정자가 지불할 의사가 있는 최대 금액이다.

신약이 비용효과적이기 위한 조건은 다음과 같다.

$$
\Delta C < \lambda \Delta H.
$$

비용효과평면에서 $\Delta C=\lambda\Delta H$는 원점을 지나는 직선이다. 이 직선 아래에 있는 점은 순편익 기준에서 비용효과적인 것으로 해석할 수 있다.


기준선의 기울기는 $\lambda$이다. 지불의사금액이 커질수록 직선은 더 가파르게 회전하며, 추가 효과에 더 높은 금전적 가치를 부여하게 된다. 비용효과적 영역은 다음 부등식으로 정의된다.

$$
\lambda\Delta H-\Delta C>0.
$$

이 조건은 모든 사분면에 일관되게 적용된다. 예를 들어 남서 사분면에서는 $\Delta H<0$이고 $\Delta C<0$이므로, 절감되는 비용이 손실되는 건강효과의 가치보다 큰지를 판단한다. 따라서 단순히 음의 ICER라는 이유만으로 비용효과적이거나 비용효과적이지 않다고 결론 내릴 수 없다.

점 구름이 여러 사분면에 걸쳐 있으면 ICER의 평균이나 신뢰구간보다 기준선 아래에 위치한 비율을 보는 것이 해석에 유리하다. 이 비율이 바로 특정 $\lambda$에서 비용효과적일 확률과 연결된다.

![비용효과평면과 지불의사금액 기준선. 기준선 아래의 점은 순편익이 양수인 영역이다.](figures/ch02/fig-ch02-ce-plane.png){width="88%"}


위 그림에서 한 점의 가로좌표는 증분효과, 세로좌표는 증분비용이다. 원점에서 점까지의 기울기는 ICER이며, 지불의사금액 기준선 아래에 있는 점은 $\lambda\Delta H-\Delta C>0$을 만족한다. 모의점이 기준선의 양쪽에 분포하면 비용효과성에 의사결정 불확실성이 존재한다.

::: {.callout-tip}
## 비용효과평면의 장점 {.unnumbered}

ICER 하나만 제시하면 불확실성과 사분면의 의미를 충분히 전달하기 어렵다. 비용효과평면은 증분비용과 증분효과의 결합분포를 시각적으로 보여주기 때문에 확률론적 민감도 분석 결과를 해석하는 데 유용하다.
:::

## 화폐단위로 정의된 순편익의 증분 {#sec-incremental-net-benefit}

ICER는 경제성 평가에서 널리 사용되지만 몇 가지 한계가 있다. 특히 증분효과가 0에 가까울 때 불안정하고, 사분면에 따라 해석이 복잡하다. 이를 보완하기 위해 순편익 접근법이 자주 사용된다.

지불의사금액을 $\lambda$라고 할 때 치료전략 $j$의 순편익은 다음과 같이 정의된다.

$$
NB_j(\lambda)=\lambda H_j-C_j.
$$

여기서 $H_j$는 효과, $C_j$는 비용이다. 순편익은 효과를 화폐단위로 변환한 후 비용을 뺀 값이다. 신약 $1$과 기존 치료 $0$의 증분순편익은 다음과 같다.

$$
INB(\lambda)=NB_1(\lambda)-NB_0(\lambda).
$$

이를 전개하면 다음과 같다.

$$
INB(\lambda)
=\lambda(H_1-H_0)-(C_1-C_0)
=\lambda\Delta H-\Delta C.
$$

신약이 비용효과적이기 위한 조건은 다음과 같다.

$$
INB(\lambda)>0.
$$

### ICER와 INB의 관계

$\Delta H>0$일 때 ICER 기준은 다음과 같다.

$$
ICER < \lambda.
$$

이는 다음과 동치이다.

$$
\frac{\Delta C}{\Delta H}<\lambda
\quad\Longleftrightarrow\quad
\Delta C<\lambda\Delta H
\quad\Longleftrightarrow\quad
INB(\lambda)>0.
$$

따라서 $\Delta H>0$인 경우 ICER 기준과 INB 기준은 동일한 의사결정을 제공한다. 하지만 INB는 $\Delta H$가 0에 가까울 때도 안정적이고, 회귀분석이나 확률론적 분석에 적용하기 쉽다는 장점이 있다.

### 예제: INB 계산 {.unnumbered}

앞서 신약의 증분비용이 1,200만 원, 증분효과가 0.5 QALY라고 하자. 지불의사금액이 QALY당 3,000만 원이라면 INB는 다음과 같다.

$$
INB=30{,}000{,}000\times0.5-12{,}000{,}000
=3{,}000{,}000.
$$

INB가 양수이므로 이 기준에서 신약은 비용효과적인 것으로 해석된다.

![지불의사금액이 커질수록 증분순편익은 선형적으로 증가한다.](figures/ch02/fig-ch02-inb-threshold.png){width="88%"}


위 그림에서 직선의 절편은 $-\Delta C$이고 기울기는 $\Delta H$이다. 증분효과가 양수이면 지불의사금액이 증가할수록 증분순편익이 증가한다. 직선이 0을 통과하는 지불의사금액은 증분효과가 양수인 경우 ICER와 같다.

$$
\lambda^*
=\frac{\Delta C}{\Delta H}.
$$

### 확률론적 해석

확률론적 민감도 분석에서는 $\Delta C$와 $\Delta H$가 불확실한 값이다. 따라서 INB도 확률변수가 된다.

$$
INB^{(m)}(\lambda)=\lambda\Delta H^{(m)}-\Delta C^{(m)},
\qquad m=1,\ldots,M.
$$

신약이 비용효과적일 확률은 다음과 같이 추정할 수 있다.

$$
P\{INB(\lambda)>0\}
\approx
\frac{1}{M}\sum_{m=1}^{M}
I\{INB^{(m)}(\lambda)>0\}.
$$

이 값은 비용효과수용곡선의 기본이 된다. 다만 비용효과적일 확률이 높다는 사실이 곧바로 급여 결정을 의미하지는 않는다. 의사결정은 기대순편익, 예산영향, 형평성, 질병 중증도, 대체 치료 가능성 등을 함께 고려해야 한다.

### INB의 표준오차

임상시험 기반 경제성 평가에서 $\widehat{\Delta H}$와 $\widehat{\Delta C}$를 추정했다고 하자. 두 추정량의 분산과 공분산을 각각 $V_H$, $V_C$, $V_{HC}$라고 하면 증분순편익 추정량의 분산은 다음과 같다.

$$
\operatorname{Var}\{\widehat{INB}(\lambda)\}
=\lambda^2V_H+V_C-2\lambda V_{HC}.
$$

이 식은 순편익 접근법이 통계적 추론에 편리한 이유를 보여준다. 비용과 효과의 결합 불확실성이 선형결합의 분산으로 표현되기 때문이다.


증분순편익의 표준오차는 다음과 같다.

$$
SE\{\widehat{INB}(\lambda)\}
=
\sqrt{
\lambda^2V_H+V_C-2\lambda V_{HC}
}.
$$

큰 표본 근사를 사용하면 다음과 같은 신뢰구간을 구성할 수 있다.

$$
\widehat{INB}(\lambda)
\pm z_{1-\alpha/2}
SE\{\widehat{INB}(\lambda)\}.
$$

신뢰구간 전체가 0보다 크면 해당 지불의사금액에서 증분순편익이 양수라는 통계적 근거가 강하다고 해석할 수 있다. 그러나 경제성 평가의 최종 의사결정은 가설검정의 기각 여부보다는 기대순편익의 크기와 의사결정 오류의 결과를 중심으로 이루어진다.

### 여러 전략의 기대순편익

전략이 $J$개인 경우 각 전략의 기대순편익을 계산하여 가장 큰 전략을 선택한다.

$$
ENB_j(\lambda)
=\lambda\mathbb{E}(H_j)-\mathbb{E}(C_j),
\qquad j=1,\ldots,J.
$$

최적 전략은 다음과 같다.

$$
j^*(\lambda)
=\arg\max_j ENB_j(\lambda).
$$

이 표현은 모든 전략을 공통 척도에서 직접 비교할 수 있으며, 열등성과 확장 열등성을 순편익 관점에서도 확인할 수 있게 한다.

### 비용효과수용곡선의 해석상 주의

비용효과수용곡선은 각 지불의사금액에서 특정 전략이 가장 비용효과적일 확률을 나타낸다. 확률이 가장 높다는 것은 불확실성 하에서 그 전략이 최적일 가능성이 가장 크다는 의미이지, 기대순편익의 차이가 크다는 의미는 아니다.

두 전략의 기대순편익 차이가 매우 작으면 한 전략이 비용효과적일 확률이 50%에 가까울 수 있다. 반대로 확률이 높더라도 잘못된 선택을 했을 때의 손실이 클 수 있다. 따라서 비용효과적 확률과 기대순편익의 크기를 함께 살펴보아야 한다.

::: {.callout-important}
## 순편익 접근법의 장점 {.unnumbered}

순편익은 ICER와 동일한 의사결정 원리를 가지면서도 통계적으로 더 다루기 쉽다. 특히 회귀분석, 불확실성 분석, 비용효과수용곡선, 정보의 가치 분석에서 유용하다.
:::

## 확증적 임상시험의 통계 분석과 경제성 평가 분석의 차이점 {#sec-trial-statistics-vs-economic-evaluation}

확증적 임상시험의 통계 분석과 경제성 평가 분석은 모두 임상자료를 사용하지만 목적과 사고방식이 다르다.

확증적 임상시험의 주요 목적은 치료효과의 존재를 검증하는 것이다. 예를 들어 신약이 기존 치료보다 주요 평가변수에서 우월한지, 비열등한지, 또는 통계적으로 유의한 차이를 보이는지가 핵심 질문이다.

반면 경제성 평가는 신약을 급여하거나 사용할 가치가 있는지를 평가한다. 따라서 치료효과뿐 아니라 비용, 삶의 질, 장기 결과, 불확실성, 대체 치료전략, 의사결정 기준을 함께 고려해야 한다.

| 구분 | 확증적 임상시험 분석 | 경제성 평가 분석 |
|---|---|---|
| 핵심 질문 | 치료효과가 있는가? | 비용 대비 가치가 있는가? |
| 주요 결과 | p-value, 신뢰구간, 위험비, 평균 차이 | ICER, INB, QALY, 비용효과수용곡선 |
| 주된 기준 | 통계적 유의성 | 기대가치와 의사결정 기준 |
| 시간 범위 | 임상시험 추적기간 중심 | 장기 또는 생애기간 가능 |
| 자료원 | 주로 임상시험 자료 | 임상시험, 문헌, 청구자료, 비용자료, 효용자료 |
| 불확실성 표현 | 신뢰구간, p-value | PSA, 비용효과평면, CEAC, VOI |
| 관점 | 과학적 검증 | 자원배분 의사결정 |

### 가설검정과 의사결정의 차이

확증적 임상시험에서는 보통 귀무가설과 대립가설을 설정한다.

$$
H_0:\Delta H=0,
\qquad
H_1:\Delta H\neq0.
$$

우월성 시험에서는 다음과 같이 설정할 수 있다.

$$
H_0:\Delta H\leq0,
\qquad
H_1:\Delta H>0.
$$

하지만 경제성 평가의 의사결정 문제는 다음과 같이 표현하는 것이 더 자연스럽다.

$$
\text{Choose new drug if }\quad
\mathbb{E}\{NB_1(\lambda)\}>\mathbb{E}\{NB_0(\lambda)\}.
$$

동일하게 증분순편익으로 표현하면 다음과 같다.

$$
\text{Choose new drug if }\quad
\mathbb{E}\{INB(\lambda)\}>0.
$$

이 식은 경제성 평가가 통계적 유의성보다 기대순편익의 최대화에 초점을 둔다는 점을 보여준다.


### 분석 estimand의 차이

확증적 임상시험은 대개 사전에 정의된 임상 평가변수의 치료효과를 추정한다. 반면 경제성 평가는 동일한 환자집단에서 장기간 누적되는 비용과 건강효과의 평균을 추정해야 한다. 따라서 두 분석의 estimand가 다를 수 있다.

임상시험의 대표적인 효과 estimand를 다음과 같이 쓸 수 있다.

$$
\theta_H
=\mathbb{E}(H_1-H_0).
$$

경제성 평가의 의사결정 estimand는 비용을 결합한 다음 값이다.

$$
\theta_{NB}(\lambda)
=\mathbb{E}\{\lambda(H_1-H_0)-(C_1-C_0)\}.
$$

임상적 효과가 양수이더라도 비용 증가가 더 크면 $\theta_{NB}(\lambda)$는 음수가 될 수 있다. 반대로 효과의 불확실성이 크더라도 기대순편익이 양수이면 현재 근거에서 신약을 선택하는 것이 기대가치를 높일 수 있다.

### 임상시험 이후의 외삽과 자료결합

임상시험은 제한된 추적기간을 갖기 때문에 경제성 평가에서는 관찰기간 이후의 생존, 치료 지속, 이상반응, 자원 사용을 외삽해야 하는 경우가 많다. 임상시험 자료를 $D_{trial}$, 외부 자료를 $D_{ext}$라고 하면 장기 모형의 모수는 두 자료원을 결합하여 추정할 수 있다.

$$
p(\theta\mid D_{trial},D_{ext})
\propto
p(D_{trial},D_{ext}\mid\theta)p(\theta).
$$

빈도주의 접근에서도 외부 생존자료, 역학자료, 실제사용자료를 이용하여 기준 위험과 장기 전이확률을 보완할 수 있다. 이 과정에서는 자료원 간 환자구성, 치료환경, 측정정의가 다를 수 있으므로 구조적 가정이 명확해야 한다.

### 결측과 중도절단의 의미

임상시험의 임상효과 분석에서는 결측과 중도절단이 주요 문제이지만, 경제성 평가에서는 비용과 효용의 누적값도 동시에 누락될 수 있다. 특히 사망은 단순한 결측이 아니라 건강결과 과정의 일부이며, 사망 이후 효용은 0이고 일반적인 의료비는 더 이상 발생하지 않지만 사망 직전 비용이 집중될 수 있다.

따라서 임상 평가변수에 사용한 결측처리 방법을 비용과 QALY에 그대로 적용하는 것은 적절하지 않을 수 있다. 비용, 효용, 생존의 상호의존성을 고려한 공동 분석 또는 적절한 가중·다중대치 방법이 필요하다.

![확증적 임상시험 분석과 경제성 평가 분석은 서로 다른 질문에 답한다.](figures/ch02/fig-ch02-trial-vs-hee.png){width="92%"}


위 그림은 임상시험의 결과가 경제성 평가의 중요한 입력자료이지만 그 자체가 급여 결론은 아니라는 점을 보여준다. 임상시험에서 추정한 상대효과는 장기 생존, 삶의 질, 비용, 실제 진료환경의 환자구성, 의사결정 기준과 결합되어야 최종 가치평가로 이어진다.

### 통계적 유의성과 비용효과성은 다르다

어떤 신약의 치료효과가 통계적으로 유의하더라도 비용효과적이지 않을 수 있다. 반대로 임상시험에서 통계적 유의성이 충분히 확보되지 않았더라도, 현재 자료와 비용 구조를 고려할 때 기대순편익이 양수일 수 있다. 이러한 차이는 두 분석이 서로 다른 질문에 답하기 때문이다.

- 통계적 유의성: 관찰된 치료효과가 우연으로 설명되기 어려운가?
- 비용효과성: 치료효과와 비용을 고려할 때 이 치료를 선택하는 것이 기대가치를 높이는가?

::: {.callout-note}
## 핵심 메시지 {.unnumbered}

임상시험 분석은 근거의 존재를 평가하고, 경제성 평가는 의사결정의 가치를 평가한다. 두 분석은 상호보완적이지만 동일하지 않다.
:::

## 핵심 수식 정리 {#sec-ch2-key-equations .unnumbered}

| 개념 | 수식 |
|---|---|
| 분석 대상 인구집단의 평균 비용 | $\mu_{C,j}(\mathcal{P})=\mathbb{E}(C_j \mid X\in\mathcal{P})$ |
| 분석 대상 인구집단의 평균 효과 | $\mu_{H,j}(\mathcal{P})=\mathbb{E}(H_j \mid X\in\mathcal{P})$ |
| 할인 누적 비용 | $C_j(\tau;r_C)=\int_0^\tau c_j(t)(1+r_C)^{-t}\,dt$ |
| 할인 누적 효과 | $H_j(\tau;r_H)=\int_0^\tau h_j(t)(1+r_H)^{-t}\,dt$ |
| 증분비용 | $\Delta C=C_1-C_0$ |
| 증분효과 | $\Delta H=H_1-H_0$ |
| ICER | $ICER=\Delta C/\Delta H$ |
| 제한평균 생존시간 | $RMST(\tau)=\int_0^\tau S(t)\,dt$ |
| QALY | $Q(\tau)=\int_0^\tau u(t)I(T>t)\,dt$ |
| 상태 기반 QALY | $Q_j=\sum_k\sum_s p_{jsk}u_s\Delta_k(1+r_Q)^{-t_k}$ |
| 생존곡선 기반 QALY | $Q=\int_0^\tau[u_{PF}S_{PFS}(t)+u_{PD}\{S_{OS}(t)-S_{PFS}(t)\}](1+r_Q)^{-t}\,dt$ |
| 자원 사용량 기반 비용 | $C_j=\sum_m R_{jm}a_m$ |
| 순편익 | $NB_j(\lambda)=\lambda H_j-C_j$ |
| 증분순편익 | $INB(\lambda)=\lambda\Delta H-\Delta C$ |
| 비용효과적 조건 | $INB(\lambda)>0$ |
| CEAC 추정 | $M^{-1}\sum_{m=1}^M I\{INB^{(m)}(\lambda)>0\}$ |

## 핵심 용어 {#sec-ch2-key-terms .unnumbered}

| 용어 | 의미 |
|---|---|
| 분석 대상 인구집단 | 경제성 평가 모델이 직접 대상으로 삼는 환자집단 |
| 급여 대상 인구집단 | 실제 급여 의사결정이 적용되는 환자집단 |

| 비용효용분석 | 효과를 QALY로 측정하는 경제성 평가 |

| 비용효과평면 | 증분효과와 증분비용의 결합분포를 나타내는 평면 |

### 실습 1: ICER와 INB 계산하기 {.unnumbered}

```{r}
#| label: r-ch02-icer-inb
#| echo: true
#| eval: true

cost0 <- 20000000
cost1 <- 32000000
qaly0 <- 2.40
qaly1 <- 2.90
lambda <- 30000000

delta_cost <- cost1 - cost0
delta_qaly <- qaly1 - qaly0
icer <- delta_cost / delta_qaly
inb <- lambda * delta_qaly - delta_cost

result_icer <- data.frame(
  delta_cost = delta_cost,
  delta_qaly = delta_qaly,
  icer = icer,
  lambda = lambda,
  inb = inb,
  decision = ifelse(inb > 0, "신약 선택", "기존 치료 선택")
)

result_icer
```

위 예제에서는 ICER가 24,000,000원/QALY이고, 지불의사금액이 30,000,000원/QALY이면 증분순편익이 양수이다.

### 실습 2: 분석 기간과 할인 적용 {.unnumbered}

```{r}
#| label: r-ch02-time-horizon-discount
#| echo: true
#| eval: true

cycle <- 1:10
r_cost <- 0.045
r_qaly <- 0.045

cost_new <- c(25000000, rep(3000000, 9))
cost_comp <- rep(4500000, 10)
qaly_new <- c(0.78, 0.76, 0.73, 0.70, 0.66, 0.62, 0.58, 0.54, 0.50, 0.46)
qaly_comp <- c(0.70, 0.66, 0.61, 0.56, 0.50, 0.44, 0.38, 0.32, 0.26, 0.20)

disc_cost <- 1 / (1 + r_cost)^(cycle - 0.5)
disc_qaly <- 1 / (1 + r_qaly)^(cycle - 0.5)

summary_horizon <- data.frame(
  horizon = cycle,
  cum_cost_new = cumsum(cost_new * disc_cost),
  cum_cost_comp = cumsum(cost_comp * disc_cost),
  cum_qaly_new = cumsum(qaly_new * disc_qaly),
  cum_qaly_comp = cumsum(qaly_comp * disc_qaly)
)

summary_horizon$delta_cost <- summary_horizon$cum_cost_new - summary_horizon$cum_cost_comp
summary_horizon$delta_qaly <- summary_horizon$cum_qaly_new - summary_horizon$cum_qaly_comp
summary_horizon$icer <- summary_horizon$delta_cost / summary_horizon$delta_qaly

round(summary_horizon[, c("horizon", "delta_cost", "delta_qaly", "icer")], 2)
```

이 코드는 분석 기간이 길어질수록 증분비용, 증분 QALY, ICER가 어떻게 바뀌는지를 보여준다.

### 실습 5: 확률론적 민감도 분석에서 CEAC 계산하기 {.unnumbered}

```{r}
#| label: r-ch02-ceac
#| echo: true
#| eval: true
#| fig-cap: "비용효과수용곡선 예제"
#| fig-width: 7
#| fig-height: 4.5

set.seed(123)
M <- 5000

delta_qaly <- rnorm(M, mean = 0.45, sd = 0.15)
delta_cost <- rnorm(M, mean = 12000000, sd = 6500000)

lambda_grid <- seq(0, 60000000, by = 1000000)
ce_prob <- sapply(lambda_grid, function(lambda) {
  mean(lambda * delta_qaly - delta_cost > 0)
})

ceac <- data.frame(
  lambda = lambda_grid,
  probability_cost_effective = ce_prob
)

head(ceac)
tail(ceac)

plot(lambda_grid / 1000000, ce_prob, type = "l", lwd = 2,
     xlab = "Willingness-to-pay threshold (million KRW/QALY)",
     ylab = "Probability cost-effective",
     main = "Cost-effectiveness acceptability curve")
abline(h = c(0.5, 0.8, 0.95), lty = 3)
```

CEAC는 지불의사금액이 변할 때 신약의 증분순편익이 양수일 확률이 어떻게 변하는지 보여준다.
