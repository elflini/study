10.1 서론

10.1.1 표준 모수적 생존모형의 한계

표준 모수적 생존모형은 생존시간 \(T\)의 분포를 소수의 모수로 표현한다. 예를 들어 exponential 모형은 일정한 위험함수를 가정한다.

\[ h(t)=\lambda. \]

Weibull 모형은 shape-scale 모수화에서 다음과 같이 표현할 수 있다.

\[ S(t)=\exp\left[-\left(\frac{t}{\lambda}\right)^k\right], \qquad h(t)=\frac{k}{\lambda}\left(\frac{t}{\lambda}\right)^{k-1}. \]

이때 \(k>1\)이면 위험함수는 단조 증가하고, \(k<1\)이면 단조 감소하며, \(k=1\)이면 exponential 모형이 된다. Gompertz 모형은 위험함수가 시간에 따라 지수적으로 변한다고 가정한다.

\[ h(t)=\lambda\exp(\gamma t). \]

이러한 모형은 단순하고 안정적이지만 위험함수의 형태에 제약이 있다. 예를 들어 Weibull 모형은 위험이 증가하다가 감소하는 형태를 표현할 수 없고, exponential 모형은 치료 초기와 장기 추적기간의 위험 차이를 설명할 수 없다. 그러나 실제 생존자료에서는 다음과 같은 양상이 자주 나타난다.

  • 치료 초기 독성 또는 질병 부담 때문에 초기 위험이 높다가 이후 낮아지는 경우
  • 일정 기간 후 재발 또는 진행 위험이 다시 증가하는 경우
  • 면역항암제처럼 치료효과가 지연되어 생존곡선이 뒤늦게 분리되는 경우
  • 장기 생존자가 존재하여 생존곡선 꼬리가 완만해지는 경우
  • 서로 다른 예후를 가진 잠재적 하위집단이 섞여 있는 경우

경제성 평가에서 이러한 제한은 단순한 통계적 적합도 문제가 아니다. 생존외삽은 다음 적분을 통해 기대 생존기간과 기대 QALY를 결정한다.

\[ \operatorname{RMST}(\tau)=\int_0^\tau S(t)dt, \]

\[ Q(\tau)=\int_0^\tau u(t)S(t)dt, \]

여기서 \(u(t)\)는 시간 \(t\)에서의 효용가중치이다. 관찰기간 이후 생존곡선의 꼬리가 조금만 달라져도 \(\operatorname{RMST}\)와 \(Q\)는 크게 달라질 수 있고, 이는 ICER에 직접적인 영향을 준다.

이 그림에서 확인해야 할 핵심은 관찰구간의 시각적 적합도가 아니라 분석기간 전체에서 두 곡선 사이에 누적되는 면적 차이이다. 경제성 평가에서는 이 면적 차이가 기대 생존기간과 QALY 차이로 직접 변환된다.

10.1.2 유연한 생존모형이 필요한 상황

유연한 생존모형은 다음 상황에서 고려할 수 있다.

상황 표준 모형의 한계 고려 가능한 모형
위험함수가 비단조적임 Weibull, Gompertz가 부적절할 수 있음 Flexible parametric model, spline model
치료효과가 시간에 따라 변함 비례위험 가정이 부적절함 Time-varying effect model, landmark model
장기 생존자가 존재함 모든 환자의 질병 관련 위험이 결국 계속된다는 가정이 부적절할 수 있음 Cure model, relative survival model
환자집단이 이질적임 단일 분포가 평균적 패턴만 설명함 Mixture model
특정 시점 이후 다른 자료원을 써야 함 단일 외삽식이 임상적으로 부적절함 Piecewise model, external-data anchored model
임상시험 추적기간이 짧음 꼬리 부분 추정이 불안정함 External data, cure/mixture/piecewise scenario analysis
Warning유연성의 역설

모형이 유연할수록 관찰기간 내 자료에는 더 잘 맞을 수 있다. 그러나 장기 외삽에서는 작은 형태 차이가 큰 QALY 차이로 확대된다. 따라서 유연한 생존모형은 “더 좋은 모형”이 아니라 “더 많은 판단과 검증이 필요한 모형”이다.

10.1.3 생존외삽의 일반적 우도 구조

중도절단 생존자료에서 환자 \(i\)의 관찰값을 \((t_i,\delta_i,x_i)\)라고 하자. 여기서 \(t_i\)는 관찰시간, \(\delta_i=1\)은 사건 발생, \(\delta_i=0\)은 중도절단, \(x_i\)는 공변량이다. 생존함수를 \(S(t\mid x_i;\theta)\), 밀도함수를 \(f(t\mid x_i;\theta)\), 위험함수를 \(h(t\mid x_i;\theta)\)라고 하면 개별 가능도 기여분은 다음과 같다.

\[ L_i(\theta)=f(t_i\mid x_i;\theta)^{\delta_i}S(t_i\mid x_i;\theta)^{1-\delta_i}. \]

\(f(t)=h(t)S(t)\)이므로 같은 식을 다음과 같이 쓸 수 있다.

\[ L_i(\theta)=h(t_i\mid x_i;\theta)^{\delta_i}S(t_i\mid x_i;\theta). \]

전체 로그가능도는 다음과 같다.

\[ \ell(\theta)=\sum_{i=1}^n\left[\delta_i\log h(t_i\mid x_i;\theta)+\log S(t_i\mid x_i;\theta)\right]. \]

유연한 생존모형은 결국 \(S(t)\), \(H(t)\) 또는 \(h(t)\)의 형태를 더 넓은 함수공간에서 표현하는 방법이다. 다만 외삽이 목적일 때는 관찰구간 밖에서도 임상적으로 타당한 함수 형태를 가져야 한다.

10.1.4 유연성, 근사오차와 추정오차

유연한 생존모형은 미리 정해진 하나의 분포를 선택하기보다, 기저함수의 선형결합을 이용하여 실제 위험 구조를 근사한다. 일반적으로 어떤 변환된 생존량을 \(g(t)\)라고 할 때 다음과 같이 표현할 수 있다.

\[ g(t)=\sum_{k=1}^{K}\gamma_k b_k(t), \]

여기서 \(b_k(t)\)는 spline 또는 구간지시함수와 같은 기저함수이고, \(K\)는 모형의 복잡도를 결정한다. \(K\)가 너무 작으면 실제 곡률을 표현하지 못해 근사편향이 커지고, \(K\)가 너무 크면 사건이 적은 구간의 우연한 변동까지 따라가 추정분산이 커진다. 이를 개념적으로 나타내면 예측오차는 다음 세 부분으로 나눌 수 있다.

\[ \mathbb{E}\{(\widehat g(t)-g_0(t))^2\} = \operatorname{Bias}\{\widehat g(t)\}^2 + \operatorname{Var}\{\widehat g(t)\} + \sigma^2_{\text{irreducible}}. \]

관찰구간 안에서는 자유도를 늘리면 편향이 줄어드는 경우가 많지만, 외삽구간에서는 자료가 없기 때문에 분산뿐 아니라 함수의 경계조건과 꼬리 가정이 결과를 지배한다. 따라서 유연성 선택은 단순한 적합도 최적화가 아니라, 관찰자료가 제공하는 정보량과 장기 구조 가정 사이의 균형을 정하는 과정이다.

10.1.5 외삽 구간의 부분식별

최대 추적시점을 \(t_{\max}\)라고 하면 자료의 가능도는 주로 \(0\le t\le t_{\max}\)에서의 생존곡선을 식별한다. 두 모형 \(M_1\)과 \(M_2\)가 관찰구간에서 거의 같은 생존함수를 갖더라도,

\[ S_1(t)\approx S_2(t),\qquad 0\le t\le t_{\max}, \]

관찰구간 이후에는 서로 다른 값을 가질 수 있다.

\[ S_1(t)\ne S_2(t),\qquad t>t_{\max}. \]

따라서 전체 기대 생존기간은 다음처럼 관찰부분과 외삽부분으로 분해하는 것이 유용하다.

\[ \int_0^{\tau}S(t)dt = \int_0^{t_{\max}}S(t)dt + \int_{t_{\max}}^{\tau}S(t)dt. \]

첫 번째 항은 자료에 비교적 강하게 지지되지만 두 번째 항은 모형 구조, 외부자료, 일반인 사망률과 임상적 판단에 더 크게 의존한다. 이 의미에서 장기 평균 생존기간과 QALY는 완전히 비모수적으로 식별되는 양이 아니라, 자료와 외삽 가정을 함께 사용하여 부분적으로 식별되는 의사결정 입력값이다.

10.1.6 지연진입과 구간중도절단을 포함한 우도

모든 생존자료가 단순한 우측중도절단 형태인 것은 아니다. 환자 \(i\)가 시간 \(e_i\) 이후에 위험집합에 들어오는 좌측절단 자료에서는 조건부 가능도 기여분이 다음과 같다.

\[ L_i(\theta) = \frac{f(t_i;\theta)^{\delta_i}S(t_i;\theta)^{1-\delta_i}} {S(e_i;\theta)}. \]

사건시간이 구간 \((L_i,R_i]\) 안에 있다는 것만 알려진 구간중도절단 자료의 기여분은

\[ L_i(\theta)=S(L_i;\theta)-S(R_i;\theta) \]

가 된다. 유연한 모형은 함수 형태뿐 아니라 관찰과정을 정확하게 우도에 반영해야 한다. 지연진입이나 구간중도절단을 무시하면 spline의 유연성이 커도 기저위험과 장기 외삽이 편향될 수 있다.

위험함수의 봉우리와 굴곡은 질병 자연사, 치료 초기 독성, 지연 치료효과 또는 생존자 구성의 변화를 반영할 수 있다. 후반부의 굴곡은 위험집합이 작은 데서 생긴 우연한 변동일 수도 있으므로 number at risk와 함께 해석해야 한다.

10.2 Flexible parametric model

10.2.1 기본 아이디어

Flexible parametric survival model은 생존함수, 누적위험함수 또는 위험함수의 특정 변환을 spline 함수로 표현하는 모형이다. 경제성 평가에서 가장 자주 언급되는 형태는 Royston–Parmar 모형이다. 이 모형은 로그 누적위험함수를 로그 시간의 restricted cubic spline으로 표현한다.

\[ \eta(t\mid x)=\log H(t\mid x)=s_0(\log t;\gamma)+x^T\beta. \]

여기서 \(H(t\mid x)\)는 누적위험함수이고, \(s_0(\log t;\gamma)\)는 로그 시간에 대한 spline 함수이다. 따라서 생존함수는 다음과 같다.

\[ S(t\mid x)=\exp\{-H(t\mid x)\} =\exp\left[-\exp\{s_0(\log t;\gamma)+x^T\beta\}\right]. \]

공변량 효과가 시간과 무관하게 더해지는 위 구조에서는 누적위험비가 다음과 같이 일정하다.

\[ \frac{H(t\mid x=1)}{H(t\mid x=0)}=\exp(\beta). \]

로그 누적위험 척도에서 \(\exp(\beta)\)는 cumulative hazard ratio이다. 시간-의존 효과가 없고 모형 구조가 적절하면 instantaneous hazard ratio 역시 일정한 비례위험 구조로 해석될 수 있다. 그러나 시간-의존 효과를 포함하면 cumulative hazard ratio와 instantaneous hazard ratio의 구분이 중요해진다.

10.2.2 모형화 척도와 암묵적 효과 가정

Flexible parametric model은 어떤 변환을 spline으로 표현하느냐에 따라 서로 다른 회귀구조를 갖는다. 로그 누적위험 척도는 비례위험 구조와 연결된다.

\[ \log H(t\mid x)=s(\log t)+x^T\beta. \]

반면 로그 누적오즈 척도를 사용하면 다음과 같은 비례오즈 구조가 된다.

\[ \log\left\{\frac{1-S(t\mid x)}{S(t\mid x)}\right\} =s(\log t)+x^T\beta. \]

이 경우 \(\exp(\beta)\)는 사건 누적오즈의 비를 나타낸다. 정규 분위수 척도에서는

\[ \Phi^{-1}\{1-S(t\mid x)\}=s(\log t)+x^T\beta \]

와 같이 표현할 수 있다. 이러한 모형들은 관찰기간 안에서 비슷한 적합도를 보일 수 있지만, 꼬리에서의 선형성 제약이 서로 다른 생존형태로 변환되기 때문에 장기 외삽은 달라질 수 있다. 따라서 spline 자유도뿐 아니라 모형화 척도 자체도 구조적 불확실성의 원천이다.

10.2.3 Spline 함수와 knot

Restricted cubic spline은 로그 시간축 \(z=\log t\) 위에서 다음과 같은 형태로 표현할 수 있다.

Restricted cubic spline은 경계 knot 밖에서 함수가 선형이 되도록 제약한 cubic spline이다. 내부 knot를 \(\kappa_1<\cdots<\kappa_K\)라고 하면, 한 가지 truncated-power 표현은 다음과 같다.

\[ s(z)=\gamma_0+\gamma_1z+\sum_{j=1}^{K-2}\gamma_{j+1}d_j(z), \]

\[ d_j(z) =(z-\kappa_j)_+^3 -\frac{\kappa_K-\kappa_j}{\kappa_K-\kappa_{K-1}}(z-\kappa_{K-1})_+^3 +\frac{\kappa_{K-1}-\kappa_j}{\kappa_K-\kappa_{K-1}}(z-\kappa_K)_+^3, \]

여기서 \((a)_+=\max(a,0)\)이다. 이 선형 제약은 경계 밖의 세제곱 발산을 억제하지만, 로그 누적위험 척도에서 선형이라는 조건이 생존확률 척도에서 완만한 꼬리를 보장하는 것은 아니다. 경계 기울기는 장기 누적위험의 증가속도를 결정하므로 마지막 knot 부근의 사건 수가 적을 때 특히 불안정할 수 있다.

\[ s_0(z;\gamma)=\gamma_0+\gamma_1z+\sum_{m=1}^{M}\gamma_{m+1}b_m(z), \]

여기서 \(b_m(z)\)는 knot 위치에 의해 정의되는 spline basis 함수이다. 제한 cubic spline은 양쪽 꼬리에서 선형성을 갖도록 제약되어 있어, 관찰범위 밖에서 과도한 굴곡을 줄이는 데 도움을 준다.

Knot 수 또는 자유도는 모형의 유연성을 결정한다. 자유도가 작으면 모형은 안정적이지만 복잡한 위험 패턴을 설명하기 어렵다. 자유도가 크면 관찰자료에는 잘 맞을 수 있지만 외삽이 불안정해질 수 있다.

Knot 위치는 보통 사건시간 분포의 분위수에 배치하지만, 이는 관찰구간 내 적합을 위한 경험적 규칙이다. 후반부 위험집합이 작으면 마지막 몇 개 knot가 소수의 사건에 의해 결정될 수 있다. 사건 수를 \(D\), 추정모수 수를 \(p\)라고 할 때 \(D/p\)가 작아질수록 분산과 수렴 문제가 커진다. 정확한 절대 기준은 없지만, 후보 자유도를 늘릴 때 다음을 함께 확인해야 한다.

  • 마지막 추적구간에서 spline 계수의 표준오차와 상관성이 급격히 커지는가?
  • 예측 생존함수가 단조 감소하고 누적위험함수가 단조 증가하는가?
  • 장기 위험이 0, 무한대 또는 일반인 위험 이하로 비현실적으로 수렴하는가?
  • 작은 knot 이동만으로 RMST와 ICER가 크게 변하는가?

이 점검은 정보기준보다 외삽 안정성에 직접 관련된다.

Spline 곡선은 knot 사이에서는 유연하지만 경계 밖에서는 제한조건에 따라 단순한 형태로 이어진다. 따라서 마지막 knot 이후의 기울기가 장기 누적위험을 어떻게 결정하는지 확인하는 것이 중요하다.

TipKnot 수 선택

Knot 수는 AIC나 BIC만으로 결정하지 않는 것이 좋다. 후보 knot 수별 생존곡선, 위험함수, 장기 생존율, RMST, ICER를 함께 비교하고, number at risk가 매우 적은 후반부의 굴곡을 과도하게 따라가지 않는지 확인해야 한다.

10.2.4 위험함수의 계산

Royston–Parmar 모형에서 \(H(t\mid x)=\exp\{\eta(t\mid x)\}\)이다. 위험함수는 누적위험함수의 도함수이므로 다음과 같다.

\[ h(t\mid x)=\frac{dH(t\mid x)}{dt}=H(t\mid x)\frac{\partial \eta(t\mid x)}{\partial t}. \]

공변량 효과가 시간과 무관하고 \(z=\log t\)이면,

\[ \frac{\partial \eta(t\mid x)}{\partial t}=\frac{1}{t}\frac{\partial s_0(z;\gamma)}{\partial z}. \]

따라서 위험함수는 다음과 같이 표현된다.

\[ h(t\mid x)=\frac{H(t\mid x)}{t}s_0'(\log t;\gamma). \]

이 식은 flexible parametric model에서 위험함수의 장기 형태가 spline의 도함수에 의해 결정됨을 보여준다. 생존곡선은 단조 감소하더라도, 위험함수의 장기 형태가 임상적으로 부자연스러울 수 있으므로 반드시 함께 확인해야 한다.

로그 누적위험 모형이 유효하려면 \(H(t)\)가 증가함수여야 하므로

\[ \frac{\partial \eta(t)}{\partial t}\ge 0 \]

가 필요하다. 일반적인 restricted cubic spline 적합은 관찰된 시간범위에서 대체로 이 조건을 만족하도록 추정되지만, 수치오차나 과도한 자유도 때문에 국소적으로 음의 위험이 계산되는지 확인해야 한다. 단조성을 명시적으로 보장해야 하는 경우에는 I-spline, monotone spline 또는 양의 위험함수를 직접 모형화하는 접근을 사용할 수 있다.

장기 꼬리는 경계에서 \(s_0'(\log t)\)가 어떤 값으로 수렴하는지에 의해 결정된다. 경계 밖에서

\[ s_0(\log t)\approx a+b\log t \]

이면

\[ H(t)\approx e^a t^b, \qquad h(t)\approx e^a b t^{b-1}. \]

즉, 로그 누적위험 척도의 restricted cubic spline은 최종적으로 Weibull과 유사한 꼬리 거동을 갖는다. 유연한 모형도 관찰구간 밖에서는 완전히 자유로운 것이 아니라 경계 제약이 암묵적인 장기 분포 가정으로 작동한다.

10.2.5 비례위험 형태와 시간-의존 치료효과

치료변수 \(x\)가 이진변수라고 하자. 비례위험 형태의 flexible parametric model은 다음과 같다.

\[ \eta(t\mid x)=s_0(\log t;\gamma)+x\beta. \]

반면 치료효과가 시간에 따라 변할 수 있도록 하려면 다음과 같이 치료와 시간 spline의 상호작용을 포함할 수 있다.

\[ \eta(t\mid x)=s_0(\log t;\gamma)+x\beta+x s_1(\log t;\alpha). \]

이때 누적위험비는 다음과 같다.

\[ \frac{H(t\mid x=1)}{H(t\mid x=0)}=\exp\{\beta+s_1(\log t;\alpha)\}. \]

하지만 instantaneous hazard ratio는 일반적으로 다음과 같이 도함수 항까지 포함한다.

\[ HR(t)=\frac{h(t\mid x=1)}{h(t\mid x=0)} =\exp\{\beta+s_1(\log t;\alpha)\}\frac{\partial \eta(t\mid x=1)/\partial t}{\partial \eta(t\mid x=0)/\partial t}. \]

따라서 시간-의존 효과를 가진 flexible parametric model을 보고할 때는 단일 HR만 제시하기보다 시간별 생존함수, 시간별 위험함수, 시간별 HR 또는 cumulative hazard ratio를 함께 제시하는 것이 바람직하다.

시간가변 효과는 spline 계수의 집합으로 표현되므로 개별 계수의 해석보다는 함수 전체에 대한 검정과 예측이 중요하다. 시간가변 항이 없는 모형을 \(M_0\), 있는 모형을 \(M_1\)이라고 하면 우도비 검정통계량은

\[ 2\{\ell(M_1)-\ell(M_0)\} \]

이며, 정규성 조건 아래 추가된 시간상호작용 자유도에 해당하는 카이제곱분포와 비교할 수 있다. 그러나 검정력이 낮거나 임상적으로 작은 위반도 장기 QALY에는 큰 영향을 줄 수 있으므로, 유의확률만으로 비례위험 구조를 결정해서는 안 된다.

또한 조건부 생존곡선만 제시하면 공변량 분포가 다른 모집단으로 결과를 옮기기 어렵다. 목표 모집단의 공변량 분포가 \(F_X\)일 때 치료전략 \(a\)의 표준화 생존함수는

\[ S_a^{\mathrm{std}}(t)=\int S(t\mid A=a,X=x)dF_X(x) \]

로 정의된다. 표본자료에서는

\[ \widehat S_a^{\mathrm{std}}(t) =\frac{1}{n}\sum_{i=1}^{n}\widehat S(t\mid A=a,X=x_i) \]

로 계산한다. 이 표준화는 비선형 모형에서 평균 공변량을 대입한 생존곡선과 일반적으로 같지 않으며, 경제성 평가의 목표 인구집단에 맞춘 절대 생존편익을 제공한다.

시간가변 치료효과에서는 두 군의 곡선이 늦게 분리되거나 다시 가까워질 수 있다. 이때 단일 위험비는 치료효과의 시간적 패턴을 숨기므로 시점별 생존차, RMST 차이와 함께 평가해야 한다.

10.2.6 경제성 평가에서의 활용

Flexible parametric model은 다음 방식으로 경제성 평가에 사용된다.

  1. 각 치료군에 독립적으로 적합한다.
  2. 치료군을 공변량으로 포함하여 공동 적합한다.
  3. 비례위험 구조 또는 시간-의존 치료효과 구조를 비교한다.
  4. spline 자유도를 바꾸어 시나리오 분석을 수행한다.
  5. 외부 registry, 자연사 자료, 일반인 사망률과 장기 외삽을 비교한다.
  6. 생존곡선뿐 아니라 위험함수를 경제성 평가 보고서에 포함한다.

독립 적합은 두 군의 생존곡선 형태를 자유롭게 허용하지만 군 간 관계에 대한 통계적 정보를 덜 활용한다. 공동 적합은 더 안정적일 수 있으나 치료효과 구조를 명시적으로 가정해야 한다. 어느 접근이 더 적절한지는 생존곡선의 형태, 비례위험 가정, 임상적 치료효과 지속 가정, 외부 자료와의 일관성에 따라 판단해야 한다.

10.2.7 벌점화와 유효 자유도

사건 수에 비해 spline 자유도가 크거나 시간가변 효과를 함께 포함하면 일반 최대가능도 추정이 불안정할 수 있다. 벌점화 spline은 굴곡의 크기에 제약을 두어 이를 완화한다.

\[ \ell_p(\gamma,\beta) = \ell(\gamma,\beta) - \frac{\lambda}{2}\gamma^T K\gamma, \]

여기서 \(K\)는 곡률을 측정하는 벌점행렬이고 \(\lambda\)는 평활모수이다. \(\lambda\)가 클수록 함수는 단순해지고, 작을수록 자료의 세부 변동을 더 많이 따라간다. 이때 실제 복잡도는 기저함수 개수 자체가 아니라 평활에 의해 축소된 유효 자유도로 해석한다.

벌점화는 과적합을 줄일 수 있지만 외삽 근거를 새로 만들어 주지는 않는다. 관찰구간 밖의 꼬리는 여전히 기저함수의 경계조건과 외부 제약에 의해 결정된다. 따라서 교차검증이나 AIC로 평활모수를 정하더라도 장기 생존율과 위험함수의 임상적 검토가 별도로 필요하다.

10.3 Mixture model

10.3.1 기본 아이디어

Mixture survival model은 전체 환자집단이 하나의 균질한 생존분포를 따르는 것이 아니라, 서로 다른 생존 특성을 가진 잠재적 하위집단의 혼합으로 구성되어 있다고 가정한다. \(G\)개의 성분이 있는 mixture model은 다음과 같이 쓸 수 있다.

\[ S(t)=\sum_{g=1}^{G}\pi_g S_g(t), \qquad \sum_{g=1}^{G}\pi_g=1, \qquad \pi_g\ge 0. \]

두 성분인 경우에는 다음과 같다.

\[ S(t)=\pi S_1(t)+(1-\pi)S_2(t). \]

여기서 \(S_1(t)\)와 \(S_2(t)\)는 각각 잠재 하위집단의 생존함수이고, \(\pi\)는 첫 번째 성분에 속할 사전 확률이다. 각 성분은 Weibull, log-normal, log-logistic 또는 spline 기반 생존함수로 설정할 수 있다.

혼합곡선의 긴 꼬리는 반드시 완치 환자의 존재를 의미하지 않는다. 서로 다른 사건속도를 가진 두 비완치 성분이 섞여 있어도 같은 형태가 나타날 수 있다.

10.3.2 Mixture model의 위험함수

Mixture model에서는 밀도함수도 성분별 밀도의 가중합이다.

\[ f(t)=\sum_{g=1}^{G}\pi_g f_g(t). \]

따라서 population-level 위험함수는 다음과 같다.

\[ h(t)=\frac{f(t)}{S(t)} =\frac{\sum_{g=1}^{G}\pi_g f_g(t)}{\sum_{g=1}^{G}\pi_g S_g(t)}. \]

\(f_g(t)=h_g(t)S_g(t)\)를 이용하면,

\[ h(t)=\sum_{g=1}^{G}w_g(t)h_g(t), \]

여기서

\[ w_g(t)=\frac{\pi_g S_g(t)}{\sum_{r=1}^{G}\pi_r S_r(t)} \]

는 시간 \(t\)까지 생존한 환자가 성분 \(g\)에 속할 조건부 확률이다. 이 식은 mixture model의 중요한 직관을 제공한다. 시간이 지남에 따라 고위험 성분의 환자는 더 빨리 사건을 경험하므로, 생존자 중 저위험 성분의 비중이 커진다. 따라서 population-level hazard는 시간이 지남에 따라 감소하거나 복잡한 형태를 보일 수 있다.

이 가중치는 베이즈 정리를 적용한 사후 성분확률이다. 사건이 시간 \(t\)에 발생한 환자의 성분확률은 생존자에서의 가중치와 다르며 다음과 같다.

\[ P(G=g\mid T=t) = \frac{\pi_g f_g(t)}{\sum_r\pi_r f_r(t)}. \]

따라서 “현재까지 생존한 환자가 어느 성분에 속하는가”와 “이 시점에 사건을 경험한 환자가 어느 성분에 속하는가”는 서로 다른 조건부 질문이다. 동적 예측이나 하위집단별 비용을 계산할 때 두 확률을 혼동하면 안 된다.

혼합분포의 평균 생존시간이 존재한다면 선형성에 의해

\[ \mathbb{E}(T)=\sum_{g=1}^{G}\pi_g\mathbb{E}(T\mid G=g) \]

가 된다. 그러나 혼합위험함수는 성분별 위험함수의 고정 가중평균이 아니라 \(w_g(t)\)가 시간에 따라 변하는 가중평균이다. 이 차이 때문에 성분별로 모두 단조 위험을 갖더라도 전체 위험은 비단조가 될 수 있다.

시간이 지날수록 저위험 성분의 조건부 비중이 증가하는 것은 선택된 생존자 구성의 변화이다. 전체 위험의 감소를 개인 수준의 위험 감소로 곧바로 해석해서는 안 된다.

10.3.3 Mixture model의 가능도

개별 환자 \(i\)의 관찰자료가 \((t_i,\delta_i)\)일 때, \(G\)성분 mixture model의 가능도 기여분은 다음과 같다.

\[ L_i=\left\{\sum_{g=1}^{G}\pi_g f_g(t_i)\right\}^{\delta_i} \left\{\sum_{g=1}^{G}\pi_g S_g(t_i)\right\}^{1-\delta_i}. \]

전체 가능도는 다음과 같다.

\[ L=\prod_{i=1}^{n}L_i. \]

모형은 직접 최대가능도법으로 적합할 수도 있고, 잠재 성분 소속을 결측자료로 보는 EM 알고리즘으로 적합할 수도 있다. 다만 성분 수가 늘어나면 식별성이 약해지고, 서로 다른 초기값에서 다른 해로 수렴할 수 있다.

잠재 성분지시자를 \(Z_{ig}\in\{0,1\}\)라고 하면 완전자료 로그가능도는

\[ \ell_c = \sum_{i=1}^{n}\sum_{g=1}^{G}Z_{ig} \left[ \log\pi_g +\delta_i\log f_g(t_i) +(1-\delta_i)\log S_g(t_i) \right] \]

이다. EM 알고리즘의 E-step에서는 현재 모수에서 \(Z_{ig}\)의 조건부 기대값을 계산하고, M-step에서는 이를 가중치로 사용하여 혼합비율과 성분모수를 갱신한다. 중도절단된 관찰의 사후 성분확률은 \(\pi_gS_g(t_i)\)에 비례하고, 사건 관찰은 \(\pi_gf_g(t_i)\)에 비례한다.

혼합모형에는 다음과 같은 식별 문제가 있다.

  1. 두 성분의 분포가 유사하면 혼합비율과 성분모수를 분리하기 어렵다.
  2. 성분 라벨을 바꾸어도 같은 가능도를 얻는 label switching이 존재한다.
  3. 한 성분의 분산이 극단적으로 작아지거나 소수 관찰을 독점하면 국소 최댓값이 생길 수 있다.
  4. 추적기간이 짧으면 장기 생존 성분과 cure 성분을 구별하기 어렵다.

따라서 여러 초기값, 프로파일 가능도, 부트스트랩, 베이지안 사후분포 등을 통해 수렴과 식별성을 확인해야 한다. 정보기준이 성분 수를 지지하더라도 성분별 장기 생존이 임상적으로 설명되지 않으면 경제성 평가의 기본분석으로 사용하기 어렵다.

10.3.4 경제성 평가에서의 해석과 주의점

Mixture model은 단일 분포가 초기 위험과 장기 꼬리를 동시에 설명하지 못할 때 유용하다. 하지만 잠재 성분은 통계적 구성물이며, 반드시 실제 생물학적 하위집단과 일치하지 않는다. 바이오마커, 반응 여부, 병기, 치료순응도 등으로 실제 하위집단을 설명할 수 없다면, mixture 성분을 임상적으로 독립된 환자군으로 해석하는 데 주의해야 한다.

Mixture survival model과 mixture cure model은 수학적 형태가 비슷하지만 목적이 다르다. 일반 mixture model에서는 모든 성분이 결국 사건을 경험할 수 있어

\[ \lim_{t\to\infty}S_g(t)=0 \]

이고 따라서 전체 생존함수도 0으로 수렴한다. 반면 mixture cure model에서는 한 성분의 질병 관련 생존함수가 1로 유지되어 상대생존이 양의 plateau로 수렴한다. 제한된 추적자료에서는 매우 긴 꼬리를 가진 일반 mixture와 cure model이 거의 같은 적합도를 보일 수 있으므로, 두 모형의 구분은 통계적 적합도보다 외부 장기근거에 의존한다.

WarningMixture model의 해석상 주의

Mixture model의 성분은 관찰된 생존곡선을 설명하기 위해 도입된 잠재 구조이다. 성분별 생존곡선이 임상적으로 그럴듯해 보여도, 외부 근거 없이 “반응군”과 “비반응군”으로 직접 해석하면 안 된다.

경제성 평가에서는 다음을 점검해야 한다.

  • 성분 수가 자료와 임상지식으로 정당화되는가?
  • 장기 생존 성분의 비율이 과대추정되지 않았는가?
  • 각 성분의 장기 위험함수가 외부 자료와 일치하는가?
  • mixture model 선택이 증분 QALY와 ICER에 얼마나 영향을 주는가?
  • 성분별 모수의 불확실성을 PSA에 반영했는가?

10.4 Landmark model

10.4.1 기본 아이디어

Landmark model은 특정 시점 \(t_L\)을 기준으로, 그 시점까지 생존하거나 특정 상태에 도달한 환자만을 대상으로 이후 생존을 모델링하는 접근이다. 예를 들어 6개월 시점의 종양반응 여부가 이후 생존을 예측한다고 판단되면, 6개월을 landmark time으로 설정하고 6개월까지 생존한 환자에서 이후 생존을 비교할 수 있다.

Landmark 이후 시간 \(u\ge 0\)에 대한 조건부 생존함수는 다음과 같이 정의할 수 있다.

\[ S_L(u\mid Z_L)=P(T>t_L+u\mid T>t_L, Z(t_L)=Z_L), \]

여기서 \(Z(t_L)\)은 landmark 시점에서 관찰된 반응, 진행 여부, 치료 지속 여부 등이다.

이 모형의 estimand는 기저시점 전체 환자의 생존이 아니라, landmark 시점까지 사건 없이 관찰되고 특정 정보 \(Z_L\)를 가진 환자의 조건부 미래 생존이다. 즉 분석대상과 의사결정 시점이 바뀐다. 기저시점 치료전략의 총 효과를 추정하려는 분석과, 치료 도중 새 정보를 얻은 뒤 예후를 갱신하려는 동적 예측은 동일한 질문이 아니다.

Landmark 시점에서의 위험집합을

\[ \mathcal{R}(t_L)=\{i:T_i\ge t_L,\ C_i\ge t_L\} \]

로 정의하면 이후 모형은 이 집합에 조건부로 적합된다. 따라서 \(t_L\) 전에 사망하거나 중도절단된 환자는 이후 조건부 모형에 정보를 제공하지 않는다. 중도절단이 예후와 관련되어 있다면 landmark까지 관찰될 확률에 대한 역확률가중치를 고려해야 한다.

시간-의존 정보를 단순히 baseline 공변량처럼 사용하면 immortal time bias가 발생할 수 있다. 어떤 환자가 “반응군”으로 분류되기 위해서는 반응 평가 시점까지 생존해야 하므로, 이 기간을 적절히 처리하지 않으면 반응군의 생존이 인위적으로 길어 보일 수 있다. Landmark 분석은 이 문제를 줄이는 실용적인 접근이다.

ImportantImmortal time bias

반응군으로 분류되기 위해 반드시 살아 있어야 하는 기간이 존재하는데 이를 분석에서 무시하면 반응군의 예후가 과대평가될 수 있다. Landmark 분석은 landmark 시점까지 생존한 환자만을 위험집단으로 재정의하여 이 편향을 줄인다.

10.4.2 조건부 생존함수

공변량을 고려하지 않는 단순한 경우, landmark 시점까지 생존한 환자에서 이후 생존함수는 다음과 같다.

\[ P(T>t\mid T>t_L)=\frac{P(T>t,T>t_L)}{P(T>t_L)}. \]

\(t>t_L\)이면 \(T>t\)는 \(T>t_L\)을 포함하므로,

\[ P(T>t\mid T>t_L)=\frac{S(t)}{S(t_L)}. \]

landmark 이후 경과시간 \(u=t-t_L\)를 사용하면,

\[ S_L(u)=\frac{S(t_L+u)}{S(t_L)}. \]

경제성 평가에서는 이 조건부 생존함수를 landmark 이후 상태에 도달한 환자의 장기 생존외삽에 사용할 수 있다.

반응상태 \(Z_L=z\)에 따라 조건부 생존을 다르게 추정하면 전체 생존은 landmark 상태별 경로확률을 사용하여 다시 결합할 수 있다.

\[ P(T>t_L+u) = \sum_z P\{Z_L=z,T>t_L\} S_L(u\mid Z_L=z). \]

\(Z_L\)가 landmark까지 생존한 사람에게만 정의된다면

\[ P\{Z_L=z,T>t_L\} =P(T>t_L)P(Z_L=z\mid T>t_L) \]

로 분해된다. 이 결합은 반응군과 비반응군의 조건부 생존곡선만으로 전체 치료전략의 생존을 계산할 수 없음을 보여준다.

하나의 landmark만 사용하면 선택한 시점에 따라 결과가 달라질 수 있다. 여러 landmark 시점 \(t_{L1},t_{L2},\ldots\)에서 모형을 반복 적합하거나, landmark 시점 자체를 공변량으로 포함한 landmark supermodel을 사용하면 예측시간에 따라 갱신되는 동적 생존확률을 얻을 수 있다. 그러나 동일 환자가 여러 landmark 자료셋에 반복 포함되므로 표준오차는 환자 내 상관을 반영해야 한다.

조건부 생존곡선은 landmark 시점에서 1로 다시 시작하지만, 전체 환자의 생존확률이 1로 회복된다는 뜻은 아니다. 전체 기대결과를 계산할 때는 landmark까지 도달할 확률을 반드시 곱해야 한다.

10.4.3 경제성 평가에서의 활용

Landmark model은 다음과 같은 상황에서 유용하다.

  • 특정 시점의 반응 여부에 따라 이후 생존을 다르게 모델링할 때
  • 단기 surrogate outcome과 장기 생존을 연결할 때
  • 진행, 치료중단, 반응, 이상반응 이후의 생존을 별도 모델링할 때
  • 일정 시점 이후 외부 장기자료 또는 registry 자료를 결합할 때
  • 치료효과가 특정 시점 이후 달라진다고 가정할 때

다만 landmark 분석은 \(t_L\) 이전에 사건이 발생한 환자를 제외하므로, landmark 이후 분석만으로 전체 치료전략의 기대 생존기간을 직접 계산할 수는 없다. 전체 경제성 평가 모델에서는 \(t_L\) 이전의 경로확률과 \(t_L\) 이후 조건부 생존을 결합해야 한다.

\[ \mathbb{E}(Q)=\mathbb{E}(Q_{0:t_L})+P(T>t_L)\mathbb{E}(Q_{t_L:\tau}\mid T>t_L). \]

이 식은 landmark 이후 결과가 전체 기대 QALY에 기여하려면 landmark까지 도달할 확률이 함께 곱해져야 함을 보여준다.

Landmark 접근은 시간의존 Cox 모형이나 다상태모형의 대안이지만 동일하지 않다. 시간의존 Cox 모형은 전체 추적기간의 위험집합을 유지하면서 \(Z(t)\)의 현재값과 위험의 관계를 모델링한다. 다상태모형은 반응, 진행, 치료중단과 같은 상태 사이의 전이를 직접 모델링한다. Landmark 모형은 구현과 해석이 단순하지만, landmark 이전 정보의 손실과 시점 선택에 따른 민감성이 존재한다. 경제성 평가에서는 임상적 의사결정이 실제로 갱신되는 시점과 모형의 landmark가 일치하는지 확인해야 한다.

10.5 Piecewise model

10.5.1 기본 아이디어

Piecewise model은 시간축을 여러 구간으로 나누고, 각 구간에서 서로 다른 위험함수 또는 생존모형을 적용하는 방법이다. 예를 들어 치료 초기 0–2년, 중기 2–6년, 장기 6년 이후의 위험 패턴이 다르다고 판단되면 각 구간별로 다른 위험률을 사용할 수 있다.

가장 단순한 형태는 piecewise exponential model이다. 시간 구간을 다음과 같이 나눈다.

\[ 0=\tau_0<\tau_1<\tau_2<\cdots<\tau_K. \]

구간 \([\tau_{k-1},\tau_k)\)에서 위험률이 일정하다고 가정하면,

\[ h(t)=\lambda_k,\qquad \tau_{k-1}\le t<\tau_k. \]

시간 \(t\)가 \(k\)번째 구간에 있을 때 누적위험함수는 다음과 같다.

\[ H(t)=\sum_{j=1}^{k-1}\lambda_j(\tau_j-\tau_{j-1})+\lambda_k(t-\tau_{k-1}). \]

따라서 생존함수는 다음과 같다.

\[ S(t)=\exp\{-H(t)\}. \]

구간 \(k\)의 사건 수를 \(D_k\), 총 사람-시간을 \(Y_k\)라고 하면 piecewise exponential 모형의 로그가능도는 상수항을 제외하고

\[ \ell(\lambda_1,\ldots,\lambda_K) = \sum_{k=1}^{K}\{D_k\log\lambda_k-\lambda_kY_k\} \]

로 쓸 수 있다. 이는

\[ D_k\sim\operatorname{Poisson}(\lambda_kY_k) \]

인 Poisson 회귀와 같은 형태이다. 개인별 추적시간을 구간별로 분할하고 로그 사람-시간을 offset으로 사용하면 공변량과 시간구간 효과를 함께 추정할 수 있다.

\[ \log\lambda_{ik}=\alpha_k+x_i^T\beta, \qquad \log E(D_{ik})=\log Y_{ik}+\alpha_k+x_i^T\beta. \]

이 연결은 piecewise exponential 모형을 생존자료뿐 아니라 발생률 자료와도 자연스럽게 결합할 수 있게 한다.

위험률은 구간 경계에서 불연속적으로 바뀔 수 있지만 생존함수는 누적위험을 통해 연속적으로 이어진다. 경계 직후의 급격한 위험 변화가 임상적으로 설명되는지 별도로 확인해야 한다.

10.5.2 주기별 전이확률

마코프모형에서 주기 \([a,b]\) 동안 위험함수가 \(h(u)\)라면 사건 발생확률은 다음과 같다.

\[ p(a,b)=1-\exp\left[-\int_a^b h(u)du\right]. \]

piecewise exponential model에서 주기 전체가 하나의 구간 \(k\)에 포함되면,

\[ p_k=1-\exp\{-\lambda_k(b-a)\}. \]

주기가 여러 구간을 가로지르면 각 구간의 노출시간을 합산해야 한다.

\[ p(a,b)=1-\exp\left[-\sum_{k=1}^{K}\lambda_k d_k(a,b)\right], \]

여기서 \(d_k(a,b)\)는 주기 \([a,b]\)가 \(k\)번째 구간 안에서 보낸 시간이다.

경쟁위험이 있는 경우, 구간 \(k\)에서 상태 \(r\)에서 \(s\)로 가는 전이강도를 \(\lambda_{rs,k}\)라고 하자. 총 이탈강도는

\[ \lambda_{r\cdot,k}=\sum_{s\ne r}\lambda_{rs,k} \]

이다. 같은 구간 안에서 주기 길이가 \(\Delta t\)이면 원인별 전이확률은 다음과 같다.

\[ p_{rs,k}=\frac{\lambda_{rs,k}}{\lambda_{r\cdot,k}}\left\{1-\exp(-\lambda_{r\cdot,k}\Delta t)\right\}. \]

이 식은 여러 전이 사건이 경쟁하는 마코프모형에서 발생률을 주기별 전이확률로 바꿀 때 중요하다.

상태가 여러 개인 경우에는 각 구간의 생성행렬 \(Q_k\)를 구성하고 행렬지수를 이용하는 것이 가장 일반적이다.

\[ P_k(\Delta t)=\exp(Q_k\Delta t). \]

주기 \([a,b]\)가 여러 구간을 지나면 전이행렬은 시간 순서대로 곱해진다.

\[ P(a,b) = \exp(Q_{k_1}d_{k_1}) \exp(Q_{k_2}d_{k_2})\cdots \exp(Q_{k_m}d_{k_m}). \]

행렬곱은 일반적으로 교환법칙이 성립하지 않으므로 구간 순서를 바꾸면 안 된다. 이 방식은 같은 주기 안에서 여러 번의 전이가 가능한 연속시간 과정과 확률합이 1이 되는 조건을 동시에 보장한다.

10.5.3 장점과 주의점

Piecewise model은 복잡한 생존분포를 하나의 수식으로 설명하기보다, 구간별 임상적 가정을 명시적으로 반영한다. 예를 들어 임상시험 관찰기간에는 Kaplan–Meier 또는 모수모형을 사용하고, 이후 일정 기간에는 외삽모형을 사용하며, 장기 구간에는 일반인 사망률 또는 registry 자료를 연결할 수 있다.

그러나 구간 경계 설정은 결과에 영향을 준다. 구간 경계는 Kaplan–Meier 곡선의 변화, 위험함수 추정, 치료효과 소실 시점, 치료 중단 시점, 외부 자료 사용 가능 시점, 임상전문가 의견에 근거해야 한다. 또한 구간 경계에서 위험함수가 갑자기 변하는 것이 임상적으로 타당한지 검토해야 한다.

서로 다른 자료원이나 모형을 연결할 때는 생존확률의 연속성을 보장해야 한다. 시점 \(\tau\) 이후 외부 생존함수 \(S_{\mathrm{ext}}(t)\)를 사용한다면 단순히 교체하지 않고 다음과 같이 재척도화할 수 있다.

\[ S(t)= \begin{cases} S_{\mathrm{trial}}(t), & t\le \tau,\\[4pt] S_{\mathrm{trial}}(\tau) \dfrac{S_{\mathrm{ext}}(t)}{S_{\mathrm{ext}}(\tau)}, & t>\tau. \end{cases} \]

이 식은 생존함수의 점프를 방지하지만 위험함수의 연속성까지 보장하지는 않는다. 연결 직전과 직후의 위험이 크게 다르면 완충구간, 가중결합 또는 위험비의 점진적 감소를 고려할 수 있다.

자료에서 변화점을 자동 탐색하는 방법은 구간 선택의 객관성을 높일 수 있지만, 같은 자료로 변화점을 선택하고 모수를 추정하면 불확실성이 과소평가될 수 있다. 변화점 자체를 모수로 추정하거나 후보 경계에 대한 모형 평균화와 시나리오 분석을 수행하는 것이 더 타당하다.

10.6 Cure model

10.6.1 Cure의 의미

Cure model은 일부 환자가 장기적으로 질병 관련 초과위험에서 벗어난다고 가정하는 모형이다. 여기서 cure는 반드시 임상적 완치를 의미하지 않는다. 경제성 평가에서는 일정 비율의 환자가 더 이상 해당 질병으로 인한 추가 사건위험을 경험하지 않는 장기 생존 상태에 도달한다고 해석하는 것이 적절하다.

Cure model은 다음 상황에서 고려된다.

  • 생존곡선이 장기 plateau에 가까워지는 경우
  • 장기 추적자료에서 일정 시점 이후 질병 관련 사건이 거의 발생하지 않는 경우
  • 완치 가능성이 있는 암, 감염질환, 일부 희귀질환
  • 세포치료제나 유전자치료제처럼 장기 효과가 기대되는 경우
  • 일반인 사망률과 연결한 장기 외삽이 필요한 경우
WarningCure fraction의 해석

Cure model의 cure fraction은 통계적 장기 생존 성분이다. 추적기간이 짧고 사건 수가 적으면 cure fraction은 강한 외삽 가정에 크게 의존한다. 따라서 외부 장기자료, 임상적 근거, 민감도 분석 없이 cure fraction을 확정적 사실처럼 해석하면 안 된다.

10.6.2 Mixture cure model

질병 관련 초과위험 또는 상대생존 척도에서 가장 단순한 mixture cure model은 다음과 같다.

\[ S_{rel}(t)=\pi+(1-\pi)S_u(t), \]

여기서 \(\pi\)는 cure fraction이고, \(S_u(t)\)는 uncured 성분의 상대생존함수 또는 질병 관련 생존함수이다. \(S_u(t)\to 0\)이면,

\[ \lim_{t\to\infty}S_{rel}(t)=\pi. \]

공변량을 포함할 경우 cure fraction은 로지스틱 회귀로 모델링할 수 있다.

\[ \pi(x)=\frac{\exp(x^T\alpha)}{1+\exp(x^T\alpha)}. \]

uncured 성분의 생존함수는 Weibull, log-normal, log-logistic, flexible parametric model 등으로 표현할 수 있다.

Mixture cure model의 population-level 위험함수는

\[ h(t) = \frac{(1-\pi)f_u(t)}{\pi+(1-\pi)S_u(t)} = w_u(t)h_u(t), \]

\[ w_u(t) = \frac{(1-\pi)S_u(t)}{\pi+(1-\pi)S_u(t)} \]

로 표현된다. \(w_u(t)\)는 시간 \(t\)까지 사건 없이 생존한 환자가 uncured 성분에 속할 조건부 확률이다. 시간이 지날수록 사건 없이 남아 있는 환자 중 cured 성분의 비중이 커지므로, uncured 환자의 위험 \(h_u(t)\)가 일정하더라도 전체 위험은 감소할 수 있다.

공변량은 cure 발생확률과 uncured 환자의 사건시간에 서로 다른 방식으로 작용할 수 있다.

\[ \operatorname{logit}\{\pi(x)\}=x^T\alpha, \]

\[ \log H_u(t\mid z)=s(\log t)+z^T\beta. \]

\(\alpha\)는 장기적으로 초과위험에서 벗어날 확률에 대한 효과이고, \(\beta\)는 uncured 집단 안에서 사건속도에 대한 효과이다. 하나의 공변량이 두 부분에 모두 포함될 수 있지만 그 해석은 구분해야 한다.

10.6.3 일반인 사망률과 상대생존

경제성 평가에서 all-cause survival을 모델링할 때는 매우 중요한 점이 있다. Cure fraction에 속한 환자도 일반인 사망위험은 경험한다. 따라서 \(S(t)=\pi+(1-\pi)S_u(t)\)라는 plateau 형태를 all-cause survival에 직접 적용하면 장기적으로 사망하지 않는 환자가 존재하는 것처럼 되어 비현실적일 수 있다.

상대생존 접근에서는 관찰 생존함수를 다음과 같이 분해한다.

\[ S_{all}(t)=S_{bg}(t)S_{rel}(t), \]

여기서 \(S_{bg}(t)\)는 같은 연령, 성별, calendar year를 가진 일반인 기대생존함수이고, \(S_{rel}(t)\)는 질병 관련 상대생존함수이다. mixture cure model을 상대생존에 적용하면 다음과 같다.

\[ S_{all}(t)=S_{bg}(t)\left\{\pi+(1-\pi)S_u(t)\right\}. \]

위험함수 척도에서는 다음처럼 표현할 수 있다.

\[ h_{all}(t)=h_{bg}(a+t,sex,calendar)+h_{excess}(t). \]

Cure 상태에서는 질병 관련 초과위험 \(h_{excess}(t)\)가 0 또는 매우 작은 값으로 수렴한다고 해석할 수 있다. 이 구조는 장기 생존외삽에서 일반인 사망률보다 낮은 all-cause mortality가 발생하지 않도록 하는 데 중요하다.

일반인 사망률은 연령과 달력시간에 따라 달라지므로, 진입연령을 \(a_0\), 진입연도를 \(c_0\)라고 하면 배경 누적위험은

\[ H_{bg}(t) = \int_0^t h_{pop}(a_0+u,c_0+u,sex,\ldots)du \]

로 계산해야 한다. 따라서 \(S_{bg}(t)=\exp\{-H_{bg}(t)\}\)는 단순한 고정 exponential 분포가 아니다. 긴 분석기간에서는 생존자 연령 증가와 달력연도 변화가 배경사망률에 미치는 영향을 반영해야 한다.

상대생존 모형은 사망원인이 정확히 분류되지 않아도 전체 사망과 일반인 기대사망의 차이를 이용해 초과사망을 추정할 수 있다는 장점이 있다. 그러나 일반인 생명표가 환자의 사회경제적 수준, 흡연, 동반질환과 크게 다르면 \(h_{bg}(t)\)가 실제 비질병 사망위험을 정확히 나타내지 않을 수 있다. 이 경우 배경사망률 보정 또는 대체 생명표에 대한 민감도 분석이 필요하다.

상대생존의 plateau는 질병 관련 초과사망이 사라지는 상태를 나타낸다. 전체 생존은 배경사망 때문에 계속 감소하므로 경제성 평가에는 두 생존함수를 구분하여 적용해야 한다.

전체 사망위험은 배경위험과 질병 관련 초과위험의 합으로 해석된다. 장기 외삽에서 초과위험이 음수가 되거나 전체 위험이 근거 없이 배경위험보다 낮아지는지 점검해야 한다.

10.6.4 Non-mixture cure model

Non-mixture cure model은 population-level hazard가 시간이 지남에 따라 0에 가까워지는 형태를 통해 장기 생존 plateau를 표현한다. 상대생존 척도에서 한 가지 표현은 다음과 같다.

\[ S_{rel}(t)=\exp\{-\theta F_u(t)\}, \]

여기서 \(F_u(t)=1-S_u(t)\)이다. \(F_u(t)\to 1\)이면 장기 상대생존은 다음과 같다.

\[ \lim_{t\to\infty}S_{rel}(t)=\exp(-\theta). \]

따라서 cure fraction은 \(\pi=\exp(-\theta)\)로 해석할 수 있다. 같은 식을 \(\theta=-\log\pi\)로 치환하면 다음과 같다.

\[ S_{rel}(t)=\pi^{F_u(t)}. \]

Mixture cure model은 cured와 uncured 성분을 명시적으로 구분하기 쉽고, non-mixture cure model은 population-level hazard의 감소를 자연스럽게 표현한다. 경제성 평가에서는 두 모형 모두 장기 QALY에 큰 영향을 줄 수 있으므로, cure fraction과 uncured 성분 분포에 대한 민감도 분석이 필요하다.

10.6.5 Cure fraction의 식별 조건

Cure fraction은 생존곡선이 평평해 보인다는 이유만으로 식별되지 않는다. 다음 조건이 충족될수록 추정의 신뢰성이 높아진다.

  • 충분한 비율의 환자가 질병 관련 사건이 거의 발생하지 않는 기간까지 추적되었는가?
  • 마지막 사건 이후에도 충분한 위험집합과 추적시간이 남아 있는가?
  • 배경사망률과 질병 초과사망률을 구분할 자료가 있는가?
  • 외부 장기자료에서 유사한 plateau 또는 초과위험 소실이 관찰되는가?
  • 치료군과 대조군의 cure 구조가 임상적으로 설명되는가?

추적기간이 짧으면 \(\pi\)와 uncured 분포의 꼬리 모수가 강하게 상관되어 서로 대체될 수 있다. 예를 들어 더 큰 cure fraction과 더 짧은 uncured 생존은 더 작은 cure fraction과 더 긴 uncured 생존과 관찰구간에서 유사한 곡선을 만들 수 있다. 이때 프로파일 가능도는 평평해지고 표준오차의 정규근사가 부정확해질 수 있다. 프로파일 신뢰구간, 부트스트랩 또는 베이지안 사후분포로 불확실성을 평가하는 것이 바람직하다.

Cure가 임상적으로 불확실한 경우에는 cure model 하나만을 기본분석으로 고정하기보다, 비-cure 장기꼬리 모형과 함께 구조적 시나리오를 구성해야 한다. Cure model의 우수한 AIC는 장기 plateau의 존재를 증명하지 않는다.

10.6.6 Cure model이 ICER에 미치는 영향

Cure fraction이 증가하면 장기 생존기간과 QALY가 크게 증가할 수 있다. 특히 비용이 치료 초기에 대부분 발생하고 장기 관리비용이 상대적으로 작다면, cure fraction의 작은 변화도 증분 QALY를 크게 바꾸어 ICER를 낮출 수 있다.

치료전략 \(j\)의 장기 QALY를 단순화하여 효용 \(u\)가 일정하다고 하면,

\[ Q_j(\tau)=u\int_0^\tau S_j(t)dt. \]

cure fraction \(\pi_j\)가 포함된 상대생존 모형에서는 \(S_j(t)\)의 장기 꼬리가 \(\pi_j\)에 민감하므로,

\[ \frac{\partial Q_j(\tau)}{\partial \pi_j} =u\int_0^\tau S_{bg}(t)\{1-S_{u,j}(t)\}dt \]

와 같이 cure fraction 변화가 QALY에 미치는 영향을 볼 수 있다. 이 민감도는 추적기간이 짧고 \(\tau\)가 길수록 커지는 경향이 있다.

10.7.1 왜 위험함수를 보아야 하는가?

생존곡선은 누적된 결과를 보여준다. 서로 다른 위험함수 형태를 가진 모형이라도 관찰기간 내 생존곡선은 비슷해 보일 수 있다. 그러나 관찰기간 이후 외삽에서는 위험함수의 작은 차이가 장기 생존율과 RMST에 큰 차이를 만든다.

위험함수는 특정 시점까지 생존한 환자가 바로 그 시점 이후 사건을 경험할 순간위험이다.

\[ h(t)=\lim_{\Delta t\to 0}\frac{P(t\le T<t+\Delta t\mid T\ge t)}{\Delta t}. \]

생존함수와 누적위험함수의 관계는 다음과 같다.

\[ H(t)=\int_0^t h(u)du, \qquad S(t)=\exp\{-H(t)\}. \]

따라서 장기 생존외삽은 결국 장기 위험함수를 어떻게 가정하는가의 문제이다.

위험함수는 국소적 변화에 민감하므로 비모수 추정값 자체도 평활방법과 대역폭에 따라 달라진다. 따라서 외삽모형의 위험함수를 평가할 때 비모수 위험추정치를 절대적인 참값으로 보아서는 안 된다. Kaplan–Meier 생존곡선, Nelson–Aalen 누적위험, 평활 위험함수와 사건 수를 함께 보아야 한다.

누적위험 척도에서는

\[ -\log S(t)=H(t) \]

이므로 생존확률이 1에 가까운 초기 구간보다 사건이 충분히 누적된 구간에서 모형 차이를 더 명확히 볼 수 있다. 또한 로그 누적위험을 로그 시간에 대해 그리면 직선성이나 곡률을 통해 Weibull형 꼬리와 spline의 경계거동을 진단할 수 있다.

생존함수는 위험의 누적결과이므로 서로 다른 국소 위험패턴을 평활화해 보여준다. 위험함수를 함께 보면 장기 꼬리를 만드는 실제 가정이 증가위험인지 감소위험인지 더 분명하게 확인할 수 있다.

10.7.2 위험함수 평가 기준

경제성 평가에서 위험함수를 평가할 때는 다음 질문을 고려한다.

  • 위험이 시간이 지남에 따라 증가하는 것이 질병 자연사와 일치하는가?
  • 위험이 계속 감소하여 0에 가까워지는 것이 임상적으로 타당한가?
  • 치료군의 all-cause mortality가 일반인 사망률보다 낮아지는 비현실적 패턴은 없는가?
  • 치료효과가 장기적으로 계속 유지되는 것이 타당한가?
  • 치료효과 소실 또는 감소를 반영해야 하는가?
  • 관찰기간 말기의 number at risk와 사건 수가 충분한가?
  • 외부 registry 또는 장기 추적자료의 위험 패턴과 일치하는가?
  • 위험함수의 작은 차이가 ICER에 얼마나 영향을 주는가?

표준 모형별 위험함수 형태는 다음과 같이 요약할 수 있다.

관찰구간 적합은 수치지표와 그래프를 함께 사용한다. 시점 \(t_j\)에서 비모수 생존추정량을 \(\widehat S_{KM}(t_j)\), 모형 예측을 \(\widehat S_m(t_j)\)라고 하면 가중 오차는

\[ E_m = \sum_j w_j\left\{\widehat S_{KM}(t_j)-\widehat S_m(t_j)\right\}^2 \]

로 계산할 수 있다. 그러나 \(w_j\)를 크게 주는 시점과 추적 후반의 불확실성 처리에 따라 순위가 달라질 수 있다. 외부자료가 있을 때는 주요 시점의 생존율, 누적사건률, 배경사망 대비 초과위험을 직접 비교해야 한다.

장기 임상적 타당성은 다음 제약으로 표현할 수 있다.

\[ h_{all}(t)\ge h_{bg}(t) \]

또는 질병 초과위험이 음수가 되지 않아야 한다는 조건이다. 특정 치료가 일반인보다 낮은 사망위험을 실제로 만들 수 있는 특별한 근거가 없다면, 이 제약을 위반하는 외삽은 모형 적합도가 좋아도 배제하거나 조정해야 한다.

10.7.3 모형 선택이 ICER에 미치는 영향

생존외삽 모형 선택은 증분 QALY를 통해 ICER에 영향을 준다.

\[ ICER_m=\frac{\Delta C_m}{\Delta Q_m}, \]

여기서 \(m\)은 생존외삽 시나리오를 의미한다. 비용이 주로 치료 초기에 발생하면 \(\Delta C_m\)은 모형별 차이가 상대적으로 작을 수 있지만, \(\Delta Q_m\)은 장기 생존외삽에 매우 민감할 수 있다. 따라서 생존외삽 모형별 ICER를 시나리오 분석으로 제시해야 한다.

모형 \(m\)의 순편익을

\[ NMB_m(\lambda)=\lambda\Delta Q_m-\Delta C_m \]

라고 하면 생존외삽 선택의 의사결정 영향은 ICER 차이보다 \(NMB_m(\lambda)\)의 부호와 크기로 평가하는 것이 안정적이다. 여러 모형이 모두 임상적으로 타당하다면 모형별 의사결정이 일치하는지 확인하고, 불일치할 경우 구조적 불확실성을 명시적으로 제시해야 한다.

모형확률 \(p_m\)을 정의할 수 있다면 모형평균 기대순편익은

\[ \mathbb{E}_{M,\theta}(NMB) = \sum_m p_m\mathbb{E}_{\theta_m}(NMB_m) \]

로 계산할 수 있다. 다만 AIC 가중치는 후보집합 안에서의 상대적 예측근거일 뿐 임상적 타당성의 확률은 아니다. 비현실적인 꼬리를 가진 모형을 가중평균에 포함하면 결과도 비현실적일 수 있으므로 후보모형을 먼저 임상적 제약으로 선별해야 한다.

시나리오 간 ICER 차이가 크다면 이는 단순한 모수 오차가 아니라 외삽 구조가 의사결정을 좌우한다는 신호이다. 이 경우 한 모형의 PSA만 제시해서는 전체 불확실성을 설명할 수 없다.

10.8 유연한 생존모형의 선택과 보고

10.8.1 Base-case와 scenario analysis

경제성 평가 보고서에서는 하나의 base-case 생존외삽 모형을 선택해야 하는 경우가 많다. 그러나 생존외삽에는 구조적 불확실성이 크므로, 여러 plausible model을 scenario analysis로 제시하는 것이 바람직하다.

Base-case 모형은 다음 조건을 충족해야 한다.

  • 관찰자료에 충분히 적합하다.
  • 위험함수의 장기 형태가 임상적으로 타당하다.
  • 장기 생존율이 외부 자료와 모순되지 않는다.
  • 일반인 사망률 또는 자연사 자료와 일관된다.
  • 경제성 평가 모형 구조와 일관된다.
  • 가정이 의사결정자에게 설명 가능하다.

Scenario analysis에는 다음을 포함할 수 있다.

Base-case 선택은 다음 세 층의 근거를 순서대로 검토하는 것이 유용하다.

  1. 통계적 적합성: 우도, AIC/BIC, 잔차, 관찰구간의 생존·누적위험 적합
  2. 외적 타당성: registry, 장기 추적, 자연사, 일반인 생명표와의 일치
  3. 의사결정 타당성: RMST, QALY, 비용, NMB가 합리적인 범위에 있고 대안 가정에 얼마나 민감한지

첫 번째 층만 만족하는 모형은 관찰자료 설명모형일 수는 있어도 경제성 평가의 장기 예측모형으로 충분하지 않다. 특히 AIC 차이가 작을 때는 단일 최적모형을 선택하는 것보다 복수의 임상적으로 타당한 모형을 유지하는 것이 합리적이다.

  • 다른 knot 수를 가진 flexible parametric model
  • 독립 적합과 공동 적합 비교
  • 비례위험과 시간-의존 치료효과 비교
  • mixture model의 성분 수 또는 성분분포 변경
  • cure fraction 또는 일반인 사망률 연결 가정 변경
  • 임상시험 이후 특정 시점부터 외부자료를 쓰는 piecewise model
  • 치료효과가 일정 시점 이후 감소하거나 소실되는 모형

10.8.3 모수 불확실성과 구조적 불확실성의 전파

모형 \(m\)의 모수벡터를 \(\theta_m\)이라고 하면 PSA에서는 먼저 모형을 고정한 채

\[ \theta_m^{(b)}\sim p(\theta_m\mid D,m) \]

를 생성하고 비용과 QALY를 계산한다. 이는 모형 내 불확실성을 반영한다. Knot 수, 척도, mixture 성분 수, cure 구조와 같은 모형 선택까지 반영하려면

\[ M^{(b)}\sim p(M\mid D), \qquad \theta_{M^{(b)}}^{(b)}\sim p(\theta_{M^{(b)}}\mid D,M^{(b)}) \]

와 같은 계층적 생성이 필요하다. 전체 분산은

\[ \operatorname{Var}(Y) = \mathbb{E}_M\{\operatorname{Var}(Y\mid M)\} + \operatorname{Var}_M\{\mathbb{E}(Y\mid M)\} \]

로 분해되며, 두 번째 항이 구조적 모형 불확실성이다.

모형확률을 정당화하기 어렵다면 확률적 평균 대신 각 구조를 분리한 시나리오 분석을 제시할 수 있다. 중요한 것은 한 모형의 계수 공분산만 PSA에 넣고 모형 선택의 불확실성을 모두 해결했다고 해석하지 않는 것이다.

10.8.4 의사결정 중심의 검증

생존모형의 검증 대상은 생존확률뿐 아니라 경제성 평가에서 실제로 사용되는 함수여야 한다. 주요 검증량은 다음과 같다.

\[ \operatorname{RMST}(\tau)=\int_0^\tau S(t)dt, \]

\[ Q(\tau)=\int_0^\tau u(t)S(t)dt, \]

\[ C(\tau)=\int_0^\tau c(t)S(t)dt, \]

\[ NMB(\lambda)=\lambda\Delta Q-\Delta C. \]

두 모형이 관찰구간 생존곡선에서는 거의 같더라도 진행 이후 비용이나 장기 효용이 크게 다르면 NMB 차이가 확대될 수 있다. 따라서 외삽 검증과 보고는 주요 시점별 생존율뿐 아니라 RMST, 상태체류시간, 증분 QALY와 NMB까지 연결되어야 한다.

Note투명성의 원칙

생존외삽은 경제성 평가에서 가장 큰 구조적 불확실성의 원천 중 하나이다. 어떤 모형을 선택했는지보다, 왜 그 모형을 선택했는지와 다른 합리적 선택을 했을 때 결과가 어떻게 달라지는지를 투명하게 제시하는 것이 더 중요하다.

piecewise_survival <- function(time, cuts, hazards) {
  H <- numeric(length(time))
  for (i in seq_along(time)) {
    t <- time[i]
    cumhaz <- 0
    for (k in seq_along(hazards)) {
      start <- cuts[k]
      end <- cuts[k + 1]
      duration <- max(0, min(t, end) - start)
      cumhaz <- cumhaz + hazards[k] * duration
    }
    H[i] <- cumhaz
  }
  exp(-H)
}

# 생존분석 Ⅲ - 유연한 생존모형 {#sec-flexible-survival-models}

## 서론 {#sec-flexible-survival-introduction}

### 표준 모수적 생존모형의 한계

표준 모수적 생존모형은 생존시간 $T$의 분포를 소수의 모수로 표현한다. 예를 들어 exponential 모형은 일정한 위험함수를 가정한다.

$$
h(t)=\lambda.
$$

Weibull 모형은 shape-scale 모수화에서 다음과 같이 표현할 수 있다.

$$
S(t)=\exp\left[-\left(\frac{t}{\lambda}\right)^k\right],
\qquad
h(t)=\frac{k}{\lambda}\left(\frac{t}{\lambda}\right)^{k-1}.
$$

이때 $k>1$이면 위험함수는 단조 증가하고, $k<1$이면 단조 감소하며, $k=1$이면 exponential 모형이 된다. Gompertz 모형은 위험함수가 시간에 따라 지수적으로 변한다고 가정한다.

$$
h(t)=\lambda\exp(\gamma t).
$$

이러한 모형은 단순하고 안정적이지만 위험함수의 형태에 제약이 있다. 예를 들어 Weibull 모형은 위험이 증가하다가 감소하는 형태를 표현할 수 없고, exponential 모형은 치료 초기와 장기 추적기간의 위험 차이를 설명할 수 없다. 그러나 실제 생존자료에서는 다음과 같은 양상이 자주 나타난다.

- 치료 초기 독성 또는 질병 부담 때문에 초기 위험이 높다가 이후 낮아지는 경우
- 일정 기간 후 재발 또는 진행 위험이 다시 증가하는 경우
- 면역항암제처럼 치료효과가 지연되어 생존곡선이 뒤늦게 분리되는 경우
- 장기 생존자가 존재하여 생존곡선 꼬리가 완만해지는 경우
- 서로 다른 예후를 가진 잠재적 하위집단이 섞여 있는 경우

경제성 평가에서 이러한 제한은 단순한 통계적 적합도 문제가 아니다. 생존외삽은 다음 적분을 통해 기대 생존기간과 기대 QALY를 결정한다.

$$
\operatorname{RMST}(\tau)=\int_0^\tau S(t)dt,
$$

$$
Q(\tau)=\int_0^\tau u(t)S(t)dt,
$$

여기서 $u(t)$는 시간 $t$에서의 효용가중치이다. 관찰기간 이후 생존곡선의 꼬리가 조금만 달라져도 $\operatorname{RMST}$와 $Q$는 크게 달라질 수 있고, 이는 ICER에 직접적인 영향을 준다.

![표준 Weibull 생존곡선과 유연한 생존곡선의 예시. 관찰구간에서는 차이가 작아 보여도 장기 외삽에서는 곡선 아래 면적 차이가 커질 수 있다.](figures/ch10/fig-ch10-standard-vs-flexible.png)

이 그림에서 확인해야 할 핵심은 관찰구간의 시각적 적합도가 아니라 분석기간 전체에서 두 곡선 사이에 누적되는 면적 차이이다. 경제성 평가에서는 이 면적 차이가 기대 생존기간과 QALY 차이로 직접 변환된다.

### 유연한 생존모형이 필요한 상황

유연한 생존모형은 다음 상황에서 고려할 수 있다.

| 상황 | 표준 모형의 한계 | 고려 가능한 모형 |
|---|---|---|
| 위험함수가 비단조적임 | Weibull, Gompertz가 부적절할 수 있음 | Flexible parametric model, spline model |
| 치료효과가 시간에 따라 변함 | 비례위험 가정이 부적절함 | Time-varying effect model, landmark model |
| 장기 생존자가 존재함 | 모든 환자의 질병 관련 위험이 결국 계속된다는 가정이 부적절할 수 있음 | Cure model, relative survival model |
| 환자집단이 이질적임 | 단일 분포가 평균적 패턴만 설명함 | Mixture model |
| 특정 시점 이후 다른 자료원을 써야 함 | 단일 외삽식이 임상적으로 부적절함 | Piecewise model, external-data anchored model |
| 임상시험 추적기간이 짧음 | 꼬리 부분 추정이 불안정함 | External data, cure/mixture/piecewise scenario analysis |

## 유연성의 역설 {.unnumbered}

모형이 유연할수록 관찰기간 내 자료에는 더 잘 맞을 수 있다. 그러나 장기 외삽에서는 작은 형태 차이가 큰 QALY 차이로 확대된다. 따라서 유연한 생존모형은 “더 좋은 모형”이 아니라 “더 많은 판단과 검증이 필요한 모형”이다.

### 생존외삽의 일반적 우도 구조

중도절단 생존자료에서 환자 $i$의 관찰값을 $(t_i,\delta_i,x_i)$라고 하자. 여기서 $t_i$는 관찰시간, $\delta_i=1$은 사건 발생, $\delta_i=0$은 중도절단, $x_i$는 공변량이다. 생존함수를 $S(t\mid x_i;\theta)$, 밀도함수를 $f(t\mid x_i;\theta)$, 위험함수를 $h(t\mid x_i;\theta)$라고 하면 개별 가능도 기여분은 다음과 같다.

$$
L_i(\theta)=f(t_i\mid x_i;\theta)^{\delta_i}S(t_i\mid x_i;\theta)^{1-\delta_i}.
$$

$f(t)=h(t)S(t)$이므로 같은 식을 다음과 같이 쓸 수 있다.

$$
L_i(\theta)=h(t_i\mid x_i;\theta)^{\delta_i}S(t_i\mid x_i;\theta).
$$

전체 로그가능도는 다음과 같다.

$$
\ell(\theta)=\sum_{i=1}^n\left[\delta_i\log h(t_i\mid x_i;\theta)+\log S(t_i\mid x_i;\theta)\right].
$$

유연한 생존모형은 결국 $S(t)$, $H(t)$ 또는 $h(t)$의 형태를 더 넓은 함수공간에서 표현하는 방법이다. 다만 외삽이 목적일 때는 관찰구간 밖에서도 임상적으로 타당한 함수 형태를 가져야 한다.


### 유연성, 근사오차와 추정오차

유연한 생존모형은 미리 정해진 하나의 분포를 선택하기보다, 기저함수의 선형결합을 이용하여 실제 위험 구조를 근사한다. 일반적으로 어떤 변환된 생존량을 $g(t)$라고 할 때 다음과 같이 표현할 수 있다.

$$
g(t)=\sum_{k=1}^{K}\gamma_k b_k(t),
$$

여기서 $b_k(t)$는 spline 또는 구간지시함수와 같은 기저함수이고, $K$는 모형의 복잡도를 결정한다. $K$가 너무 작으면 실제 곡률을 표현하지 못해 **근사편향**이 커지고, $K$가 너무 크면 사건이 적은 구간의 우연한 변동까지 따라가 **추정분산**이 커진다. 이를 개념적으로 나타내면 예측오차는 다음 세 부분으로 나눌 수 있다.

$$
\mathbb{E}\{(\widehat g(t)-g_0(t))^2\}
=
\operatorname{Bias}\{\widehat g(t)\}^2
+
\operatorname{Var}\{\widehat g(t)\}
+
\sigma^2_{\text{irreducible}}.
$$

관찰구간 안에서는 자유도를 늘리면 편향이 줄어드는 경우가 많지만, 외삽구간에서는 자료가 없기 때문에 분산뿐 아니라 함수의 경계조건과 꼬리 가정이 결과를 지배한다. 따라서 유연성 선택은 단순한 적합도 최적화가 아니라, **관찰자료가 제공하는 정보량과 장기 구조 가정 사이의 균형**을 정하는 과정이다.

### 외삽 구간의 부분식별

최대 추적시점을 $t_{\max}$라고 하면 자료의 가능도는 주로 $0\le t\le t_{\max}$에서의 생존곡선을 식별한다. 두 모형 $M_1$과 $M_2$가 관찰구간에서 거의 같은 생존함수를 갖더라도,

$$
S_1(t)\approx S_2(t),\qquad 0\le t\le t_{\max},
$$

관찰구간 이후에는 서로 다른 값을 가질 수 있다.

$$
S_1(t)\ne S_2(t),\qquad t>t_{\max}.
$$

따라서 전체 기대 생존기간은 다음처럼 관찰부분과 외삽부분으로 분해하는 것이 유용하다.

$$
\int_0^{\tau}S(t)dt
=
\int_0^{t_{\max}}S(t)dt
+
\int_{t_{\max}}^{\tau}S(t)dt.
$$

첫 번째 항은 자료에 비교적 강하게 지지되지만 두 번째 항은 모형 구조, 외부자료, 일반인 사망률과 임상적 판단에 더 크게 의존한다. 이 의미에서 장기 평균 생존기간과 QALY는 완전히 비모수적으로 식별되는 양이 아니라, **자료와 외삽 가정을 함께 사용하여 부분적으로 식별되는 의사결정 입력값**이다.

### 지연진입과 구간중도절단을 포함한 우도

모든 생존자료가 단순한 우측중도절단 형태인 것은 아니다. 환자 $i$가 시간 $e_i$ 이후에 위험집합에 들어오는 좌측절단 자료에서는 조건부 가능도 기여분이 다음과 같다.

$$
L_i(\theta)
=
\frac{f(t_i;\theta)^{\delta_i}S(t_i;\theta)^{1-\delta_i}}
{S(e_i;\theta)}.
$$

사건시간이 구간 $(L_i,R_i]$ 안에 있다는 것만 알려진 구간중도절단 자료의 기여분은

$$
L_i(\theta)=S(L_i;\theta)-S(R_i;\theta)
$$

가 된다. 유연한 모형은 함수 형태뿐 아니라 관찰과정을 정확하게 우도에 반영해야 한다. 지연진입이나 구간중도절단을 무시하면 spline의 유연성이 커도 기저위험과 장기 외삽이 편향될 수 있다.

![경제성 평가에서 문제가 되는 여러 위험함수 형태. 표준 Weibull은 단조 위험만 표현하지만 실제 자료에서는 초기 고위험, 비단조 위험, 지연 치료효과 등이 나타날 수 있다.](figures/ch10/fig-ch10-hazard-shapes-flexible.png)

위험함수의 봉우리와 굴곡은 질병 자연사, 치료 초기 독성, 지연 치료효과 또는 생존자 구성의 변화를 반영할 수 있다. 후반부의 굴곡은 위험집합이 작은 데서 생긴 우연한 변동일 수도 있으므로 number at risk와 함께 해석해야 한다.

## Flexible parametric model {#sec-flexible-parametric-model}

### 기본 아이디어

Flexible parametric survival model은 생존함수, 누적위험함수 또는 위험함수의 특정 변환을 spline 함수로 표현하는 모형이다. 경제성 평가에서 가장 자주 언급되는 형태는 Royston--Parmar 모형이다. 이 모형은 로그 누적위험함수를 로그 시간의 restricted cubic spline으로 표현한다.

$$
\eta(t\mid x)=\log H(t\mid x)=s_0(\log t;\gamma)+x^T\beta.
$$

여기서 $H(t\mid x)$는 누적위험함수이고, $s_0(\log t;\gamma)$는 로그 시간에 대한 spline 함수이다. 따라서 생존함수는 다음과 같다.

$$
S(t\mid x)=\exp\{-H(t\mid x)\}
=\exp\left[-\exp\{s_0(\log t;\gamma)+x^T\beta\}\right].
$$

공변량 효과가 시간과 무관하게 더해지는 위 구조에서는 누적위험비가 다음과 같이 일정하다.

$$
\frac{H(t\mid x=1)}{H(t\mid x=0)}=\exp(\beta).
$$

로그 누적위험 척도에서 $\exp(\beta)$는 cumulative hazard ratio이다. 시간-의존 효과가 없고 모형 구조가 적절하면 instantaneous hazard ratio 역시 일정한 비례위험 구조로 해석될 수 있다. 그러나 시간-의존 효과를 포함하면 cumulative hazard ratio와 instantaneous hazard ratio의 구분이 중요해진다.


### 모형화 척도와 암묵적 효과 가정

Flexible parametric model은 어떤 변환을 spline으로 표현하느냐에 따라 서로 다른 회귀구조를 갖는다. 로그 누적위험 척도는 비례위험 구조와 연결된다.

$$
\log H(t\mid x)=s(\log t)+x^T\beta.
$$

반면 로그 누적오즈 척도를 사용하면 다음과 같은 비례오즈 구조가 된다.

$$
\log\left\{\frac{1-S(t\mid x)}{S(t\mid x)}\right\}
=s(\log t)+x^T\beta.
$$

이 경우 $\exp(\beta)$는 사건 누적오즈의 비를 나타낸다. 정규 분위수 척도에서는

$$
\Phi^{-1}\{1-S(t\mid x)\}=s(\log t)+x^T\beta
$$

와 같이 표현할 수 있다. 이러한 모형들은 관찰기간 안에서 비슷한 적합도를 보일 수 있지만, 꼬리에서의 선형성 제약이 서로 다른 생존형태로 변환되기 때문에 장기 외삽은 달라질 수 있다. 따라서 spline 자유도뿐 아니라 **모형화 척도 자체도 구조적 불확실성의 원천**이다.

### Spline 함수와 knot

Restricted cubic spline은 로그 시간축 $z=\log t$ 위에서 다음과 같은 형태로 표현할 수 있다.


Restricted cubic spline은 경계 knot 밖에서 함수가 선형이 되도록 제약한 cubic spline이다. 내부 knot를 $\kappa_1<\cdots<\kappa_K$라고 하면, 한 가지 truncated-power 표현은 다음과 같다.

$$
s(z)=\gamma_0+\gamma_1z+\sum_{j=1}^{K-2}\gamma_{j+1}d_j(z),
$$

$$
d_j(z)
=(z-\kappa_j)_+^3
-\frac{\kappa_K-\kappa_j}{\kappa_K-\kappa_{K-1}}(z-\kappa_{K-1})_+^3
+\frac{\kappa_{K-1}-\kappa_j}{\kappa_K-\kappa_{K-1}}(z-\kappa_K)_+^3,
$$

여기서 $(a)_+=\max(a,0)$이다. 이 선형 제약은 경계 밖의 세제곱 발산을 억제하지만, 로그 누적위험 척도에서 선형이라는 조건이 생존확률 척도에서 완만한 꼬리를 보장하는 것은 아니다. 경계 기울기는 장기 누적위험의 증가속도를 결정하므로 마지막 knot 부근의 사건 수가 적을 때 특히 불안정할 수 있다.

$$
s_0(z;\gamma)=\gamma_0+\gamma_1z+\sum_{m=1}^{M}\gamma_{m+1}b_m(z),
$$

여기서 $b_m(z)$는 knot 위치에 의해 정의되는 spline basis 함수이다. 제한 cubic spline은 양쪽 꼬리에서 선형성을 갖도록 제약되어 있어, 관찰범위 밖에서 과도한 굴곡을 줄이는 데 도움을 준다.

Knot 수 또는 자유도는 모형의 유연성을 결정한다. 자유도가 작으면 모형은 안정적이지만 복잡한 위험 패턴을 설명하기 어렵다. 자유도가 크면 관찰자료에는 잘 맞을 수 있지만 외삽이 불안정해질 수 있다.


Knot 위치는 보통 사건시간 분포의 분위수에 배치하지만, 이는 관찰구간 내 적합을 위한 경험적 규칙이다. 후반부 위험집합이 작으면 마지막 몇 개 knot가 소수의 사건에 의해 결정될 수 있다. 사건 수를 $D$, 추정모수 수를 $p$라고 할 때 $D/p$가 작아질수록 분산과 수렴 문제가 커진다. 정확한 절대 기준은 없지만, 후보 자유도를 늘릴 때 다음을 함께 확인해야 한다.

- 마지막 추적구간에서 spline 계수의 표준오차와 상관성이 급격히 커지는가?
- 예측 생존함수가 단조 감소하고 누적위험함수가 단조 증가하는가?
- 장기 위험이 0, 무한대 또는 일반인 위험 이하로 비현실적으로 수렴하는가?
- 작은 knot 이동만으로 RMST와 ICER가 크게 변하는가?

이 점검은 정보기준보다 외삽 안정성에 직접 관련된다.

![로그 누적위험을 로그 시간의 선형 함수로 표현하는 경우와 spline으로 표현하는 경우. Spline은 관찰자료의 굴곡을 더 잘 반영할 수 있지만 외삽에서는 더 세심한 검토가 필요하다.](figures/ch10/fig-ch10-spline-log-cumhaz.png)

Spline 곡선은 knot 사이에서는 유연하지만 경계 밖에서는 제한조건에 따라 단순한 형태로 이어진다. 따라서 마지막 knot 이후의 기울기가 장기 누적위험을 어떻게 결정하는지 확인하는 것이 중요하다.

## Knot 수 선택 {.unnumbered}

Knot 수는 AIC나 BIC만으로 결정하지 않는 것이 좋다. 후보 knot 수별 생존곡선, 위험함수, 장기 생존율, RMST, ICER를 함께 비교하고, number at risk가 매우 적은 후반부의 굴곡을 과도하게 따라가지 않는지 확인해야 한다.
:::

### 위험함수의 계산

Royston--Parmar 모형에서 $H(t\mid x)=\exp\{\eta(t\mid x)\}$이다. 위험함수는 누적위험함수의 도함수이므로 다음과 같다.

$$
h(t\mid x)=\frac{dH(t\mid x)}{dt}=H(t\mid x)\frac{\partial \eta(t\mid x)}{\partial t}.
$$

공변량 효과가 시간과 무관하고 $z=\log t$이면,

$$
\frac{\partial \eta(t\mid x)}{\partial t}=\frac{1}{t}\frac{\partial s_0(z;\gamma)}{\partial z}.
$$

따라서 위험함수는 다음과 같이 표현된다.

$$
h(t\mid x)=\frac{H(t\mid x)}{t}s_0'(\log t;\gamma).
$$

이 식은 flexible parametric model에서 위험함수의 장기 형태가 spline의 도함수에 의해 결정됨을 보여준다. 생존곡선은 단조 감소하더라도, 위험함수의 장기 형태가 임상적으로 부자연스러울 수 있으므로 반드시 함께 확인해야 한다.


로그 누적위험 모형이 유효하려면 $H(t)$가 증가함수여야 하므로

$$
\frac{\partial \eta(t)}{\partial t}\ge 0
$$

가 필요하다. 일반적인 restricted cubic spline 적합은 관찰된 시간범위에서 대체로 이 조건을 만족하도록 추정되지만, 수치오차나 과도한 자유도 때문에 국소적으로 음의 위험이 계산되는지 확인해야 한다. 단조성을 명시적으로 보장해야 하는 경우에는 I-spline, monotone spline 또는 양의 위험함수를 직접 모형화하는 접근을 사용할 수 있다.

장기 꼬리는 경계에서 $s_0'(\log t)$가 어떤 값으로 수렴하는지에 의해 결정된다. 경계 밖에서

$$
s_0(\log t)\approx a+b\log t
$$

이면

$$
H(t)\approx e^a t^b,
\qquad
h(t)\approx e^a b t^{b-1}.
$$

즉, 로그 누적위험 척도의 restricted cubic spline은 최종적으로 Weibull과 유사한 꼬리 거동을 갖는다. 유연한 모형도 관찰구간 밖에서는 완전히 자유로운 것이 아니라 경계 제약이 암묵적인 장기 분포 가정으로 작동한다.

### 비례위험 형태와 시간-의존 치료효과

치료변수 $x$가 이진변수라고 하자. 비례위험 형태의 flexible parametric model은 다음과 같다.

$$
\eta(t\mid x)=s_0(\log t;\gamma)+x\beta.
$$

반면 치료효과가 시간에 따라 변할 수 있도록 하려면 다음과 같이 치료와 시간 spline의 상호작용을 포함할 수 있다.

$$
\eta(t\mid x)=s_0(\log t;\gamma)+x\beta+x s_1(\log t;\alpha).
$$

이때 누적위험비는 다음과 같다.

$$
\frac{H(t\mid x=1)}{H(t\mid x=0)}=\exp\{\beta+s_1(\log t;\alpha)\}.
$$

하지만 instantaneous hazard ratio는 일반적으로 다음과 같이 도함수 항까지 포함한다.

$$
HR(t)=\frac{h(t\mid x=1)}{h(t\mid x=0)}
=\exp\{\beta+s_1(\log t;\alpha)\}\frac{\partial \eta(t\mid x=1)/\partial t}{\partial \eta(t\mid x=0)/\partial t}.
$$

따라서 시간-의존 효과를 가진 flexible parametric model을 보고할 때는 단일 HR만 제시하기보다 시간별 생존함수, 시간별 위험함수, 시간별 HR 또는 cumulative hazard ratio를 함께 제시하는 것이 바람직하다.


시간가변 효과는 spline 계수의 집합으로 표현되므로 개별 계수의 해석보다는 함수 전체에 대한 검정과 예측이 중요하다. 시간가변 항이 없는 모형을 $M_0$, 있는 모형을 $M_1$이라고 하면 우도비 검정통계량은

$$
2\{\ell(M_1)-\ell(M_0)\}
$$

이며, 정규성 조건 아래 추가된 시간상호작용 자유도에 해당하는 카이제곱분포와 비교할 수 있다. 그러나 검정력이 낮거나 임상적으로 작은 위반도 장기 QALY에는 큰 영향을 줄 수 있으므로, 유의확률만으로 비례위험 구조를 결정해서는 안 된다.

또한 조건부 생존곡선만 제시하면 공변량 분포가 다른 모집단으로 결과를 옮기기 어렵다. 목표 모집단의 공변량 분포가 $F_X$일 때 치료전략 $a$의 표준화 생존함수는

$$
S_a^{\mathrm{std}}(t)=\int S(t\mid A=a,X=x)dF_X(x)
$$

로 정의된다. 표본자료에서는

$$
\widehat S_a^{\mathrm{std}}(t)
=\frac{1}{n}\sum_{i=1}^{n}\widehat S(t\mid A=a,X=x_i)
$$

로 계산한다. 이 표준화는 비선형 모형에서 평균 공변량을 대입한 생존곡선과 일반적으로 같지 않으며, 경제성 평가의 목표 인구집단에 맞춘 절대 생존편익을 제공한다.

![비례위험 형태와 시간-의존 치료효과 형태의 생존곡선 예시. 시간-의존 효과에서는 초기와 장기 치료효과가 다르게 나타날 수 있다.](figures/ch10/fig-ch10-time-varying-effect.png)

시간가변 치료효과에서는 두 군의 곡선이 늦게 분리되거나 다시 가까워질 수 있다. 이때 단일 위험비는 치료효과의 시간적 패턴을 숨기므로 시점별 생존차, RMST 차이와 함께 평가해야 한다.

### 경제성 평가에서의 활용

Flexible parametric model은 다음 방식으로 경제성 평가에 사용된다.

1. 각 치료군에 독립적으로 적합한다.
2. 치료군을 공변량으로 포함하여 공동 적합한다.
3. 비례위험 구조 또는 시간-의존 치료효과 구조를 비교한다.
4. spline 자유도를 바꾸어 시나리오 분석을 수행한다.
5. 외부 registry, 자연사 자료, 일반인 사망률과 장기 외삽을 비교한다.
6. 생존곡선뿐 아니라 위험함수를 경제성 평가 보고서에 포함한다.

독립 적합은 두 군의 생존곡선 형태를 자유롭게 허용하지만 군 간 관계에 대한 통계적 정보를 덜 활용한다. 공동 적합은 더 안정적일 수 있으나 치료효과 구조를 명시적으로 가정해야 한다. 어느 접근이 더 적절한지는 생존곡선의 형태, 비례위험 가정, 임상적 치료효과 지속 가정, 외부 자료와의 일관성에 따라 판단해야 한다.


### 벌점화와 유효 자유도

사건 수에 비해 spline 자유도가 크거나 시간가변 효과를 함께 포함하면 일반 최대가능도 추정이 불안정할 수 있다. 벌점화 spline은 굴곡의 크기에 제약을 두어 이를 완화한다.

$$
\ell_p(\gamma,\beta)
=
\ell(\gamma,\beta)
-
\frac{\lambda}{2}\gamma^T K\gamma,
$$

여기서 $K$는 곡률을 측정하는 벌점행렬이고 $\lambda$는 평활모수이다. $\lambda$가 클수록 함수는 단순해지고, 작을수록 자료의 세부 변동을 더 많이 따라간다. 이때 실제 복잡도는 기저함수 개수 자체가 아니라 평활에 의해 축소된 **유효 자유도**로 해석한다.

벌점화는 과적합을 줄일 수 있지만 외삽 근거를 새로 만들어 주지는 않는다. 관찰구간 밖의 꼬리는 여전히 기저함수의 경계조건과 외부 제약에 의해 결정된다. 따라서 교차검증이나 AIC로 평활모수를 정하더라도 장기 생존율과 위험함수의 임상적 검토가 별도로 필요하다.

## Mixture model {#sec-mixture-model}

### 기본 아이디어

Mixture survival model은 전체 환자집단이 하나의 균질한 생존분포를 따르는 것이 아니라, 서로 다른 생존 특성을 가진 잠재적 하위집단의 혼합으로 구성되어 있다고 가정한다. $G$개의 성분이 있는 mixture model은 다음과 같이 쓸 수 있다.

$$
S(t)=\sum_{g=1}^{G}\pi_g S_g(t),
\qquad
\sum_{g=1}^{G}\pi_g=1,
\qquad
\pi_g\ge 0.
$$

두 성분인 경우에는 다음과 같다.

$$
S(t)=\pi S_1(t)+(1-\pi)S_2(t).
$$

여기서 $S_1(t)$와 $S_2(t)$는 각각 잠재 하위집단의 생존함수이고, $\pi$는 첫 번째 성분에 속할 사전 확률이다. 각 성분은 Weibull, log-normal, log-logistic 또는 spline 기반 생존함수로 설정할 수 있다.

![단일 생존분포와 두 성분 mixture survival model의 비교. Mixture model은 초기 급격한 감소와 장기 완만한 꼬리를 동시에 표현할 수 있다.](figures/ch10/fig-ch10-mixture-survival.png)

혼합곡선의 긴 꼬리는 반드시 완치 환자의 존재를 의미하지 않는다. 서로 다른 사건속도를 가진 두 비완치 성분이 섞여 있어도 같은 형태가 나타날 수 있다.

### Mixture model의 위험함수

Mixture model에서는 밀도함수도 성분별 밀도의 가중합이다.

$$
f(t)=\sum_{g=1}^{G}\pi_g f_g(t).
$$

따라서 population-level 위험함수는 다음과 같다.

$$
h(t)=\frac{f(t)}{S(t)}
=\frac{\sum_{g=1}^{G}\pi_g f_g(t)}{\sum_{g=1}^{G}\pi_g S_g(t)}.
$$

$f_g(t)=h_g(t)S_g(t)$를 이용하면,

$$
h(t)=\sum_{g=1}^{G}w_g(t)h_g(t),
$$

여기서

$$
w_g(t)=\frac{\pi_g S_g(t)}{\sum_{r=1}^{G}\pi_r S_r(t)}
$$

는 시간 $t$까지 생존한 환자가 성분 $g$에 속할 조건부 확률이다. 이 식은 mixture model의 중요한 직관을 제공한다. 시간이 지남에 따라 고위험 성분의 환자는 더 빨리 사건을 경험하므로, 생존자 중 저위험 성분의 비중이 커진다. 따라서 population-level hazard는 시간이 지남에 따라 감소하거나 복잡한 형태를 보일 수 있다.


이 가중치는 베이즈 정리를 적용한 사후 성분확률이다. 사건이 시간 $t$에 발생한 환자의 성분확률은 생존자에서의 가중치와 다르며 다음과 같다.

$$
P(G=g\mid T=t)
=
\frac{\pi_g f_g(t)}{\sum_r\pi_r f_r(t)}.
$$

따라서 “현재까지 생존한 환자가 어느 성분에 속하는가”와 “이 시점에 사건을 경험한 환자가 어느 성분에 속하는가”는 서로 다른 조건부 질문이다. 동적 예측이나 하위집단별 비용을 계산할 때 두 확률을 혼동하면 안 된다.

혼합분포의 평균 생존시간이 존재한다면 선형성에 의해

$$
\mathbb{E}(T)=\sum_{g=1}^{G}\pi_g\mathbb{E}(T\mid G=g)
$$

가 된다. 그러나 혼합위험함수는 성분별 위험함수의 고정 가중평균이 아니라 $w_g(t)$가 시간에 따라 변하는 가중평균이다. 이 차이 때문에 성분별로 모두 단조 위험을 갖더라도 전체 위험은 비단조가 될 수 있다.

![Mixture model에서 시간에 따라 생존자 중 각 성분의 비중이 변하는 양상. 장기 생존자 중에는 저위험 성분의 비중이 커진다.](figures/ch10/fig-ch10-mixture-weights.png)

시간이 지날수록 저위험 성분의 조건부 비중이 증가하는 것은 선택된 생존자 구성의 변화이다. 전체 위험의 감소를 개인 수준의 위험 감소로 곧바로 해석해서는 안 된다.

### Mixture model의 가능도

개별 환자 $i$의 관찰자료가 $(t_i,\delta_i)$일 때, $G$성분 mixture model의 가능도 기여분은 다음과 같다.

$$
L_i=\left\{\sum_{g=1}^{G}\pi_g f_g(t_i)\right\}^{\delta_i}
\left\{\sum_{g=1}^{G}\pi_g S_g(t_i)\right\}^{1-\delta_i}.
$$

전체 가능도는 다음과 같다.

$$
L=\prod_{i=1}^{n}L_i.
$$

모형은 직접 최대가능도법으로 적합할 수도 있고, 잠재 성분 소속을 결측자료로 보는 EM 알고리즘으로 적합할 수도 있다. 다만 성분 수가 늘어나면 식별성이 약해지고, 서로 다른 초기값에서 다른 해로 수렴할 수 있다.


잠재 성분지시자를 $Z_{ig}\in\{0,1\}$라고 하면 완전자료 로그가능도는

$$
\ell_c
=
\sum_{i=1}^{n}\sum_{g=1}^{G}Z_{ig}
\left[
\log\pi_g
+\delta_i\log f_g(t_i)
+(1-\delta_i)\log S_g(t_i)
\right]
$$

이다. EM 알고리즘의 E-step에서는 현재 모수에서 $Z_{ig}$의 조건부 기대값을 계산하고, M-step에서는 이를 가중치로 사용하여 혼합비율과 성분모수를 갱신한다. 중도절단된 관찰의 사후 성분확률은 $\pi_gS_g(t_i)$에 비례하고, 사건 관찰은 $\pi_gf_g(t_i)$에 비례한다.

혼합모형에는 다음과 같은 식별 문제가 있다.

1. 두 성분의 분포가 유사하면 혼합비율과 성분모수를 분리하기 어렵다.
2. 성분 라벨을 바꾸어도 같은 가능도를 얻는 label switching이 존재한다.
3. 한 성분의 분산이 극단적으로 작아지거나 소수 관찰을 독점하면 국소 최댓값이 생길 수 있다.
4. 추적기간이 짧으면 장기 생존 성분과 cure 성분을 구별하기 어렵다.

따라서 여러 초기값, 프로파일 가능도, 부트스트랩, 베이지안 사후분포 등을 통해 수렴과 식별성을 확인해야 한다. 정보기준이 성분 수를 지지하더라도 성분별 장기 생존이 임상적으로 설명되지 않으면 경제성 평가의 기본분석으로 사용하기 어렵다.

### 경제성 평가에서의 해석과 주의점

Mixture model은 단일 분포가 초기 위험과 장기 꼬리를 동시에 설명하지 못할 때 유용하다. 하지만 잠재 성분은 통계적 구성물이며, 반드시 실제 생물학적 하위집단과 일치하지 않는다. 바이오마커, 반응 여부, 병기, 치료순응도 등으로 실제 하위집단을 설명할 수 없다면, mixture 성분을 임상적으로 독립된 환자군으로 해석하는 데 주의해야 한다.


Mixture survival model과 mixture cure model은 수학적 형태가 비슷하지만 목적이 다르다. 일반 mixture model에서는 모든 성분이 결국 사건을 경험할 수 있어

$$
\lim_{t\to\infty}S_g(t)=0
$$

이고 따라서 전체 생존함수도 0으로 수렴한다. 반면 mixture cure model에서는 한 성분의 질병 관련 생존함수가 1로 유지되어 상대생존이 양의 plateau로 수렴한다. 제한된 추적자료에서는 매우 긴 꼬리를 가진 일반 mixture와 cure model이 거의 같은 적합도를 보일 수 있으므로, 두 모형의 구분은 통계적 적합도보다 외부 장기근거에 의존한다.

::: {.callout-warning}
## Mixture model의 해석상 주의 {.unnumbered}

Mixture model의 성분은 관찰된 생존곡선을 설명하기 위해 도입된 잠재 구조이다. 성분별 생존곡선이 임상적으로 그럴듯해 보여도, 외부 근거 없이 “반응군”과 “비반응군”으로 직접 해석하면 안 된다.
:::

경제성 평가에서는 다음을 점검해야 한다.

- 성분 수가 자료와 임상지식으로 정당화되는가?
- 장기 생존 성분의 비율이 과대추정되지 않았는가?
- 각 성분의 장기 위험함수가 외부 자료와 일치하는가?
- mixture model 선택이 증분 QALY와 ICER에 얼마나 영향을 주는가?
- 성분별 모수의 불확실성을 PSA에 반영했는가?

## Landmark model {#sec-landmark-model}

### 기본 아이디어

Landmark model은 특정 시점 $t_L$을 기준으로, 그 시점까지 생존하거나 특정 상태에 도달한 환자만을 대상으로 이후 생존을 모델링하는 접근이다. 예를 들어 6개월 시점의 종양반응 여부가 이후 생존을 예측한다고 판단되면, 6개월을 landmark time으로 설정하고 6개월까지 생존한 환자에서 이후 생존을 비교할 수 있다.

Landmark 이후 시간 $u\ge 0$에 대한 조건부 생존함수는 다음과 같이 정의할 수 있다.

$$
S_L(u\mid Z_L)=P(T>t_L+u\mid T>t_L, Z(t_L)=Z_L),
$$

여기서 $Z(t_L)$은 landmark 시점에서 관찰된 반응, 진행 여부, 치료 지속 여부 등이다.


이 모형의 estimand는 기저시점 전체 환자의 생존이 아니라, **landmark 시점까지 사건 없이 관찰되고 특정 정보 $Z_L$를 가진 환자의 조건부 미래 생존**이다. 즉 분석대상과 의사결정 시점이 바뀐다. 기저시점 치료전략의 총 효과를 추정하려는 분석과, 치료 도중 새 정보를 얻은 뒤 예후를 갱신하려는 동적 예측은 동일한 질문이 아니다.

Landmark 시점에서의 위험집합을

$$
\mathcal{R}(t_L)=\{i:T_i\ge t_L,\ C_i\ge t_L\}
$$

로 정의하면 이후 모형은 이 집합에 조건부로 적합된다. 따라서 $t_L$ 전에 사망하거나 중도절단된 환자는 이후 조건부 모형에 정보를 제공하지 않는다. 중도절단이 예후와 관련되어 있다면 landmark까지 관찰될 확률에 대한 역확률가중치를 고려해야 한다.

시간-의존 정보를 단순히 baseline 공변량처럼 사용하면 immortal time bias가 발생할 수 있다. 어떤 환자가 “반응군”으로 분류되기 위해서는 반응 평가 시점까지 생존해야 하므로, 이 기간을 적절히 처리하지 않으면 반응군의 생존이 인위적으로 길어 보일 수 있다. Landmark 분석은 이 문제를 줄이는 실용적인 접근이다.

::: {.callout-important}
## Immortal time bias {.unnumbered}

반응군으로 분류되기 위해 반드시 살아 있어야 하는 기간이 존재하는데 이를 분석에서 무시하면 반응군의 예후가 과대평가될 수 있다. Landmark 분석은 landmark 시점까지 생존한 환자만을 위험집단으로 재정의하여 이 편향을 줄인다.
:::

### 조건부 생존함수

공변량을 고려하지 않는 단순한 경우, landmark 시점까지 생존한 환자에서 이후 생존함수는 다음과 같다.

$$
P(T>t\mid T>t_L)=\frac{P(T>t,T>t_L)}{P(T>t_L)}.
$$

$t>t_L$이면 $T>t$는 $T>t_L$을 포함하므로,

$$
P(T>t\mid T>t_L)=\frac{S(t)}{S(t_L)}.
$$

landmark 이후 경과시간 $u=t-t_L$를 사용하면,

$$
S_L(u)=\frac{S(t_L+u)}{S(t_L)}.
$$

경제성 평가에서는 이 조건부 생존함수를 landmark 이후 상태에 도달한 환자의 장기 생존외삽에 사용할 수 있다.


반응상태 $Z_L=z$에 따라 조건부 생존을 다르게 추정하면 전체 생존은 landmark 상태별 경로확률을 사용하여 다시 결합할 수 있다.

$$
P(T>t_L+u)
=
\sum_z P\{Z_L=z,T>t_L\}
S_L(u\mid Z_L=z).
$$

$Z_L$가 landmark까지 생존한 사람에게만 정의된다면

$$
P\{Z_L=z,T>t_L\}
=P(T>t_L)P(Z_L=z\mid T>t_L)
$$

로 분해된다. 이 결합은 반응군과 비반응군의 조건부 생존곡선만으로 전체 치료전략의 생존을 계산할 수 없음을 보여준다.

하나의 landmark만 사용하면 선택한 시점에 따라 결과가 달라질 수 있다. 여러 landmark 시점 $t_{L1},t_{L2},\ldots$에서 모형을 반복 적합하거나, landmark 시점 자체를 공변량으로 포함한 landmark supermodel을 사용하면 예측시간에 따라 갱신되는 동적 생존확률을 얻을 수 있다. 그러나 동일 환자가 여러 landmark 자료셋에 반복 포함되므로 표준오차는 환자 내 상관을 반영해야 한다.

![Landmark 시점까지 생존한 환자에서 이후 조건부 생존함수를 계산하는 개념. Landmark 이후 생존확률은 $S(t)/S(t_L)$로 재척도화된다.](figures/ch10/fig-ch10-landmark-conditional.png)

조건부 생존곡선은 landmark 시점에서 1로 다시 시작하지만, 전체 환자의 생존확률이 1로 회복된다는 뜻은 아니다. 전체 기대결과를 계산할 때는 landmark까지 도달할 확률을 반드시 곱해야 한다.

### 경제성 평가에서의 활용

Landmark model은 다음과 같은 상황에서 유용하다.

- 특정 시점의 반응 여부에 따라 이후 생존을 다르게 모델링할 때
- 단기 surrogate outcome과 장기 생존을 연결할 때
- 진행, 치료중단, 반응, 이상반응 이후의 생존을 별도 모델링할 때
- 일정 시점 이후 외부 장기자료 또는 registry 자료를 결합할 때
- 치료효과가 특정 시점 이후 달라진다고 가정할 때

다만 landmark 분석은 $t_L$ 이전에 사건이 발생한 환자를 제외하므로, landmark 이후 분석만으로 전체 치료전략의 기대 생존기간을 직접 계산할 수는 없다. 전체 경제성 평가 모델에서는 $t_L$ 이전의 경로확률과 $t_L$ 이후 조건부 생존을 결합해야 한다.

$$
\mathbb{E}(Q)=\mathbb{E}(Q_{0:t_L})+P(T>t_L)\mathbb{E}(Q_{t_L:\tau}\mid T>t_L).
$$

이 식은 landmark 이후 결과가 전체 기대 QALY에 기여하려면 landmark까지 도달할 확률이 함께 곱해져야 함을 보여준다.


Landmark 접근은 시간의존 Cox 모형이나 다상태모형의 대안이지만 동일하지 않다. 시간의존 Cox 모형은 전체 추적기간의 위험집합을 유지하면서 $Z(t)$의 현재값과 위험의 관계를 모델링한다. 다상태모형은 반응, 진행, 치료중단과 같은 상태 사이의 전이를 직접 모델링한다. Landmark 모형은 구현과 해석이 단순하지만, landmark 이전 정보의 손실과 시점 선택에 따른 민감성이 존재한다. 경제성 평가에서는 임상적 의사결정이 실제로 갱신되는 시점과 모형의 landmark가 일치하는지 확인해야 한다.

## Piecewise model {#sec-piecewise-model}

### 기본 아이디어

Piecewise model은 시간축을 여러 구간으로 나누고, 각 구간에서 서로 다른 위험함수 또는 생존모형을 적용하는 방법이다. 예를 들어 치료 초기 0--2년, 중기 2--6년, 장기 6년 이후의 위험 패턴이 다르다고 판단되면 각 구간별로 다른 위험률을 사용할 수 있다.

가장 단순한 형태는 piecewise exponential model이다. 시간 구간을 다음과 같이 나눈다.

$$
0=\tau_0<\tau_1<\tau_2<\cdots<\tau_K.
$$

구간 $[\tau_{k-1},\tau_k)$에서 위험률이 일정하다고 가정하면,

$$
h(t)=\lambda_k,\qquad \tau_{k-1}\le t<\tau_k.
$$

시간 $t$가 $k$번째 구간에 있을 때 누적위험함수는 다음과 같다.

$$
H(t)=\sum_{j=1}^{k-1}\lambda_j(\tau_j-\tau_{j-1})+\lambda_k(t-\tau_{k-1}).
$$

따라서 생존함수는 다음과 같다.

$$
S(t)=\exp\{-H(t)\}.
$$


구간 $k$의 사건 수를 $D_k$, 총 사람-시간을 $Y_k$라고 하면 piecewise exponential 모형의 로그가능도는 상수항을 제외하고

$$
\ell(\lambda_1,\ldots,\lambda_K)
=
\sum_{k=1}^{K}\{D_k\log\lambda_k-\lambda_kY_k\}
$$

로 쓸 수 있다. 이는

$$
D_k\sim\operatorname{Poisson}(\lambda_kY_k)
$$

인 Poisson 회귀와 같은 형태이다. 개인별 추적시간을 구간별로 분할하고 로그 사람-시간을 offset으로 사용하면 공변량과 시간구간 효과를 함께 추정할 수 있다.

$$
\log\lambda_{ik}=\alpha_k+x_i^T\beta,
\qquad
\log E(D_{ik})=\log Y_{ik}+\alpha_k+x_i^T\beta.
$$

이 연결은 piecewise exponential 모형을 생존자료뿐 아니라 발생률 자료와도 자연스럽게 결합할 수 있게 한다.

![구간별 위험률과 그에 따른 생존함수. Piecewise model은 시간 구간별 임상적 가정을 명시적으로 반영할 수 있다.](figures/ch10/fig-ch10-piecewise-hazard-survival.png)

위험률은 구간 경계에서 불연속적으로 바뀔 수 있지만 생존함수는 누적위험을 통해 연속적으로 이어진다. 경계 직후의 급격한 위험 변화가 임상적으로 설명되는지 별도로 확인해야 한다.

### 주기별 전이확률

마코프모형에서 주기 $[a,b]$ 동안 위험함수가 $h(u)$라면 사건 발생확률은 다음과 같다.

$$
p(a,b)=1-\exp\left[-\int_a^b h(u)du\right].
$$

piecewise exponential model에서 주기 전체가 하나의 구간 $k$에 포함되면,

$$
p_k=1-\exp\{-\lambda_k(b-a)\}.
$$

주기가 여러 구간을 가로지르면 각 구간의 노출시간을 합산해야 한다.

$$
p(a,b)=1-\exp\left[-\sum_{k=1}^{K}\lambda_k d_k(a,b)\right],
$$

여기서 $d_k(a,b)$는 주기 $[a,b]$가 $k$번째 구간 안에서 보낸 시간이다.

경쟁위험이 있는 경우, 구간 $k$에서 상태 $r$에서 $s$로 가는 전이강도를 $\lambda_{rs,k}$라고 하자. 총 이탈강도는

$$
\lambda_{r\cdot,k}=\sum_{s\ne r}\lambda_{rs,k}
$$

이다. 같은 구간 안에서 주기 길이가 $\Delta t$이면 원인별 전이확률은 다음과 같다.

$$
p_{rs,k}=\frac{\lambda_{rs,k}}{\lambda_{r\cdot,k}}\left\{1-\exp(-\lambda_{r\cdot,k}\Delta t)\right\}.
$$

이 식은 여러 전이 사건이 경쟁하는 마코프모형에서 발생률을 주기별 전이확률로 바꿀 때 중요하다.


상태가 여러 개인 경우에는 각 구간의 생성행렬 $Q_k$를 구성하고 행렬지수를 이용하는 것이 가장 일반적이다.

$$
P_k(\Delta t)=\exp(Q_k\Delta t).
$$

주기 $[a,b]$가 여러 구간을 지나면 전이행렬은 시간 순서대로 곱해진다.

$$
P(a,b)
=
\exp(Q_{k_1}d_{k_1})
\exp(Q_{k_2}d_{k_2})\cdots
\exp(Q_{k_m}d_{k_m}).
$$

행렬곱은 일반적으로 교환법칙이 성립하지 않으므로 구간 순서를 바꾸면 안 된다. 이 방식은 같은 주기 안에서 여러 번의 전이가 가능한 연속시간 과정과 확률합이 1이 되는 조건을 동시에 보장한다.

### 장점과 주의점

Piecewise model은 복잡한 생존분포를 하나의 수식으로 설명하기보다, 구간별 임상적 가정을 명시적으로 반영한다. 예를 들어 임상시험 관찰기간에는 Kaplan--Meier 또는 모수모형을 사용하고, 이후 일정 기간에는 외삽모형을 사용하며, 장기 구간에는 일반인 사망률 또는 registry 자료를 연결할 수 있다.

그러나 구간 경계 설정은 결과에 영향을 준다. 구간 경계는 Kaplan--Meier 곡선의 변화, 위험함수 추정, 치료효과 소실 시점, 치료 중단 시점, 외부 자료 사용 가능 시점, 임상전문가 의견에 근거해야 한다. 또한 구간 경계에서 위험함수가 갑자기 변하는 것이 임상적으로 타당한지 검토해야 한다.


서로 다른 자료원이나 모형을 연결할 때는 생존확률의 연속성을 보장해야 한다. 시점 $\tau$ 이후 외부 생존함수 $S_{\mathrm{ext}}(t)$를 사용한다면 단순히 교체하지 않고 다음과 같이 재척도화할 수 있다.

$$
S(t)=
\begin{cases}
S_{\mathrm{trial}}(t), & t\le \tau,\\[4pt]
S_{\mathrm{trial}}(\tau)
\dfrac{S_{\mathrm{ext}}(t)}{S_{\mathrm{ext}}(\tau)}, & t>\tau.
\end{cases}
$$

이 식은 생존함수의 점프를 방지하지만 위험함수의 연속성까지 보장하지는 않는다. 연결 직전과 직후의 위험이 크게 다르면 완충구간, 가중결합 또는 위험비의 점진적 감소를 고려할 수 있다.

자료에서 변화점을 자동 탐색하는 방법은 구간 선택의 객관성을 높일 수 있지만, 같은 자료로 변화점을 선택하고 모수를 추정하면 불확실성이 과소평가될 수 있다. 변화점 자체를 모수로 추정하거나 후보 경계에 대한 모형 평균화와 시나리오 분석을 수행하는 것이 더 타당하다.

## Cure model {#sec-cure-model}

### Cure의 의미

Cure model은 일부 환자가 장기적으로 질병 관련 초과위험에서 벗어난다고 가정하는 모형이다. 여기서 cure는 반드시 임상적 완치를 의미하지 않는다. 경제성 평가에서는 일정 비율의 환자가 더 이상 해당 질병으로 인한 추가 사건위험을 경험하지 않는 장기 생존 상태에 도달한다고 해석하는 것이 적절하다.

Cure model은 다음 상황에서 고려된다.

- 생존곡선이 장기 plateau에 가까워지는 경우
- 장기 추적자료에서 일정 시점 이후 질병 관련 사건이 거의 발생하지 않는 경우
- 완치 가능성이 있는 암, 감염질환, 일부 희귀질환
- 세포치료제나 유전자치료제처럼 장기 효과가 기대되는 경우
- 일반인 사망률과 연결한 장기 외삽이 필요한 경우

::: {.callout-warning}
## Cure fraction의 해석 {.unnumbered}

Cure model의 cure fraction은 통계적 장기 생존 성분이다. 추적기간이 짧고 사건 수가 적으면 cure fraction은 강한 외삽 가정에 크게 의존한다. 따라서 외부 장기자료, 임상적 근거, 민감도 분석 없이 cure fraction을 확정적 사실처럼 해석하면 안 된다.
:::

### Mixture cure model

질병 관련 초과위험 또는 상대생존 척도에서 가장 단순한 mixture cure model은 다음과 같다.

$$
S_{rel}(t)=\pi+(1-\pi)S_u(t),
$$

여기서 $\pi$는 cure fraction이고, $S_u(t)$는 uncured 성분의 상대생존함수 또는 질병 관련 생존함수이다. $S_u(t)\to 0$이면,

$$
\lim_{t\to\infty}S_{rel}(t)=\pi.
$$

공변량을 포함할 경우 cure fraction은 로지스틱 회귀로 모델링할 수 있다.

$$
\pi(x)=\frac{\exp(x^T\alpha)}{1+\exp(x^T\alpha)}.
$$

uncured 성분의 생존함수는 Weibull, log-normal, log-logistic, flexible parametric model 등으로 표현할 수 있다.


Mixture cure model의 population-level 위험함수는

$$
h(t)
=
\frac{(1-\pi)f_u(t)}{\pi+(1-\pi)S_u(t)}
=
w_u(t)h_u(t),
$$

$$
w_u(t)
=
\frac{(1-\pi)S_u(t)}{\pi+(1-\pi)S_u(t)}
$$

로 표현된다. $w_u(t)$는 시간 $t$까지 사건 없이 생존한 환자가 uncured 성분에 속할 조건부 확률이다. 시간이 지날수록 사건 없이 남아 있는 환자 중 cured 성분의 비중이 커지므로, uncured 환자의 위험 $h_u(t)$가 일정하더라도 전체 위험은 감소할 수 있다.

공변량은 cure 발생확률과 uncured 환자의 사건시간에 서로 다른 방식으로 작용할 수 있다.

$$
\operatorname{logit}\{\pi(x)\}=x^T\alpha,
$$

$$
\log H_u(t\mid z)=s(\log t)+z^T\beta.
$$

$\alpha$는 장기적으로 초과위험에서 벗어날 확률에 대한 효과이고, $\beta$는 uncured 집단 안에서 사건속도에 대한 효과이다. 하나의 공변량이 두 부분에 모두 포함될 수 있지만 그 해석은 구분해야 한다.

### 일반인 사망률과 상대생존

경제성 평가에서 all-cause survival을 모델링할 때는 매우 중요한 점이 있다. Cure fraction에 속한 환자도 일반인 사망위험은 경험한다. 따라서 $S(t)=\pi+(1-\pi)S_u(t)$라는 plateau 형태를 all-cause survival에 직접 적용하면 장기적으로 사망하지 않는 환자가 존재하는 것처럼 되어 비현실적일 수 있다.

상대생존 접근에서는 관찰 생존함수를 다음과 같이 분해한다.

$$
S_{all}(t)=S_{bg}(t)S_{rel}(t),
$$

여기서 $S_{bg}(t)$는 같은 연령, 성별, calendar year를 가진 일반인 기대생존함수이고, $S_{rel}(t)$는 질병 관련 상대생존함수이다. mixture cure model을 상대생존에 적용하면 다음과 같다.

$$
S_{all}(t)=S_{bg}(t)\left\{\pi+(1-\pi)S_u(t)\right\}.
$$

위험함수 척도에서는 다음처럼 표현할 수 있다.

$$
h_{all}(t)=h_{bg}(a+t,sex,calendar)+h_{excess}(t).
$$

Cure 상태에서는 질병 관련 초과위험 $h_{excess}(t)$가 0 또는 매우 작은 값으로 수렴한다고 해석할 수 있다. 이 구조는 장기 생존외삽에서 일반인 사망률보다 낮은 all-cause mortality가 발생하지 않도록 하는 데 중요하다.


일반인 사망률은 연령과 달력시간에 따라 달라지므로, 진입연령을 $a_0$, 진입연도를 $c_0$라고 하면 배경 누적위험은

$$
H_{bg}(t)
=
\int_0^t h_{pop}(a_0+u,c_0+u,sex,\ldots)du
$$

로 계산해야 한다. 따라서 $S_{bg}(t)=\exp\{-H_{bg}(t)\}$는 단순한 고정 exponential 분포가 아니다. 긴 분석기간에서는 생존자 연령 증가와 달력연도 변화가 배경사망률에 미치는 영향을 반영해야 한다.

상대생존 모형은 사망원인이 정확히 분류되지 않아도 전체 사망과 일반인 기대사망의 차이를 이용해 초과사망을 추정할 수 있다는 장점이 있다. 그러나 일반인 생명표가 환자의 사회경제적 수준, 흡연, 동반질환과 크게 다르면 $h_{bg}(t)$가 실제 비질병 사망위험을 정확히 나타내지 않을 수 있다. 이 경우 배경사망률 보정 또는 대체 생명표에 대한 민감도 분석이 필요하다.

![상대생존 cure model과 일반인 사망률을 결합한 all-cause 생존곡선. 상대생존은 plateau를 보일 수 있지만 all-cause survival은 일반인 사망률 때문에 계속 감소한다.](figures/ch10/fig-ch10-cure-background.png)

상대생존의 plateau는 질병 관련 초과사망이 사라지는 상태를 나타낸다. 전체 생존은 배경사망 때문에 계속 감소하므로 경제성 평가에는 두 생존함수를 구분하여 적용해야 한다.

![일반인 사망위험, 질병 관련 초과위험, 전체 사망위험의 개념적 관계. 장기 외삽에서는 전체 사망위험이 일반인 사망위험보다 비현실적으로 낮아지지 않는지 점검해야 한다.](figures/ch10/fig-ch10-excess-hazard.png)

전체 사망위험은 배경위험과 질병 관련 초과위험의 합으로 해석된다. 장기 외삽에서 초과위험이 음수가 되거나 전체 위험이 근거 없이 배경위험보다 낮아지는지 점검해야 한다.

### Non-mixture cure model

Non-mixture cure model은 population-level hazard가 시간이 지남에 따라 0에 가까워지는 형태를 통해 장기 생존 plateau를 표현한다. 상대생존 척도에서 한 가지 표현은 다음과 같다.

$$
S_{rel}(t)=\exp\{-\theta F_u(t)\},
$$

여기서 $F_u(t)=1-S_u(t)$이다. $F_u(t)\to 1$이면 장기 상대생존은 다음과 같다.

$$
\lim_{t\to\infty}S_{rel}(t)=\exp(-\theta).
$$

따라서 cure fraction은 $\pi=\exp(-\theta)$로 해석할 수 있다. 같은 식을 $\theta=-\log\pi$로 치환하면 다음과 같다.

$$
S_{rel}(t)=\pi^{F_u(t)}.
$$

Mixture cure model은 cured와 uncured 성분을 명시적으로 구분하기 쉽고, non-mixture cure model은 population-level hazard의 감소를 자연스럽게 표현한다. 경제성 평가에서는 두 모형 모두 장기 QALY에 큰 영향을 줄 수 있으므로, cure fraction과 uncured 성분 분포에 대한 민감도 분석이 필요하다.


### Cure fraction의 식별 조건

Cure fraction은 생존곡선이 평평해 보인다는 이유만으로 식별되지 않는다. 다음 조건이 충족될수록 추정의 신뢰성이 높아진다.

- 충분한 비율의 환자가 질병 관련 사건이 거의 발생하지 않는 기간까지 추적되었는가?
- 마지막 사건 이후에도 충분한 위험집합과 추적시간이 남아 있는가?
- 배경사망률과 질병 초과사망률을 구분할 자료가 있는가?
- 외부 장기자료에서 유사한 plateau 또는 초과위험 소실이 관찰되는가?
- 치료군과 대조군의 cure 구조가 임상적으로 설명되는가?

추적기간이 짧으면 $\pi$와 uncured 분포의 꼬리 모수가 강하게 상관되어 서로 대체될 수 있다. 예를 들어 더 큰 cure fraction과 더 짧은 uncured 생존은 더 작은 cure fraction과 더 긴 uncured 생존과 관찰구간에서 유사한 곡선을 만들 수 있다. 이때 프로파일 가능도는 평평해지고 표준오차의 정규근사가 부정확해질 수 있다. 프로파일 신뢰구간, 부트스트랩 또는 베이지안 사후분포로 불확실성을 평가하는 것이 바람직하다.

Cure가 임상적으로 불확실한 경우에는 cure model 하나만을 기본분석으로 고정하기보다, 비-cure 장기꼬리 모형과 함께 구조적 시나리오를 구성해야 한다. Cure model의 우수한 AIC는 장기 plateau의 존재를 증명하지 않는다.

### Cure model이 ICER에 미치는 영향

Cure fraction이 증가하면 장기 생존기간과 QALY가 크게 증가할 수 있다. 특히 비용이 치료 초기에 대부분 발생하고 장기 관리비용이 상대적으로 작다면, cure fraction의 작은 변화도 증분 QALY를 크게 바꾸어 ICER를 낮출 수 있다.

치료전략 $j$의 장기 QALY를 단순화하여 효용 $u$가 일정하다고 하면,

$$
Q_j(\tau)=u\int_0^\tau S_j(t)dt.
$$

cure fraction $\pi_j$가 포함된 상대생존 모형에서는 $S_j(t)$의 장기 꼬리가 $\pi_j$에 민감하므로,

$$
\frac{\partial Q_j(\tau)}{\partial \pi_j}
=u\int_0^\tau S_{bg}(t)\{1-S_{u,j}(t)\}dt
$$

와 같이 cure fraction 변화가 QALY에 미치는 영향을 볼 수 있다. 이 민감도는 추적기간이 짧고 $\tau$가 길수록 커지는 경향이 있다.

## 외삽의 정확도를 위험함수로 평가하기 {#sec-evaluating-extrapolation-with-hazard}

### 왜 위험함수를 보아야 하는가?

생존곡선은 누적된 결과를 보여준다. 서로 다른 위험함수 형태를 가진 모형이라도 관찰기간 내 생존곡선은 비슷해 보일 수 있다. 그러나 관찰기간 이후 외삽에서는 위험함수의 작은 차이가 장기 생존율과 RMST에 큰 차이를 만든다.

위험함수는 특정 시점까지 생존한 환자가 바로 그 시점 이후 사건을 경험할 순간위험이다.

$$
h(t)=\lim_{\Delta t\to 0}\frac{P(t\le T<t+\Delta t\mid T\ge t)}{\Delta t}.
$$

생존함수와 누적위험함수의 관계는 다음과 같다.

$$
H(t)=\int_0^t h(u)du,
\qquad
S(t)=\exp\{-H(t)\}.
$$

따라서 장기 생존외삽은 결국 장기 위험함수를 어떻게 가정하는가의 문제이다.


위험함수는 국소적 변화에 민감하므로 비모수 추정값 자체도 평활방법과 대역폭에 따라 달라진다. 따라서 외삽모형의 위험함수를 평가할 때 비모수 위험추정치를 절대적인 참값으로 보아서는 안 된다. Kaplan--Meier 생존곡선, Nelson--Aalen 누적위험, 평활 위험함수와 사건 수를 함께 보아야 한다.

누적위험 척도에서는

$$
-\log S(t)=H(t)
$$

이므로 생존확률이 1에 가까운 초기 구간보다 사건이 충분히 누적된 구간에서 모형 차이를 더 명확히 볼 수 있다. 또한 로그 누적위험을 로그 시간에 대해 그리면 직선성이나 곡률을 통해 Weibull형 꼬리와 spline의 경계거동을 진단할 수 있다.

![관찰구간에서 생존곡선은 비슷해 보여도 위험함수의 장기 형태는 크게 다를 수 있다. 외삽 평가에서는 생존곡선과 위험함수를 함께 보아야 한다.](figures/ch10/fig-ch10-survival-hazard-difference.png)

생존함수는 위험의 누적결과이므로 서로 다른 국소 위험패턴을 평활화해 보여준다. 위험함수를 함께 보면 장기 꼬리를 만드는 실제 가정이 증가위험인지 감소위험인지 더 분명하게 확인할 수 있다.

### 위험함수 평가 기준

경제성 평가에서 위험함수를 평가할 때는 다음 질문을 고려한다.

- 위험이 시간이 지남에 따라 증가하는 것이 질병 자연사와 일치하는가?
- 위험이 계속 감소하여 0에 가까워지는 것이 임상적으로 타당한가?
- 치료군의 all-cause mortality가 일반인 사망률보다 낮아지는 비현실적 패턴은 없는가?
- 치료효과가 장기적으로 계속 유지되는 것이 타당한가?
- 치료효과 소실 또는 감소를 반영해야 하는가?
- 관찰기간 말기의 number at risk와 사건 수가 충분한가?
- 외부 registry 또는 장기 추적자료의 위험 패턴과 일치하는가?
- 위험함수의 작은 차이가 ICER에 얼마나 영향을 주는가?

표준 모형별 위험함수 형태는 다음과 같이 요약할 수 있다.


관찰구간 적합은 수치지표와 그래프를 함께 사용한다. 시점 $t_j$에서 비모수 생존추정량을 $\widehat S_{KM}(t_j)$, 모형 예측을 $\widehat S_m(t_j)$라고 하면 가중 오차는

$$
E_m
=
\sum_j w_j\left\{\widehat S_{KM}(t_j)-\widehat S_m(t_j)\right\}^2
$$

로 계산할 수 있다. 그러나 $w_j$를 크게 주는 시점과 추적 후반의 불확실성 처리에 따라 순위가 달라질 수 있다. 외부자료가 있을 때는 주요 시점의 생존율, 누적사건률, 배경사망 대비 초과위험을 직접 비교해야 한다.

장기 임상적 타당성은 다음 제약으로 표현할 수 있다.

$$
h_{all}(t)\ge h_{bg}(t)
$$

또는 질병 초과위험이 음수가 되지 않아야 한다는 조건이다. 특정 치료가 일반인보다 낮은 사망위험을 실제로 만들 수 있는 특별한 근거가 없다면, 이 제약을 위반하는 외삽은 모형 적합도가 좋아도 배제하거나 조정해야 한다.

| 모형 | 위험함수 형태 | 외삽 시 주의점 |
|---|---|---|
| Exponential | 일정 | 장기 위험이 변하지 않는다는 강한 가정 |
| Weibull | 단조 증가 또는 감소 | 비단조 위험을 설명하지 못함 |
| Gompertz | 지수적 증가 또는 감소 | 장기 위험이 과도하게 증가하거나 감소할 수 있음 |
| Log-normal | 증가 후 감소 가능 | 장기 위험이 0에 가까워질 수 있음 |
| Log-logistic | 증가 후 감소 가능 | 긴 꼬리를 만들 수 있음 |
| Generalized gamma | 매우 유연 | 해석이 어렵고 불안정할 수 있음 |
| Flexible parametric | knot에 따라 다양 | knot 선택과 꼬리 형태에 민감 |
| Mixture | 성분 가중치 변화에 따라 다양 | 잠재 성분 해석과 식별성 주의 |
| Cure model | 상대생존 plateau 가능 | cure fraction과 일반인 사망률 연결 근거 필요 |
| Piecewise | 구간별로 명시 | 구간 경계와 위험률 변화의 근거 필요 |

### 모형 선택이 ICER에 미치는 영향

생존외삽 모형 선택은 증분 QALY를 통해 ICER에 영향을 준다.

$$
ICER_m=\frac{\Delta C_m}{\Delta Q_m},
$$

여기서 $m$은 생존외삽 시나리오를 의미한다. 비용이 주로 치료 초기에 발생하면 $\Delta C_m$은 모형별 차이가 상대적으로 작을 수 있지만, $\Delta Q_m$은 장기 생존외삽에 매우 민감할 수 있다. 따라서 생존외삽 모형별 ICER를 시나리오 분석으로 제시해야 한다.


모형 $m$의 순편익을

$$
NMB_m(\lambda)=\lambda\Delta Q_m-\Delta C_m
$$

라고 하면 생존외삽 선택의 의사결정 영향은 ICER 차이보다 $NMB_m(\lambda)$의 부호와 크기로 평가하는 것이 안정적이다. 여러 모형이 모두 임상적으로 타당하다면 모형별 의사결정이 일치하는지 확인하고, 불일치할 경우 구조적 불확실성을 명시적으로 제시해야 한다.

모형확률 $p_m$을 정의할 수 있다면 모형평균 기대순편익은

$$
\mathbb{E}_{M,\theta}(NMB)
=
\sum_m p_m\mathbb{E}_{\theta_m}(NMB_m)
$$

로 계산할 수 있다. 다만 AIC 가중치는 후보집합 안에서의 상대적 예측근거일 뿐 임상적 타당성의 확률은 아니다. 비현실적인 꼬리를 가진 모형을 가중평균에 포함하면 결과도 비현실적일 수 있으므로 후보모형을 먼저 임상적 제약으로 선별해야 한다.

![생존외삽 시나리오에 따라 ICER가 달라지는 예시. 같은 임상자료라도 장기 생존 꼬리 가정에 따라 의사결정 결론이 바뀔 수 있다.](figures/ch10/fig-ch10-scenario-icer.png)

시나리오 간 ICER 차이가 크다면 이는 단순한 모수 오차가 아니라 외삽 구조가 의사결정을 좌우한다는 신호이다. 이 경우 한 모형의 PSA만 제시해서는 전체 불확실성을 설명할 수 없다.

## 유연한 생존모형의 선택과 보고 {#sec-reporting-flexible-survival-models}

### Base-case와 scenario analysis

경제성 평가 보고서에서는 하나의 base-case 생존외삽 모형을 선택해야 하는 경우가 많다. 그러나 생존외삽에는 구조적 불확실성이 크므로, 여러 plausible model을 scenario analysis로 제시하는 것이 바람직하다.

Base-case 모형은 다음 조건을 충족해야 한다.

- 관찰자료에 충분히 적합하다.
- 위험함수의 장기 형태가 임상적으로 타당하다.
- 장기 생존율이 외부 자료와 모순되지 않는다.
- 일반인 사망률 또는 자연사 자료와 일관된다.
- 경제성 평가 모형 구조와 일관된다.
- 가정이 의사결정자에게 설명 가능하다.

Scenario analysis에는 다음을 포함할 수 있다.


Base-case 선택은 다음 세 층의 근거를 순서대로 검토하는 것이 유용하다.

1. **통계적 적합성**: 우도, AIC/BIC, 잔차, 관찰구간의 생존·누적위험 적합
2. **외적 타당성**: registry, 장기 추적, 자연사, 일반인 생명표와의 일치
3. **의사결정 타당성**: RMST, QALY, 비용, NMB가 합리적인 범위에 있고 대안 가정에 얼마나 민감한지

첫 번째 층만 만족하는 모형은 관찰자료 설명모형일 수는 있어도 경제성 평가의 장기 예측모형으로 충분하지 않다. 특히 AIC 차이가 작을 때는 단일 최적모형을 선택하는 것보다 복수의 임상적으로 타당한 모형을 유지하는 것이 합리적이다.

- 다른 knot 수를 가진 flexible parametric model
- 독립 적합과 공동 적합 비교
- 비례위험과 시간-의존 치료효과 비교
- mixture model의 성분 수 또는 성분분포 변경
- cure fraction 또는 일반인 사망률 연결 가정 변경
- 임상시험 이후 특정 시점부터 외부자료를 쓰는 piecewise model
- 치료효과가 일정 시점 이후 감소하거나 소실되는 모형

### 모수 불확실성과 구조적 불확실성의 전파

모형 $m$의 모수벡터를 $\theta_m$이라고 하면 PSA에서는 먼저 모형을 고정한 채

$$
\theta_m^{(b)}\sim p(\theta_m\mid D,m)
$$

를 생성하고 비용과 QALY를 계산한다. 이는 **모형 내 불확실성**을 반영한다. Knot 수, 척도, mixture 성분 수, cure 구조와 같은 모형 선택까지 반영하려면

$$
M^{(b)}\sim p(M\mid D),
\qquad
\theta_{M^{(b)}}^{(b)}\sim p(\theta_{M^{(b)}}\mid D,M^{(b)})
$$

와 같은 계층적 생성이 필요하다. 전체 분산은

$$
\operatorname{Var}(Y)
=
\mathbb{E}_M\{\operatorname{Var}(Y\mid M)\}
+
\operatorname{Var}_M\{\mathbb{E}(Y\mid M)\}
$$

로 분해되며, 두 번째 항이 구조적 모형 불확실성이다.

모형확률을 정당화하기 어렵다면 확률적 평균 대신 각 구조를 분리한 시나리오 분석을 제시할 수 있다. 중요한 것은 한 모형의 계수 공분산만 PSA에 넣고 모형 선택의 불확실성을 모두 해결했다고 해석하지 않는 것이다.

### 의사결정 중심의 검증

생존모형의 검증 대상은 생존확률뿐 아니라 경제성 평가에서 실제로 사용되는 함수여야 한다. 주요 검증량은 다음과 같다.

$$
\operatorname{RMST}(\tau)=\int_0^\tau S(t)dt,
$$

$$
Q(\tau)=\int_0^\tau u(t)S(t)dt,
$$

$$
C(\tau)=\int_0^\tau c(t)S(t)dt,
$$

$$
NMB(\lambda)=\lambda\Delta Q-\Delta C.
$$

두 모형이 관찰구간 생존곡선에서는 거의 같더라도 진행 이후 비용이나 장기 효용이 크게 다르면 NMB 차이가 확대될 수 있다. 따라서 외삽 검증과 보고는 주요 시점별 생존율뿐 아니라 RMST, 상태체류시간, 증분 QALY와 NMB까지 연결되어야 한다.

::: {.callout-note}
## 투명성의 원칙 {.unnumbered}

생존외삽은 경제성 평가에서 가장 큰 구조적 불확실성의 원천 중 하나이다. 어떤 모형을 선택했는지보다, 왜 그 모형을 선택했는지와 다른 합리적 선택을 했을 때 결과가 어떻게 달라지는지를 투명하게 제시하는 것이 더 중요하다.
:::

rmst <- function(time, survival) {
  sum(diff(time) * (head(survival, -1) + tail(survival, -1)) / 2)
}

weibull_surv <- function(t, scale, shape) {
  exp(- (t / scale)^shape)
}

make_flexible_surv <- function(time) {
  H <- 0.025 * time^1.05 + 0.020 * pmax(time - 3, 0)^1.55 -
    0.010 * pmax(time - 8.5, 0)^1.25
  H <- cummax(pmax(H, 0))
  exp(-H)
}

time <- seq(0, 15, by = 0.05)
S_weibull <- weibull_surv(time, scale = 10.5, shape = 1.35)
S_flexible <- make_flexible_surv(time)

c(
  rmst_weibull_15 = rmst(time, S_weibull),
  rmst_flexible_15 = rmst(time, S_flexible),
  difference = rmst(time, S_flexible) - rmst(time, S_weibull)
)

plot(time, S_weibull, type = "l", ylim = c(0, 1),
     xlab = "Time", ylab = "Survival")
lines(time, S_flexible, lty = 2)
legend("topright", legend = c("Weibull", "Flexible-like"),
       lty = c(1, 2), bty = "n")

### Piecewise exponential model {.unnumbered}

```{r}
#| label: code-ch10-piecewise
#| eval: true
#| warning: false
#| message: false

piecewise_survival <- function(time, cuts, hazards) {
  H <- numeric(length(time))
  for (i in seq_along(time)) {
    t <- time[i]
    cumhaz <- 0
    for (k in seq_along(hazards)) {
      start <- cuts[k]
      end <- cuts[k + 1]
      duration <- max(0, min(t, end) - start)
      cumhaz <- cumhaz + hazards[k] * duration
    }
    H[i] <- cumhaz
  }
  exp(-H)
}

cuts <- c(0, 2, 6, Inf)
hazards <- c(0.18, 0.075, 0.045)
S_piece <- piecewise_survival(time, cuts, hazards)
cycle <- 1
transition_probs <- 1 - exp(-hazards * cycle)

data.frame(
  interval = c("0-2", "2-6", "6+"),
  hazard = hazards,
  annual_probability = transition_probs
)

plot(time, S_piece, type = "l", ylim = c(0, 1), xlab = "Time", ylab = "Survival")
abline(v = cuts[2:3], lty = 3)
```
