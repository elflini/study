4.1 의사결정론의 핵심 아이디어

경제성 평가는 본질적으로 불확실성하의 의사결정 문제이다. 의사결정자는 여러 치료전략 중 하나를 선택해야 하며, 각 전략의 임상 결과와 비용은 불확실하다. 신약은 기존 치료보다 생존을 연장할 수 있지만 더 비쌀 수 있고, 치료효과가 장기적으로 유지될 수도 있지만 시간이 지나면서 감소할 수도 있다. 또한 치료 전략에 따라 이상반응, 치료 중단, 후속 치료, 입원, 삶의 질 저하가 서로 다르게 발생할 수 있다.

의사결정론에서는 선택 가능한 대안을 전략이라고 한다. 의약품 경제성 평가에서는 다음과 같은 전략을 비교할 수 있다.

  • 기존 표준치료
  • 신약 단독 치료
  • 신약과 기존 치료의 병용요법
  • 바이오마커 검사 후 양성 환자에게만 신약을 사용하는 전략
  • 1차 치료 후 반응 여부에 따라 2차 치료를 선택하는 순차치료 전략
  • 치료 반응, 독성, 재발 여부에 따라 치료를 중단하거나 전환하는 동적 전략

전략 \(j\)를 선택했을 때 환자 한 명에게 발생하는 총 비용을 \(C_j\), 총 QALY를 \(Q_j\)라고 하자. 비용과 QALY는 불확실한 임상 경로에 따라 달라지므로 확률변수로 볼 수 있다. 비용효용분석에서 지불의사금액을 \(\lambda\)라고 하면 전략 \(j\)의 순편익은 다음과 같이 정의된다.

\[ NB_j(\lambda)=\lambda Q_j-C_j. \]

의사결정자가 관심을 가지는 것은 개별 환자 한 명의 우연한 결과가 아니라 대상 인구집단에서의 기대가치이다. 따라서 기대순편익은 다음과 같다.

\[ \mu_{NB,j}(\lambda)=\mathbb{E}\{NB_j(\lambda)\} =\lambda \mathbb{E}(Q_j)-\mathbb{E}(C_j). \]

비교 가능한 전략 집합을 \(\mathcal{J}\)라고 하면 기대순편익 기준의 최적 전략은 다음과 같다.

\[ j^*(\lambda)=\arg\max_{j\in\mathcal{J}} \mu_{NB,j}(\lambda). \]

이 식은 모형 기반 경제성 평가의 핵심을 압축한다. 모델은 단순히 장기 비용과 장기 효과를 예측하는 계산 장치가 아니라, 각 전략의 기대순편익을 비교하기 위해 질병 진행, 치료효과, 비용, 효용, 불확실성을 하나의 수리적 구조 안에 결합하는 도구이다.

4.1.1 기대효용과 순편익의 관계

순편익 기준은 비용과 건강효과를 하나의 공통 척도로 바꾸어 기대효용을 비교하는 의사결정 규칙으로 해석할 수 있다. 지불의사금액 \(\lambda\)가 일정하고 건강효과 한 단위의 사회적 가치가 선형이라고 가정하면, 전략 \(j\)의 효용은 \(\lambda Q_j-C_j\)에 비례한다. 이때 기대순편익을 최대화하는 전략은 기대효용을 최대화하는 전략과 일치한다.

경제성 평가에서 불확실한 모수의 집합을 \(\boldsymbol{\theta}\)라고 하면 전략 \(j\)의 순편익은 \(NB_j(\boldsymbol{\theta};\lambda)\)로 쓸 수 있다. 현재 근거에 기반한 의사결정은 모수의 사후분포 또는 표본분포에 대해 평균을 취한 다음 기대순편익이 가장 큰 전략을 선택하는 문제이다.

\[ j^*(\lambda) =\arg\max_{j\in\mathcal{J}} \mathbb{E}_{\boldsymbol{\theta}} \left[NB_j(\boldsymbol{\theta};\lambda)\right]. \]

순편익이 비용과 QALY에 대해 선형이므로 다음 관계가 성립한다.

\[ \mathbb{E}_{\boldsymbol{\theta}}\{NB_j(\boldsymbol{\theta};\lambda)\} =\lambda\mathbb{E}_{\boldsymbol{\theta}}\{Q_j(\boldsymbol{\theta})\} -\mathbb{E}_{\boldsymbol{\theta}}\{C_j(\boldsymbol{\theta})\}. \]

반면 ICER는 비선형 비율이므로 일반적으로 다음 등식은 성립하지 않는다.

\[ \mathbb{E}\left(\frac{\Delta C}{\Delta Q}\right) \ne \frac{\mathbb{E}(\Delta C)}{\mathbb{E}(\Delta Q)}. \]

따라서 불확실성하의 전략 선택에서는 개별 모수 추출값에서 계산한 ICER를 단순 평균하는 것보다 증분순편익의 분포를 이용하는 것이 수학적으로 안정적이다.

4.1.2 결과의 무작위성과 모수 불확실성

모형 기반 평가에는 서로 다른 두 층위의 불확실성이 존재한다. 첫째는 동일한 모수값이 주어져도 환자별 질병 경로와 비용이 달라지는 결과의 무작위성이다. 둘째는 전이위험, 치료효과, 비용, 효용과 같은 모수 자체에 대한 불확실성이다. 미래 환자 결과를 \(Y\)라고 하면 전체 기대값은 반복기대값 법칙에 의해 다음과 같이 분해된다.

\[ \mathbb{E}(Y) =\mathbb{E}_{\boldsymbol{\theta}} \left\{\mathbb{E}(Y\mid\boldsymbol{\theta})\right\}. \]

전체 분산은 다음과 같이 분해된다.

\[ \operatorname{Var}(Y) =\mathbb{E}_{\boldsymbol{\theta}} \left\{\operatorname{Var}(Y\mid\boldsymbol{\theta})\right\} +\operatorname{Var}_{\boldsymbol{\theta}} \left\{\mathbb{E}(Y\mid\boldsymbol{\theta})\right\}. \]

첫 번째 항은 환자 경로의 변동성을, 두 번째 항은 모수 불확실성을 나타낸다. 경제성 평가의 확률론적 민감도 분석은 주로 두 번째 항이 의사결정 불확실성에 미치는 영향을 평가한다.

Note핵심 메시지

모형 기반 경제성 평가는 “치료효과가 통계적으로 유의한가?”보다 넓은 질문을 다룬다. 핵심 질문은 “현재의 근거와 명시적인 가정하에서 어떤 전략의 기대순편익이 가장 큰가?”이다.

이 그림은 경제성 평가 모델의 입력과 출력 사이의 논리적 흐름을 보여준다. 의사결정 문제와 대상 인구집단을 먼저 정의한 뒤, 임상근거와 비용·효용 자료를 모형 구조에 결합하여 전략별 기대순편익을 산출한다. 따라서 모형 구조나 입력자료를 먼저 선택한 뒤 의사결정 문제를 끼워 맞추는 방식은 피해야 한다.

4.1.3 의사결정 문제의 구성요소

모형 기반 경제성 평가에서 의사결정 문제는 보통 다음 요소로 구성된다.

구성요소 의미 예
전략 비교 대상 치료 대안 신약, 기존 치료, 병용요법, 검사 기반 치료
대상 인구집단 의사결정이 적용되는 환자집단 전이성 암 2차 치료 환자, 특정 유전자 변이 양성 환자
시간 범위 비용과 건강효과를 누적할 기간 1년, 5년, 10년, 평생

모델 구조는 어떤 건강상태를 포함할지, 상태 간 이동을 어떻게 허용할지, 시간에 따라 비용과 효과를 어떻게 누적할지를 결정한다. 따라서 모형 구조는 단순한 형식 선택이 아니라 경제성 평가 결과의 타당성을 좌우하는 핵심 가정이다.

대상 인구집단에 환자 특성 \(X\)가 분포한다고 하면 전략 \(j\)의 인구집단 기대순편익은 다음과 같다.

\[ \mu_{NB,j}(\lambda) =\mathbb{E}_{X}\left[ \lambda\,\mathbb{E}(Q_j\mid X) -\mathbb{E}(C_j\mid X) \right]. \]

이 식은 평균적인 환자 한 명만을 모델링하는 것과 환자 이질성을 적절히 평균하는 것이 항상 같지 않음을 보여준다. 치료효과, 기저위험, 비용 또는 효용이 비선형적으로 환자 특성에 의존하면 평균 환자에 대한 결과가 목표 모집단의 평균 결과를 재현하지 못할 수 있다. 이 경우에는 하위집단 분석, 표준화 또는 환자 수준 시뮬레이션이 필요하다.

4.2 경제성 평가 모델

경제성 평가 모델은 질병 진행과 치료전략의 결과를 수학적 또는 컴퓨터 시뮬레이션 구조로 표현한 것이다. 좋은 모델은 실제 세계를 완벽하게 복제하지 않는다. 대신 의사결정에 중요한 임상 경로와 비용·효과 발생 과정을 충분히 타당하고 투명하게 표현한다. 모델은 자료가 없는 부분을 임의로 채우는 도구가 아니라, 서로 다른 자료원을 일관된 의사결정 구조 안에서 결합하고 관찰되지 않은 장기 결과를 명시적 가정하에 추정하는 도구이다.

4.2.1 연속시간 표현

전략 \(j\)를 따르는 환자의 건강상태 과정을 \(S_j(t)\)라고 하자. 분석 시간 범위는 \(0\le t\le \tau\)이다. 상태 \(s\)에서 시간 \(t\)에 발생하는 비용률을 \(c_j(s,t)\), 효용을 \(u_j(s,t)\)라고 하자. 비용과 QALY에 같은 할인율을 적용한다고 하면 할인계수는 다음과 같다.

\[ d(t)=\frac{1}{(1+r)^t}. \]

이때 연속시간에서 기대비용과 기대 QALY는 다음과 같이 표현할 수 있다.

\[ \mu_{C,j}(\tau)=\mathbb{E}\left[\int_0^\tau d(t)c_j\{S_j(t),t\}\,dt +\sum_{m} d(T_{jm})c^{event}_{jm}\right], \]

\[ \mu_{Q,j}(\tau)=\mathbb{E}\left[\int_0^\tau d(t)u_j\{S_j(t),t\}\,dt\right]. \]

여기서 \(T_{jm}\)은 전략 \(j\)에서 사건 \(m\)이 발생하는 시간이고, \(c^{event}_{jm}\)은 해당 사건에 연결되는 일회성 비용이다. 예를 들어 중증 이상반응 발생 시 입원비, 치료 시작 시 검사 비용, 사망 직전 비용은 사건 비용으로 모델링할 수 있다.

연속시간 표현에서 상태 비용률과 효용은 환자가 각 상태에 머무는 시간에 비례하여 누적된다. 상태 \(s\)의 점유확률을 \(\pi_{j,s}(t)=P\{S_j(t)=s\}\)라고 하면 반복기대값 법칙을 이용하여 기대비용의 상태 보상 부분을 다음처럼 다시 쓸 수 있다.

\[ \mathbb{E}\left[ \int_0^\tau d(t)c_j\{S_j(t),t\}\,dt \right] = \int_0^\tau d(t) \sum_s \pi_{j,s}(t)c_j(s,t)\,dt. \]

따라서 대부분의 상태 기반 모델은 결국 시간별 상태 점유확률과 상태별 보상을 결합하는 구조를 가진다. 결정수형, 마코프모델, 분할생존모델은 상태 점유확률을 산출하는 방식이 서로 다를 뿐, 비용과 QALY를 누적하는 기본 원리는 동일하다.

4.2.2 연속시간 전이와 생성행렬

연속시간 마코프과정에서 상태 \(a\)에서 상태 \(b\)로 이동하는 순간 전이율을 \(q_{ab}\)라고 하자. 생성행렬 \(\boldsymbol{Q}\)는 비대각 원소가 음이 아닌 전이율이고, 대각 원소는 해당 상태에서 빠져나가는 총 전이율의 음수로 정의된다.

\[ q_{ab}\ge 0\quad(a\ne b), \qquad q_{aa}=-\sum_{b\ne a}q_{ab}. \]

전이율이 시간에 따라 일정하면 길이 \(\Delta t\)인 주기의 전이확률 행렬은 행렬지수로 계산된다.

\[ \boldsymbol{P}(\Delta t)=\exp(\boldsymbol{Q}\Delta t). \]

이 관계는 연속시간 사건 발생 과정과 이산시간 마코프모델을 연결한다. 경쟁하는 전이가 여러 개 있거나 상태 간 왕복 이동이 가능한 경우, 각 전이율을 별도로 단순 변환하는 것보다 생성행렬의 행렬지수를 이용하는 것이 확률의 합과 다단계 이동을 일관되게 반영한다.

4.2.3 이산시간 표현

대부분의 경제성 평가 모델은 계산의 편의를 위해 시간을 일정한 주기로 나눈다. 주기 길이를 \(\Delta t\)라고 하고, 시점 \(t=0,1,\ldots,T\)에서 전략 \(j\)의 상태분포 벡터를 \(\boldsymbol{\pi}_{j,t}\)라고 하자. 상태별 비용 벡터를 \(\boldsymbol{c}_{j,t}\), 상태별 효용 벡터를 \(\boldsymbol{u}_{j,t}\)라고 하면 한 주기의 기대비용과 기대효용은 다음과 같다.

\[ \mathbb{E}(C_{j,t})=\boldsymbol{\pi}_{j,t}\boldsymbol{c}_{j,t}^{\top}, \]

\[ \mathbb{E}(U_{j,t})=\boldsymbol{\pi}_{j,t}\boldsymbol{u}_{j,t}^{\top}. \]

전체 분석 기간 동안 누적 기대비용과 기대 QALY는 다음과 같이 근사할 수 있다.

\[ \mu_{C,j}(\tau)\approx \sum_{t=0}^{T-1} \boldsymbol{\pi}_{j,t}^{*}\boldsymbol{c}_{j,t}^{\top}d(t^*), \]

\[ \mu_{Q,j}(\tau)\approx \sum_{t=0}^{T-1} \boldsymbol{\pi}_{j,t}^{*}\boldsymbol{u}_{j,t}^{\top}\Delta t\,d(t^*). \]

여기서 \(\boldsymbol{\pi}_{j,t}^{*}\)는 보상을 계산할 때 사용하는 대표 상태분포이다. 주기 시작 분포를 사용할 수도 있고, 주기 종료 분포를 사용할 수도 있으며, 반주기 보정을 사용하면 다음과 같이 주기 시작과 종료의 평균을 사용할 수 있다.

\[ \boldsymbol{\pi}_{j,t}^{*}=\frac{\boldsymbol{\pi}_{j,t}+\boldsymbol{\pi}_{j,t+1}}{2}. \]

\(t^*\)는 할인을 적용하는 대표 시점이다. 월별 주기에서 첫 번째 주기 중간에 보상이 발생한다고 가정하면 \(t^*=(t+0.5)\Delta t\)를 사용할 수 있다.

반주기 보정은 수치적분의 사다리꼴 공식과 같은 원리를 사용한다. 시간에 따른 기대 보상률을 \(g(t)\)라고 하면 다음 근사가 성립한다.

\[ \int_0^{T\Delta t}g(t)\,dt \approx \Delta t\left[ \frac{g(0)}{2} +\sum_{t=1}^{T-1}g(t\Delta t) +\frac{g(T\Delta t)}{2} \right]. \]

주기 시작과 종료의 상태분포를 평균하는 반주기 보정은 이 사다리꼴 근사를 상태 보상에 적용한 것이다. 다만 치료 시작비용, 진행 진단비용, 사망비용처럼 특정 시점에 발생하는 사건 보상에는 반주기 보정을 기계적으로 적용해서는 안 된다. 사건 보상은 실제 또는 가정된 사건 발생 시점에 할인해야 한다.

Important모형의 구조와 모수

경제성 평가 모델은 구조와 모수로 나눌 수 있다. 구조는 상태, 사건, 전이, 보상 누적 방식을 의미하고, 모수는 전이확률, 위험률, 생존곡선, 비용, 효용, 상대효과 등을 의미한다. 구조가 임상적으로 부적절하면 정확한 모수를 사용해도 결과가 왜곡될 수 있다.

이 그림에서 상태 점유확률은 임상모형이 산출하는 부분이고, 비용과 효용은 보상모형이 제공하는 부분이다. 두 부분을 분리하여 생각하면 어떤 가정이 임상 경로에 관한 것인지, 어떤 가정이 자원사용과 삶의 질에 관한 것인지 명확해진다. 또한 동일한 질병진행모형에 서로 다른 비용 관점이나 효용값을 적용할 수 있고, 반대로 동일한 보상구조에 여러 생존 외삽 시나리오를 적용할 수 있다.

4.2.4 모형 구조 선택의 기본 원칙

모형 구조는 평가 대상 질병의 자연사, 치료 경로, 의사결정 문제의 시간 범위, 이용 가능한 자료의 형태에 맞추어 선택해야 한다. 가장 좋은 모델은 가장 복잡한 모델이 아니라, 의사결정에 중요한 요소를 충분히 반영하면서도 검증과 설명이 가능한 모델이다.

의사결정 문제의 특징 우선 고려할 모형
단기 사건, 명확한 성공·실패, 반복 경로가 거의 없음 결정수형
장기 질병 진행, 상태별 비용과 효용, 반복 주기 마코프 코호트 모델

그림의 모형들은 서로 배타적인 선택지가 아니다. 예를 들어 초기 진단검사 결과는 결정수형으로 표현하고, 이후 장기 질병 진행은 마코프모델로 연결할 수 있다. 또는 분할생존모델의 상태 점유확률에 환자 수준 치료중단 모듈을 결합할 수도 있다. 중요한 것은 모형의 이름보다 각 구성요소가 어떤 자료와 가정으로 계산되는지를 명시하는 것이다.

4.3 결정수형

결정수형은 가장 단순하고 직관적인 경제성 평가 모델 중 하나이다. 결정수형에서는 의사결정자가 선택할 수 있는 전략에서 시작하여, 이후 발생할 수 있는 사건과 결과를 가지 형태로 표현한다. 각 가지에는 확률이 부여되고, 말단 노드에는 비용과 QALY가 연결된다.

결정수형은 보통 다음과 같은 상황에 적합하다.

  • 분석 기간이 짧다.
  • 사건의 순서가 비교적 단순하다.
  • 환자가 동일한 건강상태를 반복적으로 오가지 않는다.
  • 시간에 따른 장기 질병 진행보다 단기 사건 발생 여부가 중요하다.
  • 말단 결과를 임상적으로 명확하게 정의할 수 있다.

4.3.1 경로 기반 기대값 계산

전략 \(j\)에서 가능한 말단 경로의 집합을 \(\mathcal{L}_j\)라고 하자. 경로 \(\ell\in\mathcal{L}_j\)의 발생확률을 \(p_{j\ell}\), 해당 경로의 총 비용과 QALY를 각각 \(C_{j\ell}\), \(Q_{j\ell}\)라고 하면 전략 \(j\)의 기대비용과 기대 QALY는 다음과 같다.

\[ \mu_{C,j}=\sum_{\ell\in\mathcal{L}_j}p_{j\ell}C_{j\ell}, \]

\[ \mu_{Q,j}=\sum_{\ell\in\mathcal{L}_j}p_{j\ell}Q_{j\ell}. \]

각 전략의 경로 확률은 해당 경로를 구성하는 가지 확률의 곱으로 계산된다. 예를 들어 전략 \(j\)에서 성공 여부와 중증 이상반응 여부를 모두 고려하고 두 사건이 조건부로 순차적으로 발생한다면, 특정 경로의 확률은 다음과 같이 계산될 수 있다.

\[ p_{j,\text{success, AE}}=P(\text{success}\mid j)P(\text{AE}\mid \text{success},j). \]

두 전략 \(1\)과 \(0\)을 비교할 때 증분비용, 증분 QALY, ICER는 다음과 같다.

\[ \Delta C=\mu_{C,1}-\mu_{C,0}, \]

\[ \Delta Q=\mu_{Q,1}-\mu_{Q,0}, \]

\[ ICER=\frac{\Delta C}{\Delta Q},\qquad \Delta Q\neq 0. \]

순편익 기준으로는 다음을 비교하면 된다.

\[ INB(\lambda)=\lambda\Delta Q-\Delta C. \]

\(INB(\lambda)>0\)이면 지불의사금액 \(\lambda\)에서 전략 \(1\)의 기대순편익이 전략 \(0\)보다 크다.

4.3.2 경로확률과 역방향 계산

각 말단 경로의 확률은 0 이상이어야 하며 한 전략 아래 모든 상호 배타적 경로의 확률 합은 1이어야 한다.

\[ \sum_{\ell\in\mathcal{L}_j}p_{j\ell}=1. \]

결정수형은 말단 노드에서 시작하여 기대값을 거꾸로 계산하는 역방향 계산 또는 rollback으로 평가할 수 있다. 확률 노드 \(n\)의 하위 노드 집합을 \(\mathcal{C}(n)\)이라고 하고, 하위 노드 \(m\)으로 이동할 조건부확률을 \(p_{nm}\), 하위 노드의 가치를 \(V(m)\)이라고 하면 확률 노드의 가치는 다음과 같다.

\[ V(n)=\sum_{m\in\mathcal{C}(n)}p_{nm}V(m). \]

의사결정 노드에서는 가능한 가지 중 기대순편익이 가장 큰 가지를 선택한다.

\[ V(n)=\max_{m\in\mathcal{C}(n)}V(m). \]

이 재귀적 계산은 결정수형이 동적계획법의 가장 단순한 형태임을 보여준다. 다만 사건이 반복되거나 과거 이력에 따라 이후 확률이 달라지면 동일한 임상상태라도 서로 다른 가지로 계속 분리해야 하므로 나무의 크기가 기하급수적으로 증가한다.

그림을 읽을 때는 먼저 전략별로 가능한 모든 말단 경로가 빠짐없이 포함되었는지 확인해야 한다. 다음으로 각 분기확률이 이전 사건에 조건부인지, 독립확률로 잘못 사용되지 않았는지 점검해야 한다. 마지막으로 말단 비용과 QALY가 경로 중 발생한 모든 사건을 누적한 값인지 확인한다.

간단한 예제

신약과 기존 치료를 비교한다고 하자. 1개월 이내 치료 성공 여부만 고려하며, 이후 장기 결과는 고려하지 않는 단기 의사결정 문제이다.

전략 성공확률 성공 시 비용 실패 시 비용 성공 시 QALY 실패 시 QALY
신약 0.80 5,000,000 7,000,000 0.080 0.050
기존 치료 0.65 2,000,000 5,000,000 0.075 0.045

신약의 기대비용과 기대 QALY는 다음과 같다.

\[ \mu_{C,1}=0.80\times 5{,}000{,}000+0.20\times 7{,}000{,}000=5{,}400{,}000, \]

\[ \mu_{Q,1}=0.80\times 0.080+0.20\times 0.050=0.074. \]

기존 치료의 기대비용과 기대 QALY는 다음과 같다.

\[ \mu_{C,0}=0.65\times 2{,}000{,}000+0.35\times 5{,}000{,}000=3{,}050{,}000, \]

\[ \mu_{Q,0}=0.65\times 0.075+0.35\times 0.045=0.0645. \]

따라서 증분비용과 증분 QALY는 다음과 같다.

\[ \Delta C=5{,}400{,}000-3{,}050{,}000=2{,}350{,}000, \]

\[ \Delta Q=0.074-0.0645=0.0095. \]

ICER는 다음과 같다.

\[ ICER=\frac{2{,}350{,}000}{0.0095}=247{,}368{,}421 \text{ KRW/QALY}. \]

이 예제에서 신약은 더 효과적이지만 비용도 증가시킨다. 따라서 신약의 비용효과성은 지불의사금액 기준과 비교하여 판단한다. 예를 들어 \(\lambda=50{,}000{,}000\) KRW/QALY이면 다음과 같다.

\[ INB(50{,}000{,}000)=50{,}000{,}000\times0.0095-2{,}350{,}000=-1{,}875{,}000. \]

따라서 이 지불의사금액에서는 신약의 기대순편익이 기존 치료보다 작다.

4.3.3 결정수형의 장점과 한계

결정수형의 가장 큰 장점은 직관성이다. 의사결정 노드, 확률 노드, 결과 노드가 명확하게 표현되므로 비전문가도 모델 구조를 이해하기 쉽다. 또한 분석 기간이 짧고 사건이 단순한 경우에는 결정수형만으로도 충분히 타당한 경제성 평가가 가능하다.

그러나 결정수형은 시간에 따른 반복적 질병 진행을 표현하기 어렵다. 만성질환이나 암처럼 환자가 여러 건강상태를 거치고 장기간 비용과 효과가 누적되는 경우 결정수형은 가지가 빠르게 증가하여 해석과 검증이 어려워진다. 이런 경우에는 마코프모델이나 환자 수준 시뮬레이션이 더 적합하다.

Tip결정수형을 사용할 수 있는 경우

결정수형은 단기 의사결정, 일회성 사건, 명확한 치료 성공 또는 실패 구조를 가진 문제에 적합하다. 반복적인 질병 진행, 장기 생존, 상태 간 순환, 상태 체류기간 효과가 중요한 문제에는 적합하지 않을 수 있다.

4.4 마코프모델

마코프모델은 모형 기반 경제성 평가에서 가장 널리 사용되는 구조 중 하나이다. 마코프모델에서는 질병 진행을 상호 배타적이고 포괄적인 건강상태의 집합으로 표현하고, 환자가 일정한 시간 간격마다 한 상태에서 다른 상태로 이동한다고 가정한다.

마코프모델은 특히 다음 상황에 적합하다.

  • 질병이 시간에 따라 진행된다.
  • 환자가 여러 건강상태를 거친다.
  • 비용과 효용이 상태별로 누적된다.
  • 장기 분석 기간이 필요하다.
  • 상태 간 전이확률 또는 전이위험을 추정할 수 있다.

예를 들어 진행성 암 경제성 평가에서는 다음과 같은 3상태 구조가 자주 사용된다.

\[ \text{Progression-free}\rightarrow \text{Progressed disease}\rightarrow \text{Death}. \]

4.4.1 상태분포 벡터와 전이행렬

건강상태가 \(K\)개라고 하자. 시간 \(t\)에서의 상태분포는 행벡터로 표현할 수 있다.

\[ \boldsymbol{\pi}_t=(\pi_{t1},\pi_{t2},\ldots,\pi_{tK}). \]

여기서 \(\pi_{tk}\)는 시간 \(t\)에서 상태 \(k\)에 있는 환자의 비율이다. 모든 환자는 하나의 상태에 속해야 하므로 다음이 성립한다.

\[ \sum_{k=1}^{K}\pi_{tk}=1. \]

전이확률 행렬은 다음과 같다.

\[ \boldsymbol{P}_t= \begin{pmatrix} p_{11,t} & p_{12,t} & \cdots & p_{1K,t} \\ p_{21,t} & p_{22,t} & \cdots & p_{2K,t} \\ \vdots & \vdots & \ddots & \vdots \\ p_{K1,t} & p_{K2,t} & \cdots & p_{KK,t} \end{pmatrix}. \]

여기서 \(p_{ab,t}\)는 시간 \(t\)에서 상태 \(a\)에 있는 환자가 다음 주기에 상태 \(b\)로 이동할 확률이다. 각 행의 합은 1이어야 한다.

\[ \sum_{b=1}^{K}p_{ab,t}=1,\qquad a=1,\ldots,K. \]

다음 주기의 상태분포는 다음과 같이 계산한다.

\[ \boldsymbol{\pi}_{t+1}=\boldsymbol{\pi}_t\boldsymbol{P}_t. \]

전이행렬이 시간에 따라 변하지 않으면 시간동질 마코프모델이고, \(\boldsymbol{P}_t\)가 시간, 나이, 주기, 치료 지속기간 등에 따라 달라지면 시간비동질 마코프모델이다. 실제 경제성 평가에서는 나이 증가에 따른 배경 사망률, 치료효과 감소, 치료 중단률 변화 등을 반영하기 위해 시간비동질 구조가 자주 필요하다.

그림의 화살표는 임상적으로 가능한 전이만을 나타낸다. 화살표가 없다는 것은 해당 전이가 불가능하다는 구조적 가정이다. 예를 들어 진행 후 무진행 상태로 돌아가는 화살표를 제외하면 치료반응이나 재관해를 모형에서 허용하지 않는다는 의미가 된다. 따라서 상태도는 단순한 설명 그림이 아니라 허용되는 환자 경로를 규정하는 수학적 제약이다.

4.4.2 상태 보상, 전이 보상, 반주기 보정

상태별 비용 벡터를 \(\boldsymbol{c}_t=(c_{1,t},\ldots,c_{K,t})\), 상태별 효용 벡터를 \(\boldsymbol{u}_t=(u_{1,t},\ldots,u_{K,t})\)라고 하자. 주기 \(t\)에서 반주기 보정을 적용한 대표 상태분포를 \(\boldsymbol{\pi}_t^*\)라고 하면 상태 보상에 의한 비용과 QALY는 다음과 같다.

\[ C_t^{state}=\boldsymbol{\pi}_t^*\boldsymbol{c}_t^\top, \]

\[ Q_t^{state}=\boldsymbol{\pi}_t^*\boldsymbol{u}_t^\top\Delta t. \]

반주기 보정은 환자가 주기 시작 또는 주기 종료에만 상태를 바꾸는 것이 아니라 주기 중간에 평균적으로 상태를 이동한다고 보는 근사이다. 가장 흔한 형태는 다음과 같다.

\[ \boldsymbol{\pi}_t^*=\frac{\boldsymbol{\pi}_t+\boldsymbol{\pi}_{t+1}}{2}. \]

일부 비용은 상태에 머무는 것보다 상태 전이에 의해 발생한다. 예를 들어 진행 진단 비용, 사망 직전 비용, 치료 시작 비용은 전이 보상 또는 사건 보상으로 모델링하는 것이 더 자연스럽다. 상태 \(a\)에서 상태 \(b\)로 이동할 때 발생하는 전이 비용을 \(r^C_{ab,t}\)라고 하면 해당 주기의 기대 전이 비용은 다음과 같다.

\[ C_t^{transition}=\sum_{a=1}^{K}\sum_{b=1}^{K}\pi_{t,a}p_{ab,t}r^C_{ab,t}. \]

따라서 주기 \(t\)의 전체 비용은 다음과 같이 표현할 수 있다.

\[ C_t=C_t^{state}+C_t^{transition}. \]

상태 \(k\)에서의 기대 체류시간은 상태 점유확률 곡선 아래의 면적으로 해석할 수 있다. 이산시간에서는 다음과 같이 근사한다.

\[ \mathbb{E}(T_k) \approx \Delta t\sum_{t=0}^{T-1}\pi_{t,k}^{*}. \]

상태별 비용이 단위시간당 비용률 \(c_k\)이고 시간에 따라 일정하다면, 상태 보상 비용은 기대 체류시간과 비용률의 곱으로 이해할 수 있다.

\[ \mu_C^{state} \approx \sum_{k=1}^{K}c_k\,\mathbb{E}(T_k), \]

할인이 있으면 각 시점의 점유확률에 할인계수를 적용한 할인 체류시간을 사용한다. 이 표현은 Markov trace가 단순한 환자 비율의 변화가 아니라 상태별 생존시간, 비용, QALY를 계산하는 핵심 중간 산출물임을 보여준다.

전체 누적 비용과 QALY는 할인계수 \(d(t^*)\)를 적용하여 다음과 같이 계산한다.

\[ \mu_C=\sum_{t=0}^{T-1} C_t d(t^*), \]

\[ \mu_Q=\sum_{t=0}^{T-1} Q_t^{state} d(t^*). \]

Markov trace의 각 행은 한 시점의 상태분포이므로 행의 합은 항상 1이어야 한다. 흡수상태가 사망인 일반적인 질병모형에서는 시간이 지날수록 사망상태의 점유확률은 감소하지 않아야 한다. 이러한 단순한 제약은 구현 오류를 발견하는 내부 검증 규칙으로 사용할 수 있다.

4.4.3 위험률에서 전이확률로 변환

마코프모델의 전이확률은 임상시험이나 관찰연구에서 직접 얻을 수도 있지만, 흔히 위험률 또는 생존함수에서 변환하여 계산한다. 한 주기 동안 상태 \(a\)에서 다른 상태로 나가는 총 위험률이 \(h_a\)이고 주기 길이가 \(\Delta t\)라면, 상수 위험률 가정하에서 상태 \(a\)를 떠날 확률은 다음과 같다.

\[ p_{a,\text{leave}}=1-\exp(-h_a\Delta t). \]

여러 경쟁 전이가 있고 상태 \(a\)에서 상태 \(b\)로 가는 원인별 위험률이 \(h_{ab}\)라면 총 위험률은 \(h_a=\sum_{b\ne a}h_{ab}\)이다. 위험률이 주기 안에서 일정하다고 가정하면 전이확률은 다음과 같다.

\[ p_{ab}=\frac{h_{ab}}{h_a}\{1-\exp(-h_a\Delta t)\},\qquad b\ne a, \]

\[ p_{aa}=\exp(-h_a\Delta t). \]

이 식은 특히 여러 전이가 동시에 가능한 상태에서 각 전이확률의 합이 1을 넘지 않도록 만드는 데 중요하다.

위 식은 주기 안에서 원인별 위험률이 일정하고, 상태를 떠난 뒤 같은 주기 안에 추가 전이를 하지 않는 단순 구조에서 직관적으로 해석할 수 있다. 일반적인 연속시간 다상태모형에서는 생성행렬 \(\boldsymbol{Q}\)를 구성한 뒤 다음과 같이 전이확률 행렬을 얻는 것이 더 일반적이다.

\[ \boldsymbol{P}(\Delta t)=\exp(\boldsymbol{Q}\Delta t). \]

행렬지수는 한 주기 안에서 발생할 수 있는 연속된 여러 이동을 수학적으로 포함한다. 주기가 길거나 상태 간 왕복 이동이 가능할수록 단순한 위험률 변환과 행렬지수의 차이가 커질 수 있다.

4.4.4 주기 길이와 이산화 오차

주기 길이가 길면 사건 발생 시점이 거칠게 근사되어 비용과 QALY에 이산화 오차가 생길 수 있다. 반대로 지나치게 짧은 주기는 계산량을 늘리고, 자료에서 직접 추정하기 어려운 짧은 구간 전이확률을 요구한다. 적절한 주기 길이는 임상적으로 중요한 사건 간격보다 충분히 짧아야 하며, 주기를 더 짧게 했을 때 결과가 안정되는지 확인해야 한다.

상태 체류기간이 미래 전이에 영향을 주는 경우에는 터널 상태를 사용할 수 있다. 예를 들어 진행 후 첫 3개월의 사망위험이 특히 높다면 진행 상태를 \(PD_1,PD_2,PD_3,PD_{4+}\)로 나누어 진행 후 경과시간을 상태에 포함할 수 있다. 이는 과거 이력을 확장된 현재 상태로 바꾸어 마코프 가정을 회복하는 방법이다.

4.4.5 마코프 가정과 그 한계

전통적인 마코프모델은 현재 상태가 주어지면 미래 상태가 과거의 경로와 무관하다는 가정을 사용한다.

\[ P(S_{t+1}=b\mid S_t=a,S_{t-1},\ldots,S_0) =P(S_{t+1}=b\mid S_t=a). \]

이 가정은 모델을 단순하게 만들지만, 현실의 질병 진행을 충분히 반영하지 못할 수 있다. 예를 들어 진행 상태에 들어온 지 오래된 환자와 방금 진행된 환자의 사망위험은 다를 수 있다. 이런 경우에는 진행 후 경과시간을 구분하는 터널 상태를 추가하거나, 상태 체류기간을 전이확률에 포함하거나, 환자 수준 시뮬레이션을 사용할 수 있다.

Warning마코프 가정의 한계

마코프모델에서는 현재 상태가 같으면 과거 경로와 상태 체류기간이 달라도 동일한 미래 전이확률을 가진다고 가정하는 경우가 많다. 질병 이력, 누적 독성, 치료 지속기간, 진행 후 시간 등이 예후에 중요하다면 단순 마코프 가정은 부적절할 수 있다.

4.5 분할생존모델

분할생존모델은 특히 종양학 경제성 평가에서 널리 사용되는 모형 구조이다. 분할생존모델은 건강상태 간 전이확률을 직접 모델링하기보다, 전체생존곡선과 무진행생존곡선을 이용하여 시간별 상태 점유확률을 계산한다.

전형적인 종양학 분할생존모델은 세 상태로 구성된다.

  1. 무진행 생존 상태
  2. 진행 후 생존 상태
  3. 사망 상태

시간 \(t\)에서 무진행생존확률을 \(S_{PFS}(t)\), 전체생존확률을 \(S_{OS}(t)\)라고 하자. 그러면 각 상태의 점유확률은 다음과 같이 계산된다.

\[ \pi_{PF}(t)=S_{PFS}(t), \]

\[ \pi_{PD}(t)=S_{OS}(t)-S_{PFS}(t), \]

\[ \pi_D(t)=1-S_{OS}(t). \]

이 구조의 핵심은 전체 생존 환자 중 무진행 상태에 있지 않은 환자를 진행 후 생존 상태로 분류한다는 점이다. 전체생존곡선 \(S_{OS}(t)\)는 시간 \(t\)까지 생존해 있는 환자의 비율이고, 무진행생존곡선 \(S_{PFS}(t)\)는 시간 \(t\)까지 진행도 사망도 경험하지 않은 환자의 비율이다. 따라서 진행 후 생존 상태는 다음 차이로 정의된다.

분할생존모델은 두 주변 생존분포로 상태 점유확률을 정의하지만, 개별 환자의 진행시간과 사망시간의 결합분포를 직접 규정하지 않는다. 동일한 PFS와 OS 곡선을 재현하는 여러 결합 경로가 존재할 수 있으므로 진행 후 사망위험이나 진행 후 생존기간의 분포는 두 곡선만으로 완전히 식별되지 않는다. 이 점이 상태전이모형과의 중요한 차이이다.

\[ \text{Progressed disease}=\text{Alive}-\text{Progression-free}. \]

그림에서 PFS 곡선 아래의 영역은 무진행 상태에서 보낸 기대시간에 해당하고, OS와 PFS 곡선 사이의 영역은 진행 후 생존 상태에서 보낸 기대시간에 해당한다. OS 곡선 위쪽의 여집합은 누적 사망확률이다. 따라서 분할생존모델의 상태 점유시간은 생존곡선의 면적으로 직접 계산된다.

4.5.1 상태별 제한평균 생존시간

분석 기간을 \(\tau\)라고 하면 무진행 상태의 기대 체류시간은 제한평균 무진행생존시간과 같다.

\[ RMST_{PF}(\tau) =\int_0^\tau S_{PFS}(t)\,dt. \]

전체 생존시간의 제한평균은 다음과 같다.

\[ RMST_{OS}(\tau) =\int_0^\tau S_{OS}(t)\,dt. \]

따라서 진행 후 생존 상태의 기대 체류시간은 두 면적의 차이이다.

\[ RMST_{PD}(\tau) =RMST_{OS}(\tau)-RMST_{PF}(\tau). \]

상태 효용이 시간에 따라 일정하고 할인을 생략하면 기대 QALY는 다음처럼 간단히 표현된다.

\[ \mu_Q(\tau) =u_{PF}RMST_{PF}(\tau) +u_{PD}\{RMST_{OS}(\tau)-RMST_{PF}(\tau)\}. \]

이 식은 PFS와 OS 외삽의 작은 차이가 장기 QALY에 직접 누적될 수 있음을 보여준다.

4.5.2 비용과 QALY 계산

상태별 비용을 \(c_{PF}\), \(c_{PD}\), \(c_D\)라고 하고 상태별 효용을 \(u_{PF}\), \(u_{PD}\), \(u_D\)라고 하자. 일반적으로 사망 상태의 효용은 0이고, 사망 상태 비용도 0으로 두지만, 사망 직전 비용은 별도의 사건 비용으로 추가할 수 있다. 시간 \(t\)에서의 기대비용과 기대효용은 다음과 같다.

\[ C(t)=\pi_{PF}(t)c_{PF}+\pi_{PD}(t)c_{PD}+\pi_D(t)c_D, \]

\[ U(t)=\pi_{PF}(t)u_{PF}+\pi_{PD}(t)u_{PD}+\pi_D(t)u_D. \]

연속시간에서 누적 기대비용과 기대 QALY는 다음과 같다.

\[ \mu_C(\tau)=\int_0^\tau C(t)d(t)\,dt, \]

\[ \mu_Q(\tau)=\int_0^\tau U(t)d(t)\,dt. \]

이산 시간 근사를 사용하면 다음과 같다.

\[ \mu_Q(\tau)\approx \sum_{t=0}^{T-1}U(t^*)\Delta t\,d(t^*). \]

4.5.3 분할생존모델의 일관성 조건

분할생존모델에서는 모든 시점에서 다음 조건이 성립해야 한다.

\[ 1\ge S_{OS}(t)\ge S_{PFS}(t)\ge 0. \]

하지만 PFS와 OS를 서로 독립적으로 모수적 생존모형으로 외삽하면 일부 시점에서 \(S_{PFS}(t)>S_{OS}(t)\)가 되는 비현실적인 결과가 나타날 수 있다. 또한 PFS와 OS 곡선의 상관구조가 명시적으로 반영되지 않을 수 있고, 진행 후 치료나 사망 전 비용의 세부 구조를 직접 모델링하기 어렵다. 이러한 한계 때문에 분할생존모델에서는 생존곡선의 시각적 점검, 장기 외삽의 임상적 타당성, PFS와 OS의 논리적 일관성, 진행 후 생존의 해석 가능성을 반드시 확인해야 한다.

PFS와 OS 추정량은 동일한 임상시험 환자에서 산출되므로 통계적으로 상관되어 있다. 확률론적 민감도 분석에서 두 생존모형의 모수를 독립적으로 추출하면 상태 점유확률의 불확실성을 왜곡할 수 있다. 가능한 경우에는 공동 공분산 구조, 재표본추출 또는 동일한 환자 수준 자료에 대한 공동 적합을 통해 상관을 보존해야 한다.

분할생존모델과 상태전이모형이 동일한 관찰기간 자료에 잘 적합하더라도 장기 외삽은 다를 수 있다. 분할생존모델은 PFS와 OS를 직접 외삽하고, 상태전이모형은 진행과 사망의 원인별 전이과정을 외삽한다. 따라서 두 구조의 비교는 단순한 적합도 비교가 아니라 장기 질병경로에 대한 구조적 시나리오 분석으로 해석해야 한다.

Important분할생존모델의 핵심 점검사항

분할생존모델에서는 모든 시점에서 \(S_{OS}(t)\ge S_{PFS}(t)\)가 성립해야 한다. 두 생존곡선을 독립적으로 외삽하면 이 조건이 깨질 수 있으므로 반드시 시각적·수치적으로 확인해야 한다.

4.6 마코프 환자 수준 시뮬레이션

마코프 코호트 모델은 전체 환자집단의 상태분포를 추적한다. 반면 마코프 환자 수준 시뮬레이션은 개별 환자의 경로를 하나씩 생성한 후, 많은 환자의 결과를 평균하여 기대비용과 기대 QALY를 추정한다. 이를 개별 환자 시뮬레이션 또는 microsimulation이라고도 한다.

환자 수준 시뮬레이션은 다음과 같은 상황에서 유용하다.

  • 환자 특성에 따라 전이확률이 다르다.
  • 과거 사건 경험이나 상태 체류기간이 미래 위험에 영향을 준다.
  • 치료 중단, 재치료, 순차치료 등 복잡한 경로가 필요하다.
  • 개별 환자별 이질성을 반영해야 한다.
  • 상태 수가 많아 코호트 모델이 지나치게 복잡해진다.

4.6.1 개별 환자 전이확률

환자 \(i\)가 시간 \(t\)에서 상태 \(S_{i,t}=a\)에 있다고 하자. 다음 상태는 현재 상태, 환자 특성 \(X_i\), 과거 이력 \(H_{i,t}\)에 따라 결정될 수 있다.

\[ P(S_{i,t+1}=b\mid S_{i,t}=a,X_i,H_{i,t}). \]

전통적인 코호트 마코프모델에서는 보통 다음과 같은 단순한 형태를 사용한다.

\[ P(S_{t+1}=b\mid S_t=a). \]

반면 환자 수준 시뮬레이션에서는 개인별 전이확률을 사용할 수 있다. 예를 들어 상태 \(a\)에서 가능한 다음 상태 집합을 \(\mathcal{A}(a)\)라고 하면 다항 로짓 형태로 다음과 같이 쓸 수 있다.

\[ P(S_{i,t+1}=b\mid S_{i,t}=a,X_i,H_{i,t}) =\frac{\exp(\eta_{iabt})}{\sum_{\ell\in\mathcal{A}(a)}\exp(\eta_{ia\ell t})}, \]

\[ \eta_{iabt}=\alpha_{ab}+\boldsymbol{\beta}_{ab}^{\top}X_i+\boldsymbol{\gamma}_{ab}^{\top}H_{i,t}. \]

이 표현은 환자 특성뿐 아니라 상태 체류기간, 이전 이상반응, 누적 치료기간 같은 이력 변수를 전이확률에 반영할 수 있음을 보여준다.

4.6.2 환자별 비용과 QALY

환자 \(i\)의 총 비용과 QALY는 각 주기 보상의 합으로 표현할 수 있다.

\[ C_i=\sum_{t=0}^{T-1} c(S_{i,t},X_i,H_{i,t})d(t^*) +\sum_m c^{event}_{im}d(T_{im}), \]

\[ Q_i=\sum_{t=0}^{T-1} u(S_{i,t},X_i,H_{i,t})\Delta t\,d(t^*). \]

모수 \(\boldsymbol{\theta}\)가 고정되어 있을 때 개별 환자 결과 \(C_i\)가 서로 독립이고 동일한 분포를 따르면, 표본평균은 큰수의 법칙에 의해 조건부 기대비용으로 수렴한다.

\[ \widehat{\mu}_C(\boldsymbol{\theta}) \xrightarrow[N\to\infty]{P} \mathbb{E}(C_i\mid\boldsymbol{\theta}). \]

중심극한정리에 의해 충분히 큰 \(N\)에서는 다음 근사가 성립한다.

\[ \sqrt{N} \left\{ \widehat{\mu}_C(\boldsymbol{\theta}) -\mu_C(\boldsymbol{\theta}) \right\} \overset{approx}{\sim} N(0,\sigma_C^2). \]

따라서 시뮬레이션 환자 수는 임의로 정하기보다 관심 있는 증분결과의 Monte Carlo 표준오차가 충분히 작아질 때까지 증가시키는 것이 바람직하다.

\(N\)명의 시뮬레이션 환자를 생성하면 기대비용과 기대 QALY는 다음과 같이 추정한다.

\[ \widehat{\mu}_C=\frac{1}{N}\sum_{i=1}^{N}C_i, \]

\[ \widehat{\mu}_Q=\frac{1}{N}\sum_{i=1}^{N}Q_i. \]

환자 수준 시뮬레이션에는 Monte Carlo 오차가 존재한다. 비용 결과의 표본표준편차를 \(s_C\)라고 하면 Monte Carlo 표준오차는 다음과 같다.

\[ MCSE(\widehat{\mu}_C)=\frac{s_C}{\sqrt{N}}. \]

마찬가지로 QALY의 Monte Carlo 표준오차는 \(s_Q/\sqrt{N}\)이다. 환자 수 \(N\)을 늘리면 Monte Carlo 오차는 감소하지만 계산 시간이 증가한다.

그림의 두 접근은 기대값 수준에서는 같은 질병과정과 보상구조를 사용하면 동일한 결과에 수렴할 수 있다. 차이는 코호트모형이 확률분포를 직접 전파하는 반면, 환자 수준 시뮬레이션은 그 분포에서 무작위 경로를 반복 추출한다는 점이다. 따라서 환자 수준 시뮬레이션의 유연성에는 Monte Carlo 오차와 더 복잡한 검증 부담이 따른다.

4.6.3 분산감소와 공통 난수

두 전략의 증분결과를 비교할 때 동일한 가상 환자와 동일한 난수열을 사용하는 공통 난수 방법은 Monte Carlo 오차를 줄일 수 있다. 두 전략의 비용 추정치를 \(\widehat{C}_1\)과 \(\widehat{C}_0\)라고 하면 증분비용의 분산은 다음과 같다.

\[ \operatorname{Var}(\widehat{C}_1-\widehat{C}_0) =\operatorname{Var}(\widehat{C}_1) +\operatorname{Var}(\widehat{C}_0) -2\operatorname{Cov}(\widehat{C}_1,\widehat{C}_0). \]

공통 난수로 두 전략의 결과에 양의 상관을 유도하면 마지막 공분산 항 때문에 증분비용의 분산이 감소한다. 이는 전략별 평균의 정밀도보다 증분결과의 정밀도가 중요한 경제성 평가에 특히 유용하다.

4.6.4 1차 불확실성과 2차 불확실성

환자 수준 시뮬레이션에서는 두 종류의 불확실성을 구분하는 것이 중요하다. 첫째, 같은 모수값이 주어졌을 때 개별 환자의 경로가 우연히 달라지는 1차 불확실성이 있다. 이는 환자 간 임상 경로의 무작위 변동성이다. 둘째, 전이확률, 비용, 효용, 상대효과 같은 모수 자체가 불확실한 2차 불확실성이 있다. 경제성 평가의 확률론적 민감도 분석에서 주로 반영해야 하는 것은 2차 불확실성이다.

따라서 환자 수준 시뮬레이션을 PSA와 결합할 때는 보통 바깥 반복에서 모수값을 추출하고, 안쪽 반복에서 충분한 수의 환자를 시뮬레이션한다. 계산량을 줄이기 위해 공통 난수, 고정된 가상 환자집단, 충분히 큰 환자 수를 사용할 수 있다.

Tip환자 수준 시뮬레이션 사용 원칙

환자 수준 시뮬레이션은 유연하지만 항상 필요한 것은 아니다. 환자 이질성, 과거 이력, 상태 체류기간, 순차치료 경로가 의사결정 결과에 중요한 영향을 줄 때 사용하는 것이 적절하다.

4.7 이산 사건 시뮬레이션

이산 사건 시뮬레이션은 환자의 상태를 일정한 주기마다 갱신하는 대신, 중요한 사건이 발생하는 시간 자체를 직접 시뮬레이션하는 접근이다. 환자는 시간의 흐름 속에서 치료 시작, 반응, 진행, 이상반응, 치료 중단, 입원, 사망과 같은 사건을 경험한다. 모델은 이러한 사건이 언제 발생하는지를 생성하고, 사건 발생 시 비용과 QALY를 업데이트한다.

이산 사건 시뮬레이션은 다음과 같은 상황에서 유용하다.

  • 사건 발생 시간이 중요하다.
  • 여러 사건이 서로 경쟁하거나 사건 순서에 따라 이후 위험이 달라진다.
  • 자원 제약, 대기시간, 병상 가용성처럼 시스템 수준 요인을 모델링해야 한다.
  • 환자별 경로가 매우 다양하다.
  • 고정 주기 모델이 비효율적이거나 부정확하다.

그림의 핵심은 시간이 일정한 간격으로 진행되지 않고 사건이 발생하는 시점으로 바로 이동한다는 점이다. 가장 이른 사건이 발생하면 환자의 상태와 위험요인이 바뀔 수 있으므로, 아직 발생하지 않은 후보 사건을 그대로 유지할지 취소하고 다시 생성할지에 대한 규칙을 명확히 해야 한다.

4.7.1 사건시간 생성

이산 사건 시뮬레이션에서는 환자 \(i\)에 대해 여러 후보 사건시간을 생성한다. 예를 들어 진행, 사망, 중증 이상반응 시간을 다음과 같이 둘 수 있다.

\[ T_{i,prog}=\text{progression time}, \]

\[ T_{i,death}=\text{death time}, \]

\[ T_{i,AE}=\text{adverse event time}. \]

다음 사건 시간과 사건 종류는 다음과 같이 결정된다.

\[ T_{i,next}=\min(T_{i,prog},T_{i,death},T_{i,AE}), \]

\[ K_{i,next}=\arg\min_{k\in\{prog,death,AE\}}T_{i,k}. \]

사건 시간이 생존함수 \(S_k(t)\)를 따른다면 역변환법을 사용할 수 있다. \(U\sim Uniform(0,1)\)일 때 \(S_k(T)=U\)가 되도록 \(T\)를 생성한다. Weibull 생존함수를 shape-scale 모수화로 정의하되, 지불의사금액 \(\lambda\)와 혼동을 피하기 위해 scale 모수를 \(\eta\)로 표기하자.

\[ S(t)=\exp\left[-\left(\frac{t}{\eta}\right)^k\right]. \]

그러면 사건시간은 다음과 같이 생성된다.

\[ T=\eta\{-\log(U)\}^{1/k}. \]

다른 모수화인 \(S(t)=\exp(-\alpha t^k)\)를 사용하면 다음과 같다.

\[ T=\left\{\frac{-\log(U)}{\alpha}\right\}^{1/k}. \]

두 식은 모수화만 다르다. 분석 보고서에서는 반드시 어떤 모수화를 사용했는지 명시해야 한다.

보다 일반적으로 사건의 누적위험함수를 \(H(t)\)라고 하면 생존함수는 \(S(t)=\exp\{-H(t)\}\)이다. 따라서 역변환법은 다음과 같이 표현된다.

\[ T=H^{-1}\{-\log(U)\}. \]

위험률이 시간이나 환자 특성에 따라 변하더라도 누적위험함수를 계산하고 역함수를 구할 수 있으면 같은 원리를 사용할 수 있다. 닫힌 형태의 역함수가 없으면 수치적 근찾기나 thinning 알고리즘을 사용할 수 있다.

4.7.2 경쟁 사건과 사건 시계

진행, 이상반응, 사망의 후보시간을 각각 독립적으로 생성하고 최소값을 선택하는 방법은 후보 잠재시간의 독립성 또는 특정한 결합구조를 암묵적으로 가정한다. 사건 간 의존성이 강하면 공유 frailty, 다변량 생존모형 또는 상태 변화 후 조건부 위험률을 이용해야 한다.

상태가 변한 뒤 사건시간을 갱신하는 방식도 명시해야 한다. 새로운 상태에 진입한 시점을 시간의 원점으로 다시 설정하면 clock-reset 접근이고, 질병 시작 이후의 절대시간을 계속 사용하면 clock-forward 접근이다. 전자는 상태 체류기간이 위험을 결정하는 준마코프 과정을, 후자는 달력시간이나 진단 후 경과시간이 위험을 결정하는 과정을 표현한다.

4.7.3 이산 사건 시뮬레이션의 장점과 한계

이산 사건 시뮬레이션은 매우 유연하다. 복잡한 환자 경로, 시간 의존 위험, 반복 사건, 자원 제약, 대기시간, 환자 이질성을 표현하기 쉽다. 그러나 모델이 복잡해질수록 투명성과 검증 가능성이 낮아질 수 있다. 또한 많은 수의 환자 경로를 시뮬레이션해야 하므로 계산 부담이 커질 수 있다.

따라서 이산 사건 시뮬레이션은 문제의 복잡성이 그 유연성을 필요로 할 때 사용하는 것이 바람직하다. 단순한 3상태 질병 진행 문제를 이산 사건 시뮬레이션으로 표현하는 것은 오히려 불필요한 복잡성을 초래할 수 있다.

4.8 모형의 검증, 보정, 구조적 불확실성

경제성 평가 모델은 계산이 실행된다는 사실만으로 타당성이 보장되지 않는다. 모델 검증은 구현이 의도한 수학적 구조와 일치하는지 확인하는 과정이고, 모델 타당화는 그 구조와 결과가 실제 임상현상 및 의사결정 목적에 적절한지 평가하는 과정이다.

4.8.1 구현 검증과 내부 타당성

구현 검증에서는 수식, 코드, 입력자료, 단위, 할인, 상태전이, 보상 누적이 명세서와 일치하는지 확인한다. 대표적인 점검 항목은 다음과 같다.

  • 모든 전이확률이 0과 1 사이이고 각 행의 합이 1인지 확인한다.
  • 상태 점유확률이 음수가 아니고 각 시점에서 합이 1인지 확인한다.
  • 사망 흡수상태의 점유확률이 감소하지 않는지 확인한다.
  • 비용과 QALY를 0으로 설정했을 때 결과도 0이 되는지 확인한다.
  • 두 전략의 모든 입력값을 같게 설정했을 때 증분결과가 0이 되는지 확인한다.
  • 주기 길이와 시뮬레이션 수를 변화시켰을 때 결과가 수렴하는지 확인한다.

이러한 극단값 검사와 불변조건 검사는 복잡한 결과표보다 구현 오류를 더 빠르게 발견할 수 있다.

4.8.2 외적 타당성과 예측 타당성

외적 타당성은 모델 결과가 모델 적합에 사용되지 않은 자료와 얼마나 일치하는지를 평가한다. 관찰된 생존곡선, 재발률, 입원율, 치료중단률, 누적비용과 모델 예측을 시점별로 비교할 수 있다. 관찰기간 안의 적합만으로 장기 외삽이 보장되지는 않으므로, 장기 자연사 자료와 임상전문가의 판단을 함께 사용해야 한다.

예측값을 \(\widehat{y}_m\)이고 외부 목표값을 \(y_m\)이라고 하면 단순한 오차 측도는 다음과 같다.

\[ RMSE =\sqrt{ \frac{1}{M} \sum_{m=1}^{M} (\widehat{y}_m-y_m)^2 }. \]

그러나 경제성 평가에서는 평균 오차뿐 아니라 임상적으로 중요한 시점과 상태에서의 방향성, 장기 꼬리, 치료군 간 차이를 함께 평가해야 한다.

4.8.3 모형 보정

직접 추정하기 어려운 모수를 외부 관찰값에 맞추어 결정하는 과정을 보정이라고 한다. 보정 모수를 \(\boldsymbol{\theta}\), 모델이 생성하는 목표값을 \(g_m(\boldsymbol{\theta})\), 관찰 목표값을 \(y_m\)이라고 하면 가중 최소제곱 보정은 다음 문제로 표현할 수 있다.

\[ \widehat{\boldsymbol{\theta}} =\arg\min_{\boldsymbol{\theta}} \sum_{m=1}^{M} w_m \{g_m(\boldsymbol{\theta})-y_m\}^2. \]

가중치 \(w_m\)은 목표값의 정밀도나 의사결정 중요도를 반영할 수 있다. 베이지안 보정에서는 관찰 목표값의 가능도와 사전분포를 결합한다.

\[ p(\boldsymbol{\theta}\mid\boldsymbol{y}) \propto p(\boldsymbol{y}\mid\boldsymbol{\theta}) p(\boldsymbol{\theta}). \]

보정 후에는 목표값에 대한 적합뿐 아니라 보정에 사용하지 않은 결과에 대한 재현성과 모수의 식별 가능성을 점검해야 한다. 서로 다른 모수 조합이 동일한 목표값을 재현하면 의사결정 결과의 불확실성이 과소평가될 수 있다.

4.8.4 구조적 불확실성과 모형 불일치

모형은 현실을 단순화하므로 관찰값과 모델값의 차이는 모수 오차만으로 설명되지 않을 수 있다. 이를 개념적으로 다음과 같이 표현할 수 있다.

\[ y(t)=g\{t,\boldsymbol{\theta}\}+\delta(t)+\varepsilon(t), \]

여기서 \(g\{t,\boldsymbol{\theta}\}\)는 모델 예측, \(\delta(t)\)는 구조적 모형 불일치, \(\varepsilon(t)\)는 관측오차이다. 상태 정의, 전이구조, 생존분포, 치료효과 지속기간, 후속치료 규칙이 달라지면 \(\delta(t)\)의 형태도 달라진다.

구조적 불확실성은 하나의 모형에서 모수분포만 넓히는 방식으로 충분히 반영되지 않는다. 대안적 상태구조, 생존 외삽, 치료효과 감소, 시간 범위, 자료원에 대한 시나리오를 별도로 분석하고, 각 구조에서 전략 선택이 얼마나 달라지는지 확인해야 한다. 여러 구조에 합리적인 확률을 부여할 수 있다면 모형평균을 사용할 수 있지만, 그 확률 자체도 투명하게 정당화되어야 한다.

run_markov <- function(P, cost, utility, n_cycles = 60,
                       cycle_length = 1 / 12,
                       annual_discount = 0.045,
                       half_cycle = TRUE) {
  state_names <- names(cost)
  trace <- matrix(NA_real_, nrow = n_cycles + 1, ncol = length(cost))
  colnames(trace) <- state_names
  trace[1, ] <- c(PF = 1, PD = 0, Death = 0)

  for (t in 1:n_cycles) {
    trace[t + 1, ] <- trace[t, ] %*% P
  }

  if (half_cycle) {
    reward_trace <- (trace[1:n_cycles, , drop = FALSE] +
                       trace[2:(n_cycles + 1), , drop = FALSE]) / 2
    discount_time <- ((0:(n_cycles - 1)) + 0.5) * cycle_length
  } else {
    reward_trace <- trace[1:n_cycles, , drop = FALSE]
    discount_time <- (0:(n_cycles - 1)) * cycle_length
  }

  discount <- 1 / ((1 + annual_discount) ^ discount_time)
  cycle_cost <- as.numeric(reward_trace %*% cost)
  cycle_qaly <- as.numeric(reward_trace %*% utility) * cycle_length

  list(
    trace = trace,
    total_cost = sum(cycle_cost * discount),
    total_qaly = sum(cycle_qaly * discount),
    cycle_cost = cycle_cost,
    cycle_qaly = cycle_qaly
  )
}

simulate_one_patient <- function(P, cost, utility,
                                 n_cycles = 60,
                                 cycle_length = 1 / 12,
                                 annual_discount = 0.045) {
  state <- 1
  total_cost <- 0
  total_qaly <- 0
  path <- integer(n_cycles + 1)
  path[1] <- state

  for (t in 1:n_cycles) {
    time_mid <- (t - 0.5) * cycle_length
    discount <- 1 / ((1 + annual_discount) ^ time_mid)

    total_cost <- total_cost + cost[[state]] * discount
    total_qaly <- total_qaly + utility[[state]] * cycle_length * discount

    state <- sample(seq_along(cost), size = 1, prob = P[state, ])
    path[t + 1] <- state
  }

  c(cost = as.numeric(total_cost), qaly = as.numeric(total_qaly))
}

## 의사결정론의 핵심 아이디어 {#sec-decision-theory-core}

경제성 평가는 본질적으로 불확실성하의 의사결정 문제이다. 의사결정자는 여러 치료전략 중 하나를 선택해야 하며, 각 전략의 임상 결과와 비용은 불확실하다. 신약은 기존 치료보다 생존을 연장할 수 있지만 더 비쌀 수 있고, 치료효과가 장기적으로 유지될 수도 있지만 시간이 지나면서 감소할 수도 있다. 또한 치료 전략에 따라 이상반응, 치료 중단, 후속 치료, 입원, 삶의 질 저하가 서로 다르게 발생할 수 있다.

의사결정론에서는 선택 가능한 대안을 전략이라고 한다. 의약품 경제성 평가에서는 다음과 같은 전략을 비교할 수 있다.

- 기존 표준치료
- 신약 단독 치료
- 신약과 기존 치료의 병용요법
- 바이오마커 검사 후 양성 환자에게만 신약을 사용하는 전략
- 1차 치료 후 반응 여부에 따라 2차 치료를 선택하는 순차치료 전략
- 치료 반응, 독성, 재발 여부에 따라 치료를 중단하거나 전환하는 동적 전략

전략 $j$를 선택했을 때 환자 한 명에게 발생하는 총 비용을 $C_j$, 총 QALY를 $Q_j$라고 하자. 비용과 QALY는 불확실한 임상 경로에 따라 달라지므로 확률변수로 볼 수 있다. 비용효용분석에서 지불의사금액을 $\lambda$라고 하면 전략 $j$의 순편익은 다음과 같이 정의된다.

$$
NB_j(\lambda)=\lambda Q_j-C_j.
$$

의사결정자가 관심을 가지는 것은 개별 환자 한 명의 우연한 결과가 아니라 대상 인구집단에서의 기대가치이다. 따라서 기대순편익은 다음과 같다.

$$
\mu_{NB,j}(\lambda)=\mathbb{E}\{NB_j(\lambda)\}
=\lambda \mathbb{E}(Q_j)-\mathbb{E}(C_j).
$$

비교 가능한 전략 집합을 $\mathcal{J}$라고 하면 기대순편익 기준의 최적 전략은 다음과 같다.

$$
j^*(\lambda)=\arg\max_{j\in\mathcal{J}} \mu_{NB,j}(\lambda).
$$

이 식은 모형 기반 경제성 평가의 핵심을 압축한다. 모델은 단순히 장기 비용과 장기 효과를 예측하는 계산 장치가 아니라, 각 전략의 기대순편익을 비교하기 위해 질병 진행, 치료효과, 비용, 효용, 불확실성을 하나의 수리적 구조 안에 결합하는 도구이다.


### 기대효용과 순편익의 관계

순편익 기준은 비용과 건강효과를 하나의 공통 척도로 바꾸어 기대효용을 비교하는 의사결정 규칙으로 해석할 수 있다. 지불의사금액 $\lambda$가 일정하고 건강효과 한 단위의 사회적 가치가 선형이라고 가정하면, 전략 $j$의 효용은 $\lambda Q_j-C_j$에 비례한다. 이때 기대순편익을 최대화하는 전략은 기대효용을 최대화하는 전략과 일치한다.

경제성 평가에서 불확실한 모수의 집합을 $\boldsymbol{\theta}$라고 하면 전략 $j$의 순편익은 $NB_j(\boldsymbol{\theta};\lambda)$로 쓸 수 있다. 현재 근거에 기반한 의사결정은 모수의 사후분포 또는 표본분포에 대해 평균을 취한 다음 기대순편익이 가장 큰 전략을 선택하는 문제이다.

$$
 j^*(\lambda)
 =\arg\max_{j\in\mathcal{J}}
 \mathbb{E}_{\boldsymbol{\theta}}
 \left[NB_j(\boldsymbol{\theta};\lambda)\right].
$$

순편익이 비용과 QALY에 대해 선형이므로 다음 관계가 성립한다.

$$
\mathbb{E}_{\boldsymbol{\theta}}\{NB_j(\boldsymbol{\theta};\lambda)\}
=\lambda\mathbb{E}_{\boldsymbol{\theta}}\{Q_j(\boldsymbol{\theta})\}
-\mathbb{E}_{\boldsymbol{\theta}}\{C_j(\boldsymbol{\theta})\}.
$$

반면 ICER는 비선형 비율이므로 일반적으로 다음 등식은 성립하지 않는다.

$$
\mathbb{E}\left(\frac{\Delta C}{\Delta Q}\right)
\ne
\frac{\mathbb{E}(\Delta C)}{\mathbb{E}(\Delta Q)}.
$$

따라서 불확실성하의 전략 선택에서는 개별 모수 추출값에서 계산한 ICER를 단순 평균하는 것보다 증분순편익의 분포를 이용하는 것이 수학적으로 안정적이다.

### 결과의 무작위성과 모수 불확실성

모형 기반 평가에는 서로 다른 두 층위의 불확실성이 존재한다. 첫째는 동일한 모수값이 주어져도 환자별 질병 경로와 비용이 달라지는 결과의 무작위성이다. 둘째는 전이위험, 치료효과, 비용, 효용과 같은 모수 자체에 대한 불확실성이다. 미래 환자 결과를 $Y$라고 하면 전체 기대값은 반복기대값 법칙에 의해 다음과 같이 분해된다.

$$
\mathbb{E}(Y)
=\mathbb{E}_{\boldsymbol{\theta}}
\left\{\mathbb{E}(Y\mid\boldsymbol{\theta})\right\}.
$$

전체 분산은 다음과 같이 분해된다.

$$
\operatorname{Var}(Y)
=\mathbb{E}_{\boldsymbol{\theta}}
\left\{\operatorname{Var}(Y\mid\boldsymbol{\theta})\right\}
+\operatorname{Var}_{\boldsymbol{\theta}}
\left\{\mathbb{E}(Y\mid\boldsymbol{\theta})\right\}.
$$

첫 번째 항은 환자 경로의 변동성을, 두 번째 항은 모수 불확실성을 나타낸다. 경제성 평가의 확률론적 민감도 분석은 주로 두 번째 항이 의사결정 불확실성에 미치는 영향을 평가한다.

::: {.callout-note title="핵심 메시지"}
모형 기반 경제성 평가는 “치료효과가 통계적으로 유의한가?”보다 넓은 질문을 다룬다. 핵심 질문은 “현재의 근거와 명시적인 가정하에서 어떤 전략의 기대순편익이 가장 큰가?”이다.
:::

이 그림은 경제성 평가 모델의 입력과 출력 사이의 논리적 흐름을 보여준다. 의사결정 문제와 대상 인구집단을 먼저 정의한 뒤, 임상근거와 비용·효용 자료를 모형 구조에 결합하여 전략별 기대순편익을 산출한다. 따라서 모형 구조나 입력자료를 먼저 선택한 뒤 의사결정 문제를 끼워 맞추는 방식은 피해야 한다.

### 의사결정 문제의 구성요소

모형 기반 경제성 평가에서 의사결정 문제는 보통 다음 요소로 구성된다.

| 구성요소 | 의미 | 예 |
|---|---|---|
| 전략 | 비교 대상 치료 대안 | 신약, 기존 치료, 병용요법, 검사 기반 치료 |
| 대상 인구집단 | 의사결정이 적용되는 환자집단 | 전이성 암 2차 치료 환자, 특정 유전자 변이 양성 환자 |
| 시간 범위 | 비용과 건강효과를 누적할 기간 | 1년, 5년, 10년, 평생 |
| 건강상태 | 환자가 속할 수 있는 상호 배타적 상태 | 무진행, 진행 후 생존, 사망 |
| 사건 | 비용이나 효용을 변화시키는 임상 사건 | 이상반응, 입원, 재발, 치료 중단 |
| 전이 구조 | 상태 사이의 이동 가능성 | 무진행 → 진행, 진행 → 사망 |
| 보상 구조 | 상태나 사건에 연결되는 비용과 효용 | 상태 비용, 사건 비용, 상태 효용 |
| 자료원 | 모수 추정에 사용되는 근거 | 임상시험, 등록자료, 문헌, 전문가 의견 |
| 의사결정 기준 | 전략 선택 기준 | ICER, 순편익, CEAC, EVPI |

모델 구조는 어떤 건강상태를 포함할지, 상태 간 이동을 어떻게 허용할지, 시간에 따라 비용과 효과를 어떻게 누적할지를 결정한다. 따라서 모형 구조는 단순한 형식 선택이 아니라 경제성 평가 결과의 타당성을 좌우하는 핵심 가정이다.


대상 인구집단에 환자 특성 $X$가 분포한다고 하면 전략 $j$의 인구집단 기대순편익은 다음과 같다.

$$
\mu_{NB,j}(\lambda)
=\mathbb{E}_{X}\left[
\lambda\,\mathbb{E}(Q_j\mid X)
-\mathbb{E}(C_j\mid X)
\right].
$$

이 식은 평균적인 환자 한 명만을 모델링하는 것과 환자 이질성을 적절히 평균하는 것이 항상 같지 않음을 보여준다. 치료효과, 기저위험, 비용 또는 효용이 비선형적으로 환자 특성에 의존하면 평균 환자에 대한 결과가 목표 모집단의 평균 결과를 재현하지 못할 수 있다. 이 경우에는 하위집단 분석, 표준화 또는 환자 수준 시뮬레이션이 필요하다.

## 경제성 평가 모델 {#sec-economic-evaluation-models}

경제성 평가 모델은 질병 진행과 치료전략의 결과를 수학적 또는 컴퓨터 시뮬레이션 구조로 표현한 것이다. 좋은 모델은 실제 세계를 완벽하게 복제하지 않는다. 대신 의사결정에 중요한 임상 경로와 비용·효과 발생 과정을 충분히 타당하고 투명하게 표현한다. 모델은 자료가 없는 부분을 임의로 채우는 도구가 아니라, 서로 다른 자료원을 일관된 의사결정 구조 안에서 결합하고 관찰되지 않은 장기 결과를 명시적 가정하에 추정하는 도구이다.

### 연속시간 표현

전략 $j$를 따르는 환자의 건강상태 과정을 $S_j(t)$라고 하자. 분석 시간 범위는 $0\le t\le \tau$이다. 상태 $s$에서 시간 $t$에 발생하는 비용률을 $c_j(s,t)$, 효용을 $u_j(s,t)$라고 하자. 비용과 QALY에 같은 할인율을 적용한다고 하면 할인계수는 다음과 같다.

$$
d(t)=\frac{1}{(1+r)^t}.
$$

이때 연속시간에서 기대비용과 기대 QALY는 다음과 같이 표현할 수 있다.

$$
\mu_{C,j}(\tau)=\mathbb{E}\left[\int_0^\tau d(t)c_j\{S_j(t),t\}\,dt
+\sum_{m} d(T_{jm})c^{event}_{jm}\right],
$$

$$
\mu_{Q,j}(\tau)=\mathbb{E}\left[\int_0^\tau d(t)u_j\{S_j(t),t\}\,dt\right].
$$

여기서 $T_{jm}$은 전략 $j$에서 사건 $m$이 발생하는 시간이고, $c^{event}_{jm}$은 해당 사건에 연결되는 일회성 비용이다. 예를 들어 중증 이상반응 발생 시 입원비, 치료 시작 시 검사 비용, 사망 직전 비용은 사건 비용으로 모델링할 수 있다.


연속시간 표현에서 상태 비용률과 효용은 환자가 각 상태에 머무는 시간에 비례하여 누적된다. 상태 $s$의 점유확률을 $\pi_{j,s}(t)=P\{S_j(t)=s\}$라고 하면 반복기대값 법칙을 이용하여 기대비용의 상태 보상 부분을 다음처럼 다시 쓸 수 있다.

$$
\mathbb{E}\left[
\int_0^\tau d(t)c_j\{S_j(t),t\}\,dt
\right]
=
\int_0^\tau d(t)
\sum_s \pi_{j,s}(t)c_j(s,t)\,dt.
$$

따라서 대부분의 상태 기반 모델은 결국 시간별 상태 점유확률과 상태별 보상을 결합하는 구조를 가진다. 결정수형, 마코프모델, 분할생존모델은 상태 점유확률을 산출하는 방식이 서로 다를 뿐, 비용과 QALY를 누적하는 기본 원리는 동일하다.

### 연속시간 전이와 생성행렬

연속시간 마코프과정에서 상태 $a$에서 상태 $b$로 이동하는 순간 전이율을 $q_{ab}$라고 하자. 생성행렬 $\boldsymbol{Q}$는 비대각 원소가 음이 아닌 전이율이고, 대각 원소는 해당 상태에서 빠져나가는 총 전이율의 음수로 정의된다.

$$
q_{ab}\ge 0\quad(a\ne b),
\qquad
q_{aa}=-\sum_{b\ne a}q_{ab}.
$$

전이율이 시간에 따라 일정하면 길이 $\Delta t$인 주기의 전이확률 행렬은 행렬지수로 계산된다.

$$
\boldsymbol{P}(\Delta t)=\exp(\boldsymbol{Q}\Delta t).
$$

이 관계는 연속시간 사건 발생 과정과 이산시간 마코프모델을 연결한다. 경쟁하는 전이가 여러 개 있거나 상태 간 왕복 이동이 가능한 경우, 각 전이율을 별도로 단순 변환하는 것보다 생성행렬의 행렬지수를 이용하는 것이 확률의 합과 다단계 이동을 일관되게 반영한다.

### 이산시간 표현

대부분의 경제성 평가 모델은 계산의 편의를 위해 시간을 일정한 주기로 나눈다. 주기 길이를 $\Delta t$라고 하고, 시점 $t=0,1,\ldots,T$에서 전략 $j$의 상태분포 벡터를 $\boldsymbol{\pi}_{j,t}$라고 하자. 상태별 비용 벡터를 $\boldsymbol{c}_{j,t}$, 상태별 효용 벡터를 $\boldsymbol{u}_{j,t}$라고 하면 한 주기의 기대비용과 기대효용은 다음과 같다.

$$
\mathbb{E}(C_{j,t})=\boldsymbol{\pi}_{j,t}\boldsymbol{c}_{j,t}^{\top},
$$

$$
\mathbb{E}(U_{j,t})=\boldsymbol{\pi}_{j,t}\boldsymbol{u}_{j,t}^{\top}.
$$

전체 분석 기간 동안 누적 기대비용과 기대 QALY는 다음과 같이 근사할 수 있다.

$$
\mu_{C,j}(\tau)\approx \sum_{t=0}^{T-1}
\boldsymbol{\pi}_{j,t}^{*}\boldsymbol{c}_{j,t}^{\top}d(t^*),
$$

$$
\mu_{Q,j}(\tau)\approx \sum_{t=0}^{T-1}
\boldsymbol{\pi}_{j,t}^{*}\boldsymbol{u}_{j,t}^{\top}\Delta t\,d(t^*).
$$

여기서 $\boldsymbol{\pi}_{j,t}^{*}$는 보상을 계산할 때 사용하는 대표 상태분포이다. 주기 시작 분포를 사용할 수도 있고, 주기 종료 분포를 사용할 수도 있으며, 반주기 보정을 사용하면 다음과 같이 주기 시작과 종료의 평균을 사용할 수 있다.

$$
\boldsymbol{\pi}_{j,t}^{*}=\frac{\boldsymbol{\pi}_{j,t}+\boldsymbol{\pi}_{j,t+1}}{2}.
$$

$t^*$는 할인을 적용하는 대표 시점이다. 월별 주기에서 첫 번째 주기 중간에 보상이 발생한다고 가정하면 $t^*=(t+0.5)\Delta t$를 사용할 수 있다.


반주기 보정은 수치적분의 사다리꼴 공식과 같은 원리를 사용한다. 시간에 따른 기대 보상률을 $g(t)$라고 하면 다음 근사가 성립한다.

$$
\int_0^{T\Delta t}g(t)\,dt
\approx
\Delta t\left[
\frac{g(0)}{2}
+\sum_{t=1}^{T-1}g(t\Delta t)
+\frac{g(T\Delta t)}{2}
\right].
$$

주기 시작과 종료의 상태분포를 평균하는 반주기 보정은 이 사다리꼴 근사를 상태 보상에 적용한 것이다. 다만 치료 시작비용, 진행 진단비용, 사망비용처럼 특정 시점에 발생하는 사건 보상에는 반주기 보정을 기계적으로 적용해서는 안 된다. 사건 보상은 실제 또는 가정된 사건 발생 시점에 할인해야 한다.

::: {.callout-important title="모형의 구조와 모수"}
경제성 평가 모델은 구조와 모수로 나눌 수 있다. 구조는 상태, 사건, 전이, 보상 누적 방식을 의미하고, 모수는 전이확률, 위험률, 생존곡선, 비용, 효용, 상대효과 등을 의미한다. 구조가 임상적으로 부적절하면 정확한 모수를 사용해도 결과가 왜곡될 수 있다.
:::

이 그림에서 상태 점유확률은 임상모형이 산출하는 부분이고, 비용과 효용은 보상모형이 제공하는 부분이다. 두 부분을 분리하여 생각하면 어떤 가정이 임상 경로에 관한 것인지, 어떤 가정이 자원사용과 삶의 질에 관한 것인지 명확해진다. 또한 동일한 질병진행모형에 서로 다른 비용 관점이나 효용값을 적용할 수 있고, 반대로 동일한 보상구조에 여러 생존 외삽 시나리오를 적용할 수 있다.

### 모형 구조 선택의 기본 원칙

모형 구조는 평가 대상 질병의 자연사, 치료 경로, 의사결정 문제의 시간 범위, 이용 가능한 자료의 형태에 맞추어 선택해야 한다. 가장 좋은 모델은 가장 복잡한 모델이 아니라, 의사결정에 중요한 요소를 충분히 반영하면서도 검증과 설명이 가능한 모델이다.

| 의사결정 문제의 특징 | 우선 고려할 모형 |
|---|---|
| 단기 사건, 명확한 성공·실패, 반복 경로가 거의 없음 | 결정수형 |
| 장기 질병 진행, 상태별 비용과 효용, 반복 주기 | 마코프 코호트 모델 |
| 종양학에서 PFS와 OS 곡선이 핵심 입력값 | 분할생존모델 |
| 환자 특성, 과거 이력, 상태 체류기간이 중요함 | 환자 수준 시뮬레이션 |
| 사건 발생 시점, 경쟁 사건, 자원 제약, 대기시간이 중요함 | 이산 사건 시뮬레이션 |

![의사결정 문제의 시간 범위, 반복 상태, 생존곡선 자료, 환자 이질성, 사건 발생시간의 중요도에 따라 적절한 모형 구조가 달라진다.](figures/ch04/fig-ch04-model-selection-map.png){width="94%"}


그림의 모형들은 서로 배타적인 선택지가 아니다. 예를 들어 초기 진단검사 결과는 결정수형으로 표현하고, 이후 장기 질병 진행은 마코프모델로 연결할 수 있다. 또는 분할생존모델의 상태 점유확률에 환자 수준 치료중단 모듈을 결합할 수도 있다. 중요한 것은 모형의 이름보다 각 구성요소가 어떤 자료와 가정으로 계산되는지를 명시하는 것이다.

## 결정수형 {#sec-decision-tree}

결정수형은 가장 단순하고 직관적인 경제성 평가 모델 중 하나이다. 결정수형에서는 의사결정자가 선택할 수 있는 전략에서 시작하여, 이후 발생할 수 있는 사건과 결과를 가지 형태로 표현한다. 각 가지에는 확률이 부여되고, 말단 노드에는 비용과 QALY가 연결된다.

결정수형은 보통 다음과 같은 상황에 적합하다.

- 분석 기간이 짧다.
- 사건의 순서가 비교적 단순하다.
- 환자가 동일한 건강상태를 반복적으로 오가지 않는다.
- 시간에 따른 장기 질병 진행보다 단기 사건 발생 여부가 중요하다.
- 말단 결과를 임상적으로 명확하게 정의할 수 있다.

### 경로 기반 기대값 계산

전략 $j$에서 가능한 말단 경로의 집합을 $\mathcal{L}_j$라고 하자. 경로 $\ell\in\mathcal{L}_j$의 발생확률을 $p_{j\ell}$, 해당 경로의 총 비용과 QALY를 각각 $C_{j\ell}$, $Q_{j\ell}$라고 하면 전략 $j$의 기대비용과 기대 QALY는 다음과 같다.

$$
\mu_{C,j}=\sum_{\ell\in\mathcal{L}_j}p_{j\ell}C_{j\ell},
$$

$$
\mu_{Q,j}=\sum_{\ell\in\mathcal{L}_j}p_{j\ell}Q_{j\ell}.
$$

각 전략의 경로 확률은 해당 경로를 구성하는 가지 확률의 곱으로 계산된다. 예를 들어 전략 $j$에서 성공 여부와 중증 이상반응 여부를 모두 고려하고 두 사건이 조건부로 순차적으로 발생한다면, 특정 경로의 확률은 다음과 같이 계산될 수 있다.

$$
p_{j,\text{success, AE}}=P(\text{success}\mid j)P(\text{AE}\mid \text{success},j).
$$

두 전략 $1$과 $0$을 비교할 때 증분비용, 증분 QALY, ICER는 다음과 같다.

$$
\Delta C=\mu_{C,1}-\mu_{C,0},
$$

$$
\Delta Q=\mu_{Q,1}-\mu_{Q,0},
$$

$$
ICER=\frac{\Delta C}{\Delta Q},\qquad \Delta Q\neq 0.
$$

순편익 기준으로는 다음을 비교하면 된다.

$$
INB(\lambda)=\lambda\Delta Q-\Delta C.
$$

$INB(\lambda)>0$이면 지불의사금액 $\lambda$에서 전략 $1$의 기대순편익이 전략 $0$보다 크다.


### 경로확률과 역방향 계산

각 말단 경로의 확률은 0 이상이어야 하며 한 전략 아래 모든 상호 배타적 경로의 확률 합은 1이어야 한다.

$$
\sum_{\ell\in\mathcal{L}_j}p_{j\ell}=1.
$$

결정수형은 말단 노드에서 시작하여 기대값을 거꾸로 계산하는 역방향 계산 또는 rollback으로 평가할 수 있다. 확률 노드 $n$의 하위 노드 집합을 $\mathcal{C}(n)$이라고 하고, 하위 노드 $m$으로 이동할 조건부확률을 $p_{nm}$, 하위 노드의 가치를 $V(m)$이라고 하면 확률 노드의 가치는 다음과 같다.

$$
V(n)=\sum_{m\in\mathcal{C}(n)}p_{nm}V(m).
$$

의사결정 노드에서는 가능한 가지 중 기대순편익이 가장 큰 가지를 선택한다.

$$
V(n)=\max_{m\in\mathcal{C}(n)}V(m).
$$

이 재귀적 계산은 결정수형이 동적계획법의 가장 단순한 형태임을 보여준다. 다만 사건이 반복되거나 과거 이력에 따라 이후 확률이 달라지면 동일한 임상상태라도 서로 다른 가지로 계속 분리해야 하므로 나무의 크기가 기하급수적으로 증가한다.

![결정수형은 전략에서 시작하여 사건 가지를 따라 말단 경로의 비용과 QALY를 확률가중평균하는 구조이다.](figures/ch04/fig-ch04-decision-tree.png){width="92%"}


그림을 읽을 때는 먼저 전략별로 가능한 모든 말단 경로가 빠짐없이 포함되었는지 확인해야 한다. 다음으로 각 분기확률이 이전 사건에 조건부인지, 독립확률로 잘못 사용되지 않았는지 점검해야 한다. 마지막으로 말단 비용과 QALY가 경로 중 발생한 모든 사건을 누적한 값인지 확인한다.

### 간단한 예제 {.unnumbered}

신약과 기존 치료를 비교한다고 하자. 1개월 이내 치료 성공 여부만 고려하며, 이후 장기 결과는 고려하지 않는 단기 의사결정 문제이다.

| 전략 | 성공확률 | 성공 시 비용 | 실패 시 비용 | 성공 시 QALY | 실패 시 QALY |
|---|---:|---:|---:|---:|---:|
| 신약 | 0.80 | 5,000,000 | 7,000,000 | 0.080 | 0.050 |
| 기존 치료 | 0.65 | 2,000,000 | 5,000,000 | 0.075 | 0.045 |

신약의 기대비용과 기대 QALY는 다음과 같다.

$$
\mu_{C,1}=0.80\times 5{,}000{,}000+0.20\times 7{,}000{,}000=5{,}400{,}000,
$$

$$
\mu_{Q,1}=0.80\times 0.080+0.20\times 0.050=0.074.
$$

기존 치료의 기대비용과 기대 QALY는 다음과 같다.

$$
\mu_{C,0}=0.65\times 2{,}000{,}000+0.35\times 5{,}000{,}000=3{,}050{,}000,
$$

$$
\mu_{Q,0}=0.65\times 0.075+0.35\times 0.045=0.0645.
$$

따라서 증분비용과 증분 QALY는 다음과 같다.

$$
\Delta C=5{,}400{,}000-3{,}050{,}000=2{,}350{,}000,
$$

$$
\Delta Q=0.074-0.0645=0.0095.
$$

ICER는 다음과 같다.

$$
ICER=\frac{2{,}350{,}000}{0.0095}=247{,}368{,}421 \text{ KRW/QALY}.
$$

이 예제에서 신약은 더 효과적이지만 비용도 증가시킨다. 따라서 신약의 비용효과성은 지불의사금액 기준과 비교하여 판단한다. 예를 들어 $\lambda=50{,}000{,}000$ KRW/QALY이면 다음과 같다.

$$
INB(50{,}000{,}000)=50{,}000{,}000\times0.0095-2{,}350{,}000=-1{,}875{,}000.
$$

따라서 이 지불의사금액에서는 신약의 기대순편익이 기존 치료보다 작다.

### 결정수형의 장점과 한계

결정수형의 가장 큰 장점은 직관성이다. 의사결정 노드, 확률 노드, 결과 노드가 명확하게 표현되므로 비전문가도 모델 구조를 이해하기 쉽다. 또한 분석 기간이 짧고 사건이 단순한 경우에는 결정수형만으로도 충분히 타당한 경제성 평가가 가능하다.

그러나 결정수형은 시간에 따른 반복적 질병 진행을 표현하기 어렵다. 만성질환이나 암처럼 환자가 여러 건강상태를 거치고 장기간 비용과 효과가 누적되는 경우 결정수형은 가지가 빠르게 증가하여 해석과 검증이 어려워진다. 이런 경우에는 마코프모델이나 환자 수준 시뮬레이션이 더 적합하다.

::: {.callout-tip title="결정수형을 사용할 수 있는 경우"}
결정수형은 단기 의사결정, 일회성 사건, 명확한 치료 성공 또는 실패 구조를 가진 문제에 적합하다. 반복적인 질병 진행, 장기 생존, 상태 간 순환, 상태 체류기간 효과가 중요한 문제에는 적합하지 않을 수 있다.
:::

## 마코프모델 {#sec-markov-model}

마코프모델은 모형 기반 경제성 평가에서 가장 널리 사용되는 구조 중 하나이다. 마코프모델에서는 질병 진행을 상호 배타적이고 포괄적인 건강상태의 집합으로 표현하고, 환자가 일정한 시간 간격마다 한 상태에서 다른 상태로 이동한다고 가정한다.

마코프모델은 특히 다음 상황에 적합하다.

- 질병이 시간에 따라 진행된다.
- 환자가 여러 건강상태를 거친다.
- 비용과 효용이 상태별로 누적된다.
- 장기 분석 기간이 필요하다.
- 상태 간 전이확률 또는 전이위험을 추정할 수 있다.

예를 들어 진행성 암 경제성 평가에서는 다음과 같은 3상태 구조가 자주 사용된다.

$$
\text{Progression-free}\rightarrow \text{Progressed disease}\rightarrow \text{Death}.
$$

### 상태분포 벡터와 전이행렬

건강상태가 $K$개라고 하자. 시간 $t$에서의 상태분포는 행벡터로 표현할 수 있다.

$$
\boldsymbol{\pi}_t=(\pi_{t1},\pi_{t2},\ldots,\pi_{tK}).
$$

여기서 $\pi_{tk}$는 시간 $t$에서 상태 $k$에 있는 환자의 비율이다. 모든 환자는 하나의 상태에 속해야 하므로 다음이 성립한다.

$$
\sum_{k=1}^{K}\pi_{tk}=1.
$$

전이확률 행렬은 다음과 같다.

$$
\boldsymbol{P}_t=
\begin{pmatrix}
p_{11,t} & p_{12,t} & \cdots & p_{1K,t} \\
p_{21,t} & p_{22,t} & \cdots & p_{2K,t} \\
\vdots & \vdots & \ddots & \vdots \\
p_{K1,t} & p_{K2,t} & \cdots & p_{KK,t}
\end{pmatrix}.
$$

여기서 $p_{ab,t}$는 시간 $t$에서 상태 $a$에 있는 환자가 다음 주기에 상태 $b$로 이동할 확률이다. 각 행의 합은 1이어야 한다.

$$
\sum_{b=1}^{K}p_{ab,t}=1,\qquad a=1,\ldots,K.
$$

다음 주기의 상태분포는 다음과 같이 계산한다.

$$
\boldsymbol{\pi}_{t+1}=\boldsymbol{\pi}_t\boldsymbol{P}_t.
$$

전이행렬이 시간에 따라 변하지 않으면 시간동질 마코프모델이고, $\boldsymbol{P}_t$가 시간, 나이, 주기, 치료 지속기간 등에 따라 달라지면 시간비동질 마코프모델이다. 실제 경제성 평가에서는 나이 증가에 따른 배경 사망률, 치료효과 감소, 치료 중단률 변화 등을 반영하기 위해 시간비동질 구조가 자주 필요하다.

![3상태 마코프모델에서는 환자가 무진행 상태, 진행 후 생존 상태, 사망 상태 사이를 주기별 전이확률에 따라 이동한다.](figures/ch04/fig-ch04-markov-state-transition.png){width="90%"}


그림의 화살표는 임상적으로 가능한 전이만을 나타낸다. 화살표가 없다는 것은 해당 전이가 불가능하다는 구조적 가정이다. 예를 들어 진행 후 무진행 상태로 돌아가는 화살표를 제외하면 치료반응이나 재관해를 모형에서 허용하지 않는다는 의미가 된다. 따라서 상태도는 단순한 설명 그림이 아니라 허용되는 환자 경로를 규정하는 수학적 제약이다.

### 상태 보상, 전이 보상, 반주기 보정

상태별 비용 벡터를 $\boldsymbol{c}_t=(c_{1,t},\ldots,c_{K,t})$, 상태별 효용 벡터를 $\boldsymbol{u}_t=(u_{1,t},\ldots,u_{K,t})$라고 하자. 주기 $t$에서 반주기 보정을 적용한 대표 상태분포를 $\boldsymbol{\pi}_t^*$라고 하면 상태 보상에 의한 비용과 QALY는 다음과 같다.

$$
C_t^{state}=\boldsymbol{\pi}_t^*\boldsymbol{c}_t^\top,
$$

$$
Q_t^{state}=\boldsymbol{\pi}_t^*\boldsymbol{u}_t^\top\Delta t.
$$

반주기 보정은 환자가 주기 시작 또는 주기 종료에만 상태를 바꾸는 것이 아니라 주기 중간에 평균적으로 상태를 이동한다고 보는 근사이다. 가장 흔한 형태는 다음과 같다.

$$
\boldsymbol{\pi}_t^*=\frac{\boldsymbol{\pi}_t+\boldsymbol{\pi}_{t+1}}{2}.
$$

일부 비용은 상태에 머무는 것보다 상태 전이에 의해 발생한다. 예를 들어 진행 진단 비용, 사망 직전 비용, 치료 시작 비용은 전이 보상 또는 사건 보상으로 모델링하는 것이 더 자연스럽다. 상태 $a$에서 상태 $b$로 이동할 때 발생하는 전이 비용을 $r^C_{ab,t}$라고 하면 해당 주기의 기대 전이 비용은 다음과 같다.

$$
C_t^{transition}=\sum_{a=1}^{K}\sum_{b=1}^{K}\pi_{t,a}p_{ab,t}r^C_{ab,t}.
$$

따라서 주기 $t$의 전체 비용은 다음과 같이 표현할 수 있다.

$$
C_t=C_t^{state}+C_t^{transition}.
$$



상태 $k$에서의 기대 체류시간은 상태 점유확률 곡선 아래의 면적으로 해석할 수 있다. 이산시간에서는 다음과 같이 근사한다.

$$
\mathbb{E}(T_k)
\approx
\Delta t\sum_{t=0}^{T-1}\pi_{t,k}^{*}.
$$

상태별 비용이 단위시간당 비용률 $c_k$이고 시간에 따라 일정하다면, 상태 보상 비용은 기대 체류시간과 비용률의 곱으로 이해할 수 있다.

$$
\mu_C^{state}
\approx
\sum_{k=1}^{K}c_k\,\mathbb{E}(T_k),
$$

할인이 있으면 각 시점의 점유확률에 할인계수를 적용한 할인 체류시간을 사용한다. 이 표현은 Markov trace가 단순한 환자 비율의 변화가 아니라 상태별 생존시간, 비용, QALY를 계산하는 핵심 중간 산출물임을 보여준다.

전체 누적 비용과 QALY는 할인계수 $d(t^*)$를 적용하여 다음과 같이 계산한다.

$$
\mu_C=\sum_{t=0}^{T-1} C_t d(t^*),
$$

$$
\mu_Q=\sum_{t=0}^{T-1} Q_t^{state} d(t^*).
$$

![전이행렬을 반복적으로 적용하면 시간에 따른 상태 점유확률, 즉 Markov trace를 얻을 수 있다.](figures/ch04/fig-ch04-markov-trace.png){width="86%"}


Markov trace의 각 행은 한 시점의 상태분포이므로 행의 합은 항상 1이어야 한다. 흡수상태가 사망인 일반적인 질병모형에서는 시간이 지날수록 사망상태의 점유확률은 감소하지 않아야 한다. 이러한 단순한 제약은 구현 오류를 발견하는 내부 검증 규칙으로 사용할 수 있다.

### 위험률에서 전이확률로 변환

마코프모델의 전이확률은 임상시험이나 관찰연구에서 직접 얻을 수도 있지만, 흔히 위험률 또는 생존함수에서 변환하여 계산한다. 한 주기 동안 상태 $a$에서 다른 상태로 나가는 총 위험률이 $h_a$이고 주기 길이가 $\Delta t$라면, 상수 위험률 가정하에서 상태 $a$를 떠날 확률은 다음과 같다.

$$
p_{a,\text{leave}}=1-\exp(-h_a\Delta t).
$$

여러 경쟁 전이가 있고 상태 $a$에서 상태 $b$로 가는 원인별 위험률이 $h_{ab}$라면 총 위험률은 $h_a=\sum_{b\ne a}h_{ab}$이다. 위험률이 주기 안에서 일정하다고 가정하면 전이확률은 다음과 같다.

$$
p_{ab}=\frac{h_{ab}}{h_a}\{1-\exp(-h_a\Delta t)\},\qquad b\ne a,
$$

$$
p_{aa}=\exp(-h_a\Delta t).
$$

이 식은 특히 여러 전이가 동시에 가능한 상태에서 각 전이확률의 합이 1을 넘지 않도록 만드는 데 중요하다.


위 식은 주기 안에서 원인별 위험률이 일정하고, 상태를 떠난 뒤 같은 주기 안에 추가 전이를 하지 않는 단순 구조에서 직관적으로 해석할 수 있다. 일반적인 연속시간 다상태모형에서는 생성행렬 $\boldsymbol{Q}$를 구성한 뒤 다음과 같이 전이확률 행렬을 얻는 것이 더 일반적이다.

$$
\boldsymbol{P}(\Delta t)=\exp(\boldsymbol{Q}\Delta t).
$$

행렬지수는 한 주기 안에서 발생할 수 있는 연속된 여러 이동을 수학적으로 포함한다. 주기가 길거나 상태 간 왕복 이동이 가능할수록 단순한 위험률 변환과 행렬지수의 차이가 커질 수 있다.

### 주기 길이와 이산화 오차

주기 길이가 길면 사건 발생 시점이 거칠게 근사되어 비용과 QALY에 이산화 오차가 생길 수 있다. 반대로 지나치게 짧은 주기는 계산량을 늘리고, 자료에서 직접 추정하기 어려운 짧은 구간 전이확률을 요구한다. 적절한 주기 길이는 임상적으로 중요한 사건 간격보다 충분히 짧아야 하며, 주기를 더 짧게 했을 때 결과가 안정되는지 확인해야 한다.

상태 체류기간이 미래 전이에 영향을 주는 경우에는 터널 상태를 사용할 수 있다. 예를 들어 진행 후 첫 3개월의 사망위험이 특히 높다면 진행 상태를 $PD_1,PD_2,PD_3,PD_{4+}$로 나누어 진행 후 경과시간을 상태에 포함할 수 있다. 이는 과거 이력을 확장된 현재 상태로 바꾸어 마코프 가정을 회복하는 방법이다.

### 마코프 가정과 그 한계

전통적인 마코프모델은 현재 상태가 주어지면 미래 상태가 과거의 경로와 무관하다는 가정을 사용한다.

$$
P(S_{t+1}=b\mid S_t=a,S_{t-1},\ldots,S_0)
=P(S_{t+1}=b\mid S_t=a).
$$

이 가정은 모델을 단순하게 만들지만, 현실의 질병 진행을 충분히 반영하지 못할 수 있다. 예를 들어 진행 상태에 들어온 지 오래된 환자와 방금 진행된 환자의 사망위험은 다를 수 있다. 이런 경우에는 진행 후 경과시간을 구분하는 터널 상태를 추가하거나, 상태 체류기간을 전이확률에 포함하거나, 환자 수준 시뮬레이션을 사용할 수 있다.

::: {.callout-warning title="마코프 가정의 한계"}
마코프모델에서는 현재 상태가 같으면 과거 경로와 상태 체류기간이 달라도 동일한 미래 전이확률을 가진다고 가정하는 경우가 많다. 질병 이력, 누적 독성, 치료 지속기간, 진행 후 시간 등이 예후에 중요하다면 단순 마코프 가정은 부적절할 수 있다.
:::

## 분할생존모델 {#sec-partitioned-survival-model}

분할생존모델은 특히 종양학 경제성 평가에서 널리 사용되는 모형 구조이다. 분할생존모델은 건강상태 간 전이확률을 직접 모델링하기보다, 전체생존곡선과 무진행생존곡선을 이용하여 시간별 상태 점유확률을 계산한다.

전형적인 종양학 분할생존모델은 세 상태로 구성된다.

1. 무진행 생존 상태
2. 진행 후 생존 상태
3. 사망 상태

시간 $t$에서 무진행생존확률을 $S_{PFS}(t)$, 전체생존확률을 $S_{OS}(t)$라고 하자. 그러면 각 상태의 점유확률은 다음과 같이 계산된다.

$$
\pi_{PF}(t)=S_{PFS}(t),
$$

$$
\pi_{PD}(t)=S_{OS}(t)-S_{PFS}(t),
$$

$$
\pi_D(t)=1-S_{OS}(t).
$$

이 구조의 핵심은 전체 생존 환자 중 무진행 상태에 있지 않은 환자를 진행 후 생존 상태로 분류한다는 점이다. 전체생존곡선 $S_{OS}(t)$는 시간 $t$까지 생존해 있는 환자의 비율이고, 무진행생존곡선 $S_{PFS}(t)$는 시간 $t$까지 진행도 사망도 경험하지 않은 환자의 비율이다. 따라서 진행 후 생존 상태는 다음 차이로 정의된다.


분할생존모델은 두 주변 생존분포로 상태 점유확률을 정의하지만, 개별 환자의 진행시간과 사망시간의 결합분포를 직접 규정하지 않는다. 동일한 PFS와 OS 곡선을 재현하는 여러 결합 경로가 존재할 수 있으므로 진행 후 사망위험이나 진행 후 생존기간의 분포는 두 곡선만으로 완전히 식별되지 않는다. 이 점이 상태전이모형과의 중요한 차이이다.


$$
\text{Progressed disease}=\text{Alive}-\text{Progression-free}.
$$

![분할생존모델에서는 PFS와 OS 곡선을 이용하여 무진행, 진행 후 생존, 사망의 상태 점유확률을 직접 계산한다.](figures/ch04/fig-ch04-partitioned-survival.png){width="88%"}


그림에서 PFS 곡선 아래의 영역은 무진행 상태에서 보낸 기대시간에 해당하고, OS와 PFS 곡선 사이의 영역은 진행 후 생존 상태에서 보낸 기대시간에 해당한다. OS 곡선 위쪽의 여집합은 누적 사망확률이다. 따라서 분할생존모델의 상태 점유시간은 생존곡선의 면적으로 직접 계산된다.

### 상태별 제한평균 생존시간

분석 기간을 $\tau$라고 하면 무진행 상태의 기대 체류시간은 제한평균 무진행생존시간과 같다.

$$
RMST_{PF}(\tau)
=\int_0^\tau S_{PFS}(t)\,dt.
$$

전체 생존시간의 제한평균은 다음과 같다.

$$
RMST_{OS}(\tau)
=\int_0^\tau S_{OS}(t)\,dt.
$$

따라서 진행 후 생존 상태의 기대 체류시간은 두 면적의 차이이다.

$$
RMST_{PD}(\tau)
=RMST_{OS}(\tau)-RMST_{PF}(\tau).
$$

상태 효용이 시간에 따라 일정하고 할인을 생략하면 기대 QALY는 다음처럼 간단히 표현된다.

$$
\mu_Q(\tau)
=u_{PF}RMST_{PF}(\tau)
+u_{PD}\{RMST_{OS}(\tau)-RMST_{PF}(\tau)\}.
$$

이 식은 PFS와 OS 외삽의 작은 차이가 장기 QALY에 직접 누적될 수 있음을 보여준다.

### 비용과 QALY 계산

상태별 비용을 $c_{PF}$, $c_{PD}$, $c_D$라고 하고 상태별 효용을 $u_{PF}$, $u_{PD}$, $u_D$라고 하자. 일반적으로 사망 상태의 효용은 0이고, 사망 상태 비용도 0으로 두지만, 사망 직전 비용은 별도의 사건 비용으로 추가할 수 있다. 시간 $t$에서의 기대비용과 기대효용은 다음과 같다.

$$
C(t)=\pi_{PF}(t)c_{PF}+\pi_{PD}(t)c_{PD}+\pi_D(t)c_D,
$$

$$
U(t)=\pi_{PF}(t)u_{PF}+\pi_{PD}(t)u_{PD}+\pi_D(t)u_D.
$$

연속시간에서 누적 기대비용과 기대 QALY는 다음과 같다.

$$
\mu_C(\tau)=\int_0^\tau C(t)d(t)\,dt,
$$

$$
\mu_Q(\tau)=\int_0^\tau U(t)d(t)\,dt.
$$

이산 시간 근사를 사용하면 다음과 같다.

$$
\mu_Q(\tau)\approx \sum_{t=0}^{T-1}U(t^*)\Delta t\,d(t^*).
$$

### 분할생존모델의 일관성 조건

분할생존모델에서는 모든 시점에서 다음 조건이 성립해야 한다.

$$
1\ge S_{OS}(t)\ge S_{PFS}(t)\ge 0.
$$

하지만 PFS와 OS를 서로 독립적으로 모수적 생존모형으로 외삽하면 일부 시점에서 $S_{PFS}(t)>S_{OS}(t)$가 되는 비현실적인 결과가 나타날 수 있다. 또한 PFS와 OS 곡선의 상관구조가 명시적으로 반영되지 않을 수 있고, 진행 후 치료나 사망 전 비용의 세부 구조를 직접 모델링하기 어렵다. 이러한 한계 때문에 분할생존모델에서는 생존곡선의 시각적 점검, 장기 외삽의 임상적 타당성, PFS와 OS의 논리적 일관성, 진행 후 생존의 해석 가능성을 반드시 확인해야 한다.


PFS와 OS 추정량은 동일한 임상시험 환자에서 산출되므로 통계적으로 상관되어 있다. 확률론적 민감도 분석에서 두 생존모형의 모수를 독립적으로 추출하면 상태 점유확률의 불확실성을 왜곡할 수 있다. 가능한 경우에는 공동 공분산 구조, 재표본추출 또는 동일한 환자 수준 자료에 대한 공동 적합을 통해 상관을 보존해야 한다.

분할생존모델과 상태전이모형이 동일한 관찰기간 자료에 잘 적합하더라도 장기 외삽은 다를 수 있다. 분할생존모델은 PFS와 OS를 직접 외삽하고, 상태전이모형은 진행과 사망의 원인별 전이과정을 외삽한다. 따라서 두 구조의 비교는 단순한 적합도 비교가 아니라 장기 질병경로에 대한 구조적 시나리오 분석으로 해석해야 한다.

::: {.callout-important title="분할생존모델의 핵심 점검사항"}
분할생존모델에서는 모든 시점에서 $S_{OS}(t)\ge S_{PFS}(t)$가 성립해야 한다. 두 생존곡선을 독립적으로 외삽하면 이 조건이 깨질 수 있으므로 반드시 시각적·수치적으로 확인해야 한다.
:::

## 마코프 환자 수준 시뮬레이션 {#sec-markov-patient-level-simulation}

마코프 코호트 모델은 전체 환자집단의 상태분포를 추적한다. 반면 마코프 환자 수준 시뮬레이션은 개별 환자의 경로를 하나씩 생성한 후, 많은 환자의 결과를 평균하여 기대비용과 기대 QALY를 추정한다. 이를 개별 환자 시뮬레이션 또는 microsimulation이라고도 한다.

환자 수준 시뮬레이션은 다음과 같은 상황에서 유용하다.

- 환자 특성에 따라 전이확률이 다르다.
- 과거 사건 경험이나 상태 체류기간이 미래 위험에 영향을 준다.
- 치료 중단, 재치료, 순차치료 등 복잡한 경로가 필요하다.
- 개별 환자별 이질성을 반영해야 한다.
- 상태 수가 많아 코호트 모델이 지나치게 복잡해진다.

### 개별 환자 전이확률

환자 $i$가 시간 $t$에서 상태 $S_{i,t}=a$에 있다고 하자. 다음 상태는 현재 상태, 환자 특성 $X_i$, 과거 이력 $H_{i,t}$에 따라 결정될 수 있다.

$$
P(S_{i,t+1}=b\mid S_{i,t}=a,X_i,H_{i,t}).
$$

전통적인 코호트 마코프모델에서는 보통 다음과 같은 단순한 형태를 사용한다.

$$
P(S_{t+1}=b\mid S_t=a).
$$

반면 환자 수준 시뮬레이션에서는 개인별 전이확률을 사용할 수 있다. 예를 들어 상태 $a$에서 가능한 다음 상태 집합을 $\mathcal{A}(a)$라고 하면 다항 로짓 형태로 다음과 같이 쓸 수 있다.

$$
P(S_{i,t+1}=b\mid S_{i,t}=a,X_i,H_{i,t})
=\frac{\exp(\eta_{iabt})}{\sum_{\ell\in\mathcal{A}(a)}\exp(\eta_{ia\ell t})},
$$

$$
\eta_{iabt}=\alpha_{ab}+\boldsymbol{\beta}_{ab}^{\top}X_i+\boldsymbol{\gamma}_{ab}^{\top}H_{i,t}.
$$

이 표현은 환자 특성뿐 아니라 상태 체류기간, 이전 이상반응, 누적 치료기간 같은 이력 변수를 전이확률에 반영할 수 있음을 보여준다.

### 환자별 비용과 QALY

환자 $i$의 총 비용과 QALY는 각 주기 보상의 합으로 표현할 수 있다.

$$
C_i=\sum_{t=0}^{T-1} c(S_{i,t},X_i,H_{i,t})d(t^*)
+\sum_m c^{event}_{im}d(T_{im}),
$$

$$
Q_i=\sum_{t=0}^{T-1} u(S_{i,t},X_i,H_{i,t})\Delta t\,d(t^*).
$$



모수 $\boldsymbol{\theta}$가 고정되어 있을 때 개별 환자 결과 $C_i$가 서로 독립이고 동일한 분포를 따르면, 표본평균은 큰수의 법칙에 의해 조건부 기대비용으로 수렴한다.

$$
\widehat{\mu}_C(\boldsymbol{\theta})
\xrightarrow[N\to\infty]{P}
\mathbb{E}(C_i\mid\boldsymbol{\theta}).
$$

중심극한정리에 의해 충분히 큰 $N$에서는 다음 근사가 성립한다.

$$
\sqrt{N}
\left\{
\widehat{\mu}_C(\boldsymbol{\theta})
-\mu_C(\boldsymbol{\theta})
\right\}
\overset{approx}{\sim}
N(0,\sigma_C^2).
$$

따라서 시뮬레이션 환자 수는 임의로 정하기보다 관심 있는 증분결과의 Monte Carlo 표준오차가 충분히 작아질 때까지 증가시키는 것이 바람직하다.

$N$명의 시뮬레이션 환자를 생성하면 기대비용과 기대 QALY는 다음과 같이 추정한다.

$$
\widehat{\mu}_C=\frac{1}{N}\sum_{i=1}^{N}C_i,
$$

$$
\widehat{\mu}_Q=\frac{1}{N}\sum_{i=1}^{N}Q_i.
$$

환자 수준 시뮬레이션에는 Monte Carlo 오차가 존재한다. 비용 결과의 표본표준편차를 $s_C$라고 하면 Monte Carlo 표준오차는 다음과 같다.

$$
MCSE(\widehat{\mu}_C)=\frac{s_C}{\sqrt{N}}.
$$

마찬가지로 QALY의 Monte Carlo 표준오차는 $s_Q/\sqrt{N}$이다. 환자 수 $N$을 늘리면 Monte Carlo 오차는 감소하지만 계산 시간이 증가한다.

![코호트 마코프모델은 상태분포 벡터를 추적하고, 환자 수준 시뮬레이션은 개별 환자의 경로를 생성한 뒤 평균을 계산한다.](figures/ch04/fig-ch04-microsimulation-vs-cohort.png){width="92%"}


그림의 두 접근은 기대값 수준에서는 같은 질병과정과 보상구조를 사용하면 동일한 결과에 수렴할 수 있다. 차이는 코호트모형이 확률분포를 직접 전파하는 반면, 환자 수준 시뮬레이션은 그 분포에서 무작위 경로를 반복 추출한다는 점이다. 따라서 환자 수준 시뮬레이션의 유연성에는 Monte Carlo 오차와 더 복잡한 검증 부담이 따른다.

### 분산감소와 공통 난수

두 전략의 증분결과를 비교할 때 동일한 가상 환자와 동일한 난수열을 사용하는 공통 난수 방법은 Monte Carlo 오차를 줄일 수 있다. 두 전략의 비용 추정치를 $\widehat{C}_1$과 $\widehat{C}_0$라고 하면 증분비용의 분산은 다음과 같다.

$$
\operatorname{Var}(\widehat{C}_1-\widehat{C}_0)
=\operatorname{Var}(\widehat{C}_1)
+\operatorname{Var}(\widehat{C}_0)
-2\operatorname{Cov}(\widehat{C}_1,\widehat{C}_0).
$$

공통 난수로 두 전략의 결과에 양의 상관을 유도하면 마지막 공분산 항 때문에 증분비용의 분산이 감소한다. 이는 전략별 평균의 정밀도보다 증분결과의 정밀도가 중요한 경제성 평가에 특히 유용하다.

### 1차 불확실성과 2차 불확실성

환자 수준 시뮬레이션에서는 두 종류의 불확실성을 구분하는 것이 중요하다. 첫째, 같은 모수값이 주어졌을 때 개별 환자의 경로가 우연히 달라지는 1차 불확실성이 있다. 이는 환자 간 임상 경로의 무작위 변동성이다. 둘째, 전이확률, 비용, 효용, 상대효과 같은 모수 자체가 불확실한 2차 불확실성이 있다. 경제성 평가의 확률론적 민감도 분석에서 주로 반영해야 하는 것은 2차 불확실성이다.

따라서 환자 수준 시뮬레이션을 PSA와 결합할 때는 보통 바깥 반복에서 모수값을 추출하고, 안쪽 반복에서 충분한 수의 환자를 시뮬레이션한다. 계산량을 줄이기 위해 공통 난수, 고정된 가상 환자집단, 충분히 큰 환자 수를 사용할 수 있다.

::: {.callout-tip title="환자 수준 시뮬레이션 사용 원칙"}
환자 수준 시뮬레이션은 유연하지만 항상 필요한 것은 아니다. 환자 이질성, 과거 이력, 상태 체류기간, 순차치료 경로가 의사결정 결과에 중요한 영향을 줄 때 사용하는 것이 적절하다.
:::

## 이산 사건 시뮬레이션 {#sec-discrete-event-simulation}

이산 사건 시뮬레이션은 환자의 상태를 일정한 주기마다 갱신하는 대신, 중요한 사건이 발생하는 시간 자체를 직접 시뮬레이션하는 접근이다. 환자는 시간의 흐름 속에서 치료 시작, 반응, 진행, 이상반응, 치료 중단, 입원, 사망과 같은 사건을 경험한다. 모델은 이러한 사건이 언제 발생하는지를 생성하고, 사건 발생 시 비용과 QALY를 업데이트한다.

이산 사건 시뮬레이션은 다음과 같은 상황에서 유용하다.

- 사건 발생 시간이 중요하다.
- 여러 사건이 서로 경쟁하거나 사건 순서에 따라 이후 위험이 달라진다.
- 자원 제약, 대기시간, 병상 가용성처럼 시스템 수준 요인을 모델링해야 한다.
- 환자별 경로가 매우 다양하다.
- 고정 주기 모델이 비효율적이거나 부정확하다.

![이산 사건 시뮬레이션은 환자 특성 생성, 후보 사건시간 생성, 가장 이른 사건 선택, 상태·비용·효용 갱신, 다음 사건 스케줄링을 반복한다.](figures/ch04/fig-ch04-des-flow.png){width="72%"}


그림의 핵심은 시간이 일정한 간격으로 진행되지 않고 사건이 발생하는 시점으로 바로 이동한다는 점이다. 가장 이른 사건이 발생하면 환자의 상태와 위험요인이 바뀔 수 있으므로, 아직 발생하지 않은 후보 사건을 그대로 유지할지 취소하고 다시 생성할지에 대한 규칙을 명확히 해야 한다.

### 사건시간 생성

이산 사건 시뮬레이션에서는 환자 $i$에 대해 여러 후보 사건시간을 생성한다. 예를 들어 진행, 사망, 중증 이상반응 시간을 다음과 같이 둘 수 있다.

$$
T_{i,prog}=\text{progression time},
$$

$$
T_{i,death}=\text{death time},
$$

$$
T_{i,AE}=\text{adverse event time}.
$$

다음 사건 시간과 사건 종류는 다음과 같이 결정된다.

$$
T_{i,next}=\min(T_{i,prog},T_{i,death},T_{i,AE}),
$$

$$
K_{i,next}=\arg\min_{k\in\{prog,death,AE\}}T_{i,k}.
$$

사건 시간이 생존함수 $S_k(t)$를 따른다면 역변환법을 사용할 수 있다. $U\sim Uniform(0,1)$일 때 $S_k(T)=U$가 되도록 $T$를 생성한다. Weibull 생존함수를 shape-scale 모수화로 정의하되, 지불의사금액 $\lambda$와 혼동을 피하기 위해 scale 모수를 $\eta$로 표기하자.

$$
S(t)=\exp\left[-\left(\frac{t}{\eta}\right)^k\right].
$$

그러면 사건시간은 다음과 같이 생성된다.

$$
T=\eta\{-\log(U)\}^{1/k}.
$$

다른 모수화인 $S(t)=\exp(-\alpha t^k)$를 사용하면 다음과 같다.

$$
T=\left\{\frac{-\log(U)}{\alpha}\right\}^{1/k}.
$$

두 식은 모수화만 다르다. 분석 보고서에서는 반드시 어떤 모수화를 사용했는지 명시해야 한다.


보다 일반적으로 사건의 누적위험함수를 $H(t)$라고 하면 생존함수는 $S(t)=\exp\{-H(t)\}$이다. 따라서 역변환법은 다음과 같이 표현된다.

$$
T=H^{-1}\{-\log(U)\}.
$$

위험률이 시간이나 환자 특성에 따라 변하더라도 누적위험함수를 계산하고 역함수를 구할 수 있으면 같은 원리를 사용할 수 있다. 닫힌 형태의 역함수가 없으면 수치적 근찾기나 thinning 알고리즘을 사용할 수 있다.

### 경쟁 사건과 사건 시계

진행, 이상반응, 사망의 후보시간을 각각 독립적으로 생성하고 최소값을 선택하는 방법은 후보 잠재시간의 독립성 또는 특정한 결합구조를 암묵적으로 가정한다. 사건 간 의존성이 강하면 공유 frailty, 다변량 생존모형 또는 상태 변화 후 조건부 위험률을 이용해야 한다.

상태가 변한 뒤 사건시간을 갱신하는 방식도 명시해야 한다. 새로운 상태에 진입한 시점을 시간의 원점으로 다시 설정하면 clock-reset 접근이고, 질병 시작 이후의 절대시간을 계속 사용하면 clock-forward 접근이다. 전자는 상태 체류기간이 위험을 결정하는 준마코프 과정을, 후자는 달력시간이나 진단 후 경과시간이 위험을 결정하는 과정을 표현한다.

### 이산 사건 시뮬레이션의 장점과 한계

이산 사건 시뮬레이션은 매우 유연하다. 복잡한 환자 경로, 시간 의존 위험, 반복 사건, 자원 제약, 대기시간, 환자 이질성을 표현하기 쉽다. 그러나 모델이 복잡해질수록 투명성과 검증 가능성이 낮아질 수 있다. 또한 많은 수의 환자 경로를 시뮬레이션해야 하므로 계산 부담이 커질 수 있다.

따라서 이산 사건 시뮬레이션은 문제의 복잡성이 그 유연성을 필요로 할 때 사용하는 것이 바람직하다. 단순한 3상태 질병 진행 문제를 이산 사건 시뮬레이션으로 표현하는 것은 오히려 불필요한 복잡성을 초래할 수 있다.

## 모형의 검증, 보정, 구조적 불확실성

경제성 평가 모델은 계산이 실행된다는 사실만으로 타당성이 보장되지 않는다. 모델 검증은 구현이 의도한 수학적 구조와 일치하는지 확인하는 과정이고, 모델 타당화는 그 구조와 결과가 실제 임상현상 및 의사결정 목적에 적절한지 평가하는 과정이다.

### 구현 검증과 내부 타당성

구현 검증에서는 수식, 코드, 입력자료, 단위, 할인, 상태전이, 보상 누적이 명세서와 일치하는지 확인한다. 대표적인 점검 항목은 다음과 같다.

- 모든 전이확률이 0과 1 사이이고 각 행의 합이 1인지 확인한다.
- 상태 점유확률이 음수가 아니고 각 시점에서 합이 1인지 확인한다.
- 사망 흡수상태의 점유확률이 감소하지 않는지 확인한다.
- 비용과 QALY를 0으로 설정했을 때 결과도 0이 되는지 확인한다.
- 두 전략의 모든 입력값을 같게 설정했을 때 증분결과가 0이 되는지 확인한다.
- 주기 길이와 시뮬레이션 수를 변화시켰을 때 결과가 수렴하는지 확인한다.

이러한 극단값 검사와 불변조건 검사는 복잡한 결과표보다 구현 오류를 더 빠르게 발견할 수 있다.

### 외적 타당성과 예측 타당성

외적 타당성은 모델 결과가 모델 적합에 사용되지 않은 자료와 얼마나 일치하는지를 평가한다. 관찰된 생존곡선, 재발률, 입원율, 치료중단률, 누적비용과 모델 예측을 시점별로 비교할 수 있다. 관찰기간 안의 적합만으로 장기 외삽이 보장되지는 않으므로, 장기 자연사 자료와 임상전문가의 판단을 함께 사용해야 한다.

예측값을 $\widehat{y}_m$이고 외부 목표값을 $y_m$이라고 하면 단순한 오차 측도는 다음과 같다.

$$
RMSE
=\sqrt{
\frac{1}{M}
\sum_{m=1}^{M}
(\widehat{y}_m-y_m)^2
}.
$$

그러나 경제성 평가에서는 평균 오차뿐 아니라 임상적으로 중요한 시점과 상태에서의 방향성, 장기 꼬리, 치료군 간 차이를 함께 평가해야 한다.

### 모형 보정

직접 추정하기 어려운 모수를 외부 관찰값에 맞추어 결정하는 과정을 보정이라고 한다. 보정 모수를 $\boldsymbol{\theta}$, 모델이 생성하는 목표값을 $g_m(\boldsymbol{\theta})$, 관찰 목표값을 $y_m$이라고 하면 가중 최소제곱 보정은 다음 문제로 표현할 수 있다.

$$
\widehat{\boldsymbol{\theta}}
=\arg\min_{\boldsymbol{\theta}}
\sum_{m=1}^{M}
w_m
\{g_m(\boldsymbol{\theta})-y_m\}^2.
$$

가중치 $w_m$은 목표값의 정밀도나 의사결정 중요도를 반영할 수 있다. 베이지안 보정에서는 관찰 목표값의 가능도와 사전분포를 결합한다.

$$
p(\boldsymbol{\theta}\mid\boldsymbol{y})
\propto
p(\boldsymbol{y}\mid\boldsymbol{\theta})
p(\boldsymbol{\theta}).
$$

보정 후에는 목표값에 대한 적합뿐 아니라 보정에 사용하지 않은 결과에 대한 재현성과 모수의 식별 가능성을 점검해야 한다. 서로 다른 모수 조합이 동일한 목표값을 재현하면 의사결정 결과의 불확실성이 과소평가될 수 있다.

### 구조적 불확실성과 모형 불일치

모형은 현실을 단순화하므로 관찰값과 모델값의 차이는 모수 오차만으로 설명되지 않을 수 있다. 이를 개념적으로 다음과 같이 표현할 수 있다.

$$
y(t)=g\{t,\boldsymbol{\theta}\}+\delta(t)+\varepsilon(t),
$$

여기서 $g\{t,\boldsymbol{\theta}\}$는 모델 예측, $\delta(t)$는 구조적 모형 불일치, $\varepsilon(t)$는 관측오차이다. 상태 정의, 전이구조, 생존분포, 치료효과 지속기간, 후속치료 규칙이 달라지면 $\delta(t)$의 형태도 달라진다.

구조적 불확실성은 하나의 모형에서 모수분포만 넓히는 방식으로 충분히 반영되지 않는다. 대안적 상태구조, 생존 외삽, 치료효과 감소, 시간 범위, 자료원에 대한 시나리오를 별도로 분석하고, 각 구조에서 전략 선택이 얼마나 달라지는지 확인해야 한다. 여러 구조에 합리적인 확률을 부여할 수 있다면 모형평균을 사용할 수 있지만, 그 확률 자체도 투명하게 정당화되어야 한다.

run_markov <- function(P, cost, utility, n_cycles = 60,
                       cycle_length = 1 / 12,
                       annual_discount = 0.045,
                       half_cycle = TRUE) {
  state_names <- names(cost)
  trace <- matrix(NA_real_, nrow = n_cycles + 1, ncol = length(cost))
  colnames(trace) <- state_names
  trace[1, ] <- c(PF = 1, PD = 0, Death = 0)

  for (t in 1:n_cycles) {
    trace[t + 1, ] <- trace[t, ] %*% P
  }

  if (half_cycle) {
    reward_trace <- (trace[1:n_cycles, , drop = FALSE] +
                       trace[2:(n_cycles + 1), , drop = FALSE]) / 2
    discount_time <- ((0:(n_cycles - 1)) + 0.5) * cycle_length
  } else {
    reward_trace <- trace[1:n_cycles, , drop = FALSE]
    discount_time <- (0:(n_cycles - 1)) * cycle_length
  }

  discount <- 1 / ((1 + annual_discount) ^ discount_time)
  cycle_cost <- as.numeric(reward_trace %*% cost)
  cycle_qaly <- as.numeric(reward_trace %*% utility) * cycle_length

  list(
    trace = trace,
    total_cost = sum(cycle_cost * discount),
    total_qaly = sum(cycle_qaly * discount),
    cycle_cost = cycle_cost,
    cycle_qaly = cycle_qaly
  )
}

simulate_one_patient <- function(P, cost, utility,
                                 n_cycles = 60,
                                 cycle_length = 1 / 12,
                                 annual_discount = 0.045) {
  state <- 1
  total_cost <- 0
  total_qaly <- 0
  path <- integer(n_cycles + 1)
  path[1] <- state

  for (t in 1:n_cycles) {
    time_mid <- (t - 0.5) * cycle_length
    discount <- 1 / ((1 + annual_discount) ^ time_mid)

    total_cost <- total_cost + cost[[state]] * discount
    total_qaly <- total_qaly + utility[[state]] * cycle_length * discount

    state <- sample(seq_along(cost), size = 1, prob = P[state, ])
    path[t + 1] <- state
  }

  c(cost = as.numeric(total_cost), qaly = as.numeric(total_qaly))
}

rweibull_scale_shape <- function(n, scale, shape) {
  u <- runif(n)

## 핵심 수식 정리 {.unnumbered}

| 개념 | 수식 |
|---|---|
| 순편익 | $NB_j(\lambda)=\lambda Q_j-C_j$ |
| 기대순편익 | $\mu_{NB,j}(\lambda)=\lambda\mathbb{E}(Q_j)-\mathbb{E}(C_j)$ |
| 최적 전략 | $j^*(\lambda)=\arg\max_{j\in\mathcal{J}}\mu_{NB,j}(\lambda)$ |
| 반복기대값 법칙 | $\mathbb{E}(Y)=\mathbb{E}_{\boldsymbol{\theta}}\{\mathbb{E}(Y\mid\boldsymbol{\theta})\}$ |
| 연속시간 전이확률 | $\boldsymbol{P}(\Delta t)=\exp(\boldsymbol{Q}\Delta t)$ |
| 결정수형 기대비용 | $\mu_{C,j}=\sum_{\ell\in\mathcal{L}_j}p_{j\ell}C_{j\ell}$ |
| 결정수형 기대 QALY | $\mu_{Q,j}=\sum_{\ell\in\mathcal{L}_j}p_{j\ell}Q_{j\ell}$ |
| 마코프 상태분포 갱신 | $\boldsymbol{\pi}_{t+1}=\boldsymbol{\pi}_t\boldsymbol{P}_t$ |
| 전이행렬 조건 | $\sum_{b=1}^{K}p_{ab,t}=1$ |
| 반주기 보정 | $\boldsymbol{\pi}_t^*=(\boldsymbol{\pi}_t+\boldsymbol{\pi}_{t+1})/2$ |
| 상태 보상 비용 | $C_t^{state}=\boldsymbol{\pi}_t^*\boldsymbol{c}_t^\top$ |
| 상태 보상 QALY | $Q_t^{state}=\boldsymbol{\pi}_t^*\boldsymbol{u}_t^\top\Delta t$ |
| 경쟁위험 전이확률 | $p_{ab}=h_{ab}h_a^{-1}\{1-\exp(-h_a\Delta t)\}$ |
| 분할생존 무진행 | $\pi_{PF}(t)=S_{PFS}(t)$ |
| 분할생존 진행 후 생존 | $\pi_{PD}(t)=S_{OS}(t)-S_{PFS}(t)$ |
| 분할생존 사망 | $\pi_D(t)=1-S_{OS}(t)$ |
| 무진행 제한평균시간 | $RMST_{PF}(\tau)=\int_0^\tau S_{PFS}(t)\,dt$ |

| Weibull 사건시간 생성 | $T=\eta\{-\log(U)\}^{1/k}$ |
| 일반 사건시간 생성 | $T=H^{-1}\{-\log(U)\}$ |
