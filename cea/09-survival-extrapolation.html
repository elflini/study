Note이 장의 핵심 질문

생존외삽의 핵심 질문은 “관찰된 추적기간 안에서 어느 모형이 가장 잘 맞는가?”가 아니다. 더 중요한 질문은 “현재 자료, 임상 지식, 외부 근거를 모두 고려할 때 어떤 장기 생존곡선이 의사결정에 가장 타당한가?”이다.

9.1 경제성평가에서 사용하는 생존분석에서는 외삽이 필요하다

9.1.1 임상시험 추적기간과 경제성 평가 분석기간

확증적 임상시험에서 생존분석의 주된 목적은 제한된 추적기간 안에서 두 치료군의 생존 경험을 비교하는 것이다. 전체생존기간(overall survival, OS), 무진행생존기간(progression-free survival, PFS), 사건 없는 생존기간(event-free survival, EFS)을 평가변수로 사용한 임상시험에서는 Kaplan-Meier 곡선, 로그순위검정, Cox 비례위험모형이 주로 사용된다.

경제성 평가는 질문이 다르다. 경제성 평가는 한 치료전략을 선택했을 때 분석기간 동안 누적되는 비용과 건강효과를 추정한다. 생존기간이 건강효과의 핵심 요소라면 생존함수 아래 면적이 기대 생존기간과 QALY에 직접 연결된다. 생존시간을 \(T\), 생존함수를 \(S(t)=P(T>t)\), 분석기간을 \(\tau\)라고 하면 제한평균 생존기간은 다음과 같다.

\[ \operatorname{RMST}(\tau)=\mathbb{E}\{\min(T,\tau)\}=\int_0^\tau S(t)\,dt. \]

시간 \(t\)에서의 효용가중치를 \(u(t)\)라고 하면 기대 QALY는 다음과 같이 쓸 수 있다.

\[ \mathbb{E}(Q)=\int_0^\tau u(t)S(t)\,dt. \]

효용가중치가 시간에 따라 일정하게 \(u\)라면 다음과 같이 단순화된다.

\[ \mathbb{E}(Q)=u\int_0^\tau S(t)\,dt. \]

문제는 임상시험 추적기간 \(t_{\max}\)가 분석기간 \(\tau\)보다 짧은 경우가 대부분이라는 점이다. 이 경우 \(0\)부터 \(t_{\max}\)까지의 면적은 관찰자료에 근거해 추정할 수 있지만, \(t_{\max}\) 이후의 면적은 모형에 의해 예측해야 한다.

\[ \int_0^\tau S(t)\,dt = \int_0^{t_{\max}} S(t)\,dt + \int_{t_{\max}}^\tau S(t)\,dt. \]

오른쪽 두 번째 항이 바로 외삽 영역이다.

외삽이 결과에 미치는 정도는 전체 기대 생존기간 중 관찰기간 이후 면적이 차지하는 비율로 나타낼 수 있다. 다음의 외삽 비중은 장기 결과가 자료보다 모형 가정에 얼마나 의존하는지를 보여주는 진단지표이다.

\[ R_{ext}(\tau) = \frac{\displaystyle\int_{t_{\max}}^\tau S(t)\,dt} {\displaystyle\int_0^\tau S(t)\,dt}. \]

\(R_{ext}(\tau)\)가 클수록 총 기대 생존기간의 많은 부분이 실제 관찰자료가 아니라 꼬리 분포 가정으로 결정된다. 두 치료전략의 비교에서는 전체 생존기간보다 증분 생존편익의 외삽 의존도가 더 중요할 수 있다.

\[ R_{ext}^{\Delta}(\tau) = \frac{\displaystyle\int_{t_{\max}}^\tau \{S_1(t)-S_0(t)\}\,dt} {\displaystyle\int_0^\tau \{S_1(t)-S_0(t)\}\,dt}. \]

분모가 0에 가까우면 이 비율은 불안정하므로, 실제 보고에서는 관찰구간과 외삽구간의 증분 생존기간을 각각 절대값으로 함께 제시하는 것이 바람직하다.

이 그림에서 수직 경계의 왼쪽은 임상시험 자료가 생존곡선의 형태를 직접 제약하는 구간이고, 오른쪽은 선택한 분포와 치료효과 지속 가정이 결과를 지배하는 구간이다. 외삽곡선 사이의 작은 수직 차이도 긴 시간 동안 적분되면 기대 생존기간과 QALY에서 큰 차이로 누적될 수 있다.

Important외삽은 보간이 아니다

보간(interpolation)은 관찰된 자료점 사이의 값을 추정하는 문제이다. 외삽(extrapolation)은 관찰된 자료 범위를 넘어선 미래를 예측하는 문제이다. 경제성 평가에서 생존외삽은 관찰되지 않은 장기 생존, 장기 비용, 장기 QALY, ICER를 결정하므로 단순한 기술적 절차가 아니라 핵심 의사결정 요소이다.

9.1.2 Kaplan-Meier 곡선만으로는 충분하지 않은 이유

Kaplan-Meier 추정량은 관찰된 사건 시점에서 생존확률이 계단식으로 감소하는 비모수 추정량이다. 이 추정량은 관찰된 기간 안에서는 매우 유용하지만 마지막 사건 시점 이후의 생존곡선 형태를 제공하지 않는다. 따라서 다음과 같은 평균 생존기간은 Kaplan-Meier 곡선만으로는 일반적으로 식별되지 않는다.

\[ \mathbb{E}(T)=\int_0^\infty S(t)\,dt. \]

임상시험에서 관찰 가능한 최대 사건 시점을 \(t_{\max}\)라고 하면 Kaplan-Meier 곡선이 직접 제공하는 정보는 대략 다음 면적에 해당한다.

\[ \int_0^{t_{\max}} \widehat S_{KM}(t)\,dt. \]

그러나 평생 분석에서는 다음 꼬리 면적이 필요하다.

\[ \int_{t_{\max}}^\infty S(t)\,dt. \]

이 꼬리 면적은 자료만으로 결정되지 않는다. 같은 관찰구간 적합도를 보이는 여러 모형이 장기 생존에서는 크게 다를 수 있다. 따라서 생존외삽은 통계적 적합도, 위험함수의 형태, 임상적 개연성, 외부 장기자료, 일반 인구 사망률을 함께 고려해야 한다.

통계적으로 말하면 \(t_{\max}\) 이후의 생존함수는 임상시험 자료만으로는 비모수적으로 식별되지 않는다. 마지막 관찰시점의 생존확률을 \(S(t_{\max})\)라고 할 때, 단조감소 조건만으로는 미래 생존함수에 다음과 같은 매우 넓은 범위만 부여된다.

\[ 0\le S(t)\le S(t_{\max}), \qquad t>t_{\max}. \]

따라서 추가적인 분포 가정, 외부자료 또는 임상적 제약이 없으면 꼬리 면적의 하한과 상한도 지나치게 넓어진다. 생존외삽은 관찰자료가 제공하지 않는 정보를 가정으로 보충하는 과정이며, 이 가정을 명시하고 검증 가능한 부분과 검증 불가능한 부분을 구분해야 한다.

9.1.3 외삽의 대상 estimand

외삽모형을 선택하기 전에 먼저 무엇을 추정하려는지 명확히 해야 한다. 경제성 평가에서 생존외삽의 대상은 보통 특정 치료전략 \(j\)에서의 장기 생존함수 \(S_j(t)\), 제한평균 생존기간 \(M_j(\tau)\), 기대 QALY \(\mathbb{E}(Q_j)\)이다.

\[ M_j(\tau)=\int_0^\tau S_j(t)\,dt. \]

두 치료전략 \(1\)과 \(0\)을 비교할 때 증분 생존기간과 증분 QALY는 다음과 같다.

\[ \Delta M(\tau)=M_1(\tau)-M_0(\tau), \]

\[ \Delta Q=\int_0^\tau \{u_1(t)S_1(t)-u_0(t)S_0(t)\}\,dt. \]

따라서 생존외삽의 실무적 질문은 특정 모형의 회귀계수가 얼마인지가 아니라, 그 모형이 \(S_j(t)\)의 장기 꼬리와 \(\Delta Q\)를 얼마나 타당하게 예측하는지이다.

9.1.4 목표 모집단과 표준화 생존함수

외삽 대상은 임상시험 표본 자체의 생존함수인지, 실제 급여 대상 모집단의 생존함수인지에 따라 달라진다. 기저 공변량을 \(X\)라고 하면 치료전략 \(j\)에서 목표 모집단의 주변 생존함수는 조건부 생존함수를 목표 모집단 분포에 대해 평균하여 얻는다.

\[ S_j^{pop}(t) = \int S_j(t\mid x)\,dF_{pop}(x). \]

표본자료에서는 다음과 같이 표준화할 수 있다.

\[ \widehat S_j^{pop}(t) = \sum_{i=1}^{n} w_i\widehat S_j(t\mid X_i), \qquad \sum_{i=1}^{n}w_i=1. \]

이 과정은 연령, 질병 단계, 바이오마커와 같이 장기 예후를 변경하는 변수의 분포가 임상시험과 실제 진료에서 다를 때 중요하다. 조건부 모형의 계수를 그대로 외삽하는 것만으로는 목표 모집단의 장기 생존을 보장하지 않으며, 공변량 분포까지 함께 운반해야 한다.

9.2 모수적 모형

9.2.1 중도절단 자료의 우도

모수적 생존모형은 생존시간 \(T\)가 모수 \(\theta\)를 가지는 특정 분포를 따른다고 가정한다.

\[ T \sim F(t;\theta). \]

생존시간 분포는 밀도함수 \(f(t;\theta)\), 생존함수 \(S(t;\theta)\), 위험함수 \(h(t;\theta)\), 누적위험함수 \(H(t;\theta)\)로 표현할 수 있다.

\[ S(t;\theta)=P(T>t), \]

\[ f(t;\theta)=-\frac{dS(t;\theta)}{dt}, \]

\[ h(t;\theta)=\frac{f(t;\theta)}{S(t;\theta)}, \]

\[ H(t;\theta)=\int_0^t h(u;\theta)\,du, \]

\[ S(t;\theta)=\exp\{-H(t;\theta)\}. \]

환자 \(i\)의 관찰시간을 \(t_i\), 사건 관찰 여부를 \(\delta_i\)라고 하자. 사건이 관찰된 환자는 밀도함수 \(f(t_i;\theta)\)에 기여하고, 중도절단된 환자는 해당 시점까지 생존했다는 정보 \(S(t_i;\theta)\)에 기여한다. 따라서 독립적 중도절단 가정하에서 우도는 다음과 같다.

\[ L(\theta)=\prod_{i=1}^n f(t_i;\theta)^{\delta_i}S(t_i;\theta)^{1-\delta_i}. \]

위험함수와 누적위험함수로 쓰면 \(f(t)=h(t)S(t)\)이므로 다음과 같다.

\[ L(\theta)=\prod_{i=1}^n h(t_i;\theta)^{\delta_i}\exp\{-H(t_i;\theta)\}. \]

로그우도는 다음과 같다.

\[ \ell(\theta)=\sum_{i=1}^n\left[\delta_i\log h(t_i;\theta)-H(t_i;\theta)\right]. \]

이 식은 모수적 생존모형을 이해하는 핵심이다. 사건이 발생한 환자는 해당 시점의 순간위험에 대한 정보를 제공하고, 모든 환자는 관찰된 시간까지 누적위험에 대한 정보를 제공한다.

위 우도는 진입 시점부터 관찰되고 우측 중도절단만 존재하는 가장 단순한 형태이다. 연구 진입 전부터 위험에 노출되어 있고 진입시점 \(a_i\)까지 생존한 사람만 포함되는 좌측절단 자료에서는 조건부 생존을 반영하여 개인별 우도 기여도가 다음과 같이 수정된다.

\[ L_i(\theta) = \frac{f(t_i;\theta)^{\delta_i}S(t_i;\theta)^{1-\delta_i}} {S(a_i;\theta)}. \]

사건이 정확한 시점이 아니라 구간 \((L_i,R_i]\) 안에서 발생한 것으로만 알려진 구간중도절단 자료의 우도 기여도는 다음과 같다.

\[ L_i(\theta)=S(L_i;\theta)-S(R_i;\theta). \]

또한 표준 우도는 사건시간과 중도절단시간이 공변량을 조건으로 독립이라는 가정에 의존한다. 이 가정이 위반되면 관찰된 꼬리 부분의 환자가 선택적으로 남게 되어 위험함수와 외삽곡선이 함께 왜곡될 수 있다. 따라서 치료중단, 추적탈락, 행정적 중도절단의 원인을 구분하고 필요하면 역확률 중도절단 가중치나 공동모형을 고려해야 한다.

최대가능도 추정량 \(\widehat\theta\)의 공분산행렬은 관찰정보행렬의 역행렬로 근사된다.

\[ \operatorname{Var}(\widehat\theta) \approx \left[-\frac{\partial^2\ell(\theta)}{\partial\theta\partial\theta^\top} \bigg|_{\theta=\widehat\theta}\right]^{-1}. \]

장기 생존함수는 모수의 비선형 함수이므로, 관찰기간 말미의 정보가 적으면 작은 모수 불확실성이 장기 꼬리에서 크게 증폭될 수 있다.

9.2.2 주요 모수적 생존분포

경제성 평가에서 자주 사용되는 모수적 생존분포는 다음과 같다.

분포 생존함수 \(S(t)\) 위험함수 형태 외삽 해석
Exponential \(\exp(-\lambda t)\) 일정 가장 단순하지만 위험 변화 표현 불가
Weibull \(\exp\{-(t/\lambda)^k\}\) 단조 증가 또는 단조 감소 단순하면서 실무적으로 많이 사용
Gompertz \(\exp[-\{b/a\}(e^{at}-1)]\) 지수적 증가 또는 감소 노화 관련 사망위험 표현 가능
Log-normal \(1-\Phi\{(\log t-\mu)/\sigma\}\) 비단조 가능 초기 증가 후 감소하는 위험 표현 가능
Log-logistic \(\{1+(t/\lambda)^k\}^{-1}\) 비단조 가능, 두꺼운 꼬리 장기 생존 꼬리를 크게 예측할 수 있음
Generalized gamma 모수화에 따라 다양 매우 유연 여러 표준 분포를 포함하지만 해석이 어려움

이 그림은 관찰 초기에 비슷해 보이는 생존곡선도 시간이 길어질수록 꼬리 감소 속도가 크게 달라질 수 있음을 보여준다. 특히 log-logistic과 log-normal 계열은 단순 지수형 분포보다 장기 생존확률을 높게 유지할 수 있으므로, 평생 QALY가 꼬리 선택에 민감해진다.

위험함수 그림에서는 각 분포가 허용하는 형태의 범위를 확인해야 한다. 생존곡선은 누적 결과이므로 서로 비슷해 보일 수 있지만, 위험함수는 일정·단조 증가·단조 감소·단봉형이라는 구조적 차이를 더 분명히 드러낸다.

9.2.3 Exponential 모형

Exponential 모형은 위험함수가 시간에 따라 일정하다고 가정한다.

\[ h(t)=\lambda, \qquad \lambda>0. \]

따라서 누적위험함수와 생존함수는 다음과 같다.

\[ H(t)=\lambda t, \]

\[ S(t)=\exp(-\lambda t). \]

평균 생존시간은 다음과 같다.

\[ \mathbb{E}(T)=\frac{1}{\lambda}. \]

Exponential 모형은 단순하고 안정적이지만 시간에 따른 위험 변화를 허용하지 않는다. 따라서 질병 진행 직후 사망위험이 높아졌다가 시간이 지나며 낮아지는 상황, 또는 고령화로 사망위험이 증가하는 상황에는 부적절할 수 있다.

9.2.4 Weibull 모형

Weibull 모형은 Exponential 모형을 일반화한다. 이 책에서는 scale 모수 \(\lambda>0\)와 shape 모수 \(k>0\)를 사용하는 모수화를 따른다.

\[ S(t)=\exp\left\{-\left(\frac{t}{\lambda}\right)^k\right\}. \]

위험함수와 누적위험함수는 다음과 같다.

\[ h(t)=\frac{k}{\lambda}\left(\frac{t}{\lambda}\right)^{k-1}, \]

\[ H(t)=\left(\frac{t}{\lambda}\right)^k. \]

shape 모수 \(k\)는 위험함수의 형태를 결정한다.

\(k\) 값 위험함수 형태 해석
\(k=1\) 일정 Exponential 모형과 동일
\(k>1\) 시간에 따라 증가 시간이 지날수록 사건위험 증가
\(k<1\) 시간에 따라 감소 초기 위험이 높고 이후 감소

Weibull 모형의 평균 생존시간은 다음과 같다.

\[ \mathbb{E}(T)=\lambda\Gamma\left(1+\frac{1}{k}\right), \]

여기서 \(\Gamma(\cdot)\)는 감마함수이다.

TipWeibull 모형의 장점과 한계

Weibull 모형은 위험함수가 단조 증가 또는 단조 감소하는 상황에 적합하다. 하지만 위험이 초기에 증가했다가 이후 감소하는 비단조 형태는 표현하지 못한다. 항암제 장기 외삽에서 위험함수 형태가 비단조적일 가능성이 있다면 log-normal, log-logistic, spline 기반 모형, mixture cure model 등을 함께 검토해야 한다.

9.2.5 Gompertz 모형

Gompertz 모형은 위험함수가 시간에 따라 지수적으로 변화한다고 가정한다.

\[ h(t)=b\exp(at), \qquad b>0. \]

\(a\ne0\)일 때 누적위험함수는 다음과 같다.

\[ H(t)=\frac{b}{a}\{\exp(at)-1\}. \]

따라서 생존함수는 다음과 같다.

\[ S(t)=\exp\left[-\frac{b}{a}\{\exp(at)-1\}\right]. \]

\(a>0\)이면 위험이 시간이 지남에 따라 증가하고, \(a<0\)이면 위험이 감소한다. Gompertz 모형은 연령 증가에 따른 사망위험 증가를 표현하는 데 자연스러울 수 있다. 그러나 \(a<0\)인 경우 장기적으로 누적위험이 유한값에 수렴할 수 있으므로 장기 생존 꼬리를 과대평가할 가능성을 점검해야 한다.

9.2.6 Log-normal 모형

Log-normal 모형은 생존시간의 로그가 정규분포를 따른다고 가정한다.

\[ \log T \sim N(\mu,\sigma^2). \]

생존함수는 다음과 같다.

\[ S(t)=1-\Phi\left(\frac{\log t-\mu}{\sigma}\right), \]

여기서 \(\Phi(\cdot)\)는 표준정규 누적분포함수이다. 평균 생존시간은 다음과 같다.

\[ \mathbb{E}(T)=\exp\left(\mu+\frac{\sigma^2}{2}\right). \]

Log-normal 모형은 위험함수가 초기에 증가했다가 이후 감소하는 형태를 가질 수 있다. 장기 생존자가 존재하거나 치료 후 일정 기간을 넘기면 사건위험이 낮아지는 질환에서 후보 모형이 될 수 있다. 그러나 꼬리 영역이 상대적으로 두꺼워 장기 생존기간을 크게 예측할 수 있으므로 외부자료와 임상적 개연성 검토가 필요하다.

9.2.7 Log-logistic 모형

Log-logistic 모형의 생존함수는 다음과 같다.

\[ S(t)=\frac{1}{1+(t/\lambda)^k}. \]

위험함수는 다음과 같다.

\[ h(t)=\frac{(k/\lambda)(t/\lambda)^{k-1}}{1+(t/\lambda)^k}. \]

\(k>1\)이면 위험함수는 초기에는 증가하다가 이후 감소할 수 있다. 평균 생존시간은 \(k>1\)일 때만 존재하며 다음과 같다.

\[ \mathbb{E}(T)=\frac{\lambda\pi/k}{\sin(\pi/k)}. \]

Log-logistic 모형은 장기 꼬리가 두꺼울 수 있어 평생 분석에서 QALY를 크게 만들 수 있다. 따라서 단순히 AIC나 BIC가 좋다는 이유만으로 선택하기보다 장기 생존이 임상적으로 가능한지 검토해야 한다.

9.2.8 Generalized gamma 모형

Generalized gamma 모형은 Weibull, log-normal, gamma 분포 등을 포함할 수 있는 매우 유연한 모형이다. 유연성이 높다는 것은 관찰자료에 잘 맞을 가능성이 크다는 장점이 있지만, 장기 외삽에서는 작은 모수 변화가 꼬리 영역에 큰 영향을 줄 수 있다는 단점도 있다.

경제성 평가에서 generalized gamma 모형을 사용할 때는 다음을 확인해야 한다.

  • 장기 생존꼬리가 임상적으로 가능한가?
  • 위험함수 형태가 질병 자연사와 맞는가?
  • 모수 추정의 불확실성이 과도하게 크지 않은가?
  • 단순 모형보다 복잡한 모형을 사용할 충분한 이유가 있는가?

9.2.9 꼬리 거동과 평균 생존시간의 존재

분포 선택은 단순히 곡선의 모양뿐 아니라 꼬리의 감소 속도를 선택하는 것이다. 지수분포와 Weibull 분포는 대체로 지수형 꼬리를 가지지만, log-logistic 분포는 다항식 형태로 더 천천히 감소할 수 있다. 이러한 차이는 평균 생존시간의 존재 조건과 직접 연결된다.

\[ \mathbb{E}(T)=\int_0^\infty S(t)\,dt. \]

이 적분이 유한하지 않으면 평생 평균 생존시간이 존재하지 않는다. 예를 들어 log-logistic 분포에서는 shape 모수 \(k>1\)일 때에만 평균이 유한하다. 실제 경제성 평가는 유한한 분석기간을 사용하므로 수치 계산은 가능하지만, 매우 두꺼운 꼬리는 분석기간 선택에 따라 결과가 급격히 증가할 수 있다. 따라서 평균 존재 여부, 장기 위험률의 극한, 특정 시점의 생존율을 함께 확인해야 한다.

9.2.10 유연 모수적 생존모형

표준 분포가 허용하는 위험함수 형태가 지나치게 제한적일 때는 제한적 세제곱 스플라인을 이용한 유연 모수적 생존모형을 사용할 수 있다. Royston–Parmar 모형의 대표적 표현은 로그 누적위험의 로그를 로그시간의 스플라인 함수로 모형화한다.

\[ \log H(t\mid x) = s\{\log(t);\gamma\}+x^\top\beta, \]

여기서 \(s(\cdot)\)는 절점에 의해 정의되는 제한적 세제곱 스플라인이다. 이에 따라

\[ S(t\mid x) = \exp\left[-\exp\{s(\log t;\gamma)+x^\top\beta\}\right]. \]

절점 수가 증가하면 관찰구간 적합도는 좋아질 수 있지만, 자료가 희박한 꼬리에서는 스플라인의 기울기가 장기 예측을 과도하게 지배할 수 있다. 따라서 자유도 선택, 경계 절점, 장기 위험의 방향과 외부 타당성을 함께 검토해야 한다.

9.2.11 Piecewise exponential 모형

시간축을 \(0=\tau_0<\tau_1<\cdots<\tau_K\)로 분할하고 각 구간에서 위험률이 일정하다고 가정하면

\[ h(t)=\lambda_k, \qquad \tau_{k-1}<t\le \tau_k. \]

누적위험함수는 구간별 위험을 합산하여 계산한다.

\[ H(t) = \sum_{j<k}\lambda_j(\tau_j-\tau_{j-1}) +\lambda_k(t-\tau_{k-1}). \]

이 모형은 관찰구간의 위험 변화는 유연하게 표현하지만 마지막 구간 이후 어떤 위험률을 유지할지 별도의 외삽 가정이 필요하다. 마지막 구간 위험을 무기한 유지하면 절점 위치와 마지막 사건 수에 결과가 매우 민감해질 수 있다.

9.2.12 Cure 모형

일부 환자가 장기적으로 질병 관련 사건을 더 이상 경험하지 않는다고 가정할 수 있는 상황에서는 cure 모형을 고려한다. 혼합 cure 모형은 모집단을 장기 생존군과 비장기 생존군의 혼합으로 표현한다.

\[ S(t)=\pi+(1-\pi)S_u(t), \]

여기서 \(\pi\)는 cure fraction이고 \(S_u(t)\)는 비장기 생존군의 생존함수이다. \(t\to\infty\)일 때 \(S_u(t)\to0\)이면 질병 관련 생존함수는 \(\pi\)에 접근한다. 전체 사망을 모형화할 때에는 배경 사망률을 결합해야 하므로 총 생존함수가 양의 상수에 수렴한다고 해석해서는 안 된다.

비혼합 cure 모형의 대표적인 promotion-time 표현은 잠재 사건 수를 나타내는 모수 \(\theta>0\)와 비장기 생존 성분의 누적분포함수 \(F_u(t)\)를 이용한다.

\[ S(t)=\exp\{-\theta F_u(t)\}. \]

\(F_u(t)\to1\)이면 장기 생존비율은 \(\exp(-\theta)\)에 수렴한다. cure fraction은 충분히 긴 추적과 생물학적 근거가 없으면 자료에서 약하게 식별될 수 있다. 관찰기간 중 생존곡선의 plateau가 보인다는 이유만으로 cure를 확정하지 말고, number at risk, 후속치료, 배경 사망률과 외부 장기자료를 함께 확인해야 한다.

9.3 비례위험모형과 가속고장 시간모형

9.3.1 비례위험모형

비례위험(proportional hazards, PH) 모형은 공변량이 위험함수에 곱셈적으로 작용한다고 가정한다. 공변량 벡터를 \(x\)라고 하면 다음과 같이 쓸 수 있다.

\[ h(t\mid x)=h_0(t)\exp(x^\top\beta). \]

여기서 \(h_0(t)\)는 기준 위험함수이고, \(\exp(\beta_r)\)는 공변량 \(x_r\)이 한 단위 증가할 때의 위험비이다. PH 모형의 생존함수는 다음과 같다.

\[ S(t\mid x)=S_0(t)^{\exp(x^\top\beta)}. \]

두 치료군을 비교할 때 치료군 지시변수 \(Z\)를 사용하면 다음과 같다.

\[ h(t\mid Z)=h_0(t)\exp(\beta Z). \]

위험비는 \(HR=\exp(\beta)\)이고 시간에 따라 일정하다고 가정한다. 따라서 장기 외삽에서는 관찰된 치료효과가 분석기간 내내 동일한 상대위험 감소로 지속된다고 가정하는 셈이다.

WarningPH 가정의 장기 외삽상 의미

PH 모형에서 위험비가 일정하다는 것은 관찰기간 이후에도 치료효과가 동일한 비율로 유지된다는 강한 가정이다. 면역항암제, 세포치료제, 만성질환 치료제처럼 치료효과가 시간에 따라 변할 가능성이 있는 경우에는 시간의존 위험비, 치료효과 소실, cure 모형 등을 시나리오로 검토해야 한다.

9.3.2 가속고장 시간모형

가속고장시간(accelerated failure time, AFT) 모형은 공변량이 생존시간의 시간축을 늘리거나 줄인다고 해석한다. 일반적으로 다음과 같이 쓴다.

\[ \log T = \alpha+x^\top\beta+\sigma\varepsilon, \]

여기서 \(\varepsilon\)의 분포 선택에 따라 Weibull, log-normal, log-logistic AFT 모형이 된다. 치료군 지시변수 \(Z\)의 계수가 \(\beta\)라면 시간비(time ratio)는 다음과 같다.

\[ TR=\exp(\beta). \]

\(TR>1\)이면 생존시간이 늘어나는 방향의 치료효과를 의미한다. AFT 모형에서 생존함수는 다음과 같이 표현할 수 있다.

\[ S(t\mid x)=S_0\{t\exp(-x^\top\beta)\}. \]

즉, 공변량은 생존곡선의 시간축을 이동시키는 역할을 한다.

이 그림에서 PH 모형은 같은 시점의 순간위험을 일정한 배율로 조정하는 반면, AFT 모형은 전체 생존시간 축을 늘리거나 줄인다. 두 모형이 관찰구간에서 비슷한 적합도를 보이더라도 장기 치료효과의 유지 방식은 서로 다르다.

9.3.3 Weibull 모형에서 PH와 AFT의 연결

Weibull 모형은 PH 모형과 AFT 모형으로 모두 표현될 수 있는 특수한 분포이다. AFT 표현에서

\[ \log T=\alpha+\beta Z+\sigma\varepsilon \]

라고 하면 shape 모수는 \(k=1/\sigma\)로 연결된다. 이때 치료군의 시간비는 \(TR=\exp(\beta)\)이고, 대응되는 위험비는 다음과 같다.

\[ HR=\exp(-k\beta)=TR^{-k}. \]

따라서 AFT 계수 \(\beta\)가 양수이면 생존시간이 늘어나고, 대응되는 위험비는 1보다 작다.

9.3.5 비례위험 가정이 성립하지 않는 경우

치료효과가 시간에 따라 변하면 위험비를 \(HR(t)=\exp\{\beta(t)\}\)로 표현할 수 있다.

\[ h_1(t)=h_0(t)\exp\{\beta(t)\}. \]

이때 단일 Cox 위험비는 추적기간과 사건 발생 분포에 따라 가중된 평균에 가까우며, 장기 외삽에 그대로 적용할 고정된 생물학적 상수로 해석할 수 없다. 시간가변 계수는 스플라인이나 구간별 계수로 모형화할 수 있다.

\[ \beta(t)=\sum_{k=1}^{K}\alpha_k B_k\{\log(t)\}. \]

교차하는 생존곡선이나 지연 치료효과가 존재할 때에는 치료군별 생존함수를 직접 추정한 후 목표 모집단에 표준화하는 접근이 위험비 중심 접근보다 해석에 유리할 수 있다.

\[ S_j^{pop}(t) = \frac{1}{n}\sum_{i=1}^{n}\widehat S(t\mid Z=j,X_i). \]

이 주변 생존함수는 치료군별 기대 생존기간과 QALY 계산에 직접 사용할 수 있으며, 조건부 위험비의 비축약성 문제를 피할 수 있다.

9.4 모델링 방법

9.4.1 생존외삽의 기본 절차

생존외삽은 다음의 순서로 진행하는 것이 바람직하다.

  1. 자료 구조를 확인한다. 추적기간, 사건 수, 중도절단 비율, number at risk, 교차투여, 후속치료를 점검한다.
  2. Kaplan-Meier 곡선을 작성하고 각 치료군의 관찰구간 생존 패턴을 확인한다.
  3. 임상적으로 가능한 위험함수 형태를 논의한다.
  4. 후보 모수적 모형을 사전에 정의한다.
  5. 독립 적합과 공동 적합의 적절성을 검토한다.
  6. 관찰구간 내 적합도와 장기 외삽 타당성을 각각 평가한다.
  7. 기본분석 모형을 선택하고 대안 모형을 시나리오 분석으로 제시한다.
  8. 모수 불확실성을 PSA에 반영한다.
  9. 외삽 선택이 ICER에 미치는 영향을 보고한다.

9.4.2 독립 적합과 공동 적합

두 치료군의 생존곡선을 외삽할 때는 크게 독립 적합과 공동 적합을 고려할 수 있다.

독립 적합은 각 치료군에 별도의 생존분포를 적합하는 방법이다.

\[ S_0(t)=S(t;\theta_0), \qquad S_1(t)=S(t;\theta_1). \]

공동 적합은 하나의 모형 안에 치료군 지시변수를 포함하여 두 군의 생존곡선을 동시에 추정하는 방법이다.

\[ h(t\mid Z)=h_0(t;\theta)\exp(\beta Z). \]

또는 AFT 형태로 다음과 같이 쓸 수 있다.

\[ \log T = \alpha+\beta Z+\sigma\varepsilon. \]

독립 적합은 두 군의 생존곡선 형태가 다를 수 있음을 허용하지만, 표본 수가 작거나 사건 수가 부족할 때 불안정할 수 있다. 공동 적합은 효율성이 높고 치료효과를 직접 추정하지만, PH 또는 AFT 같은 구조적 가정을 부여한다.

독립 적합과 공동 적합 사이에는 일부 모수만 공유하는 부분공유 모형도 가능하다. 예를 들어 두 군이 공통 shape 모수를 가지되 scale 모수는 다르게 둘 수 있다.

\[ S_j(t)=\exp\left[-\left\{\frac{t}{\lambda_j}\right\}^{k}\right], \qquad j\in\{0,1\}. \]

이 접근은 완전 독립 적합보다 안정적이고, 완전 공동 PH 모형보다 유연하다. 어떤 모수를 공유할지는 임상적 기전과 관찰된 위험함수 형태를 근거로 결정해야 하며, 공유 여부 자체도 구조적 불확실성으로 평가해야 한다.

독립 적합은 각 군의 꼬리 형태를 자유롭게 허용하지만 두 군의 모수 불확실성이 별도로 추정되고 장기 곡선이 비현실적으로 교차할 수 있다. 공동 적합은 정보를 공유하여 안정성을 높이지만, 공통 shape나 일정한 치료효과와 같은 제약이 틀리면 두 군 모두에 구조적 편향이 생길 수 있다.

9.4.3 치료효과 유지, 감소, 소실 가정

장기 외삽에서 가장 민감한 요소 중 하나는 관찰기간 이후 치료효과가 어떻게 변하는가이다. 관찰기간의 위험비가 0.70이라고 해서 이 효과가 평생 지속된다고 자동으로 가정할 수는 없다.

대표적인 가정은 다음과 같다.

가정 시간의존 위험비 예 해석
치료효과 유지 \(HR(t)=HR_0\) 관찰된 상대효과가 장기까지 동일하게 유지
점진적 감소 \(HR(t)=1-(1-HR_0)\exp\{-\rho(t-t_w)_+\}\) 특정 시점 이후 효과가 서서히 1로 접근
효과 소실 \(HR(t)=HR_0\) for \(t<t_w\), \(HR(t)=1\) for \(t\ge t_w\) 일정 시점 이후 치료효과가 없어짐
지연 효과 \(HR(t)\)가 초기에는 1에 가깝고 이후 감소 면역항암제 등에서 가능

여기서 \((a)_+=\max(a,0)\)이다. 치료효과 감소율 \(\rho\)와 감소 시작 시점 \(t_w\)는 자료만으로 안정적으로 추정하기 어려운 경우가 많다. 따라서 임상 전문가 의견, 장기 추적자료, 유사 약제 자료, 생물학적 치료기전을 함께 고려해야 한다.

점진적 감소 가정에서 치료군 위험함수는 기준군 위험함수와 시간가변 위험비의 곱으로 구성된다.

\[ h_1(t)=h_0(t)HR(t). \]

따라서 치료군 생존함수는 단순히 기준군 생존함수를 고정된 거듭제곱으로 변환할 수 없으며 다음과 같이 다시 적분해야 한다.

\[ S_1(t) = \exp\left[-\int_0^t h_0(u)HR(u)\,du\right]. \]

효과 소실 시점에서 위험함수를 갑자기 1로 전환하면 위험함수는 불연속일 수 있으나 생존함수는 연속이어야 한다. 구현에서는 소실 시점 직전까지의 누적위험을 보존한 채 이후 기준위험을 누적해야 한다.

이 그림은 관찰기간 이후 동일한 생존자료가 서로 다른 치료효과 지속 가정으로 연결될 수 있음을 보여준다. 효과감소 시작시점과 감소속도는 대개 시험자료에서 직접 식별되지 않으므로, 해당 가정은 추정 결과라기보다 명시적인 의사결정 시나리오로 다루어야 한다.

9.4.4 배경 사망률의 반영

전체생존기간을 외삽할 때 장기 생존곡선은 일반 인구 사망률보다 더 낙관적이어서는 안 된다. 일반 인구 배경 사망위험을 \(h_{bg}(t)\), 질병 관련 초과위험을 \(h_{excess}(t)\)라고 하면 총 사망위험을 다음과 같이 표현할 수 있다.

\[ h_{total}(t)=h_{bg}(t)+h_{excess}(t). \]

독립적인 위험요인으로 해석하면 생존함수는 다음과 같이 분해된다.

\[ S_{total}(t)=S_{bg}(t)S_{excess}(t). \]

외삽된 OS 위험함수가 장기적으로 일반 인구 사망위험보다 낮아지는 경우는 임상적으로 부적절할 수 있다. 특히 고령 환자군에서 평생 분석을 수행할 때는 연령, 성별, 국가별 생명표를 이용하여 배경 사망률을 반영해야 한다.

그림의 총 사망위험은 질병 관련 초과위험과 배경 사망위험을 합한 값이다. 시간이 지나 질병 관련 초과위험이 감소하더라도 연령 증가에 따라 배경 사망위험은 커지므로, 전체 사망위험이 장기적으로 0에 접근하는 외삽은 일반적으로 타당하지 않다.

Warning배경 사망률 점검

외삽된 총 사망위험이 동일 연령·성별 일반 인구 사망위험보다 낮다면, 해당 모형은 장기적으로 비현실적인 생존을 예측할 수 있다. 이는 특히 log-normal, log-logistic, cure 모형의 꼬리 영역에서 중요하다.

9.4.5 상대생존과 초과위험 모형

사망원인이 정확히 구분되지 않더라도 일반 인구 생명표를 이용하면 상대생존 접근으로 질병 관련 초과위험을 모형화할 수 있다. 진단 시 연령을 \(a_0\), 진단 후 시간을 \(t\)라고 하면 배경위험은 달력시간과 도달연령 \(a_0+t\)에 따라 달라진다.

\[ h_{all}(t\mid x) = h_{pop}(a_0+t,\text{sex},\text{calendar year}) +h_{excess}(t\mid x). \]

이에 대응하는 생존함수는

\[ S_{all}(t\mid x) = S_{pop}(t\mid x)S_{relative}(t\mid x) \]

로 분해된다. 배경위험을 초기 연령의 고정값으로 두면 고령화에 따른 사망위험 증가를 놓치므로, 외삽 시점마다 도달연령과 달력연도를 갱신해야 한다. 또한 임상시험 모집단의 건강상태가 일반 인구와 다르면 생명표 사망률을 그대로 적용하는 것 자체가 추가 가정이 된다.

9.5 적합된 모수적 모형과 외삽의 적절성을 평가하는 방법

9.5.1 관찰기간 내 적합도

모형 적합도는 우도 기반 지표와 시각적 검토를 함께 사용한다. 모형 \(m\)의 최대 로그우도를 \(\ell_m\), 추정 모수 수를 \(p_m\), 표본 수를 \(n\)이라고 하면 Akaike information criterion(AIC)와 Bayesian information criterion(BIC)는 다음과 같다.

\[ AIC_m=-2\ell_m+2p_m, \]

\[ BIC_m=-2\ell_m+p_m\log n. \]

값이 작을수록 관찰자료에 대한 상대적 적합도가 좋다고 해석한다. 그러나 AIC와 BIC는 관찰구간 안에서의 상대적 적합도를 요약할 뿐이며, 장기 외삽이 타당하다는 것을 보장하지 않는다.

AIC는 후보 모형의 예측분포와 실제 자료생성분포 사이의 Kullback–Leibler 정보손실을 근사적으로 최소화하는 관점에 가깝고, BIC는 정규성·큰 표본 조건에서 모형의 주변가능도에 대한 근사를 제공한다. 두 기준 모두 관찰된 시간범위의 우도에 기반하므로, 관찰되지 않은 꼬리에 대한 직접적인 점수는 포함하지 않는다. 후보 모형이 모두 잘못 지정되어 있을 때는 가장 작은 정보기준이 절대적 타당성을 의미하지도 않는다.

관찰기간 내 적합도 평가에는 다음을 포함하는 것이 좋다.

  • Kaplan-Meier 곡선과 적합된 생존곡선의 중첩 그림
  • 누적위험 또는 log-cumulative hazard 그림
  • Cox-Snell 잔차 또는 quantile-quantile plot
  • 각 치료군의 number at risk와 censoring pattern
  • 사건 수가 충분한 구간과 부족한 구간의 구분

9.5.2 AIC와 BIC의 한계

AIC나 BIC가 가장 낮은 모형이 항상 기본분석 모형이 되어야 하는 것은 아니다. 장기 외삽에서는 관찰구간의 작은 차이가 분석기간 전체에서 큰 차이로 확대될 수 있다. 특히 관찰구간에서 여러 모형이 거의 같은 적합도를 보이는 경우, 외삽구간에서의 생존곡선은 크게 벌어질 수 있다.

이 그림에서 관찰구간 안의 곡선들은 거의 겹치지만, 관찰종료 이후의 기울기와 꼬리 감소속도는 크게 다르다. 이는 관찰구간 적합도만으로 장기 모형을 순위화하기 어려운 이유이며, 외부시점 생존율과 위험률에 대한 제약이 별도로 필요함을 보여준다.

따라서 AIC/BIC는 모형 선택의 출발점이지 최종 판단 기준이 아니다. 경제성 평가에서는 “통계적으로 가장 잘 맞는 모형”보다 “의사결정에 사용할 장기 예측으로 가장 타당한 모형”이 중요하다.

9.5.3 외삽 타당성 평가

외삽 타당성은 다음의 질문을 통해 검토한다.

  1. 장기 생존율이 질병 자연사와 부합하는가?
  2. 외삽된 생존곡선이 외부 장기자료 또는 등록자료와 유사한가?
  3. 위험함수 형태가 치료기전과 임상 경험에 부합하는가?
  4. 일반 인구 사망률보다 비현실적으로 낮은 사망위험을 예측하지 않는가?
  5. 장기 생존 꼬리가 QALY와 ICER에 얼마나 큰 영향을 주는가?
  6. 관찰기간 말미의 number at risk가 너무 적어 꼬리 추정이 불안정하지 않은가?
  7. 치료효과 유지 가정이 임상적으로 정당화되는가?

9.5.4 위험함수 기반 평가

생존곡선만 보면 장기 외삽의 문제를 놓칠 수 있다. 생존곡선은 누적된 결과이기 때문에 여러 위험함수 형태가 비슷한 생존곡선을 만들 수 있다. 반면 위험함수는 시간에 따른 사건위험의 변화를 직접 보여준다.

예를 들어 다음과 같은 위험함수 형태는 서로 다른 임상적 의미를 가진다.

위험함수 형태 가능한 임상적 해석
일정 시간에 따라 사건위험이 변하지 않음
단조 증가 시간이 지날수록 질병 악화 또는 노화 효과가 증가
단조 감소 초기 고위험군에서 사건이 집중되고 이후 안정화
초기 증가 후 감소 치료 초기 취약기간 이후 장기 생존자군 형성 가능
장기적으로 일반 인구 위험에 접근 질병 관련 초과위험이 감소

경제성 평가 보고서에서는 후보 모형의 생존곡선뿐 아니라 위험함수를 함께 제시하는 것이 바람직하다.

9.5.5 외부자료와 전문가 판단

외부자료는 장기 외삽 타당성을 평가하는 중요한 근거이다. 사용할 수 있는 자료원은 다음과 같다.

  • 동일 질환의 장기 추적 임상시험
  • 확장 추적 연구
  • 질병 등록자료
  • 실제임상자료(real-world data)
  • 기존 치료제의 장기 생존자료
  • 건강보험 청구자료
  • 일반 인구 생명표
  • 임상 전문가의 구조화된 판단

외부자료가 임상시험 모집단과 다를 수 있으므로 단순 비교는 위험하다. 연령, 성별, 질병 단계, 이전 치료, 바이오마커, 치료선, 사망 원인, 후속치료 차이를 함께 검토해야 한다.

9.5.6 외부자료를 이용한 보정

외부자료가 특정 시점 \(t_k\)의 생존율 \(S_k^{ext}\)와 불확실성 \(v_k\)를 제공한다면, 임상시험 우도와 외부자료 적합도를 결합한 목적함수를 사용할 수 있다.

\[ \ell_{joint}(\theta) = \ell_{trial}(\theta) - \frac{1}{2}\sum_{k=1}^{K} \frac{\{g[S(t_k;\theta)]-g(S_k^{ext})\}^2}{v_k}, \]

여기서 \(g(\cdot)\)는 logit 또는 complementary log-log 변환이다. 이 방식은 외부자료를 정확한 상수로 강제하지 않고 그 불확실성에 비례하여 가중한다. 베이지안 접근에서는 외부 생존율, 장기 위험률 또는 cure fraction에 대한 사전분포를 설정할 수 있다.

외부자료를 결합하기 전에는 목표 모집단과 사건정의의 교환가능성을 검토해야 한다. 교환가능성이 약하면 직접 통합보다 외적 타당성 확인이나 시나리오 범위 설정에 사용하는 편이 안전하다.

9.5.7 시간 분할 검증과 장기 예측성

추적자료가 충분하다면 초기 구간만 사용하여 모형을 적합하고 이후 관찰구간을 예측하는 시간 분할 검증을 수행할 수 있다. 절단시점 \(c\) 이전 자료로 적합한 모형의 예측 생존율 \(\widehat S_c(t)\)를 실제 후속 Kaplan–Meier 추정량과 비교한다.

\[ E_c(t)=\widehat S_c(t)-\widehat S_{KM}(t), \qquad t>c. \]

이 검증도 평생 꼬리를 직접 검증하지는 못하지만, 후보 모형이 관찰되지 않은 미래를 예측하는 상대적 능력을 평가한다는 점에서 전체 자료에 대한 AIC 비교보다 외삽 목적에 더 가까운 정보를 제공한다.

9.6 모형 선택 알고리즘

9.6.1 모형 선택의 원칙

생존외삽 모형 선택은 다음 원칙을 따른다.

  1. 사전에 후보 모형과 선택 기준을 정의한다.
  2. 관찰구간 적합도와 외삽 타당성을 분리하여 평가한다.
  3. 단순한 모형과 복잡한 모형을 모두 검토한다.
  4. 치료효과 유지 가정을 명시적으로 보고한다.
  5. 기본분석 모형 선택 이유를 통계적·임상적으로 설명한다.
  6. 대안적으로 타당한 모형은 시나리오 분석에 포함한다.
  7. 모수 불확실성과 모형 불확실성을 구분하여 보고한다.

이 알고리즘은 정보기준만으로 자동 선택하는 절차가 아니라 통계적 적합도, 위험함수의 임상적 의미, 외부 근거와 경제성 결과의 민감도를 순차적으로 통합하는 판단 구조이다. 어느 단계에서 후보 모형을 제외했는지와 그 근거를 기록해야 선택과정의 재현성이 확보된다.

9.6.2 기본분석과 시나리오 분석

기본분석(base-case)에 사용할 모형은 의사결정자의 관점에서 가장 타당한 장기 예측을 제공해야 한다. 그러나 외삽모형 선택에는 구조적 불확실성이 크므로, 다음과 같은 시나리오를 함께 제시하는 것이 일반적이다.

  • 다른 모수적 분포 사용
  • 독립 적합 대신 공동 적합 사용
  • PH 대신 AFT 가정 사용
  • 치료효과 점진적 감소 또는 소실 가정
  • 일반 인구 사망률 반영 방식 변경
  • 외부자료를 이용한 보정 또는 제한
  • 장기 cure fraction 가정 사용 여부 변경

모형 간 ICER가 크게 달라진다면, 단일 기본분석 결과보다 외삽 불확실성 자체가 의사결정의 핵심이 된다. 이 경우 추가 자료 수집의 가치, 조건부 급여, 위험분담제와 같은 의사결정 대안을 함께 논의할 필요가 있다.

9.6.3 모형 불확실성과 모형 평균화

하나의 분포를 확정적으로 선택하기 어려울 때는 후보 모형 \(m=1,\ldots,M\)에 가중치 \(w_m\)을 부여하여 생존함수 또는 순편익을 평균할 수 있다.

\[ S_{MA}(t)=\sum_{m=1}^{M}w_mS_m(t), \qquad \sum_{m=1}^{M}w_m=1. \]

AIC 기반 가중치는 다음과 같이 계산할 수 있다.

\[ w_m = \frac{\exp(-\Delta_m/2)} {\sum_{r=1}^{M}\exp(-\Delta_r/2)}, \qquad \Delta_m=AIC_m-\min_r AIC_r. \]

그러나 이 가중치도 관찰구간 적합도만 반영한다. 임상적 개연성과 외부자료를 반영하려면 전문가 사전확률이나 베이지안 모형확률을 사용할 수 있다. 모형 평균화의 전체 분산은 모형 내부 모수분산과 모형 간 평균 차이를 모두 포함한다.

\[ \operatorname{Var}(Y) = \sum_m w_m\operatorname{Var}(Y\mid m) + \sum_m w_m\{\mathbb{E}(Y\mid m)-\mathbb{E}(Y)\}^2. \]

PSA에서 모형을 고정한 채 모수만 추출하면 두 번째 항이 누락된다. 후보 모형 자체를 확률적으로 추출하거나, 각 모형별 PSA 결과를 가중 결합해야 구조적 불확실성을 반영할 수 있다.

9.7 생존함수를 이용하여 마코프모델에 사용할 전이확률의 추정

9.7.1 생존함수와 조건부 전이확률

마코프모형에서는 주기별 전이확률이 필요하다. 생존함수 \(S(t)\)가 주어졌을 때, 시간 \(t\)까지 사건이 발생하지 않은 사람이 다음 주기 \([t,t+\Delta)\) 동안 사건을 경험할 조건부 확률은 다음과 같다.

\[ p(t,t+\Delta)=P(t\le T<t+\Delta\mid T\ge t). \]

생존함수를 이용하면 다음과 같이 계산된다.

\[ p(t,t+\Delta)=1-\frac{S(t+\Delta)}{S(t)}. \]

이 식은 생존함수에서 마코프 전이확률을 계산하는 핵심 공식이다.

그림에서 주기별 전이확률은 생존곡선의 절대 감소량이 아니라, 주기 시작 시점까지 사건 없이 남아 있는 사람을 분모로 한 조건부 감소율이다. 따라서 같은 생존확률 감소량이라도 위험집합의 크기에 따라 전이확률은 달라진다.

9.7.2 일정 위험률 가정의 특수한 경우

위험률이 주기 안에서 일정하게 \(r\)이라고 가정하면 생존함수는 다음과 같다.

\[ S(t)=\exp(-rt). \]

따라서 주기 길이 \(\Delta\)의 전이확률은 다음과 같다.

\[ p=1-\exp(-r\Delta). \]

이는 발생률 또는 위험률을 전이확률로 변환할 때 가장 자주 사용되는 식이다. 그러나 위험률이 시간에 따라 변하면 \(r\)을 단순히 전체 기간 평균값으로 사용하는 것은 부정확할 수 있다.

9.7.3 시간의존 전이확률

위험함수가 시간에 따라 변하는 경우 \([t,t+\Delta)\) 구간의 조건부 사건확률은 다음과 같다.

\[ p(t,t+\Delta)=1-\exp\left\{-\int_t^{t+\Delta}h(u)\,du\right\}. \]

누적위험함수 \(H(t)\)를 이용하면 다음과 같이 쓸 수 있다.

\[ p(t,t+\Delta)=1-\exp[-\{H(t+\Delta)-H(t)\}]. \]

이 식은 Weibull, Gompertz, log-normal, log-logistic 등 모든 모수적 생존모형에 적용할 수 있다. 예를 들어 Weibull 모형에서

\[ H(t)=\left(\frac{t}{\lambda}\right)^k \]

이므로 전이확률은 다음과 같다.

\[ p(t,t+\Delta)=1-\exp\left[-\left\{\left(\frac{t+\Delta}{\lambda}\right)^k-\left(\frac{t}{\lambda}\right)^k\right\}\right]. \]

9.7.4 경쟁위험이 있는 경우

하나의 상태에서 여러 사건으로 전이할 수 있다면 원인별 위험함수(cause-specific hazard)를 사용해야 한다. 예를 들어 무진행 상태에서 진행 또는 사망으로 전이할 수 있다면 각각의 위험함수를 \(h_P(t)\)와 \(h_D(t)\)라고 하자. 총 위험함수는 다음과 같다.

\[ h_{total}(t)=h_P(t)+h_D(t). \]

구간 \([t,t+\Delta)\)에서 사건 \(r\)로 전이할 확률은 다음과 같다.

\[ p_r(t,t+\Delta)=\int_t^{t+\Delta}\frac{S(u)}{S(t)}h_r(u)\,du, \]

여기서 \(S(u)/S(t)\)는 시간 \(t\)까지 생존한 조건에서 \(u\)까지 어떤 사건도 발생하지 않을 조건부 생존확률이다. 구간 안에서 원인별 위험함수가 일정하다고 가정하면 다음과 같이 근사할 수 있다.

\[ p_r(t,t+\Delta)=\frac{h_r}{h_{total}}\left\{1-\exp(-h_{total}\Delta)\right\}. \]

위 식은 구간 내 위험률이 일정할 때는 근사가 아니라 정확한 식이다. 각 원인별 사건확률의 합과 무사건확률은 다음 조건을 만족한다.

\[ \sum_r p_r(t,t+\Delta) + \exp(-h_{total}\Delta) =1. \]

원인별 위험을 각각 단순히 \(1-\exp(-h_r\Delta)\)로 변환하면 동일한 주기 안에서 여러 사건이 독립적으로 발생할 수 있는 것처럼 계산되어 확률의 합이 1을 초과할 수 있다.

9.7.5 다상태모형의 생성행렬

여러 상태 사이의 전이를 동시에 다룰 때는 전이강도행렬 \(Q(t)\)를 사용한다. 비대각 원소 \(q_{rs}(t)\)는 상태 \(r\)에서 \(s\)로의 순간 전이강도이고, 대각 원소는 행의 합이 0이 되도록 정의한다.

\[ q_{rr}(t)=-\sum_{s\ne r}q_{rs}(t). \]

시간동질 모형에서 길이 \(\Delta\)의 전이확률행렬은 행렬지수로 계산한다.

\[ P(\Delta)=\exp\{Q\Delta\}. \]

시간비동질 모형에서는 각 주기별 생성행렬을 이용하거나 곱적분을 계산해야 한다. 이 접근은 여러 경쟁 전이가 존재할 때 각 전이확률을 개별적으로 변환하는 것보다 확률 일관성을 보장한다.

9.7.6 PFS와 OS를 이용한 분할생존모형의 상태 점유율

분할생존모형(partitioned survival model)에서는 PFS와 OS 생존함수를 이용하여 세 상태의 점유율을 계산한다. 무진행 상태, 진행 후 생존 상태, 사망 상태를 각각 PF, PD, Dead라고 하면 다음과 같다.

\[ P_{PF}(t)=S_{PFS}(t), \]

\[ P_{Dead}(t)=1-S_{OS}(t), \]

\[ P_{PD}(t)=S_{OS}(t)-S_{PFS}(t). \]

이 식이 성립하려면 모든 시점에서 다음 조건이 필요하다.

\[ S_{OS}(t)\ge S_{PFS}(t). \]

만약 독립적으로 적합한 PFS와 OS 외삽곡선이 장기에서 교차한다면 상태 점유율이 음수가 되는 문제가 발생한다. 따라서 PFS와 OS 외삽은 개별 곡선의 적합도뿐 아니라 두 곡선 사이의 논리적 일관성도 확인해야 한다.

분할생존모형은 시점별 상태점유율을 결정하지만 개별 환자의 진행 후 사망 경로를 명시적으로 생성하지 않는다. 따라서 PFS와 OS의 주변분포만으로는 진행시점과 사망시점의 결합분포가 식별되지 않는다. 동일한 \(S_{PFS}(t)\)와 \(S_{OS}(t)\)를 가지더라도 진행 후 생존기간의 분포는 서로 다를 수 있다.

경제성 결과가 진행 후 비용이나 효용의 지속기간에 민감하면, 다음의 질량보존 조건뿐 아니라 진행 후 생존에 대한 외부근거를 확인해야 한다.

\[ P_{PF}(t)+P_{PD}(t)+P_{Dead}(t)=1. \]

PFS와 OS를 PSA에서 독립적으로 추출하면 곡선 교차와 상태점유율의 음수 문제가 반복될 수 있다. 임상시험에서 공동 추정된 모수 공분산을 이용하거나, 논리적 제약을 만족하는 공동 다상태모형으로부터 두 곡선을 생성하는 방법이 더 타당하다.

이 그림에서 PFS 곡선 아래 영역은 무진행 상태, OS와 PFS 사이의 영역은 진행 후 생존 상태, OS 위쪽 영역은 사망 상태에 해당한다. 두 생존곡선을 독립적으로 외삽하면 장기에서 PFS가 OS보다 높아지는 논리적 모순이 생길 수 있으므로 공동 제약이 필요하다.

9.8 실무 예제: 생존외삽 결과가 ICER에 미치는 영향

생존외삽 모형 선택은 기대 생존기간과 QALY를 바꾸고, 이는 ICER에 직접적인 영향을 준다. 예를 들어 신약이 기존 치료보다 관찰기간 안에서는 유사한 생존편익을 보이지만, log-logistic 모형이 장기 꼬리를 크게 예측하면 증분 QALY가 커져 ICER가 낮아질 수 있다. 반대로 치료효과 소실 가정을 적용하면 증분 QALY가 줄어 ICER가 높아질 수 있다.

증분비용을 \(\Delta C\), 증분 QALY를 \(\Delta Q\)라고 하면 ICER는 다음과 같다.

\[ ICER=\frac{\Delta C}{\Delta Q}. \]

여기서 \(\Delta Q\)는 외삽된 생존함수에 크게 의존한다.

\[ \Delta Q= \int_0^\tau \{u_1(t)S_1(t)-u_0(t)S_0(t)\}\,dt. \]

따라서 생존외삽 모형의 차이가 작아 보이더라도 분석기간 전체의 면적 차이는 크게 누적될 수 있다.

증분 QALY를 관찰구간과 외삽구간으로 분해하면 결과가 어느 부분에서 발생하는지 확인할 수 있다.

\[ \Delta Q = \underbrace{\int_0^{t_{\max}} \{u_1(t)S_1(t)-u_0(t)S_0(t)\}\,dt}_{\Delta Q_{obs}} + \underbrace{\int_{t_{\max}}^{\tau} \{u_1(t)S_1(t)-u_0(t)S_0(t)\}\,dt}_{\Delta Q_{ext}}. \]

\(\Delta Q_{ext}\)가 전체 증분 QALY의 대부분을 차지한다면 비용효과성 결론은 관찰된 임상효과보다 외삽 가정에 더 의존한다. 이 경우 모형별 \(\Delta Q_{obs}\)와 \(\Delta Q_{ext}\)를 별도로 보고하면 의사결정자가 근거의 위치를 명확히 파악할 수 있다.

9.8.1 모수 불확실성의 전파

각 생존모형의 모수벡터를 \(\theta\)라고 하면 기대 QALY는 \(Q(\theta)\)라는 비선형 함수이다. 델타방법에 의한 근사분산은 다음과 같다.

\[ \operatorname{Var}\{Q(\widehat\theta)\} \approx \nabla Q(\widehat\theta)^\top \operatorname{Var}(\widehat\theta) \nabla Q(\widehat\theta). \]

실제 PSA에서는 \(\theta^{(b)}\)를 다변량 정규근사, 부트스트랩 또는 베이지안 사후분포에서 공동 추출한 뒤 각 반복에서 생존곡선과 QALY를 다시 계산한다. shape와 scale 모수의 상관성을 무시한 독립 추출은 장기 꼬리의 불확실성을 과대 또는 과소평가할 수 있다.

이 그림은 외삽모형이 증분비용을 직접 바꾸지 않더라도 증분 QALY의 분모를 변화시켜 ICER를 크게 이동시킬 수 있음을 보여준다. 특히 증분 QALY가 작을 때에는 꼬리 영역의 작은 차이가 비율척도에서 크게 증폭된다.

km_estimate <- function(time, status) {
  event_times <- sort(unique(time[status == 1]))
  n_risk <- sapply(event_times, function(tt) sum(time >= tt))
  n_event <- sapply(event_times, function(tt) sum(time == tt & status == 1))
  survival <- cumprod(1 - n_event / n_risk)
  data.frame(
    time = c(0, event_times),
    survival = c(1, survival),
    n_risk = c(length(time), n_risk),
    n_event = c(0, n_event)
  )
}

fit_exponential <- function(time, status) {
  rate <- sum(status) / sum(time)
  loglik <- sum(status * log(rate) - rate * time)
  list(dist = "Exponential", par = c(rate = rate), logLik = loglik, npar = 1)
}

fit_weibull <- function(time, status) {
  nll <- function(lp) {
    k <- exp(lp[1])
    lambda <- exp(lp[2])
    log_h <- log(k) - log(lambda) + (k - 1) * (log(time) - log(lambda))
    H <- (time / lambda)^k
    -sum(status * log_h - H)
  }
  opt <- optim(c(log(1), log(median(time))), nll, method = "BFGS")
  k <- exp(opt$par[1])
  lambda <- exp(opt$par[2])
  list(dist = "Weibull", par = c(shape = k, scale = lambda), logLik = -opt$value, npar = 2)
}

fit_lognormal <- function(time, status) {
  nll <- function(par) {
    mu <- par[1]
    sigma <- exp(par[2])
    z <- (log(time) - mu) / sigma
    log_f <- dnorm(z, log = TRUE) - log(time) - log(sigma)
    log_S <- pnorm(z, lower.tail = FALSE, log.p = TRUE)
    -sum(status * log_f + (1 - status) * log_S)
  }
  opt <- optim(c(mean(log(time)), log(sd(log(time)))), nll, method = "BFGS")
  list(dist = "Log-normal", par = c(mu = opt$par[1], sigma = exp(opt$par[2])), logLik = -opt$value, npar = 2)
}

fit_loglogistic <- function(time, status) {
  nll <- function(lp) {
    k <- exp(lp[1])
    lambda <- exp(lp[2])
    z <- exp(k * (log(time) - log(lambda)))
    log_S <- -log1p(z)
    log_f <- log(k) - log(lambda) + (k - 1) * (log(time) - log(lambda)) - 2 * log1p(z)
    -sum(status * log_f + (1 - status) * log_S)
  }
  opt <- optim(c(log(1.2), log(median(time))), nll, method = "BFGS")
  list(dist = "Log-logistic", par = c(shape = exp(opt$par[1]), scale = exp(opt$par[2])), logLik = -opt$value, npar = 2)
}

fit_all <- function(time, status) {
  fits <- list(
    fit_exponential(time, status),
    fit_weibull(time, status),
    fit_lognormal(time, status),
    fit_loglogistic(time, status)
  )
  out <- data.frame(
    dist = sapply(fits, `[[`, "dist"),
    logLik = sapply(fits, `[[`, "logLik"),
    npar = sapply(fits, `[[`, "npar")
  )
  out$AIC <- -2 * out$logLik + 2 * out$npar
  out$BIC <- -2 * out$logLik + out$npar * log(length(time))
  list(summary = out[order(out$AIC), ], fits = fits)
}

surv_fun <- function(fit, t) {
  p <- fit$par
  if (fit$dist == "Exponential") {
    exp(-p["rate"] * t)
  } else if (fit$dist == "Weibull") {
    exp(-(t / p["scale"])^p["shape"])
  } else if (fit$dist == "Log-normal") {
    pnorm((log(t) - p["mu"]) / p["sigma"], lower.tail = FALSE)
  } else if (fit$dist == "Log-logistic") {
    1 / (1 + (t / p["scale"])^p["shape"])
  } else {
    stop("Unknown distribution")
  }
}

rmst_numeric <- function(fit, tau = 120, step = 0.1) {
  grid <- seq(0.001, tau, by = step)
  s <- surv_fun(fit, grid)
  sum((s[-1] + s[-length(s)]) / 2) * step
}

## 경제성평가에서 사용하는 생존분석에서는 외삽이 필요하다

### 임상시험 추적기간과 경제성 평가 분석기간

확증적 임상시험에서 생존분석의 주된 목적은 제한된 추적기간 안에서 두 치료군의 생존 경험을 비교하는 것이다. 전체생존기간(overall survival, OS), 무진행생존기간(progression-free survival, PFS), 사건 없는 생존기간(event-free survival, EFS)을 평가변수로 사용한 임상시험에서는 Kaplan-Meier 곡선, 로그순위검정, Cox 비례위험모형이 주로 사용된다.

경제성 평가는 질문이 다르다. 경제성 평가는 한 치료전략을 선택했을 때 분석기간 동안 누적되는 비용과 건강효과를 추정한다. 생존기간이 건강효과의 핵심 요소라면 생존함수 아래 면적이 기대 생존기간과 QALY에 직접 연결된다. 생존시간을 $T$, 생존함수를 $S(t)=P(T>t)$, 분석기간을 $\tau$라고 하면 제한평균 생존기간은 다음과 같다.

$$
\operatorname{RMST}(\tau)=\mathbb{E}\{\min(T,\tau)\}=\int_0^\tau S(t)\,dt.
$$

시간 $t$에서의 효용가중치를 $u(t)$라고 하면 기대 QALY는 다음과 같이 쓸 수 있다.

$$
\mathbb{E}(Q)=\int_0^\tau u(t)S(t)\,dt.
$$

효용가중치가 시간에 따라 일정하게 $u$라면 다음과 같이 단순화된다.

$$
\mathbb{E}(Q)=u\int_0^\tau S(t)\,dt.
$$

문제는 임상시험 추적기간 $t_{\max}$가 분석기간 $\tau$보다 짧은 경우가 대부분이라는 점이다. 이 경우 $0$부터 $t_{\max}$까지의 면적은 관찰자료에 근거해 추정할 수 있지만, $t_{\max}$ 이후의 면적은 모형에 의해 예측해야 한다.

$$
\int_0^\tau S(t)\,dt
=
\int_0^{t_{\max}} S(t)\,dt
+
\int_{t_{\max}}^\tau S(t)\,dt.
$$

오른쪽 두 번째 항이 바로 외삽 영역이다.

외삽이 결과에 미치는 정도는 전체 기대 생존기간 중 관찰기간 이후 면적이 차지하는 비율로 나타낼 수 있다. 다음의 외삽 비중은 장기 결과가 자료보다 모형 가정에 얼마나 의존하는지를 보여주는 진단지표이다.

$$
R_{ext}(\tau)
=
\frac{\displaystyle\int_{t_{\max}}^\tau S(t)\,dt}
{\displaystyle\int_0^\tau S(t)\,dt}.
$$

$R_{ext}(\tau)$가 클수록 총 기대 생존기간의 많은 부분이 실제 관찰자료가 아니라 꼬리 분포 가정으로 결정된다. 두 치료전략의 비교에서는 전체 생존기간보다 **증분 생존편익의 외삽 의존도**가 더 중요할 수 있다.

$$
R_{ext}^{\Delta}(\tau)
=
\frac{\displaystyle\int_{t_{\max}}^\tau \{S_1(t)-S_0(t)\}\,dt}
{\displaystyle\int_0^\tau \{S_1(t)-S_0(t)\}\,dt}.
$$

분모가 0에 가까우면 이 비율은 불안정하므로, 실제 보고에서는 관찰구간과 외삽구간의 증분 생존기간을 각각 절대값으로 함께 제시하는 것이 바람직하다.

![관찰된 생존곡선과 외삽 영역](figures/ch09/fig-ch09-observed-extrapolated-area.png){fig-align="center" width="90%"}

이 그림에서 수직 경계의 왼쪽은 임상시험 자료가 생존곡선의 형태를 직접 제약하는 구간이고, 오른쪽은 선택한 분포와 치료효과 지속 가정이 결과를 지배하는 구간이다. 외삽곡선 사이의 작은 수직 차이도 긴 시간 동안 적분되면 기대 생존기간과 QALY에서 큰 차이로 누적될 수 있다.

::: {.callout-important title="외삽은 보간이 아니다"}
보간(interpolation)은 관찰된 자료점 사이의 값을 추정하는 문제이다. 외삽(extrapolation)은 관찰된 자료 범위를 넘어선 미래를 예측하는 문제이다. 경제성 평가에서 생존외삽은 관찰되지 않은 장기 생존, 장기 비용, 장기 QALY, ICER를 결정하므로 단순한 기술적 절차가 아니라 핵심 의사결정 요소이다.
:::

### Kaplan-Meier 곡선만으로는 충분하지 않은 이유

Kaplan-Meier 추정량은 관찰된 사건 시점에서 생존확률이 계단식으로 감소하는 비모수 추정량이다. 이 추정량은 관찰된 기간 안에서는 매우 유용하지만 마지막 사건 시점 이후의 생존곡선 형태를 제공하지 않는다. 따라서 다음과 같은 평균 생존기간은 Kaplan-Meier 곡선만으로는 일반적으로 식별되지 않는다.

$$
\mathbb{E}(T)=\int_0^\infty S(t)\,dt.
$$

임상시험에서 관찰 가능한 최대 사건 시점을 $t_{\max}$라고 하면 Kaplan-Meier 곡선이 직접 제공하는 정보는 대략 다음 면적에 해당한다.

$$
\int_0^{t_{\max}} \widehat S_{KM}(t)\,dt.
$$

그러나 평생 분석에서는 다음 꼬리 면적이 필요하다.

$$
\int_{t_{\max}}^\infty S(t)\,dt.
$$

이 꼬리 면적은 자료만으로 결정되지 않는다. 같은 관찰구간 적합도를 보이는 여러 모형이 장기 생존에서는 크게 다를 수 있다. 따라서 생존외삽은 통계적 적합도, 위험함수의 형태, 임상적 개연성, 외부 장기자료, 일반 인구 사망률을 함께 고려해야 한다.

통계적으로 말하면 $t_{\max}$ 이후의 생존함수는 임상시험 자료만으로는 비모수적으로 식별되지 않는다. 마지막 관찰시점의 생존확률을 $S(t_{\max})$라고 할 때, 단조감소 조건만으로는 미래 생존함수에 다음과 같은 매우 넓은 범위만 부여된다.

$$
0\le S(t)\le S(t_{\max}), \qquad t>t_{\max}.
$$

따라서 추가적인 분포 가정, 외부자료 또는 임상적 제약이 없으면 꼬리 면적의 하한과 상한도 지나치게 넓어진다. 생존외삽은 관찰자료가 제공하지 않는 정보를 가정으로 보충하는 과정이며, 이 가정을 명시하고 검증 가능한 부분과 검증 불가능한 부분을 구분해야 한다.

### 외삽의 대상 estimand

외삽모형을 선택하기 전에 먼저 무엇을 추정하려는지 명확히 해야 한다. 경제성 평가에서 생존외삽의 대상은 보통 특정 치료전략 $j$에서의 장기 생존함수 $S_j(t)$, 제한평균 생존기간 $M_j(\tau)$, 기대 QALY $\mathbb{E}(Q_j)$이다.

$$
M_j(\tau)=\int_0^\tau S_j(t)\,dt.
$$

두 치료전략 $1$과 $0$을 비교할 때 증분 생존기간과 증분 QALY는 다음과 같다.

$$
\Delta M(\tau)=M_1(\tau)-M_0(\tau),
$$

$$
\Delta Q=\int_0^\tau \{u_1(t)S_1(t)-u_0(t)S_0(t)\}\,dt.
$$

따라서 생존외삽의 실무적 질문은 특정 모형의 회귀계수가 얼마인지가 아니라, 그 모형이 $S_j(t)$의 장기 꼬리와 $\Delta Q$를 얼마나 타당하게 예측하는지이다.

### 목표 모집단과 표준화 생존함수

외삽 대상은 임상시험 표본 자체의 생존함수인지, 실제 급여 대상 모집단의 생존함수인지에 따라 달라진다. 기저 공변량을 $X$라고 하면 치료전략 $j$에서 목표 모집단의 주변 생존함수는 조건부 생존함수를 목표 모집단 분포에 대해 평균하여 얻는다.

$$
S_j^{pop}(t)
=
\int S_j(t\mid x)\,dF_{pop}(x).
$$

표본자료에서는 다음과 같이 표준화할 수 있다.

$$
\widehat S_j^{pop}(t)
=
\sum_{i=1}^{n} w_i\widehat S_j(t\mid X_i),
\qquad
\sum_{i=1}^{n}w_i=1.
$$

이 과정은 연령, 질병 단계, 바이오마커와 같이 장기 예후를 변경하는 변수의 분포가 임상시험과 실제 진료에서 다를 때 중요하다. 조건부 모형의 계수를 그대로 외삽하는 것만으로는 목표 모집단의 장기 생존을 보장하지 않으며, 공변량 분포까지 함께 운반해야 한다.

## 모수적 모형

### 중도절단 자료의 우도

모수적 생존모형은 생존시간 $T$가 모수 $\theta$를 가지는 특정 분포를 따른다고 가정한다.

$$
T \sim F(t;\theta).
$$

생존시간 분포는 밀도함수 $f(t;\theta)$, 생존함수 $S(t;\theta)$, 위험함수 $h(t;\theta)$, 누적위험함수 $H(t;\theta)$로 표현할 수 있다.

$$
S(t;\theta)=P(T>t),
$$

$$
f(t;\theta)=-\frac{dS(t;\theta)}{dt},
$$

$$
h(t;\theta)=\frac{f(t;\theta)}{S(t;\theta)},
$$

$$
H(t;\theta)=\int_0^t h(u;\theta)\,du,
$$

$$
S(t;\theta)=\exp\{-H(t;\theta)\}.
$$

환자 $i$의 관찰시간을 $t_i$, 사건 관찰 여부를 $\delta_i$라고 하자. 사건이 관찰된 환자는 밀도함수 $f(t_i;\theta)$에 기여하고, 중도절단된 환자는 해당 시점까지 생존했다는 정보 $S(t_i;\theta)$에 기여한다. 따라서 독립적 중도절단 가정하에서 우도는 다음과 같다.

$$
L(\theta)=\prod_{i=1}^n f(t_i;\theta)^{\delta_i}S(t_i;\theta)^{1-\delta_i}.
$$

위험함수와 누적위험함수로 쓰면 $f(t)=h(t)S(t)$이므로 다음과 같다.

$$
L(\theta)=\prod_{i=1}^n h(t_i;\theta)^{\delta_i}\exp\{-H(t_i;\theta)\}.
$$

로그우도는 다음과 같다.

$$
\ell(\theta)=\sum_{i=1}^n\left[\delta_i\log h(t_i;\theta)-H(t_i;\theta)\right].
$$

이 식은 모수적 생존모형을 이해하는 핵심이다. 사건이 발생한 환자는 해당 시점의 순간위험에 대한 정보를 제공하고, 모든 환자는 관찰된 시간까지 누적위험에 대한 정보를 제공한다.

위 우도는 진입 시점부터 관찰되고 우측 중도절단만 존재하는 가장 단순한 형태이다. 연구 진입 전부터 위험에 노출되어 있고 진입시점 $a_i$까지 생존한 사람만 포함되는 좌측절단 자료에서는 조건부 생존을 반영하여 개인별 우도 기여도가 다음과 같이 수정된다.

$$
L_i(\theta)
=
\frac{f(t_i;\theta)^{\delta_i}S(t_i;\theta)^{1-\delta_i}}
{S(a_i;\theta)}.
$$

사건이 정확한 시점이 아니라 구간 $(L_i,R_i]$ 안에서 발생한 것으로만 알려진 구간중도절단 자료의 우도 기여도는 다음과 같다.

$$
L_i(\theta)=S(L_i;\theta)-S(R_i;\theta).
$$

또한 표준 우도는 사건시간과 중도절단시간이 공변량을 조건으로 독립이라는 가정에 의존한다. 이 가정이 위반되면 관찰된 꼬리 부분의 환자가 선택적으로 남게 되어 위험함수와 외삽곡선이 함께 왜곡될 수 있다. 따라서 치료중단, 추적탈락, 행정적 중도절단의 원인을 구분하고 필요하면 역확률 중도절단 가중치나 공동모형을 고려해야 한다.

최대가능도 추정량 $\widehat\theta$의 공분산행렬은 관찰정보행렬의 역행렬로 근사된다.

$$
\operatorname{Var}(\widehat\theta)
\approx
\left[-\frac{\partial^2\ell(\theta)}{\partial\theta\partial\theta^\top}
\bigg|_{\theta=\widehat\theta}\right]^{-1}.
$$

장기 생존함수는 모수의 비선형 함수이므로, 관찰기간 말미의 정보가 적으면 작은 모수 불확실성이 장기 꼬리에서 크게 증폭될 수 있다.

### 주요 모수적 생존분포

경제성 평가에서 자주 사용되는 모수적 생존분포는 다음과 같다.

| 분포 | 생존함수 $S(t)$ | 위험함수 형태 | 외삽 해석 |
|---|---|---|---|
| Exponential | $\exp(-\lambda t)$ | 일정 | 가장 단순하지만 위험 변화 표현 불가 |
| Weibull | $\exp\{-(t/\lambda)^k\}$ | 단조 증가 또는 단조 감소 | 단순하면서 실무적으로 많이 사용 |
| Gompertz | $\exp[-\{b/a\}(e^{at}-1)]$ | 지수적 증가 또는 감소 | 노화 관련 사망위험 표현 가능 |
| Log-normal | $1-\Phi\{(\log t-\mu)/\sigma\}$ | 비단조 가능 | 초기 증가 후 감소하는 위험 표현 가능 |
| Log-logistic | $\{1+(t/\lambda)^k\}^{-1}$ | 비단조 가능, 두꺼운 꼬리 | 장기 생존 꼬리를 크게 예측할 수 있음 |
| Generalized gamma | 모수화에 따라 다양 | 매우 유연 | 여러 표준 분포를 포함하지만 해석이 어려움 |

![주요 모수적 생존분포의 생존곡선 예시](figures/ch09/fig-ch09-parametric-survival.png){fig-align="center" width="90%"}

이 그림은 관찰 초기에 비슷해 보이는 생존곡선도 시간이 길어질수록 꼬리 감소 속도가 크게 달라질 수 있음을 보여준다. 특히 log-logistic과 log-normal 계열은 단순 지수형 분포보다 장기 생존확률을 높게 유지할 수 있으므로, 평생 QALY가 꼬리 선택에 민감해진다.

![외삽모형이 가정하는 위험함수 형태](figures/ch09/fig-ch09-hazard-shapes.png){fig-align="center" width="90%"}

위험함수 그림에서는 각 분포가 허용하는 형태의 범위를 확인해야 한다. 생존곡선은 누적 결과이므로 서로 비슷해 보일 수 있지만, 위험함수는 일정·단조 증가·단조 감소·단봉형이라는 구조적 차이를 더 분명히 드러낸다.

### Exponential 모형

Exponential 모형은 위험함수가 시간에 따라 일정하다고 가정한다.

$$
h(t)=\lambda, \qquad \lambda>0.
$$

따라서 누적위험함수와 생존함수는 다음과 같다.

$$
H(t)=\lambda t,
$$

$$
S(t)=\exp(-\lambda t).
$$

평균 생존시간은 다음과 같다.

$$
\mathbb{E}(T)=\frac{1}{\lambda}.
$$

Exponential 모형은 단순하고 안정적이지만 시간에 따른 위험 변화를 허용하지 않는다. 따라서 질병 진행 직후 사망위험이 높아졌다가 시간이 지나며 낮아지는 상황, 또는 고령화로 사망위험이 증가하는 상황에는 부적절할 수 있다.

### Weibull 모형

Weibull 모형은 Exponential 모형을 일반화한다. 이 책에서는 scale 모수 $\lambda>0$와 shape 모수 $k>0$를 사용하는 모수화를 따른다.

$$
S(t)=\exp\left\{-\left(\frac{t}{\lambda}\right)^k\right\}.
$$

위험함수와 누적위험함수는 다음과 같다.

$$
h(t)=\frac{k}{\lambda}\left(\frac{t}{\lambda}\right)^{k-1},
$$

$$
H(t)=\left(\frac{t}{\lambda}\right)^k.
$$

shape 모수 $k$는 위험함수의 형태를 결정한다.

| $k$ 값 | 위험함수 형태 | 해석 |
|---|---|---|
| $k=1$ | 일정 | Exponential 모형과 동일 |
| $k>1$ | 시간에 따라 증가 | 시간이 지날수록 사건위험 증가 |
| $k<1$ | 시간에 따라 감소 | 초기 위험이 높고 이후 감소 |

Weibull 모형의 평균 생존시간은 다음과 같다.

$$
\mathbb{E}(T)=\lambda\Gamma\left(1+\frac{1}{k}\right),
$$

여기서 $\Gamma(\cdot)$는 감마함수이다.

::: {.callout-tip title="Weibull 모형의 장점과 한계"}
Weibull 모형은 위험함수가 단조 증가 또는 단조 감소하는 상황에 적합하다. 하지만 위험이 초기에 증가했다가 이후 감소하는 비단조 형태는 표현하지 못한다. 항암제 장기 외삽에서 위험함수 형태가 비단조적일 가능성이 있다면 log-normal, log-logistic, spline 기반 모형, mixture cure model 등을 함께 검토해야 한다.
:::

### Gompertz 모형

Gompertz 모형은 위험함수가 시간에 따라 지수적으로 변화한다고 가정한다.

$$
h(t)=b\exp(at), \qquad b>0.
$$

$a\ne0$일 때 누적위험함수는 다음과 같다.

$$
H(t)=\frac{b}{a}\{\exp(at)-1\}.
$$

따라서 생존함수는 다음과 같다.

$$
S(t)=\exp\left[-\frac{b}{a}\{\exp(at)-1\}\right].
$$

$a>0$이면 위험이 시간이 지남에 따라 증가하고, $a<0$이면 위험이 감소한다. Gompertz 모형은 연령 증가에 따른 사망위험 증가를 표현하는 데 자연스러울 수 있다. 그러나 $a<0$인 경우 장기적으로 누적위험이 유한값에 수렴할 수 있으므로 장기 생존 꼬리를 과대평가할 가능성을 점검해야 한다.

### Log-normal 모형

Log-normal 모형은 생존시간의 로그가 정규분포를 따른다고 가정한다.

$$
\log T \sim N(\mu,\sigma^2).
$$

생존함수는 다음과 같다.

$$
S(t)=1-\Phi\left(\frac{\log t-\mu}{\sigma}\right),
$$

여기서 $\Phi(\cdot)$는 표준정규 누적분포함수이다. 평균 생존시간은 다음과 같다.

$$
\mathbb{E}(T)=\exp\left(\mu+\frac{\sigma^2}{2}\right).
$$

Log-normal 모형은 위험함수가 초기에 증가했다가 이후 감소하는 형태를 가질 수 있다. 장기 생존자가 존재하거나 치료 후 일정 기간을 넘기면 사건위험이 낮아지는 질환에서 후보 모형이 될 수 있다. 그러나 꼬리 영역이 상대적으로 두꺼워 장기 생존기간을 크게 예측할 수 있으므로 외부자료와 임상적 개연성 검토가 필요하다.

### Log-logistic 모형

Log-logistic 모형의 생존함수는 다음과 같다.

$$
S(t)=\frac{1}{1+(t/\lambda)^k}.
$$

위험함수는 다음과 같다.

$$
h(t)=\frac{(k/\lambda)(t/\lambda)^{k-1}}{1+(t/\lambda)^k}.
$$

$k>1$이면 위험함수는 초기에는 증가하다가 이후 감소할 수 있다. 평균 생존시간은 $k>1$일 때만 존재하며 다음과 같다.

$$
\mathbb{E}(T)=\frac{\lambda\pi/k}{\sin(\pi/k)}.
$$

Log-logistic 모형은 장기 꼬리가 두꺼울 수 있어 평생 분석에서 QALY를 크게 만들 수 있다. 따라서 단순히 AIC나 BIC가 좋다는 이유만으로 선택하기보다 장기 생존이 임상적으로 가능한지 검토해야 한다.

### Generalized gamma 모형

Generalized gamma 모형은 Weibull, log-normal, gamma 분포 등을 포함할 수 있는 매우 유연한 모형이다. 유연성이 높다는 것은 관찰자료에 잘 맞을 가능성이 크다는 장점이 있지만, 장기 외삽에서는 작은 모수 변화가 꼬리 영역에 큰 영향을 줄 수 있다는 단점도 있다.

경제성 평가에서 generalized gamma 모형을 사용할 때는 다음을 확인해야 한다.

- 장기 생존꼬리가 임상적으로 가능한가?
- 위험함수 형태가 질병 자연사와 맞는가?
- 모수 추정의 불확실성이 과도하게 크지 않은가?
- 단순 모형보다 복잡한 모형을 사용할 충분한 이유가 있는가?

### 꼬리 거동과 평균 생존시간의 존재

분포 선택은 단순히 곡선의 모양뿐 아니라 꼬리의 감소 속도를 선택하는 것이다. 지수분포와 Weibull 분포는 대체로 지수형 꼬리를 가지지만, log-logistic 분포는 다항식 형태로 더 천천히 감소할 수 있다. 이러한 차이는 평균 생존시간의 존재 조건과 직접 연결된다.

$$
\mathbb{E}(T)=\int_0^\infty S(t)\,dt.
$$

이 적분이 유한하지 않으면 평생 평균 생존시간이 존재하지 않는다. 예를 들어 log-logistic 분포에서는 shape 모수 $k>1$일 때에만 평균이 유한하다. 실제 경제성 평가는 유한한 분석기간을 사용하므로 수치 계산은 가능하지만, 매우 두꺼운 꼬리는 분석기간 선택에 따라 결과가 급격히 증가할 수 있다. 따라서 평균 존재 여부, 장기 위험률의 극한, 특정 시점의 생존율을 함께 확인해야 한다.

### 유연 모수적 생존모형

표준 분포가 허용하는 위험함수 형태가 지나치게 제한적일 때는 제한적 세제곱 스플라인을 이용한 유연 모수적 생존모형을 사용할 수 있다. Royston–Parmar 모형의 대표적 표현은 로그 누적위험의 로그를 로그시간의 스플라인 함수로 모형화한다.

$$
\log H(t\mid x)
=
s\{\log(t);\gamma\}+x^\top\beta,
$$

여기서 $s(\cdot)$는 절점에 의해 정의되는 제한적 세제곱 스플라인이다. 이에 따라

$$
S(t\mid x)
=
\exp\left[-\exp\{s(\log t;\gamma)+x^\top\beta\}\right].
$$

절점 수가 증가하면 관찰구간 적합도는 좋아질 수 있지만, 자료가 희박한 꼬리에서는 스플라인의 기울기가 장기 예측을 과도하게 지배할 수 있다. 따라서 자유도 선택, 경계 절점, 장기 위험의 방향과 외부 타당성을 함께 검토해야 한다.

### Piecewise exponential 모형

시간축을 $0=\tau_0<\tau_1<\cdots<\tau_K$로 분할하고 각 구간에서 위험률이 일정하다고 가정하면

$$
h(t)=\lambda_k,
\qquad \tau_{k-1}<t\le \tau_k.
$$

누적위험함수는 구간별 위험을 합산하여 계산한다.

$$
H(t)
=
\sum_{j<k}\lambda_j(\tau_j-\tau_{j-1})
+\lambda_k(t-\tau_{k-1}).
$$

이 모형은 관찰구간의 위험 변화는 유연하게 표현하지만 마지막 구간 이후 어떤 위험률을 유지할지 별도의 외삽 가정이 필요하다. 마지막 구간 위험을 무기한 유지하면 절점 위치와 마지막 사건 수에 결과가 매우 민감해질 수 있다.

### Cure 모형

일부 환자가 장기적으로 질병 관련 사건을 더 이상 경험하지 않는다고 가정할 수 있는 상황에서는 cure 모형을 고려한다. 혼합 cure 모형은 모집단을 장기 생존군과 비장기 생존군의 혼합으로 표현한다.

$$
S(t)=\pi+(1-\pi)S_u(t),
$$

여기서 $\pi$는 cure fraction이고 $S_u(t)$는 비장기 생존군의 생존함수이다. $t\to\infty$일 때 $S_u(t)\to0$이면 질병 관련 생존함수는 $\pi$에 접근한다. 전체 사망을 모형화할 때에는 배경 사망률을 결합해야 하므로 총 생존함수가 양의 상수에 수렴한다고 해석해서는 안 된다.

비혼합 cure 모형의 대표적인 promotion-time 표현은 잠재 사건 수를 나타내는 모수 $\theta>0$와 비장기 생존 성분의 누적분포함수 $F_u(t)$를 이용한다.

$$
S(t)=\exp\{-\theta F_u(t)\}.
$$

$F_u(t)\to1$이면 장기 생존비율은 $\exp(-\theta)$에 수렴한다. cure fraction은 충분히 긴 추적과 생물학적 근거가 없으면 자료에서 약하게 식별될 수 있다. 관찰기간 중 생존곡선의 plateau가 보인다는 이유만으로 cure를 확정하지 말고, number at risk, 후속치료, 배경 사망률과 외부 장기자료를 함께 확인해야 한다.

## 비례위험모형과 가속고장 시간모형

### 비례위험모형

비례위험(proportional hazards, PH) 모형은 공변량이 위험함수에 곱셈적으로 작용한다고 가정한다. 공변량 벡터를 $x$라고 하면 다음과 같이 쓸 수 있다.

$$
h(t\mid x)=h_0(t)\exp(x^\top\beta).
$$

여기서 $h_0(t)$는 기준 위험함수이고, $\exp(\beta_r)$는 공변량 $x_r$이 한 단위 증가할 때의 위험비이다. PH 모형의 생존함수는 다음과 같다.

$$
S(t\mid x)=S_0(t)^{\exp(x^\top\beta)}.
$$

두 치료군을 비교할 때 치료군 지시변수 $Z$를 사용하면 다음과 같다.

$$
h(t\mid Z)=h_0(t)\exp(\beta Z).
$$

위험비는 $HR=\exp(\beta)$이고 시간에 따라 일정하다고 가정한다. 따라서 장기 외삽에서는 관찰된 치료효과가 분석기간 내내 동일한 상대위험 감소로 지속된다고 가정하는 셈이다.

::: {.callout-warning title="PH 가정의 장기 외삽상 의미"}
PH 모형에서 위험비가 일정하다는 것은 관찰기간 이후에도 치료효과가 동일한 비율로 유지된다는 강한 가정이다. 면역항암제, 세포치료제, 만성질환 치료제처럼 치료효과가 시간에 따라 변할 가능성이 있는 경우에는 시간의존 위험비, 치료효과 소실, cure 모형 등을 시나리오로 검토해야 한다.
:::

### 가속고장 시간모형

가속고장시간(accelerated failure time, AFT) 모형은 공변량이 생존시간의 시간축을 늘리거나 줄인다고 해석한다. 일반적으로 다음과 같이 쓴다.

$$
\log T = \alpha+x^\top\beta+\sigma\varepsilon,
$$

여기서 $\varepsilon$의 분포 선택에 따라 Weibull, log-normal, log-logistic AFT 모형이 된다. 치료군 지시변수 $Z$의 계수가 $\beta$라면 시간비(time ratio)는 다음과 같다.

$$
TR=\exp(\beta).
$$

$TR>1$이면 생존시간이 늘어나는 방향의 치료효과를 의미한다. AFT 모형에서 생존함수는 다음과 같이 표현할 수 있다.

$$
S(t\mid x)=S_0\{t\exp(-x^\top\beta)\}.
$$

즉, 공변량은 생존곡선의 시간축을 이동시키는 역할을 한다.

![비례위험모형과 가속고장시간모형의 직관적 차이](figures/ch09/fig-ch09-ph-aft.png){fig-align="center" width="95%"}

이 그림에서 PH 모형은 같은 시점의 순간위험을 일정한 배율로 조정하는 반면, AFT 모형은 전체 생존시간 축을 늘리거나 줄인다. 두 모형이 관찰구간에서 비슷한 적합도를 보이더라도 장기 치료효과의 유지 방식은 서로 다르다.

### Weibull 모형에서 PH와 AFT의 연결

Weibull 모형은 PH 모형과 AFT 모형으로 모두 표현될 수 있는 특수한 분포이다. AFT 표현에서

$$
\log T=\alpha+\beta Z+\sigma\varepsilon
$$

라고 하면 shape 모수는 $k=1/\sigma$로 연결된다. 이때 치료군의 시간비는 $TR=\exp(\beta)$이고, 대응되는 위험비는 다음과 같다.

$$
HR=\exp(-k\beta)=TR^{-k}.
$$

따라서 AFT 계수 $\beta$가 양수이면 생존시간이 늘어나고, 대응되는 위험비는 1보다 작다.

### PH와 AFT의 비교

| 구분 | PH 모형 | AFT 모형 |
|---|---|---|
| 기본 가정 | 위험의 비율이 일정 | 생존시간의 비율이 일정 |
| 대표 효과척도 | 위험비 $HR$ | 시간비 $TR$ |
| 생존함수 표현 | $S(t\mid x)=S_0(t)^{\exp(x^\top\beta)}$ | $S(t\mid x)=S_0\{t\exp(-x^\top\beta)\}$ |
| 직관적 해석 | 순간위험을 몇 배로 바꾸는가 | 사건까지의 시간을 몇 배로 늘리는가 |
| 장기 외삽상 주의점 | 치료효과가 계속 같은 비율로 유지됨 | 시간축 이동이 장기까지 유지됨 |

경제성 평가에서는 두 접근 중 하나가 항상 우월하다고 볼 수 없다. Kaplan-Meier 곡선의 형태, 로그누적위험 그림, Schoenfeld 잔차, 위험함수 추정, 임상적 치료기전을 함께 검토해야 한다.

### 비례위험 가정이 성립하지 않는 경우

치료효과가 시간에 따라 변하면 위험비를 $HR(t)=\exp\{\beta(t)\}$로 표현할 수 있다.

$$
h_1(t)=h_0(t)\exp\{\beta(t)\}.
$$

이때 단일 Cox 위험비는 추적기간과 사건 발생 분포에 따라 가중된 평균에 가까우며, 장기 외삽에 그대로 적용할 고정된 생물학적 상수로 해석할 수 없다. 시간가변 계수는 스플라인이나 구간별 계수로 모형화할 수 있다.

$$
\beta(t)=\sum_{k=1}^{K}\alpha_k B_k\{\log(t)\}.
$$

교차하는 생존곡선이나 지연 치료효과가 존재할 때에는 치료군별 생존함수를 직접 추정한 후 목표 모집단에 표준화하는 접근이 위험비 중심 접근보다 해석에 유리할 수 있다.

$$
S_j^{pop}(t)
=
\frac{1}{n}\sum_{i=1}^{n}\widehat S(t\mid Z=j,X_i).
$$

이 주변 생존함수는 치료군별 기대 생존기간과 QALY 계산에 직접 사용할 수 있으며, 조건부 위험비의 비축약성 문제를 피할 수 있다.

## 모델링 방법

### 생존외삽의 기본 절차

생존외삽은 다음의 순서로 진행하는 것이 바람직하다.

1. 자료 구조를 확인한다. 추적기간, 사건 수, 중도절단 비율, number at risk, 교차투여, 후속치료를 점검한다.
2. Kaplan-Meier 곡선을 작성하고 각 치료군의 관찰구간 생존 패턴을 확인한다.
3. 임상적으로 가능한 위험함수 형태를 논의한다.
4. 후보 모수적 모형을 사전에 정의한다.
5. 독립 적합과 공동 적합의 적절성을 검토한다.
6. 관찰구간 내 적합도와 장기 외삽 타당성을 각각 평가한다.
7. 기본분석 모형을 선택하고 대안 모형을 시나리오 분석으로 제시한다.
8. 모수 불확실성을 PSA에 반영한다.
9. 외삽 선택이 ICER에 미치는 영향을 보고한다.

### 독립 적합과 공동 적합

두 치료군의 생존곡선을 외삽할 때는 크게 독립 적합과 공동 적합을 고려할 수 있다.

독립 적합은 각 치료군에 별도의 생존분포를 적합하는 방법이다.

$$
S_0(t)=S(t;\theta_0), \qquad S_1(t)=S(t;\theta_1).
$$

공동 적합은 하나의 모형 안에 치료군 지시변수를 포함하여 두 군의 생존곡선을 동시에 추정하는 방법이다.

$$
h(t\mid Z)=h_0(t;\theta)\exp(\beta Z).
$$

또는 AFT 형태로 다음과 같이 쓸 수 있다.

$$
\log T = \alpha+\beta Z+\sigma\varepsilon.
$$

독립 적합은 두 군의 생존곡선 형태가 다를 수 있음을 허용하지만, 표본 수가 작거나 사건 수가 부족할 때 불안정할 수 있다. 공동 적합은 효율성이 높고 치료효과를 직접 추정하지만, PH 또는 AFT 같은 구조적 가정을 부여한다.

독립 적합과 공동 적합 사이에는 일부 모수만 공유하는 부분공유 모형도 가능하다. 예를 들어 두 군이 공통 shape 모수를 가지되 scale 모수는 다르게 둘 수 있다.

$$
S_j(t)=\exp\left[-\left\{\frac{t}{\lambda_j}\right\}^{k}\right],
\qquad j\in\{0,1\}.
$$

이 접근은 완전 독립 적합보다 안정적이고, 완전 공동 PH 모형보다 유연하다. 어떤 모수를 공유할지는 임상적 기전과 관찰된 위험함수 형태를 근거로 결정해야 하며, 공유 여부 자체도 구조적 불확실성으로 평가해야 한다.

![독립 적합과 공동 적합의 개념](figures/ch09/fig-ch09-independent-joint-fit.png){fig-align="center" width="90%"}

독립 적합은 각 군의 꼬리 형태를 자유롭게 허용하지만 두 군의 모수 불확실성이 별도로 추정되고 장기 곡선이 비현실적으로 교차할 수 있다. 공동 적합은 정보를 공유하여 안정성을 높이지만, 공통 shape나 일정한 치료효과와 같은 제약이 틀리면 두 군 모두에 구조적 편향이 생길 수 있다.

### 치료효과 유지, 감소, 소실 가정

장기 외삽에서 가장 민감한 요소 중 하나는 관찰기간 이후 치료효과가 어떻게 변하는가이다. 관찰기간의 위험비가 0.70이라고 해서 이 효과가 평생 지속된다고 자동으로 가정할 수는 없다.

대표적인 가정은 다음과 같다.

| 가정 | 시간의존 위험비 예 | 해석 |
|---|---|---|
| 치료효과 유지 | $HR(t)=HR_0$ | 관찰된 상대효과가 장기까지 동일하게 유지 |
| 점진적 감소 | $HR(t)=1-(1-HR_0)\exp\{-\rho(t-t_w)_+\}$ | 특정 시점 이후 효과가 서서히 1로 접근 |
| 효과 소실 | $HR(t)=HR_0$ for $t<t_w$, $HR(t)=1$ for $t\ge t_w$ | 일정 시점 이후 치료효과가 없어짐 |
| 지연 효과 | $HR(t)$가 초기에는 1에 가깝고 이후 감소 | 면역항암제 등에서 가능 |

여기서 $(a)_+=\max(a,0)$이다. 치료효과 감소율 $\rho$와 감소 시작 시점 $t_w$는 자료만으로 안정적으로 추정하기 어려운 경우가 많다. 따라서 임상 전문가 의견, 장기 추적자료, 유사 약제 자료, 생물학적 치료기전을 함께 고려해야 한다.

점진적 감소 가정에서 치료군 위험함수는 기준군 위험함수와 시간가변 위험비의 곱으로 구성된다.

$$
h_1(t)=h_0(t)HR(t).
$$

따라서 치료군 생존함수는 단순히 기준군 생존함수를 고정된 거듭제곱으로 변환할 수 없으며 다음과 같이 다시 적분해야 한다.

$$
S_1(t)
=
\exp\left[-\int_0^t h_0(u)HR(u)\,du\right].
$$

효과 소실 시점에서 위험함수를 갑자기 1로 전환하면 위험함수는 불연속일 수 있으나 생존함수는 연속이어야 한다. 구현에서는 소실 시점 직전까지의 누적위험을 보존한 채 이후 기준위험을 누적해야 한다.

![장기 외삽에서 치료효과 가정](figures/ch09/fig-ch09-treatment-waning.png){fig-align="center" width="90%"}

이 그림은 관찰기간 이후 동일한 생존자료가 서로 다른 치료효과 지속 가정으로 연결될 수 있음을 보여준다. 효과감소 시작시점과 감소속도는 대개 시험자료에서 직접 식별되지 않으므로, 해당 가정은 추정 결과라기보다 명시적인 의사결정 시나리오로 다루어야 한다.

### 배경 사망률의 반영

전체생존기간을 외삽할 때 장기 생존곡선은 일반 인구 사망률보다 더 낙관적이어서는 안 된다. 일반 인구 배경 사망위험을 $h_{bg}(t)$, 질병 관련 초과위험을 $h_{excess}(t)$라고 하면 총 사망위험을 다음과 같이 표현할 수 있다.

$$
h_{total}(t)=h_{bg}(t)+h_{excess}(t).
$$

독립적인 위험요인으로 해석하면 생존함수는 다음과 같이 분해된다.

$$
S_{total}(t)=S_{bg}(t)S_{excess}(t).
$$

외삽된 OS 위험함수가 장기적으로 일반 인구 사망위험보다 낮아지는 경우는 임상적으로 부적절할 수 있다. 특히 고령 환자군에서 평생 분석을 수행할 때는 연령, 성별, 국가별 생명표를 이용하여 배경 사망률을 반영해야 한다.

![질병 관련 위험과 배경 사망위험의 결합](figures/ch09/fig-ch09-background-mortality.png){fig-align="center" width="90%"}

그림의 총 사망위험은 질병 관련 초과위험과 배경 사망위험을 합한 값이다. 시간이 지나 질병 관련 초과위험이 감소하더라도 연령 증가에 따라 배경 사망위험은 커지므로, 전체 사망위험이 장기적으로 0에 접근하는 외삽은 일반적으로 타당하지 않다.

::: {.callout-warning title="배경 사망률 점검"}
외삽된 총 사망위험이 동일 연령·성별 일반 인구 사망위험보다 낮다면, 해당 모형은 장기적으로 비현실적인 생존을 예측할 수 있다. 이는 특히 log-normal, log-logistic, cure 모형의 꼬리 영역에서 중요하다.
:::

### 상대생존과 초과위험 모형

사망원인이 정확히 구분되지 않더라도 일반 인구 생명표를 이용하면 상대생존 접근으로 질병 관련 초과위험을 모형화할 수 있다. 진단 시 연령을 $a_0$, 진단 후 시간을 $t$라고 하면 배경위험은 달력시간과 도달연령 $a_0+t$에 따라 달라진다.

$$
h_{all}(t\mid x)
=
h_{pop}(a_0+t,\text{sex},\text{calendar year})
+h_{excess}(t\mid x).
$$

이에 대응하는 생존함수는

$$
S_{all}(t\mid x)
=
S_{pop}(t\mid x)S_{relative}(t\mid x)
$$

로 분해된다. 배경위험을 초기 연령의 고정값으로 두면 고령화에 따른 사망위험 증가를 놓치므로, 외삽 시점마다 도달연령과 달력연도를 갱신해야 한다. 또한 임상시험 모집단의 건강상태가 일반 인구와 다르면 생명표 사망률을 그대로 적용하는 것 자체가 추가 가정이 된다.

## 적합된 모수적 모형과 외삽의 적절성을 평가하는 방법

### 관찰기간 내 적합도

모형 적합도는 우도 기반 지표와 시각적 검토를 함께 사용한다. 모형 $m$의 최대 로그우도를 $\ell_m$, 추정 모수 수를 $p_m$, 표본 수를 $n$이라고 하면 Akaike information criterion(AIC)와 Bayesian information criterion(BIC)는 다음과 같다.

$$
AIC_m=-2\ell_m+2p_m,
$$

$$
BIC_m=-2\ell_m+p_m\log n.
$$

값이 작을수록 관찰자료에 대한 상대적 적합도가 좋다고 해석한다. 그러나 AIC와 BIC는 관찰구간 안에서의 상대적 적합도를 요약할 뿐이며, 장기 외삽이 타당하다는 것을 보장하지 않는다.

AIC는 후보 모형의 예측분포와 실제 자료생성분포 사이의 Kullback–Leibler 정보손실을 근사적으로 최소화하는 관점에 가깝고, BIC는 정규성·큰 표본 조건에서 모형의 주변가능도에 대한 근사를 제공한다. 두 기준 모두 관찰된 시간범위의 우도에 기반하므로, 관찰되지 않은 꼬리에 대한 직접적인 점수는 포함하지 않는다. 후보 모형이 모두 잘못 지정되어 있을 때는 가장 작은 정보기준이 절대적 타당성을 의미하지도 않는다.

관찰기간 내 적합도 평가에는 다음을 포함하는 것이 좋다.

- Kaplan-Meier 곡선과 적합된 생존곡선의 중첩 그림
- 누적위험 또는 log-cumulative hazard 그림
- Cox-Snell 잔차 또는 quantile-quantile plot
- 각 치료군의 number at risk와 censoring pattern
- 사건 수가 충분한 구간과 부족한 구간의 구분

### AIC와 BIC의 한계

AIC나 BIC가 가장 낮은 모형이 항상 기본분석 모형이 되어야 하는 것은 아니다. 장기 외삽에서는 관찰구간의 작은 차이가 분석기간 전체에서 큰 차이로 확대될 수 있다. 특히 관찰구간에서 여러 모형이 거의 같은 적합도를 보이는 경우, 외삽구간에서의 생존곡선은 크게 벌어질 수 있다.

![관찰구간 적합도가 비슷해도 장기 외삽은 달라질 수 있다](figures/ch09/fig-ch09-fit-vs-extrapolation.png){fig-align="center" width="90%"}

이 그림에서 관찰구간 안의 곡선들은 거의 겹치지만, 관찰종료 이후의 기울기와 꼬리 감소속도는 크게 다르다. 이는 관찰구간 적합도만으로 장기 모형을 순위화하기 어려운 이유이며, 외부시점 생존율과 위험률에 대한 제약이 별도로 필요함을 보여준다.

따라서 AIC/BIC는 모형 선택의 출발점이지 최종 판단 기준이 아니다. 경제성 평가에서는 “통계적으로 가장 잘 맞는 모형”보다 “의사결정에 사용할 장기 예측으로 가장 타당한 모형”이 중요하다.

### 외삽 타당성 평가

외삽 타당성은 다음의 질문을 통해 검토한다.

1. 장기 생존율이 질병 자연사와 부합하는가?
2. 외삽된 생존곡선이 외부 장기자료 또는 등록자료와 유사한가?
3. 위험함수 형태가 치료기전과 임상 경험에 부합하는가?
4. 일반 인구 사망률보다 비현실적으로 낮은 사망위험을 예측하지 않는가?
5. 장기 생존 꼬리가 QALY와 ICER에 얼마나 큰 영향을 주는가?
6. 관찰기간 말미의 number at risk가 너무 적어 꼬리 추정이 불안정하지 않은가?
7. 치료효과 유지 가정이 임상적으로 정당화되는가?

### 위험함수 기반 평가

생존곡선만 보면 장기 외삽의 문제를 놓칠 수 있다. 생존곡선은 누적된 결과이기 때문에 여러 위험함수 형태가 비슷한 생존곡선을 만들 수 있다. 반면 위험함수는 시간에 따른 사건위험의 변화를 직접 보여준다.

예를 들어 다음과 같은 위험함수 형태는 서로 다른 임상적 의미를 가진다.

| 위험함수 형태 | 가능한 임상적 해석 |
|---|---|
| 일정 | 시간에 따라 사건위험이 변하지 않음 |
| 단조 증가 | 시간이 지날수록 질병 악화 또는 노화 효과가 증가 |
| 단조 감소 | 초기 고위험군에서 사건이 집중되고 이후 안정화 |
| 초기 증가 후 감소 | 치료 초기 취약기간 이후 장기 생존자군 형성 가능 |
| 장기적으로 일반 인구 위험에 접근 | 질병 관련 초과위험이 감소 |

경제성 평가 보고서에서는 후보 모형의 생존곡선뿐 아니라 위험함수를 함께 제시하는 것이 바람직하다.

### 외부자료와 전문가 판단

외부자료는 장기 외삽 타당성을 평가하는 중요한 근거이다. 사용할 수 있는 자료원은 다음과 같다.

- 동일 질환의 장기 추적 임상시험
- 확장 추적 연구
- 질병 등록자료
- 실제임상자료(real-world data)
- 기존 치료제의 장기 생존자료
- 건강보험 청구자료
- 일반 인구 생명표
- 임상 전문가의 구조화된 판단

외부자료가 임상시험 모집단과 다를 수 있으므로 단순 비교는 위험하다. 연령, 성별, 질병 단계, 이전 치료, 바이오마커, 치료선, 사망 원인, 후속치료 차이를 함께 검토해야 한다.

### 외부자료를 이용한 보정

외부자료가 특정 시점 $t_k$의 생존율 $S_k^{ext}$와 불확실성 $v_k$를 제공한다면, 임상시험 우도와 외부자료 적합도를 결합한 목적함수를 사용할 수 있다.

$$
\ell_{joint}(\theta)
=
\ell_{trial}(\theta)
-
\frac{1}{2}\sum_{k=1}^{K}
\frac{\{g[S(t_k;\theta)]-g(S_k^{ext})\}^2}{v_k},
$$

여기서 $g(\cdot)$는 logit 또는 complementary log-log 변환이다. 이 방식은 외부자료를 정확한 상수로 강제하지 않고 그 불확실성에 비례하여 가중한다. 베이지안 접근에서는 외부 생존율, 장기 위험률 또는 cure fraction에 대한 사전분포를 설정할 수 있다.

외부자료를 결합하기 전에는 목표 모집단과 사건정의의 교환가능성을 검토해야 한다. 교환가능성이 약하면 직접 통합보다 외적 타당성 확인이나 시나리오 범위 설정에 사용하는 편이 안전하다.

### 시간 분할 검증과 장기 예측성

추적자료가 충분하다면 초기 구간만 사용하여 모형을 적합하고 이후 관찰구간을 예측하는 시간 분할 검증을 수행할 수 있다. 절단시점 $c$ 이전 자료로 적합한 모형의 예측 생존율 $\widehat S_c(t)$를 실제 후속 Kaplan–Meier 추정량과 비교한다.

$$
E_c(t)=\widehat S_c(t)-\widehat S_{KM}(t),
\qquad t>c.
$$

이 검증도 평생 꼬리를 직접 검증하지는 못하지만, 후보 모형이 관찰되지 않은 미래를 예측하는 상대적 능력을 평가한다는 점에서 전체 자료에 대한 AIC 비교보다 외삽 목적에 더 가까운 정보를 제공한다.

## 모형 선택 알고리즘

### 모형 선택의 원칙

생존외삽 모형 선택은 다음 원칙을 따른다.

1. 사전에 후보 모형과 선택 기준을 정의한다.
2. 관찰구간 적합도와 외삽 타당성을 분리하여 평가한다.
3. 단순한 모형과 복잡한 모형을 모두 검토한다.
4. 치료효과 유지 가정을 명시적으로 보고한다.
5. 기본분석 모형 선택 이유를 통계적·임상적으로 설명한다.
6. 대안적으로 타당한 모형은 시나리오 분석에 포함한다.
7. 모수 불확실성과 모형 불확실성을 구분하여 보고한다.

![생존외삽 모형 선택 알고리즘](figures/ch09/fig-ch09-model-selection-algorithm.png){fig-align="center" width="95%"}

이 알고리즘은 정보기준만으로 자동 선택하는 절차가 아니라 통계적 적합도, 위험함수의 임상적 의미, 외부 근거와 경제성 결과의 민감도를 순차적으로 통합하는 판단 구조이다. 어느 단계에서 후보 모형을 제외했는지와 그 근거를 기록해야 선택과정의 재현성이 확보된다.

### 기본분석과 시나리오 분석

기본분석(base-case)에 사용할 모형은 의사결정자의 관점에서 가장 타당한 장기 예측을 제공해야 한다. 그러나 외삽모형 선택에는 구조적 불확실성이 크므로, 다음과 같은 시나리오를 함께 제시하는 것이 일반적이다.

- 다른 모수적 분포 사용
- 독립 적합 대신 공동 적합 사용
- PH 대신 AFT 가정 사용
- 치료효과 점진적 감소 또는 소실 가정
- 일반 인구 사망률 반영 방식 변경
- 외부자료를 이용한 보정 또는 제한
- 장기 cure fraction 가정 사용 여부 변경

모형 간 ICER가 크게 달라진다면, 단일 기본분석 결과보다 외삽 불확실성 자체가 의사결정의 핵심이 된다. 이 경우 추가 자료 수집의 가치, 조건부 급여, 위험분담제와 같은 의사결정 대안을 함께 논의할 필요가 있다.

### 모형 불확실성과 모형 평균화

하나의 분포를 확정적으로 선택하기 어려울 때는 후보 모형 $m=1,\ldots,M$에 가중치 $w_m$을 부여하여 생존함수 또는 순편익을 평균할 수 있다.

$$
S_{MA}(t)=\sum_{m=1}^{M}w_mS_m(t),
\qquad
\sum_{m=1}^{M}w_m=1.
$$

AIC 기반 가중치는 다음과 같이 계산할 수 있다.

$$
w_m
=
\frac{\exp(-\Delta_m/2)}
{\sum_{r=1}^{M}\exp(-\Delta_r/2)},
\qquad
\Delta_m=AIC_m-\min_r AIC_r.
$$

그러나 이 가중치도 관찰구간 적합도만 반영한다. 임상적 개연성과 외부자료를 반영하려면 전문가 사전확률이나 베이지안 모형확률을 사용할 수 있다. 모형 평균화의 전체 분산은 모형 내부 모수분산과 모형 간 평균 차이를 모두 포함한다.

$$
\operatorname{Var}(Y)
=
\sum_m w_m\operatorname{Var}(Y\mid m)
+
\sum_m w_m\{\mathbb{E}(Y\mid m)-\mathbb{E}(Y)\}^2.
$$

PSA에서 모형을 고정한 채 모수만 추출하면 두 번째 항이 누락된다. 후보 모형 자체를 확률적으로 추출하거나, 각 모형별 PSA 결과를 가중 결합해야 구조적 불확실성을 반영할 수 있다.

## 생존함수를 이용하여 마코프모델에 사용할 전이확률의 추정

### 생존함수와 조건부 전이확률

마코프모형에서는 주기별 전이확률이 필요하다. 생존함수 $S(t)$가 주어졌을 때, 시간 $t$까지 사건이 발생하지 않은 사람이 다음 주기 $[t,t+\Delta)$ 동안 사건을 경험할 조건부 확률은 다음과 같다.

$$
p(t,t+\Delta)=P(t\le T<t+\Delta\mid T\ge t).
$$

생존함수를 이용하면 다음과 같이 계산된다.

$$
p(t,t+\Delta)=1-\frac{S(t+\Delta)}{S(t)}.
$$

이 식은 생존함수에서 마코프 전이확률을 계산하는 핵심 공식이다.

![생존함수에서 주기별 전이확률로의 변환](figures/ch09/fig-ch09-survival-to-transition.png){fig-align="center" width="90%"}

그림에서 주기별 전이확률은 생존곡선의 절대 감소량이 아니라, 주기 시작 시점까지 사건 없이 남아 있는 사람을 분모로 한 조건부 감소율이다. 따라서 같은 생존확률 감소량이라도 위험집합의 크기에 따라 전이확률은 달라진다.

### 일정 위험률 가정의 특수한 경우

위험률이 주기 안에서 일정하게 $r$이라고 가정하면 생존함수는 다음과 같다.

$$
S(t)=\exp(-rt).
$$

따라서 주기 길이 $\Delta$의 전이확률은 다음과 같다.

$$
p=1-\exp(-r\Delta).
$$

이는 발생률 또는 위험률을 전이확률로 변환할 때 가장 자주 사용되는 식이다. 그러나 위험률이 시간에 따라 변하면 $r$을 단순히 전체 기간 평균값으로 사용하는 것은 부정확할 수 있다.

### 시간의존 전이확률

위험함수가 시간에 따라 변하는 경우 $[t,t+\Delta)$ 구간의 조건부 사건확률은 다음과 같다.

$$
p(t,t+\Delta)=1-\exp\left\{-\int_t^{t+\Delta}h(u)\,du\right\}.
$$

누적위험함수 $H(t)$를 이용하면 다음과 같이 쓸 수 있다.

$$
p(t,t+\Delta)=1-\exp[-\{H(t+\Delta)-H(t)\}].
$$

이 식은 Weibull, Gompertz, log-normal, log-logistic 등 모든 모수적 생존모형에 적용할 수 있다. 예를 들어 Weibull 모형에서

$$
H(t)=\left(\frac{t}{\lambda}\right)^k
$$

이므로 전이확률은 다음과 같다.

$$
p(t,t+\Delta)=1-\exp\left[-\left\{\left(\frac{t+\Delta}{\lambda}\right)^k-\left(\frac{t}{\lambda}\right)^k\right\}\right].
$$

### 경쟁위험이 있는 경우

하나의 상태에서 여러 사건으로 전이할 수 있다면 원인별 위험함수(cause-specific hazard)를 사용해야 한다. 예를 들어 무진행 상태에서 진행 또는 사망으로 전이할 수 있다면 각각의 위험함수를 $h_P(t)$와 $h_D(t)$라고 하자. 총 위험함수는 다음과 같다.

$$
h_{total}(t)=h_P(t)+h_D(t).
$$

구간 $[t,t+\Delta)$에서 사건 $r$로 전이할 확률은 다음과 같다.

$$
p_r(t,t+\Delta)=\int_t^{t+\Delta}\frac{S(u)}{S(t)}h_r(u)\,du,
$$

여기서 $S(u)/S(t)$는 시간 $t$까지 생존한 조건에서 $u$까지 어떤 사건도 발생하지 않을 조건부 생존확률이다. 구간 안에서 원인별 위험함수가 일정하다고 가정하면 다음과 같이 근사할 수 있다.

$$
p_r(t,t+\Delta)=\frac{h_r}{h_{total}}\left\{1-\exp(-h_{total}\Delta)\right\}.
$$

위 식은 구간 내 위험률이 일정할 때는 근사가 아니라 정확한 식이다. 각 원인별 사건확률의 합과 무사건확률은 다음 조건을 만족한다.

$$
\sum_r p_r(t,t+\Delta)
+
\exp(-h_{total}\Delta)
=1.
$$

원인별 위험을 각각 단순히 $1-\exp(-h_r\Delta)$로 변환하면 동일한 주기 안에서 여러 사건이 독립적으로 발생할 수 있는 것처럼 계산되어 확률의 합이 1을 초과할 수 있다.

### 다상태모형의 생성행렬

여러 상태 사이의 전이를 동시에 다룰 때는 전이강도행렬 $Q(t)$를 사용한다. 비대각 원소 $q_{rs}(t)$는 상태 $r$에서 $s$로의 순간 전이강도이고, 대각 원소는 행의 합이 0이 되도록 정의한다.

$$
q_{rr}(t)=-\sum_{s\ne r}q_{rs}(t).
$$

시간동질 모형에서 길이 $\Delta$의 전이확률행렬은 행렬지수로 계산한다.

$$
P(\Delta)=\exp\{Q\Delta\}.
$$

시간비동질 모형에서는 각 주기별 생성행렬을 이용하거나 곱적분을 계산해야 한다. 이 접근은 여러 경쟁 전이가 존재할 때 각 전이확률을 개별적으로 변환하는 것보다 확률 일관성을 보장한다.

### PFS와 OS를 이용한 분할생존모형의 상태 점유율

분할생존모형(partitioned survival model)에서는 PFS와 OS 생존함수를 이용하여 세 상태의 점유율을 계산한다. 무진행 상태, 진행 후 생존 상태, 사망 상태를 각각 PF, PD, Dead라고 하면 다음과 같다.

$$
P_{PF}(t)=S_{PFS}(t),
$$

$$
P_{Dead}(t)=1-S_{OS}(t),
$$

$$
P_{PD}(t)=S_{OS}(t)-S_{PFS}(t).
$$

이 식이 성립하려면 모든 시점에서 다음 조건이 필요하다.

$$
S_{OS}(t)\ge S_{PFS}(t).
$$

만약 독립적으로 적합한 PFS와 OS 외삽곡선이 장기에서 교차한다면 상태 점유율이 음수가 되는 문제가 발생한다. 따라서 PFS와 OS 외삽은 개별 곡선의 적합도뿐 아니라 두 곡선 사이의 논리적 일관성도 확인해야 한다.

분할생존모형은 시점별 상태점유율을 결정하지만 개별 환자의 진행 후 사망 경로를 명시적으로 생성하지 않는다. 따라서 PFS와 OS의 주변분포만으로는 진행시점과 사망시점의 결합분포가 식별되지 않는다. 동일한 $S_{PFS}(t)$와 $S_{OS}(t)$를 가지더라도 진행 후 생존기간의 분포는 서로 다를 수 있다.

경제성 결과가 진행 후 비용이나 효용의 지속기간에 민감하면, 다음의 질량보존 조건뿐 아니라 진행 후 생존에 대한 외부근거를 확인해야 한다.

$$
P_{PF}(t)+P_{PD}(t)+P_{Dead}(t)=1.
$$

PFS와 OS를 PSA에서 독립적으로 추출하면 곡선 교차와 상태점유율의 음수 문제가 반복될 수 있다. 임상시험에서 공동 추정된 모수 공분산을 이용하거나, 논리적 제약을 만족하는 공동 다상태모형으로부터 두 곡선을 생성하는 방법이 더 타당하다.

![PFS와 OS를 이용한 분할생존모형 상태 점유율](figures/ch09/fig-ch09-partitioned-survival-states.png){fig-align="center" width="90%"}

이 그림에서 PFS 곡선 아래 영역은 무진행 상태, OS와 PFS 사이의 영역은 진행 후 생존 상태, OS 위쪽 영역은 사망 상태에 해당한다. 두 생존곡선을 독립적으로 외삽하면 장기에서 PFS가 OS보다 높아지는 논리적 모순이 생길 수 있으므로 공동 제약이 필요하다.

## 실무 예제: 생존외삽 결과가 ICER에 미치는 영향

생존외삽 모형 선택은 기대 생존기간과 QALY를 바꾸고, 이는 ICER에 직접적인 영향을 준다. 예를 들어 신약이 기존 치료보다 관찰기간 안에서는 유사한 생존편익을 보이지만, log-logistic 모형이 장기 꼬리를 크게 예측하면 증분 QALY가 커져 ICER가 낮아질 수 있다. 반대로 치료효과 소실 가정을 적용하면 증분 QALY가 줄어 ICER가 높아질 수 있다.

증분비용을 $\Delta C$, 증분 QALY를 $\Delta Q$라고 하면 ICER는 다음과 같다.

$$
ICER=\frac{\Delta C}{\Delta Q}.
$$

여기서 $\Delta Q$는 외삽된 생존함수에 크게 의존한다.

$$
\Delta Q=
\int_0^\tau \{u_1(t)S_1(t)-u_0(t)S_0(t)\}\,dt.
$$

따라서 생존외삽 모형의 차이가 작아 보이더라도 분석기간 전체의 면적 차이는 크게 누적될 수 있다.

증분 QALY를 관찰구간과 외삽구간으로 분해하면 결과가 어느 부분에서 발생하는지 확인할 수 있다.

$$
\Delta Q
=
\underbrace{\int_0^{t_{\max}}
\{u_1(t)S_1(t)-u_0(t)S_0(t)\}\,dt}_{\Delta Q_{obs}}
+
\underbrace{\int_{t_{\max}}^{\tau}
\{u_1(t)S_1(t)-u_0(t)S_0(t)\}\,dt}_{\Delta Q_{ext}}.
$$

$\Delta Q_{ext}$가 전체 증분 QALY의 대부분을 차지한다면 비용효과성 결론은 관찰된 임상효과보다 외삽 가정에 더 의존한다. 이 경우 모형별 $\Delta Q_{obs}$와 $\Delta Q_{ext}$를 별도로 보고하면 의사결정자가 근거의 위치를 명확히 파악할 수 있다.

### 모수 불확실성의 전파

각 생존모형의 모수벡터를 $\theta$라고 하면 기대 QALY는 $Q(\theta)$라는 비선형 함수이다. 델타방법에 의한 근사분산은 다음과 같다.

$$
\operatorname{Var}\{Q(\widehat\theta)\}
\approx
\nabla Q(\widehat\theta)^\top
\operatorname{Var}(\widehat\theta)
\nabla Q(\widehat\theta).
$$

실제 PSA에서는 $\theta^{(b)}$를 다변량 정규근사, 부트스트랩 또는 베이지안 사후분포에서 공동 추출한 뒤 각 반복에서 생존곡선과 QALY를 다시 계산한다. shape와 scale 모수의 상관성을 무시한 독립 추출은 장기 꼬리의 불확실성을 과대 또는 과소평가할 수 있다.

![외삽모형 선택이 ICER에 미치는 영향 예시](figures/ch09/fig-ch09-icer-impact.png){fig-align="center" width="85%"}

이 그림은 외삽모형이 증분비용을 직접 바꾸지 않더라도 증분 QALY의 분모를 변화시켜 ICER를 크게 이동시킬 수 있음을 보여준다. 특히 증분 QALY가 작을 때에는 꼬리 영역의 작은 차이가 비율척도에서 크게 증폭된다.

fit_exponential <- function(time, status) {
  rate <- sum(status) / sum(time)
  loglik <- sum(status * log(rate) - rate * time)
  list(dist = "Exponential", par = c(rate = rate), logLik = loglik, npar = 1)
}

fit_weibull <- function(time, status) {
  nll <- function(lp) {
    k <- exp(lp[1])
    lambda <- exp(lp[2])
    log_h <- log(k) - log(lambda) + (k - 1) * (log(time) - log(lambda))
    H <- (time / lambda)^k
    -sum(status * log_h - H)
  }
  opt <- optim(c(log(1), log(median(time))), nll, method = "BFGS")
  k <- exp(opt$par[1])
  lambda <- exp(opt$par[2])
  list(dist = "Weibull", par = c(shape = k, scale = lambda), logLik = -opt$value, npar = 2)
}

fit_lognormal <- function(time, status) {
  nll <- function(par) {
    mu <- par[1]
    sigma <- exp(par[2])
    z <- (log(time) - mu) / sigma
    log_f <- dnorm(z, log = TRUE) - log(time) - log(sigma)
    log_S <- pnorm(z, lower.tail = FALSE, log.p = TRUE)
    -sum(status * log_f + (1 - status) * log_S)
  }
  opt <- optim(c(mean(log(time)), log(sd(log(time)))), nll, method = "BFGS")
  list(dist = "Log-normal", par = c(mu = opt$par[1], sigma = exp(opt$par[2])), logLik = -opt$value, npar = 2)
}

fit_loglogistic <- function(time, status) {
  nll <- function(lp) {
    k <- exp(lp[1])
    lambda <- exp(lp[2])
    z <- exp(k * (log(time) - log(lambda)))
    log_S <- -log1p(z)
    log_f <- log(k) - log(lambda) + (k - 1) * (log(time) - log(lambda)) - 2 * log1p(z)
    -sum(status * log_f + (1 - status) * log_S)
  }
  opt <- optim(c(log(1.2), log(median(time))), nll, method = "BFGS")
  list(dist = "Log-logistic", par = c(shape = exp(opt$par[1]), scale = exp(opt$par[2])), logLik = -opt$value, npar = 2)
}

fit_all <- function(time, status) {
  fits <- list(
    fit_exponential(time, status),
    fit_weibull(time, status),
    fit_lognormal(time, status),
    fit_loglogistic(time, status)
  )
  out <- data.frame(
    dist = sapply(fits, `[[`, "dist"),
    logLik = sapply(fits, `[[`, "logLik"),
    npar = sapply(fits, `[[`, "npar")
  )
  out$AIC <- -2 * out$logLik + 2 * out$npar
  out$BIC <- -2 * out$logLik + out$npar * log(length(time))
  list(summary = out[order(out$AIC), ], fits = fits)
}

new_fit <- with(subset(dat, treatment == "New"), fit_all(time, status))

surv_fun <- function(fit, t) {
  p <- fit$par
  if (fit$dist == "Exponential") {
    exp(-p["rate"] * t)
  } else if (fit$dist == "Weibull") {
    exp(-(t / p["scale"])^p["shape"])
  } else if (fit$dist == "Log-normal") {
    pnorm((log(t) - p["mu"]) / p["sigma"], lower.tail = FALSE)
  } else if (fit$dist == "Log-logistic") {
    1 / (1 + (t / p["scale"])^p["shape"])
  } else {
    stop("Unknown distribution")
  }
}

rmst_numeric <- function(fit, tau = 120, step = 0.1) {
  grid <- seq(0.001, tau, by = step)
  s <- surv_fun(fit, grid)
  sum((s[-1] + s[-length(s)]) / 2) * step
}

time_grid <- seq(0.1, 120, by = 0.5)

best_control <- control_fit$fits[[match(control_fit$summary$dist[1], sapply(control_fit$fits, `[[`, "dist"))]]
best_new <- new_fit$fits[[match(new_fit$summary$dist[1], sapply(new_fit$fits, `[[`, "dist"))]]

     ylim = c(0, 1), xlab = "Time (months)", ylab = "Survival probability")

legend("topright", legend = c(paste("Control:", best_control$dist), paste("New:", best_new$dist)),
       lty = c(1, 2), lwd = c(1, 2), bty = "n")
