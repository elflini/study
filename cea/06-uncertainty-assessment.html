6.1 기본 분석

기본 분석(base-case analysis)은 분석자가 사전에 정한 가장 타당한 자료원, 모형 구조, 분석 기간, 할인율, 비용 범위, 건강결과 지표, 모수 값을 이용해 산출한 중심 결과이다. 기본 분석은 여러 시나리오 중 하나가 아니라, 의사결정자가 가장 먼저 검토하는 기준 결과이다. 따라서 기본 분석에는 분석자의 최선의 과학적 판단이 반영되어야 하며, 편의에 따라 비용효과성이 좋아 보이는 가정을 선택해서는 안 된다.

전략 집합을 \(\mathcal{J}\)라고 하자. 기존 치료를 \(j=0\), 신약 치료를 \(j=1\)로 표시한다. 전략 \(j\)의 기대비용과 기대 QALY를 각각 \(\mu_{C,j}\), \(\mu_{Q,j}\)라고 하면 다음과 같이 정의할 수 있다.

\[ \mu_{C,j}=\mathbb{E}(C_j), \qquad \mu_{Q,j}=\mathbb{E}(Q_j). \]

신약의 증분비용과 증분 QALY는 다음과 같다.

\[ \Delta C=\mu_{C,1}-\mu_{C,0}, \qquad \Delta Q=\mu_{Q,1}-\mu_{Q,0}. \]

\(\Delta Q \ne 0\)이면 ICER는 다음과 같이 정의된다.

\[ ICER=\frac{\Delta C}{\Delta Q}. \]

지불의사금액을 \(\lambda\)라고 하면 증분순편익(incremental net benefit, INB)은 다음과 같다.

\[ INB(\lambda)=\lambda\Delta Q-\Delta C. \]

\(\Delta Q>0\)이고 \(\Delta C>0\)인 상황에서는 \(ICER<\lambda\)와 \(INB(\lambda)>0\)이 동등하다. 그러나 \(\Delta Q\)가 0에 가깝거나 음수인 경우, ICER는 해석이 어려워질 수 있다. 이 때문에 불확실성 분석에서는 ICER보다 순편익 척도를 사용하는 것이 수학적으로 더 안정적이다.

경제성 평가의 기본 의사결정은 통계적 가설검정과 다르다. 의사결정자는 귀무가설의 기각 여부가 아니라, 현재 이용 가능한 정보에서 기대순편익이 가장 큰 전략을 선택한다. 전략이 두 개보다 많을 때 전략 \(j\)의 순편익을

\[ NB_j(\lambda,\theta)=\lambda Q_j(\theta)-C_j(\theta) \]

라고 하면, 현재 정보하의 최적 전략은 다음과 같다.

\[ j^*(\lambda)=\arg\max_{j\in\mathcal{J}} \mathbb{E}_{\theta}\{NB_j(\lambda,\theta)\}. \]

따라서 어떤 전략의 비용효과확률이 가장 높다는 사실과 그 전략의 기대순편익이 가장 크다는 사실은 반드시 일치하지 않는다. 급여 의사결정은 비용효과확률 자체가 아니라 기대순편익 최대화 원칙에 기반해야 한다.

ImportantICER와 순편익의 차이

ICER는 비율이므로 분모인 \(\Delta Q\)가 0에 가까우면 매우 불안정해진다. 반면 \(INB(\lambda)=\lambda\Delta Q-\Delta C\)는 선형 함수이므로 확률분포, 평균, 분산, 회귀모형, PSA 결과를 다루기 쉽다. 경제성 평가의 의사결정 규칙은 가능하면 순편익 척도로 표현하는 것이 좋다.

기본 분석에서 사용한 모수 벡터를 \(\theta_0\)라고 하자. 경제성 평가 모형을 \(M(\theta)\)로 표시하면 기본 분석은 다음과 같은 plug-in 계산이다.

\[ \widehat{\mu}_{C,j}^{\,0}=\mu_{C,j}(\theta_0), \qquad \widehat{\mu}_{Q,j}^{\,0}=\mu_{Q,j}(\theta_0). \]

이 결과로부터 \(\widehat{\Delta C}^{\,0}\), \(\widehat{\Delta Q}^{\,0}\), \(\widehat{ICER}^{\,0}\), \(\widehat{INB}^{\,0}(\lambda)\)가 계산된다. 여기서 위첨자 0은 기본 분석에서 선택한 중심값을 사용했다는 뜻이다.

기본 분석의 plug-in 결과와 불확실성을 평균한 기대 결과는 구분해야 한다. 일반적으로 비선형 함수 \(g(\theta)\)에 대해서는

\[ g\{\mathbb{E}(\theta)\}\ne \mathbb{E}\{g(\theta)\} \]

가 성립한다. ICER는 비선형 비율이므로 중심 모수에서 계산한 ICER와 PSA에서 산출된 결과를 단순 평균한 값은 서로 다를 수 있다. 반면 순편익은 비용과 효과의 선형결합이므로 기대값의 계산과 전략 간 비교가 상대적으로 안정적이다. 다만 비용과 효과 자체가 모수의 비선형 함수라면, 중심 모수를 대입한 순편익과 PSA 평균 순편익도 달라질 수 있다. 이 차이는 모형의 비선형성과 모수 불확실성이 결합하여 발생한다.

예제: 기본 분석 결과의 계산

신약과 기존 치료의 기대비용과 기대 QALY가 다음과 같다고 하자.

전략 기대비용 기대 QALY
기존 치료 30,000,000원 2.40
신약 치료 45,000,000원 2.90

증분비용과 증분 QALY는 다음과 같다.

\[ \Delta C=45,000,000-30,000,000=15,000,000, \]

\[ \Delta Q=2.90-2.40=0.50. \]

따라서 ICER는 다음과 같다.

\[ ICER=\frac{15,000,000}{0.50}=30,000,000\text{원/QALY}. \]

지불의사금액이 QALY당 50,000,000원이라면 증분순편익은 다음과 같다.

\[ INB(50,000,000)=50,000,000\times0.50-15,000,000=10,000,000. \]

이 기본 분석에서는 신약 치료가 비용효과적인 것으로 판단된다.

기본 분석 결과는 하나의 점이다. 그러나 이 점은 자료의 불확실성, 모형 구조의 불확실성, 모수 간 상관성, 환자 특성에 따른 이질성을 보여주지 않는다. 경제성 평가는 기본 분석 결과와 함께 불확실성 분석 결과를 제시해야 한다.

위 그림에서 기본 분석 점과 지불의사금액 기준선 사이의 수직거리는 통화 단위의 순편익과 직접 같지는 않지만, 점이 기준선의 어느 쪽에 위치하는지는 순편익의 부호와 일치한다. 점이 기준선에 가까울수록 작은 모수 변화에도 의사결정이 바뀔 가능성이 크므로, 기본 분석의 위치만 아니라 점 주변의 불확실성 분포를 함께 살펴야 한다.

6.2 변동성, 이질성, 불확실성

경제성 평가에서 “불확실성”이라는 용어는 넓게 사용되지만, 실제로는 서로 다른 개념을 포함한다. 특히 변동성(variability), 이질성(heterogeneity), 모수 불확실성(parameter uncertainty), 모형 불확실성(structural uncertainty)을 구분하는 것이 중요하다. 이 구분을 잘못하면 PSA에 넣어야 할 것을 하위군 분석으로 처리하거나, 하위군별 의사결정을 해야 할 것을 단순 민감도 분석으로만 처리하는 오류가 생긴다.

이 구분은 우연적 불확실성(aleatory uncertainty)과 인식론적 불확실성(epistemic uncertainty)의 구분과도 연결된다. 개인별 사건 발생과 비용의 무작위성은 우연적 변동에 가깝고, 치료효과나 생존모형 모수를 충분히 알지 못하는 문제는 인식론적 불확실성에 가깝다. 전자는 더 많은 환자를 관찰해도 개인 수준에서는 사라지지 않지만, 후자는 추가 연구와 자료 축적으로 줄일 수 있다. 구조적 불확실성은 어떤 상태구조나 외삽함수가 실제 현상을 가장 잘 나타내는지 알지 못한다는 점에서 인식론적 불확실성의 한 형태이다.

환자 \(i\)의 결과를 \(Y_i\), 환자 특성 벡터를 \(X_i\), 모수 벡터를 \(\theta\)라고 하자. 일반적으로 결과는 다음과 같이 표현할 수 있다.

\[ Y_i=m(X_i;\theta)+\varepsilon_i. \]

여기서 \(m(X_i;\theta)=\mathbb{E}(Y_i\mid X_i,\theta)\)는 환자 특성에 따른 조건부 평균이고, \(\varepsilon_i\)는 같은 특성을 가진 환자들 사이에서도 남아 있는 개인 수준 변동이다.

변동성

변동성은 개인 간에 실제로 존재하는 자연스러운 차이이다. 같은 치료를 받은 환자라도 생존기간, 비용, 효용, 이상반응 경험은 서로 다를 수 있다. 변동성은 표본 수가 무한히 커져도 사라지지 않는다. 예를 들어 비용자료에서 개인별 총 비용 \(C_i\)가 다음과 같은 분포를 따른다고 하자.

\[ C_i\mid X_i=x \sim F_C(c\mid x). \]

이 분포의 폭은 실제 환자 간 비용 차이를 나타낸다. PSA는 보통 모수의 불확실성을 평가하는 방법이지, 개인 간 변동성을 그대로 반복해서 평균 비용의 불확실성으로 해석하는 방법이 아니다. 환자 수준 시뮬레이션에서는 개인 간 변동성과 모수 불확실성을 구분하여 1차 불확실성(first-order uncertainty)과 2차 불확실성(second-order uncertainty)으로 나누어 다루는 것이 좋다.

이질성

이질성은 환자 특성에 따라 평균 비용이나 평균 효과가 체계적으로 달라지는 현상이다. 예를 들어 바이오마커 양성 환자에서 치료효과가 더 크거나, 고위험군에서 기준 사건위험이 높아 절대효과가 커지는 경우가 이에 해당한다.

하위군 \(X=x\)에서의 증분 QALY와 증분비용은 다음과 같이 표현할 수 있다.

\[ \Delta Q(x)=\mu_{Q,1}(x)-\mu_{Q,0}(x), \qquad \Delta C(x)=\mu_{C,1}(x)-\mu_{C,0}(x). \]

따라서 조건부 증분순편익은 다음과 같다.

\[ INB(\lambda\mid X=x)=\lambda\Delta Q(x)-\Delta C(x). \]

이질성이 크면 전체 모집단에서의 평균 결과만으로는 충분하지 않다. 특정 하위군에 대해서만 급여하거나, 위험도 기반으로 치료 대상을 제한하는 의사결정이 필요할 수 있다.

모수 불확실성

모수 불확실성은 치료효과, 비용, 효용, 전이확률, 생존모형 계수 등 모수의 참값을 정확히 알지 못해서 발생한다. 모수 \(\theta\)가 알려져 있지 않을 때 분석자는 추정값 \(\widehat{\theta}\)와 표준오차, 공분산행렬, 또는 사후분포를 이용한다.

빈도론적 관점에서는 다음과 같은 근사를 사용할 수 있다.

\[ \widehat{\theta}\approx N(\theta,\Sigma_{\widehat{\theta}}). \]

PSA에서는 이 식을 실무적으로 뒤집어 다음과 같이 모수 후보값을 추출한다.

\[ \theta^{(s)}\sim N(\widehat{\theta},\widehat{\Sigma}_{\widehat{\theta}}), \qquad s=1,\ldots,S. \]

베이지안 관점에서는 모수의 불확실성을 사후분포로 직접 표현한다.

\[ p(\theta\mid y)\propto p(y\mid\theta)p(\theta). \]

전체 분산의 법칙과 개념적 구분

변동성과 이질성은 전체 분산의 법칙을 이용하면 더 명확해진다.

\[ \operatorname{Var}(Y)=\mathbb{E}\{\operatorname{Var}(Y\mid X)\}+\operatorname{Var}\{\mathbb{E}(Y\mid X)\}. \]

첫 번째 항은 같은 특성을 가진 환자들 사이의 남은 변동성이고, 두 번째 항은 환자 특성 \(X\)에 따라 평균 결과가 달라지는 이질성이다. 여기에 \(\theta\)의 불확실성과 모델 구조의 불확실성이 추가되면 경제성 평가의 전체 불확실성이 된다.

모수 불확실성까지 포함하면 분산을 한 단계 더 분해할 수 있다. 모형 구조를 고정하고 \(X\)와 \(\theta\)가 모두 불확실하다고 하면,

\[ \operatorname{Var}(Y) = \mathbb{E}_{\theta}\!\left[ \mathbb{E}_{X}\{\operatorname{Var}(Y\mid X,\theta)\} + \operatorname{Var}_{X}\{\mathbb{E}(Y\mid X,\theta)\} \right] + \operatorname{Var}_{\theta}\{\mathbb{E}(Y\mid\theta)\}. \]

오른쪽의 세 항은 각각 개인 수준 변동성, 관찰 가능한 환자 특성에 따른 이질성, 모수 불확실성을 나타낸다. 모형 구조 \(M\)까지 불확실하면 마지막에 \(\operatorname{Var}_M\{\mathbb{E}(Y\mid M)\}\)에 해당하는 구조적 변동이 추가된다. 이 분해는 모든 불확실성을 하나의 PSA 분포에 무차별적으로 섞지 말아야 하는 이유를 보여준다.

위 그림의 범주들은 서로 배타적이지 않다. 예를 들어 환자 위험도의 차이는 관찰 가능한 특성으로 설명되면 이질성이지만, 위험도 분포를 정확히 추정하지 못한 부분은 모수 불확실성이다. 또한 치료효과 소실을 어떤 함수로 표현할지의 문제는 구조적 불확실성이며, 선택한 함수의 계수 추정오차는 그 구조 안의 모수 불확실성이다. 따라서 불확실성의 원인과 분석 방법을 일대일로 대응시켜야 한다.

Note실무적 구분

변동성은 “환자들이 실제로 다르다”는 문제이고, 이질성은 “어떤 환자군에서 평균 결과가 체계적으로 다르다”는 문제이며, 불확실성은 “우리가 모수나 모형을 충분히 알지 못한다”는 문제이다. 더 많은 연구로 줄일 수 있는 것은 주로 모수 불확실성이다.

6.3 결정론적 민감도 분석

결정론적 민감도 분석(deterministic sensitivity analysis, DSA)은 하나 또는 몇 개의 입력값을 사전에 정한 범위 안에서 변화시키고, 경제성 평가 결과가 어떻게 달라지는지 확인하는 방법이다. DSA는 특정 입력값이 결론에 미치는 영향을 직관적으로 보여주는 장점이 있다.

기본 분석 모수 벡터를 \(\theta_0=(\theta_{1,0},\ldots,\theta_{K,0})\)라고 하자. 일원 민감도 분석(one-way sensitivity analysis)은 \(k\)번째 모수만 낮은 값 \(\theta_k^-\) 또는 높은 값 \(\theta_k^+\)로 바꾸고 나머지는 기본값으로 고정한다.

\[ INB_k^-(\lambda)=INB(\lambda;\theta_{1,0},\ldots,\theta_k^-,\ldots,\theta_{K,0}), \]

\[ INB_k^+(\lambda)=INB(\lambda;\theta_{1,0},\ldots,\theta_k^+,\ldots,\theta_{K,0}). \]

모수 \(k\)가 결과에 미치는 영향은 다음과 같이 요약할 수 있다.

\[ W_k=\left|INB_k^+(\lambda)-INB_k^-(\lambda)\right|. \]

\(W_k\)가 클수록 해당 모수는 결과에 큰 영향을 준다. 여러 모수의 \(W_k\)를 큰 순서로 정렬해 그리면 토네이도 그림이 된다.

일원 민감도 분석은 전역 범위의 변화량을 보여주지만, 국소 민감도는 편미분으로 표현할 수 있다.

\[ S_k=\left.\frac{\partial INB(\lambda;\theta)}{\partial\theta_k}\right|_{\theta=\theta_0}. \]

모수의 단위가 서로 다르면 절대 미분값을 직접 비교하기 어렵다. 이때는 탄력도 형태의 무차원 민감도 지표를 사용할 수 있다.

\[ E_k= \left.\frac{\partial INB}{\partial\theta_k} \frac{\theta_k}{INB}\right|_{\theta=\theta_0}. \]

다만 \(INB\)가 0에 가까우면 탄력도가 불안정하므로 해석에 주의해야 한다. 또한 토네이도 막대가 길다는 것은 지정한 범위에서 결과 변화가 크다는 뜻이지, 그 모수가 전체 의사결정 불확실성에 가장 많이 기여한다는 뜻은 아니다. 전체 분산 기여도는 PSA 기반 분산분해나 EVPPI와 같은 별도 분석으로 평가해야 한다.

위 토네이도 그림은 기본값을 중심으로 각 모수를 한 번에 하나씩 변화시킨 결과이다. 막대의 양 끝이 모두 0보다 크면 지정한 범위에서는 의사결정이 바뀌지 않고, 막대가 0을 가로지르면 그 모수의 가능한 범위 안에서 비용효과성 판단이 역전될 수 있다. 막대 길이는 범위의 폭에도 의존하므로, 서로 다른 근거로 정한 범위를 사용할 때는 단순 순위 비교를 과도하게 해석하지 않아야 한다.

민감도 분석 범위의 설정

DSA에서 가장 중요한 실무적 판단은 입력값의 범위이다. 범위는 임의로 정하면 안 되며, 가능한 한 다음 근거를 사용해야 한다.

  • 추정치의 95% 신뢰구간 또는 credible interval
  • 메타분석 또는 네트워크 메타분석의 예측구간
  • 임상 전문가가 판단한 임상적으로 가능한 범위
  • 국내 단가, 약가, 진료패턴의 plausible range
  • 생존외삽, 치료효과 지속, 할인율과 같은 구조적 가정의 대안 시나리오

모수 불확실성에 해당하는 범위는 PSA의 확률분포와 일관되어야 한다. 반면 구조적 가정은 단순히 확률분포를 부여하기보다 시나리오 분석으로 제시하는 것이 더 투명할 수 있다.

신뢰구간의 양 끝을 그대로 낮은 값과 높은 값으로 사용하는 관행도 항상 적절한 것은 아니다. 신뢰구간은 추정량의 불확실성을 나타내지만, 임상적으로 가능한 범위나 미래 환경에서의 변화 범위와 동일하지 않다. 비용 단가처럼 정책적으로 조정 가능한 입력은 정책 범위를, 치료효과처럼 추정된 모수는 통계적 불확실성 범위를, 치료효과 지속기간처럼 구조적 가정은 임상적으로 타당한 대안 시나리오를 사용하는 것이 합리적이다.

역치 분석

역치 분석(threshold analysis)은 특정 모수가 어떤 값을 가질 때 의사결정이 바뀌는지 찾는 방법이다. 예를 들어 어떤 모수 \(\theta_k\)에 대해 \(INB(\lambda;\theta_k)=0\)을 만족하는 값을 \(\theta_k^*\)라고 하면, 이 값은 비용효과성 판단의 경계가 된다.

\[ INB(\lambda;\theta_k^*)=0. \]

만약 \(INB\)가 \(\theta_k\) 근처에서 선형이라고 근사할 수 있으면,

\[ INB(\lambda;\theta_k)\approx a+b\theta_k \]

이고 역치값은 다음과 같다.

\[ \theta_k^*=-\frac{a}{b}. \]

실무에서는 약가, 투약기간, 치료효과 지속기간, 효용 차이, 사망률 등의 역치값이 정책적으로 유용할 수 있다. 예를 들어 “신약의 월 약가가 어느 수준 이하이면 비용효과적인가?” 또는 “치료효과가 몇 년 이상 유지되어야 비용효과적인가?”와 같은 질문에 답할 수 있다.

이원 민감도 분석

이원 민감도 분석(two-way sensitivity analysis)은 두 입력값을 동시에 변화시킨다. 예를 들어 치료효과와 약가를 함께 변화시키면, 어떤 조합에서 신약이 비용효과적인지 시각적으로 확인할 수 있다.

위 그림의 경계선은 \(INB(\lambda;\theta_1,\theta_2)=0\)을 만족하는 모수 조합이다. 경계선이 직선이 아니면 두 모수가 결과에 비선형적으로 작용하거나 상호작용한다는 뜻이다. 두 모수의 결합효과는 국소적으로 다음 교차편미분으로 평가할 수 있다.

\[ \frac{\partial^2 INB}{\partial\theta_1\partial\theta_2}. \]

이 값이 0이 아니면 한 모수의 영향이 다른 모수의 수준에 따라 달라진다. 따라서 이원 민감도 분석은 단순히 두 개의 일원 분석을 겹친 것이 아니라, 모수 간 상호작용과 의사결정 경계를 확인하는 분석이다.

DSA는 결과를 설명하기 쉽지만, 여러 모수가 동시에 불확실하다는 사실을 충분히 반영하지 못한다. 특히 모수들 간 상관성이 있거나 비선형 모형에서 여러 입력값이 함께 변할 때는 DSA만으로 의사결정 불확실성을 평가하기 어렵다. 이를 보완하기 위해 PSA가 필요하다.

6.4 확률론적 민감도 분석

확률론적 민감도 분석(probabilistic sensitivity analysis, PSA)은 불확실한 모수에 확률분포를 부여하고, 그 분포에서 반복적으로 모수를 추출하여 경제성 평가 결과의 분포를 계산하는 방법이다. PSA는 여러 모수의 불확실성을 동시에 반영하며, 비용효과평면, 비용효과수용곡선, 순편익 분포를 통해 의사결정 불확실성을 표현한다.

모수 벡터를 \(\theta\)라고 하고, 그 불확실성 분포를 \(G(\theta)\)라고 하자. PSA는 다음 절차로 수행된다.

여기서 \(G(\theta)\)는 개별 입력분포의 단순한 곱이 아니라, 가능한 경우 모수 간 상관성을 포함하는 결합분포이어야 한다. PSA의 목적은 입력 모수의 불확실성을 모형의 결과로 전파하는 것이다. 수학적으로는 모형 출력 \(h(\theta)\)의 유도분포를

\[ F_h(z)=\int I\{h(\theta)\le z\}\,dG(\theta) \]

와 같이 평가하는 과정으로 볼 수 있다. 실제로 이 적분은 해석적으로 계산하기 어려우므로 Monte Carlo 표본으로 근사한다.

  1. 불확실한 모수와 그 분포 \(G(\theta)\)를 정의한다.
  2. \(s=1,\ldots,S\)에 대해 \(\theta^{(s)}\sim G(\theta)\)를 추출한다.
  3. 각 추출값에서 모형을 실행하여 \(\Delta C^{(s)}\), \(\Delta Q^{(s)}\)를 계산한다.
  4. 각 반복에서 \(INB^{(s)}(\lambda)=\lambda\Delta Q^{(s)}-\Delta C^{(s)}\)를 계산한다.
  5. \(INB^{(s)}(\lambda)>0\)인 비율로 비용효과확률을 추정한다.

PSA 기반 비용효과확률은 다음과 같다.

\[ \widehat{P}_{CE}(\lambda)=\frac{1}{S}\sum_{s=1}^{S} I\{INB^{(s)}(\lambda)>0\}. \]

여기서 \(I(\cdot)\)는 조건이 참이면 1, 거짓이면 0인 지시함수이다. 이 값을 여러 \(\lambda\) 값에 대해 계산하면 비용효과수용곡선(cost-effectiveness acceptability curve, CEAC)이 된다.

PSA에서 평균 증분순편익은 다음과 같이 추정한다.

\[ \widehat{\mathbb{E}}\{INB(\lambda)\}=\frac{1}{S}\sum_{s=1}^{S} INB^{(s)}(\lambda). \]

Monte Carlo 반복 수가 충분하지 않으면 PSA 결과 자체에도 시뮬레이션 오차가 남는다. 비용효과확률의 Monte Carlo 표준오차는 다음과 같이 근사할 수 있다.

\[ SE_{MC}\{\widehat{P}_{CE}(\lambda)\}=\sqrt{\frac{\widehat{P}_{CE}(\lambda)\{1-\widehat{P}_{CE}(\lambda)\}}{S}}. \]

따라서 CEAC의 값이 0.50 근처이고 반복 수가 적으면, 단순한 Monte Carlo 오차만으로도 결과가 흔들릴 수 있다.

평균 증분순편익의 Monte Carlo 표준오차는 PSA 반복값의 표준편차를 이용해 다음과 같이 추정한다.

\[ SE_{MC}\{\overline{INB}(\lambda)\} = \frac{s_{INB}(\lambda)}{\sqrt{S}}. \]

독립 추출이라면 중심극한정리에 따라

\[ \sqrt{S}\left[\overline{INB}(\lambda)- \mathbb{E}\{INB(\lambda)\}\right] \xrightarrow{d} N\left(0,\operatorname{Var}\{INB(\lambda)\}\right). \]

따라서 반복 수는 관행적으로 정하기보다 주요 의사결정 지표의 Monte Carlo 표준오차가 충분히 작아질 때까지 늘리는 것이 바람직하다. MCMC 사후표본을 사용하는 경우 표본 간 자기상관 때문에 명목 반복 수 대신 유효표본크기를 사용해야 한다.

WarningICER 평균을 계산하지 말 것

PSA 반복마다 \(ICER^{(s)}=\Delta C^{(s)}/\Delta Q^{(s)}\)를 계산할 수는 있지만, \(ICER^{(s)}\)의 평균은 일반적으로 의미 있는 의사결정 척도가 아니다. \(\Delta Q^{(s)}\)가 0에 가까운 반복에서 비율이 폭발할 수 있기 때문이다. PSA 결과는 평균 비용, 평균 QALY, INB, CE plane, CEAC 중심으로 보고하는 것이 좋다.

위 비용효과평면의 점 구름은 증분비용과 증분효과의 주변분포뿐 아니라 두 결과의 상관성도 보여준다. 점 구름이 길고 기울어진 형태라면 비용과 효과가 강하게 연관되어 있음을 뜻한다. 사분면별 점의 비율은 신약이 더 효과적이면서 더 비싼지, 우월하거나 열등한지에 대한 확률적 정보를 제공하지만, 최종 의사결정은 각 점의 순편익과 그 평균에 기반해야 한다.

위 곡선의 높이는 효과가 통계적으로 유의할 확률이 아니라, 주어진 지불의사금액에서 순편익이 가장 큰 전략이 될 확률을 나타낸다. 곡선이 0.5를 넘는 지점은 기대순편익의 부호가 바뀌는 역치와 반드시 일치하지 않으며, 여러 전략을 비교할 때는 가장 높은 CEAC를 기계적으로 선택해서는 안 된다.

비용효과수용곡선, 수용경계와 기대손실

두 전략을 비교할 때 CEAC는 \(P\{INB(\lambda)>0\}\)를 나타낸다. 전략이 여러 개라면 전략 \(j\)의 비용효과수용곡선은 해당 전략의 순편익이 모든 전략 중 가장 큰 확률로 정의할 수 있다.

\[ CEAC_j(\lambda) = P\left[ NB_j(\lambda,\theta)=\max_{k\in\mathcal{J}}NB_k(\lambda,\theta) \right]. \]

그러나 가장 높은 비용효과확률을 가진 전략이 기대순편익이 가장 큰 전략과 다를 수 있다. 비용효과수용경계(cost-effectiveness acceptability frontier, CEAF)는 각 \(\lambda\)에서 기대순편익을 최대화하는 전략 \(j^*(\lambda)\)의 최적일 확률을 표시한다.

\[ CEAF(\lambda)=CEAC_{j^*(\lambda)}(\lambda). \]

의사결정의 불확실성은 기대기회손실로도 표현할 수 있다. 현재 전략 \(j\)를 선택했을 때 모수값 \(\theta\)에서의 기회손실은

\[ OL_j(\theta,\lambda) = \max_k NB_k(\theta,\lambda)-NB_j(\theta,\lambda) \]

이고, 기대기회손실은 \(\mathbb{E}_{\theta}\{OL_j(\theta,\lambda)\}\)이다. 기대순편익을 최대화하는 전략은 기대기회손실을 최소화하는 전략과 같다. CEAC는 선택의 확률을 보여주고, 기대기회손실은 잘못된 선택이 초래하는 결과의 크기까지 반영한다.

1차 불확실성과 2차 불확실성

환자 수준 시뮬레이션에서는 1차 불확실성과 2차 불확실성을 구분해야 한다. 1차 불확실성은 같은 모수값 아래에서도 환자 경로가 무작위로 달라지는 개인 수준 변동이다. 2차 불확실성은 모수 \(\theta\)의 참값을 알지 못하는 데서 생기는 불확실성이다.

경제성 평가의 의사결정은 보통 현재 모수 불확실성하에서 기대값이 가장 큰 전략을 선택하는 문제이다. 따라서 PSA에서는 2차 불확실성을 반영하는 것이 핵심이다. 환자 수준 모델에서 각 PSA 반복마다 환자 수가 너무 적으면 1차 Monte Carlo 오차가 2차 모수 불확실성과 섞인다. 이를 줄이려면 각 모수 추출값에서 충분히 많은 환자를 시뮬레이션하거나, common random numbers를 사용하거나, 코호트 모델과 환자 수준 모델의 결과를 검증해야 한다.

중첩 시뮬레이션을 수식으로 나타내면, 외부 반복에서 모수 \(\theta^{(s)}\)를 추출하고 내부 반복에서 환자 결과 \(Y_{sr}\)를 생성한다.

\[ \theta^{(s)}\sim G(\theta),\qquad Y_{sr}\sim p(y\mid\theta^{(s)}), \qquad r=1,\ldots,R. \]

각 외부 반복의 조건부 평균은

\[ \overline{Y}_s=\frac{1}{R}\sum_{r=1}^{R}Y_{sr} \]

로 추정한다. \(R\)이 작으면 \(\overline{Y}_s\)의 변동에 1차 오차가 크게 남고, 이것이 모수 불확실성처럼 보일 수 있다. 공통 난수는 비교 전략에서 같은 난수 흐름을 사용하여 증분결과의 분산을 줄이는 방법이며, 전략 간 공분산을 증가시켜 \(\operatorname{Var}(Y_1-Y_0)\)를 감소시킨다.

6.5 확률론적 민감도 분석에 자주 사용되는 확률분포

PSA에서 확률분포는 모수의 가능한 값 범위와 통계적 성격에 맞게 선택해야 한다. 확률은 0과 1 사이, 비용과 위험률은 양수, 회귀계수는 실수 전체, 다항 전이확률은 합이 1이 되어야 한다. 이 제약을 무시하면 PSA 반복에서 불가능한 값이 생성될 수 있다.

여기서 PSA 입력분포는 환자 수준 관찰값의 분포와 모수 추정량의 불확실성 분포를 구분해야 한다. 예를 들어 개인별 입원비가 감마분포를 따른다고 해서 평균 입원비의 추정 불확실성도 동일한 감마분포를 따르는 것은 아니다. PSA에는 모형에 입력되는 평균 비용이나 회귀계수의 불확실성을 반영해야 하며, 가능하면 원자료 분석에서 얻은 공분산행렬이나 부트스트랩 표본을 사용해야 한다.

분포 선택은 지지집합만 맞추는 문제가 아니다. 평균, 분산, 왜도, 모수 간 의존구조와 자료 생성과정을 함께 고려해야 한다. 동일한 평균과 표준오차를 갖더라도 베타분포와 로짓정규분포는 꼬리 형태가 다르며, 비선형 모형에서는 이 차이가 결과에 영향을 줄 수 있다.

모수 유형 값의 범위 자주 사용하는 분포 예

위 그림은 분포 선택의 출발점을 값의 범위로 제시하지만, 동일한 범위를 갖는 모수라도 자료 생성과정에 따라 적절한 분포가 달라질 수 있다. 예를 들어 확률 하나에는 베타분포가 편리하지만, 여러 전이확률의 합이 1이어야 하면 디리클레분포나 logistic-normal 분포가 필요하다. 또한 회귀모형에서 추정된 모수는 원자료의 경험적 분포가 아니라 추정계수의 공동분포를 사용해야 한다.

베타분포

베타분포는 0과 1 사이의 확률이나 효용에 자주 사용된다.

\[ p\sim Beta(\alpha,\beta). \]

평균과 분산은 다음과 같다.

\[ \mathbb{E}(p)=\frac{\alpha}{\alpha+\beta}, \]

\[ \operatorname{Var}(p)=\frac{\alpha\beta}{(\alpha+\beta)^2(\alpha+\beta+1)}. \]

평균 \(\mu\)와 표준오차 \(s\)가 주어졌을 때 \(\alpha\), \(\beta\)는 다음과 같이 계산할 수 있다.

\[ \phi=\frac{\mu(1-\mu)}{s^2}-1, \]

\[ \alpha=\mu\phi, \qquad \beta=(1-\mu)\phi. \]

이때 \(0<s^2<\mu(1-\mu)\)이어야 한다. 이 조건을 만족하지 않으면 입력된 평균과 표준오차가 베타분포와 양립하기 어렵다.

\(\phi=\alpha+\beta\)는 분포의 정밀도 또는 유효표본크기와 유사한 역할을 한다. \(\mu\)가 같을 때 \(\phi\)가 클수록 분포가 평균 주변에 집중한다. 이 해석은 전문가 의견이나 외부자료를 베타분포로 변환할 때 유용하지만, 실제 표본크기와 동일하다고 기계적으로 해석해서는 안 된다.

효용값에 베타분포를 사용할 때는 척도의 범위를 확인해야 한다. EQ-5D와 같이 0보다 작은 값이 가능한 효용척도에는 표준 베타분포를 직접 사용할 수 없다. 이 경우 선형변환한 베타분포, 절단정규분포, 로짓정규분포, 점질량을 포함한 혼합분포를 고려할 수 있다. 특히 완전건강 1에 큰 점질량이 있으면 연속 베타분포 하나로는 분포 형태를 충분히 표현하지 못한다.

감마분포

감마분포는 비용, 발생률, 위험률처럼 양수인 모수에 자주 사용된다. shape-scale 모수화를 사용하면 다음과 같이 쓴다.

\[ X\sim Gamma(\alpha,\theta). \]

평균과 분산은 다음과 같다.

\[ \mathbb{E}(X)=\alpha\theta, \qquad \operatorname{Var}(X)=\alpha\theta^2. \]

평균 \(m\)과 표준편차 \(s\)가 주어지면 다음처럼 계산한다.

\[ \alpha=\frac{m^2}{s^2}, \qquad \theta=\frac{s^2}{m}. \]

R의 rgamma()는 shape와 rate 또는 scale을 사용할 수 있다. rate는 scale의 역수이다.

감마분포의 변동계수는 \(CV=1/\sqrt{\alpha}\)이므로 shape가 작을수록 오른쪽 왜도가 커진다. 다만 비용 회귀모형에서 추정한 평균 비용을 PSA에 반영할 때는 관찰된 개인비용의 감마분포에서 직접 추출하기보다, 회귀계수의 다변량 분포에서 계수를 추출한 뒤 예측평균을 계산하는 것이 원래 분석의 불확실성 구조를 더 잘 보존한다.

\[ rate=\frac{1}{\theta}=\frac{m}{s^2}. \]

로그정규분포

로그정규분포는 양수이고 오른쪽 꼬리가 긴 비용, 상대효과, 위험률에 적합하다. \(X\)가 로그정규분포를 따르면 다음과 같이 쓸 수 있다.

\[ \log X\sim N(\mu_L,\sigma_L^2). \]

이때 평균과 분산은 다음과 같다.

\[ \mathbb{E}(X)=\exp\left(\mu_L+\frac{\sigma_L^2}{2}\right), \]

\[ \operatorname{Var}(X)=\left\{\exp(\sigma_L^2)-1\right\}\exp(2\mu_L+\sigma_L^2). \]

원척도의 평균 \(m\)과 표준편차 \(s\)가 주어지면 로그척도 모수는 다음과 같이 계산한다.

\[ \sigma_L^2=\log\left(1+\frac{s^2}{m^2}\right), \]

\[ \mu_L=\log(m)-\frac{1}{2}\sigma_L^2. \]

로그정규분포에서는 \(\exp(\mu_L)\)가 원척도 평균이 아니라 중앙값이다. 따라서 로그척도 추정치를 단순 지수변환하면 산술평균 비용을 과소추정할 수 있다. 회귀모형의 예측평균에는 \(\exp(\sigma_L^2/2)\)에 해당하는 재변환 보정이 필요하며, 이분산성이 있으면 단일 보정계수만으로 충분하지 않을 수 있다. PSA에서는 로그척도 위치모수와 분산모수의 공동 불확실성을 함께 반영해야 한다.

디리클레분포

한 상태에서 여러 상태로 이동하는 전이확률은 합이 1이어야 한다. 예를 들어 상태 \(r\)에서 다음 주기에 상태 \(1,\ldots,K\)로 이동할 확률 벡터를 \(\boldsymbol{p}_r=(p_{r1},\ldots,p_{rK})\)라고 하면 다음 조건을 만족해야 한다.

\[ p_{rk}\ge 0, \qquad \sum_{k=1}^K p_{rk}=1. \]

이런 경우 디리클레분포를 사용할 수 있다.

\[ \boldsymbol{p}_r\sim Dirichlet(\alpha_{r1},\ldots,\alpha_{rK}). \]

평균은 다음과 같다.

\[ \mathbb{E}(p_{rk})=\frac{\alpha_{rk}}{\alpha_{r0}}, \qquad \alpha_{r0}=\sum_{k=1}^K \alpha_{rk}. \]

관찰된 전이 수가 \(n_{rk}\)라면 \(\alpha_{rk}=n_{rk}\) 또는 사전정보를 더한 \(\alpha_{rk}=n_{rk}+a_{rk}\)를 사용할 수 있다. 집계자료가 없고 평균 전이확률 \(\bar p_{rk}\)와 유효표본크기 \(N_{eff}\)만 사용할 수 있다면 \(\alpha_{rk}=N_{eff}\bar p_{rk}\)로 설정하기도 한다.

디리클레분포에서는 구성요소 사이에 음의 공분산이 유도된다.

\[ \operatorname{Var}(p_{rk})= \frac{\alpha_{rk}(\alpha_{r0}-\alpha_{rk})} {\alpha_{r0}^2(\alpha_{r0}+1)}, \]

\[ \operatorname{Cov}(p_{rk},p_{r\ell})= -\frac{\alpha_{rk}\alpha_{r\ell}} {\alpha_{r0}^2(\alpha_{r0}+1)},\qquad k\ne \ell. \]

이는 한 전이확률이 커지면 다른 전이확률의 합이 줄어야 한다는 제약을 반영한다. 그러나 디리클레분포는 공분산 구조가 제한적이다. 더 유연한 의존구조가 필요하면 기준 범주에 대한 로그비를 다변량 정규분포로 두는 logistic-normal 모형을 사용할 수 있다.

6.6 상대위험에 대한 확률분포

상대위험, 위험비, 오즈비는 모두 양수이므로 원척도에서 정규분포를 사용하면 음수 값이 생성될 수 있다. 따라서 보통 로그척도에서 정규분포를 가정한다.

상대효과를 \(R\)이라고 하자. \(R\)은 위험비 \(HR\), 상대위험 \(RR\), 오즈비 \(OR\)일 수 있다. PSA에서는 다음과 같이 설정한다.

\[ \log R\sim N(\mu_R,\sigma_R^2). \]

점추정값이 \(\widehat R\)이면 일반적으로 \(\mu_R=\log(\widehat R)\)로 둔다. 95% 신뢰구간이 \((L,U)\)이면 로그표준오차는 다음과 같이 계산한다.

\[ SE\{\log(\widehat R)\}=\frac{\log(U)-\log(L)}{2z_{0.975}}. \]

여기서 \(z_{0.975}=1.96\)이다. 따라서 PSA 반복에서는 다음과 같이 추출한다.

\[ R^{(s)}=\exp\left[\log(\widehat R)+SE\{\log(\widehat R)\}Z^{(s)}\right], \qquad Z^{(s)}\sim N(0,1). \]

상대효과를 절대위험에 적용하기

상대효과를 경제성 평가 모형에 사용할 때 가장 흔한 오류는 \(HR\), \(RR\), \(OR\)를 모두 같은 방식으로 기준 사건확률에 곱하는 것이다. 세 척도는 서로 다른 수학적 대상에 작용한다.

기준 사건확률을 \(p_0\)라고 하자. 상대위험 \(RR\)이 같은 시간 구간의 누적위험에 대해 정의되었다면 치료군 사건확률은 다음과 같이 계산할 수 있다.

\[ p_1=RR\times p_0. \]

단, 이 값은 1을 넘을 수 없으며, 누적위험이 큰 경우에는 단순 곱셈이 부적절할 수 있다.

오즈비 \(OR\)가 주어졌다면 먼저 기준 오즈를 계산한 뒤 오즈에 \(OR\)를 곱해야 한다.

\[ \frac{p_1}{1-p_1}=OR\times\frac{p_0}{1-p_0}. \]

이를 \(p_1\)에 대해 풀면 다음과 같다.

\[ p_1=\frac{OR\,p_0}{1-p_0+OR\,p_0}. \]

위험비 \(HR\)가 비례위험 가정하에서 주어지고, 기준 생존확률이 \(S_0(t)\)라면 치료군 생존확률은 다음과 같다.

\[ S_1(t)=S_0(t)^{HR}. \]

따라서 기준 사건확률 \(p_0(t)=1-S_0(t)\)에 대응하는 치료군 사건확률은 다음과 같다.

\[ p_1(t)=1-\{1-p_0(t)\}^{HR}. \]

사건률 \(r_0\)와 rate ratio \(RR_r\)가 주어졌다면 다음과 같이 전이확률을 계산한다.

\[ r_1=RR_r r_0, \qquad p_1(\Delta t)=1-\exp(-r_1\Delta t). \]

기준위험과 상대효과가 서로 다른 자료원에서 추정되더라도 독립이라고 단정할 수는 없다. 동일 연구나 계층모형에서 함께 추정되었다면 두 모수의 공분산을 유지해야 한다. 치료군 절대위험 \(p_1=f(p_0,R)\)의 근사분산은 델타방법으로

\[ \operatorname{Var}(p_1) \approx \nabla f^{\mathsf T} \begin{pmatrix} \operatorname{Var}(p_0) & \operatorname{Cov}(p_0,R)\\ \operatorname{Cov}(p_0,R) & \operatorname{Var}(R) \end{pmatrix} \nabla f \]

와 같이 표현할 수 있다. 공분산을 무시하면 절대효과의 불확실성이 왜곡될 수 있다.

위험비를 이용한 \(S_1(t)=S_0(t)^{HR}\)는 비례위험 가정이 성립할 때만 타당하다. 치료효과가 시간에 따라 변하면 \(HR(t)\) 또는 시간구간별 효과를 사용해야 하며,

\[ S_1(t)=\exp\left[-\int_0^t HR(u)h_0(u)\,du\right] \]

로 일반화된다. 단일 HR를 장기 외삽 전체에 적용하면 치료효과 지속에 관한 강한 구조적 가정을 암묵적으로 도입하게 된다.

위 그림에서 기준위험이 낮을 때는 RR, OR, HR로 변환한 절대위험이 비슷해 보일 수 있지만, 기준위험이 커질수록 차이가 확대된다. 따라서 희귀사건 근사에 기대어 OR를 RR처럼 사용하거나, HR를 누적위험에 직접 곱하는 오류는 고위험군과 장기 분석에서 더 큰 편향을 만든다.

Important상대효과 적용의 원칙

상대위험은 위험에, 오즈비는 오즈에, 위험비는 위험함수 또는 생존함수에 적용해야 한다. 특히 생존분석 또는 네트워크 메타분석에서 얻은 HR를 단순히 주기별 전이확률에 곱하면 치료효과를 잘못 반영할 수 있다.

6.7 모수들 간의 상관성을 반영하기

PSA에서는 모수를 독립적으로 추출하는 경우가 많지만, 실제로는 여러 모수가 서로 상관되어 있다. 상관성을 무시하면 불확실성을 과소평가하거나 과대평가할 수 있고, 불가능한 조합의 모수값이 생성될 수도 있다.

순편익이 모수의 함수 \(g(\theta)\)일 때 델타방법에 의한 근사분산은 다음과 같다.

\[ \operatorname{Var}\{g(\theta)\} \approx \nabla g(\mu)^{\mathsf T}\Sigma\nabla g(\mu). \]

이 식의 비대각 원소는 모수 간 공분산의 기여를 나타낸다. 두 모수만 있는 경우,

\[ \operatorname{Var}(g) \approx g_1^2\sigma_1^2+g_2^2\sigma_2^2 +2g_1g_2\sigma_{12}. \]

공분산항의 부호는 전체 불확실성을 증가시키거나 감소시킬 수 있다. 따라서 상관성을 무시하면 항상 보수적이거나 항상 낙관적인 결과가 되는 것이 아니라, 모형의 민감도 방향에 따라 어느 쪽으로도 왜곡될 수 있다.

예를 들어 회귀모형의 절편과 기울기는 보통 상관되어 있다. Weibull 생존모형의 shape와 scale, Gompertz 모형의 계수, spline 기반 생존모형의 계수, 네트워크 메타분석에서 여러 치료효과 추정치 역시 공분산을 가진다. 이런 경우 모수 벡터 전체를 함께 추출해야 한다.

모수 벡터를 \(\boldsymbol{\theta}\)라고 하고 평균 벡터와 공분산행렬을 각각 \(\boldsymbol{\mu}\), \(\Sigma\)라고 하자.

\[ \boldsymbol{\theta}\sim N_p(\boldsymbol{\mu},\Sigma). \]

Cholesky 분해를 이용하면 \(\Sigma=LL^{\mathsf{T}}\)이고, \(\boldsymbol{z}^{(s)}\sim N_p(\boldsymbol{0},I)\)일 때 다음처럼 상관된 모수를 생성할 수 있다.

\[ \boldsymbol{\theta}^{(s)}=\boldsymbol{\mu}+L\boldsymbol{z}^{(s)}. \]

양수 모수는 로그척도에서 다변량 정규분포를 적용한 뒤 지수변환한다.

\[ \log\boldsymbol{\eta}^{(s)}\sim N_p(\boldsymbol{\mu}_{\log\eta},\Sigma_{\log\eta}), \qquad \boldsymbol{\eta}^{(s)}=\exp\{\log\boldsymbol{\eta}^{(s)}\}. \]

위 그림의 타원형 점 구름은 공분산행렬이 허용하는 모수 조합을 나타낸다. 독립 추출은 이 타원을 축과 평행한 원형 또는 직사각형 범위로 바꾸어 실제로 거의 발생하지 않는 조합을 생성할 수 있다. 생존곡선의 절편과 기울기처럼 상관성이 큰 모수에서는 이러한 왜곡이 장기 외삽의 꼬리 부분에서 특히 커질 수 있다.

전이확률도 독립 추출에 주의해야 한다. 예를 들어 한 상태에서 세 개의 상태로 이동하는 확률 \(p_1\), \(p_2\), \(p_3\)가 있을 때 각각을 독립 베타분포에서 추출하면 합이 1이 되지 않을 수 있다. 이 경우 디리클레분포 또는 다항 로짓 변환을 사용하는 것이 더 적절하다.

공분산행렬은 양의 준정부호여야 Cholesky 분해가 가능하다. 반올림되거나 서로 다른 출처에서 조합된 상관계수로 구성한 행렬은 이 조건을 위반할 수 있다. 이 경우 임의로 상관성을 제거하기보다 원자료 또는 모형의 분산-공분산행렬을 다시 확보하고, 필요한 경우 가장 가까운 양의 정부호 행렬로 보정한 근거를 보고해야 한다. 서로 다른 주변분포를 유지하면서 의존구조를 반영해야 할 때는 copula 접근도 사용할 수 있지만, copula의 선택 자체가 추가적인 구조적 가정이 된다.

6.8 빈도론적 확률론적 민감도 분석의 절차

빈도론적 PSA는 추정량의 표준오차와 공분산행렬을 이용해 모수 불확실성을 근사하는 접근이다. 가장 기본적인 아이디어는 다음과 같다.

이 접근은 대개 최대가능도 추정량의 점근적 정규성을 이용한 모수적 부트스트랩과 유사하다. 표본크기가 작거나 모수가 경계에 있거나 가능도 표면이 비대칭이면 정규근사가 좋지 않을 수 있다. 이런 경우 변환척도, 프로파일 가능도, 비모수 부트스트랩 또는 원 분석모형의 재적합을 고려해야 한다.

\[ \widehat{\theta}\approx N(\theta,\widehat{\Sigma}_{\widehat{\theta}}). \]

실무에서는 모수의 불확실성을 나타내기 위해 다음과 같이 추정값 주변에서 모수를 추출한다.

\[ \theta^{(s)}\sim N(\widehat{\theta},\widehat{\Sigma}_{\widehat{\theta}}). \]

모수가 확률, 비용, 상대효과처럼 제약된 범위를 가진 경우에는 적절한 변환척도에서 정규근사를 적용하거나 베타, 감마, 로그정규분포를 사용한다.

빈도론적 PSA의 일반 절차는 다음과 같다.

  1. 기본 분석의 모수 추정값 \(\widehat{\theta}\)를 정리한다.
  2. 각 모수의 표준오차, 신뢰구간, 공분산행렬을 수집한다.
  3. 모수의 범위와 척도에 맞는 확률분포를 지정한다.
  4. 상관된 모수는 공분산행렬을 이용해 함께 추출한다.
  5. 각 반복에서 모형을 실행하고 \(\Delta C^{(s)}\), \(\Delta Q^{(s)}\), \(INB^{(s)}(\lambda)\)를 저장한다.
  6. CE plane, CEAC, 순편익 분포, 비용효과확률을 보고한다.

비모수 부트스트랩과 모수적 PSA

임상시험 기반 경제성 평가에서는 비모수 부트스트랩을 사용할 수 있다. 환자 단위 자료 \((C_i,Q_i,A_i)\)가 있을 때, 치료군별로 환자를 재표본추출하고 각 표본에서 \(\Delta C\)와 \(\Delta Q\)를 다시 계산한다. 이 방법은 비용과 QALY의 상관성, 비정규성, 오른쪽 꼬리 등을 어느 정도 반영할 수 있다.

모형 기반 경제성 평가에서는 모수적 PSA가 더 일반적이다. 각 입력 모수에 확률분포를 지정하고, 모형을 반복 실행한다. 이때 입력분포가 임상시험, 메타분석, 생존모형, 청구자료, 전문가 의견 등 다양한 자료원에서 오므로 분포 선택과 상관성 반영을 투명하게 보고해야 한다.

부트스트랩의 재표본추출 단위는 자료의 독립 단위와 일치해야 한다. 군집무작위시험에서는 개인이 아니라 군집을, 반복측정자료에서는 관측시점이 아니라 환자를, 다기관 자료에서 기관 수준 변동을 반영하려면 기관 또는 계층구조를 고려해야 한다. 결측자료를 다중대치한 경우에는 대치 불확실성과 부트스트랩 불확실성을 함께 반영해야 하므로, 대치와 재표본추출의 순서 및 결합규칙을 명확히 정의해야 한다.

Note빈도론적 PSA의 해석

빈도론적 PSA의 비용효과확률은 엄밀한 의미에서 항상 “신약이 비용효과적일 확률”로 해석되는 것은 아니다. 이는 추정량의 표본추출 불확실성을 모수분포처럼 근사하여 의사결정 불확실성을 표현한 값이다. 그럼에도 실무적으로는 CEAC와 순편익 분포를 통해 의사결정 민감도를 보여주는 유용한 도구이다.

6.9 베이지안 확률론적 민감도 분석

베이지안 PSA는 모수의 사후분포에서 직접 추출한 값으로 경제성 평가 모형을 반복 실행하는 접근이다. 베이지안 분석에서는 자료 \(y\)를 관찰한 뒤 모수 \(\theta\)에 대한 불확실성을 다음 사후분포로 표현한다.

\[ p(\theta\mid y)=\frac{p(y\mid\theta)p(\theta)}{p(y)}. \]

여기서 \(p(\theta)\)는 사전분포, \(p(y\mid\theta)\)는 가능도, \(p(\theta\mid y)\)는 사후분포이다. 경제성 평가에서 베이지안 PSA는 다음처럼 수행된다.

  1. 치료효과, 자연사, 비용, 효용, 전이확률 등에 대한 통계모형을 정의한다.
  2. 모수의 사전분포를 설정한다.
  3. 관찰자료를 이용해 사후분포 \(p(\theta\mid y)\)를 계산한다.
  4. 사후표본 \(\theta^{(s)}\)를 경제성 평가 모형에 입력한다.
  5. 사후 순편익 \(INB^{(s)}(\lambda)\)를 계산한다.
  6. \(P\{INB(\lambda)>0\mid y\}\), 기대순편익, CEAC를 보고한다.

베이지안 PSA에서 비용효과확률은 다음과 같이 사후확률로 해석할 수 있다.

\[ P\{INB(\lambda)>0\mid y\}=\int I\{INB(\lambda;\theta)>0\}p(\theta\mid y)d\theta. \]

사후표본을 사용하면 다음과 같이 근사한다.

\[ \widehat{P}\{INB(\lambda)>0\mid y\}=\frac{1}{S}\sum_{s=1}^S I\{INB^{(s)}(\lambda)>0\}. \]

사후분포의 기대순편익은

\[ \mathbb{E}\{NB_j(\lambda,\theta)\mid y\} = \int NB_j(\lambda,\theta)p(\theta\mid y)d\theta \]

로 정의되며, 현재 자료하의 최적 전략은 이 사후기대순편익을 최대화하는 전략이다. 여기서 모수의 사후분포와 미래 환자 결과의 사후예측분포를 구분해야 한다. 경제성 모형의 기대비용과 기대효과가 이미 조건부 평균이라면 PSA에는 모수 사후분포를 전달한다. 새로운 환자의 실제 결과 분포까지 예측하려면

\[ p(\widetilde y\mid y)=\int p(\widetilde y\mid\theta)p(\theta\mid y)d\theta \]

인 사후예측분포가 필요하다.

위 그림에서 두 접근은 반복 계산의 외형은 비슷하지만 출발점이 다르다. 빈도론적 PSA는 추정량의 표본추출분포를 이용해 불확실성을 근사하고, 베이지안 PSA는 자료와 사전정보가 주어진 모수의 사후분포를 사용한다. 따라서 동일한 CEAC 모양이 나오더라도 확률의 철학적 해석과 입력분포를 구성하는 방법은 다르다.

베이지안 PSA의 장점과 주의점

베이지안 PSA의 장점은 모수 불확실성과 의사결정 불확실성의 해석이 자연스럽다는 점이다. 사후분포에서 추출한 값은 관찰자료와 사전정보를 모두 반영한 모수의 불확실성을 나타내며, \(P\{INB(\lambda)>0\mid y\}\)는 관찰자료가 주어진 후 신약의 순편익이 양수일 확률로 해석할 수 있다.

또한 베이지안 계층모형을 사용하면 여러 자료원을 동시에 합성하고, 상관된 모수의 사후분포를 자연스럽게 반영할 수 있다. 네트워크 메타분석, 다상태모형, 생존외삽, MAIC 등 복잡한 분석에서는 사후표본을 경제성 평가 모형으로 직접 전달하는 방식이 유용하다.

다만 사전분포의 영향, MCMC 수렴, posterior predictive check, 모형 적합도, 사후표본의 autocorrelation을 확인해야 한다. 사후표본 수가 충분하지 않으면 CEAC나 EVPI 같은 후속 분석이 불안정해질 수 있다.

MCMC 표본의 유효표본크기를 \(S_{eff}\)라고 하면 사후평균의 Monte Carlo 표준오차는 대략 \(s/\sqrt{S_{eff}}\)로 계산한다. 여러 체인의 혼합, 잠재적 척도감소계수, trace plot과 자기상관을 함께 확인해야 한다. 특히 EVPI처럼 각 반복에서 최대값을 취하는 비선형 함수는 꼬리와 극단값에 민감하므로, 일반적인 모수 사후평균보다 더 많은 유효표본이 필요할 수 있다.

6.10 모형 불확실성과 하위군 분석

모수 불확실성은 같은 모형 구조 안에서 입력값의 참값을 모르는 문제이다. 반면 모형 불확실성은 어떤 모형 구조나 분석 가정이 타당한지 모르는 문제이다. 경제성 평가에서는 모형 불확실성이 특히 중요하다. 장기 생존외삽, 치료효과 소실, cure fraction, 전이상태 수, 치료 중단 규칙, 이상반응 반영 방식, 비용 범위, 분석 관점 등은 모두 구조적 가정이다.

모형 구조를 확률변수 \(M\)으로 보면 전체 기대순편익은 전체기대값의 법칙에 따라

\[ \mathbb{E}(NB_j)= \sum_{m=1}^{M}P(M_m)\, \mathbb{E}(NB_j\mid M_m) \]

로 표현할 수 있다. 전체 분산은

\[ \operatorname{Var}(NB_j) = \mathbb{E}_M\{\operatorname{Var}(NB_j\mid M)\} + \operatorname{Var}_M\{\mathbb{E}(NB_j\mid M)\} \]

로 분해된다. 첫 번째 항은 각 구조 안의 모수 불확실성이고, 두 번째 항은 구조 간 기대결과 차이에 따른 불확실성이다. 단일 구조의 PSA만 수행하면 두 번째 항은 반영되지 않는다.

시나리오 분석

모형 불확실성을 평가하는 가장 일반적인 방법은 시나리오 분석이다. 각 시나리오 \(m=1,\ldots,M\)에 대해 모형 \(M_m\)을 정의하고, 각 모형에서 기본 분석 또는 PSA를 수행한다.

\[ INB_m(\lambda)=\lambda\Delta Q_m-\Delta C_m. \]

시나리오 분석은 단순히 부록에 넣는 보조분석이 아니라, 결론의 강건성을 평가하는 핵심 자료이다. 예를 들어 기본 분석에서는 비용효과적이지만 치료효과 소실 시나리오에서는 비용효과적이지 않다면, 의사결정자는 치료효과 지속에 대한 불확실성을 중요한 쟁점으로 보아야 한다.

위 그림에서 시나리오 간 결과 차이가 모수 PSA의 분산보다 크다면, 의사결정 불확실성의 주된 원인이 입력값의 표준오차보다 모형 구조일 수 있다. 이 경우 단일 구조에서 PSA 반복 수를 늘리는 것만으로는 핵심 불확실성이 줄어들지 않으며, 구조 선택의 근거와 대안 모형 결과를 함께 제시해야 한다.

모형 평균화

여러 모형이 모두 그럴듯하고 하나의 모형만 선택하기 어려운 경우에는 모형 평균화(model averaging)를 고려할 수 있다. 모형 \(M_m\)의 가중치를 \(w_m\)이라고 하자. 이때 \(\sum_{m=1}^M w_m=1\)이다. 전략 \(j\)의 기대순편익은 다음과 같이 평균화할 수 있다.

\[ \mathbb{E}\{NB_j(\lambda)\}=\sum_{m=1}^M w_m\,\mathbb{E}\{NB_j(\lambda)\mid M_m\}. \]

가중치 \(w_m\)은 베이지안 모형확률, AIC/BIC 기반 가중치, 전문가 판단, 또는 사전 정의한 동일 가중치에서 올 수 있다. 그러나 실무에서는 모형 평균화 결과만 제시하기보다 각 시나리오 결과와 평균화 방법을 함께 투명하게 제시해야 한다.

AIC 또는 BIC 가중치는 후보모형 집합 안에서의 상대적 적합도를 반영할 뿐, 후보모형 밖의 구조적 오류를 제거하지 않는다. 또한 동일 자료에 대한 적합도 가중치가 정책적 타당성이나 임상적 개연성을 자동으로 보장하지 않는다. 모형 평균화는 불확실성을 없애는 방법이 아니라, 명시적으로 정의한 후보구조 사이에 불확실성을 배분하는 방법이다.

하위군 분석

하위군 분석은 환자 특성에 따라 비용효과성이 달라지는지 평가한다. 하위군 \(g\)에서의 증분순편익은 다음과 같다.

\[ INB_g(\lambda)=\lambda\Delta Q_g-\Delta C_g. \]

전체 모집단에서 하위군 비율을 \(w_g\)라고 하면 전체 모집단의 증분순편익은 다음과 같이 표현할 수 있다.

\[ INB_{pop}(\lambda)=\sum_{g=1}^G w_g INB_g(\lambda). \]

특정 하위군에서만 \(INB_g(\lambda)>0\)이면 급여 대상을 제한하는 의사결정이 합리적일 수 있다. 반대로 전체 모집단에서는 비용효과적이더라도 일부 하위군에서 순편익이 음수라면, 치료 대상 확대의 타당성을 다시 검토해야 한다.

위 그림은 하위군별 점추정치뿐 아니라 각 하위군의 불확실성 구간을 함께 읽어야 한다. 전체 평균의 INB가 양수라도 일부 하위군의 기대순편익이 음수일 수 있으며, 반대로 전체 분석에서는 비용효과적이지 않아도 고위험 하위군에서는 절대효과가 커져 순편익이 양수가 될 수 있다. 다만 하위군 간 차이를 주장하려면 각 하위군의 개별 유의성보다 치료효과 또는 순편익의 상호작용을 평가하는 것이 중요하다.

하위군 분석은 임상적 근거, 생물학적 근거, 사전 정의된 분석계획에 기반해야 한다. 사후적으로 여러 하위군을 탐색하면 우연에 의해 비용효과적인 하위군이 발견될 가능성이 커진다. 또한 하위군별 표본 수가 작으면 치료효과와 비용효과성 추정의 불확실성이 커진다.

하위군별 정책을 \(d(x)\)라고 하면 목표는 환자 특성 \(X=x\)에서 기대순편익이 가장 큰 전략을 선택하는 것이다.

\[ d^*(x)=\arg\max_j \mathbb{E}\{NB_j(\lambda,\theta)\mid X=x\}. \]

개별화 정책의 인구집단 기대순편익은

\[ \mathbb{E}_X\left[ \max_j \mathbb{E}\{NB_j\mid X\} \right] \]

으로 나타낼 수 있다. 이는 모든 환자에게 하나의 전략을 적용할 때의

\[ \max_j \mathbb{E}_X\left[ \mathbb{E}\{NB_j\mid X\} \right] \]

보다 작지 않다. 두 값의 차이는 이론적으로 하위군 맞춤 의사결정의 최대 가치를 나타낸다. 다만 실제 정책에서는 바이오마커 검사비, 분류오류, 검사 접근성, 치료대상 제한의 형평성과 실행 가능성을 차감해야 한다.

Warning하위군 분석의 주의점

하위군 비용효과성은 평균 효과의 단순 분할이 아니라 의사결정 대상의 재정의와 연결된다. 하위군을 제안할 때는 임상적 타당성, 검사 가능성, 형평성, 실제 급여 기준으로 운영 가능한지까지 함께 검토해야 한다.

6.11 가치정보분석

PSA가 현재 의사결정의 불확실성을 묘사한다면, 가치정보분석(value of information analysis)은 추가 연구를 통해 그 불확실성을 줄이는 것이 얼마나 가치 있는지를 평가한다. 전략 \(j\)의 순편익을 \(NB_j(\theta)\)라고 하자. 현재 정보에서 선택할 전략의 기대순편익은 다음과 같다.

\[ \max_j \mathbb{E}_{\theta}\{NB_j(\theta)\}. \]

모든 불확실한 모수의 참값을 의사결정 전에 완전히 알 수 있다면, 각 \(\theta\)에서 가장 좋은 전략을 선택할 수 있다. 완전정보하의 기대순편익은 다음과 같다.

\[ \mathbb{E}_{\theta}\left\{\max_j NB_j(\theta)\right\}. \]

따라서 환자 1인당 완전정보의 기대가치(expected value of perfect information, EVPI)는

\[ EVPI = \mathbb{E}_{\theta}\left\{\max_j NB_j(\theta)\right\} - \max_j \mathbb{E}_{\theta}\{NB_j(\theta)\} \]

로 정의된다. 최대함수의 볼록성 때문에 EVPI는 항상 0 이상이다. EVPI는 현재의 불확실성으로 인해 발생할 수 있는 기대기회손실의 최솟값과 같다.

PSA 표본으로는 다음과 같이 추정한다.

\[ \widehat{EVPI} = \frac{1}{S}\sum_{s=1}^{S}\max_j NB_j^{(s)} - \max_j\left\{ \frac{1}{S}\sum_{s=1}^{S}NB_j^{(s)} \right\}. \]

인구집단 EVPI는 환자 1인당 EVPI에 해당 의사결정의 영향을 받을 미래 환자 수를 곱해 계산한다. 환자 유입이 시간에 따라 \(N_t\)이고 할인율이 \(r\)이면,

\[ EVPI_{pop} = EVPI_{person} \sum_{t=0}^{T}\frac{N_t}{(1+r)^t}. \]

이 값은 완전한 정보를 얻기 위해 지불할 수 있는 연구비의 이론적 상한이다.

부분완전정보의 기대가치

모수 벡터를 관심 모수 \(\phi\)와 나머지 모수 \(\psi\)로 나누자. \(\phi\)만 완전히 알 수 있을 때 부분완전정보의 기대가치(expected value of partial perfect information, EVPPI)는 다음과 같다.

\[ EVPPI(\phi) = \mathbb{E}_{\phi}\left[ \max_j \mathbb{E}_{\psi\mid\phi}\{NB_j(\phi,\psi)\} \right] - \max_j\mathbb{E}_{\theta}\{NB_j(\theta)\}. \]

EVPPI가 큰 모수군은 의사결정 불확실성에 중요한 기여를 하므로 향후 연구의 우선순위가 될 수 있다. 토네이도 그림의 막대 길이는 입력범위에 대한 결과 민감도이고, EVPPI는 해당 모수의 불확실성을 완전히 제거했을 때 얻는 의사결정 가치라는 점에서 서로 다르다.

표본정보의 기대가치

실제 연구는 모수의 참값을 완전히 알려주지 않고 추가 표본자료 \(Y^{new}\)를 제공한다. 표본정보의 기대가치(expected value of sample information, EVSI)는 다음과 같다.

\[ EVSI = \mathbb{E}_{Y^{new}}\left[ \max_j \mathbb{E}_{\theta\mid Y^{new},y}\{NB_j(\theta)\} \right] - \max_j\mathbb{E}_{\theta\mid y}\{NB_j(\theta)\}. \]

인구집단 EVSI에서 연구 수행비용을 뺀 값을 기대순표본편익(expected net benefit of sampling, ENBS)이라고 한다.

\[ ENBS=EVSI_{pop}-Cost_{research}. \]

ENBS가 양수이면 해당 설계의 추가 연구가 경제적으로 정당화될 수 있다. 그러나 연구기간 동안 발생하는 의사결정 지연, 모집 가능성, 윤리성, 연구결과의 채택 가능성도 함께 고려해야 한다.

calc_inb <- function(drug_cost = 15000000,
                     delta_qaly = 0.50,
                     ae_cost = 2000000,
                     utility_multiplier = 1.00,
                     treatment_waning = 1.00) {
  adjusted_qaly <- delta_qaly * utility_multiplier * treatment_waning
  adjusted_cost <- drug_cost + ae_cost
  lambda * adjusted_qaly - adjusted_cost
}

## 기본 분석 {#sec-base-case-analysis}

기본 분석(base-case analysis)은 분석자가 사전에 정한 가장 타당한 자료원, 모형 구조, 분석 기간, 할인율, 비용 범위, 건강결과 지표, 모수 값을 이용해 산출한 중심 결과이다. 기본 분석은 여러 시나리오 중 하나가 아니라, 의사결정자가 가장 먼저 검토하는 기준 결과이다. 따라서 기본 분석에는 분석자의 최선의 과학적 판단이 반영되어야 하며, 편의에 따라 비용효과성이 좋아 보이는 가정을 선택해서는 안 된다.

전략 집합을 $\mathcal{J}$라고 하자. 기존 치료를 $j=0$, 신약 치료를 $j=1$로 표시한다. 전략 $j$의 기대비용과 기대 QALY를 각각 $\mu_{C,j}$, $\mu_{Q,j}$라고 하면 다음과 같이 정의할 수 있다.

$$
\mu_{C,j}=\mathbb{E}(C_j), \qquad \mu_{Q,j}=\mathbb{E}(Q_j).
$$

신약의 증분비용과 증분 QALY는 다음과 같다.

$$
\Delta C=\mu_{C,1}-\mu_{C,0}, \qquad \Delta Q=\mu_{Q,1}-\mu_{Q,0}.
$$

$\Delta Q \ne 0$이면 ICER는 다음과 같이 정의된다.

$$
ICER=\frac{\Delta C}{\Delta Q}.
$$

지불의사금액을 $\lambda$라고 하면 증분순편익(incremental net benefit, INB)은 다음과 같다.

$$
INB(\lambda)=\lambda\Delta Q-\Delta C.
$$

$\Delta Q>0$이고 $\Delta C>0$인 상황에서는 $ICER<\lambda$와 $INB(\lambda)>0$이 동등하다. 그러나 $\Delta Q$가 0에 가깝거나 음수인 경우, ICER는 해석이 어려워질 수 있다. 이 때문에 불확실성 분석에서는 ICER보다 순편익 척도를 사용하는 것이 수학적으로 더 안정적이다.

경제성 평가의 기본 의사결정은 통계적 가설검정과 다르다. 의사결정자는 귀무가설의 기각 여부가 아니라, 현재 이용 가능한 정보에서 기대순편익이 가장 큰 전략을 선택한다. 전략이 두 개보다 많을 때 전략 $j$의 순편익을

$$
NB_j(\lambda,\theta)=\lambda Q_j(\theta)-C_j(\theta)
$$

라고 하면, 현재 정보하의 최적 전략은 다음과 같다.

$$
j^*(\lambda)=\arg\max_{j\in\mathcal{J}}
\mathbb{E}_{\theta}\{NB_j(\lambda,\theta)\}.
$$

따라서 어떤 전략의 비용효과확률이 가장 높다는 사실과 그 전략의 기대순편익이 가장 크다는 사실은 반드시 일치하지 않는다. 급여 의사결정은 비용효과확률 자체가 아니라 기대순편익 최대화 원칙에 기반해야 한다.

::: {.callout-important title="ICER와 순편익의 차이"}
ICER는 비율이므로 분모인 $\Delta Q$가 0에 가까우면 매우 불안정해진다. 반면 $INB(\lambda)=\lambda\Delta Q-\Delta C$는 선형 함수이므로 확률분포, 평균, 분산, 회귀모형, PSA 결과를 다루기 쉽다. 경제성 평가의 의사결정 규칙은 가능하면 순편익 척도로 표현하는 것이 좋다.
:::

기본 분석에서 사용한 모수 벡터를 $\theta_0$라고 하자. 경제성 평가 모형을 $M(\theta)$로 표시하면 기본 분석은 다음과 같은 plug-in 계산이다.

$$
\widehat{\mu}_{C,j}^{\,0}=\mu_{C,j}(\theta_0), \qquad
\widehat{\mu}_{Q,j}^{\,0}=\mu_{Q,j}(\theta_0).
$$

이 결과로부터 $\widehat{\Delta C}^{\,0}$, $\widehat{\Delta Q}^{\,0}$, $\widehat{ICER}^{\,0}$, $\widehat{INB}^{\,0}(\lambda)$가 계산된다. 여기서 위첨자 0은 기본 분석에서 선택한 중심값을 사용했다는 뜻이다.

기본 분석의 plug-in 결과와 불확실성을 평균한 기대 결과는 구분해야 한다. 일반적으로 비선형 함수 $g(\theta)$에 대해서는

$$
g\{\mathbb{E}(\theta)\}\ne \mathbb{E}\{g(\theta)\}
$$

가 성립한다. ICER는 비선형 비율이므로 중심 모수에서 계산한 ICER와 PSA에서 산출된 결과를 단순 평균한 값은 서로 다를 수 있다. 반면 순편익은 비용과 효과의 선형결합이므로 기대값의 계산과 전략 간 비교가 상대적으로 안정적이다. 다만 비용과 효과 자체가 모수의 비선형 함수라면, 중심 모수를 대입한 순편익과 PSA 평균 순편익도 달라질 수 있다. 이 차이는 모형의 비선형성과 모수 불확실성이 결합하여 발생한다.

### 예제: 기본 분석 결과의 계산 {.unnumbered}

신약과 기존 치료의 기대비용과 기대 QALY가 다음과 같다고 하자.

| 전략 | 기대비용 | 기대 QALY |
|---|---:|---:|
| 기존 치료 | 30,000,000원 | 2.40 |
| 신약 치료 | 45,000,000원 | 2.90 |

$$
\Delta C=45,000,000-30,000,000=15,000,000,
$$

$$
\Delta Q=2.90-2.40=0.50.
$$

따라서 ICER는 다음과 같다.

$$
ICER=\frac{15,000,000}{0.50}=30,000,000\text{원/QALY}.
$$

지불의사금액이 QALY당 50,000,000원이라면 증분순편익은 다음과 같다.

$$
INB(50,000,000)=50,000,000\times0.50-15,000,000=10,000,000.
$$

## 변동성, 이질성, 불확실성 {#sec-variability-heterogeneity-uncertainty}

경제성 평가에서 “불확실성”이라는 용어는 넓게 사용되지만, 실제로는 서로 다른 개념을 포함한다. 특히 **변동성(variability)**, **이질성(heterogeneity)**, **모수 불확실성(parameter uncertainty)**, **모형 불확실성(structural uncertainty)**을 구분하는 것이 중요하다. 이 구분을 잘못하면 PSA에 넣어야 할 것을 하위군 분석으로 처리하거나, 하위군별 의사결정을 해야 할 것을 단순 민감도 분석으로만 처리하는 오류가 생긴다.

이 구분은 우연적 불확실성(aleatory uncertainty)과 인식론적 불확실성(epistemic uncertainty)의 구분과도 연결된다. 개인별 사건 발생과 비용의 무작위성은 우연적 변동에 가깝고, 치료효과나 생존모형 모수를 충분히 알지 못하는 문제는 인식론적 불확실성에 가깝다. 전자는 더 많은 환자를 관찰해도 개인 수준에서는 사라지지 않지만, 후자는 추가 연구와 자료 축적으로 줄일 수 있다. 구조적 불확실성은 어떤 상태구조나 외삽함수가 실제 현상을 가장 잘 나타내는지 알지 못한다는 점에서 인식론적 불확실성의 한 형태이다.

환자 $i$의 결과를 $Y_i$, 환자 특성 벡터를 $X_i$, 모수 벡터를 $\theta$라고 하자. 일반적으로 결과는 다음과 같이 표현할 수 있다.

$$
Y_i=m(X_i;\theta)+\varepsilon_i.
$$

여기서 $m(X_i;\theta)=\mathbb{E}(Y_i\mid X_i,\theta)$는 환자 특성에 따른 조건부 평균이고, $\varepsilon_i$는 같은 특성을 가진 환자들 사이에서도 남아 있는 개인 수준 변동이다.

### 변동성 {.unnumbered}

변동성은 개인 간에 실제로 존재하는 자연스러운 차이이다. 같은 치료를 받은 환자라도 생존기간, 비용, 효용, 이상반응 경험은 서로 다를 수 있다. 변동성은 표본 수가 무한히 커져도 사라지지 않는다. 예를 들어 비용자료에서 개인별 총 비용 $C_i$가 다음과 같은 분포를 따른다고 하자.

$$
C_i\mid X_i=x \sim F_C(c\mid x).
$$

이 분포의 폭은 실제 환자 간 비용 차이를 나타낸다. PSA는 보통 모수의 불확실성을 평가하는 방법이지, 개인 간 변동성을 그대로 반복해서 평균 비용의 불확실성으로 해석하는 방법이 아니다. 환자 수준 시뮬레이션에서는 개인 간 변동성과 모수 불확실성을 구분하여 1차 불확실성(first-order uncertainty)과 2차 불확실성(second-order uncertainty)으로 나누어 다루는 것이 좋다.

### 이질성 {.unnumbered}

이질성은 환자 특성에 따라 평균 비용이나 평균 효과가 체계적으로 달라지는 현상이다. 예를 들어 바이오마커 양성 환자에서 치료효과가 더 크거나, 고위험군에서 기준 사건위험이 높아 절대효과가 커지는 경우가 이에 해당한다.

하위군 $X=x$에서의 증분 QALY와 증분비용은 다음과 같이 표현할 수 있다.

$$
\Delta Q(x)=\mu_{Q,1}(x)-\mu_{Q,0}(x), \qquad
\Delta C(x)=\mu_{C,1}(x)-\mu_{C,0}(x).
$$

따라서 조건부 증분순편익은 다음과 같다.

$$
INB(\lambda\mid X=x)=\lambda\Delta Q(x)-\Delta C(x).
$$

이질성이 크면 전체 모집단에서의 평균 결과만으로는 충분하지 않다. 특정 하위군에 대해서만 급여하거나, 위험도 기반으로 치료 대상을 제한하는 의사결정이 필요할 수 있다.

### 모수 불확실성 {.unnumbered}

모수 불확실성은 치료효과, 비용, 효용, 전이확률, 생존모형 계수 등 모수의 참값을 정확히 알지 못해서 발생한다. 모수 $\theta$가 알려져 있지 않을 때 분석자는 추정값 $\widehat{\theta}$와 표준오차, 공분산행렬, 또는 사후분포를 이용한다.

빈도론적 관점에서는 다음과 같은 근사를 사용할 수 있다.

$$
\widehat{\theta}\approx N(\theta,\Sigma_{\widehat{\theta}}).
$$

PSA에서는 이 식을 실무적으로 뒤집어 다음과 같이 모수 후보값을 추출한다.

$$
\theta^{(s)}\sim N(\widehat{\theta},\widehat{\Sigma}_{\widehat{\theta}}), \qquad s=1,\ldots,S.
$$

베이지안 관점에서는 모수의 불확실성을 사후분포로 직접 표현한다.

$$
p(\theta\mid y)\propto p(y\mid\theta)p(\theta).
$$

### 전체 분산의 법칙과 개념적 구분 {.unnumbered}

변동성과 이질성은 전체 분산의 법칙을 이용하면 더 명확해진다.

$$
\operatorname{Var}(Y)=\mathbb{E}\{\operatorname{Var}(Y\mid X)\}+\operatorname{Var}\{\mathbb{E}(Y\mid X)\}.
$$

첫 번째 항은 같은 특성을 가진 환자들 사이의 남은 변동성이고, 두 번째 항은 환자 특성 $X$에 따라 평균 결과가 달라지는 이질성이다. 여기에 $\theta$의 불확실성과 모델 구조의 불확실성이 추가되면 경제성 평가의 전체 불확실성이 된다.

모수 불확실성까지 포함하면 분산을 한 단계 더 분해할 수 있다. 모형 구조를 고정하고 $X$와 $\theta$가 모두 불확실하다고 하면,

$$
\operatorname{Var}(Y)
=
\mathbb{E}_{\theta}\!\left[
\mathbb{E}_{X}\{\operatorname{Var}(Y\mid X,\theta)\}
+
\operatorname{Var}_{X}\{\mathbb{E}(Y\mid X,\theta)\}
\right]
+
\operatorname{Var}_{\theta}\{\mathbb{E}(Y\mid\theta)\}.
$$

오른쪽의 세 항은 각각 개인 수준 변동성, 관찰 가능한 환자 특성에 따른 이질성, 모수 불확실성을 나타낸다. 모형 구조 $M$까지 불확실하면 마지막에 $\operatorname{Var}_M\{\mathbb{E}(Y\mid M)\}$에 해당하는 구조적 변동이 추가된다. 이 분해는 모든 불확실성을 하나의 PSA 분포에 무차별적으로 섞지 말아야 하는 이유를 보여준다.

![경제성 평가의 불확실성은 변동성, 이질성, 모수 불확실성, 구조적 불확실성을 구분해 다루어야 한다.](figures/ch06/fig-ch06-uncertainty-taxonomy.png){width="92%"}

위 그림의 범주들은 서로 배타적이지 않다. 예를 들어 환자 위험도의 차이는 관찰 가능한 특성으로 설명되면 이질성이지만, 위험도 분포를 정확히 추정하지 못한 부분은 모수 불확실성이다. 또한 치료효과 소실을 어떤 함수로 표현할지의 문제는 구조적 불확실성이며, 선택한 함수의 계수 추정오차는 그 구조 안의 모수 불확실성이다. 따라서 불확실성의 원인과 분석 방법을 일대일로 대응시켜야 한다.

::: {.callout-note title="실무적 구분"}
변동성은 “환자들이 실제로 다르다”는 문제이고, 이질성은 “어떤 환자군에서 평균 결과가 체계적으로 다르다”는 문제이며, 불확실성은 “우리가 모수나 모형을 충분히 알지 못한다”는 문제이다. 더 많은 연구로 줄일 수 있는 것은 주로 모수 불확실성이다.
:::

## 결정론적 민감도 분석 {#sec-deterministic-sensitivity-analysis}

결정론적 민감도 분석(deterministic sensitivity analysis, DSA)은 하나 또는 몇 개의 입력값을 사전에 정한 범위 안에서 변화시키고, 경제성 평가 결과가 어떻게 달라지는지 확인하는 방법이다. DSA는 특정 입력값이 결론에 미치는 영향을 직관적으로 보여주는 장점이 있다.

기본 분석 모수 벡터를 $\theta_0=(\theta_{1,0},\ldots,\theta_{K,0})$라고 하자. 일원 민감도 분석(one-way sensitivity analysis)은 $k$번째 모수만 낮은 값 $\theta_k^-$ 또는 높은 값 $\theta_k^+$로 바꾸고 나머지는 기본값으로 고정한다.

$$
INB_k^-(\lambda)=INB(\lambda;\theta_{1,0},\ldots,\theta_k^-,\ldots,\theta_{K,0}),
$$

$$
INB_k^+(\lambda)=INB(\lambda;\theta_{1,0},\ldots,\theta_k^+,\ldots,\theta_{K,0}).
$$

모수 $k$가 결과에 미치는 영향은 다음과 같이 요약할 수 있다.

$$
W_k=\left|INB_k^+(\lambda)-INB_k^-(\lambda)\right|.
$$

$W_k$가 클수록 해당 모수는 결과에 큰 영향을 준다. 여러 모수의 $W_k$를 큰 순서로 정렬해 그리면 토네이도 그림이 된다.

일원 민감도 분석은 전역 범위의 변화량을 보여주지만, 국소 민감도는 편미분으로 표현할 수 있다.

$$
S_k=\left.\frac{\partial INB(\lambda;\theta)}{\partial\theta_k}\right|_{\theta=\theta_0}.
$$

모수의 단위가 서로 다르면 절대 미분값을 직접 비교하기 어렵다. 이때는 탄력도 형태의 무차원 민감도 지표를 사용할 수 있다.

$$
E_k=
\left.\frac{\partial INB}{\partial\theta_k}
\frac{\theta_k}{INB}\right|_{\theta=\theta_0}.
$$

다만 $INB$가 0에 가까우면 탄력도가 불안정하므로 해석에 주의해야 한다. 또한 토네이도 막대가 길다는 것은 지정한 범위에서 결과 변화가 크다는 뜻이지, 그 모수가 전체 의사결정 불확실성에 가장 많이 기여한다는 뜻은 아니다. 전체 분산 기여도는 PSA 기반 분산분해나 EVPPI와 같은 별도 분석으로 평가해야 한다.

![일원 민감도 분석은 각 입력값을 낮은 값과 높은 값으로 바꾸었을 때 증분순편익이 얼마나 달라지는지 보여준다.](figures/ch06/fig-ch06-tornado.png){width="88%"}

위 토네이도 그림은 기본값을 중심으로 각 모수를 한 번에 하나씩 변화시킨 결과이다. 막대의 양 끝이 모두 0보다 크면 지정한 범위에서는 의사결정이 바뀌지 않고, 막대가 0을 가로지르면 그 모수의 가능한 범위 안에서 비용효과성 판단이 역전될 수 있다. 막대 길이는 범위의 폭에도 의존하므로, 서로 다른 근거로 정한 범위를 사용할 때는 단순 순위 비교를 과도하게 해석하지 않아야 한다.

### 민감도 분석 범위의 설정 {.unnumbered}

DSA에서 가장 중요한 실무적 판단은 입력값의 범위이다. 범위는 임의로 정하면 안 되며, 가능한 한 다음 근거를 사용해야 한다.

- 추정치의 95% 신뢰구간 또는 credible interval
- 메타분석 또는 네트워크 메타분석의 예측구간
- 임상 전문가가 판단한 임상적으로 가능한 범위
- 국내 단가, 약가, 진료패턴의 plausible range
- 생존외삽, 치료효과 지속, 할인율과 같은 구조적 가정의 대안 시나리오

모수 불확실성에 해당하는 범위는 PSA의 확률분포와 일관되어야 한다. 반면 구조적 가정은 단순히 확률분포를 부여하기보다 시나리오 분석으로 제시하는 것이 더 투명할 수 있다.

신뢰구간의 양 끝을 그대로 낮은 값과 높은 값으로 사용하는 관행도 항상 적절한 것은 아니다. 신뢰구간은 추정량의 불확실성을 나타내지만, 임상적으로 가능한 범위나 미래 환경에서의 변화 범위와 동일하지 않다. 비용 단가처럼 정책적으로 조정 가능한 입력은 정책 범위를, 치료효과처럼 추정된 모수는 통계적 불확실성 범위를, 치료효과 지속기간처럼 구조적 가정은 임상적으로 타당한 대안 시나리오를 사용하는 것이 합리적이다.

### 역치 분석 {.unnumbered}

역치 분석(threshold analysis)은 특정 모수가 어떤 값을 가질 때 의사결정이 바뀌는지 찾는 방법이다. 예를 들어 어떤 모수 $\theta_k$에 대해 $INB(\lambda;\theta_k)=0$을 만족하는 값을 $\theta_k^*$라고 하면, 이 값은 비용효과성 판단의 경계가 된다.

$$
INB(\lambda;\theta_k^*)=0.
$$

만약 $INB$가 $\theta_k$ 근처에서 선형이라고 근사할 수 있으면,

$$
INB(\lambda;\theta_k)\approx a+b\theta_k
$$

이고 역치값은 다음과 같다.

$$
\theta_k^*=-\frac{a}{b}.
$$

실무에서는 약가, 투약기간, 치료효과 지속기간, 효용 차이, 사망률 등의 역치값이 정책적으로 유용할 수 있다. 예를 들어 “신약의 월 약가가 어느 수준 이하이면 비용효과적인가?” 또는 “치료효과가 몇 년 이상 유지되어야 비용효과적인가?”와 같은 질문에 답할 수 있다.

### 이원 민감도 분석 {.unnumbered}

이원 민감도 분석(two-way sensitivity analysis)은 두 입력값을 동시에 변화시킨다. 예를 들어 치료효과와 약가를 함께 변화시키면, 어떤 조합에서 신약이 비용효과적인지 시각적으로 확인할 수 있다.

![이원 민감도 분석은 두 입력값의 조합에 따라 $INB(\lambda)$가 양수 또는 음수가 되는 영역을 보여준다.](figures/ch06/fig-ch06-two-way-sensitivity.png){width="88%"}

위 그림의 경계선은 $INB(\lambda;\theta_1,\theta_2)=0$을 만족하는 모수 조합이다. 경계선이 직선이 아니면 두 모수가 결과에 비선형적으로 작용하거나 상호작용한다는 뜻이다. 두 모수의 결합효과는 국소적으로 다음 교차편미분으로 평가할 수 있다.

$$
\frac{\partial^2 INB}{\partial\theta_1\partial\theta_2}.
$$

이 값이 0이 아니면 한 모수의 영향이 다른 모수의 수준에 따라 달라진다. 따라서 이원 민감도 분석은 단순히 두 개의 일원 분석을 겹친 것이 아니라, 모수 간 상호작용과 의사결정 경계를 확인하는 분석이다.

DSA는 결과를 설명하기 쉽지만, 여러 모수가 동시에 불확실하다는 사실을 충분히 반영하지 못한다. 특히 모수들 간 상관성이 있거나 비선형 모형에서 여러 입력값이 함께 변할 때는 DSA만으로 의사결정 불확실성을 평가하기 어렵다. 이를 보완하기 위해 PSA가 필요하다.

## 확률론적 민감도 분석 {#sec-probabilistic-sensitivity-analysis}

확률론적 민감도 분석(probabilistic sensitivity analysis, PSA)은 불확실한 모수에 확률분포를 부여하고, 그 분포에서 반복적으로 모수를 추출하여 경제성 평가 결과의 분포를 계산하는 방법이다. PSA는 여러 모수의 불확실성을 동시에 반영하며, 비용효과평면, 비용효과수용곡선, 순편익 분포를 통해 의사결정 불확실성을 표현한다.

모수 벡터를 $\theta$라고 하고, 그 불확실성 분포를 $G(\theta)$라고 하자. PSA는 다음 절차로 수행된다.

여기서 $G(\theta)$는 개별 입력분포의 단순한 곱이 아니라, 가능한 경우 모수 간 상관성을 포함하는 결합분포이어야 한다. PSA의 목적은 입력 모수의 불확실성을 모형의 결과로 전파하는 것이다. 수학적으로는 모형 출력 $h(\theta)$의 유도분포를

$$
F_h(z)=\int I\{h(\theta)\le z\}\,dG(\theta)
$$

와 같이 평가하는 과정으로 볼 수 있다. 실제로 이 적분은 해석적으로 계산하기 어려우므로 Monte Carlo 표본으로 근사한다.

1. 불확실한 모수와 그 분포 $G(\theta)$를 정의한다.
2. $s=1,\ldots,S$에 대해 $\theta^{(s)}\sim G(\theta)$를 추출한다.
3. 각 추출값에서 모형을 실행하여 $\Delta C^{(s)}$, $\Delta Q^{(s)}$를 계산한다.
4. 각 반복에서 $INB^{(s)}(\lambda)=\lambda\Delta Q^{(s)}-\Delta C^{(s)}$를 계산한다.
5. $INB^{(s)}(\lambda)>0$인 비율로 비용효과확률을 추정한다.

PSA 기반 비용효과확률은 다음과 같다.

$$
\widehat{P}_{CE}(\lambda)=\frac{1}{S}\sum_{s=1}^{S} I\{INB^{(s)}(\lambda)>0\}.
$$

여기서 $I(\cdot)$는 조건이 참이면 1, 거짓이면 0인 지시함수이다. 이 값을 여러 $\lambda$ 값에 대해 계산하면 비용효과수용곡선(cost-effectiveness acceptability curve, CEAC)이 된다.

PSA에서 평균 증분순편익은 다음과 같이 추정한다.

$$
\widehat{\mathbb{E}}\{INB(\lambda)\}=\frac{1}{S}\sum_{s=1}^{S} INB^{(s)}(\lambda).
$$

Monte Carlo 반복 수가 충분하지 않으면 PSA 결과 자체에도 시뮬레이션 오차가 남는다. 비용효과확률의 Monte Carlo 표준오차는 다음과 같이 근사할 수 있다.

$$
SE_{MC}\{\widehat{P}_{CE}(\lambda)\}=\sqrt{\frac{\widehat{P}_{CE}(\lambda)\{1-\widehat{P}_{CE}(\lambda)\}}{S}}.
$$

따라서 CEAC의 값이 0.50 근처이고 반복 수가 적으면, 단순한 Monte Carlo 오차만으로도 결과가 흔들릴 수 있다.

평균 증분순편익의 Monte Carlo 표준오차는 PSA 반복값의 표준편차를 이용해 다음과 같이 추정한다.

$$
SE_{MC}\{\overline{INB}(\lambda)\}
=
\frac{s_{INB}(\lambda)}{\sqrt{S}}.
$$

독립 추출이라면 중심극한정리에 따라

$$
\sqrt{S}\left[\overline{INB}(\lambda)-
\mathbb{E}\{INB(\lambda)\}\right]
\xrightarrow{d}
N\left(0,\operatorname{Var}\{INB(\lambda)\}\right).
$$

따라서 반복 수는 관행적으로 정하기보다 주요 의사결정 지표의 Monte Carlo 표준오차가 충분히 작아질 때까지 늘리는 것이 바람직하다. MCMC 사후표본을 사용하는 경우 표본 간 자기상관 때문에 명목 반복 수 대신 유효표본크기를 사용해야 한다.

::: {.callout-warning title="ICER 평균을 계산하지 말 것"}
PSA 반복마다 $ICER^{(s)}=\Delta C^{(s)}/\Delta Q^{(s)}$를 계산할 수는 있지만, $ICER^{(s)}$의 평균은 일반적으로 의미 있는 의사결정 척도가 아니다. $\Delta Q^{(s)}$가 0에 가까운 반복에서 비율이 폭발할 수 있기 때문이다. PSA 결과는 평균 비용, 평균 QALY, INB, CE plane, CEAC 중심으로 보고하는 것이 좋다.
:::

![PSA 반복값은 비용효과평면에서 점 구름으로 표현된다. 기준선 아래의 점들은 해당 지불의사금액에서 $INB(\lambda)>0$인 경우이다.](figures/ch06/fig-ch06-psa-ce-plane.png){width="88%"}

위 비용효과평면의 점 구름은 증분비용과 증분효과의 주변분포뿐 아니라 두 결과의 상관성도 보여준다. 점 구름이 길고 기울어진 형태라면 비용과 효과가 강하게 연관되어 있음을 뜻한다. 사분면별 점의 비율은 신약이 더 효과적이면서 더 비싼지, 우월하거나 열등한지에 대한 확률적 정보를 제공하지만, 최종 의사결정은 각 점의 순편익과 그 평균에 기반해야 한다.

![CEAC는 지불의사금액 변화에 따른 비용효과확률을 보여준다. 이 곡선은 기대순편익을 최대화하는 전략 선택 규칙과 함께 해석해야 한다.](figures/ch06/fig-ch06-ceac.png){width="88%"}

위 곡선의 높이는 효과가 통계적으로 유의할 확률이 아니라, 주어진 지불의사금액에서 순편익이 가장 큰 전략이 될 확률을 나타낸다. 곡선이 0.5를 넘는 지점은 기대순편익의 부호가 바뀌는 역치와 반드시 일치하지 않으며, 여러 전략을 비교할 때는 가장 높은 CEAC를 기계적으로 선택해서는 안 된다.

### 비용효과수용곡선, 수용경계와 기대손실 {.unnumbered}

두 전략을 비교할 때 CEAC는 $P\{INB(\lambda)>0\}$를 나타낸다. 전략이 여러 개라면 전략 $j$의 비용효과수용곡선은 해당 전략의 순편익이 모든 전략 중 가장 큰 확률로 정의할 수 있다.

$$
CEAC_j(\lambda)
=
P\left[
NB_j(\lambda,\theta)=\max_{k\in\mathcal{J}}NB_k(\lambda,\theta)
\right].
$$

그러나 가장 높은 비용효과확률을 가진 전략이 기대순편익이 가장 큰 전략과 다를 수 있다. 비용효과수용경계(cost-effectiveness acceptability frontier, CEAF)는 각 $\lambda$에서 기대순편익을 최대화하는 전략 $j^*(\lambda)$의 최적일 확률을 표시한다.

$$
CEAF(\lambda)=CEAC_{j^*(\lambda)}(\lambda).
$$

의사결정의 불확실성은 기대기회손실로도 표현할 수 있다. 현재 전략 $j$를 선택했을 때 모수값 $\theta$에서의 기회손실은

$$
OL_j(\theta,\lambda)
=
\max_k NB_k(\theta,\lambda)-NB_j(\theta,\lambda)
$$

이고, 기대기회손실은 $\mathbb{E}_{\theta}\{OL_j(\theta,\lambda)\}$이다. 기대순편익을 최대화하는 전략은 기대기회손실을 최소화하는 전략과 같다. CEAC는 선택의 확률을 보여주고, 기대기회손실은 잘못된 선택이 초래하는 결과의 크기까지 반영한다.

### 1차 불확실성과 2차 불확실성 {.unnumbered}

환자 수준 시뮬레이션에서는 1차 불확실성과 2차 불확실성을 구분해야 한다. 1차 불확실성은 같은 모수값 아래에서도 환자 경로가 무작위로 달라지는 개인 수준 변동이다. 2차 불확실성은 모수 $\theta$의 참값을 알지 못하는 데서 생기는 불확실성이다.

경제성 평가의 의사결정은 보통 **현재 모수 불확실성하에서 기대값이 가장 큰 전략**을 선택하는 문제이다. 따라서 PSA에서는 2차 불확실성을 반영하는 것이 핵심이다. 환자 수준 모델에서 각 PSA 반복마다 환자 수가 너무 적으면 1차 Monte Carlo 오차가 2차 모수 불확실성과 섞인다. 이를 줄이려면 각 모수 추출값에서 충분히 많은 환자를 시뮬레이션하거나, common random numbers를 사용하거나, 코호트 모델과 환자 수준 모델의 결과를 검증해야 한다.

중첩 시뮬레이션을 수식으로 나타내면, 외부 반복에서 모수 $\theta^{(s)}$를 추출하고 내부 반복에서 환자 결과 $Y_{sr}$를 생성한다.

$$
\theta^{(s)}\sim G(\theta),\qquad
Y_{sr}\sim p(y\mid\theta^{(s)}),
\qquad r=1,\ldots,R.
$$

각 외부 반복의 조건부 평균은

$$
\overline{Y}_s=\frac{1}{R}\sum_{r=1}^{R}Y_{sr}
$$

로 추정한다. $R$이 작으면 $\overline{Y}_s$의 변동에 1차 오차가 크게 남고, 이것이 모수 불확실성처럼 보일 수 있다. 공통 난수는 비교 전략에서 같은 난수 흐름을 사용하여 증분결과의 분산을 줄이는 방법이며, 전략 간 공분산을 증가시켜 $\operatorname{Var}(Y_1-Y_0)$를 감소시킨다.

## 확률론적 민감도 분석에 자주 사용되는 확률분포 {#sec-distributions-for-psa}

PSA에서 확률분포는 모수의 가능한 값 범위와 통계적 성격에 맞게 선택해야 한다. 확률은 0과 1 사이, 비용과 위험률은 양수, 회귀계수는 실수 전체, 다항 전이확률은 합이 1이 되어야 한다. 이 제약을 무시하면 PSA 반복에서 불가능한 값이 생성될 수 있다.

여기서 PSA 입력분포는 환자 수준 관찰값의 분포와 모수 추정량의 불확실성 분포를 구분해야 한다. 예를 들어 개인별 입원비가 감마분포를 따른다고 해서 평균 입원비의 추정 불확실성도 동일한 감마분포를 따르는 것은 아니다. PSA에는 모형에 입력되는 평균 비용이나 회귀계수의 불확실성을 반영해야 하며, 가능하면 원자료 분석에서 얻은 공분산행렬이나 부트스트랩 표본을 사용해야 한다.

분포 선택은 지지집합만 맞추는 문제가 아니다. 평균, 분산, 왜도, 모수 간 의존구조와 자료 생성과정을 함께 고려해야 한다. 동일한 평균과 표준오차를 갖더라도 베타분포와 로짓정규분포는 꼬리 형태가 다르며, 비선형 모형에서는 이 차이가 결과에 영향을 줄 수 있다.

| 모수 유형 | 값의 범위 | 자주 사용하는 분포 | 예 |
|---|---:|---|---|
| 사건확률 | $0<p<1$ | Beta | 이상반응 확률, 반응률 |
| 효용 | 보통 제한된 범위 | Beta, truncated normal, mixture | EQ-5D utility |
| 비용 | $c>0$ | Gamma, lognormal | 약제비 외 비용, 입원비 |
| 발생률·위험률 | $r>0$ | Gamma, lognormal | 전이율, 사망률 |
| 상대위험·위험비·오즈비 | $>0$ | Lognormal | HR, RR, OR |
| 회귀계수 | 실수 전체 | Normal, multivariate normal | 선형예측자 계수 |
| 전이확률 벡터 | $p_k>0$, $\sum_k p_k=1$ | Dirichlet, logistic-normal | 다상태 전이확률 |
| 생존모형 모수 | 모수화에 따라 다름 | Multivariate normal on transformed scale | Weibull, Gompertz, spline 계수 |

![PSA에서 사용하는 분포는 모수의 범위 제약을 반영해야 한다.](figures/ch06/fig-ch06-distribution-families.png){width="94%"}

위 그림은 분포 선택의 출발점을 값의 범위로 제시하지만, 동일한 범위를 갖는 모수라도 자료 생성과정에 따라 적절한 분포가 달라질 수 있다. 예를 들어 확률 하나에는 베타분포가 편리하지만, 여러 전이확률의 합이 1이어야 하면 디리클레분포나 logistic-normal 분포가 필요하다. 또한 회귀모형에서 추정된 모수는 원자료의 경험적 분포가 아니라 추정계수의 공동분포를 사용해야 한다.

### 베타분포 {.unnumbered}

베타분포는 0과 1 사이의 확률이나 효용에 자주 사용된다.

$$
p\sim Beta(\alpha,\beta).
$$

평균과 분산은 다음과 같다.

$$
\mathbb{E}(p)=\frac{\alpha}{\alpha+\beta},
$$

$$
\operatorname{Var}(p)=\frac{\alpha\beta}{(\alpha+\beta)^2(\alpha+\beta+1)}.
$$

평균 $\mu$와 표준오차 $s$가 주어졌을 때 $\alpha$, $\beta$는 다음과 같이 계산할 수 있다.

$$
\phi=\frac{\mu(1-\mu)}{s^2}-1,
$$

$$
\alpha=\mu\phi, \qquad \beta=(1-\mu)\phi.
$$

이때 $0<s^2<\mu(1-\mu)$이어야 한다. 이 조건을 만족하지 않으면 입력된 평균과 표준오차가 베타분포와 양립하기 어렵다.

$\phi=\alpha+\beta$는 분포의 정밀도 또는 유효표본크기와 유사한 역할을 한다. $\mu$가 같을 때 $\phi$가 클수록 분포가 평균 주변에 집중한다. 이 해석은 전문가 의견이나 외부자료를 베타분포로 변환할 때 유용하지만, 실제 표본크기와 동일하다고 기계적으로 해석해서는 안 된다.

효용값에 베타분포를 사용할 때는 척도의 범위를 확인해야 한다. EQ-5D와 같이 0보다 작은 값이 가능한 효용척도에는 표준 베타분포를 직접 사용할 수 없다. 이 경우 선형변환한 베타분포, 절단정규분포, 로짓정규분포, 점질량을 포함한 혼합분포를 고려할 수 있다. 특히 완전건강 1에 큰 점질량이 있으면 연속 베타분포 하나로는 분포 형태를 충분히 표현하지 못한다.

### 감마분포 {.unnumbered}

감마분포는 비용, 발생률, 위험률처럼 양수인 모수에 자주 사용된다. shape-scale 모수화를 사용하면 다음과 같이 쓴다.

$$
X\sim Gamma(\alpha,\theta).
$$

평균과 분산은 다음과 같다.

$$
\mathbb{E}(X)=\alpha\theta, \qquad \operatorname{Var}(X)=\alpha\theta^2.
$$

평균 $m$과 표준편차 $s$가 주어지면 다음처럼 계산한다.

$$
\alpha=\frac{m^2}{s^2}, \qquad \theta=\frac{s^2}{m}.
$$

R의 `rgamma()`는 `shape`와 `rate` 또는 `scale`을 사용할 수 있다. `rate`는 `scale`의 역수이다.

감마분포의 변동계수는 $CV=1/\sqrt{\alpha}$이므로 shape가 작을수록 오른쪽 왜도가 커진다. 다만 비용 회귀모형에서 추정한 평균 비용을 PSA에 반영할 때는 관찰된 개인비용의 감마분포에서 직접 추출하기보다, 회귀계수의 다변량 분포에서 계수를 추출한 뒤 예측평균을 계산하는 것이 원래 분석의 불확실성 구조를 더 잘 보존한다.

$$
rate=\frac{1}{\theta}=\frac{m}{s^2}.
$$

### 로그정규분포 {.unnumbered}

로그정규분포는 양수이고 오른쪽 꼬리가 긴 비용, 상대효과, 위험률에 적합하다. $X$가 로그정규분포를 따르면 다음과 같이 쓸 수 있다.

$$
\log X\sim N(\mu_L,\sigma_L^2).
$$

이때 평균과 분산은 다음과 같다.

$$
\mathbb{E}(X)=\exp\left(\mu_L+\frac{\sigma_L^2}{2}\right),
$$

$$
\operatorname{Var}(X)=\left\{\exp(\sigma_L^2)-1\right\}\exp(2\mu_L+\sigma_L^2).
$$

원척도의 평균 $m$과 표준편차 $s$가 주어지면 로그척도 모수는 다음과 같이 계산한다.

$$
\sigma_L^2=\log\left(1+\frac{s^2}{m^2}\right),
$$

$$
\mu_L=\log(m)-\frac{1}{2}\sigma_L^2.
$$

로그정규분포에서는 $\exp(\mu_L)$가 원척도 평균이 아니라 중앙값이다. 따라서 로그척도 추정치를 단순 지수변환하면 산술평균 비용을 과소추정할 수 있다. 회귀모형의 예측평균에는 $\exp(\sigma_L^2/2)$에 해당하는 재변환 보정이 필요하며, 이분산성이 있으면 단일 보정계수만으로 충분하지 않을 수 있다. PSA에서는 로그척도 위치모수와 분산모수의 공동 불확실성을 함께 반영해야 한다.

### 디리클레분포 {.unnumbered}

한 상태에서 여러 상태로 이동하는 전이확률은 합이 1이어야 한다. 예를 들어 상태 $r$에서 다음 주기에 상태 $1,\ldots,K$로 이동할 확률 벡터를 $\boldsymbol{p}_r=(p_{r1},\ldots,p_{rK})$라고 하면 다음 조건을 만족해야 한다.

$$
p_{rk}\ge 0, \qquad \sum_{k=1}^K p_{rk}=1.
$$

이런 경우 디리클레분포를 사용할 수 있다.

$$
\boldsymbol{p}_r\sim Dirichlet(\alpha_{r1},\ldots,\alpha_{rK}).
$$

평균은 다음과 같다.

$$
\mathbb{E}(p_{rk})=\frac{\alpha_{rk}}{\alpha_{r0}}, \qquad \alpha_{r0}=\sum_{k=1}^K \alpha_{rk}.
$$

관찰된 전이 수가 $n_{rk}$라면 $\alpha_{rk}=n_{rk}$ 또는 사전정보를 더한 $\alpha_{rk}=n_{rk}+a_{rk}$를 사용할 수 있다. 집계자료가 없고 평균 전이확률 $\bar p_{rk}$와 유효표본크기 $N_{eff}$만 사용할 수 있다면 $\alpha_{rk}=N_{eff}\bar p_{rk}$로 설정하기도 한다.

디리클레분포에서는 구성요소 사이에 음의 공분산이 유도된다.

$$
\operatorname{Var}(p_{rk})=
\frac{\alpha_{rk}(\alpha_{r0}-\alpha_{rk})}
{\alpha_{r0}^2(\alpha_{r0}+1)},
$$

$$
\operatorname{Cov}(p_{rk},p_{r\ell})=
-\frac{\alpha_{rk}\alpha_{r\ell}}
{\alpha_{r0}^2(\alpha_{r0}+1)},\qquad k\ne \ell.
$$

이는 한 전이확률이 커지면 다른 전이확률의 합이 줄어야 한다는 제약을 반영한다. 그러나 디리클레분포는 공분산 구조가 제한적이다. 더 유연한 의존구조가 필요하면 기준 범주에 대한 로그비를 다변량 정규분포로 두는 logistic-normal 모형을 사용할 수 있다.

## 상대위험에 대한 확률분포 {#sec-distribution-for-relative-risk}

상대위험, 위험비, 오즈비는 모두 양수이므로 원척도에서 정규분포를 사용하면 음수 값이 생성될 수 있다. 따라서 보통 로그척도에서 정규분포를 가정한다.

상대효과를 $R$이라고 하자. $R$은 위험비 $HR$, 상대위험 $RR$, 오즈비 $OR$일 수 있다. PSA에서는 다음과 같이 설정한다.

$$
\log R\sim N(\mu_R,\sigma_R^2).
$$

점추정값이 $\widehat R$이면 일반적으로 $\mu_R=\log(\widehat R)$로 둔다. 95% 신뢰구간이 $(L,U)$이면 로그표준오차는 다음과 같이 계산한다.

$$
SE\{\log(\widehat R)\}=\frac{\log(U)-\log(L)}{2z_{0.975}}.
$$

여기서 $z_{0.975}=1.96$이다. 따라서 PSA 반복에서는 다음과 같이 추출한다.

$$
R^{(s)}=\exp\left[\log(\widehat R)+SE\{\log(\widehat R)\}Z^{(s)}\right], \qquad Z^{(s)}\sim N(0,1).
$$

### 상대효과를 절대위험에 적용하기 {.unnumbered}

상대효과를 경제성 평가 모형에 사용할 때 가장 흔한 오류는 $HR$, $RR$, $OR$를 모두 같은 방식으로 기준 사건확률에 곱하는 것이다. 세 척도는 서로 다른 수학적 대상에 작용한다.

기준 사건확률을 $p_0$라고 하자. 상대위험 $RR$이 같은 시간 구간의 누적위험에 대해 정의되었다면 치료군 사건확률은 다음과 같이 계산할 수 있다.

$$
p_1=RR\times p_0.
$$

단, 이 값은 1을 넘을 수 없으며, 누적위험이 큰 경우에는 단순 곱셈이 부적절할 수 있다.

오즈비 $OR$가 주어졌다면 먼저 기준 오즈를 계산한 뒤 오즈에 $OR$를 곱해야 한다.

$$
\frac{p_1}{1-p_1}=OR\times\frac{p_0}{1-p_0}.
$$

이를 $p_1$에 대해 풀면 다음과 같다.

$$
p_1=\frac{OR\,p_0}{1-p_0+OR\,p_0}.
$$

위험비 $HR$가 비례위험 가정하에서 주어지고, 기준 생존확률이 $S_0(t)$라면 치료군 생존확률은 다음과 같다.

$$
S_1(t)=S_0(t)^{HR}.
$$

따라서 기준 사건확률 $p_0(t)=1-S_0(t)$에 대응하는 치료군 사건확률은 다음과 같다.

$$
p_1(t)=1-\{1-p_0(t)\}^{HR}.
$$

사건률 $r_0$와 rate ratio $RR_r$가 주어졌다면 다음과 같이 전이확률을 계산한다.

$$
r_1=RR_r r_0, \qquad p_1(\Delta t)=1-\exp(-r_1\Delta t).
$$

기준위험과 상대효과가 서로 다른 자료원에서 추정되더라도 독립이라고 단정할 수는 없다. 동일 연구나 계층모형에서 함께 추정되었다면 두 모수의 공분산을 유지해야 한다. 치료군 절대위험 $p_1=f(p_0,R)$의 근사분산은 델타방법으로

$$
\operatorname{Var}(p_1)
\approx
\nabla f^{\mathsf T}
\begin{pmatrix}
\operatorname{Var}(p_0) & \operatorname{Cov}(p_0,R)\\
\operatorname{Cov}(p_0,R) & \operatorname{Var}(R)
\end{pmatrix}
\nabla f
$$

와 같이 표현할 수 있다. 공분산을 무시하면 절대효과의 불확실성이 왜곡될 수 있다.

위험비를 이용한 $S_1(t)=S_0(t)^{HR}$는 비례위험 가정이 성립할 때만 타당하다. 치료효과가 시간에 따라 변하면 $HR(t)$ 또는 시간구간별 효과를 사용해야 하며,

$$
S_1(t)=\exp\left[-\int_0^t HR(u)h_0(u)\,du\right]
$$

로 일반화된다. 단일 HR를 장기 외삽 전체에 적용하면 치료효과 지속에 관한 강한 구조적 가정을 암묵적으로 도입하게 된다.

![동일한 숫자 0.65라도 RR, OR, HR은 절대 사건확률에 서로 다른 방식으로 작용한다.](figures/ch06/fig-ch06-relative-effect-transform.png){width="88%"}

위 그림에서 기준위험이 낮을 때는 RR, OR, HR로 변환한 절대위험이 비슷해 보일 수 있지만, 기준위험이 커질수록 차이가 확대된다. 따라서 희귀사건 근사에 기대어 OR를 RR처럼 사용하거나, HR를 누적위험에 직접 곱하는 오류는 고위험군과 장기 분석에서 더 큰 편향을 만든다.

::: {.callout-important title="상대효과 적용의 원칙"}
상대위험은 위험에, 오즈비는 오즈에, 위험비는 위험함수 또는 생존함수에 적용해야 한다. 특히 생존분석 또는 네트워크 메타분석에서 얻은 HR를 단순히 주기별 전이확률에 곱하면 치료효과를 잘못 반영할 수 있다.
:::

## 모수들 간의 상관성을 반영하기 {#sec-correlation-between-parameters}

PSA에서는 모수를 독립적으로 추출하는 경우가 많지만, 실제로는 여러 모수가 서로 상관되어 있다. 상관성을 무시하면 불확실성을 과소평가하거나 과대평가할 수 있고, 불가능한 조합의 모수값이 생성될 수도 있다.

순편익이 모수의 함수 $g(\theta)$일 때 델타방법에 의한 근사분산은 다음과 같다.

$$
\operatorname{Var}\{g(\theta)\}
\approx
\nabla g(\mu)^{\mathsf T}\Sigma\nabla g(\mu).
$$

이 식의 비대각 원소는 모수 간 공분산의 기여를 나타낸다. 두 모수만 있는 경우,

$$
\operatorname{Var}(g)
\approx
g_1^2\sigma_1^2+g_2^2\sigma_2^2
+2g_1g_2\sigma_{12}.
$$

공분산항의 부호는 전체 불확실성을 증가시키거나 감소시킬 수 있다. 따라서 상관성을 무시하면 항상 보수적이거나 항상 낙관적인 결과가 되는 것이 아니라, 모형의 민감도 방향에 따라 어느 쪽으로도 왜곡될 수 있다.

예를 들어 회귀모형의 절편과 기울기는 보통 상관되어 있다. Weibull 생존모형의 shape와 scale, Gompertz 모형의 계수, spline 기반 생존모형의 계수, 네트워크 메타분석에서 여러 치료효과 추정치 역시 공분산을 가진다. 이런 경우 모수 벡터 전체를 함께 추출해야 한다.

모수 벡터를 $\boldsymbol{\theta}$라고 하고 평균 벡터와 공분산행렬을 각각 $\boldsymbol{\mu}$, $\Sigma$라고 하자.

$$
\boldsymbol{\theta}\sim N_p(\boldsymbol{\mu},\Sigma).
$$

Cholesky 분해를 이용하면 $\Sigma=LL^{\mathsf{T}}$이고, $\boldsymbol{z}^{(s)}\sim N_p(\boldsymbol{0},I)$일 때 다음처럼 상관된 모수를 생성할 수 있다.

$$
\boldsymbol{\theta}^{(s)}=\boldsymbol{\mu}+L\boldsymbol{z}^{(s)}.
$$

양수 모수는 로그척도에서 다변량 정규분포를 적용한 뒤 지수변환한다.

$$
\log\boldsymbol{\eta}^{(s)}\sim N_p(\boldsymbol{\mu}_{\log\eta},\Sigma_{\log\eta}), \qquad
\boldsymbol{\eta}^{(s)}=\exp\{\log\boldsymbol{\eta}^{(s)}\}.
$$

![상관된 모수를 독립적으로 추출하면 실제 불확실성 구조를 왜곡할 수 있다.](figures/ch06/fig-ch06-correlation.png){width="82%"}

위 그림의 타원형 점 구름은 공분산행렬이 허용하는 모수 조합을 나타낸다. 독립 추출은 이 타원을 축과 평행한 원형 또는 직사각형 범위로 바꾸어 실제로 거의 발생하지 않는 조합을 생성할 수 있다. 생존곡선의 절편과 기울기처럼 상관성이 큰 모수에서는 이러한 왜곡이 장기 외삽의 꼬리 부분에서 특히 커질 수 있다.

전이확률도 독립 추출에 주의해야 한다. 예를 들어 한 상태에서 세 개의 상태로 이동하는 확률 $p_1$, $p_2$, $p_3$가 있을 때 각각을 독립 베타분포에서 추출하면 합이 1이 되지 않을 수 있다. 이 경우 디리클레분포 또는 다항 로짓 변환을 사용하는 것이 더 적절하다.

공분산행렬은 양의 준정부호여야 Cholesky 분해가 가능하다. 반올림되거나 서로 다른 출처에서 조합된 상관계수로 구성한 행렬은 이 조건을 위반할 수 있다. 이 경우 임의로 상관성을 제거하기보다 원자료 또는 모형의 분산-공분산행렬을 다시 확보하고, 필요한 경우 가장 가까운 양의 정부호 행렬로 보정한 근거를 보고해야 한다. 서로 다른 주변분포를 유지하면서 의존구조를 반영해야 할 때는 copula 접근도 사용할 수 있지만, copula의 선택 자체가 추가적인 구조적 가정이 된다.

## 빈도론적 확률론적 민감도 분석의 절차 {#sec-frequentist-psa}

빈도론적 PSA는 추정량의 표준오차와 공분산행렬을 이용해 모수 불확실성을 근사하는 접근이다. 가장 기본적인 아이디어는 다음과 같다.

이 접근은 대개 최대가능도 추정량의 점근적 정규성을 이용한 모수적 부트스트랩과 유사하다. 표본크기가 작거나 모수가 경계에 있거나 가능도 표면이 비대칭이면 정규근사가 좋지 않을 수 있다. 이런 경우 변환척도, 프로파일 가능도, 비모수 부트스트랩 또는 원 분석모형의 재적합을 고려해야 한다.

$$
\widehat{\theta}\approx N(\theta,\widehat{\Sigma}_{\widehat{\theta}}).
$$

실무에서는 모수의 불확실성을 나타내기 위해 다음과 같이 추정값 주변에서 모수를 추출한다.

$$
\theta^{(s)}\sim N(\widehat{\theta},\widehat{\Sigma}_{\widehat{\theta}}).
$$

모수가 확률, 비용, 상대효과처럼 제약된 범위를 가진 경우에는 적절한 변환척도에서 정규근사를 적용하거나 베타, 감마, 로그정규분포를 사용한다.

빈도론적 PSA의 일반 절차는 다음과 같다.

1. 기본 분석의 모수 추정값 $\widehat{\theta}$를 정리한다.
2. 각 모수의 표준오차, 신뢰구간, 공분산행렬을 수집한다.
3. 모수의 범위와 척도에 맞는 확률분포를 지정한다.
4. 상관된 모수는 공분산행렬을 이용해 함께 추출한다.
5. 각 반복에서 모형을 실행하고 $\Delta C^{(s)}$, $\Delta Q^{(s)}$, $INB^{(s)}(\lambda)$를 저장한다.
6. CE plane, CEAC, 순편익 분포, 비용효과확률을 보고한다.

### 비모수 부트스트랩과 모수적 PSA {.unnumbered}

임상시험 기반 경제성 평가에서는 비모수 부트스트랩을 사용할 수 있다. 환자 단위 자료 $(C_i,Q_i,A_i)$가 있을 때, 치료군별로 환자를 재표본추출하고 각 표본에서 $\Delta C$와 $\Delta Q$를 다시 계산한다. 이 방법은 비용과 QALY의 상관성, 비정규성, 오른쪽 꼬리 등을 어느 정도 반영할 수 있다.

모형 기반 경제성 평가에서는 모수적 PSA가 더 일반적이다. 각 입력 모수에 확률분포를 지정하고, 모형을 반복 실행한다. 이때 입력분포가 임상시험, 메타분석, 생존모형, 청구자료, 전문가 의견 등 다양한 자료원에서 오므로 분포 선택과 상관성 반영을 투명하게 보고해야 한다.

부트스트랩의 재표본추출 단위는 자료의 독립 단위와 일치해야 한다. 군집무작위시험에서는 개인이 아니라 군집을, 반복측정자료에서는 관측시점이 아니라 환자를, 다기관 자료에서 기관 수준 변동을 반영하려면 기관 또는 계층구조를 고려해야 한다. 결측자료를 다중대치한 경우에는 대치 불확실성과 부트스트랩 불확실성을 함께 반영해야 하므로, 대치와 재표본추출의 순서 및 결합규칙을 명확히 정의해야 한다.

::: {.callout-note title="빈도론적 PSA의 해석"}
빈도론적 PSA의 비용효과확률은 엄밀한 의미에서 항상 “신약이 비용효과적일 확률”로 해석되는 것은 아니다. 이는 추정량의 표본추출 불확실성을 모수분포처럼 근사하여 의사결정 불확실성을 표현한 값이다. 그럼에도 실무적으로는 CEAC와 순편익 분포를 통해 의사결정 민감도를 보여주는 유용한 도구이다.
:::

## 베이지안 확률론적 민감도 분석 {#sec-bayesian-psa}

베이지안 PSA는 모수의 사후분포에서 직접 추출한 값으로 경제성 평가 모형을 반복 실행하는 접근이다. 베이지안 분석에서는 자료 $y$를 관찰한 뒤 모수 $\theta$에 대한 불확실성을 다음 사후분포로 표현한다.

$$
p(\theta\mid y)=\frac{p(y\mid\theta)p(\theta)}{p(y)}.
$$

여기서 $p(\theta)$는 사전분포, $p(y\mid\theta)$는 가능도, $p(\theta\mid y)$는 사후분포이다. 경제성 평가에서 베이지안 PSA는 다음처럼 수행된다.

1. 치료효과, 자연사, 비용, 효용, 전이확률 등에 대한 통계모형을 정의한다.
2. 모수의 사전분포를 설정한다.
3. 관찰자료를 이용해 사후분포 $p(\theta\mid y)$를 계산한다.
4. 사후표본 $\theta^{(s)}$를 경제성 평가 모형에 입력한다.
5. 사후 순편익 $INB^{(s)}(\lambda)$를 계산한다.
6. $P\{INB(\lambda)>0\mid y\}$, 기대순편익, CEAC를 보고한다.

베이지안 PSA에서 비용효과확률은 다음과 같이 사후확률로 해석할 수 있다.

$$
P\{INB(\lambda)>0\mid y\}=\int I\{INB(\lambda;\theta)>0\}p(\theta\mid y)d\theta.
$$

사후표본을 사용하면 다음과 같이 근사한다.

$$
\widehat{P}\{INB(\lambda)>0\mid y\}=\frac{1}{S}\sum_{s=1}^S I\{INB^{(s)}(\lambda)>0\}.
$$

사후분포의 기대순편익은

$$
\mathbb{E}\{NB_j(\lambda,\theta)\mid y\}
=
\int NB_j(\lambda,\theta)p(\theta\mid y)d\theta
$$

로 정의되며, 현재 자료하의 최적 전략은 이 사후기대순편익을 최대화하는 전략이다. 여기서 모수의 사후분포와 미래 환자 결과의 사후예측분포를 구분해야 한다. 경제성 모형의 기대비용과 기대효과가 이미 조건부 평균이라면 PSA에는 모수 사후분포를 전달한다. 새로운 환자의 실제 결과 분포까지 예측하려면

$$
p(\widetilde y\mid y)=\int p(\widetilde y\mid\theta)p(\theta\mid y)d\theta
$$

인 사후예측분포가 필요하다.

![빈도론적 PSA와 베이지안 PSA는 모두 모수 불확실성을 경제성 평가 결과로 전파하지만, 불확실성 분포의 해석이 다르다.](figures/ch06/fig-ch06-frequentist-bayesian.png){width="90%"}

위 그림에서 두 접근은 반복 계산의 외형은 비슷하지만 출발점이 다르다. 빈도론적 PSA는 추정량의 표본추출분포를 이용해 불확실성을 근사하고, 베이지안 PSA는 자료와 사전정보가 주어진 모수의 사후분포를 사용한다. 따라서 동일한 CEAC 모양이 나오더라도 확률의 철학적 해석과 입력분포를 구성하는 방법은 다르다.

### 베이지안 PSA의 장점과 주의점 {.unnumbered}

베이지안 PSA의 장점은 모수 불확실성과 의사결정 불확실성의 해석이 자연스럽다는 점이다. 사후분포에서 추출한 값은 관찰자료와 사전정보를 모두 반영한 모수의 불확실성을 나타내며, $P\{INB(\lambda)>0\mid y\}$는 관찰자료가 주어진 후 신약의 순편익이 양수일 확률로 해석할 수 있다.

또한 베이지안 계층모형을 사용하면 여러 자료원을 동시에 합성하고, 상관된 모수의 사후분포를 자연스럽게 반영할 수 있다. 네트워크 메타분석, 다상태모형, 생존외삽, MAIC 등 복잡한 분석에서는 사후표본을 경제성 평가 모형으로 직접 전달하는 방식이 유용하다.

다만 사전분포의 영향, MCMC 수렴, posterior predictive check, 모형 적합도, 사후표본의 autocorrelation을 확인해야 한다. 사후표본 수가 충분하지 않으면 CEAC나 EVPI 같은 후속 분석이 불안정해질 수 있다.

MCMC 표본의 유효표본크기를 $S_{eff}$라고 하면 사후평균의 Monte Carlo 표준오차는 대략 $s/\sqrt{S_{eff}}$로 계산한다. 여러 체인의 혼합, 잠재적 척도감소계수, trace plot과 자기상관을 함께 확인해야 한다. 특히 EVPI처럼 각 반복에서 최대값을 취하는 비선형 함수는 꼬리와 극단값에 민감하므로, 일반적인 모수 사후평균보다 더 많은 유효표본이 필요할 수 있다.

## 모형 불확실성과 하위군 분석 {#sec-model-uncertainty-subgroups}

모수 불확실성은 같은 모형 구조 안에서 입력값의 참값을 모르는 문제이다. 반면 모형 불확실성은 어떤 모형 구조나 분석 가정이 타당한지 모르는 문제이다. 경제성 평가에서는 모형 불확실성이 특히 중요하다. 장기 생존외삽, 치료효과 소실, cure fraction, 전이상태 수, 치료 중단 규칙, 이상반응 반영 방식, 비용 범위, 분석 관점 등은 모두 구조적 가정이다.

모형 구조를 확률변수 $M$으로 보면 전체 기대순편익은 전체기대값의 법칙에 따라

$$
\mathbb{E}(NB_j)=
\sum_{m=1}^{M}P(M_m)\,
\mathbb{E}(NB_j\mid M_m)
$$

로 표현할 수 있다. 전체 분산은

$$
\operatorname{Var}(NB_j)
=
\mathbb{E}_M\{\operatorname{Var}(NB_j\mid M)\}
+
\operatorname{Var}_M\{\mathbb{E}(NB_j\mid M)\}
$$

로 분해된다. 첫 번째 항은 각 구조 안의 모수 불확실성이고, 두 번째 항은 구조 간 기대결과 차이에 따른 불확실성이다. 단일 구조의 PSA만 수행하면 두 번째 항은 반영되지 않는다.

### 시나리오 분석 {.unnumbered}

모형 불확실성을 평가하는 가장 일반적인 방법은 시나리오 분석이다. 각 시나리오 $m=1,\ldots,M$에 대해 모형 $M_m$을 정의하고, 각 모형에서 기본 분석 또는 PSA를 수행한다.

$$
INB_m(\lambda)=\lambda\Delta Q_m-\Delta C_m.
$$

시나리오 분석은 단순히 부록에 넣는 보조분석이 아니라, 결론의 강건성을 평가하는 핵심 자료이다. 예를 들어 기본 분석에서는 비용효과적이지만 치료효과 소실 시나리오에서는 비용효과적이지 않다면, 의사결정자는 치료효과 지속에 대한 불확실성을 중요한 쟁점으로 보아야 한다.

![시나리오 분석은 구조적 가정이 바뀔 때 ICER 또는 INB가 얼마나 달라지는지 보여준다.](figures/ch06/fig-ch06-scenario-analysis.png){width="88%"}

위 그림에서 시나리오 간 결과 차이가 모수 PSA의 분산보다 크다면, 의사결정 불확실성의 주된 원인이 입력값의 표준오차보다 모형 구조일 수 있다. 이 경우 단일 구조에서 PSA 반복 수를 늘리는 것만으로는 핵심 불확실성이 줄어들지 않으며, 구조 선택의 근거와 대안 모형 결과를 함께 제시해야 한다.

### 모형 평균화 {.unnumbered}

여러 모형이 모두 그럴듯하고 하나의 모형만 선택하기 어려운 경우에는 모형 평균화(model averaging)를 고려할 수 있다. 모형 $M_m$의 가중치를 $w_m$이라고 하자. 이때 $\sum_{m=1}^M w_m=1$이다. 전략 $j$의 기대순편익은 다음과 같이 평균화할 수 있다.

$$
\mathbb{E}\{NB_j(\lambda)\}=\sum_{m=1}^M w_m\,\mathbb{E}\{NB_j(\lambda)\mid M_m\}.
$$

가중치 $w_m$은 베이지안 모형확률, AIC/BIC 기반 가중치, 전문가 판단, 또는 사전 정의한 동일 가중치에서 올 수 있다. 그러나 실무에서는 모형 평균화 결과만 제시하기보다 각 시나리오 결과와 평균화 방법을 함께 투명하게 제시해야 한다.

AIC 또는 BIC 가중치는 후보모형 집합 안에서의 상대적 적합도를 반영할 뿐, 후보모형 밖의 구조적 오류를 제거하지 않는다. 또한 동일 자료에 대한 적합도 가중치가 정책적 타당성이나 임상적 개연성을 자동으로 보장하지 않는다. 모형 평균화는 불확실성을 없애는 방법이 아니라, 명시적으로 정의한 후보구조 사이에 불확실성을 배분하는 방법이다.

### 하위군 분석 {.unnumbered}

하위군 분석은 환자 특성에 따라 비용효과성이 달라지는지 평가한다. 하위군 $g$에서의 증분순편익은 다음과 같다.

$$
INB_g(\lambda)=\lambda\Delta Q_g-\Delta C_g.
$$

전체 모집단에서 하위군 비율을 $w_g$라고 하면 전체 모집단의 증분순편익은 다음과 같이 표현할 수 있다.

$$
INB_{pop}(\lambda)=\sum_{g=1}^G w_g INB_g(\lambda).
$$

특정 하위군에서만 $INB_g(\lambda)>0$이면 급여 대상을 제한하는 의사결정이 합리적일 수 있다. 반대로 전체 모집단에서는 비용효과적이더라도 일부 하위군에서 순편익이 음수라면, 치료 대상 확대의 타당성을 다시 검토해야 한다.

![하위군별 INB를 비교하면 전체 평균에서 보이지 않는 의사결정 이질성을 확인할 수 있다.](figures/ch06/fig-ch06-subgroup-inb.png){width="88%"}

위 그림은 하위군별 점추정치뿐 아니라 각 하위군의 불확실성 구간을 함께 읽어야 한다. 전체 평균의 INB가 양수라도 일부 하위군의 기대순편익이 음수일 수 있으며, 반대로 전체 분석에서는 비용효과적이지 않아도 고위험 하위군에서는 절대효과가 커져 순편익이 양수가 될 수 있다. 다만 하위군 간 차이를 주장하려면 각 하위군의 개별 유의성보다 치료효과 또는 순편익의 상호작용을 평가하는 것이 중요하다.

하위군 분석은 임상적 근거, 생물학적 근거, 사전 정의된 분석계획에 기반해야 한다. 사후적으로 여러 하위군을 탐색하면 우연에 의해 비용효과적인 하위군이 발견될 가능성이 커진다. 또한 하위군별 표본 수가 작으면 치료효과와 비용효과성 추정의 불확실성이 커진다.

하위군별 정책을 $d(x)$라고 하면 목표는 환자 특성 $X=x$에서 기대순편익이 가장 큰 전략을 선택하는 것이다.

$$
d^*(x)=\arg\max_j
\mathbb{E}\{NB_j(\lambda,\theta)\mid X=x\}.
$$

개별화 정책의 인구집단 기대순편익은

$$
\mathbb{E}_X\left[
\max_j \mathbb{E}\{NB_j\mid X\}
\right]
$$

으로 나타낼 수 있다. 이는 모든 환자에게 하나의 전략을 적용할 때의

$$
\max_j \mathbb{E}_X\left[
\mathbb{E}\{NB_j\mid X\}
\right]
$$

보다 작지 않다. 두 값의 차이는 이론적으로 하위군 맞춤 의사결정의 최대 가치를 나타낸다. 다만 실제 정책에서는 바이오마커 검사비, 분류오류, 검사 접근성, 치료대상 제한의 형평성과 실행 가능성을 차감해야 한다.

::: {.callout-warning title="하위군 분석의 주의점"}
하위군 비용효과성은 평균 효과의 단순 분할이 아니라 의사결정 대상의 재정의와 연결된다. 하위군을 제안할 때는 임상적 타당성, 검사 가능성, 형평성, 실제 급여 기준으로 운영 가능한지까지 함께 검토해야 한다.
:::


## 가치정보분석 {#sec-value-of-information}

PSA가 현재 의사결정의 불확실성을 묘사한다면, 가치정보분석(value of information analysis)은 추가 연구를 통해 그 불확실성을 줄이는 것이 얼마나 가치 있는지를 평가한다. 전략 $j$의 순편익을 $NB_j(\theta)$라고 하자. 현재 정보에서 선택할 전략의 기대순편익은 다음과 같다.

$$
\max_j \mathbb{E}_{\theta}\{NB_j(\theta)\}.
$$

모든 불확실한 모수의 참값을 의사결정 전에 완전히 알 수 있다면, 각 $\theta$에서 가장 좋은 전략을 선택할 수 있다. 완전정보하의 기대순편익은 다음과 같다.

$$
\mathbb{E}_{\theta}\left\{\max_j NB_j(\theta)\right\}.
$$

따라서 환자 1인당 완전정보의 기대가치(expected value of perfect information, EVPI)는

$$
EVPI
=
\mathbb{E}_{\theta}\left\{\max_j NB_j(\theta)\right\}
-
\max_j \mathbb{E}_{\theta}\{NB_j(\theta)\}
$$

로 정의된다. 최대함수의 볼록성 때문에 EVPI는 항상 0 이상이다. EVPI는 현재의 불확실성으로 인해 발생할 수 있는 기대기회손실의 최솟값과 같다.

PSA 표본으로는 다음과 같이 추정한다.

$$
\widehat{EVPI}
=
\frac{1}{S}\sum_{s=1}^{S}\max_j NB_j^{(s)}
-
\max_j\left\{
\frac{1}{S}\sum_{s=1}^{S}NB_j^{(s)}
\right\}.
$$

인구집단 EVPI는 환자 1인당 EVPI에 해당 의사결정의 영향을 받을 미래 환자 수를 곱해 계산한다. 환자 유입이 시간에 따라 $N_t$이고 할인율이 $r$이면,

$$
EVPI_{pop}
=
EVPI_{person}
\sum_{t=0}^{T}\frac{N_t}{(1+r)^t}.
$$

이 값은 완전한 정보를 얻기 위해 지불할 수 있는 연구비의 이론적 상한이다.

### 부분완전정보의 기대가치 {.unnumbered}

모수 벡터를 관심 모수 $\phi$와 나머지 모수 $\psi$로 나누자. $\phi$만 완전히 알 수 있을 때 부분완전정보의 기대가치(expected value of partial perfect information, EVPPI)는 다음과 같다.

$$
EVPPI(\phi)
=
\mathbb{E}_{\phi}\left[
\max_j
\mathbb{E}_{\psi\mid\phi}\{NB_j(\phi,\psi)\}
\right]
-
\max_j\mathbb{E}_{\theta}\{NB_j(\theta)\}.
$$

EVPPI가 큰 모수군은 의사결정 불확실성에 중요한 기여를 하므로 향후 연구의 우선순위가 될 수 있다. 토네이도 그림의 막대 길이는 입력범위에 대한 결과 민감도이고, EVPPI는 해당 모수의 불확실성을 완전히 제거했을 때 얻는 의사결정 가치라는 점에서 서로 다르다.

### 표본정보의 기대가치 {.unnumbered}

실제 연구는 모수의 참값을 완전히 알려주지 않고 추가 표본자료 $Y^{new}$를 제공한다. 표본정보의 기대가치(expected value of sample information, EVSI)는 다음과 같다.

$$
EVSI
=
\mathbb{E}_{Y^{new}}\left[
\max_j
\mathbb{E}_{\theta\mid Y^{new},y}\{NB_j(\theta)\}
\right]
-
\max_j\mathbb{E}_{\theta\mid y}\{NB_j(\theta)\}.
$$

인구집단 EVSI에서 연구 수행비용을 뺀 값을 기대순표본편익(expected net benefit of sampling, ENBS)이라고 한다.

$$
ENBS=EVSI_{pop}-Cost_{research}.
$$

ENBS가 양수이면 해당 설계의 추가 연구가 경제적으로 정당화될 수 있다. 그러나 연구기간 동안 발생하는 의사결정 지연, 모집 가능성, 윤리성, 연구결과의 채택 가능성도 함께 고려해야 한다.

                     treatment_waning = 1.00) {
  adjusted_qaly <- delta_qaly * utility_multiplier * treatment_waning
  adjusted_cost <- drug_cost + ae_cost
  lambda * adjusted_qaly - adjusted_cost
}

base_inb <- calc_inb()

ranges <- data.frame(
  parameter = c("Drug cost", "Incremental QALY", "AE cost", "Utility multiplier", "Treatment waning"),
  low = c(10000000, 0.30, 500000, 0.90, 0.70),
  high = c(25000000, 0.75, 5000000, 1.05, 1.00)
)

low_inb <- high_inb <- numeric(nrow(ranges))
for (i in seq_len(nrow(ranges))) {
  p <- ranges$parameter[i]
  if (p == "Drug cost") {
    low_inb[i] <- calc_inb(drug_cost = ranges$low[i])
    high_inb[i] <- calc_inb(drug_cost = ranges$high[i])
  }
  if (p == "Incremental QALY") {
    low_inb[i] <- calc_inb(delta_qaly = ranges$low[i])
    high_inb[i] <- calc_inb(delta_qaly = ranges$high[i])
  }
  if (p == "AE cost") {
    low_inb[i] <- calc_inb(ae_cost = ranges$low[i])
    high_inb[i] <- calc_inb(ae_cost = ranges$high[i])
  }
  if (p == "Utility multiplier") {
    low_inb[i] <- calc_inb(utility_multiplier = ranges$low[i])
    high_inb[i] <- calc_inb(utility_multiplier = ranges$high[i])
  }
  if (p == "Treatment waning") {
    low_inb[i] <- calc_inb(treatment_waning = ranges$low[i])
    high_inb[i] <- calc_inb(treatment_waning = ranges$high[i])
  }
}

dsa <- data.frame(
  parameter = ranges$parameter,
  low_INB = low_inb,
  high_INB = high_inb
)
dsa$width <- abs(dsa$high_INB - dsa$low_INB)
dsa <- dsa[order(dsa$width, decreasing = TRUE), ]
print(dsa)

oldpar <- par(no.readonly = TRUE)
par(mar = c(5, 8, 3, 2))
y <- seq_len(nrow(dsa))
xmin <- pmin(dsa$low_INB, dsa$high_INB)
xmax <- pmax(dsa$low_INB, dsa$high_INB)
plot(NULL, xlim = range(c(xmin, xmax, 0)), ylim = c(0.5, nrow(dsa) + 0.5),
     yaxt = "n", xlab = "Incremental net benefit", ylab = "",
     main = "One-way sensitivity analysis")
segments(xmin, y, xmax, y, lwd = 10, col = "grey70")
abline(v = base_inb, lty = 2)
abline(v = 0, lty = 3)
axis(2, at = y, labels = dsa$parameter, las = 1)
par(oldpar)

mean_delta_c <- 15000000
sd_delta_c <- 3500000
shape_c <- mean_delta_c^2 / sd_delta_c^2

delta_c <- rgamma(S, shape = shape_c, scale = scale_c)

inb <- lambda * delta_q - delta_c

mc_se <- sqrt(ce_prob * (1 - ce_prob) / S)
