경제성 평가에서 회귀분석의 핵심 목적은 p-value가 작은 변수를 찾는 것이 아니다. 더 중요한 목적은 목표 인구집단에서 비용, QALY, 효용, 사건확률, 자원사용량의 평균값을 예측하고, 그 예측 불확실성을 의사결정 모형에 반영하는 것이다.

11.1 회귀분석

11.1.1 회귀분석의 공통 구조

회귀분석은 결과변수 \(Y_i\)의 조건부 분포를 설명변수 벡터 \(x_i\)의 함수로 표현한다. 가장 일반적인 표기는 다음과 같다.

\[ Y_i \mid x_i \sim f(y_i \mid \theta_i), \]

여기서 \(\theta_i\)는 조건부 분포의 모수이다. 많은 회귀모형에서는 조건부 평균을 중심으로 모형을 세운다.

\[ \mu_i=\mathbb{E}(Y_i\mid x_i). \]

일반화 선형모형에서는 연결함수 \(g(\cdot)\)를 이용하여 평균과 선형예측자를 연결한다.

\[ g(\mu_i)=\eta_i=x_i^T\beta. \]

이때 \(x_i\)는 절편, 치료군, 연령, 성별, 중증도, 기저 효용, 동반질환 등의 공변량을 포함할 수 있고, \(\beta\)는 회귀계수 벡터이다. 연결함수와 분포를 바꾸면 서로 다른 형태의 결과변수를 다룰 수 있다.

11.1.2 지수족, 분산함수와 준가능도

일반화 선형모형의 다수는 결과변수의 분포가 지수족에 속한다고 가정한다. 한 관측값의 밀도 또는 확률질량함수는 다음과 같이 표현할 수 있다.

\[ f(y_i\mid\theta_i,\phi) =\exp\left[\frac{y_i\theta_i-b(\theta_i)}{a(\phi)}+c(y_i,\phi)\right]. \]

여기서 \(\theta_i\)는 정준모수, \(\phi\)는 산포모수이다. 지수족에서는 평균과 분산이 다음 관계를 가진다.

\[ \mathbb{E}(Y_i\mid x_i)=b'(\theta_i)=\mu_i, \qquad \operatorname{Var}(Y_i\mid x_i)=b''(\theta_i)a(\phi) =\phi V(\mu_i). \]

\(V(\mu_i)\)는 분산함수이다. 정규분포에서는 \(V(\mu)=1\), 포아송분포에서는 \(V(\mu)=\mu\), 감마분포에서는 \(V(\mu)=\mu^2\)이다. 따라서 결과변수의 평균뿐 아니라 평균이 증가할 때 분산이 어떤 속도로 증가하는지를 함께 고려해야 한다.

연결함수 \(g(\mu_i)\)가 정준모수와 직접 연결되면 정준연결함수라고 한다. 그러나 경제성 평가에서는 정준성보다 해석과 예측척도가 더 중요할 수 있다. 예를 들어 감마분포의 정준연결은 역수 연결이지만, 비용의 평균비를 직관적으로 표현하고 예측값을 양수로 제한하기 위해 로그 연결을 더 자주 사용한다.

분포 전체를 정확히 지정하지 않고 평균모형과 분산함수만 지정하는 준가능도 접근도 가능하다. 평균모형이 올바르면 회귀계수는 일관되게 추정될 수 있지만, 분산함수의 오지정은 모형 기반 표준오차를 왜곡할 수 있다. 이때 sandwich 형태의 강건분산을 사용할 수 있다. 다만 강건분산은 잘못 지정된 평균함수나 연결함수를 교정하지는 못한다.

위 그림은 회귀계수 자체가 최종 산출물이 아니라는 점을 보여준다. 자료에서 적합한 조건부 모형은 목표 인구집단의 공변량 분포에 대해 표준화되어야 하며, 그 결과가 비용·QALY·사건확률의 전략별 평균으로 전달된다.

11.1.3 조건부 효과와 주변 효과

회귀계수는 보통 조건부 효과를 나타낸다. 예를 들어 선형모형에서 치료계수 \(\beta_1\)은 공변량이 같은 환자들 사이의 평균 차이를 의미한다.

\[ \mathbb{E}(Y_i\mid A_i=1,x_i)-\mathbb{E}(Y_i\mid A_i=0,x_i)=\beta_1. \]

하지만 경제성 평가에서 필요한 값은 대개 목표 인구집단 전체의 평균 비용과 평균 QALY이다. 목표 인구집단의 공변량 분포를 \(F^*(x)\)라고 하면 치료전략 \(a\)의 주변 평균은 다음과 같이 정의된다.

\[ \mu_a^*=\int \mathbb{E}(Y\mid A=a,X=x)dF^*(x). \]

표본이 목표 인구집단을 대표한다고 가정하면 이는 예측값의 평균으로 근사할 수 있다.

\[ \widehat{\mu}_a^*=\frac{1}{n}\sum_{i=1}^n \widehat{m}(a,x_i), \]

여기서 \(\widehat{m}(a,x_i)\)는 환자 \(i\)가 치료 \(a\)를 받았다고 가정했을 때의 예측 평균이다. 이를 표준화, g-computation, 또는 average predictive comparison이라고 부른다.

증분 평균은 다음과 같이 계산한다.

\[ \widehat{\Delta}=\widehat{\mu}_1^*-\widehat{\mu}_0^*. \]

비용과 QALY에 각각 적용하면 \(\widehat{\Delta C}\)와 \(\widehat{\Delta Q}\)를 얻을 수 있고, 이는 ICER와 INB 계산으로 이어진다.

\[ \widehat{ICER}=\frac{\widehat{\Delta C}}{\widehat{\Delta Q}}, \qquad \widehat{INB}(\lambda)=\lambda\widehat{\Delta Q}-\widehat{\Delta C}. \]

11.1.4 표준화의 인과적 해석과 식별 조건

치료전략별 표준화 평균을 잠재결과 표기로 쓰면 다음과 같다.

\[ \mu_a^*=\mathbb{E}_{F^*}\{Y(a)\}. \]

관찰자료에서 이를 회귀모형으로 식별하려면 일관성, 조건부 교환가능성, 양의 확률 조건이 필요하다.

\[ Y=Y(A), \]

\[ Y(a)\perp A\mid X, \]

\[ 0<P(A=a\mid X=x)<1 \]

가 목표 모집단에서 성립해야 한다. 무작위배정 임상시험에서는 치료배정의 교환가능성이 설계에 의해 확보되지만, 탈락이나 치료교차가 결과와 관련되면 추가 가정이 필요할 수 있다. 관찰연구에서는 중요한 교란변수가 누락되면 표준화된 예측값도 인과효과로 해석할 수 없다.

목표 모집단이 분석표본과 다르면 가중 표준화를 사용할 수 있다. 목표 모집단 대표성을 반영하는 가중치를 \(w_i\)라고 하면 다음과 같다.

\[ \widehat{\mu}_a^* =\frac{\sum_{i=1}^n w_i\widehat{m}(a,x_i)}{\sum_{i=1}^n w_i}. \]

따라서 회귀모형의 외삽은 두 종류로 구분해야 한다. 하나는 관찰된 공변량 범위 안에서 치료만 바꾸는 치료전략 외삽이고, 다른 하나는 분석표본과 다른 공변량 분포로 이동하는 인구집단 외삽이다. 후자는 효과변경인자가 충분히 측정되고 모형이 올바르게 지정되었다는 더 강한 조건을 요구한다.

위 그림에서 분포와 연결함수의 선택은 단순한 소프트웨어 옵션이 아니다. 결과변수의 지지집합, 평균–분산 관계, 0이나 1의 점질량, 반복측정 구조를 반영해야 원래 척도의 평균값을 안정적으로 추정할 수 있다.

Important실무에서 중요한 구분

회귀모형의 치료계수와 경제성 평가에 필요한 평균 차이는 항상 같지 않다. 특히 로지스틱 회귀, 감마 회귀, 로그정규 회귀처럼 비선형 연결함수를 사용하는 경우에는 회귀계수 하나를 그대로 ICER의 입력값으로 사용하면 안 된다. 각 치료전략에 대해 목표 인구집단의 예측값을 계산하고 평균을 내는 과정이 필요하다.

11.2 다중 선형회귀분석

다중 선형회귀분석은 연속형 결과변수의 조건부 평균을 공변량의 선형결합으로 표현한다.

\[ Y_i=x_i^T\beta+\varepsilon_i, \qquad \mathbb{E}(\varepsilon_i\mid x_i)=0. \]

고전적 선형모형에서는 다음 분산 가정을 추가한다.

\[ \operatorname{Var}(\varepsilon_i\mid x_i)=\sigma^2. \]

표본 전체에 대해 \(Y=(Y_1,\ldots,Y_n)^T\), 설계행렬을 \(X\)라고 하면 최소제곱 추정량은 다음과 같다.

\[ \widehat{\beta}=(X^TX)^{-1}X^TY. \]

오차분산 추정량은 다음과 같다.

\[ \widehat{\sigma}^2=\frac{1}{n-p}\sum_{i=1}^n (Y_i-x_i^T\widehat{\beta})^2, \]

여기서 \(p\)는 회귀계수의 수이다. 추정량의 분산은 다음과 같이 추정한다.

\[ \widehat{\operatorname{Var}}(\widehat{\beta})=\widehat{\sigma}^2(X^TX)^{-1}. \]

경제성 평가에서는 QALY, 특정 기간의 효용 평균, 체중, 검사수치, 연속형 임상지표를 분석할 때 선형회귀를 사용할 수 있다. 그러나 비용자료는 양수이고 오른쪽으로 긴 꼬리를 가지는 경우가 많으므로 선형모형을 기계적으로 적용하면 음의 예측비용이나 과도한 영향점 문제가 발생할 수 있다.

11.2.1 예측 평균과 표준오차

치료전략 \(a\)의 표준화 평균을 다음과 같이 정의하자.

\[ \widehat{\mu}_a^*=\frac{1}{n}\sum_{i=1}^n x_i(a)^T\widehat{\beta}, \]

여기서 \(x_i(a)\)는 환자 \(i\)의 공변량은 그대로 두고 치료변수만 \(a\)로 바꾼 설계벡터이다. 평균 예측값은 선형함수이므로 다음과 같이 쓸 수 있다.

\[ \widehat{\mu}_a^*=\bar{x}(a)^T\widehat{\beta}, \qquad \bar{x}(a)=\frac{1}{n}\sum_{i=1}^n x_i(a). \]

따라서 분산은 다음과 같이 계산할 수 있다.

\[ \widehat{\operatorname{Var}}(\widehat{\mu}_a^*)=\bar{x}(a)^T\widehat{\operatorname{Var}}(\widehat{\beta})\bar{x}(a). \]

증분 평균 \(\widehat{\Delta}=\widehat{\mu}_1^*-\widehat{\mu}_0^*\)의 분산은 다음과 같다.

\[ \widehat{\operatorname{Var}}(\widehat{\Delta})= \{\bar{x}(1)-\bar{x}(0)\}^T \widehat{\operatorname{Var}}(\widehat{\beta}) \{\bar{x}(1)-\bar{x}(0)\}. \]

이 식은 선형모형에서는 분석적으로 편리하지만, 여러 비선형 모형을 결합하여 ICER를 계산할 때는 부트스트랩이나 PSA가 더 실용적인 경우가 많다.

11.2.2 최소제곱 추정량의 성질과 강건분산

최소제곱 추정량이 조건부 평균효과를 올바르게 추정하려면 다음 평균 독립 조건이 핵심이다.

\[ \mathbb{E}(\varepsilon_i\mid X)=0. \]

오차의 정규성은 \(\widehat{\beta}\)의 불편성에 필요한 조건이 아니다. 정규성은 주로 작은 표본에서 정확한 \(t\) 검정과 신뢰구간을 구성할 때 사용된다. 또한 등분산성은 최소제곱 추정량의 불편성보다 효율성과 통상적 표준오차 공식에 필요한 조건이다.

비용이나 효용자료에서 이분산성이 존재하면 다음 sandwich 분산추정량을 사용할 수 있다.

\[ \widehat{\operatorname{Var}}_{\mathrm{HC}}(\widehat{\beta}) =(X^TX)^{-1} \left(\sum_{i=1}^n x_ix_i^T\widehat{\varepsilon}_i^2\right) (X^TX)^{-1}. \]

강건분산은 이분산성으로 인한 표준오차 왜곡을 줄이지만, 비선형 평균관계, 누락된 상호작용, 영향력이 큰 극단값을 해결하지는 않는다. 따라서 잔차–적합값 관계, 부분잔차, 영향도와 표준화 예측값의 민감도를 함께 점검해야 한다.

선형모형의 장점은 결과변수의 분포가 비대칭이어도 조건부 평균식이 올바르고 표본이 충분히 크면 평균 차이 추정에 사용할 수 있다는 점이다. 그러나 작은 표본에서 고비용 관측값이 소수 존재하면 평균 추정량과 부트스트랩 분포가 불안정할 수 있으므로, 감마 GLM이나 로그정규모형과 함께 비교하는 것이 바람직하다.

11.3 공분산분석

공분산분석은 치료군 비교에서 기저값 또는 예후인자를 보정하여 평균 결과를 추정하는 선형모형이다. 임상시험 기반 경제성 평가에서는 기저 효용 또는 기저 비용을 보정한 QALY 분석에 자주 사용된다.

예를 들어 \(Y_i\)를 추적기간 QALY, \(A_i\)를 치료군, \(B_i\)를 기저 효용이라고 하면 ANCOVA 모형은 다음과 같다.

\[ Y_i=\beta_0+\beta_A A_i+\beta_B B_i+\varepsilon_i. \]

무작위배정 임상시험에서 단순 평균 차이도 인과적으로 해석할 수 있지만, 기저값을 보정하면 추정 정밀도가 향상될 수 있다. 특히 기저 효용과 추적기간 QALY의 상관이 클수록 보정의 이득이 커진다.

치료군별 기저값 분포가 표본에서 우연히 다를 수 있으므로, 경제성 평가에서는 다음과 같이 공통 공변량 분포에서 표준화된 평균 QALY를 계산하는 것이 바람직하다.

\[ \widehat{Q}_a=\frac{1}{n}\sum_{i=1}^n \left(\widehat{\beta}_0+\widehat{\beta}_A a+\widehat{\beta}_B B_i\right). \]

증분 QALY는 다음과 같다.

\[ \widehat{\Delta Q}=\widehat{Q}_1-\widehat{Q}_0. \]

선형모형에 치료와 기저값의 상호작용이 없으면 \(\widehat{\Delta Q}=\widehat{\beta}_A\)가 된다. 그러나 상호작용을 포함하면 치료효과는 기저값에 따라 달라지므로 목표 인구집단 분포에서 표준화해야 한다.

\[ Y_i=\beta_0+\beta_A A_i+\beta_B B_i+\beta_{AB}A_iB_i+\varepsilon_i. \]

이때 환자 \(i\)의 조건부 치료효과는 다음과 같다.

\[ \mathbb{E}(Y_i\mid A_i=1,B_i)-\mathbb{E}(Y_i\mid A_i=0,B_i) =\beta_A+\beta_{AB}B_i. \]

목표 인구집단에서의 평균 치료효과는 다음과 같다.

\[ \Delta Q^*=\beta_A+\beta_{AB}\mathbb{E}_{F^*}(B). \]

11.3.1 ANCOVA와 변화량 분석의 차이

기저값 \(B_i\)와 추적 결과 \(Y_i\)가 모두 관찰될 때 변화량 \(Y_i-B_i\)를 비교하는 방법도 가능하다. 그러나 변화량 분석은 기저값의 회귀계수를 1로 고정한 특수한 모형에 해당한다. 반면 ANCOVA는 자료에서 기저값과 추적 결과의 관계를 추정한다.

\[ Y_i=\beta_0+\beta_AA_i+\beta_BB_i+\varepsilon_i. \]

기저값이 결과를 잘 예측할수록 잔차분산이 감소한다. 단순화된 균형 임상시험에서 기저값이 결과변동의 \(R_B^2\)를 설명하면 치료효과 추정량의 분산은 대략 다음과 같이 감소한다.

\[ \operatorname{Var}(\widehat{\beta}_A\mid B) \approx \sigma_Y^2(1-R_B^2) \left(\frac{1}{n_1}+\frac{1}{n_0}\right). \]

따라서 기저 효용과 추적기간 QALY의 상관이 높을수록 ANCOVA의 정밀도 이득이 커진다. 무작위배정 이후에 측정된 변수는 치료의 영향을 받을 수 있으므로 단순한 정밀도 향상을 목적으로 보정해서는 안 된다. 치료 후 변수의 보정은 매개경로를 차단하거나 collider bias를 유발하여 치료전략 효과의 estimand를 바꿀 수 있다.

위 그림은 각 군을 서로 다른 기저 효용값에서 직접 비교하는 대신, 동일한 기저 효용 분포로 표준화하여 평균 QALY를 비교하는 원리를 나타낸다.

TipANCOVA의 경제성 평가 해석

QALY 분석에서 ANCOVA를 사용했다면 회귀계수만 보고 끝내지 말고, 각 치료군의 보정 평균 QALY와 증분 QALY를 함께 제시하는 것이 좋다. 비용효용분석에서는 이 값이 ICER의 분모가 되기 때문이다.

11.4 로지스틱 회귀분석

로지스틱 회귀분석은 이항 결과변수의 조건부 사건확률을 모델링한다. \(Y_i=1\)이면 사건 발생, \(Y_i=0\)이면 사건 미발생이라고 하자.

\[ Y_i\mid x_i\sim \operatorname{Bernoulli}(p_i), \]

\[ \operatorname{logit}(p_i)=\log\left(\frac{p_i}{1-p_i}\right)=x_i^T\beta. \]

따라서 사건확률은 다음과 같다.

\[ p_i=\frac{\exp(x_i^T\beta)}{1+\exp(x_i^T\beta)}. \]

치료변수 \(A_i\)의 계수를 \(\beta_A\)라고 하면 조건부 오즈비는 다음과 같다.

\[ OR=\exp(\beta_A). \]

하지만 경제성 평가에서 필요한 입력값은 대개 오즈비 자체가 아니라 치료군별 사건확률이다. 예를 들어 이상반응 비용을 반영하려면 \(P(Y=1\mid A=1)\)과 \(P(Y=1\mid A=0)\)가 필요하다. 목표 인구집단에서 표준화한 사건확률은 다음과 같다.

\[ \widehat{p}_a^*=\frac{1}{n}\sum_{i=1}^n \frac{\exp\{x_i(a)^T\widehat{\beta}\}}{1+\exp\{x_i(a)^T\widehat{\beta}\}}. \]

주변 위험차와 위험비는 다음과 같이 계산한다.

\[ \widehat{RD}=\widehat{p}_1^*-\widehat{p}_0^*, \qquad \widehat{RR}=\frac{\widehat{p}_1^*}{\widehat{p}_0^*}. \]

로지스틱 회귀의 로그가능도는 다음과 같다.

\[ \ell(\beta)=\sum_{i=1}^n \left[y_i\log(p_i)+(1-y_i)\log(1-p_i)\right]. \]

연속 공변량 \(x_{ij}\)의 계수 \(\beta_j\)는 로그오즈의 변화량이지만, 확률척도의 한계효과는 현재 사건확률에 따라 달라진다.

\[ \frac{\partial p_i}{\partial x_{ij}} =\beta_jp_i(1-p_i). \]

따라서 동일한 \(\beta_j\)라도 사건이 매우 드물거나 매우 흔한 환자에서는 절대확률 변화가 작다. 평균 한계효과는 환자별 미분값을 평균하여 계산할 수 있지만, 이항 치료변수에서는 치료값을 0과 1로 바꾼 표준화 위험차가 더 직접적이다.

모형의 적합도가 좋아도 확률예측이 잘 보정되었다고 보장되지는 않는다. 경제성 평가에서 사건확률을 입력값으로 사용할 때는 예측확률의 평균뿐 아니라 calibration-in-the-large와 calibration slope를 점검해야 한다. 과대적합된 모형은 극단적인 사건확률을 만들어 비용과 효용 손실을 과대평가할 수 있다.

11.4.1 오즈비를 절대확률로 변환하기

기준 사건확률이 \(p_0\)이고 조건부 또는 적용 가능한 오즈비가 \(OR\)일 때, 사건확률은 다음과 같이 변환된다.

\[ p_1=\frac{OR\,p_0}{1-p_0+OR\,p_0}. \]

이 식은 오즈비를 확률로 해석할 때 특히 중요하다. 오즈비가 일정해도 기준위험 \(p_0\)가 다르면 위험차 \(p_1-p_0\)는 달라진다.

위 그림은 오즈비가 일정하더라도 로지스틱 곡선의 위치에 따라 절대위험 변화가 달라짐을 보여준다. 경제성 평가에서는 기준위험이 높은 하위군과 낮은 하위군에서 동일한 오즈비가 서로 다른 비용 및 QALY 영향을 만들 수 있다.

Warning오즈비의 비축약성

로지스틱 회귀의 오즈비는 비축약적이다. 즉, 교란이 없더라도 공변량을 보정한 조건부 오즈비와 보정하지 않은 주변 오즈비가 다를 수 있다. 따라서 경제성 평가에서는 오즈비 자체보다 표준화된 사건확률과 그 차이를 계산하는 것이 더 직접적이다.

11.5 감마 회귀분석

의료비 자료는 0보다 크고 오른쪽으로 긴 꼬리를 가지는 경우가 많다. 감마 회귀분석은 이러한 양수 연속형 자료에 적합한 일반화 선형모형이다.

감마분포를 평균 \(\mu_i\)와 shape 모수 \(\alpha\)로 표현하면 분산은 다음과 같다.

\[ \operatorname{Var}(Y_i\mid x_i)=\frac{\mu_i^2}{\alpha}. \]

일반화 선형모형에서는 보통 로그 연결함수를 사용한다.

\[ \log(\mu_i)=x_i^T\beta, \qquad \mu_i=\exp(x_i^T\beta). \]

치료계수 \(\beta_A\)의 지수값은 조건부 평균비로 해석된다.

\[ \frac{\mathbb{E}(Y_i\mid A_i=1,x_i)}{\mathbb{E}(Y_i\mid A_i=0,x_i)}=\exp(\beta_A). \]

하지만 ICER에는 평균비가 아니라 평균 비용 차이가 필요하다. 따라서 다음처럼 치료전략별 예측 비용을 평균해야 한다.

\[ \widehat{C}_a=\frac{1}{n}\sum_{i=1}^n \exp\{x_i(a)^T\widehat{\beta}\}. \]

증분비용은 다음과 같다.

\[ \widehat{\Delta C}=\widehat{C}_1-\widehat{C}_0. \]

감마 회귀는 예측값이 항상 양수라는 장점이 있다. 그러나 실제 자료에 비용이 0인 관측값이 많다면 감마분포가 직접 적용되지 않는다. 이 경우에는 two-part model 또는 hurdle model을 고려해야 한다.

감마 GLM에서 변동계수는 shape 모수가 일정할 때 일정하다.

\[ \frac{\sqrt{\operatorname{Var}(Y_i\mid x_i)}}{\mathbb{E}(Y_i\mid x_i)} =\frac{1}{\sqrt{\alpha}}. \]

즉 평균비용이 커질수록 표준편차도 평균에 비례하여 커진다고 가정한다. 실제 자료의 평균–분산 관계가 이와 크게 다르면 분산함수의 오지정이 발생한다. 모형 선택에서는 로그변환 후 정규성만 보는 것보다 평균–분산 관계와 원래 척도에서의 예측 성능을 함께 비교해야 한다.

비용이 0인 관측값이 있는 경우 두 부분 모형의 전체 평균은 다음과 같다.

\[ \mathbb{E}(C_i\mid x_i) =P(C_i>0\mid x_i) \mathbb{E}(C_i\mid C_i>0,x_i). \]

첫 번째 부분은 비용 발생확률을 로지스틱 회귀로, 두 번째 부분은 양의 비용을 감마 GLM 등으로 분석할 수 있다. 경제성 평가에 입력하는 값은 두 번째 부분의 조건부 평균만이 아니라 두 부분을 곱한 전체 평균이다.

위 그림은 두 모형이 모두 오른쪽 비대칭을 허용하지만 꼬리와 분산구조에 대한 가정은 다르다는 점을 나타낸다. 모형 선택은 로그척도의 적합도보다 원래 비용척도의 평균과 증분비용이 얼마나 안정적으로 추정되는지를 기준으로 해야 한다.

11.6 로그 정규 회귀분석

로그 정규 회귀분석은 비용의 로그값이 정규분포를 따른다고 가정한다.

\[ \log(Y_i)=x_i^T\beta+\varepsilon_i, \qquad \varepsilon_i\sim N(0,\sigma^2). \]

이때 원래 비용척도에서 조건부 평균은 단순히 \(\exp(x_i^T\beta)\)가 아니다. 로그정규분포의 평균은 다음과 같다.

\[ \mathbb{E}(Y_i\mid x_i)=\exp\left(x_i^T\beta+\frac{\sigma^2}{2}\right). \]

따라서 로그 회귀모형에서 예측비용을 원래 척도로 되돌릴 때는 재변환 보정이 필요하다. 정규성과 등분산성을 가정하면 \(\exp(\widehat{\sigma}^2/2)\)를 곱한다.

\[ \widehat{C}_a=\frac{1}{n}\sum_{i=1}^n \exp\left\{x_i(a)^T\widehat{\beta}+\frac{\widehat{\sigma}^2}{2}\right\}. \]

분포 가정이 불확실하면 Duan의 smearing factor를 사용할 수 있다.

\[ \widehat{s}=\frac{1}{n}\sum_{i=1}^n \exp(\widehat{\varepsilon}_i), \]

\[ \widehat{C}_a=\frac{1}{n}\sum_{i=1}^n \exp\{x_i(a)^T\widehat{\beta}\}\widehat{s}. \]

로그 정규 회귀는 극단적인 고비용 관측값을 완화해서 모델링할 수 있지만, 원래 비용척도의 평균 추정이 관심 대상이라면 재변환 단계의 불확실성과 영향점을 반드시 점검해야 한다.

로그척도에서 \(x_i^T\beta\)는 조건부 로그평균이자 원래 척도에서의 조건부 중앙값의 로그이다.

\[ \operatorname{Median}(Y_i\mid x_i)=\exp(x_i^T\beta). \]

평균과 중앙값의 차이는 Jensen 부등식에서 발생한다.

\[ \mathbb{E}\{\exp(Z)\}>\exp\{\mathbb{E}(Z)\} \]

가 \(Z\)에 변동성이 있을 때 성립한다. 오차분산이 공변량에 따라 달라지면 하나의 전역 smearing factor는 충분하지 않을 수 있다. 일반적인 재변환은 다음과 같다.

\[ \mathbb{E}(Y_i\mid x_i) =\exp(x_i^T\beta)\mathbb{E}\{\exp(\varepsilon_i)\mid x_i\}. \]

따라서 이분산성이 있으면 공변량 구간별 smearing factor, 분산모형, 또는 원래 척도의 GLM을 고려해야 한다. 재변환 보정의 추정오차도 부트스트랩 반복 안에서 다시 계산해야 증분비용의 불확실성이 올바르게 반영된다.

Important비용모형 선택의 핵심

감마 회귀와 로그 정규 회귀는 모두 비용자료에 사용할 수 있지만 목표가 다르다. 경제성 평가의 ICER에는 원래 비용척도의 기대값이 필요하므로, 모형을 로그척도에서 적합하더라도 최종 입력값은 반드시 원래 척도의 평균비용으로 변환해야 한다.

11.7 포아송 회귀분석

포아송 회귀분석은 사건 수 또는 자원사용 횟수를 모델링한다. 예를 들어 입원 횟수, 응급실 방문 횟수, 검사 횟수, 이상반응 발생 건수를 분석할 수 있다.

\[ Y_i\mid x_i\sim \operatorname{Poisson}(\mu_i), \]

\[ \log(\mu_i)=x_i^T\beta. \]

추적기간이나 노출시간이 환자마다 다르면 offset을 포함한다. \(t_i\)를 관찰시간, \(r_i\)를 단위시간당 사건률이라고 하면 다음과 같다.

\[ \mu_i=t_i r_i, \qquad \log(\mu_i)=\log(t_i)+x_i^T\beta. \]

여기서 \(\log(t_i)\)는 계수가 1로 고정된 offset이다. 치료계수의 지수값은 사건률비로 해석된다.

\[ IRR=\exp(\beta_A). \]

포아송 모형의 중요한 가정은 평균과 분산이 같다는 것이다.

\[ \mathbb{E}(Y_i\mid x_i)=\operatorname{Var}(Y_i\mid x_i)=\mu_i. \]

실제 의료이용자료에서는 분산이 평균보다 큰 과산포가 흔하다. 과산포가 있으면 포아송 회귀계수의 점추정은 비교적 안정적일 수 있지만 표준오차가 과소추정되어 불확실성을 작게 보일 수 있다.

포아송 로그가능도는 다음과 같다.

\[ \ell(\beta)=\sum_{i=1}^n \left[y_i\log(\mu_i)-\mu_i-\log(y_i!)\right]. \]

Offset을 포함한 모형은 관찰시간 동안의 기대 사건 수를 추정한다. 단위시간당 사건률을 경제성 평가의 고정된 주기 길이 \(\Delta\)에 적용할 때는 사건이 독립적으로 발생한다는 가정 아래 기대 사건 수가 \(r_i\Delta\)가 된다. 그러나 같은 환자에서 재발사건이 군집되거나 사건 이후 위험이 변하면 단순 포아송 과정은 충분하지 않다. 이 경우 환자 수준 무작위효과, GEE, 재발사건 생존모형 또는 상태전이모형을 고려해야 한다.

11.8 음이항 회귀분석

음이항 회귀분석은 계수자료의 과산포를 반영한다. 흔히 사용하는 NB2 모수화에서는 평균과 분산이 다음과 같다.

\[ \mathbb{E}(Y_i\mid x_i)=\mu_i, \]

\[ \operatorname{Var}(Y_i\mid x_i)=\mu_i+\alpha\mu_i^2, \]

여기서 \(\alpha>0\)는 과산포 모수이다. \(\alpha=0\)이면 포아송 모형에 가까워진다.

로그 연결함수를 사용하면 다음과 같다.

\[ \log(\mu_i)=\log(t_i)+x_i^T\beta. \]

치료계수의 지수값은 포아송 회귀와 마찬가지로 사건률비로 해석할 수 있다.

\[ IRR=\exp(\beta_A). \]

음이항분포는 포아송 평균 자체가 환자마다 감마분포를 따른다는 혼합모형에서 유도할 수 있다. 잠재 사건률 \(\Lambda_i\)에 대해

\[ Y_i\mid\Lambda_i\sim\operatorname{Poisson}(\Lambda_i), \qquad \Lambda_i\mid x_i\sim\operatorname{Gamma}\left(\frac{1}{\alpha},\,\alpha\mu_i\right) \]

라고 하면 주변분포의 평균과 분산은

\[ \mathbb{E}(Y_i\mid x_i)=\mu_i, \qquad \operatorname{Var}(Y_i\mid x_i)=\mu_i+\alpha\mu_i^2 \]

가 된다. 이 표현은 과산포가 단순한 측정오차가 아니라 관찰되지 않은 사건성향의 이질성에서 발생할 수 있음을 보여준다.

경제성 평가에서는 입원 횟수, 외래 방문 횟수, 검사 횟수의 예측값에 단가를 곱하여 비용을 산출할 수 있다. 자원사용량 \(R_{ik}\)의 기대값과 단가 \(u_k\)가 주어지면 환자 \(i\)의 기대 자원사용 비용은 다음과 같다.

\[ \mathbb{E}(C_i\mid x_i)=\sum_{k=1}^K u_k\mathbb{E}(R_{ik}\mid x_i). \]

위 그림은 평균이 증가함에 따라 음이항모형의 분산이 포아송모형보다 더 빠르게 커지는 모습을 나타낸다. 과산포를 무시하면 평균 예측 자체보다 그 불확실성이 지나치게 작아져 PSA의 비용 분산을 축소할 수 있다.

11.9 베타 회귀분석

효용값은 보통 0과 1 사이의 값을 가진다. 이러한 제한된 연속형 결과변수에는 베타 회귀분석을 고려할 수 있다. 베타분포는 평균 \(\mu_i\)와 정밀도 \(\phi\)를 이용하여 다음과 같이 모수화할 수 있다.

\[ Y_i\mid x_i\sim \operatorname{Beta}(\alpha_i,\beta_i), \]

\[ \alpha_i=\mu_i\phi, \qquad \beta_i=(1-\mu_i)\phi. \]

이때 조건부 평균과 분산은 다음과 같다.

\[ \mathbb{E}(Y_i\mid x_i)=\mu_i, \]

\[ \operatorname{Var}(Y_i\mid x_i)=\frac{\mu_i(1-\mu_i)}{1+\phi}. \]

평균에는 보통 로짓 연결함수를 사용한다.

\[ \operatorname{logit}(\mu_i)=x_i^T\beta. \]

정밀도 모수도 공변량에 따라 달라질 수 있다.

\[ \log(\phi_i)=z_i^T\gamma. \]

평균모형만 적합하고 실제 정밀도가 환자 특성에 따라 크게 달라지면 평균계수의 추론과 예측구간이 불안정해질 수 있다. 베타 회귀의 회귀계수는 효용의 직접 차이가 아니라 평균 효용 오즈의 로그변화이므로, 경제성 평가에는 치료전략별 예측 효용을 원래 척도에서 평균해야 한다.

베타 회귀는 예측 효용이 0과 1 사이에 머무른다는 장점이 있다. 그러나 EQ-5D 효용값은 0보다 작을 수 있고, 정확히 1에 많은 관측값이 몰리는 경우도 있다. 이 경우에는 다음 대안이 필요할 수 있다.

  • 효용값을 적절한 범위로 재척도화한 후 베타 회귀 적용
  • 1의 질량을 따로 모델링하는 one-inflated beta model
  • 음의 효용을 허용하는 일반 선형모형 또는 혼합모형
  • 효용값과 사망 상태를 결합한 joint model 또는 longitudinal-survival model

정확히 1인 관측값의 질량을 \(\pi_i\)로 분리하는 one-inflated beta model에서는 전체 평균이 다음과 같다.

\[ \mathbb{E}(Y_i\mid x_i,z_i) =\pi_i+(1-\pi_i)\mu_i. \]

이때 \(\pi_i\)는 완전건강 상태에 있을 확률이고, \(\mu_i\)는 완전건강이 아닌 사람의 조건부 평균 효용이다. EQ-5D처럼 1에서 큰 질량과 그 아래의 간격이 나타나는 자료에서는 이 두 과정이 임상적으로 다른 메커니즘을 나타낼 수 있다. 단순 재척도화는 지지집합을 맞출 수 있지만 점질량과 음의 효용값의 의미를 제거하지는 못한다.

위 그림은 연속적인 베타밀도가 0과 1 사이의 비대칭성은 설명할 수 있지만, 정확히 1에 쌓이는 관측값은 별도의 확률질량으로 다루어야 함을 보여준다.

11.10 영과잉 포아송 회귀분석

의료이용자료에서는 0이 매우 많이 관찰된다. 예를 들어 대부분의 환자는 특정 기간 동안 입원하지 않지만, 일부 환자는 반복적으로 입원할 수 있다. 이 경우 단순 포아송 모형은 0의 비율과 양의 횟수 분포를 동시에 설명하기 어려울 수 있다.

영과잉 포아송 모형은 두 과정을 결합한다.

  1. 구조적으로 항상 0이 되는 과정
  2. 포아송 분포를 따르는 계수 과정

수식으로 쓰면 다음과 같다.

\[ P(Y_i=0\mid x_i,z_i)=\pi_i+(1-\pi_i)\exp(-\mu_i), \]

\[ P(Y_i=y\mid x_i,z_i)=(1-\pi_i)\frac{\exp(-\mu_i)\mu_i^y}{y!}, \qquad y=1,2,\ldots. \]

여기서 \(\pi_i\)는 구조적 0에 속할 확률이고, \(\mu_i\)는 포아송 계수 과정의 평균이다. 보통 다음과 같이 두 개의 회귀식을 사용한다.

\[ \operatorname{logit}(\pi_i)=z_i^T\gamma, \qquad \log(\mu_i)=x_i^T\beta. \]

전체 조건부 평균은 다음과 같다.

\[ \mathbb{E}(Y_i\mid x_i,z_i)=(1-\pi_i)\mu_i. \]

전체 분산은 다음과 같다.

\[ \operatorname{Var}(Y_i\mid x_i,z_i) =(1-\pi_i)\mu_i\{1+\pi_i\mu_i\}. \]

따라서 영과잉 과정 자체가 추가 과산포를 만든다. 영과잉모형과 hurdle 모형은 0의 생성기전을 다르게 가정한다. Hurdle 모형에서는 0과 양의 값이 완전히 분리되고, 양의 값은 0에서 절단된 계수분포를 따른다.

\[ P(Y_i=0)=\pi_i, \qquad P(Y_i=y\mid Y_i>0)= \frac{f_{\text{count}}(y;\mu_i)}{1-f_{\text{count}}(0;\mu_i)}. \]

영과잉모형은 계수 과정에서도 우연한 0이 발생할 수 있지만, hurdle 모형의 양의 계수 과정에서는 0이 불가능하다. 구조적 0이라는 잠재집단이 임상적으로 구분되지 않으면 두 성분의 식별이 약해질 수 있으므로, 단순히 0의 비율만으로 모형을 선택해서는 안 된다.

경제성 평가에 입력할 자원사용량은 계수 과정의 평균 \(\mu_i\)가 아니라 전체 평균 \((1-\pi_i)\mu_i\)이다. 구조적 0의 의미가 임상적으로 타당한지 확인하는 것도 중요하다. 단순히 0이 많다는 이유만으로 zero-inflated model을 사용하는 것은 적절하지 않을 수 있다.

위 그림은 관찰된 0이 단일한 원인에서 나온다고 가정하지 않는다. 다만 두 잠재과정의 구분은 통계적 적합도뿐 아니라 임상적으로 ‘발생 가능성이 없는 환자’가 실제로 존재하는지에 의해 뒷받침되어야 한다.

11.11 순서형 로지스틱 회귀분석

순서형 로지스틱 회귀분석은 결과변수가 자연스러운 순서를 가지는 범주형 자료일 때 사용한다. 예를 들어 치료반응을 악화, 불변, 부분반응, 완전반응으로 구분하거나, 통증을 없음, 경도, 중등도, 중증으로 구분하는 경우가 있다.

누적 로짓 모형은 다음과 같이 표현한다.

\[ \operatorname{logit}\{P(Y_i\le k\mid x_i)\}=\alpha_k-x_i^T\beta, \qquad k=1,\ldots,K-1. \]

여기서 \(\alpha_k\)는 절단점이고, \(\beta\)는 모든 누적 로짓에 공통으로 적용되는 회귀계수이다. 이 공통성은 비례오즈 가정이라고 부른다.

잠재 연속변수 \(Y_i^*\)를 이용하면 누적 로짓 모형을 다음과 같이 이해할 수 있다.

\[ Y_i^*=x_i^T\beta+\varepsilon_i, \qquad Y_i=k\quad\text{if}\quad \alpha_{k-1}<Y_i^*\le\alpha_k, \]

여기서 \(\varepsilon_i\)는 로지스틱분포를 따른다. 비례오즈 가정은 공변량이 잠재반응의 위치를 이동시키지만 절단점마다 효과의 크기는 같다는 뜻이다. 이 가정이 성립하지 않으면 일부 계수만 절단점별로 다르게 허용하는 부분 비례오즈모형을 고려할 수 있다.

누적오즈비 \(\exp(\beta_j)\)는 특정 범주 하나의 오즈비가 아니라, 어느 절단점을 사용하더라도 ‘더 높은 범주’에 속할 상대오즈가 동일하다는 의미이다. 경제성 평가에서는 이 조건부 오즈비보다 각 범주의 표준화 확률이 비용과 효용을 계산하는 데 직접적으로 필요하다.

범주별 확률은 누적확률의 차이로 계산한다.

\[ P(Y_i=1\mid x_i)=P(Y_i\le 1\mid x_i), \]

\[ P(Y_i=k\mid x_i)=P(Y_i\le k\mid x_i)-P(Y_i\le k-1\mid x_i), \qquad k=2,\ldots,K-1, \]

\[ P(Y_i=K\mid x_i)=1-P(Y_i\le K-1\mid x_i). \]

경제성 평가에서는 각 반응 범주에 비용 또는 효용을 부여할 수 있다. 범주 \(k\)의 효용을 \(u_k\)라고 하면 기대 효용은 다음과 같다.

\[ \mathbb{E}(U_i\mid x_i)=\sum_{k=1}^K u_k P(Y_i=k\mid x_i). \]

위 그림은 치료효과를 하나의 공통 오즈비로 요약하더라도 경제성 평가의 기대 효용은 범주별 확률 전체와 각 범주에 부여한 효용값에 의해 결정된다는 점을 보여준다.

11.12 혼합모형

혼합모형은 고정효과와 무작위효과를 함께 포함하는 모형이다. 반복측정 효용자료, 다기관 임상시험, 국가별 자료, 환자군집 자료에서 자주 사용된다.

연속형 반복측정 결과 \(Y_{ij}\)를 환자 \(i\)의 시점 \(j\) 결과라고 하자. 선형 혼합모형은 다음과 같이 쓸 수 있다.

\[ Y_{ij}=x_{ij}^T\beta+z_{ij}^T b_i+\varepsilon_{ij}, \]

\[ b_i\sim N(0,D), \qquad \varepsilon_i\sim N(0,R_i). \]

같은 환자에서 두 시점 \(j\)와 \(k\)의 공분산은 다음과 같다.

\[ \operatorname{Cov}(Y_{ij},Y_{ik}\mid X_i) =z_{ij}^TDz_{ik}+R_i[j,k]. \]

무작위 절편만 있고 잔차가 독립이면 환자 내 상관계수는 다음과 같다.

\[ ICC=\frac{\sigma_b^2}{\sigma_b^2+\sigma_\varepsilon^2}. \]

ICC는 전체 변동 중 환자 간 차이가 차지하는 비율을 나타낸다. 반복측정 횟수가 많아도 ICC가 크면 독립 관측값과 같은 정보량을 제공하지 않으므로, 환자 수가 추론의 핵심 단위가 된다.

여기서 \(b_i\)는 환자별 무작위효과이며, 같은 환자 내 반복측정값 사이의 상관성을 유도한다. 단순한 무작위 절편모형은 다음과 같다.

\[ Y_{ij}=\beta_0+\beta_A A_i+\beta_t t_{ij}+\beta_{At}A_i t_{ij}+b_i+\varepsilon_{ij}. \]

이 모형에서 시간 \(t\)의 치료군별 평균 효용은 다음과 같다.

\[ \mathbb{E}(Y_{ij}\mid A_i=a,t_{ij}=t)=\beta_0+\beta_A a+\beta_t t+\beta_{At}at. \]

추적기간 \([0,\tau]\)의 기대 QALY는 효용곡선을 적분하여 얻는다.

\[ Q_a(\tau)=\int_0^\tau \mathbb{E}\{U_a(t)\}dt. \]

사망이 발생할 수 있는 자료에서는 살아 있는 환자의 평균 효용과 생존확률을 분리하여 다음처럼 표현하는 것이 더 명확하다.

\[ Q_a(\tau) =\int_0^\tau S_a(t)\, \mathbb{E}\{U_a(t)\mid T_a>t\}\,dt. \]

효용 관찰이 사망 전 환자에게만 가능하므로, 단순한 혼합모형이 추정하는 값은 흔히 생존자 조건부 평균이다. 사망과 탈락이 효용궤적과 관련되면 누락이 무작위라는 가정이 성립하지 않을 수 있다. 이 경우 longitudinal–survival joint model, pattern-mixture model, 또는 민감도 분석을 통해 정보성 탈락의 영향을 평가해야 한다.

무작위효과가 포함된 비선형 모형에서는 조건부 평균과 주변 평균이 다를 수 있다. 예를 들어 로지스틱 혼합모형에서 다음 두 값은 일반적으로 같지 않다.

\[ \mathbb{E}_b\left[\operatorname{logit}^{-1}(x^T\beta+z^Tb)\right] \ne \operatorname{logit}^{-1}(x^T\beta). \]

따라서 경제성 평가 입력값이 환자특이적 예측인지, 목표 인구집단의 주변 평균인지 명확히 해야 한다.

위 그림에서 환자별 곡선이 공통 평균 주변에서 서로 다른 수준과 기울기를 갖는 현상은 무작위효과로 표현된다. 경제성 평가에서 필요한 평균 효용곡선은 환자별 조건부 곡선을 단순히 한 환자에게 적용하는 것이 아니라 목표 모집단의 무작위효과 분포에 대해 평균한 값이어야 한다.

11.13 일반화 추정 방정식

일반화 추정 방정식은 반복측정 또는 군집자료에서 주변 평균을 직접 모델링한다. 환자 \(i\)의 반복측정 벡터를 \(Y_i=(Y_{i1},\ldots,Y_{im_i})^T\)라고 하자. 평균벡터는 다음과 같다.

\[ \mu_i=\mathbb{E}(Y_i\mid X_i). \]

GEE는 다음 추정방정식을 푼다.

\[ \sum_{i=1}^n D_i^T V_i^{-1}(Y_i-\mu_i)=0, \]

여기서 \(D_i=\partial \mu_i/\partial\beta^T\)이고, \(V_i\)는 working covariance matrix이다. \(V_i\)는 다음과 같이 분해할 수 있다.

\[ V_i=A_i^{1/2}R(\alpha)A_i^{1/2}, \]

여기서 \(A_i\)는 분산함수로 만든 대각행렬, \(R(\alpha)\)는 working correlation matrix이다. Working correlation이 정확하지 않아도 평균모형이 올바르게 지정되어 있으면 sandwich variance를 이용해 일관된 표준오차를 얻을 수 있다.

GEE의 sandwich variance는 개념적으로 다음 형태를 가진다.

\[ \widehat{\operatorname{Var}}(\widehat{\beta})=B^{-1}MB^{-1}, \]

\[ B=\sum_{i=1}^n D_i^T V_i^{-1}D_i, \qquad M=\sum_{i=1}^n D_i^T V_i^{-1}(Y_i-\mu_i)(Y_i-\mu_i)^TV_i^{-1}D_i. \]

경제성 평가에서 GEE는 반복측정 효용값의 평균 경향을 추정하거나, 군집화된 의료이용 자료의 주변 평균을 추정할 때 유용하다.

GEE의 점근이론은 관측치 수보다 독립적인 군집 수가 증가한다는 조건에 의존한다. 기관 수나 환자 수가 적은 경우 sandwich 표준오차가 하향편향될 수 있으므로 작은 표본 보정이나 군집수준 부트스트랩이 필요하다. 또한 표준 GEE는 누락이 군집 내 관찰결과와 공변량을 조건으로 완전무작위라는 조건에서 가장 단순하게 정당화된다. 누락이 관찰된 과거 결과에 의존하는 경우에는 inverse probability weighted GEE를 사용할 수 있다.

Working correlation을 독립, 교환가능, AR(1), 비구조형 중에서 선택하더라도 평균모형이 올바르면 회귀계수의 일관성은 유지될 수 있다. 그러나 효율성과 작은 표본 성능은 달라진다. 경제성 평가의 최종 목적이 시간별 평균 효용과 누적 QALY라면 시간함수와 치료–시간 상호작용의 지정이 working correlation 선택보다 더 중요하다.

위 그림은 혼합모형과 GEE가 동일한 자료를 사용하더라도 서로 다른 평균을 목표로 할 수 있음을 나타낸다. 특히 비선형 연결함수에서는 환자특이적 계수를 주변 효과로 직접 해석할 수 없다.

Tip혼합모형과 GEE의 선택

경제성 평가에서 최종적으로 필요한 값이 목표 인구집단의 평균 비용이나 평균 QALY라면 GEE의 주변 평균 해석이 직관적일 수 있다. 반면 환자별 이질성, 장기 예측, 무작위효과 분산, 기관 간 차이를 모델링해야 한다면 혼합모형이 더 적절할 수 있다.

11.14 비용과 QALY의 공동 회귀모형

비용과 QALY는 같은 환자에게서 함께 관찰되며 일반적으로 상관되어 있다. 두 결과를 각각 선형 평균모형으로 표현하면 다음과 같다.

\[ C_i=x_{Ci}^T\beta_C+\varepsilon_{Ci}, \qquad Q_i=x_{Qi}^T\beta_Q+\varepsilon_{Qi}, \]

\[ \begin{pmatrix} \varepsilon_{Ci}\\ \varepsilon_{Qi} \end{pmatrix} \sim \left( \begin{pmatrix}0\\0\end{pmatrix}, \begin{pmatrix} \sigma_C^2 & \sigma_{CQ}\\ \sigma_{CQ} & \sigma_Q^2 \end{pmatrix} \right). \]

이 구조는 seemingly unrelated regression의 기본 형태이다. 두 식의 설명변수가 동일하면 각 회귀계수의 점추정은 별도 최소제곱과 같을 수 있지만, \(\sigma_{CQ}\)를 추정하면 증분비용과 증분 QALY의 공분산을 직접 얻을 수 있다. 설명변수가 다르면 공동추정이 효율성을 높일 수 있다.

비용이 감마분포를 따르고 QALY가 정규분포 또는 베타분포를 따르는 경우에는 단순 이변량 정규모형이 적합하지 않을 수 있다. 이때 공유 무작위효과, copula, 베이지안 다변량모형을 이용하여 서로 다른 주변분포와 결과 간 의존성을 결합할 수 있다.

지불의사금액 \(\lambda\)가 고정되면 환자 수준 순편익을 직접 회귀분석할 수도 있다.

\[ NB_i(\lambda)=\lambda Q_i-C_i, \]

\[ NB_i(\lambda)=\alpha_0+\alpha_AA_i+\alpha_X^TX_i+e_i. \]

선형 평균모형이 올바르면 치료계수 \(\alpha_A\)는 공변량을 보정한 증분순편익이다. 이 방법은 비용과 QALY의 공분산을 순편익의 분산에 자동으로 반영하지만, \(\lambda\)가 바뀔 때마다 결과변수와 회귀모형의 해석이 달라진다. 따라서 전략별 비용과 QALY를 별도로 보고하면서 순편익 회귀를 보조적으로 사용하는 것이 좋다.

11.15 회귀모형의 진단과 의사결정 관련 적합도

회귀모형의 적합도는 계수의 유의성만으로 평가할 수 없다. 경제성 평가에서는 다음 세 수준을 구분해야 한다.

첫째, 평균모형의 적합성이다. 선형성, 상호작용, 시간함수와 연결함수가 목표 인구집단의 평균을 적절히 설명해야 한다. 둘째, 분산 및 상관구조의 적합성이다. 이는 신뢰구간, 부트스트랩, PSA 분포에 영향을 준다. 셋째, 의사결정 척도의 적합성이다. 원래 척도의 평균 비용, QALY, INB를 얼마나 잘 예측하는지가 중요하다.

예측오차를 \(L(Y,\widehat{Y})\)라고 하면 교차검증 위험은 다음과 같이 표현할 수 있다.

\[ \widehat{R}_{CV} =\frac{1}{K}\sum_{k=1}^K \frac{1}{|I_k|}\sum_{i\in I_k} L\{Y_i,\widehat{m}^{(-k)}(X_i)\}. \]

비용분석에서는 로그척도의 제곱오차가 작더라도 원래 척도의 평균비용 편향이 클 수 있다. 따라서 모형 비교는 관심 estimand와 동일한 척도에서 수행해야 한다. AIC나 deviance는 유용한 진단이지만, 장기 모형 입력값이나 증분순편익의 안정성을 대신하지 않는다.

11.16 회귀모형 결과를 경제성 평가 입력값으로 변환하기

회귀분석 결과를 경제성 평가에 사용하려면 회귀계수를 그대로 가져오는 것이 아니라, 비용과 QALY의 전략별 평균을 계산해야 한다. 일반적인 절차는 다음과 같다.

  1. 목표 인구집단을 정의한다.
  2. 목표 인구집단의 공변량 분포 \(F^*(x)\)를 정한다.
  3. 각 치료전략 \(a\)에 대해 예측값 \(\widehat{m}_C(a,x_i)\)와 \(\widehat{m}_Q(a,x_i)\)를 계산한다.
  4. 예측값을 평균하여 \(\widehat{C}_a\)와 \(\widehat{Q}_a\)를 얻는다.
  5. \(\widehat{\Delta C}\), \(\widehat{\Delta Q}\), \(\widehat{ICER}\), \(\widehat{INB}(\lambda)\)를 계산한다.
  6. 모형 불확실성과 표본 불확실성을 부트스트랩, delta method, 또는 PSA로 반영한다.

수식으로 쓰면 다음과 같다.

\[ \widehat{C}_a=\frac{1}{n}\sum_{i=1}^n \widehat{m}_C(a,x_i), \qquad \widehat{Q}_a=\frac{1}{n}\sum_{i=1}^n \widehat{m}_Q(a,x_i). \]

\[ \widehat{\Delta C}=\widehat{C}_1-\widehat{C}_0, \qquad \widehat{\Delta Q}=\widehat{Q}_1-\widehat{Q}_0. \]

\[ \widehat{INB}(\lambda)=\lambda\widehat{\Delta Q}-\widehat{\Delta C}. \]

회귀모형에서 비용과 QALY를 따로 적합하면 두 추정값의 상관성이 무시될 수 있다. 환자 수준 자료에서 비용과 QALY가 함께 관찰되었다면 비모수 부트스트랩은 이 상관성을 자연스럽게 보존한다. 부트스트랩 반복 \(b=1,\ldots,B\)에 대해 다음 값을 계산한다.

\[ \widehat{\Delta C}^{(b)}, \qquad \widehat{\Delta Q}^{(b)}, \qquad \widehat{INB}^{(b)}(\lambda)=\lambda\widehat{\Delta Q}^{(b)}-\widehat{\Delta C}^{(b)}. \]

비용효과수용확률은 다음과 같이 추정한다.

\[ \widehat{P}\{INB(\lambda)>0\}=\frac{1}{B}\sum_{b=1}^B I\{\widehat{INB}^{(b)}(\lambda)>0\}. \]

11.16.1 델타방법을 이용한 표준화 평균의 분산

비선형 모형의 표준화 평균을 \(h_a(\widehat{\beta})\)라고 쓰면 델타방법에 따라 다음 근사가 성립한다.

\[ \operatorname{Var}\{h_a(\widehat{\beta})\} \approx G_a^T\operatorname{Var}(\widehat{\beta})G_a, \]

\[ G_a=\left.\frac{\partial h_a(\beta)}{\partial\beta}\right|_{\widehat{\beta}}. \]

두 전략의 차이에서는 \(G_1-G_0\)가 기울기가 된다. 비용모형과 QALY모형을 별도로 적합하면 두 모형의 계수 공분산까지 필요하므로 분석적 계산이 복잡해진다. 같은 환자를 재표집하는 비모수 부트스트랩은 비용과 QALY, 공변량, 사건의 경험적 결합분포를 함께 보존한다.

군집무작위시험이나 반복측정자료에서는 관측행이 아니라 독립적인 군집이나 환자를 재표집해야 한다. 층화무작위배정을 사용했다면 부트스트랩에서도 치료군 또는 층화변수 구조를 보존하는 것이 바람직하다. 모형 선택이나 재변환 보정까지 자료의 영향을 받는다면 그 절차도 각 반복 안에서 다시 수행해야 한다.

11.16.2 결측자료와 표준화

회귀분석에 완전사례만 사용하면 결측이 결과 및 비용과 관련된 경우 목표 인구집단의 평균을 왜곡할 수 있다. 다중대치에서는 \(M\)개의 완성자료에서 전략별 평균을 각각 계산한 뒤 통합한다.

\[ \overline{\mu}_a=\frac{1}{M}\sum_{m=1}^M\widehat{\mu}_a^{(m)}. \]

대치 간 분산을 \(B_M\), 대치 내 분산의 평균을 \(\overline{U}\)라고 하면 Rubin의 전체분산은 다음과 같다.

\[ T=\overline{U}+\left(1+\frac{1}{M}\right)B_M. \]

비용과 QALY를 함께 대치할 때는 두 결과의 상관성과 치료군, 기저 효용, 생존상태, 자원사용량을 대치모형에 포함해야 한다. 사망 후 효용은 일반적인 누락값이 아니라 정의상 0인 상태일 수 있으므로, 결측기전과 구조적 0을 구분해야 한다.

위 그림은 조건부 회귀식에서 시작하여 목표 인구집단의 전략별 평균을 만든 뒤 증분결과로 이동하는 순서를 보여준다. 비선형 연결함수에서는 계수 차이가 아니라 이 전체 변환과정이 분석의 estimand를 결정한다.

위 그림에서 각 점은 비용모형과 QALY모형을 다시 적합하고 표준화한 하나의 부트스트랩 반복이다. 점들의 기울어진 분포는 증분비용과 증분 QALY의 공분산을 나타내며, 이를 무시하면 INB와 비용효과확률의 불확실성이 왜곡될 수 있다.

Warning회귀기반 경제성 평가에서 흔한 오류

비선형 회귀모형의 치료계수만을 이용해 증분비용 또는 증분효과를 계산하면 목표 인구집단의 평균 차이를 잘못 추정할 수 있다. 경제성 평가에서는 항상 치료전략별 예측값을 원래 척도로 변환한 뒤, 목표 인구집단 공변량 분포에서 평균을 내야 한다.

## 회귀분석 {#sec-regression-analysis}

### 회귀분석의 공통 구조

회귀분석은 결과변수 $Y_i$의 조건부 분포를 설명변수 벡터 $x_i$의 함수로 표현한다. 가장 일반적인 표기는 다음과 같다.

$$
Y_i \mid x_i \sim f(y_i \mid \theta_i),
$$

여기서 $\theta_i$는 조건부 분포의 모수이다. 많은 회귀모형에서는 조건부 평균을 중심으로 모형을 세운다.

$$
\mu_i=\mathbb{E}(Y_i\mid x_i).
$$

일반화 선형모형에서는 연결함수 $g(\cdot)$를 이용하여 평균과 선형예측자를 연결한다.

$$
g(\mu_i)=\eta_i=x_i^T\beta.
$$

이때 $x_i$는 절편, 치료군, 연령, 성별, 중증도, 기저 효용, 동반질환 등의 공변량을 포함할 수 있고, $\beta$는 회귀계수 벡터이다. 연결함수와 분포를 바꾸면 서로 다른 형태의 결과변수를 다룰 수 있다.

| 결과변수 | 조건부 평균 | 흔한 분포 | 연결함수 | 경제성 평가 입력값 |
|---|---:|---|---|---|
| QALY, 연속 효용 | $\mu_i$ | 정규분포 | 항등 | 평균 QALY |
| 비용 | $\mu_i>0$ | 감마분포, 로그정규분포 | 로그 | 기대 비용 |
| 이상반응 여부 | $p_i$ | Bernoulli | 로짓 | 사건확률 |
| 입원 횟수 | $\mu_i$ | Poisson, negative binomial | 로그 | 사건률, 자원사용량 |
| 효용값 | $0<\mu_i<1$ | Beta | 로짓 | 평균 효용 |
| 순서형 반응 | $P(Y_i\le k)$ | Categorical | 누적 로짓 | 반응 범주별 확률 |

### 지수족, 분산함수와 준가능도

일반화 선형모형의 다수는 결과변수의 분포가 지수족에 속한다고 가정한다. 한 관측값의 밀도 또는 확률질량함수는 다음과 같이 표현할 수 있다.

$$
f(y_i\mid\theta_i,\phi)
=\exp\left[\frac{y_i\theta_i-b(\theta_i)}{a(\phi)}+c(y_i,\phi)\right].
$$

여기서 $\theta_i$는 정준모수, $\phi$는 산포모수이다. 지수족에서는 평균과 분산이 다음 관계를 가진다.

$$
\mathbb{E}(Y_i\mid x_i)=b'(\theta_i)=\mu_i,
\qquad
\operatorname{Var}(Y_i\mid x_i)=b''(\theta_i)a(\phi)
=\phi V(\mu_i).
$$

$V(\mu_i)$는 **분산함수**이다. 정규분포에서는 $V(\mu)=1$, 포아송분포에서는 $V(\mu)=\mu$, 감마분포에서는 $V(\mu)=\mu^2$이다. 따라서 결과변수의 평균뿐 아니라 평균이 증가할 때 분산이 어떤 속도로 증가하는지를 함께 고려해야 한다.

연결함수 $g(\mu_i)$가 정준모수와 직접 연결되면 정준연결함수라고 한다. 그러나 경제성 평가에서는 정준성보다 해석과 예측척도가 더 중요할 수 있다. 예를 들어 감마분포의 정준연결은 역수 연결이지만, 비용의 평균비를 직관적으로 표현하고 예측값을 양수로 제한하기 위해 로그 연결을 더 자주 사용한다.

분포 전체를 정확히 지정하지 않고 평균모형과 분산함수만 지정하는 준가능도 접근도 가능하다. 평균모형이 올바르면 회귀계수는 일관되게 추정될 수 있지만, 분산함수의 오지정은 모형 기반 표준오차를 왜곡할 수 있다. 이때 sandwich 형태의 강건분산을 사용할 수 있다. 다만 강건분산은 잘못 지정된 평균함수나 연결함수를 교정하지는 못한다.

### 조건부 효과와 주변 효과

회귀계수는 보통 조건부 효과를 나타낸다. 예를 들어 선형모형에서 치료계수 $\beta_1$은 공변량이 같은 환자들 사이의 평균 차이를 의미한다.

$$
\mathbb{E}(Y_i\mid A_i=1,x_i)-\mathbb{E}(Y_i\mid A_i=0,x_i)=\beta_1.
$$

하지만 경제성 평가에서 필요한 값은 대개 목표 인구집단 전체의 평균 비용과 평균 QALY이다. 목표 인구집단의 공변량 분포를 $F^*(x)$라고 하면 치료전략 $a$의 주변 평균은 다음과 같이 정의된다.

$$
\mu_a^*=\int \mathbb{E}(Y\mid A=a,X=x)dF^*(x).
$$

표본이 목표 인구집단을 대표한다고 가정하면 이는 예측값의 평균으로 근사할 수 있다.

$$
\widehat{\mu}_a^*=\frac{1}{n}\sum_{i=1}^n \widehat{m}(a,x_i),
$$

여기서 $\widehat{m}(a,x_i)$는 환자 $i$가 치료 $a$를 받았다고 가정했을 때의 예측 평균이다. 이를 **표준화**, **g-computation**, 또는 **average predictive comparison**이라고 부른다.

증분 평균은 다음과 같이 계산한다.

$$
\widehat{\Delta}=\widehat{\mu}_1^*-\widehat{\mu}_0^*.
$$

비용과 QALY에 각각 적용하면 $\widehat{\Delta C}$와 $\widehat{\Delta Q}$를 얻을 수 있고, 이는 ICER와 INB 계산으로 이어진다.

$$
\widehat{ICER}=\frac{\widehat{\Delta C}}{\widehat{\Delta Q}},
\qquad
\widehat{INB}(\lambda)=\lambda\widehat{\Delta Q}-\widehat{\Delta C}.
$$

### 표준화의 인과적 해석과 식별 조건

치료전략별 표준화 평균을 잠재결과 표기로 쓰면 다음과 같다.

$$
\mu_a^*=\mathbb{E}_{F^*}\{Y(a)\}.
$$

관찰자료에서 이를 회귀모형으로 식별하려면 일관성, 조건부 교환가능성, 양의 확률 조건이 필요하다.

$$
Y=Y(A),
$$

$$
Y(a)\perp A\mid X,
$$

$$
0<P(A=a\mid X=x)<1
$$

가 목표 모집단에서 성립해야 한다. 무작위배정 임상시험에서는 치료배정의 교환가능성이 설계에 의해 확보되지만, 탈락이나 치료교차가 결과와 관련되면 추가 가정이 필요할 수 있다. 관찰연구에서는 중요한 교란변수가 누락되면 표준화된 예측값도 인과효과로 해석할 수 없다.

목표 모집단이 분석표본과 다르면 가중 표준화를 사용할 수 있다. 목표 모집단 대표성을 반영하는 가중치를 $w_i$라고 하면 다음과 같다.

$$
\widehat{\mu}_a^*
=\frac{\sum_{i=1}^n w_i\widehat{m}(a,x_i)}{\sum_{i=1}^n w_i}.
$$

따라서 회귀모형의 외삽은 두 종류로 구분해야 한다. 하나는 관찰된 공변량 범위 안에서 치료만 바꾸는 **치료전략 외삽**이고, 다른 하나는 분석표본과 다른 공변량 분포로 이동하는 **인구집단 외삽**이다. 후자는 효과변경인자가 충분히 측정되고 모형이 올바르게 지정되었다는 더 강한 조건을 요구한다.

![결과변수 유형에 따라 적절한 분포와 연결함수를 선택해야 한다.](figures/ch11/fig-ch11-glm-family-map.png)

위 그림에서 분포와 연결함수의 선택은 단순한 소프트웨어 옵션이 아니다. 결과변수의 지지집합, 평균–분산 관계, 0이나 1의 점질량, 반복측정 구조를 반영해야 원래 척도의 평균값을 안정적으로 추정할 수 있다.

## 실무에서 중요한 구분 {.unnumbered}

회귀모형의 치료계수와 경제성 평가에 필요한 평균 차이는 항상 같지 않다. 특히 로지스틱 회귀, 감마 회귀, 로그정규 회귀처럼 비선형 연결함수를 사용하는 경우에는 회귀계수 하나를 그대로 ICER의 입력값으로 사용하면 안 된다. 각 치료전략에 대해 목표 인구집단의 예측값을 계산하고 평균을 내는 과정이 필요하다.
:::

## 다중 선형회귀분석 {#sec-multiple-linear-regression}

다중 선형회귀분석은 연속형 결과변수의 조건부 평균을 공변량의 선형결합으로 표현한다.

$$
Y_i=x_i^T\beta+\varepsilon_i,
\qquad
\mathbb{E}(\varepsilon_i\mid x_i)=0.
$$

고전적 선형모형에서는 다음 분산 가정을 추가한다.

$$
\operatorname{Var}(\varepsilon_i\mid x_i)=\sigma^2.
$$

표본 전체에 대해 $Y=(Y_1,\ldots,Y_n)^T$, 설계행렬을 $X$라고 하면 최소제곱 추정량은 다음과 같다.

$$
\widehat{\beta}=(X^TX)^{-1}X^TY.
$$

오차분산 추정량은 다음과 같다.

$$
\widehat{\sigma}^2=\frac{1}{n-p}\sum_{i=1}^n (Y_i-x_i^T\widehat{\beta})^2,
$$

여기서 $p$는 회귀계수의 수이다. 추정량의 분산은 다음과 같이 추정한다.

$$
\widehat{\operatorname{Var}}(\widehat{\beta})=\widehat{\sigma}^2(X^TX)^{-1}.
$$

경제성 평가에서는 QALY, 특정 기간의 효용 평균, 체중, 검사수치, 연속형 임상지표를 분석할 때 선형회귀를 사용할 수 있다. 그러나 비용자료는 양수이고 오른쪽으로 긴 꼬리를 가지는 경우가 많으므로 선형모형을 기계적으로 적용하면 음의 예측비용이나 과도한 영향점 문제가 발생할 수 있다.

### 예측 평균과 표준오차

치료전략 $a$의 표준화 평균을 다음과 같이 정의하자.

$$
\widehat{\mu}_a^*=\frac{1}{n}\sum_{i=1}^n x_i(a)^T\widehat{\beta},
$$

여기서 $x_i(a)$는 환자 $i$의 공변량은 그대로 두고 치료변수만 $a$로 바꾼 설계벡터이다. 평균 예측값은 선형함수이므로 다음과 같이 쓸 수 있다.

$$
\widehat{\mu}_a^*=\bar{x}(a)^T\widehat{\beta},
\qquad
\bar{x}(a)=\frac{1}{n}\sum_{i=1}^n x_i(a).
$$

따라서 분산은 다음과 같이 계산할 수 있다.

$$
\widehat{\operatorname{Var}}(\widehat{\mu}_a^*)=\bar{x}(a)^T\widehat{\operatorname{Var}}(\widehat{\beta})\bar{x}(a).
$$

증분 평균 $\widehat{\Delta}=\widehat{\mu}_1^*-\widehat{\mu}_0^*$의 분산은 다음과 같다.

$$
\widehat{\operatorname{Var}}(\widehat{\Delta})=
\{\bar{x}(1)-\bar{x}(0)\}^T
\widehat{\operatorname{Var}}(\widehat{\beta})
\{\bar{x}(1)-\bar{x}(0)\}.
$$

이 식은 선형모형에서는 분석적으로 편리하지만, 여러 비선형 모형을 결합하여 ICER를 계산할 때는 부트스트랩이나 PSA가 더 실용적인 경우가 많다.

### 최소제곱 추정량의 성질과 강건분산

최소제곱 추정량이 조건부 평균효과를 올바르게 추정하려면 다음 평균 독립 조건이 핵심이다.

$$
\mathbb{E}(\varepsilon_i\mid X)=0.
$$

오차의 정규성은 $\widehat{\beta}$의 불편성에 필요한 조건이 아니다. 정규성은 주로 작은 표본에서 정확한 $t$ 검정과 신뢰구간을 구성할 때 사용된다. 또한 등분산성은 최소제곱 추정량의 불편성보다 효율성과 통상적 표준오차 공식에 필요한 조건이다.

비용이나 효용자료에서 이분산성이 존재하면 다음 sandwich 분산추정량을 사용할 수 있다.

$$
\widehat{\operatorname{Var}}_{\mathrm{HC}}(\widehat{\beta})
=(X^TX)^{-1}
\left(\sum_{i=1}^n x_ix_i^T\widehat{\varepsilon}_i^2\right)
(X^TX)^{-1}.
$$

강건분산은 이분산성으로 인한 표준오차 왜곡을 줄이지만, 비선형 평균관계, 누락된 상호작용, 영향력이 큰 극단값을 해결하지는 않는다. 따라서 잔차–적합값 관계, 부분잔차, 영향도와 표준화 예측값의 민감도를 함께 점검해야 한다.

선형모형의 장점은 결과변수의 분포가 비대칭이어도 조건부 평균식이 올바르고 표본이 충분히 크면 평균 차이 추정에 사용할 수 있다는 점이다. 그러나 작은 표본에서 고비용 관측값이 소수 존재하면 평균 추정량과 부트스트랩 분포가 불안정할 수 있으므로, 감마 GLM이나 로그정규모형과 함께 비교하는 것이 바람직하다.

## 공분산분석 {#sec-ancova}

공분산분석은 치료군 비교에서 기저값 또는 예후인자를 보정하여 평균 결과를 추정하는 선형모형이다. 임상시험 기반 경제성 평가에서는 기저 효용 또는 기저 비용을 보정한 QALY 분석에 자주 사용된다.

예를 들어 $Y_i$를 추적기간 QALY, $A_i$를 치료군, $B_i$를 기저 효용이라고 하면 ANCOVA 모형은 다음과 같다.

$$
Y_i=\beta_0+\beta_A A_i+\beta_B B_i+\varepsilon_i.
$$

무작위배정 임상시험에서 단순 평균 차이도 인과적으로 해석할 수 있지만, 기저값을 보정하면 추정 정밀도가 향상될 수 있다. 특히 기저 효용과 추적기간 QALY의 상관이 클수록 보정의 이득이 커진다.

치료군별 기저값 분포가 표본에서 우연히 다를 수 있으므로, 경제성 평가에서는 다음과 같이 공통 공변량 분포에서 표준화된 평균 QALY를 계산하는 것이 바람직하다.

$$
\widehat{Q}_a=\frac{1}{n}\sum_{i=1}^n \left(\widehat{\beta}_0+\widehat{\beta}_A a+\widehat{\beta}_B B_i\right).
$$

증분 QALY는 다음과 같다.

$$
\widehat{\Delta Q}=\widehat{Q}_1-\widehat{Q}_0.
$$

선형모형에 치료와 기저값의 상호작용이 없으면 $\widehat{\Delta Q}=\widehat{\beta}_A$가 된다. 그러나 상호작용을 포함하면 치료효과는 기저값에 따라 달라지므로 목표 인구집단 분포에서 표준화해야 한다.

$$
Y_i=\beta_0+\beta_A A_i+\beta_B B_i+\beta_{AB}A_iB_i+\varepsilon_i.
$$

이때 환자 $i$의 조건부 치료효과는 다음과 같다.

$$
\mathbb{E}(Y_i\mid A_i=1,B_i)-\mathbb{E}(Y_i\mid A_i=0,B_i)
=\beta_A+\beta_{AB}B_i.
$$

목표 인구집단에서의 평균 치료효과는 다음과 같다.

$$
\Delta Q^*=\beta_A+\beta_{AB}\mathbb{E}_{F^*}(B).
$$

### ANCOVA와 변화량 분석의 차이

기저값 $B_i$와 추적 결과 $Y_i$가 모두 관찰될 때 변화량 $Y_i-B_i$를 비교하는 방법도 가능하다. 그러나 변화량 분석은 기저값의 회귀계수를 1로 고정한 특수한 모형에 해당한다. 반면 ANCOVA는 자료에서 기저값과 추적 결과의 관계를 추정한다.

$$
Y_i=\beta_0+\beta_AA_i+\beta_BB_i+\varepsilon_i.
$$

기저값이 결과를 잘 예측할수록 잔차분산이 감소한다. 단순화된 균형 임상시험에서 기저값이 결과변동의 $R_B^2$를 설명하면 치료효과 추정량의 분산은 대략 다음과 같이 감소한다.

$$
\operatorname{Var}(\widehat{\beta}_A\mid B)
\approx \sigma_Y^2(1-R_B^2)
\left(\frac{1}{n_1}+\frac{1}{n_0}\right).
$$

따라서 기저 효용과 추적기간 QALY의 상관이 높을수록 ANCOVA의 정밀도 이득이 커진다. 무작위배정 이후에 측정된 변수는 치료의 영향을 받을 수 있으므로 단순한 정밀도 향상을 목적으로 보정해서는 안 된다. 치료 후 변수의 보정은 매개경로를 차단하거나 collider bias를 유발하여 치료전략 효과의 estimand를 바꿀 수 있다.

![ANCOVA는 기저 효용의 차이를 보정하여 공통 기준에서 치료군의 평균 QALY를 비교한다.](figures/ch11/fig-ch11-ancova-adjustment.png)

위 그림은 각 군을 서로 다른 기저 효용값에서 직접 비교하는 대신, 동일한 기저 효용 분포로 표준화하여 평균 QALY를 비교하는 원리를 나타낸다.

## ANCOVA의 경제성 평가 해석 {.unnumbered}

QALY 분석에서 ANCOVA를 사용했다면 회귀계수만 보고 끝내지 말고, 각 치료군의 보정 평균 QALY와 증분 QALY를 함께 제시하는 것이 좋다. 비용효용분석에서는 이 값이 ICER의 분모가 되기 때문이다.
:::

## 로지스틱 회귀분석 {#sec-logistic-regression}

로지스틱 회귀분석은 이항 결과변수의 조건부 사건확률을 모델링한다. $Y_i=1$이면 사건 발생, $Y_i=0$이면 사건 미발생이라고 하자.

$$
Y_i\mid x_i\sim \operatorname{Bernoulli}(p_i),
$$

$$
\operatorname{logit}(p_i)=\log\left(\frac{p_i}{1-p_i}\right)=x_i^T\beta.
$$

따라서 사건확률은 다음과 같다.

$$
p_i=\frac{\exp(x_i^T\beta)}{1+\exp(x_i^T\beta)}.
$$

치료변수 $A_i$의 계수를 $\beta_A$라고 하면 조건부 오즈비는 다음과 같다.

$$
OR=\exp(\beta_A).
$$

하지만 경제성 평가에서 필요한 입력값은 대개 오즈비 자체가 아니라 치료군별 사건확률이다. 예를 들어 이상반응 비용을 반영하려면 $P(Y=1\mid A=1)$과 $P(Y=1\mid A=0)$가 필요하다. 목표 인구집단에서 표준화한 사건확률은 다음과 같다.

$$
\widehat{p}_a^*=\frac{1}{n}\sum_{i=1}^n
\frac{\exp\{x_i(a)^T\widehat{\beta}\}}{1+\exp\{x_i(a)^T\widehat{\beta}\}}.
$$

주변 위험차와 위험비는 다음과 같이 계산한다.

$$
\widehat{RD}=\widehat{p}_1^*-\widehat{p}_0^*,
\qquad
\widehat{RR}=\frac{\widehat{p}_1^*}{\widehat{p}_0^*}.
$$

로지스틱 회귀의 로그가능도는 다음과 같다.

$$
\ell(\beta)=\sum_{i=1}^n
\left[y_i\log(p_i)+(1-y_i)\log(1-p_i)\right].
$$

연속 공변량 $x_{ij}$의 계수 $\beta_j$는 로그오즈의 변화량이지만, 확률척도의 한계효과는 현재 사건확률에 따라 달라진다.

$$
\frac{\partial p_i}{\partial x_{ij}}
=\beta_jp_i(1-p_i).
$$

따라서 동일한 $\beta_j$라도 사건이 매우 드물거나 매우 흔한 환자에서는 절대확률 변화가 작다. 평균 한계효과는 환자별 미분값을 평균하여 계산할 수 있지만, 이항 치료변수에서는 치료값을 0과 1로 바꾼 표준화 위험차가 더 직접적이다.

모형의 적합도가 좋아도 확률예측이 잘 보정되었다고 보장되지는 않는다. 경제성 평가에서 사건확률을 입력값으로 사용할 때는 예측확률의 평균뿐 아니라 calibration-in-the-large와 calibration slope를 점검해야 한다. 과대적합된 모형은 극단적인 사건확률을 만들어 비용과 효용 손실을 과대평가할 수 있다.

### 오즈비를 절대확률로 변환하기

기준 사건확률이 $p_0$이고 조건부 또는 적용 가능한 오즈비가 $OR$일 때, 사건확률은 다음과 같이 변환된다.

$$
p_1=\frac{OR\,p_0}{1-p_0+OR\,p_0}.
$$

이 식은 오즈비를 확률로 해석할 때 특히 중요하다. 오즈비가 일정해도 기준위험 $p_0$가 다르면 위험차 $p_1-p_0$는 달라진다.

![동일한 오즈비라도 기준 사건확률에 따라 절대 위험차는 달라진다.](figures/ch11/fig-ch11-logistic-curve.png)

위 그림은 오즈비가 일정하더라도 로지스틱 곡선의 위치에 따라 절대위험 변화가 달라짐을 보여준다. 경제성 평가에서는 기준위험이 높은 하위군과 낮은 하위군에서 동일한 오즈비가 서로 다른 비용 및 QALY 영향을 만들 수 있다.

## 오즈비의 비축약성 {.unnumbered}

로지스틱 회귀의 오즈비는 비축약적이다. 즉, 교란이 없더라도 공변량을 보정한 조건부 오즈비와 보정하지 않은 주변 오즈비가 다를 수 있다. 따라서 경제성 평가에서는 오즈비 자체보다 표준화된 사건확률과 그 차이를 계산하는 것이 더 직접적이다.
:::

## 감마 회귀분석 {#sec-gamma-regression}

의료비 자료는 0보다 크고 오른쪽으로 긴 꼬리를 가지는 경우가 많다. 감마 회귀분석은 이러한 양수 연속형 자료에 적합한 일반화 선형모형이다.

감마분포를 평균 $\mu_i$와 shape 모수 $\alpha$로 표현하면 분산은 다음과 같다.

$$
\operatorname{Var}(Y_i\mid x_i)=\frac{\mu_i^2}{\alpha}.
$$

일반화 선형모형에서는 보통 로그 연결함수를 사용한다.

$$
\log(\mu_i)=x_i^T\beta,
\qquad
\mu_i=\exp(x_i^T\beta).
$$

치료계수 $\beta_A$의 지수값은 조건부 평균비로 해석된다.

$$
\frac{\mathbb{E}(Y_i\mid A_i=1,x_i)}{\mathbb{E}(Y_i\mid A_i=0,x_i)}=\exp(\beta_A).
$$

하지만 ICER에는 평균비가 아니라 평균 비용 차이가 필요하다. 따라서 다음처럼 치료전략별 예측 비용을 평균해야 한다.

$$
\widehat{C}_a=\frac{1}{n}\sum_{i=1}^n \exp\{x_i(a)^T\widehat{\beta}\}.
$$

증분비용은 다음과 같다.

$$
\widehat{\Delta C}=\widehat{C}_1-\widehat{C}_0.
$$

감마 회귀는 예측값이 항상 양수라는 장점이 있다. 그러나 실제 자료에 비용이 0인 관측값이 많다면 감마분포가 직접 적용되지 않는다. 이 경우에는 two-part model 또는 hurdle model을 고려해야 한다.

감마 GLM에서 변동계수는 shape 모수가 일정할 때 일정하다.

$$
\frac{\sqrt{\operatorname{Var}(Y_i\mid x_i)}}{\mathbb{E}(Y_i\mid x_i)}
=\frac{1}{\sqrt{\alpha}}.
$$

즉 평균비용이 커질수록 표준편차도 평균에 비례하여 커진다고 가정한다. 실제 자료의 평균–분산 관계가 이와 크게 다르면 분산함수의 오지정이 발생한다. 모형 선택에서는 로그변환 후 정규성만 보는 것보다 평균–분산 관계와 원래 척도에서의 예측 성능을 함께 비교해야 한다.

비용이 0인 관측값이 있는 경우 두 부분 모형의 전체 평균은 다음과 같다.

$$
\mathbb{E}(C_i\mid x_i)
=P(C_i>0\mid x_i)
\mathbb{E}(C_i\mid C_i>0,x_i).
$$

첫 번째 부분은 비용 발생확률을 로지스틱 회귀로, 두 번째 부분은 양의 비용을 감마 GLM 등으로 분석할 수 있다. 경제성 평가에 입력하는 값은 두 번째 부분의 조건부 평균만이 아니라 두 부분을 곱한 전체 평균이다.

![비용자료는 양수이고 오른쪽 꼬리가 길기 때문에 감마 또는 로그정규 모형이 자주 사용된다.](figures/ch11/fig-ch11-cost-models.png)

위 그림은 두 모형이 모두 오른쪽 비대칭을 허용하지만 꼬리와 분산구조에 대한 가정은 다르다는 점을 나타낸다. 모형 선택은 로그척도의 적합도보다 원래 비용척도의 평균과 증분비용이 얼마나 안정적으로 추정되는지를 기준으로 해야 한다.

## 로그 정규 회귀분석 {#sec-lognormal-regression}

로그 정규 회귀분석은 비용의 로그값이 정규분포를 따른다고 가정한다.

$$
\log(Y_i)=x_i^T\beta+\varepsilon_i,
\qquad
\varepsilon_i\sim N(0,\sigma^2).
$$

이때 원래 비용척도에서 조건부 평균은 단순히 $\exp(x_i^T\beta)$가 아니다. 로그정규분포의 평균은 다음과 같다.

$$
\mathbb{E}(Y_i\mid x_i)=\exp\left(x_i^T\beta+\frac{\sigma^2}{2}\right).
$$

따라서 로그 회귀모형에서 예측비용을 원래 척도로 되돌릴 때는 재변환 보정이 필요하다. 정규성과 등분산성을 가정하면 $\exp(\widehat{\sigma}^2/2)$를 곱한다.

$$
\widehat{C}_a=\frac{1}{n}\sum_{i=1}^n
\exp\left\{x_i(a)^T\widehat{\beta}+\frac{\widehat{\sigma}^2}{2}\right\}.
$$

분포 가정이 불확실하면 Duan의 smearing factor를 사용할 수 있다.

$$
\widehat{s}=\frac{1}{n}\sum_{i=1}^n \exp(\widehat{\varepsilon}_i),
$$

$$
\widehat{C}_a=\frac{1}{n}\sum_{i=1}^n \exp\{x_i(a)^T\widehat{\beta}\}\widehat{s}.
$$

로그 정규 회귀는 극단적인 고비용 관측값을 완화해서 모델링할 수 있지만, 원래 비용척도의 평균 추정이 관심 대상이라면 재변환 단계의 불확실성과 영향점을 반드시 점검해야 한다.

로그척도에서 $x_i^T\beta$는 조건부 로그평균이자 원래 척도에서의 조건부 중앙값의 로그이다.

$$
\operatorname{Median}(Y_i\mid x_i)=\exp(x_i^T\beta).
$$

평균과 중앙값의 차이는 Jensen 부등식에서 발생한다.

$$
\mathbb{E}\{\exp(Z)\}>\exp\{\mathbb{E}(Z)\}
$$

가 $Z$에 변동성이 있을 때 성립한다. 오차분산이 공변량에 따라 달라지면 하나의 전역 smearing factor는 충분하지 않을 수 있다. 일반적인 재변환은 다음과 같다.

$$
\mathbb{E}(Y_i\mid x_i)
=\exp(x_i^T\beta)\mathbb{E}\{\exp(\varepsilon_i)\mid x_i\}.
$$

따라서 이분산성이 있으면 공변량 구간별 smearing factor, 분산모형, 또는 원래 척도의 GLM을 고려해야 한다. 재변환 보정의 추정오차도 부트스트랩 반복 안에서 다시 계산해야 증분비용의 불확실성이 올바르게 반영된다.

::: {.callout-important}
## 비용모형 선택의 핵심 {.unnumbered}

감마 회귀와 로그 정규 회귀는 모두 비용자료에 사용할 수 있지만 목표가 다르다. 경제성 평가의 ICER에는 원래 비용척도의 기대값이 필요하므로, 모형을 로그척도에서 적합하더라도 최종 입력값은 반드시 원래 척도의 평균비용으로 변환해야 한다.
:::

## 포아송 회귀분석 {#sec-poisson-regression}

포아송 회귀분석은 사건 수 또는 자원사용 횟수를 모델링한다. 예를 들어 입원 횟수, 응급실 방문 횟수, 검사 횟수, 이상반응 발생 건수를 분석할 수 있다.

$$
Y_i\mid x_i\sim \operatorname{Poisson}(\mu_i),
$$

$$
\log(\mu_i)=x_i^T\beta.
$$

추적기간이나 노출시간이 환자마다 다르면 offset을 포함한다. $t_i$를 관찰시간, $r_i$를 단위시간당 사건률이라고 하면 다음과 같다.

$$
\mu_i=t_i r_i,
\qquad
\log(\mu_i)=\log(t_i)+x_i^T\beta.
$$

여기서 $\log(t_i)$는 계수가 1로 고정된 offset이다. 치료계수의 지수값은 사건률비로 해석된다.

$$
IRR=\exp(\beta_A).
$$

포아송 모형의 중요한 가정은 평균과 분산이 같다는 것이다.

$$
\mathbb{E}(Y_i\mid x_i)=\operatorname{Var}(Y_i\mid x_i)=\mu_i.
$$

실제 의료이용자료에서는 분산이 평균보다 큰 과산포가 흔하다. 과산포가 있으면 포아송 회귀계수의 점추정은 비교적 안정적일 수 있지만 표준오차가 과소추정되어 불확실성을 작게 보일 수 있다.

포아송 로그가능도는 다음과 같다.

$$
\ell(\beta)=\sum_{i=1}^n
\left[y_i\log(\mu_i)-\mu_i-\log(y_i!)\right].
$$

Offset을 포함한 모형은 관찰시간 동안의 기대 사건 수를 추정한다. 단위시간당 사건률을 경제성 평가의 고정된 주기 길이 $\Delta$에 적용할 때는 사건이 독립적으로 발생한다는 가정 아래 기대 사건 수가 $r_i\Delta$가 된다. 그러나 같은 환자에서 재발사건이 군집되거나 사건 이후 위험이 변하면 단순 포아송 과정은 충분하지 않다. 이 경우 환자 수준 무작위효과, GEE, 재발사건 생존모형 또는 상태전이모형을 고려해야 한다.

## 음이항 회귀분석 {#sec-negative-binomial-regression}

음이항 회귀분석은 계수자료의 과산포를 반영한다. 흔히 사용하는 NB2 모수화에서는 평균과 분산이 다음과 같다.

$$
\mathbb{E}(Y_i\mid x_i)=\mu_i,
$$

$$
\operatorname{Var}(Y_i\mid x_i)=\mu_i+\alpha\mu_i^2,
$$

여기서 $\alpha>0$는 과산포 모수이다. $\alpha=0$이면 포아송 모형에 가까워진다.

로그 연결함수를 사용하면 다음과 같다.

$$
\log(\mu_i)=\log(t_i)+x_i^T\beta.
$$

치료계수의 지수값은 포아송 회귀와 마찬가지로 사건률비로 해석할 수 있다.

$$
IRR=\exp(\beta_A).
$$

음이항분포는 포아송 평균 자체가 환자마다 감마분포를 따른다는 혼합모형에서 유도할 수 있다. 잠재 사건률 $\Lambda_i$에 대해

$$
Y_i\mid\Lambda_i\sim\operatorname{Poisson}(\Lambda_i),
\qquad
\Lambda_i\mid x_i\sim\operatorname{Gamma}\left(\frac{1}{\alpha},\,\alpha\mu_i\right)
$$

라고 하면 주변분포의 평균과 분산은

$$
\mathbb{E}(Y_i\mid x_i)=\mu_i,
\qquad
\operatorname{Var}(Y_i\mid x_i)=\mu_i+\alpha\mu_i^2
$$

가 된다. 이 표현은 과산포가 단순한 측정오차가 아니라 관찰되지 않은 사건성향의 이질성에서 발생할 수 있음을 보여준다.

경제성 평가에서는 입원 횟수, 외래 방문 횟수, 검사 횟수의 예측값에 단가를 곱하여 비용을 산출할 수 있다. 자원사용량 $R_{ik}$의 기대값과 단가 $u_k$가 주어지면 환자 $i$의 기대 자원사용 비용은 다음과 같다.

$$
\mathbb{E}(C_i\mid x_i)=\sum_{k=1}^K u_k\mathbb{E}(R_{ik}\mid x_i).
$$

![포아송 모형은 평균과 분산이 같다고 가정하지만, 실제 자원사용자료에서는 음이항 형태의 과산포가 흔하다.](figures/ch11/fig-ch11-count-overdispersion.png)

위 그림은 평균이 증가함에 따라 음이항모형의 분산이 포아송모형보다 더 빠르게 커지는 모습을 나타낸다. 과산포를 무시하면 평균 예측 자체보다 그 불확실성이 지나치게 작아져 PSA의 비용 분산을 축소할 수 있다.

## 베타 회귀분석 {#sec-beta-regression}

효용값은 보통 0과 1 사이의 값을 가진다. 이러한 제한된 연속형 결과변수에는 베타 회귀분석을 고려할 수 있다. 베타분포는 평균 $\mu_i$와 정밀도 $\phi$를 이용하여 다음과 같이 모수화할 수 있다.

$$
Y_i\mid x_i\sim \operatorname{Beta}(\alpha_i,\beta_i),
$$

$$
\alpha_i=\mu_i\phi,
\qquad
\beta_i=(1-\mu_i)\phi.
$$

이때 조건부 평균과 분산은 다음과 같다.

$$
\mathbb{E}(Y_i\mid x_i)=\mu_i,
$$

$$
\operatorname{Var}(Y_i\mid x_i)=\frac{\mu_i(1-\mu_i)}{1+\phi}.
$$

평균에는 보통 로짓 연결함수를 사용한다.

$$
\operatorname{logit}(\mu_i)=x_i^T\beta.
$$

정밀도 모수도 공변량에 따라 달라질 수 있다.

$$
\log(\phi_i)=z_i^T\gamma.
$$

평균모형만 적합하고 실제 정밀도가 환자 특성에 따라 크게 달라지면 평균계수의 추론과 예측구간이 불안정해질 수 있다. 베타 회귀의 회귀계수는 효용의 직접 차이가 아니라 평균 효용 오즈의 로그변화이므로, 경제성 평가에는 치료전략별 예측 효용을 원래 척도에서 평균해야 한다.

베타 회귀는 예측 효용이 0과 1 사이에 머무른다는 장점이 있다. 그러나 EQ-5D 효용값은 0보다 작을 수 있고, 정확히 1에 많은 관측값이 몰리는 경우도 있다. 이 경우에는 다음 대안이 필요할 수 있다.

- 효용값을 적절한 범위로 재척도화한 후 베타 회귀 적용
- 1의 질량을 따로 모델링하는 one-inflated beta model
- 음의 효용을 허용하는 일반 선형모형 또는 혼합모형
- 효용값과 사망 상태를 결합한 joint model 또는 longitudinal-survival model

정확히 1인 관측값의 질량을 $\pi_i$로 분리하는 one-inflated beta model에서는 전체 평균이 다음과 같다.

$$
\mathbb{E}(Y_i\mid x_i,z_i)
=\pi_i+(1-\pi_i)\mu_i.
$$

이때 $\pi_i$는 완전건강 상태에 있을 확률이고, $\mu_i$는 완전건강이 아닌 사람의 조건부 평균 효용이다. EQ-5D처럼 1에서 큰 질량과 그 아래의 간격이 나타나는 자료에서는 이 두 과정이 임상적으로 다른 메커니즘을 나타낼 수 있다. 단순 재척도화는 지지집합을 맞출 수 있지만 점질량과 음의 효용값의 의미를 제거하지는 못한다.

![베타 회귀는 0과 1 사이의 효용값 분포를 유연하게 표현할 수 있지만, 0 또는 1의 질량이 크면 확장모형이 필요하다.](figures/ch11/fig-ch11-beta-utility.png)

## 영과잉 포아송 회귀분석 {#sec-zero-inflated-poisson-regression}

의료이용자료에서는 0이 매우 많이 관찰된다. 예를 들어 대부분의 환자는 특정 기간 동안 입원하지 않지만, 일부 환자는 반복적으로 입원할 수 있다. 이 경우 단순 포아송 모형은 0의 비율과 양의 횟수 분포를 동시에 설명하기 어려울 수 있다.

영과잉 포아송 모형은 두 과정을 결합한다.

1. 구조적으로 항상 0이 되는 과정
2. 포아송 분포를 따르는 계수 과정

수식으로 쓰면 다음과 같다.

$$
P(Y_i=0\mid x_i,z_i)=\pi_i+(1-\pi_i)\exp(-\mu_i),
$$

$$
P(Y_i=y\mid x_i,z_i)=(1-\pi_i)\frac{\exp(-\mu_i)\mu_i^y}{y!},
\qquad y=1,2,\ldots.
$$

여기서 $\pi_i$는 구조적 0에 속할 확률이고, $\mu_i$는 포아송 계수 과정의 평균이다. 보통 다음과 같이 두 개의 회귀식을 사용한다.

$$
\operatorname{logit}(\pi_i)=z_i^T\gamma,
\qquad
\log(\mu_i)=x_i^T\beta.
$$

전체 조건부 평균은 다음과 같다.

$$
\mathbb{E}(Y_i\mid x_i,z_i)=(1-\pi_i)\mu_i.
$$

전체 분산은 다음과 같다.

$$
\operatorname{Var}(Y_i\mid x_i,z_i)
=(1-\pi_i)\mu_i\{1+\pi_i\mu_i\}.
$$

따라서 영과잉 과정 자체가 추가 과산포를 만든다. 영과잉모형과 hurdle 모형은 0의 생성기전을 다르게 가정한다. Hurdle 모형에서는 0과 양의 값이 완전히 분리되고, 양의 값은 0에서 절단된 계수분포를 따른다.

$$
P(Y_i=0)=\pi_i,
\qquad
P(Y_i=y\mid Y_i>0)=
\frac{f_{\text{count}}(y;\mu_i)}{1-f_{\text{count}}(0;\mu_i)}.
$$

영과잉모형은 계수 과정에서도 우연한 0이 발생할 수 있지만, hurdle 모형의 양의 계수 과정에서는 0이 불가능하다. 구조적 0이라는 잠재집단이 임상적으로 구분되지 않으면 두 성분의 식별이 약해질 수 있으므로, 단순히 0의 비율만으로 모형을 선택해서는 안 된다.

경제성 평가에 입력할 자원사용량은 계수 과정의 평균 $\mu_i$가 아니라 전체 평균 $(1-\pi_i)\mu_i$이다. 구조적 0의 의미가 임상적으로 타당한지 확인하는 것도 중요하다. 단순히 0이 많다는 이유만으로 zero-inflated model을 사용하는 것은 적절하지 않을 수 있다.

![영과잉 모형은 구조적 0과 계수 과정을 분리하여 0이 많은 자료를 설명한다.](figures/ch11/fig-ch11-zero-inflated-count.png)

위 그림은 관찰된 0이 단일한 원인에서 나온다고 가정하지 않는다. 다만 두 잠재과정의 구분은 통계적 적합도뿐 아니라 임상적으로 ‘발생 가능성이 없는 환자’가 실제로 존재하는지에 의해 뒷받침되어야 한다.

## 순서형 로지스틱 회귀분석 {#sec-ordinal-logistic-regression}

순서형 로지스틱 회귀분석은 결과변수가 자연스러운 순서를 가지는 범주형 자료일 때 사용한다. 예를 들어 치료반응을 악화, 불변, 부분반응, 완전반응으로 구분하거나, 통증을 없음, 경도, 중등도, 중증으로 구분하는 경우가 있다.

누적 로짓 모형은 다음과 같이 표현한다.

$$
\operatorname{logit}\{P(Y_i\le k\mid x_i)\}=\alpha_k-x_i^T\beta,
\qquad k=1,\ldots,K-1.
$$

여기서 $\alpha_k$는 절단점이고, $\beta$는 모든 누적 로짓에 공통으로 적용되는 회귀계수이다. 이 공통성은 **비례오즈 가정**이라고 부른다.

잠재 연속변수 $Y_i^*$를 이용하면 누적 로짓 모형을 다음과 같이 이해할 수 있다.

$$
Y_i^*=x_i^T\beta+\varepsilon_i,
\qquad
Y_i=k\quad\text{if}\quad \alpha_{k-1}<Y_i^*\le\alpha_k,
$$

여기서 $\varepsilon_i$는 로지스틱분포를 따른다. 비례오즈 가정은 공변량이 잠재반응의 위치를 이동시키지만 절단점마다 효과의 크기는 같다는 뜻이다. 이 가정이 성립하지 않으면 일부 계수만 절단점별로 다르게 허용하는 부분 비례오즈모형을 고려할 수 있다.

누적오즈비 $\exp(\beta_j)$는 특정 범주 하나의 오즈비가 아니라, 어느 절단점을 사용하더라도 ‘더 높은 범주’에 속할 상대오즈가 동일하다는 의미이다. 경제성 평가에서는 이 조건부 오즈비보다 각 범주의 표준화 확률이 비용과 효용을 계산하는 데 직접적으로 필요하다.

범주별 확률은 누적확률의 차이로 계산한다.

$$
P(Y_i=1\mid x_i)=P(Y_i\le 1\mid x_i),
$$

$$
P(Y_i=k\mid x_i)=P(Y_i\le k\mid x_i)-P(Y_i\le k-1\mid x_i),
\qquad k=2,\ldots,K-1,
$$

$$
P(Y_i=K\mid x_i)=1-P(Y_i\le K-1\mid x_i).
$$

경제성 평가에서는 각 반응 범주에 비용 또는 효용을 부여할 수 있다. 범주 $k$의 효용을 $u_k$라고 하면 기대 효용은 다음과 같다.

$$
\mathbb{E}(U_i\mid x_i)=\sum_{k=1}^K u_k P(Y_i=k\mid x_i).
$$

![순서형 로지스틱 회귀는 각 범주의 예측확률을 제공하며, 이를 효용 또는 비용 가중평균으로 변환할 수 있다.](figures/ch11/fig-ch11-ordinal-logit.png)

위 그림은 치료효과를 하나의 공통 오즈비로 요약하더라도 경제성 평가의 기대 효용은 범주별 확률 전체와 각 범주에 부여한 효용값에 의해 결정된다는 점을 보여준다.

## 혼합모형 {#sec-mixed-models}

혼합모형은 고정효과와 무작위효과를 함께 포함하는 모형이다. 반복측정 효용자료, 다기관 임상시험, 국가별 자료, 환자군집 자료에서 자주 사용된다.

연속형 반복측정 결과 $Y_{ij}$를 환자 $i$의 시점 $j$ 결과라고 하자. 선형 혼합모형은 다음과 같이 쓸 수 있다.

$$
Y_{ij}=x_{ij}^T\beta+z_{ij}^T b_i+\varepsilon_{ij},
$$

$$
b_i\sim N(0,D),
\qquad
\varepsilon_i\sim N(0,R_i).
$$

같은 환자에서 두 시점 $j$와 $k$의 공분산은 다음과 같다.

$$
\operatorname{Cov}(Y_{ij},Y_{ik}\mid X_i)
=z_{ij}^TDz_{ik}+R_i[j,k].
$$

무작위 절편만 있고 잔차가 독립이면 환자 내 상관계수는 다음과 같다.

$$
ICC=\frac{\sigma_b^2}{\sigma_b^2+\sigma_\varepsilon^2}.
$$

ICC는 전체 변동 중 환자 간 차이가 차지하는 비율을 나타낸다. 반복측정 횟수가 많아도 ICC가 크면 독립 관측값과 같은 정보량을 제공하지 않으므로, 환자 수가 추론의 핵심 단위가 된다.

여기서 $b_i$는 환자별 무작위효과이며, 같은 환자 내 반복측정값 사이의 상관성을 유도한다. 단순한 무작위 절편모형은 다음과 같다.

$$
Y_{ij}=\beta_0+\beta_A A_i+\beta_t t_{ij}+\beta_{At}A_i t_{ij}+b_i+\varepsilon_{ij}.
$$

이 모형에서 시간 $t$의 치료군별 평균 효용은 다음과 같다.

$$
\mathbb{E}(Y_{ij}\mid A_i=a,t_{ij}=t)=\beta_0+\beta_A a+\beta_t t+\beta_{At}at.
$$

추적기간 $[0,\tau]$의 기대 QALY는 효용곡선을 적분하여 얻는다.

$$
Q_a(\tau)=\int_0^\tau \mathbb{E}\{U_a(t)\}dt.
$$

사망이 발생할 수 있는 자료에서는 살아 있는 환자의 평균 효용과 생존확률을 분리하여 다음처럼 표현하는 것이 더 명확하다.

$$
Q_a(\tau)
=\int_0^\tau
S_a(t)\,
\mathbb{E}\{U_a(t)\mid T_a>t\}\,dt.
$$

효용 관찰이 사망 전 환자에게만 가능하므로, 단순한 혼합모형이 추정하는 값은 흔히 생존자 조건부 평균이다. 사망과 탈락이 효용궤적과 관련되면 누락이 무작위라는 가정이 성립하지 않을 수 있다. 이 경우 longitudinal–survival joint model, pattern-mixture model, 또는 민감도 분석을 통해 정보성 탈락의 영향을 평가해야 한다.

무작위효과가 포함된 비선형 모형에서는 조건부 평균과 주변 평균이 다를 수 있다. 예를 들어 로지스틱 혼합모형에서 다음 두 값은 일반적으로 같지 않다.

$$
\mathbb{E}_b\left[\operatorname{logit}^{-1}(x^T\beta+z^Tb)\right]
\ne
\operatorname{logit}^{-1}(x^T\beta).
$$

따라서 경제성 평가 입력값이 환자특이적 예측인지, 목표 인구집단의 주변 평균인지 명확히 해야 한다.

![반복측정 효용자료는 같은 환자 안에서 상관되어 있으므로 혼합모형이나 GEE가 필요할 수 있다.](figures/ch11/fig-ch11-longitudinal-models.png)

위 그림에서 환자별 곡선이 공통 평균 주변에서 서로 다른 수준과 기울기를 갖는 현상은 무작위효과로 표현된다. 경제성 평가에서 필요한 평균 효용곡선은 환자별 조건부 곡선을 단순히 한 환자에게 적용하는 것이 아니라 목표 모집단의 무작위효과 분포에 대해 평균한 값이어야 한다.

## 일반화 추정 방정식 {#sec-gee}

일반화 추정 방정식은 반복측정 또는 군집자료에서 **주변 평균**을 직접 모델링한다. 환자 $i$의 반복측정 벡터를 $Y_i=(Y_{i1},\ldots,Y_{im_i})^T$라고 하자. 평균벡터는 다음과 같다.

$$
\mu_i=\mathbb{E}(Y_i\mid X_i).
$$

GEE는 다음 추정방정식을 푼다.

$$
\sum_{i=1}^n D_i^T V_i^{-1}(Y_i-\mu_i)=0,
$$

여기서 $D_i=\partial \mu_i/\partial\beta^T$이고, $V_i$는 working covariance matrix이다. $V_i$는 다음과 같이 분해할 수 있다.

$$
V_i=A_i^{1/2}R(\alpha)A_i^{1/2},
$$

여기서 $A_i$는 분산함수로 만든 대각행렬, $R(\alpha)$는 working correlation matrix이다. Working correlation이 정확하지 않아도 평균모형이 올바르게 지정되어 있으면 sandwich variance를 이용해 일관된 표준오차를 얻을 수 있다.

GEE의 sandwich variance는 개념적으로 다음 형태를 가진다.

$$
\widehat{\operatorname{Var}}(\widehat{\beta})=B^{-1}MB^{-1},
$$

$$
B=\sum_{i=1}^n D_i^T V_i^{-1}D_i,
\qquad
M=\sum_{i=1}^n D_i^T V_i^{-1}(Y_i-\mu_i)(Y_i-\mu_i)^TV_i^{-1}D_i.
$$

경제성 평가에서 GEE는 반복측정 효용값의 평균 경향을 추정하거나, 군집화된 의료이용 자료의 주변 평균을 추정할 때 유용하다.

GEE의 점근이론은 관측치 수보다 독립적인 군집 수가 증가한다는 조건에 의존한다. 기관 수나 환자 수가 적은 경우 sandwich 표준오차가 하향편향될 수 있으므로 작은 표본 보정이나 군집수준 부트스트랩이 필요하다. 또한 표준 GEE는 누락이 군집 내 관찰결과와 공변량을 조건으로 완전무작위라는 조건에서 가장 단순하게 정당화된다. 누락이 관찰된 과거 결과에 의존하는 경우에는 inverse probability weighted GEE를 사용할 수 있다.

Working correlation을 독립, 교환가능, AR(1), 비구조형 중에서 선택하더라도 평균모형이 올바르면 회귀계수의 일관성은 유지될 수 있다. 그러나 효율성과 작은 표본 성능은 달라진다. 경제성 평가의 최종 목적이 시간별 평균 효용과 누적 QALY라면 시간함수와 치료–시간 상호작용의 지정이 working correlation 선택보다 더 중요하다.

![혼합모형은 환자특이적 평균을, GEE는 인구집단 평균을 주된 estimand로 삼는 경우가 많다.](figures/ch11/fig-ch11-gee-vs-mixed.png)

위 그림은 혼합모형과 GEE가 동일한 자료를 사용하더라도 서로 다른 평균을 목표로 할 수 있음을 나타낸다. 특히 비선형 연결함수에서는 환자특이적 계수를 주변 효과로 직접 해석할 수 없다.

## 혼합모형과 GEE의 선택 {.unnumbered}

경제성 평가에서 최종적으로 필요한 값이 목표 인구집단의 평균 비용이나 평균 QALY라면 GEE의 주변 평균 해석이 직관적일 수 있다. 반면 환자별 이질성, 장기 예측, 무작위효과 분산, 기관 간 차이를 모델링해야 한다면 혼합모형이 더 적절할 수 있다.

## 비용과 QALY의 공동 회귀모형

비용과 QALY는 같은 환자에게서 함께 관찰되며 일반적으로 상관되어 있다. 두 결과를 각각 선형 평균모형으로 표현하면 다음과 같다.

$$
C_i=x_{Ci}^T\beta_C+\varepsilon_{Ci},
\qquad
Q_i=x_{Qi}^T\beta_Q+\varepsilon_{Qi},
$$

$$
\begin{pmatrix}
\varepsilon_{Ci}\\
\varepsilon_{Qi}
\end{pmatrix}
\sim
\left(
\begin{pmatrix}0\\0\end{pmatrix},
\begin{pmatrix}
\sigma_C^2 & \sigma_{CQ}\\
\sigma_{CQ} & \sigma_Q^2
\end{pmatrix}
\right).
$$

이 구조는 seemingly unrelated regression의 기본 형태이다. 두 식의 설명변수가 동일하면 각 회귀계수의 점추정은 별도 최소제곱과 같을 수 있지만, $\sigma_{CQ}$를 추정하면 증분비용과 증분 QALY의 공분산을 직접 얻을 수 있다. 설명변수가 다르면 공동추정이 효율성을 높일 수 있다.

비용이 감마분포를 따르고 QALY가 정규분포 또는 베타분포를 따르는 경우에는 단순 이변량 정규모형이 적합하지 않을 수 있다. 이때 공유 무작위효과, copula, 베이지안 다변량모형을 이용하여 서로 다른 주변분포와 결과 간 의존성을 결합할 수 있다.

지불의사금액 $\lambda$가 고정되면 환자 수준 순편익을 직접 회귀분석할 수도 있다.

$$
NB_i(\lambda)=\lambda Q_i-C_i,
$$

$$
NB_i(\lambda)=\alpha_0+\alpha_AA_i+\alpha_X^TX_i+e_i.
$$

선형 평균모형이 올바르면 치료계수 $\alpha_A$는 공변량을 보정한 증분순편익이다. 이 방법은 비용과 QALY의 공분산을 순편익의 분산에 자동으로 반영하지만, $\lambda$가 바뀔 때마다 결과변수와 회귀모형의 해석이 달라진다. 따라서 전략별 비용과 QALY를 별도로 보고하면서 순편익 회귀를 보조적으로 사용하는 것이 좋다.

## 회귀모형의 진단과 의사결정 관련 적합도

회귀모형의 적합도는 계수의 유의성만으로 평가할 수 없다. 경제성 평가에서는 다음 세 수준을 구분해야 한다.

첫째, **평균모형의 적합성**이다. 선형성, 상호작용, 시간함수와 연결함수가 목표 인구집단의 평균을 적절히 설명해야 한다. 둘째, **분산 및 상관구조의 적합성**이다. 이는 신뢰구간, 부트스트랩, PSA 분포에 영향을 준다. 셋째, **의사결정 척도의 적합성**이다. 원래 척도의 평균 비용, QALY, INB를 얼마나 잘 예측하는지가 중요하다.

예측오차를 $L(Y,\widehat{Y})$라고 하면 교차검증 위험은 다음과 같이 표현할 수 있다.

$$
\widehat{R}_{CV}
=\frac{1}{K}\sum_{k=1}^K
\frac{1}{|I_k|}\sum_{i\in I_k}
L\{Y_i,\widehat{m}^{(-k)}(X_i)\}.
$$

비용분석에서는 로그척도의 제곱오차가 작더라도 원래 척도의 평균비용 편향이 클 수 있다. 따라서 모형 비교는 관심 estimand와 동일한 척도에서 수행해야 한다. AIC나 deviance는 유용한 진단이지만, 장기 모형 입력값이나 증분순편익의 안정성을 대신하지 않는다.

## 회귀모형 결과를 경제성 평가 입력값으로 변환하기 {#sec-regression-to-economic-evaluation}

회귀분석 결과를 경제성 평가에 사용하려면 회귀계수를 그대로 가져오는 것이 아니라, 비용과 QALY의 전략별 평균을 계산해야 한다. 일반적인 절차는 다음과 같다.

1. 목표 인구집단을 정의한다.
2. 목표 인구집단의 공변량 분포 $F^*(x)$를 정한다.
3. 각 치료전략 $a$에 대해 예측값 $\widehat{m}_C(a,x_i)$와 $\widehat{m}_Q(a,x_i)$를 계산한다.
4. 예측값을 평균하여 $\widehat{C}_a$와 $\widehat{Q}_a$를 얻는다.
5. $\widehat{\Delta C}$, $\widehat{\Delta Q}$, $\widehat{ICER}$, $\widehat{INB}(\lambda)$를 계산한다.
6. 모형 불확실성과 표본 불확실성을 부트스트랩, delta method, 또는 PSA로 반영한다.

수식으로 쓰면 다음과 같다.

$$
\widehat{C}_a=\frac{1}{n}\sum_{i=1}^n \widehat{m}_C(a,x_i),
\qquad
\widehat{Q}_a=\frac{1}{n}\sum_{i=1}^n \widehat{m}_Q(a,x_i).
$$

$$
\widehat{\Delta C}=\widehat{C}_1-\widehat{C}_0,
\qquad
\widehat{\Delta Q}=\widehat{Q}_1-\widehat{Q}_0.
$$

$$
\widehat{INB}(\lambda)=\lambda\widehat{\Delta Q}-\widehat{\Delta C}.
$$

회귀모형에서 비용과 QALY를 따로 적합하면 두 추정값의 상관성이 무시될 수 있다. 환자 수준 자료에서 비용과 QALY가 함께 관찰되었다면 비모수 부트스트랩은 이 상관성을 자연스럽게 보존한다. 부트스트랩 반복 $b=1,\ldots,B$에 대해 다음 값을 계산한다.

$$
\widehat{\Delta C}^{(b)},
\qquad
\widehat{\Delta Q}^{(b)},
\qquad
\widehat{INB}^{(b)}(\lambda)=\lambda\widehat{\Delta Q}^{(b)}-\widehat{\Delta C}^{(b)}.
$$

비용효과수용확률은 다음과 같이 추정한다.

$$
\widehat{P}\{INB(\lambda)>0\}=\frac{1}{B}\sum_{b=1}^B I\{\widehat{INB}^{(b)}(\lambda)>0\}.
$$

### 델타방법을 이용한 표준화 평균의 분산

비선형 모형의 표준화 평균을 $h_a(\widehat{\beta})$라고 쓰면 델타방법에 따라 다음 근사가 성립한다.

$$
\operatorname{Var}\{h_a(\widehat{\beta})\}
\approx
G_a^T\operatorname{Var}(\widehat{\beta})G_a,
$$

$$
G_a=\left.\frac{\partial h_a(\beta)}{\partial\beta}\right|_{\widehat{\beta}}.
$$

두 전략의 차이에서는 $G_1-G_0$가 기울기가 된다. 비용모형과 QALY모형을 별도로 적합하면 두 모형의 계수 공분산까지 필요하므로 분석적 계산이 복잡해진다. 같은 환자를 재표집하는 비모수 부트스트랩은 비용과 QALY, 공변량, 사건의 경험적 결합분포를 함께 보존한다.

군집무작위시험이나 반복측정자료에서는 관측행이 아니라 독립적인 군집이나 환자를 재표집해야 한다. 층화무작위배정을 사용했다면 부트스트랩에서도 치료군 또는 층화변수 구조를 보존하는 것이 바람직하다. 모형 선택이나 재변환 보정까지 자료의 영향을 받는다면 그 절차도 각 반복 안에서 다시 수행해야 한다.

### 결측자료와 표준화

회귀분석에 완전사례만 사용하면 결측이 결과 및 비용과 관련된 경우 목표 인구집단의 평균을 왜곡할 수 있다. 다중대치에서는 $M$개의 완성자료에서 전략별 평균을 각각 계산한 뒤 통합한다.

$$
\overline{\mu}_a=\frac{1}{M}\sum_{m=1}^M\widehat{\mu}_a^{(m)}.
$$

대치 간 분산을 $B_M$, 대치 내 분산의 평균을 $\overline{U}$라고 하면 Rubin의 전체분산은 다음과 같다.

$$
T=\overline{U}+\left(1+\frac{1}{M}\right)B_M.
$$

비용과 QALY를 함께 대치할 때는 두 결과의 상관성과 치료군, 기저 효용, 생존상태, 자원사용량을 대치모형에 포함해야 한다. 사망 후 효용은 일반적인 누락값이 아니라 정의상 0인 상태일 수 있으므로, 결측기전과 구조적 0을 구분해야 한다.

비선형 회귀모형의 치료계수만을 이용해 증분비용 또는 증분효과를 계산하면 목표 인구집단의 평균 차이를 잘못 추정할 수 있다. 경제성 평가에서는 항상 치료전략별 예측값을 원래 척도로 변환한 뒤, 목표 인구집단 공변량 분포에서 평균을 내야 한다.

qaly <- pmin(pmax(qaly, 0.02), 0.99)

cost_mean <- exp(9.45 + 0.26 * trt + 0.48 * severity +

cost <- rgamma(n, shape = 2.5, scale = cost_mean / 2.5)

exposure <- runif(n, min = 0.5, max = 1.5)
hosp_mu <- exposure * exp(-0.85 + 0.14 * trt + 0.55 * severity +
                            0.010 * (age - 60))
hosp <- rnbinom(n, size = 1.25, mu = hosp_mu)

latent_response <- -0.55 + 0.55 * trt - 0.75 * severity + rlogis(n)
response <- cut(
  latent_response,
  breaks = c(-Inf, -1.0, 0.4, 1.4, Inf),
  labels = c("worse", "stable", "partial", "complete"),
  ordered_result = TRUE
)

dat <- data.frame(
  trt, age, female, baseline_util, severity,
  ae, qaly, cost, exposure, hosp, response
)

head(dat)
summary(dat[, c("qaly", "cost", "ae", "hosp")])

### 베타 회귀의 직접 최대가능도 예시 {.unnumbered}

```{r}
#| label: code-ch11-beta-regression
utility <- pmin(pmax(dat$qaly, 1e-4), 1 - 1e-4)
X_beta <- model.matrix(~ trt + age + severity + baseline_util, data = dat)

negloglik_beta <- function(par, X, y) {
  beta <- par[seq_len(ncol(X))]
  phi <- exp(par[ncol(X) + 1])
  mu <- plogis(drop(X %*% beta))
  alpha <- mu * phi
  beta_par <- (1 - mu) * phi
  -sum(dbeta(y, shape1 = alpha, shape2 = beta_par, log = TRUE))
}

start <- c(qlogis(mean(utility)), rep(0, ncol(X_beta) - 1), log(20))
opt_beta <- optim(
  par = start,
  fn = negloglik_beta,
  X = X_beta,
  y = utility,
  method = "BFGS",
  control = list(maxit = 500)
)

beta_hat <- opt_beta$par[seq_len(ncol(X_beta))]
phi_hat <- exp(opt_beta$par[ncol(X_beta) + 1])

X1 <- model.matrix(~ trt + age + severity + baseline_util, data = transform(dat, trt = 1))
X0 <- model.matrix(~ trt + age + severity + baseline_util, data = transform(dat, trt = 0))

u1 <- mean(plogis(drop(X1 %*% beta_hat)))
u0 <- mean(plogis(drop(X0 %*% beta_hat)))

round(c(mean_utility_new = u1, mean_utility_comparator = u0,
        delta_utility = u1 - u0, precision_phi = phi_hat,
        convergence_code = opt_beta$convergence), 4)
```

### 반복측정 자료와 군집강건 표준오차 {.unnumbered}

set.seed(20260709)

longdat <- data.frame(
  id = id,
  time = time,
  trt = rep(trt_id, each = 5),
  severity = rep(sev_id, each = 5),
  b = rep(random_intercept, each = 5)

longdat$utility <- 0.73 + 0.04 * longdat$trt - 0.10 * longdat$time +
  0.05 * longdat$trt * longdat$time - 0.12 * longdat$severity +
  longdat$b + rnorm(nrow(longdat), mean = 0, sd = 0.04)
longdat$utility <- pmin(pmax(longdat$utility, 0.02), 0.99)

fit_long <- lm(utility ~ trt * time + severity, data = longdat)

X <- model.matrix(fit_long)
u <- residuals(fit_long)
ids <- unique(longdat$id)
p <- ncol(X)
meat <- matrix(0, nrow = p, ncol = p)

for (g in ids) {
  idx <- which(longdat$id == g)
  Xg <- X[idx, , drop = FALSE]
  ug <- matrix(u[idx], ncol = 1)
  meat <- meat + t(Xg) %*% ug %*% t(ug) %*% Xg
}

bread <- solve(crossprod(X))
V_cluster <- bread %*% meat %*% bread
se_cluster <- sqrt(diag(V_cluster))

round(cbind(
  estimate = coef(fit_long),
  naive_se = coef(summary(fit_long))[, "Std. Error"],
  cluster_robust_se = se_cluster
), 4)

estimate_regression_ee <- function(d) {
  fit_c <- glm(
    cost ~ trt + age + female + severity + ae,
    family = Gamma(link = "log"),
    data = d
  )
  fit_q <- lm(qaly ~ trt + baseline_util + age + female + severity, data = d)
  nd1 <- transform(d, trt = 1)
  nd0 <- transform(d, trt = 0)
  c1 <- mean(predict(fit_c, newdata = nd1, type = "response"))
  c0 <- mean(predict(fit_c, newdata = nd0, type = "response"))
  q1 <- mean(predict(fit_q, newdata = nd1))
  q0 <- mean(predict(fit_q, newdata = nd0))
  c(C_new = c1, C_comparator = c0, Q_new = q1, Q_comparator = q0,
    Delta_C = c1 - c0, Delta_Q = q1 - q0)
}
