3.1 서론

의약품 경제성 평가는 크게 임상시험 기반 경제성 평가와 모형 기반 경제성 평가로 나눌 수 있다. 임상시험 기반 경제성 평가는 임상시험에서 관찰된 개별 환자 자료를 이용하여 비용과 효과를 직접 추정하는 접근이다. 반면 모형 기반 경제성 평가는 임상시험, 관찰연구, 문헌자료, 역학자료, 전문가 의견 등을 결합하여 장기적인 비용과 효과를 추정한다.

임상시험 기반 경제성 평가는 다음 질문에서 출발한다.

임상시험에서 관찰된 환자집단을 기준으로 할 때, 신약은 기존 치료에 비해 비용을 얼마나 증가시키며 QALY를 얼마나 향상시키는가?

치료전략을 \(z \in \{0,1\}\)로 표시하자. 여기서 \(z=1\)은 신약, \(z=0\)은 기존 치료를 의미한다. 분석 기간을 \(\tau\)라고 할 때, 환자 한 명의 총 비용을 \(C(z;\tau)\), 총 QALY를 \(Q(z;\tau)\)라고 하자. 임상시험 기반 비용효용분석의 가장 기본적인 관심 모수는 다음의 네 기대값이다.

\[ \mu_{C,z}(\tau)=\mathbb{E}\{C(z;\tau)\}, \]

\[ \mu_{Q,z}(\tau)=\mathbb{E}\{Q(z;\tau)\}. \]

두 치료전략의 증분비용과 증분효과는 다음과 같다.

\[ \Delta C(\tau)=\mu_{C,1}(\tau)-\mu_{C,0}(\tau), \]

\[ \Delta Q(\tau)=\mu_{Q,1}(\tau)-\mu_{Q,0}(\tau). \]

이때 비용효용분석에서 ICER는 다음과 같이 정의된다.

\[ ICER(\tau)=\frac{\Delta C(\tau)}{\Delta Q(\tau)}, \qquad \Delta Q(\tau)\neq 0. \]

효과지표가 QALY가 아니라 생존연수, 반응건수, 재발 방지 건수와 같은 자연 단위라면 \(Q\) 대신 일반 건강효과 \(H\)를 사용하면 된다. 이 장에서는 의약품 경제성 평가에서 가장 자주 사용되는 비용효용분석을 중심으로 설명하므로 효과지표를 \(Q\)로 표기한다.

Note핵심 메시지

임상시험 기반 경제성 평가는 임상시험에 참여한 환자들로부터 관찰된 비용과 QALY 자료를 이용하여 \(\Delta C\), \(\Delta Q\), \(ICER\), \(INB\)를 추정한다. 그러나 최종 의사결정은 통계적 유의성만이 아니라 지불의사금액과 의사결정 불확실성을 함께 고려한다.

3.1.1 확증적 임상시험 분석과 경제성 평가 분석의 질문 차이

확증적 임상시험에서는 사전에 정의된 주요 평가변수에 대해 통계적 가설검정을 수행한다. 예를 들어 전체생존기간을 주요 평가변수로 하는 임상시험에서는 다음과 같은 귀무가설을 검정할 수 있다.

\[ H_0: HR=1, \]

여기서 \(HR\)은 위험비이다. 이 분석의 주요 관심은 치료군 간 생존 차이가 통계적으로 유의한지 여부이다.

반면 경제성 평가는 다음과 같은 의사결정 질문에 관심을 둔다.

\[ \lambda \Delta Q-\Delta C>0 \; ? \]

여기서 \(\lambda\)는 QALY 1단위 증가에 대해 의사결정자가 지불할 의사가 있는 최대 금액이다. 위 식은 신약으로 얻는 추가 QALY를 화폐가치로 환산한 값이 추가 비용보다 큰지를 묻는다.

위 그림은 동일한 임상시험 자료가 서로 다른 추론 목표에 사용되는 과정을 보여준다. 임상시험의 가설검정은 치료효과의 존재 여부에 초점을 두지만, 경제성 평가는 비용과 효과의 크기를 동일한 의사결정 척도에 놓는다. 따라서 임상적으로 유의한 치료가 반드시 비용효과적인 것은 아니며, 통계적으로 유의하지 않은 치료도 추정된 효과와 비용의 불확실성을 함께 고려하면 의사결정 대상이 될 수 있다.

3.1.2 임상시험 기반 경제성 평가의 estimand

임상시험 기반 경제성 평가에서 특히 중요한 점은 “어떤 인구집단에서의 비용과 효과를 추정하는가?”이다. 무작위배정 임상시험의 원자료를 그대로 사용한다면 추정 대상은 기본적으로 임상시험 대상 인구집단에서의 평균 비용과 평균 QALY이다. 이를 potential outcome 표기로 명확히 나타낼 수 있다.

환자 \(i\)가 신약을 받았을 때의 비용과 QALY를 각각 \(C_i(1)\), \(Q_i(1)\)이라고 하고, 기존 치료를 받았을 때의 비용과 QALY를 각각 \(C_i(0)\), \(Q_i(0)\)이라고 하자. 같은 환자에게 두 치료전략을 동시에 적용할 수 없으므로 실제로는 다음 값만 관찰된다.

\[ C_i=Z_iC_i(1)+(1-Z_i)C_i(0), \]

\[ Q_i=Z_iQ_i(1)+(1-Z_i)Q_i(0), \]

여기서 \(Z_i=1\)이면 신약군, \(Z_i=0\)이면 대조군이다. 무작위배정이 적절하게 이루어졌다면 다음의 교환가능성이 성립한다.

\[ Z_i \perp \{C_i(1),C_i(0),Q_i(1),Q_i(0)\}. \]

따라서 임상시험 대상 인구집단에서 다음 식이 성립한다.

\[ \mathbb{E}\{C(1)\}=\mathbb{E}(C\mid Z=1), \qquad \mathbb{E}\{C(0)\}=\mathbb{E}(C\mid Z=0), \]

\[ \mathbb{E}\{Q(1)\}=\mathbb{E}(Q\mid Z=1), \qquad \mathbb{E}\{Q(0)\}=\mathbb{E}(Q\mid Z=0). \]

이 식은 단순한 평균 차이가 무작위배정 임상시험에서 인과적 해석을 가질 수 있는 이유를 보여준다. 그러나 임상시험 대상 인구집단과 실제 급여 대상 인구집단이 다르면, 위 estimand는 정책 결정에 필요한 목표 모집단 estimand와 다를 수 있다. 이 문제는 이후 회귀분석, 표준화, MAIC, 실제사용자료 활용에서 다시 등장한다.

3.1.2.1 경제성 평가 estimand의 구성요소

임상시험의 경제성 평가 estimand는 단순히 “신약과 대조군의 평균 차이”라고만 정의해서는 충분하지 않다. 적어도 다음 요소가 명확해야 한다.

  • 대상 인구집단: 임상시험에 무작위배정된 전체 환자인가, 실제 치료를 받은 환자인가, 특정 하위집단인가?
  • 치료전략: 배정된 치료를 기준으로 하는가, 실제 투여된 치료를 기준으로 하는가?
  • 결과변수: 총 비용, 총 QALY, 순편익 가운데 무엇을 분석하는가?
  • 분석 기간: 임상시험 종료 시점까지인가, 사망까지인가, 생애기간인가?
  • 중간사건 처리: 치료중단, 구조요법, 치료교차, 순응도 저하, 사망을 어떻게 반영하는가?
  • 집단 요약치: 평균 차이, 비율, 특정 분위수 차이 중 무엇을 사용할 것인가?

경제성 평가에서는 일반적으로 무작위배정된 치료전략의 정책적 효과를 평가하는 treatment-policy estimand가 자연스럽다. 이 경우 치료중단이나 구조요법 사용이 발생하더라도 환자를 최초 배정군에 따라 분석한다. 이는 임상시험의 intention-to-treat 원칙과 연결된다. 반면 실제 치료를 지속해서 받은 경우의 경제성을 평가하려면 순응도와 치료교차를 고려한 별도의 인과추론 가정이 필요하다.

치료전략 \(z\)에 대한 비용과 QALY를 벡터로 묶으면 경제성 평가 estimand는 다음과 같이 쓸 수 있다.

\[ \boldsymbol\mu_z(\tau) = \begin{pmatrix} \mu_{C,z}(\tau)\\ \mu_{Q,z}(\tau) \end{pmatrix}. \]

두 전략의 증분 estimand는

\[ \boldsymbol\delta(\tau) = \boldsymbol\mu_1(\tau)-\boldsymbol\mu_0(\tau) = \begin{pmatrix} \Delta C(\tau)\\ \Delta Q(\tau) \end{pmatrix} \]

이다. 경제성 평가의 통계분석은 결국 이 이차원 벡터와 그 불확실성을 추정하는 문제이다. ICER와 증분순편익은 이 벡터를 서로 다른 방식으로 요약한 값이다.

3.1.2.2 분석대상군과 경제성 평가의 해석

무작위배정된 모든 환자를 최초 배정군에 따라 분석하는 경우, 결과는 치료전략을 실제 정책으로 도입했을 때 기대되는 평균 비용과 평균 QALY의 차이에 가깝다. 반면 임상시험계획서를 준수한 환자만 분석하면 치료 자체의 생물학적 효능에 가까운 질문을 다룰 수 있지만, 무작위배정의 균형이 깨질 수 있다.

특히 비용은 치료중단과 구조요법에 민감하다. 치료중단 이후 발생한 비용을 제외하면 신약 전략의 실제 비용을 과소평가할 수 있고, 구조요법 비용을 포함하면서 구조요법의 건강효과는 제외하면 비용과 효과의 범위가 일치하지 않게 된다. 따라서 비용과 QALY는 같은 치료전략, 같은 분석 기간, 같은 중간사건 처리 규칙을 사용하여 정의해야 한다.

3.1.3 임상시험에서 수집되는 경제성 평가 자료

임상시험 기반 경제성 평가에서는 임상적 평가변수뿐 아니라 경제성 평가에 필요한 자료를 계획적으로 수집해야 한다. 대표적인 자료는 다음과 같다.

자료 유형 예 경제성 평가에서의 역할
자원사용량 약제 투여량, 외래 방문, 입원, 검사, 처치 비용 산출의 기초
단가 자료 약가, 수가, 입원 일당 비용, 검사비 자원사용량을 화폐단위 비용으로 변환
건강관련 삶의 질 EQ-5D, EORTC QLQ-C30, FACT 계열 QALY 계산의 기초
임상결과 생존, 진행, 반응, 이상반응 효과와 비용 발생 구조 설명
추적기간 정보 관찰기간, 탈락, 사망, 연구 종료 누적 비용과 QALY의 관찰 가능성 판단

환자 \(i\)의 분석기간 \(\tau\) 동안 총 비용은 자원사용량과 단가의 곱으로 표현할 수 있다. 자원 항목을 \(m=1,\ldots,M\)이라고 하고, 환자 \(i\)가 사용한 자원량을 \(R_{im}\), 단가를 \(u_m\)이라고 하면 다음과 같다.

\[ C_i(\tau)=\sum_{m=1}^{M}u_mR_{im}(\tau). \]

QALY는 시간에 따른 효용가중치와 생존상태를 누적하여 계산한다. 환자 \(i\)의 시간 \(t\)에서 효용값을 \(U_i(t)\), 사망시간을 \(T_i\)라고 하면 다음과 같이 표현할 수 있다.

\[ Q_i(\tau)=\int_0^{\tau} U_i(t)I(T_i>t)\,dt. \]

실제 임상시험에서는 효용값이 매 순간 관찰되지 않고 방문 시점에서만 측정되는 경우가 많다. 측정 시점을 \(0=t_0<t_1<\cdots<t_K=\tau\)라고 하고 구간 \([t_{k-1},t_k)\)에서의 효용값을 \(U_{ik}\)로 근사하면 다음과 같이 계산할 수 있다.

\[ Q_i(\tau)\approx\sum_{k=1}^{K}U_{ik}(t_k-t_{k-1})I(T_i>t_{k-1}). \]

구간 시작점의 효용값을 그대로 사용하는 위 식은 계단함수 근사이다. 방문 시점 사이에서 효용이 선형적으로 변한다고 가정하면 사다리꼴 공식이 더 자연스럽다.

\[ Q_i(\tau) \approx \sum_{k=1}^{K} \frac{U_i(t_{k-1})+U_i(t_k)}{2} (t_k-t_{k-1}). \]

단, 환자가 구간 중간에 사망한 경우에는 사망시점 이후 효용을 0으로 두고 마지막 구간의 길이를 실제 생존기간으로 줄여야 한다. 즉, \(T_i\in(t_{k-1},t_k]\)이면 마지막 구간의 기여분은 개념적으로 다음과 같다.

\[ \int_{t_{k-1}}^{T_i}U_i(t)\,dt. \]

사다리꼴 공식은 방문 사이의 효용변화가 선형이라는 가정에 의존한다. 질병 진행이나 중대한 이상반응으로 효용이 급격히 변할 수 있다면 측정 간격이 길수록 근사오차가 커진다. 따라서 효용 측정 시점은 임상 방문의 편의성만이 아니라 예상되는 건강상태 변화 시점을 고려하여 설계해야 한다.

3.1.3.1 기저 효용값과 QALY의 보정

무작위배정에도 불구하고 표본에서는 우연한 기저 효용 불균형이 발생할 수 있다. 기저 효용이 높은 환자는 이후 QALY도 높게 나타날 가능성이 있으므로, 기저 효용을 보정하면 치료효과 추정의 정밀도가 향상될 수 있다. 환자 \(i\)의 총 QALY를 \(Q_i\)라 하고 기저 효용을 \(U_{i0}\)라 하면 다음과 같은 회귀모형을 사용할 수 있다.

\[ Q_i=\beta_0+\beta_1Z_i+\beta_2U_{i0}+\boldsymbol\beta_3^TX_i+\varepsilon_i. \]

여기서 \(\beta_1\)은 동일한 기저 효용과 공변량 수준에서의 조정된 평균 QALY 차이를 나타낸다. 기저 효용을 보정하는 목적은 무작위배정을 대체하는 것이 아니라 우연한 불균형을 줄이고 정밀도를 높이는 데 있다.

3.1.3.2 비용 누적과 사건 발생 시점

총 비용은 단순한 합계이지만, 비용이 언제 발생했는지도 중요하다. 환자 \(i\)의 누적비용 과정을 \(C_i(t)\)라고 하면 분석기간 동안의 총 비용은 증가과정의 적분으로 나타낼 수 있다.

\[ C_i(\tau)=\int_0^\tau dC_i(t). \]

입원이나 수술처럼 특정 시점에 큰 비용이 발생하면 \(C_i(t)\)는 계단형으로 증가한다. 할인은 각 비용이 발생한 시점에 적용되어야 하므로, 연말 총액에 한 번만 할인하는 것보다 사건별 발생시점을 이용하는 것이 이론적으로 정확하다.

분석 기간이 1년을 넘고 할인 적용이 필요하다면 연속시간에서 할인된 비용과 QALY는 다음과 같이 표현할 수 있다.

\[ C_i^{d}(\tau)=\int_0^{\tau}e^{-r_Ct}\,dC_i(t), \]

\[ Q_i^{d}(\tau)=\int_0^{\tau}e^{-r_Qt}U_i(t)I(T_i>t)\,dt, \]

여기서 \(r_C\)와 \(r_Q\)는 각각 비용과 효과의 연속 할인율이다. 이 장에서는 표기를 단순하게 하기 위해 할인된 총 비용과 총 QALY를 각각 \(C_i\), \(Q_i\)로 쓴다.

위 그림에서 자원사용량은 사건이 발생할 때마다 누적되는 반면, 건강관련 삶의 질은 방문 시점에서 간헐적으로 측정된다. 비용은 사건기록의 완전성이 중요하고 QALY는 방문 사이의 보간가정이 중요하다는 차이가 있다. 사망이나 중도탈락이 발생하면 두 결과 모두 완전하게 관찰되지 않을 수 있으므로, 관찰 종료의 원인을 분석 단계에서 구분해야 한다.

3.2 임상시험 기반 경제성 평가의 장점과 단점

임상시험 기반 경제성 평가는 직관적이고 자료 기반이라는 점에서 강력한 장점을 가진다. 그러나 경제성 평가의 목적이 보건의료 의사결정이라는 점을 고려하면 여러 한계도 존재한다.

3.2.1 장점

첫째, 무작위배정의 장점을 활용할 수 있다. 임상시험에서 환자는 치료군과 대조군에 무작위로 배정되므로, 충분히 큰 표본에서는 관찰된 공변량뿐 아니라 관찰되지 않은 공변량도 치료군 간 균형을 이룰 것으로 기대된다. 따라서 비용과 QALY의 평균 차이를 치료전략의 차이로 해석하기 상대적으로 쉽다.

둘째, 개별 환자 수준의 비용과 QALY를 함께 관찰할 수 있다. 경제성 평가에서는 비용과 효과의 상관성이 중요하다. 오래 생존한 환자는 더 많은 치료비를 사용할 수 있지만 동시에 더 많은 QALY를 얻을 수 있다. 개별 환자 자료가 있으면 같은 환자 안에서 관찰된 비용과 QALY의 짝지어진 구조를 분석에 반영할 수 있다.

셋째, 임상적 근거와 경제성 근거가 같은 연구설계에서 생성된다. 동일한 임상시험에서 치료효과, 이상반응, 자원사용량, 삶의 질을 함께 수집하면 경제성 평가의 내부 일관성이 높아진다.

넷째, 통계적 분석이 상대적으로 투명하다. 중도절단이나 결측이 없고 추적기간이 충분하다면 치료군별 평균 비용과 평균 QALY를 직접 계산할 수 있다. 이 경우 경제성 평가 결과는 원자료의 평균 구조와 명확히 연결된다.

다섯째, 비용과 QALY의 경험적 분포를 확인할 수 있다. 비용자료는 흔히 오른쪽 꼬리가 길고, QALY는 분석기간과 생존상태에 의해 상한과 하한을 가진다. 임상시험 원자료가 있으면 이러한 분포적 특성을 직접 확인하고 부트스트랩이나 회귀분석에 반영할 수 있다.

위 산점도에서 각 점은 한 환자의 비용과 QALY 조합이다. 점들의 기울어진 방향은 두 결과의 공분산을 나타낸다. 비용과 QALY가 양의 상관을 가지면 생존기간이 긴 환자가 더 많은 의료자원을 사용하면서 더 많은 QALY를 얻는 구조일 수 있다. 이 상관을 무시하면 증분순편익의 분산과 비용효과평면의 불확실성 영역을 잘못 추정할 수 있다.

경제성 평가의 의사결정 목표는 평균 자원배분이므로 비용분포가 치우쳐 있더라도 평균 비용이 주된 분석대상이다. 중앙값 비용은 전형적인 환자의 비용을 설명하는 데 유용하지만, 전체 예산이나 기대비용을 직접 나타내지는 않는다. 따라서 평균 비용 분석에서 정규성 가정이 불안정할 때는 평균을 다른 위치모수로 바꾸기보다 부트스트랩, 강건 표준오차, 적절한 일반화선형모형을 이용하여 평균의 불확실성을 추정하는 것이 일반적이다.

3.2.2 단점

첫째, 임상시험의 추적기간이 경제성 평가에 필요한 분석 기간보다 짧은 경우가 많다. 신약의 비용은 치료 초기에 집중적으로 발생하지만, 생존 이득이나 장기 합병증 예방 효과는 오랜 기간에 걸쳐 나타날 수 있다. 이 경우 임상시험 추적기간만으로는 비용효과성을 충분히 평가하기 어렵다.

둘째, 임상시험 대상자는 실제 진료환경의 환자와 다를 수 있다. 임상시험은 선정기준과 제외기준이 엄격하므로 고령자, 동반질환이 많은 환자, 순응도가 낮은 환자가 배제될 수 있다. 따라서 임상시험 기반 경제성 평가 결과를 실제 급여 대상 인구집단에 그대로 일반화하기 어려울 수 있다.

셋째, 임상시험의 자원사용량이 실제 진료환경과 다를 수 있다. 임상시험에서는 프로토콜에 따라 검사, 방문, 모니터링이 더 자주 이루어질 수 있다. 연구 목적의 자원사용량을 경제성 평가에 그대로 포함하면 실제 의료비를 과대평가할 수 있다. 반대로 임상시험에서 지원된 약제비나 관리비가 실제 급여환경의 비용을 충분히 반영하지 못할 수도 있다.

넷째, 경제성 평가에 필요한 모든 자료가 임상시험에서 수집되지 않을 수 있다. 예를 들어 입원비, 비급여 비용, 간병비, 생산성 손실, 진행 이후 효용값, 장기 생존 이후 의료비, 후기 이상반응 관리 비용 등이 충분히 수집되지 않을 수 있다.

다섯째, 중도절단과 결측 문제가 발생할 수 있다. 특히 비용자료는 사망, 중도탈락, 연구종료 시점 때문에 완전하게 관찰되지 않는 경우가 많다. 이 장에서는 먼저 중도절단이 없는 단순한 상황을 다룬다. 중도절단이 있는 비용과 QALY 추정은 생존분석, inverse probability weighting, multiple imputation, joint modeling 등으로 확장된다.

Important실무적 관점

임상시험 기반 경제성 평가는 “자료에서 직접 관찰된 비용과 QALY”를 이용한다는 장점이 있다. 그러나 장기 가치, 실제 진료환경의 일반화 가능성, 결측과 중도절단 문제에는 한계가 있다. 많은 의약품 경제성 평가에서 임상시험 기반 분석과 모형 기반 분석을 함께 고려하는 이유가 여기에 있다.

3.2.3 임상시험 기반 분석이 적절한 경우

임상시험 기반 경제성 평가는 다음과 같은 경우에 상대적으로 적절하다.

  • 질병 경과가 짧고 주요 결과가 임상시험 기간 내에 대부분 관찰되는 경우
  • 치료효과가 단기간에 나타나는 경우
  • 비용과 QALY가 임상시험 추적기간 내에 충분히 수집된 경우
  • 장기 외삽의 필요성이 낮은 경우
  • 치료전략 간 차이가 주로 단기 자원사용량과 단기 결과에서 발생하는 경우

예를 들어 급성 감염질환 치료제, 단기 수술기법 비교, 짧은 기간의 증상 개선을 목표로 하는 치료전략 등은 임상시험 기반 경제성 평가가 비교적 자연스럽게 적용될 수 있다. 반대로 암, 만성질환, 심혈관질환, 희귀질환처럼 장기 생존, 재발, 합병증, 질병 진행이 중요한 질환에서는 임상시험 기반 분석만으로 충분하지 않을 가능성이 높다.

3.2.4 설명적 임상시험과 실용적 임상시험

임상시험의 설계 목적은 경제성 평가의 일반화 가능성에 직접 영향을 준다. 엄격한 선정기준, 높은 순응도 관리, 집중적인 방문일정을 사용하는 설명적 임상시험은 치료의 효능을 명확히 평가하는 데 유리하지만 실제 진료환경과 차이가 클 수 있다. 반면 실용적 임상시험은 실제 진료환경과 유사한 환자선정, 치료전달, 추적방식을 사용하므로 비용과 자원사용량의 외적 타당도가 상대적으로 높다.

목표 모집단에서의 평균 비용을 \(\mathbb{E}_T\{C(z)\}\), 임상시험 모집단에서의 평균 비용을 \(\mathbb{E}_S\{C(z)\}\)라고 하자. 두 모집단의 공변량 분포가 다르더라도, 치료결과가 공변량 \(X\)에 조건부로 일반화될 수 있다면 다음과 같은 표준화가 가능하다.

\[ \mathbb{E}_T\{C(z)\} = \int \mathbb{E}\{C\mid Z=z,X=x,S=1\} \,dF_T(x), \]

여기서 \(S=1\)은 임상시험 참여를 의미하고 \(F_T(x)\)는 목표 모집단의 공변량 분포이다. QALY에도 같은 원리를 적용할 수 있다. 이 식은 임상시험 결과의 일반화가 단순히 표본크기의 문제가 아니라, 결과를 변화시키는 공변량이 두 모집단에서 어떻게 분포하는지의 문제임을 보여준다.

3.3 중도절단이 없는 경우 ICER의 추정

이 절에서는 가장 기본적인 상황을 다룬다. 임상시험에 등록된 모든 환자에 대해 분석 기간 동안의 총 비용과 총 QALY가 완전히 관찰되었다고 가정한다. 이 경우 치료군별 평균 비용과 평균 QALY를 직접 계산할 수 있다.

직접적인 평균 비교가 인과적 증분비용과 증분효과를 추정하려면 다음 조건이 필요하다.

  1. 일관성: 실제로 치료 \(z\)를 받은 환자의 관찰결과는 잠재결과 \(C_i(z)\)와 \(Q_i(z)\)에 해당한다.
  2. 교환가능성: 무작위배정으로 치료배정이 잠재결과와 독립이다.
  3. 양의 확률성: 분석대상 공변량 수준에서 각 치료를 배정받을 가능성이 존재한다.
  4. 간섭 없음: 한 환자의 치료가 다른 환자의 비용이나 QALY에 영향을 주지 않는다.
  5. 완전한 결과 관찰: 분석기간의 비용과 QALY가 모든 환자에서 관찰된다.

집단수준의 자원제약이나 감염 전파처럼 환자 간 간섭이 존재하는 상황에서는 간섭 없음 가정이 성립하지 않을 수 있다. 또한 군집무작위배정 임상시험에서는 같은 의료기관이나 군집 안 환자의 결과가 상관되므로 독립표본 공식 대신 군집구조를 반영해야 한다.

3.3.1 자료 구조와 표본 평균

두 치료전략을 비교하는 무작위배정 임상시험을 생각하자. 신약군의 표본크기를 \(n_1\), 대조군의 표본크기를 \(n_0\)이라고 하자. 신약군 환자 \(i\)의 비용과 QALY를 각각 \(C_{1i}\), \(Q_{1i}\)라고 쓰고, 대조군 환자 \(i\)의 비용과 QALY를 각각 \(C_{0i}\), \(Q_{0i}\)라고 쓰자.

신약군의 평균 비용과 평균 QALY는 다음과 같다.

\[ \bar C_1=\frac{1}{n_1}\sum_{i=1}^{n_1}C_{1i}, \qquad \bar Q_1=\frac{1}{n_1}\sum_{i=1}^{n_1}Q_{1i}. \]

대조군의 평균 비용과 평균 QALY는 다음과 같다.

\[ \bar C_0=\frac{1}{n_0}\sum_{i=1}^{n_0}C_{0i}, \qquad \bar Q_0=\frac{1}{n_0}\sum_{i=1}^{n_0}Q_{0i}. \]

증분비용과 증분효과의 표본 추정량은 다음과 같다.

\[ \widehat{\Delta C}=\bar C_1-\bar C_0, \]

\[ \widehat{\Delta Q}=\bar Q_1-\bar Q_0. \]

따라서 ICER의 점 추정량은 다음과 같다.

\[ \widehat{ICER}=\frac{\widehat{\Delta C}}{\widehat{\Delta Q}}, \qquad \widehat{\Delta Q}\neq 0. \]

여기서 중요한 점은 ICER가 평균의 차이에 대한 비율이라는 것이다.

\[ \frac{\mathbb{E}\{C(1)\}-\mathbb{E}\{C(0)\}} {\mathbb{E}\{Q(1)\}-\mathbb{E}\{Q(0)\}} \neq \mathbb{E}\left[ \frac{C(1)-C(0)}{Q(1)-Q(0)} \right]. \]

오른쪽 식은 개인별 증분비용효과비의 평균이지만, 동일 환자에게 두 치료를 동시에 적용할 수 없으므로 일반적인 평행군 임상시험에서는 직접 관찰할 수도 없다. 정책 의사결정에 필요한 ICER는 왼쪽과 같이 집단 평균 비용 차이를 집단 평균 효과 차이로 나눈 값이다.

WarningICER 추정 시 주의점

\(\widehat{ICER}\)는 두 평균 차이의 비율이다. 따라서 \(\widehat{\Delta Q}\)가 0에 가까우면 매우 불안정해진다. 또한 증분효과가 음수인 경우 ICER의 부호와 크기만으로는 의사결정 의미를 직관적으로 해석하기 어렵다. 비용효과평면과 순편익 접근법을 함께 사용하는 것이 좋다.

예제: 완전 관찰 자료에서 ICER 계산

다음과 같은 임상시험 결과를 생각하자.

치료전략 표본크기 평균 비용 평균 QALY
기존 치료 100 20,000,000원 1.40
신약 100 28,000,000원 1.72

증분비용은 다음과 같다.

\[ \widehat{\Delta C}=28{,}000{,}000-20{,}000{,}000=8{,}000{,}000. \]

증분효과는 다음과 같다.

\[ \widehat{\Delta Q}=1.72-1.40=0.32. \]

따라서 ICER는 다음과 같다.

\[ \widehat{ICER}=\frac{8{,}000{,}000}{0.32}=25{,}000{,}000. \]

즉, 신약은 기존 치료에 비해 QALY 1단위를 추가로 얻기 위해 약 2,500만 원의 추가 비용이 필요한 것으로 추정된다.

3.3.2 증분비용과 증분효과의 분산과 공분산

평균 비용과 평균 QALY의 차이는 표본자료에서 추정되므로 불확실성을 가진다. 신약군과 대조군이 서로 독립이라고 하면 증분비용의 분산은 다음과 같이 추정할 수 있다.

\[ \widehat{\operatorname{Var}}(\widehat{\Delta C}) =\frac{s^2_{C,1}}{n_1}+\frac{s^2_{C,0}}{n_0}, \]

여기서 \(s^2_{C,1}\)과 \(s^2_{C,0}\)은 각각 신약군과 대조군의 비용 표본분산이다. 증분효과의 분산도 같은 방식으로 추정한다.

\[ \widehat{\operatorname{Var}}(\widehat{\Delta Q}) =\frac{s^2_{Q,1}}{n_1}+\frac{s^2_{Q,0}}{n_0}. \]

경제성 평가에서는 증분비용과 증분효과를 따로따로 보는 것만으로 충분하지 않다. 비용과 QALY는 같은 환자에서 동시에 관찰되므로 두 값 사이의 공분산도 중요하다. 신약군에서 비용과 QALY의 표본공분산을 \(s_{CQ,1}\), 대조군에서의 표본공분산을 \(s_{CQ,0}\)라고 하면 다음과 같다.

\[ \widehat{\operatorname{Cov}}(\widehat{\Delta C},\widehat{\Delta Q}) =\frac{s_{CQ,1}}{n_1}+\frac{s_{CQ,0}}{n_0}. \]

따라서 증분 추정량 벡터를 다음과 같이 정의하면,

\[ \widehat{\boldsymbol\delta} =\begin{pmatrix} \widehat{\Delta C} \\ \widehat{\Delta Q} \end{pmatrix}, \]

그 분산-공분산 행렬은 다음과 같이 추정할 수 있다.

\[ \widehat{\boldsymbol\Sigma} =\begin{pmatrix} \widehat V_C & \widehat V_{CQ} \\ \widehat V_{CQ} & \widehat V_Q \end{pmatrix}, \]

여기서

\[ \widehat V_C=\widehat{\operatorname{Var}}(\widehat{\Delta C}), \qquad \widehat V_Q=\widehat{\operatorname{Var}}(\widehat{\Delta Q}), \qquad \widehat V_{CQ}=\widehat{\operatorname{Cov}}(\widehat{\Delta C},\widehat{\Delta Q}). \]

표본크기가 충분히 크면 중심극한정리에 의해 다음의 근사분포를 사용할 수 있다.

\[ \widehat{\boldsymbol\delta} \approx N\left( \begin{pmatrix} \Delta C \\ \Delta Q \end{pmatrix}, \boldsymbol\Sigma \right). \]

이 근사분포는 비용효과평면, 순편익 신뢰구간, 비용효과수용곡선의 이론적 기초가 된다.

두 치료군의 평균벡터를 각각 \(\bar{\mathbf Y}_z=(\bar C_z,\bar Q_z)^T\)라고 하면,

\[ \widehat{\boldsymbol\delta} = \bar{\mathbf Y}_1-\bar{\mathbf Y}_0 \]

이고 독립적인 평행군 설계에서는

\[ \operatorname{Var}(\widehat{\boldsymbol\delta}) = \frac{\boldsymbol\Sigma_1}{n_1} + \frac{\boldsymbol\Sigma_0}{n_0}. \]

이 식은 앞의 분산과 공분산 공식을 행렬 형태로 표현한 것이다. 비용과 QALY를 별개의 단변량 결과로 취급하지 않고 이변량 결과로 다루면 공동 신뢰영역을 구성할 수 있다. 대규모 표본에서 다음 이차형식은 근사적으로 자유도 2인 카이제곱분포를 따른다.

\[ (\widehat{\boldsymbol\delta}-\boldsymbol\delta)^T \widehat{\boldsymbol\Sigma}^{-1} (\widehat{\boldsymbol\delta}-\boldsymbol\delta) \approx \chi^2_2. \]

따라서 비용효과평면의 타원형 신뢰영역은 다음 조건을 만족하는 점들의 집합이다.

\[ (\boldsymbol\delta-\widehat{\boldsymbol\delta})^T \widehat{\boldsymbol\Sigma}^{-1} (\boldsymbol\delta-\widehat{\boldsymbol\delta}) \le \chi^2_{2,1-\alpha}. \]

타원의 방향과 폭은 비용과 QALY의 공분산에 의해 결정된다. 공분산이 양수이면 불확실성 영역이 오른쪽 위와 왼쪽 아래 방향으로 기울어질 수 있다.

3.3.3 비용효과평면에서의 불확실성

ICER는 하나의 점 추정값이지만, 실제로는 증분비용과 증분효과 모두 불확실하다. 따라서 경제성 평가에서는 \((\widehat{\Delta Q},\widehat{\Delta C})\)를 비용효과평면에 표시한다. 비용효과평면의 가로축은 증분효과, 세로축은 증분비용이다.

사분면 의미 의사결정 해석
오른쪽 위 더 효과적이고 더 비쌈 ICER 또는 INB로 판단
오른쪽 아래 더 효과적이고 더 저렴함 신약이 우월전략
왼쪽 위 덜 효과적이고 더 비쌈 신약이 열등전략
왼쪽 아래 덜 효과적이고 더 저렴함 비용 절감과 효과 감소의 trade-off 판단

위 그림의 원점은 두 치료전략의 평균 비용과 평균 효과가 동일한 지점이다. 점이 원점에서 멀수록 증분 차이의 절대적 크기가 크지만, 비용효과성은 거리만으로 판단하지 않는다. 오른쪽 위와 왼쪽 아래 사분면에서는 지불의사금액에 따라 결론이 달라지고, 오른쪽 아래와 왼쪽 위 사분면에서는 우월전략과 열등전략 관계가 직접 결정된다.

지불의사금액 \(\lambda\)가 주어지면 비용효과평면에서 의사결정 기준선은 다음 직선으로 표현된다.

\[ \Delta C=\lambda \Delta Q. \]

점 \((\Delta Q,\Delta C)\)가 이 직선 아래에 있으면 \(\lambda\Delta Q-\Delta C>0\)이므로 신약이 비용효과적이다. 점이 직선 위에 있으면 두 전략의 순편익이 동일하고, 직선 위쪽에 있으면 신약의 증분순편익이 음수이다. 이 해석은 순편익 접근법과 직접 연결된다.

비용효과평면의 불확실성을 사분면별 확률로도 요약할 수 있다. 예를 들어 부트스트랩 반복값 중 오른쪽 아래 사분면에 위치한 비율은 신약이 더 효과적이고 더 저렴하게 추정되는 반복의 비율이다. 그러나 사분면 확률은 지불의사금액을 반영하지 않으므로 최종 판단에는 순편익 또는 CEAC가 필요하다.

3.3.4 Delta method를 이용한 ICER의 근사 표준오차

ICER는 \(g(\Delta C,\Delta Q)=\Delta C/\Delta Q\)로 정의되는 비선형 함수이다. \(\Delta Q\)가 0에서 충분히 떨어져 있고 표본크기가 충분히 크다면 delta method를 이용하여 \(\widehat{ICER}\)의 근사분산을 계산할 수 있다.

함수 \(g(c,q)=c/q\)의 기울기 벡터는 다음과 같다.

\[ \nabla g(c,q)= \begin{pmatrix} \partial g/\partial c \\ \partial g/\partial q \end{pmatrix} = \begin{pmatrix} 1/q \\ -c/q^2 \end{pmatrix}. \]

따라서 \(\widehat{ICER}\)의 근사분산은 다음과 같다.

\[ \widehat{\operatorname{Var}}(\widehat{ICER}) \approx \widehat{\nabla g}^{T}\widehat{\boldsymbol\Sigma}\widehat{\nabla g}, \]

여기서

\[ \widehat{\nabla g}= \begin{pmatrix} 1/\widehat{\Delta Q} \\ -\widehat{\Delta C}/\widehat{\Delta Q}^{2} \end{pmatrix}. \]

이를 전개하면 다음과 같다.

\[ \widehat{\operatorname{Var}}(\widehat{ICER}) \approx \frac{\widehat V_C}{\widehat{\Delta Q}^{2}} + \frac{\widehat{\Delta C}^{2}\widehat V_Q}{\widehat{\Delta Q}^{4}} - \frac{2\widehat{\Delta C}\widehat V_{CQ}}{\widehat{\Delta Q}^{3}}. \]

이 식은 ICER의 표준오차를 계산하는 데 유용하지만, \(\widehat{\Delta Q}\)가 0에 가까운 경우 매우 불안정하다. 그래서 실무에서는 ICER 자체의 신뢰구간보다 비용효과평면, 순편익, 부트스트랩 결과를 더 중시하는 경우가 많다.

Delta method는 \(g(c,q)=c/q\)를 참값 주변에서 1차 Taylor 전개하는 방법이다.

\[ g(\widehat{\boldsymbol\delta}) \approx g(\boldsymbol\delta) + \nabla g(\boldsymbol\delta)^T (\widehat{\boldsymbol\delta}-\boldsymbol\delta). \]

따라서 이 방법이 안정적이려면 증분효과의 참값이 0에서 충분히 떨어져 있고, 표본분포가 국소적으로 정규분포에 가까워야 한다. 증분효과의 신뢰구간이 0을 포함하면 비율함수의 불연속점이 추론범위 안에 들어오므로 대칭적인 Wald 신뢰구간은 부적절할 수 있다.

3.3.5 Fieller 접근의 아이디어

ICER의 신뢰구간을 다룰 때 delta method보다 원리에 더 충실한 접근은 Fieller 방식이다. 어떤 후보 ICER 값 \(k\)가 참값으로 가능한지를 보려면 다음 식을 생각할 수 있다.

\[ \Delta C-k\Delta Q=0. \]

따라서 표본에서 다음 통계량을 구성한다.

\[ T(k)= \frac{\widehat{\Delta C}-k\widehat{\Delta Q}} {\sqrt{\widehat V_C-2k\widehat V_{CQ}+k^2\widehat V_Q}}. \]

근사적으로 \(|T(k)|\le z_{1-\alpha/2}\)를 만족하는 모든 \(k\)의 집합을 ICER의 \((1-\alpha)\) 신뢰집합으로 볼 수 있다.

\[ \left\{k: \frac{(\widehat{\Delta C}-k\widehat{\Delta Q})^2} {\widehat V_C-2k\widehat V_{CQ}+k^2\widehat V_Q} \le z_{1-\alpha/2}^{2} \right\}. \]

이 집합은 일반적인 닫힌 구간일 수도 있지만, 무한 구간이거나 두 개의 분리된 구간이 될 수도 있다. 이러한 현상은 ICER가 비율이고 분모인 \(\Delta Q\)의 불확실성이 크기 때문에 발생한다.

Fieller 부등식의 양변을 정리하면 \(k\)에 대한 이차부등식이 된다.

\[ Ak^2+Bk+D\le 0, \]

여기서

\[ A=\widehat{\Delta Q}^2-z^2\widehat V_Q, \]

\[ B=-2\left(\widehat{\Delta C}\widehat{\Delta Q} -z^2\widehat V_{CQ}\right), \]

\[ D=\widehat{\Delta C}^2-z^2\widehat V_C, \]

이며 \(z=z_{1-\alpha/2}\)이다. \(A>0\)이고 판별식이 양수이면 일반적인 유한구간이 얻어진다. 반면 \(A\le 0\)이면 증분효과가 0에서 충분히 분리되어 있지 않다는 의미이며, 신뢰집합이 무한하거나 분리될 수 있다. 이는 계산 오류가 아니라 자료가 유한한 ICER 범위를 지지하지 못한다는 통계적 신호이다.

Tip순편익 접근법이 선호되는 이유

ICER의 신뢰구간은 분모가 0 근처일 때 해석이 까다롭다. 반면 순편익은 \(INB(\lambda)=\lambda\Delta Q-\Delta C\)처럼 선형 함수이므로 표준오차, 신뢰구간, 회귀분석, 부트스트랩을 적용하기 쉽다.

3.3.6 부트스트랩을 이용한 불확실성 평가

임상시험 기반 경제성 평가에서 비용과 QALY의 불확실성을 평가하는 가장 직관적인 방법 중 하나는 부트스트랩이다. 부트스트랩은 원자료에서 환자를 반복적으로 재표본추출하여 각 반복에서 증분비용과 증분효과를 다시 계산하는 방법이다.

중요한 점은 비용과 QALY를 따로 재표본추출하지 않고, 같은 환자의 비용과 QALY 쌍을 함께 재표본추출해야 한다는 것이다. 그래야 환자 수준의 상관구조가 보존된다.

위 그림의 핵심은 치료군별 층화 재표본추출이다. 전체 환자를 한꺼번에 재표본추출하면 반복마다 치료군 표본크기가 달라질 수 있으므로, 원래 무작위배정 구조를 유지하려면 각 군에서 별도로 환자를 복원추출하는 것이 일반적이다. 비용과 QALY뿐 아니라 환자 식별자에 연결된 모든 공변량과 결과를 하나의 묶음으로 추출해야 한다.

부트스트랩 절차는 다음과 같다.

  1. 신약군에서 \(n_1\)명을 복원추출한다.
  2. 대조군에서 \(n_0\)명을 복원추출한다.
  3. 각 재표본에서 평균 비용과 평균 QALY를 계산한다.
  4. \(\widehat{\Delta C}^{(b)}\), \(\widehat{\Delta Q}^{(b)}\), \(\widehat{ICER}^{(b)}\), \(\widehat{INB}^{(b)}(\lambda)\)를 계산한다.
  5. 이 과정을 \(b=1,\ldots,B\)번 반복한다.
  6. 반복 결과를 비용효과평면, 신뢰구간, 비용효과수용곡선으로 요약한다.

개별 무작위배정 임상시험에서는 환자가 재표본추출 단위이다. 군집무작위배정 임상시험에서는 환자가 아니라 군집을 재표본추출해야 군집 내 상관이 보존된다. 반복측정 원자료를 사용하는 경우에도 방문별 관측치를 따로 추출하지 않고 환자 단위로 전체 추적자료를 함께 추출해야 한다.

백분위수 부트스트랩 신뢰구간은 부트스트랩 분포의 \(\alpha/2\)와 \(1-\alpha/2\) 분위수를 사용한다. 편향이나 비대칭성이 큰 경우에는 편향보정 가속 신뢰구간을 고려할 수 있지만, ICER처럼 분모가 0을 지날 수 있는 비율에서는 어떤 단일 구간도 비용효과평면의 공동 불확실성을 완전히 대체하지 못한다.

위 그림에서 점들이 어느 사분면에 분포하는지뿐 아니라 지불의사금액 기준선의 어느 쪽에 놓이는지를 함께 보아야 한다. 점선 아래의 반복은 해당 지불의사금액에서 증분순편익이 양수인 반복이다. 점구름이 넓게 퍼질수록 비용과 효과의 공동 불확실성이 크며, 원점을 가로지르면 우월성 또는 열등성의 방향 자체도 불확실하다는 뜻이다.

3.3.7 순편익 접근법

ICER는 널리 사용되지만 통계적으로 다루기 까다롭다. 이 문제를 완화하기 위해 순편익 접근법을 사용할 수 있다. 지불의사금액을 \(\lambda\)라고 하면 치료전략 \(z\)의 순편익은 다음과 같이 정의된다.

\[ NB_z(\lambda)=\lambda Q_z-C_z. \]

두 치료전략의 증분순편익은 다음과 같다.

\[ INB(\lambda)=\lambda\Delta Q-\Delta C. \]

표본자료에서는 다음과 같이 추정한다.

\[ \widehat{INB}(\lambda) =\lambda\widehat{\Delta Q}-\widehat{\Delta C}. \]

\(\widehat{INB}(\lambda)>0\)이면 해당 지불의사금액에서 신약의 추가 QALY 가치가 추가 비용보다 크다고 해석한다.

앞의 예제에서 \(\widehat{\Delta Q}=0.32\), \(\widehat{\Delta C}=8{,}000{,}000\)이고, 지불의사금액이 QALY당 30,000,000원이라고 하자. 그러면 증분순편익은 다음과 같다.

\[ \widehat{INB}(30{,}000{,}000) =30{,}000{,}000\times0.32-8{,}000{,}000 =1{,}600{,}000. \]

즉, QALY당 3,000만 원 기준에서 신약의 증분순편익은 160만 원으로 양수이다.

순편익의 분산은 증분비용과 증분효과의 분산-공분산으로부터 다음과 같이 계산한다.

\[ \widehat{\operatorname{Var}}\{\widehat{INB}(\lambda)\} =\lambda^2\widehat V_Q+ \widehat V_C-2\lambda\widehat V_{CQ}. \]

따라서 근사적인 95% 신뢰구간은 다음과 같다.

\[ \widehat{INB}(\lambda) \pm 1.96\sqrt{\widehat{\operatorname{Var}}\{\widehat{INB}(\lambda)\}}. \]

위 그림에서 직선의 절편은 \(-\Delta C\)이고 기울기는 \(\Delta Q\)이다. 증분효과가 양수이면 지불의사금액이 증가할수록 증분순편익이 커지고, 증분효과가 음수이면 반대로 감소한다. \(\Delta Q>0\)인 경우 직선이 0을 통과하는 지불의사금액은 \(\Delta C/\Delta Q\)이므로 ICER와 일치한다. 다만 \(\Delta Q<0\)인 경우에는 같은 교차점을 단순히 비용효과성 임계값으로 해석해서는 안 되고 사분면을 함께 확인해야 한다.

3.3.8 개별 환자 수준 순편익과 회귀분석

임상시험 기반 분석에서는 개별 환자 수준에서 순편익을 정의할 수도 있다. 환자 \(i\)의 순편익은 다음과 같다.

\[ NB_i(\lambda)=\lambda Q_i-C_i. \]

치료군별 평균 순편익을 계산하면 다음과 같다.

\[ \bar{NB}_1(\lambda)=\frac{1}{n_1}\sum_{i=1}^{n_1}\left(\lambda Q_{1i}-C_{1i}\right), \]

\[ \bar{NB}_0(\lambda)=\frac{1}{n_0}\sum_{i=1}^{n_0}\left(\lambda Q_{0i}-C_{0i}\right). \]

증분순편익은 두 평균의 차이이다.

\[ \widehat{INB}(\lambda)=\bar{NB}_1(\lambda)-\bar{NB}_0(\lambda). \]

이는 앞에서 정의한 \(\lambda\widehat{\Delta Q}-\widehat{\Delta C}\)와 동일하다. 이 접근은 회귀분석으로 자연스럽게 확장된다. 치료군 지시변수 \(Z_i\)를 사용하여 다음 회귀모형을 적합할 수 있다.

\[ NB_i(\lambda)=\alpha_0+\alpha_1Z_i+\epsilon_i. \]

이때 \(\alpha_1\)은 해당 \(\lambda\)에서의 증분순편익이다. 공변량 \(X_i\)를 보정하고 싶다면 다음과 같이 확장한다.

\[ NB_i(\lambda)=\alpha_0+\alpha_1Z_i+\boldsymbol\alpha_2^{T}X_i+\epsilon_i. \]

무작위배정 임상시험에서는 공변량 보정이 필수는 아니지만, 기저치 불균형을 조정하거나 추정의 정밀도를 높이기 위해 사용할 수 있다. 비용자료의 분산이 크거나 오른쪽 꼬리가 긴 경우에는 robust standard error나 bootstrap confidence interval을 함께 사용하는 것이 좋다.

비용과 QALY를 각각 회귀분석할 때는 두 오차항의 상관을 허용할 수 있다.

\[ C_i=\alpha_C+\beta_CZ_i+\boldsymbol\gamma_C^TX_i+\varepsilon_{Ci}, \]

\[ Q_i=\alpha_Q+\beta_QZ_i+\boldsymbol\gamma_Q^TX_i+\varepsilon_{Qi}, \]

\[ \operatorname{Cov}(\varepsilon_{Ci},\varepsilon_{Qi})\neq 0. \]

두 식을 동시에 적합하는 seemingly unrelated regression은 비용과 QALY의 잔차 상관을 명시적으로 반영한다. 동일한 설명변수를 두 식에 사용하는 단순한 경우 점추정치는 개별 최소제곱 추정치와 같을 수 있지만, 공동 공분산과 순편익의 표준오차를 일관되게 계산하는 데 유용하다.

회귀모형에서 얻은 조정된 증분효과를 \(\widehat\beta_Q\), 조정된 증분비용을 \(\widehat\beta_C\)라고 하면 조정된 증분순편익은

\[ \widehat{INB}_{adj}(\lambda) = \lambda\widehat\beta_Q-\widehat\beta_C \]

이며 그 분산은

\[ \operatorname{Var}\{\widehat{INB}_{adj}(\lambda)\} = \lambda^2\operatorname{Var}(\widehat\beta_Q) + \operatorname{Var}(\widehat\beta_C) - 2\lambda\operatorname{Cov}(\widehat\beta_Q,\widehat\beta_C) \]

로 계산된다.

3.3.9 비용효과수용곡선

부트스트랩 결과를 이용하면 지불의사금액 \(\lambda\)별로 신약이 비용효과적일 확률을 추정할 수 있다. \(b=1,\ldots,B\)번째 부트스트랩 반복에서 증분비용과 증분효과를 각각 \(\widehat{\Delta C}^{(b)}\), \(\widehat{\Delta Q}^{(b)}\)라고 하자. 그러면 \(\lambda\)에서 비용효과적일 확률은 다음과 같이 추정할 수 있다.

\[ \widehat{CEAC}(\lambda) =\frac{1}{B}\sum_{b=1}^{B} I\left(\lambda\widehat{\Delta Q}^{(b)}-\widehat{\Delta C}^{(b)}>0\right). \]

여기서 \(I(\cdot)\)는 조건이 참이면 1, 거짓이면 0을 가지는 지시함수이다. \(\widehat{CEAC}(\lambda)\)를 여러 \(\lambda\) 값에 대해 계산하여 그린 곡선을 비용효과수용곡선이라고 한다.

위 그림의 가로축은 의사결정자의 지불의사금액이고 세로축은 신약의 증분순편익이 양수로 추정되는 비율이다. 곡선이 0.5를 넘는 지점은 신약이 비용효과적으로 추정되는 반복이 절반을 넘는 지점이지만, 이를 자동적인 채택기준으로 해석해서는 안 된다. 실제 결정은 기대순편익의 크기, 예산영향, 형평성, 실행 가능성 등을 함께 고려한다.

NoteCEAC 해석

비용효과수용곡선은 특정 지불의사금액에서 신약이 비용효과적으로 보이는 불확실성 요약이다. 빈도론적 부트스트랩에서는 “자료 생성과 표본추출의 반복에서 비용효과적 결론이 나올 비율”로 해석하는 것이 자연스럽다. 베이지안 분석에서는 모수의 사후분포하에서 신약이 비용효과적일 사후확률로 해석할 수 있다.

3.3.9.1 CEAC가 제공하지 않는 정보

CEAC는 비용효과성의 확률적 불확실성을 보여주지만 순편익의 크기는 보여주지 않는다. 예를 들어 비용효과적일 확률이 0.9인 치료라도 기대 증분순편익이 매우 작을 수 있고, 반대로 비용효과적일 확률이 0.6이지만 기대 증분순편익이 클 수 있다. 따라서 CEAC는 기대순편익 곡선과 함께 해석하는 것이 바람직하다.

전략이 두 개보다 많을 때는 각 지불의사금액에서 기대순편익이 가장 큰 전략을 먼저 찾는다.

\[ z^*(\lambda) = \arg\max_z \mathbb{E}\{NB_z(\lambda)\}. \]

비용효과수용경계는 이 최적 전략이 실제로 가장 높은 순편익을 가질 확률을 나타낸다. 여러 전략의 CEAC를 각각 비교하는 것만으로는 기대순편익이 최대인 전략을 정확히 식별하지 못할 수 있다.

의사결정 불확실성의 경제적 가치는 완전정보 기대가치로 연결된다. 환자 1인당 완전정보 기대가치는 다음과 같다.

\[ EVPI(\lambda) = \mathbb{E}\left[\max_z NB_z(\lambda)\right] - \max_z\mathbb{E}\left[NB_z(\lambda)\right]. \]

첫 번째 항은 불확실한 참값을 완전히 안 뒤 최적 전략을 선택할 때의 기대순편익이고, 두 번째 항은 현재 정보에서 선택한 전략의 기대순편익이다. 두 항의 차이는 추가 연구로 모든 불확실성을 제거할 수 있을 때 얻을 수 있는 최대 기대가치이다.

3.3.10 경제성 평가 보고 시 확인할 항목

임상시험 기반 경제성 평가 결과를 보고할 때는 적어도 다음 항목을 명확히 해야 한다.

분석 관점 건강보험자, 보건의료체계, 사회적 관점 중 무엇인가?
분석 기간 임상시험 추적기간만 사용했는가, 장기 외삽을 포함했는가?

경제성 평가 결과는 점추정치만으로 충분하지 않다. 치료군별 표본수, 평균 비용과 평균 QALY, 증분 추정치, 불확실성 구간, 비용효과평면, 지불의사금액별 순편익을 함께 제시해야 한다. 비용과 QALY의 수집기간이 다르거나 분석대상군이 임상효과 분석과 다르면 그 이유를 명시해야 한다. 또한 임상시험계획서에 경제성 평가 분석계획이 사전 규정되었는지, 사후 분석인지도 구분해야 한다.

## 서론 {#sec-trial-based-introduction}

의약품 경제성 평가는 크게 임상시험 기반 경제성 평가와 모형 기반 경제성 평가로 나눌 수 있다. 임상시험 기반 경제성 평가는 임상시험에서 관찰된 개별 환자 자료를 이용하여 비용과 효과를 직접 추정하는 접근이다. 반면 모형 기반 경제성 평가는 임상시험, 관찰연구, 문헌자료, 역학자료, 전문가 의견 등을 결합하여 장기적인 비용과 효과를 추정한다.

임상시험 기반 경제성 평가는 다음 질문에서 출발한다.

> 임상시험에서 관찰된 환자집단을 기준으로 할 때, 신약은 기존 치료에 비해 비용을 얼마나 증가시키며 QALY를 얼마나 향상시키는가?

치료전략을 $z \in \{0,1\}$로 표시하자. 여기서 $z=1$은 신약, $z=0$은 기존 치료를 의미한다. 분석 기간을 $\tau$라고 할 때, 환자 한 명의 총 비용을 $C(z;\tau)$, 총 QALY를 $Q(z;\tau)$라고 하자. 임상시험 기반 비용효용분석의 가장 기본적인 관심 모수는 다음의 네 기대값이다.

$$
\mu_{C,z}(\tau)=\mathbb{E}\{C(z;\tau)\},
$$

$$
\mu_{Q,z}(\tau)=\mathbb{E}\{Q(z;\tau)\}.
$$

두 치료전략의 증분비용과 증분효과는 다음과 같다.

$$
\Delta C(\tau)=\mu_{C,1}(\tau)-\mu_{C,0}(\tau),
$$

$$
\Delta Q(\tau)=\mu_{Q,1}(\tau)-\mu_{Q,0}(\tau).
$$

이때 비용효용분석에서 ICER는 다음과 같이 정의된다.

$$
ICER(\tau)=\frac{\Delta C(\tau)}{\Delta Q(\tau)},
\qquad \Delta Q(\tau)\neq 0.
$$

효과지표가 QALY가 아니라 생존연수, 반응건수, 재발 방지 건수와 같은 자연 단위라면 $Q$ 대신 일반 건강효과 $H$를 사용하면 된다. 이 장에서는 의약품 경제성 평가에서 가장 자주 사용되는 비용효용분석을 중심으로 설명하므로 효과지표를 $Q$로 표기한다.

::: {.callout-note title="핵심 메시지"}
임상시험 기반 경제성 평가는 임상시험에 참여한 환자들로부터 관찰된 비용과 QALY 자료를 이용하여 $\Delta C$, $\Delta Q$, $ICER$, $INB$를 추정한다. 그러나 최종 의사결정은 통계적 유의성만이 아니라 지불의사금액과 의사결정 불확실성을 함께 고려한다.
:::

### 확증적 임상시험 분석과 경제성 평가 분석의 질문 차이

확증적 임상시험에서는 사전에 정의된 주요 평가변수에 대해 통계적 가설검정을 수행한다. 예를 들어 전체생존기간을 주요 평가변수로 하는 임상시험에서는 다음과 같은 귀무가설을 검정할 수 있다.

$$
H_0: HR=1,
$$

여기서 $HR$은 위험비이다. 이 분석의 주요 관심은 치료군 간 생존 차이가 통계적으로 유의한지 여부이다.

반면 경제성 평가는 다음과 같은 의사결정 질문에 관심을 둔다.

$$
\lambda \Delta Q-\Delta C>0 \; ?
$$

여기서 $\lambda$는 QALY 1단위 증가에 대해 의사결정자가 지불할 의사가 있는 최대 금액이다. 위 식은 신약으로 얻는 추가 QALY를 화폐가치로 환산한 값이 추가 비용보다 큰지를 묻는다.

| 구분 | 확증적 임상시험 분석 | 임상시험 기반 경제성 평가 |
|---|---|---|
| 핵심 질문 | 치료효과가 통계적으로 유의한가? | 추가 효과가 추가 비용을 정당화하는가? |
| 주요 결과 | $p$-value, 신뢰구간, 위험비, 평균 차이 | 평균 비용, 평균 QALY, $ICER$, $INB$, CEAC |
| 판단 기준 | 유의수준, 임상적 유의성 | 지불의사금액, 기대순편익, 의사결정 불확실성 |
| 불확실성 표현 | 신뢰구간, $p$-value | 비용효과평면, 순편익 신뢰구간, CEAC |
| 시간 범위 | 임상시험 추적기간 중심 | 임상시험 추적기간 또는 장기 외삽 |

위 그림은 동일한 임상시험 자료가 서로 다른 추론 목표에 사용되는 과정을 보여준다. 임상시험의 가설검정은 치료효과의 존재 여부에 초점을 두지만, 경제성 평가는 비용과 효과의 크기를 동일한 의사결정 척도에 놓는다. 따라서 임상적으로 유의한 치료가 반드시 비용효과적인 것은 아니며, 통계적으로 유의하지 않은 치료도 추정된 효과와 비용의 불확실성을 함께 고려하면 의사결정 대상이 될 수 있다.

### 임상시험 기반 경제성 평가의 estimand

임상시험 기반 경제성 평가에서 특히 중요한 점은 “어떤 인구집단에서의 비용과 효과를 추정하는가?”이다. 무작위배정 임상시험의 원자료를 그대로 사용한다면 추정 대상은 기본적으로 임상시험 대상 인구집단에서의 평균 비용과 평균 QALY이다. 이를 potential outcome 표기로 명확히 나타낼 수 있다.

환자 $i$가 신약을 받았을 때의 비용과 QALY를 각각 $C_i(1)$, $Q_i(1)$이라고 하고, 기존 치료를 받았을 때의 비용과 QALY를 각각 $C_i(0)$, $Q_i(0)$이라고 하자. 같은 환자에게 두 치료전략을 동시에 적용할 수 없으므로 실제로는 다음 값만 관찰된다.

$$
C_i=Z_iC_i(1)+(1-Z_i)C_i(0),
$$

$$
Q_i=Z_iQ_i(1)+(1-Z_i)Q_i(0),
$$

여기서 $Z_i=1$이면 신약군, $Z_i=0$이면 대조군이다. 무작위배정이 적절하게 이루어졌다면 다음의 교환가능성이 성립한다.

$$
Z_i \perp \{C_i(1),C_i(0),Q_i(1),Q_i(0)\}.
$$

따라서 임상시험 대상 인구집단에서 다음 식이 성립한다.

$$
\mathbb{E}\{C(1)\}=\mathbb{E}(C\mid Z=1),
\qquad
\mathbb{E}\{C(0)\}=\mathbb{E}(C\mid Z=0),
$$

$$
\mathbb{E}\{Q(1)\}=\mathbb{E}(Q\mid Z=1),
\qquad
\mathbb{E}\{Q(0)\}=\mathbb{E}(Q\mid Z=0).
$$

이 식은 단순한 평균 차이가 무작위배정 임상시험에서 인과적 해석을 가질 수 있는 이유를 보여준다. 그러나 임상시험 대상 인구집단과 실제 급여 대상 인구집단이 다르면, 위 estimand는 정책 결정에 필요한 목표 모집단 estimand와 다를 수 있다. 이 문제는 이후 회귀분석, 표준화, MAIC, 실제사용자료 활용에서 다시 등장한다.


#### 경제성 평가 estimand의 구성요소

임상시험의 경제성 평가 estimand는 단순히 “신약과 대조군의 평균 차이”라고만 정의해서는 충분하지 않다. 적어도 다음 요소가 명확해야 한다.

- **대상 인구집단**: 임상시험에 무작위배정된 전체 환자인가, 실제 치료를 받은 환자인가, 특정 하위집단인가?
- **치료전략**: 배정된 치료를 기준으로 하는가, 실제 투여된 치료를 기준으로 하는가?
- **결과변수**: 총 비용, 총 QALY, 순편익 가운데 무엇을 분석하는가?
- **분석 기간**: 임상시험 종료 시점까지인가, 사망까지인가, 생애기간인가?
- **중간사건 처리**: 치료중단, 구조요법, 치료교차, 순응도 저하, 사망을 어떻게 반영하는가?
- **집단 요약치**: 평균 차이, 비율, 특정 분위수 차이 중 무엇을 사용할 것인가?

경제성 평가에서는 일반적으로 무작위배정된 치료전략의 정책적 효과를 평가하는 **treatment-policy estimand**가 자연스럽다. 이 경우 치료중단이나 구조요법 사용이 발생하더라도 환자를 최초 배정군에 따라 분석한다. 이는 임상시험의 intention-to-treat 원칙과 연결된다. 반면 실제 치료를 지속해서 받은 경우의 경제성을 평가하려면 순응도와 치료교차를 고려한 별도의 인과추론 가정이 필요하다.

치료전략 $z$에 대한 비용과 QALY를 벡터로 묶으면 경제성 평가 estimand는 다음과 같이 쓸 수 있다.

$$
\boldsymbol\mu_z(\tau)
=
\begin{pmatrix}
\mu_{C,z}(\tau)\\
\mu_{Q,z}(\tau)
\end{pmatrix}.
$$

두 전략의 증분 estimand는

$$
\boldsymbol\delta(\tau)
=
\boldsymbol\mu_1(\tau)-\boldsymbol\mu_0(\tau)
=
\begin{pmatrix}
\Delta C(\tau)\\
\Delta Q(\tau)
\end{pmatrix}
$$

이다. 경제성 평가의 통계분석은 결국 이 이차원 벡터와 그 불확실성을 추정하는 문제이다. ICER와 증분순편익은 이 벡터를 서로 다른 방식으로 요약한 값이다.

#### 분석대상군과 경제성 평가의 해석

무작위배정된 모든 환자를 최초 배정군에 따라 분석하는 경우, 결과는 치료전략을 실제 정책으로 도입했을 때 기대되는 평균 비용과 평균 QALY의 차이에 가깝다. 반면 임상시험계획서를 준수한 환자만 분석하면 치료 자체의 생물학적 효능에 가까운 질문을 다룰 수 있지만, 무작위배정의 균형이 깨질 수 있다.

특히 비용은 치료중단과 구조요법에 민감하다. 치료중단 이후 발생한 비용을 제외하면 신약 전략의 실제 비용을 과소평가할 수 있고, 구조요법 비용을 포함하면서 구조요법의 건강효과는 제외하면 비용과 효과의 범위가 일치하지 않게 된다. 따라서 비용과 QALY는 같은 치료전략, 같은 분석 기간, 같은 중간사건 처리 규칙을 사용하여 정의해야 한다.

### 임상시험에서 수집되는 경제성 평가 자료

임상시험 기반 경제성 평가에서는 임상적 평가변수뿐 아니라 경제성 평가에 필요한 자료를 계획적으로 수집해야 한다. 대표적인 자료는 다음과 같다.

| 자료 유형 | 예 | 경제성 평가에서의 역할 |
|---|---|---|
| 자원사용량 | 약제 투여량, 외래 방문, 입원, 검사, 처치 | 비용 산출의 기초 |
| 단가 자료 | 약가, 수가, 입원 일당 비용, 검사비 | 자원사용량을 화폐단위 비용으로 변환 |
| 건강관련 삶의 질 | EQ-5D, EORTC QLQ-C30, FACT 계열 | QALY 계산의 기초 |
| 임상결과 | 생존, 진행, 반응, 이상반응 | 효과와 비용 발생 구조 설명 |
| 추적기간 정보 | 관찰기간, 탈락, 사망, 연구 종료 | 누적 비용과 QALY의 관찰 가능성 판단 |

환자 $i$의 분석기간 $\tau$ 동안 총 비용은 자원사용량과 단가의 곱으로 표현할 수 있다. 자원 항목을 $m=1,\ldots,M$이라고 하고, 환자 $i$가 사용한 자원량을 $R_{im}$, 단가를 $u_m$이라고 하면 다음과 같다.

$$
C_i(\tau)=\sum_{m=1}^{M}u_mR_{im}(\tau).
$$

QALY는 시간에 따른 효용가중치와 생존상태를 누적하여 계산한다. 환자 $i$의 시간 $t$에서 효용값을 $U_i(t)$, 사망시간을 $T_i$라고 하면 다음과 같이 표현할 수 있다.

$$
Q_i(\tau)=\int_0^{\tau} U_i(t)I(T_i>t)\,dt.
$$

실제 임상시험에서는 효용값이 매 순간 관찰되지 않고 방문 시점에서만 측정되는 경우가 많다. 측정 시점을 $0=t_0<t_1<\cdots<t_K=\tau$라고 하고 구간 $[t_{k-1},t_k)$에서의 효용값을 $U_{ik}$로 근사하면 다음과 같이 계산할 수 있다.

$$
Q_i(\tau)\approx\sum_{k=1}^{K}U_{ik}(t_k-t_{k-1})I(T_i>t_{k-1}).
$$


구간 시작점의 효용값을 그대로 사용하는 위 식은 계단함수 근사이다. 방문 시점 사이에서 효용이 선형적으로 변한다고 가정하면 사다리꼴 공식이 더 자연스럽다.

$$
Q_i(\tau)
\approx
\sum_{k=1}^{K}
\frac{U_i(t_{k-1})+U_i(t_k)}{2}
(t_k-t_{k-1}).
$$

단, 환자가 구간 중간에 사망한 경우에는 사망시점 이후 효용을 0으로 두고 마지막 구간의 길이를 실제 생존기간으로 줄여야 한다. 즉, $T_i\in(t_{k-1},t_k]$이면 마지막 구간의 기여분은 개념적으로 다음과 같다.

$$
\int_{t_{k-1}}^{T_i}U_i(t)\,dt.
$$

사다리꼴 공식은 방문 사이의 효용변화가 선형이라는 가정에 의존한다. 질병 진행이나 중대한 이상반응으로 효용이 급격히 변할 수 있다면 측정 간격이 길수록 근사오차가 커진다. 따라서 효용 측정 시점은 임상 방문의 편의성만이 아니라 예상되는 건강상태 변화 시점을 고려하여 설계해야 한다.

#### 기저 효용값과 QALY의 보정

무작위배정에도 불구하고 표본에서는 우연한 기저 효용 불균형이 발생할 수 있다. 기저 효용이 높은 환자는 이후 QALY도 높게 나타날 가능성이 있으므로, 기저 효용을 보정하면 치료효과 추정의 정밀도가 향상될 수 있다. 환자 $i$의 총 QALY를 $Q_i$라 하고 기저 효용을 $U_{i0}$라 하면 다음과 같은 회귀모형을 사용할 수 있다.

$$
Q_i=\beta_0+\beta_1Z_i+\beta_2U_{i0}+\boldsymbol\beta_3^TX_i+\varepsilon_i.
$$

여기서 $\beta_1$은 동일한 기저 효용과 공변량 수준에서의 조정된 평균 QALY 차이를 나타낸다. 기저 효용을 보정하는 목적은 무작위배정을 대체하는 것이 아니라 우연한 불균형을 줄이고 정밀도를 높이는 데 있다.

#### 비용 누적과 사건 발생 시점

총 비용은 단순한 합계이지만, 비용이 언제 발생했는지도 중요하다. 환자 $i$의 누적비용 과정을 $C_i(t)$라고 하면 분석기간 동안의 총 비용은 증가과정의 적분으로 나타낼 수 있다.

$$
C_i(\tau)=\int_0^\tau dC_i(t).
$$

입원이나 수술처럼 특정 시점에 큰 비용이 발생하면 $C_i(t)$는 계단형으로 증가한다. 할인은 각 비용이 발생한 시점에 적용되어야 하므로, 연말 총액에 한 번만 할인하는 것보다 사건별 발생시점을 이용하는 것이 이론적으로 정확하다.

분석 기간이 1년을 넘고 할인 적용이 필요하다면 연속시간에서 할인된 비용과 QALY는 다음과 같이 표현할 수 있다.

$$
C_i^{d}(\tau)=\int_0^{\tau}e^{-r_Ct}\,dC_i(t),
$$

$$
Q_i^{d}(\tau)=\int_0^{\tau}e^{-r_Qt}U_i(t)I(T_i>t)\,dt,
$$

여기서 $r_C$와 $r_Q$는 각각 비용과 효과의 연속 할인율이다. 이 장에서는 표기를 단순하게 하기 위해 할인된 총 비용과 총 QALY를 각각 $C_i$, $Q_i$로 쓴다.

위 그림에서 자원사용량은 사건이 발생할 때마다 누적되는 반면, 건강관련 삶의 질은 방문 시점에서 간헐적으로 측정된다. 비용은 사건기록의 완전성이 중요하고 QALY는 방문 사이의 보간가정이 중요하다는 차이가 있다. 사망이나 중도탈락이 발생하면 두 결과 모두 완전하게 관찰되지 않을 수 있으므로, 관찰 종료의 원인을 분석 단계에서 구분해야 한다.

## 임상시험 기반 경제성 평가의 장점과 단점 {#sec-trial-based-pros-cons}

임상시험 기반 경제성 평가는 직관적이고 자료 기반이라는 점에서 강력한 장점을 가진다. 그러나 경제성 평가의 목적이 보건의료 의사결정이라는 점을 고려하면 여러 한계도 존재한다.

### 장점

첫째, 무작위배정의 장점을 활용할 수 있다. 임상시험에서 환자는 치료군과 대조군에 무작위로 배정되므로, 충분히 큰 표본에서는 관찰된 공변량뿐 아니라 관찰되지 않은 공변량도 치료군 간 균형을 이룰 것으로 기대된다. 따라서 비용과 QALY의 평균 차이를 치료전략의 차이로 해석하기 상대적으로 쉽다.

둘째, 개별 환자 수준의 비용과 QALY를 함께 관찰할 수 있다. 경제성 평가에서는 비용과 효과의 상관성이 중요하다. 오래 생존한 환자는 더 많은 치료비를 사용할 수 있지만 동시에 더 많은 QALY를 얻을 수 있다. 개별 환자 자료가 있으면 같은 환자 안에서 관찰된 비용과 QALY의 짝지어진 구조를 분석에 반영할 수 있다.

셋째, 임상적 근거와 경제성 근거가 같은 연구설계에서 생성된다. 동일한 임상시험에서 치료효과, 이상반응, 자원사용량, 삶의 질을 함께 수집하면 경제성 평가의 내부 일관성이 높아진다.

넷째, 통계적 분석이 상대적으로 투명하다. 중도절단이나 결측이 없고 추적기간이 충분하다면 치료군별 평균 비용과 평균 QALY를 직접 계산할 수 있다. 이 경우 경제성 평가 결과는 원자료의 평균 구조와 명확히 연결된다.

다섯째, 비용과 QALY의 경험적 분포를 확인할 수 있다. 비용자료는 흔히 오른쪽 꼬리가 길고, QALY는 분석기간과 생존상태에 의해 상한과 하한을 가진다. 임상시험 원자료가 있으면 이러한 분포적 특성을 직접 확인하고 부트스트랩이나 회귀분석에 반영할 수 있다.

![개별 환자 수준 자료에서는 비용과 QALY가 같은 환자에서 함께 관찰되므로 두 결과의 상관구조를 확인할 수 있다.](figures/ch03/fig-ch03-cost-qaly-scatter.png){width="86%"}


위 산점도에서 각 점은 한 환자의 비용과 QALY 조합이다. 점들의 기울어진 방향은 두 결과의 공분산을 나타낸다. 비용과 QALY가 양의 상관을 가지면 생존기간이 긴 환자가 더 많은 의료자원을 사용하면서 더 많은 QALY를 얻는 구조일 수 있다. 이 상관을 무시하면 증분순편익의 분산과 비용효과평면의 불확실성 영역을 잘못 추정할 수 있다.

경제성 평가의 의사결정 목표는 평균 자원배분이므로 비용분포가 치우쳐 있더라도 평균 비용이 주된 분석대상이다. 중앙값 비용은 전형적인 환자의 비용을 설명하는 데 유용하지만, 전체 예산이나 기대비용을 직접 나타내지는 않는다. 따라서 평균 비용 분석에서 정규성 가정이 불안정할 때는 평균을 다른 위치모수로 바꾸기보다 부트스트랩, 강건 표준오차, 적절한 일반화선형모형을 이용하여 평균의 불확실성을 추정하는 것이 일반적이다.

### 단점

첫째, 임상시험의 추적기간이 경제성 평가에 필요한 분석 기간보다 짧은 경우가 많다. 신약의 비용은 치료 초기에 집중적으로 발생하지만, 생존 이득이나 장기 합병증 예방 효과는 오랜 기간에 걸쳐 나타날 수 있다. 이 경우 임상시험 추적기간만으로는 비용효과성을 충분히 평가하기 어렵다.

둘째, 임상시험 대상자는 실제 진료환경의 환자와 다를 수 있다. 임상시험은 선정기준과 제외기준이 엄격하므로 고령자, 동반질환이 많은 환자, 순응도가 낮은 환자가 배제될 수 있다. 따라서 임상시험 기반 경제성 평가 결과를 실제 급여 대상 인구집단에 그대로 일반화하기 어려울 수 있다.

셋째, 임상시험의 자원사용량이 실제 진료환경과 다를 수 있다. 임상시험에서는 프로토콜에 따라 검사, 방문, 모니터링이 더 자주 이루어질 수 있다. 연구 목적의 자원사용량을 경제성 평가에 그대로 포함하면 실제 의료비를 과대평가할 수 있다. 반대로 임상시험에서 지원된 약제비나 관리비가 실제 급여환경의 비용을 충분히 반영하지 못할 수도 있다.

넷째, 경제성 평가에 필요한 모든 자료가 임상시험에서 수집되지 않을 수 있다. 예를 들어 입원비, 비급여 비용, 간병비, 생산성 손실, 진행 이후 효용값, 장기 생존 이후 의료비, 후기 이상반응 관리 비용 등이 충분히 수집되지 않을 수 있다.

다섯째, 중도절단과 결측 문제가 발생할 수 있다. 특히 비용자료는 사망, 중도탈락, 연구종료 시점 때문에 완전하게 관찰되지 않는 경우가 많다. 이 장에서는 먼저 중도절단이 없는 단순한 상황을 다룬다. 중도절단이 있는 비용과 QALY 추정은 생존분석, inverse probability weighting, multiple imputation, joint modeling 등으로 확장된다.

::: {.callout-important title="실무적 관점"}
임상시험 기반 경제성 평가는 “자료에서 직접 관찰된 비용과 QALY”를 이용한다는 장점이 있다. 그러나 장기 가치, 실제 진료환경의 일반화 가능성, 결측과 중도절단 문제에는 한계가 있다. 많은 의약품 경제성 평가에서 임상시험 기반 분석과 모형 기반 분석을 함께 고려하는 이유가 여기에 있다.
:::

### 임상시험 기반 분석이 적절한 경우

임상시험 기반 경제성 평가는 다음과 같은 경우에 상대적으로 적절하다.

- 질병 경과가 짧고 주요 결과가 임상시험 기간 내에 대부분 관찰되는 경우
- 치료효과가 단기간에 나타나는 경우
- 비용과 QALY가 임상시험 추적기간 내에 충분히 수집된 경우
- 장기 외삽의 필요성이 낮은 경우
- 치료전략 간 차이가 주로 단기 자원사용량과 단기 결과에서 발생하는 경우

예를 들어 급성 감염질환 치료제, 단기 수술기법 비교, 짧은 기간의 증상 개선을 목표로 하는 치료전략 등은 임상시험 기반 경제성 평가가 비교적 자연스럽게 적용될 수 있다. 반대로 암, 만성질환, 심혈관질환, 희귀질환처럼 장기 생존, 재발, 합병증, 질병 진행이 중요한 질환에서는 임상시험 기반 분석만으로 충분하지 않을 가능성이 높다.


### 설명적 임상시험과 실용적 임상시험

임상시험의 설계 목적은 경제성 평가의 일반화 가능성에 직접 영향을 준다. 엄격한 선정기준, 높은 순응도 관리, 집중적인 방문일정을 사용하는 설명적 임상시험은 치료의 효능을 명확히 평가하는 데 유리하지만 실제 진료환경과 차이가 클 수 있다. 반면 실용적 임상시험은 실제 진료환경과 유사한 환자선정, 치료전달, 추적방식을 사용하므로 비용과 자원사용량의 외적 타당도가 상대적으로 높다.

목표 모집단에서의 평균 비용을 $\mathbb{E}_T\{C(z)\}$, 임상시험 모집단에서의 평균 비용을 $\mathbb{E}_S\{C(z)\}$라고 하자. 두 모집단의 공변량 분포가 다르더라도, 치료결과가 공변량 $X$에 조건부로 일반화될 수 있다면 다음과 같은 표준화가 가능하다.

$$
\mathbb{E}_T\{C(z)\}
=
\int
\mathbb{E}\{C\mid Z=z,X=x,S=1\}
\,dF_T(x),
$$

여기서 $S=1$은 임상시험 참여를 의미하고 $F_T(x)$는 목표 모집단의 공변량 분포이다. QALY에도 같은 원리를 적용할 수 있다. 이 식은 임상시험 결과의 일반화가 단순히 표본크기의 문제가 아니라, 결과를 변화시키는 공변량이 두 모집단에서 어떻게 분포하는지의 문제임을 보여준다.

## 중도절단이 없는 경우 ICER의 추정 {#sec-icer-no-censoring}

이 절에서는 가장 기본적인 상황을 다룬다. 임상시험에 등록된 모든 환자에 대해 분석 기간 동안의 총 비용과 총 QALY가 완전히 관찰되었다고 가정한다. 이 경우 치료군별 평균 비용과 평균 QALY를 직접 계산할 수 있다.


직접적인 평균 비교가 인과적 증분비용과 증분효과를 추정하려면 다음 조건이 필요하다.

1. **일관성**: 실제로 치료 $z$를 받은 환자의 관찰결과는 잠재결과 $C_i(z)$와 $Q_i(z)$에 해당한다.
2. **교환가능성**: 무작위배정으로 치료배정이 잠재결과와 독립이다.
3. **양의 확률성**: 분석대상 공변량 수준에서 각 치료를 배정받을 가능성이 존재한다.
4. **간섭 없음**: 한 환자의 치료가 다른 환자의 비용이나 QALY에 영향을 주지 않는다.
5. **완전한 결과 관찰**: 분석기간의 비용과 QALY가 모든 환자에서 관찰된다.

집단수준의 자원제약이나 감염 전파처럼 환자 간 간섭이 존재하는 상황에서는 간섭 없음 가정이 성립하지 않을 수 있다. 또한 군집무작위배정 임상시험에서는 같은 의료기관이나 군집 안 환자의 결과가 상관되므로 독립표본 공식 대신 군집구조를 반영해야 한다.

### 자료 구조와 표본 평균

두 치료전략을 비교하는 무작위배정 임상시험을 생각하자. 신약군의 표본크기를 $n_1$, 대조군의 표본크기를 $n_0$이라고 하자. 신약군 환자 $i$의 비용과 QALY를 각각 $C_{1i}$, $Q_{1i}$라고 쓰고, 대조군 환자 $i$의 비용과 QALY를 각각 $C_{0i}$, $Q_{0i}$라고 쓰자.

신약군의 평균 비용과 평균 QALY는 다음과 같다.

$$
\bar C_1=\frac{1}{n_1}\sum_{i=1}^{n_1}C_{1i},
\qquad
\bar Q_1=\frac{1}{n_1}\sum_{i=1}^{n_1}Q_{1i}.
$$

대조군의 평균 비용과 평균 QALY는 다음과 같다.

$$
\bar C_0=\frac{1}{n_0}\sum_{i=1}^{n_0}C_{0i},
\qquad
\bar Q_0=\frac{1}{n_0}\sum_{i=1}^{n_0}Q_{0i}.
$$

증분비용과 증분효과의 표본 추정량은 다음과 같다.

$$
\widehat{\Delta C}=\bar C_1-\bar C_0,
$$

$$
\widehat{\Delta Q}=\bar Q_1-\bar Q_0.
$$

따라서 ICER의 점 추정량은 다음과 같다.

$$
\widehat{ICER}=\frac{\widehat{\Delta C}}{\widehat{\Delta Q}},
\qquad \widehat{\Delta Q}\neq 0.
$$


여기서 중요한 점은 ICER가 **평균의 차이에 대한 비율**이라는 것이다.

$$
\frac{\mathbb{E}\{C(1)\}-\mathbb{E}\{C(0)\}}
{\mathbb{E}\{Q(1)\}-\mathbb{E}\{Q(0)\}}
\neq
\mathbb{E}\left[
\frac{C(1)-C(0)}{Q(1)-Q(0)}
\right].
$$

오른쪽 식은 개인별 증분비용효과비의 평균이지만, 동일 환자에게 두 치료를 동시에 적용할 수 없으므로 일반적인 평행군 임상시험에서는 직접 관찰할 수도 없다. 정책 의사결정에 필요한 ICER는 왼쪽과 같이 집단 평균 비용 차이를 집단 평균 효과 차이로 나눈 값이다.

::: {.callout-warning title="ICER 추정 시 주의점"}
$\widehat{ICER}$는 두 평균 차이의 비율이다. 따라서 $\widehat{\Delta Q}$가 0에 가까우면 매우 불안정해진다. 또한 증분효과가 음수인 경우 ICER의 부호와 크기만으로는 의사결정 의미를 직관적으로 해석하기 어렵다. 비용효과평면과 순편익 접근법을 함께 사용하는 것이 좋다.
:::

### 예제: 완전 관찰 자료에서 ICER 계산 {.unnumbered}

다음과 같은 임상시험 결과를 생각하자.

| 치료전략 | 표본크기 | 평균 비용 | 평균 QALY |
|---|---:|---:|---:|
| 기존 치료 | 100 | 20,000,000원 | 1.40 |
| 신약 | 100 | 28,000,000원 | 1.72 |

증분비용은 다음과 같다.

$$
\widehat{\Delta C}=28{,}000{,}000-20{,}000{,}000=8{,}000{,}000.
$$

증분효과는 다음과 같다.

$$
\widehat{\Delta Q}=1.72-1.40=0.32.
$$

따라서 ICER는 다음과 같다.

$$
\widehat{ICER}=\frac{8{,}000{,}000}{0.32}=25{,}000{,}000.
$$

즉, 신약은 기존 치료에 비해 QALY 1단위를 추가로 얻기 위해 약 2,500만 원의 추가 비용이 필요한 것으로 추정된다.

### 증분비용과 증분효과의 분산과 공분산

평균 비용과 평균 QALY의 차이는 표본자료에서 추정되므로 불확실성을 가진다. 신약군과 대조군이 서로 독립이라고 하면 증분비용의 분산은 다음과 같이 추정할 수 있다.

$$
\widehat{\operatorname{Var}}(\widehat{\Delta C})
=\frac{s^2_{C,1}}{n_1}+\frac{s^2_{C,0}}{n_0},
$$

여기서 $s^2_{C,1}$과 $s^2_{C,0}$은 각각 신약군과 대조군의 비용 표본분산이다. 증분효과의 분산도 같은 방식으로 추정한다.

$$
\widehat{\operatorname{Var}}(\widehat{\Delta Q})
=\frac{s^2_{Q,1}}{n_1}+\frac{s^2_{Q,0}}{n_0}.
$$

경제성 평가에서는 증분비용과 증분효과를 따로따로 보는 것만으로 충분하지 않다. 비용과 QALY는 같은 환자에서 동시에 관찰되므로 두 값 사이의 공분산도 중요하다. 신약군에서 비용과 QALY의 표본공분산을 $s_{CQ,1}$, 대조군에서의 표본공분산을 $s_{CQ,0}$라고 하면 다음과 같다.

$$
\widehat{\operatorname{Cov}}(\widehat{\Delta C},\widehat{\Delta Q})
=\frac{s_{CQ,1}}{n_1}+\frac{s_{CQ,0}}{n_0}.
$$

따라서 증분 추정량 벡터를 다음과 같이 정의하면,

$$
\widehat{\boldsymbol\delta}
=\begin{pmatrix}
\widehat{\Delta C} \\
\widehat{\Delta Q}
\end{pmatrix},
$$

그 분산-공분산 행렬은 다음과 같이 추정할 수 있다.

$$
\widehat{\boldsymbol\Sigma}
=\begin{pmatrix}
\widehat V_C & \widehat V_{CQ} \\
\widehat V_{CQ} & \widehat V_Q
\end{pmatrix},
$$

여기서

$$
\widehat V_C=\widehat{\operatorname{Var}}(\widehat{\Delta C}),
\qquad
\widehat V_Q=\widehat{\operatorname{Var}}(\widehat{\Delta Q}),
\qquad
\widehat V_{CQ}=\widehat{\operatorname{Cov}}(\widehat{\Delta C},\widehat{\Delta Q}).
$$

표본크기가 충분히 크면 중심극한정리에 의해 다음의 근사분포를 사용할 수 있다.

$$
\widehat{\boldsymbol\delta}
\approx
N\left(
\begin{pmatrix}
\Delta C \\
\Delta Q
\end{pmatrix},
\boldsymbol\Sigma
\right).
$$

이 근사분포는 비용효과평면, 순편익 신뢰구간, 비용효과수용곡선의 이론적 기초가 된다.


두 치료군의 평균벡터를 각각 $\bar{\mathbf Y}_z=(\bar C_z,\bar Q_z)^T$라고 하면,

$$
\widehat{\boldsymbol\delta}
=
\bar{\mathbf Y}_1-\bar{\mathbf Y}_0
$$

이고 독립적인 평행군 설계에서는

$$
\operatorname{Var}(\widehat{\boldsymbol\delta})
=
\frac{\boldsymbol\Sigma_1}{n_1}
+
\frac{\boldsymbol\Sigma_0}{n_0}.
$$

이 식은 앞의 분산과 공분산 공식을 행렬 형태로 표현한 것이다. 비용과 QALY를 별개의 단변량 결과로 취급하지 않고 이변량 결과로 다루면 공동 신뢰영역을 구성할 수 있다. 대규모 표본에서 다음 이차형식은 근사적으로 자유도 2인 카이제곱분포를 따른다.

$$
(\widehat{\boldsymbol\delta}-\boldsymbol\delta)^T
\widehat{\boldsymbol\Sigma}^{-1}
(\widehat{\boldsymbol\delta}-\boldsymbol\delta)
\approx \chi^2_2.
$$

따라서 비용효과평면의 타원형 신뢰영역은 다음 조건을 만족하는 점들의 집합이다.

$$
(\boldsymbol\delta-\widehat{\boldsymbol\delta})^T
\widehat{\boldsymbol\Sigma}^{-1}
(\boldsymbol\delta-\widehat{\boldsymbol\delta})
\le \chi^2_{2,1-\alpha}.
$$

타원의 방향과 폭은 비용과 QALY의 공분산에 의해 결정된다. 공분산이 양수이면 불확실성 영역이 오른쪽 위와 왼쪽 아래 방향으로 기울어질 수 있다.

### 비용효과평면에서의 불확실성

ICER는 하나의 점 추정값이지만, 실제로는 증분비용과 증분효과 모두 불확실하다. 따라서 경제성 평가에서는 $(\widehat{\Delta Q},\widehat{\Delta C})$를 비용효과평면에 표시한다. 비용효과평면의 가로축은 증분효과, 세로축은 증분비용이다.

| 사분면 | 의미 | 의사결정 해석 |
|---|---|---|
| 오른쪽 위 | 더 효과적이고 더 비쌈 | ICER 또는 INB로 판단 |
| 오른쪽 아래 | 더 효과적이고 더 저렴함 | 신약이 우월전략 |
| 왼쪽 위 | 덜 효과적이고 더 비쌈 | 신약이 열등전략 |
| 왼쪽 아래 | 덜 효과적이고 더 저렴함 | 비용 절감과 효과 감소의 trade-off 판단 |

![비용효과평면은 증분효과와 증분비용의 부호 조합을 의사결정 관점에서 해석하게 해준다.](figures/ch03/fig-ch03-ce-plane-basic.png){width="84%"}


위 그림의 원점은 두 치료전략의 평균 비용과 평균 효과가 동일한 지점이다. 점이 원점에서 멀수록 증분 차이의 절대적 크기가 크지만, 비용효과성은 거리만으로 판단하지 않는다. 오른쪽 위와 왼쪽 아래 사분면에서는 지불의사금액에 따라 결론이 달라지고, 오른쪽 아래와 왼쪽 위 사분면에서는 우월전략과 열등전략 관계가 직접 결정된다.

지불의사금액 $\lambda$가 주어지면 비용효과평면에서 의사결정 기준선은 다음 직선으로 표현된다.

$$
\Delta C=\lambda \Delta Q.
$$

점 $(\Delta Q,\Delta C)$가 이 직선 아래에 있으면 $\lambda\Delta Q-\Delta C>0$이므로 신약이 비용효과적이다. 점이 직선 위에 있으면 두 전략의 순편익이 동일하고, 직선 위쪽에 있으면 신약의 증분순편익이 음수이다. 이 해석은 순편익 접근법과 직접 연결된다.

비용효과평면의 불확실성을 사분면별 확률로도 요약할 수 있다. 예를 들어 부트스트랩 반복값 중 오른쪽 아래 사분면에 위치한 비율은 신약이 더 효과적이고 더 저렴하게 추정되는 반복의 비율이다. 그러나 사분면 확률은 지불의사금액을 반영하지 않으므로 최종 판단에는 순편익 또는 CEAC가 필요하다.

### Delta method를 이용한 ICER의 근사 표준오차

ICER는 $g(\Delta C,\Delta Q)=\Delta C/\Delta Q$로 정의되는 비선형 함수이다. $\Delta Q$가 0에서 충분히 떨어져 있고 표본크기가 충분히 크다면 delta method를 이용하여 $\widehat{ICER}$의 근사분산을 계산할 수 있다.

함수 $g(c,q)=c/q$의 기울기 벡터는 다음과 같다.

$$
\nabla g(c,q)=
\begin{pmatrix}
\partial g/\partial c \\
\partial g/\partial q
\end{pmatrix}
=
\begin{pmatrix}
1/q \\
-c/q^2
\end{pmatrix}.
$$

따라서 $\widehat{ICER}$의 근사분산은 다음과 같다.

$$
\widehat{\operatorname{Var}}(\widehat{ICER})
\approx
\widehat{\nabla g}^{T}\widehat{\boldsymbol\Sigma}\widehat{\nabla g},
$$

여기서

$$
\widehat{\nabla g}=
\begin{pmatrix}
1/\widehat{\Delta Q} \\
-\widehat{\Delta C}/\widehat{\Delta Q}^{2}
\end{pmatrix}.
$$

이를 전개하면 다음과 같다.

$$
\widehat{\operatorname{Var}}(\widehat{ICER})
\approx
\frac{\widehat V_C}{\widehat{\Delta Q}^{2}}
+
\frac{\widehat{\Delta C}^{2}\widehat V_Q}{\widehat{\Delta Q}^{4}}
-
\frac{2\widehat{\Delta C}\widehat V_{CQ}}{\widehat{\Delta Q}^{3}}.
$$

이 식은 ICER의 표준오차를 계산하는 데 유용하지만, $\widehat{\Delta Q}$가 0에 가까운 경우 매우 불안정하다. 그래서 실무에서는 ICER 자체의 신뢰구간보다 비용효과평면, 순편익, 부트스트랩 결과를 더 중시하는 경우가 많다.


Delta method는 $g(c,q)=c/q$를 참값 주변에서 1차 Taylor 전개하는 방법이다.

$$
g(\widehat{\boldsymbol\delta})
\approx
g(\boldsymbol\delta)
+
\nabla g(\boldsymbol\delta)^T
(\widehat{\boldsymbol\delta}-\boldsymbol\delta).
$$

따라서 이 방법이 안정적이려면 증분효과의 참값이 0에서 충분히 떨어져 있고, 표본분포가 국소적으로 정규분포에 가까워야 한다. 증분효과의 신뢰구간이 0을 포함하면 비율함수의 불연속점이 추론범위 안에 들어오므로 대칭적인 Wald 신뢰구간은 부적절할 수 있다.

### Fieller 접근의 아이디어

ICER의 신뢰구간을 다룰 때 delta method보다 원리에 더 충실한 접근은 Fieller 방식이다. 어떤 후보 ICER 값 $k$가 참값으로 가능한지를 보려면 다음 식을 생각할 수 있다.

$$
\Delta C-k\Delta Q=0.
$$

따라서 표본에서 다음 통계량을 구성한다.

$$
T(k)=
\frac{\widehat{\Delta C}-k\widehat{\Delta Q}}
{\sqrt{\widehat V_C-2k\widehat V_{CQ}+k^2\widehat V_Q}}.
$$

근사적으로 $|T(k)|\le z_{1-\alpha/2}$를 만족하는 모든 $k$의 집합을 ICER의 $(1-\alpha)$ 신뢰집합으로 볼 수 있다.

$$
\left\{k:
\frac{(\widehat{\Delta C}-k\widehat{\Delta Q})^2}
{\widehat V_C-2k\widehat V_{CQ}+k^2\widehat V_Q}
\le z_{1-\alpha/2}^{2}
\right\}.
$$

이 집합은 일반적인 닫힌 구간일 수도 있지만, 무한 구간이거나 두 개의 분리된 구간이 될 수도 있다. 이러한 현상은 ICER가 비율이고 분모인 $\Delta Q$의 불확실성이 크기 때문에 발생한다.


Fieller 부등식의 양변을 정리하면 $k$에 대한 이차부등식이 된다.

$$
Ak^2+Bk+D\le 0,
$$

여기서

$$
A=\widehat{\Delta Q}^2-z^2\widehat V_Q,
$$

$$
B=-2\left(\widehat{\Delta C}\widehat{\Delta Q}
-z^2\widehat V_{CQ}\right),
$$

$$
D=\widehat{\Delta C}^2-z^2\widehat V_C,
$$

이며 $z=z_{1-\alpha/2}$이다. $A>0$이고 판별식이 양수이면 일반적인 유한구간이 얻어진다. 반면 $A\le 0$이면 증분효과가 0에서 충분히 분리되어 있지 않다는 의미이며, 신뢰집합이 무한하거나 분리될 수 있다. 이는 계산 오류가 아니라 자료가 유한한 ICER 범위를 지지하지 못한다는 통계적 신호이다.

::: {.callout-tip title="순편익 접근법이 선호되는 이유"}
ICER의 신뢰구간은 분모가 0 근처일 때 해석이 까다롭다. 반면 순편익은 $INB(\lambda)=\lambda\Delta Q-\Delta C$처럼 선형 함수이므로 표준오차, 신뢰구간, 회귀분석, 부트스트랩을 적용하기 쉽다.
:::

### 부트스트랩을 이용한 불확실성 평가

임상시험 기반 경제성 평가에서 비용과 QALY의 불확실성을 평가하는 가장 직관적인 방법 중 하나는 부트스트랩이다. 부트스트랩은 원자료에서 환자를 반복적으로 재표본추출하여 각 반복에서 증분비용과 증분효과를 다시 계산하는 방법이다.

중요한 점은 비용과 QALY를 따로 재표본추출하지 않고, 같은 환자의 비용과 QALY 쌍을 함께 재표본추출해야 한다는 것이다. 그래야 환자 수준의 상관구조가 보존된다.

![부트스트랩에서는 치료군별로 환자를 복원추출하고, 각 반복에서 증분비용과 증분효과를 다시 계산한다.](figures/ch03/fig-ch03-bootstrap-procedure.png){width="95%"}


위 그림의 핵심은 치료군별 층화 재표본추출이다. 전체 환자를 한꺼번에 재표본추출하면 반복마다 치료군 표본크기가 달라질 수 있으므로, 원래 무작위배정 구조를 유지하려면 각 군에서 별도로 환자를 복원추출하는 것이 일반적이다. 비용과 QALY뿐 아니라 환자 식별자에 연결된 모든 공변량과 결과를 하나의 묶음으로 추출해야 한다.

부트스트랩 절차는 다음과 같다.

1. 신약군에서 $n_1$명을 복원추출한다.
2. 대조군에서 $n_0$명을 복원추출한다.
3. 각 재표본에서 평균 비용과 평균 QALY를 계산한다.
4. $\widehat{\Delta C}^{(b)}$, $\widehat{\Delta Q}^{(b)}$, $\widehat{ICER}^{(b)}$, $\widehat{INB}^{(b)}(\lambda)$를 계산한다.
5. 이 과정을 $b=1,\ldots,B$번 반복한다.
6. 반복 결과를 비용효과평면, 신뢰구간, 비용효과수용곡선으로 요약한다.


개별 무작위배정 임상시험에서는 환자가 재표본추출 단위이다. 군집무작위배정 임상시험에서는 환자가 아니라 군집을 재표본추출해야 군집 내 상관이 보존된다. 반복측정 원자료를 사용하는 경우에도 방문별 관측치를 따로 추출하지 않고 환자 단위로 전체 추적자료를 함께 추출해야 한다.

백분위수 부트스트랩 신뢰구간은 부트스트랩 분포의 $\alpha/2$와 $1-\alpha/2$ 분위수를 사용한다. 편향이나 비대칭성이 큰 경우에는 편향보정 가속 신뢰구간을 고려할 수 있지만, ICER처럼 분모가 0을 지날 수 있는 비율에서는 어떤 단일 구간도 비용효과평면의 공동 불확실성을 완전히 대체하지 못한다.

![부트스트랩 반복값을 비용효과평면에 표시하면 증분비용과 증분효과의 공동 불확실성을 확인할 수 있다. 점선은 QALY당 3,000만 원 기준선이다.](figures/ch03/fig-ch03-bootstrap-ce-plane.png){width="88%"}


위 그림에서 점들이 어느 사분면에 분포하는지뿐 아니라 지불의사금액 기준선의 어느 쪽에 놓이는지를 함께 보아야 한다. 점선 아래의 반복은 해당 지불의사금액에서 증분순편익이 양수인 반복이다. 점구름이 넓게 퍼질수록 비용과 효과의 공동 불확실성이 크며, 원점을 가로지르면 우월성 또는 열등성의 방향 자체도 불확실하다는 뜻이다.

### 순편익 접근법

ICER는 널리 사용되지만 통계적으로 다루기 까다롭다. 이 문제를 완화하기 위해 순편익 접근법을 사용할 수 있다. 지불의사금액을 $\lambda$라고 하면 치료전략 $z$의 순편익은 다음과 같이 정의된다.

$$
NB_z(\lambda)=\lambda Q_z-C_z.
$$

두 치료전략의 증분순편익은 다음과 같다.

$$
INB(\lambda)=\lambda\Delta Q-\Delta C.
$$

표본자료에서는 다음과 같이 추정한다.

$$
\widehat{INB}(\lambda)
=\lambda\widehat{\Delta Q}-\widehat{\Delta C}.
$$

$\widehat{INB}(\lambda)>0$이면 해당 지불의사금액에서 신약의 추가 QALY 가치가 추가 비용보다 크다고 해석한다.

앞의 예제에서 $\widehat{\Delta Q}=0.32$, $\widehat{\Delta C}=8{,}000{,}000$이고, 지불의사금액이 QALY당 30,000,000원이라고 하자. 그러면 증분순편익은 다음과 같다.

$$
\widehat{INB}(30{,}000{,}000)
=30{,}000{,}000\times0.32-8{,}000{,}000
=1{,}600{,}000.
$$

즉, QALY당 3,000만 원 기준에서 신약의 증분순편익은 160만 원으로 양수이다.

순편익의 분산은 증분비용과 증분효과의 분산-공분산으로부터 다음과 같이 계산한다.

$$
\widehat{\operatorname{Var}}\{\widehat{INB}(\lambda)\}
=\lambda^2\widehat V_Q+
\widehat V_C-2\lambda\widehat V_{CQ}.
$$

따라서 근사적인 95% 신뢰구간은 다음과 같다.

$$
\widehat{INB}(\lambda)
\pm
1.96\sqrt{\widehat{\operatorname{Var}}\{\widehat{INB}(\lambda)\}}.
$$

![지불의사금액이 증가하면 증분순편익은 선형적으로 증가한다. 증분순편익이 0이 되는 지점은 ICER와 같다.](figures/ch03/fig-ch03-inb-by-lambda.png){width="86%"}


위 그림에서 직선의 절편은 $-\Delta C$이고 기울기는 $\Delta Q$이다. 증분효과가 양수이면 지불의사금액이 증가할수록 증분순편익이 커지고, 증분효과가 음수이면 반대로 감소한다. $\Delta Q>0$인 경우 직선이 0을 통과하는 지불의사금액은 $\Delta C/\Delta Q$이므로 ICER와 일치한다. 다만 $\Delta Q<0$인 경우에는 같은 교차점을 단순히 비용효과성 임계값으로 해석해서는 안 되고 사분면을 함께 확인해야 한다.

### 개별 환자 수준 순편익과 회귀분석

임상시험 기반 분석에서는 개별 환자 수준에서 순편익을 정의할 수도 있다. 환자 $i$의 순편익은 다음과 같다.

$$
NB_i(\lambda)=\lambda Q_i-C_i.
$$

치료군별 평균 순편익을 계산하면 다음과 같다.

$$
\bar{NB}_1(\lambda)=\frac{1}{n_1}\sum_{i=1}^{n_1}\left(\lambda Q_{1i}-C_{1i}\right),
$$

$$
\bar{NB}_0(\lambda)=\frac{1}{n_0}\sum_{i=1}^{n_0}\left(\lambda Q_{0i}-C_{0i}\right).
$$

증분순편익은 두 평균의 차이이다.

$$
\widehat{INB}(\lambda)=\bar{NB}_1(\lambda)-\bar{NB}_0(\lambda).
$$

이는 앞에서 정의한 $\lambda\widehat{\Delta Q}-\widehat{\Delta C}$와 동일하다. 이 접근은 회귀분석으로 자연스럽게 확장된다. 치료군 지시변수 $Z_i$를 사용하여 다음 회귀모형을 적합할 수 있다.

$$
NB_i(\lambda)=\alpha_0+\alpha_1Z_i+\epsilon_i.
$$

이때 $\alpha_1$은 해당 $\lambda$에서의 증분순편익이다. 공변량 $X_i$를 보정하고 싶다면 다음과 같이 확장한다.

$$
NB_i(\lambda)=\alpha_0+\alpha_1Z_i+\boldsymbol\alpha_2^{T}X_i+\epsilon_i.
$$

무작위배정 임상시험에서는 공변량 보정이 필수는 아니지만, 기저치 불균형을 조정하거나 추정의 정밀도를 높이기 위해 사용할 수 있다. 비용자료의 분산이 크거나 오른쪽 꼬리가 긴 경우에는 robust standard error나 bootstrap confidence interval을 함께 사용하는 것이 좋다.


비용과 QALY를 각각 회귀분석할 때는 두 오차항의 상관을 허용할 수 있다.

$$
C_i=\alpha_C+\beta_CZ_i+\boldsymbol\gamma_C^TX_i+\varepsilon_{Ci},
$$

$$
Q_i=\alpha_Q+\beta_QZ_i+\boldsymbol\gamma_Q^TX_i+\varepsilon_{Qi},
$$

$$
\operatorname{Cov}(\varepsilon_{Ci},\varepsilon_{Qi})\neq 0.
$$

두 식을 동시에 적합하는 seemingly unrelated regression은 비용과 QALY의 잔차 상관을 명시적으로 반영한다. 동일한 설명변수를 두 식에 사용하는 단순한 경우 점추정치는 개별 최소제곱 추정치와 같을 수 있지만, 공동 공분산과 순편익의 표준오차를 일관되게 계산하는 데 유용하다.

회귀모형에서 얻은 조정된 증분효과를 $\widehat\beta_Q$, 조정된 증분비용을 $\widehat\beta_C$라고 하면 조정된 증분순편익은

$$
\widehat{INB}_{adj}(\lambda)
=
\lambda\widehat\beta_Q-\widehat\beta_C
$$

이며 그 분산은

$$
\operatorname{Var}\{\widehat{INB}_{adj}(\lambda)\}
=
\lambda^2\operatorname{Var}(\widehat\beta_Q)
+
\operatorname{Var}(\widehat\beta_C)
-
2\lambda\operatorname{Cov}(\widehat\beta_Q,\widehat\beta_C)
$$

로 계산된다.

### 비용효과수용곡선

부트스트랩 결과를 이용하면 지불의사금액 $\lambda$별로 신약이 비용효과적일 확률을 추정할 수 있다. $b=1,\ldots,B$번째 부트스트랩 반복에서 증분비용과 증분효과를 각각 $\widehat{\Delta C}^{(b)}$, $\widehat{\Delta Q}^{(b)}$라고 하자. 그러면 $\lambda$에서 비용효과적일 확률은 다음과 같이 추정할 수 있다.

$$
\widehat{CEAC}(\lambda)
=\frac{1}{B}\sum_{b=1}^{B}
I\left(\lambda\widehat{\Delta Q}^{(b)}-\widehat{\Delta C}^{(b)}>0\right).
$$

여기서 $I(\cdot)$는 조건이 참이면 1, 거짓이면 0을 가지는 지시함수이다. $\widehat{CEAC}(\lambda)$를 여러 $\lambda$ 값에 대해 계산하여 그린 곡선을 비용효과수용곡선이라고 한다.

![비용효과수용곡선은 지불의사금액별로 신약이 비용효과적인 부트스트랩 반복의 비율을 보여준다.](figures/ch03/fig-ch03-ceac.png){width="86%"}


위 그림의 가로축은 의사결정자의 지불의사금액이고 세로축은 신약의 증분순편익이 양수로 추정되는 비율이다. 곡선이 0.5를 넘는 지점은 신약이 비용효과적으로 추정되는 반복이 절반을 넘는 지점이지만, 이를 자동적인 채택기준으로 해석해서는 안 된다. 실제 결정은 기대순편익의 크기, 예산영향, 형평성, 실행 가능성 등을 함께 고려한다.

::: {.callout-note title="CEAC 해석"}
비용효과수용곡선은 특정 지불의사금액에서 신약이 비용효과적으로 보이는 불확실성 요약이다. 빈도론적 부트스트랩에서는 “자료 생성과 표본추출의 반복에서 비용효과적 결론이 나올 비율”로 해석하는 것이 자연스럽다. 베이지안 분석에서는 모수의 사후분포하에서 신약이 비용효과적일 사후확률로 해석할 수 있다.
:::


#### CEAC가 제공하지 않는 정보

CEAC는 비용효과성의 **확률적 불확실성**을 보여주지만 순편익의 크기는 보여주지 않는다. 예를 들어 비용효과적일 확률이 0.9인 치료라도 기대 증분순편익이 매우 작을 수 있고, 반대로 비용효과적일 확률이 0.6이지만 기대 증분순편익이 클 수 있다. 따라서 CEAC는 기대순편익 곡선과 함께 해석하는 것이 바람직하다.

전략이 두 개보다 많을 때는 각 지불의사금액에서 기대순편익이 가장 큰 전략을 먼저 찾는다.

$$
z^*(\lambda)
=
\arg\max_z
\mathbb{E}\{NB_z(\lambda)\}.
$$

비용효과수용경계는 이 최적 전략이 실제로 가장 높은 순편익을 가질 확률을 나타낸다. 여러 전략의 CEAC를 각각 비교하는 것만으로는 기대순편익이 최대인 전략을 정확히 식별하지 못할 수 있다.

의사결정 불확실성의 경제적 가치는 완전정보 기대가치로 연결된다. 환자 1인당 완전정보 기대가치는 다음과 같다.

$$
EVPI(\lambda)
=
\mathbb{E}\left[\max_z NB_z(\lambda)\right]
-
\max_z\mathbb{E}\left[NB_z(\lambda)\right].
$$

첫 번째 항은 불확실한 참값을 완전히 안 뒤 최적 전략을 선택할 때의 기대순편익이고, 두 번째 항은 현재 정보에서 선택한 전략의 기대순편익이다. 두 항의 차이는 추가 연구로 모든 불확실성을 제거할 수 있을 때 얻을 수 있는 최대 기대가치이다.

| 분석대상군 | ITT, per-protocol, 실제 치료군 중 어떤 분석대상군을 사용했는가? |
| 기저치 보정 | 기저 효용과 주요 예후변수를 어떻게 보정했는가? |
| 공동 불확실성 | 비용과 QALY의 공분산을 분석과 부트스트랩에 반영했는가? |
| 군집 구조 | 다기관 또는 군집무작위 설계의 상관구조를 반영했는가? |


경제성 평가 결과는 점추정치만으로 충분하지 않다. 치료군별 표본수, 평균 비용과 평균 QALY, 증분 추정치, 불확실성 구간, 비용효과평면, 지불의사금액별 순편익을 함께 제시해야 한다. 비용과 QALY의 수집기간이 다르거나 분석대상군이 임상효과 분석과 다르면 그 이유를 명시해야 한다. 또한 임상시험계획서에 경제성 평가 분석계획이 사전 규정되었는지, 사후 분석인지도 구분해야 한다.


## 핵심 수식 정리 {.unnumbered}

| 개념 | 수식 |
|---|---|
| 기대비용 | $\mu_{C,z}=\mathbb{E}\{C(z)\}$ |
| 기대 QALY | $\mu_{Q,z}=\mathbb{E}\{Q(z)\}$ |
| 증분비용 | $\Delta C=\mu_{C,1}-\mu_{C,0}$ |
| 증분효과 | $\Delta Q=\mu_{Q,1}-\mu_{Q,0}$ |
| ICER | $ICER=\Delta C/\Delta Q$ |
| 평균 비용 추정량 | $\bar C_z=n_z^{-1}\sum_i C_{zi}$ |
| 평균 QALY 추정량 | $\bar Q_z=n_z^{-1}\sum_i Q_{zi}$ |
| 증분비용 분산 | $\widehat V_C=s^2_{C,1}/n_1+s^2_{C,0}/n_0$ |
| 증분효과 분산 | $\widehat V_Q=s^2_{Q,1}/n_1+s^2_{Q,0}/n_0$ |
| 증분비용-효과 공분산 | $\widehat V_{CQ}=s_{CQ,1}/n_1+s_{CQ,0}/n_0$ |
| 순편익 | $NB_z(\lambda)=\lambda Q_z-C_z$ |
| 증분순편익 | $INB(\lambda)=\lambda\Delta Q-\Delta C$ |
| 증분순편익 분산 | $\lambda^2\widehat V_Q+\widehat V_C-2\lambda\widehat V_{CQ}$ |
| CEAC | $B^{-1}\sum_{b=1}^{B}I\{\lambda\widehat{\Delta Q}^{(b)}-\widehat{\Delta C}^{(b)}>0\}$ |


위 표는 본문에서 사용한 기호를 빠르게 확인하기 위한 수식 참조표이다. 실제 해석에서는 각 식의 적용조건, 특히 완전 관찰, 무작위배정, 비용과 QALY의 공동분포, 증분효과가 0에 가까운지 여부를 함께 확인해야 한다.

### 분산-공분산과 순편익 신뢰구간 {.unnumbered}

#| label: ch03-practice-variance
#| eval: true
#| warning: false
#| message: false

new <- trial_data[trial_data$arm == "New drug", ]
ctl <- trial_data[trial_data$arm == "Control", ]

v_c <- var(new$cost) / nrow(new) + var(ctl$cost) / nrow(ctl)
v_q <- var(new$qaly) / nrow(new) + var(ctl$qaly) / nrow(ctl)
v_cq <- cov(new$cost, new$qaly) / nrow(new) + cov(ctl$cost, ctl$qaly) / nrow(ctl)

var_inb <- lambda^2 * v_q + v_c - 2 * lambda * v_cq
se_inb <- sqrt(var_inb)
ci_inb <- inb + c(-1, 1) * 1.96 * se_inb

variance_table <- data.frame(
  quantity = c("V_C", "V_Q", "V_CQ", "SE(INB)", "INB lower 95%", "INB upper 95%"),
  value = c(v_c, v_q, v_cq, se_inb, ci_inb[1], ci_inb[2])
)

variance_table

set.seed(2026)

boot <- matrix(NA_real_, nrow = B, ncol = 3)
colnames(boot) <- c("delta_q", "delta_c", "inb")

for (b in seq_len(B)) {
  boot_new <- new[sample(seq_len(nrow(new)), nrow(new), replace = TRUE), ]
  boot_ctl <- ctl[sample(seq_len(nrow(ctl)), nrow(ctl), replace = TRUE), ]

  dq <- mean(boot_new$qaly) - mean(boot_ctl$qaly)
  dc <- mean(boot_new$cost) - mean(boot_ctl$cost)

  boot[b, "delta_q"] <- dq
  boot[b, "delta_c"] <- dc
  boot[b, "inb"] <- lambda * dq - dc
}

boot_df <- as.data.frame(boot)

plot(
  boot_df$delta_q,
  boot_df$delta_c / 1000000,
  pch = 16,
  col = rgb(0, 0, 0, 0.25),
  xlab = "Incremental QALY",
  ylab = "Incremental cost (million KRW)",
  main = "Cost-effectiveness plane"
)
abline(h = 0, v = 0, lty = 2)
abline(a = 0, b = lambda / 1000000, lty = 3, lwd = 2)
