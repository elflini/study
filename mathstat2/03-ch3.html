3  이산확률변수의 기대값

3.1 평균

  • 정의: \(X\)의 기대값은 기대값이 존재할 때 \(E(X) \overset{def}= \displaystyle\sum_{x \in S} xf_X(x)\)로 정의한다.

  • 대안적 정의: \(E(X) \overset{def}= \displaystyle\sum_{\omega \in \Omega} X(\omega)P(\omega)\) 기대값이 존재하면.

  • 기대값의 성질: \(a\), \(b\), \(c\)를 상수라고 하자. 그러면

    • \(E(c) = c\).
    • \(E(aX + c) = aE(X) + c\) 기대값이 존재하면.
    • \(E(X + Y) = E(X) + E(Y)\) 기대값들이 존재하면.
    • \(E(aX + bY + c) = aE(X) + bE(Y) + c\) 기대값들이 존재하면.
    • 증명: 기대값들이 존재한다고 가정하자. 그러면,

\[ \begin{align} E(aX + bY + c) &= \displaystyle\sum_{\omega \in \Omega}[aX(\omega) + bY(\omega) + c] P(\omega) \\ &= a \displaystyle\sum_{\omega \in \Omega} X(\omega) P(\omega) + b \displaystyle\sum_{\omega \in \Omega} Y(\omega) P(\omega) + c \displaystyle\sum_{\omega \in \Omega} P(\omega) \\ &= aE(X) + bE(Y) + c. \end{align} \]

  • 예제
    • \(X_i \text{ for } i = 1, \dots , n\)이 확률변수이면 \(E \Bigg( \displaystyle\sum_{i=1}^n X_i \Bigg) = \displaystyle\sum_{i=1}^n E(X_i)\)이다.
    • 예제: 크랩스 게임을 한 판에 \(\$1\)씩 100번 한다. \(X_i\)를 \(i\)번째 게임에서 딴 금액이라고 하자. 총 기대수익을 구하라.

\[ X_i = \begin{cases} 1 & \text{ 게임 } i \text{에서 이기면, } \\ -1 & \text{ 게임 } i \text{에서 지면. } \end{cases} \]

  • More 예제: \(f_{X,Y} (i, j) = 2(i + 2j)/[3n(n + 1)^2] \text{ for } i = 0, \dots , n \text{ 그리고 } j = 0, \dots , n\).
    • 다음을 보일 수 있다: \(f_X (i) = 2(i + n)/[3n(n + 1)] \text{ for } i = 0, \dots , n \text{ and that } f_Y (j) = (n + 4j)/[3n(n + 1)] \text{ for } j = 0, \dots , n\).
    • 따라서,

\[ E(X) = \displaystyle\sum_{i = 0}^n \frac{2(i^2 + ni)}{3n(n + 1)} = \frac{5n + 1}{9} \text{ 그리고 } E(Y) = \displaystyle\sum_{i = 0}^n \frac{nj + 4j^2}{3n(n + 1)} = \frac{11n + 4}{18}. \]

  • 위 결과를 확인하려면 다음을 사용한다: \(\displaystyle\sum_{i = 0}^n i^2= n(n + 1)(2n + 1)/6\).

  • 무게중심 해석:

    • \(E(X)\)를 \(\mu\)로 나타내자.
    • 그러면, \(E(X − \mu) = 0\).
    • 양의 편차의 합과 음의 편차의 합은 절댓값이 같다.
    • 분포가 균형을 이루도록 하려면 받침점을 \(\mu\)에 둔다.

  • 대칭분포.

    • \(X\)의 분포가 다음을 만족하면 \(a\)를 중심으로 대칭이라고 한다: \(f_X (a − y) = f_X (a + y) \text{ 모든 } y\).
    • 다음과 같이 가정하자: \(f_X (a − y) = f_X (a + y) \text{ 모든 } y\). 그러면, \(E(X) = a\).
    • 증명: 먼저, 대칭성은 다음을 의미함에 주목하자:

\[ a − y \in S_X \Leftrightarrow a + y \in S_X. \]

  • \(X\)의 기대값은

\[ E(X) = \sum_{x \in S_X} xf_X(x) = \sum_{x \in S_X, x ＜ a} xf_X(x) + af_X(a) + \sum_{x \in S_X, x ＞ a} xf_X(x). \]

  • \(x\)를 다음과 같이 쓰자: \(x = (a − y)\) 첫 번째 합에서.
    • 그러면 \(a − y < a \Leftrightarrow y > 0\).
    • \(x\)를 다음과 같이 쓰자: \(a + y\) 두 번째 합에서. 그러면, \(a + y > a \Leftrightarrow y > 0\).
    • 따라서, the expectation is

\[ \begin{align} E(X) &= \displaystyle\sum_{a - y \in S_X, y ＞ 0} (a - y)f_X(a - y) + af_X(a) + \displaystyle\sum_{a + y \in S_X, y ＞ 0} (a + y)f_X(a + y) \\ &= \displaystyle\sum_{a - y \in S_X, y ＞ 0} (a - y + a + y)f_X(a - y) + af_X(a) \\ \text{ 왜냐하면 } a - y \in S_X &\Leftrightarrow a + y \in S_X \text{ 그리고 } f_X(a - y) = f_X(a + Y) \\ &= 2a \displaystyle\sum_{a - y \in S_X, y ＞ 0} f_X(a - y) + af_X(a) \\ &= a \displaystyle\sum_{a - y \in S_X, y ＞ 0} f_X(a - y) + af_X(a) + a \displaystyle\sum_{a + y \in S_X , y ＞ 0} f_X(a + y) \\ \text{ 왜냐하면 } a - y \in S_X &\Leftrightarrow a + y \in S_X \text{ 그리고 } f_X(a - y) = f_X(a + Y) \\ &= a \displaystyle\sum_{x \in S_X , x ＜ a} f_X(x) + af_X(a) + a \displaystyle\sum_{x \in S_X , x ＞ a} f_X(x) \\ &= a \Bigg[ \displaystyle\sum_{x \in S_X , x ＜ a} f_X(x) + f_X(a) + \displaystyle\sum_{x \in S_X , x ＞ a} f_X(x) \Bigg] \\ &= a \displaystyle\sum_{x \in S_X} f_X(x) = a × 1 = a. \end{align} \]

  • \(E(X)\) 존재하지 않을 수도 있다.
    • 예제: 더블 오어 낫싱 도박.
    • 이길 확률이 다음과 같은 게임을 한다: \(\theta\).
    • 게임에 \(\$1\)를 건다.
    • 이기면 \(\$2\)를 받는다.
    • 지면 판돈을 두 배로 올려 다시 한다. 이길 때까지 게임을 계속한다.
    • \(X\)를 최종적으로 이기기 전까지 건 총액이라고 하자. \(E(X)\)를 구하라.
    • 풀이: \(i\)번째 게임에서 이길 확률은 처음 \(i-1\)번의 게임에서 모두 지고 \(i\)번째 게임에서 이길 확률이다.
    • 게임들은 독립이므로 이 확률은 \((1 − \theta)^{i−1}\theta\).
    • \(X\)의 지지집합은

\[ S_X = \{1, 3, 7, 15, 31, \dots\} = \{2^1 − 1, 2^2 − 1, 2^3 − 1, 2^4 − 1, \dots\}. \]

  • 예를 들어 3번째 게임에서 이기면, 1번째 게임에 \(\$1\), 2번째 게임에 \(\$2\), 3번째 게임에 \(\$4\)를 건다.
    • 건 총액은 \(1 + 2 + 4 = \$7\).
    • 아래 표는 \(X\)의 확률질량함수를 요약한 것이다.

  • \(X\)의 기대값은

\[ \begin{align} E(X) &= \displaystyle\sum_{i=1}^{\infty}x_if_X(x_i) = \displaystyle\sum_{i=1}^{\infty}(2^i-1)(1-\theta)^{i-1}\theta \\ &=\theta \displaystyle\sum_{i=1}^{\infty}2^i(1-\theta)^{i-1} - \theta \displaystyle\sum_{i=1}^{\infty}(1-\theta)^{i-1} \\ &= 2\theta \displaystyle\sum_{i=1}^{\infty}2^i(1-\theta)^{i-1} - \theta \displaystyle\sum_{i=1}^{\infty}(1-\theta)^i \\ &= \begin{cases} 2\theta \Big( \frac{1}{1-2(1-\theta)} \Big) & \text{ if } 2(1-\theta) ＜ 1, \\ \infty - 1 & \text{ if } 2(1-\theta) ≥ 1 \end{cases} \\ &= \begin{cases} \frac{1}{2\theta - 1} & \text{ if } 2(1-\theta) ＜ 1, \\ \infty & \text{ if } 2(1-\theta) ≥ 1. \end{cases} \end{align} \]

  • 조건부 기대값: \(E(X|Y = y) = \displaystyle\sum_{x \in S_X} xf_{X|Y}(x|y).\) 다음에 주목하라: \(E(X|Y = y)\) 의 함수이다 \(y\).


3.2 함수의 기대값

  • \(X\)가 이산확률변수이면 \(g(X)\)도 또 다른 이산확률변수이다. 즉 \(g(X) = g[X(\omega)] = Y(\omega)\) for some function \(Y\).
  • \(E[g(X)] = E(Y) = \displaystyle\sum_{\omega}Y(\omega)P(\omega) = \displaystyle\sum_{y \in S_Y} y \displaystyle\sum_{\omega, Y = y} P(\omega) = \displaystyle\sum_{y \in S_Y} yf_Y(y)\)
  • 결과:

\[ E[g(X)] = \displaystyle\sum_{x \in S_X} g(x)f_X(x). \]

  • 증명:

\[ \begin{align} E[g(X)] &= \displaystyle\sum_{\omega \in \Omega} g[X(\omega)]P(\omega) \text{ 정의에 의해 } \\ &= \displaystyle\sum_{x \in S_X} g(x) \displaystyle\sum_{\omega, X(\omega) = x} P(\omega) \text{ 합의 항을 재배열하여 } \\ &= \displaystyle\sum_{x \in S_X} g(x)f_X(x). \end{align} \]

  • 주의: 일반적으로 \(E[g(X)] ≠ g[E(X)]\). 예를 들어, if \(g(X) = 1/X\), then

\[ E[g(X)] = \displaystyle\sum_{x \in S_X}\frac{1}{x}f_X(x) ≠ g[E(X)] = \frac{1}{E(X)} = \frac{1}{\displaystyle\sum_{x \in S_X}xf_X(x)}. \]

  • 하지만 \(g(X)\)가 선형함수이면 \(E[g(X)] = g[E(X)]\). 즉, if \(g(X) = a + bX\), 여기서 \(a\)와 \(b\)는 상수이다, then

\[ E[g(X)] = E(a + bX) = a + bE(X) = g[E(X)]. \]

  • 효용: 확률변수 \(X\)의 주관적 가치를 \(X\)의 효용이라고 하며 \(u(X)\)로 나타낸다.
    • 기대효용은

\[ E(U) = \displaystyle\sum_{x \in S_X} u(x)f_X(x). \]

  • 조건부 확률질량함수의 기대값: \(E[f_{X|Y} (x|Y)] = f_X(x)\).
    • 증명:

\[ \begin{align} E[f_{X|Y} (x|Y)] &= \displaystyle\sum_{y \in S_Y} f_{X|Y} (x|y) f_Y(y) \\ &= \displaystyle\sum_{y \in S_Y} f_{X,Y}(x,y) \text{ 조건부 pmf의 정의에 의해 } \\ &= f_X(x). \end{align} \]

  • 이 기대값은 때때로 다음과 같이 쓴다: \(E_Y [f_{X|Y} (x|Y)] = f_X(x)\) 이는 기대값이 \(Y\)의 분포에 관해 계산된다는 점을 상기시키기 위한 것이다.

  • 반복기대값: \(E_Y[E(X|Y)] = E(X)\).

    • 증명:

\[ \begin{align} E_Y[E(X|Y)] &= \displaystyle\sum_{y \in S_Y} [E(X|y)] f_Y(y) \text{ 함수의 기대값에 관한 결과에 의해 } \\ &= \displaystyle\sum_{y \in S_Y} \Bigg[ \displaystyle\sum_{x \in S_X} xf_{X|Y}(x|y) \Bigg] f_Y(y) \text{ 조건부 기대값의 정의에 의해 } \\ &= \displaystyle\sum_{y \in S_Y} \displaystyle\sum_{x \in S_X} xf_{X|Y}(x|y)f_Y(y) \\ &= \displaystyle\sum_{y \in S_Y} \displaystyle\sum_{x \in S_X} xf_{X,Y}(x,y) \text{ 조건부 pmf의 정의에 의해 } \\ &= \displaystyle\sum_{x \in S_X} x \displaystyle\sum_{y \in S_Y} f_{X,Y}(x,y) \\ &= \displaystyle\sum_{x \in S_X} x f_X(x) = E(X). \end{align} \]

  • 반복기대값의 예.
    • 다음과 같이 가정하자: 동전이 앞면이 나올 확률이 \(\theta\)이다.
    • 앞면이 나오면 \(Y=1\), 뒷면이 나오면 \(Y=0\)인 확률변수 \(Y\)를 정의하자.
    • 다음에 주목하라: \(E(Y) = θ\).
    • 동전을 던진 다음 공정한 육면체 주사위를 \(2Y + 1\) 번 굴린다.
    • \(X\)를 \(2Y +1\) 번 굴렸을 때 나온 눈의 합이라고 하자.
    • \(E(X)\)를 구하라.
    • 풀이: 한 번 굴렸을 때 주사위 눈의 기대값은 3.5이다.
      • 따라서, \(E(X|Y) = (2Y + 1)(3.5)\) and

\[ \begin{align} E(X) &= E_Y[E(X|Y)] \\ &= E_Y[(2Y + 1)(3.5)] \\ &= [2E(Y) + 1](3.5) \\ &= (2\theta + 1)(3.5). \end{align} \]

  • 동전이 공정하다면, then \(E(Y) = \frac{1}{2} \text{ 그리고 } E(X) = 7\).

  • 여러 확률변수의 함수의 기대값: \(E[g(X_1, X_2, \dots , X_k) = \displaystyle\sum_{(x_1, x_2, \dots, x_k) \in S}g(x_1, x_2, \dots, x_k)f_X(x_1, x_2, \dots, x_k)\).

    • 예제: \((X,Y)\)의 결합 지지집합이 \(S = \{(0,0),(0,1),(1,0),(1,1)\}\)라고 하자.
    • 다음의 기대값을 구하라: \(1/f_{X,Y}(X, Y)\).
    • 풀이:

\[ \begin{align} E \Bigg( \frac{1}{f_{X, Y}(X, Y)} \Bigg) &= \displaystyle\sum_{x=0}^1 \displaystyle\sum_{y=0}^1 \Bigg( \frac{1}{f_{X, Y}(X, Y)} \Bigg) f_{X, Y}(X, Y) \\ &= \displaystyle\sum_{x=0}^1 \displaystyle\sum_{y=0}^1 1 = 4. \end{align} \]

  • 독립일 때의 기대값:
    • \(X\)와 \(Y\)가 독립이면, then \(E[g(X)h(Y)] = E[g(X)]E[h(Y)]\), 단, 기대값들이 존재한다고 가정한다.
    • 증명: 다음과 같이 가정하자: \(X \perp\!\!\!\perp Y\) .
    • 그러면 \(f_{X,Y}(x, y) = f_X(x)f_Y(y)\) and

\[ \begin{align} E[g(X)h(Y)] &= \displaystyle\sum_{x \in S_X} \displaystyle\sum_{y \in S_Y} g(x)h(y)f_{X,Y}(x,y) \\ &= \displaystyle\sum_{x \in S_X} \displaystyle\sum_{y \in S_Y} g(x)h(y)f_X(x)f_Y(y) \\ &= \displaystyle\sum_{x \in S_X}g(x)f_X(x) \displaystyle\sum_{y \in S_Y}h(y)f_Y(y)\\ &= E[g(X)]E[h(Y)]. \end{align} \]

  • 주: 훨씬 더 강한 결과를 보일 수 있다. \(X \perp\!\!\!\perp Y\)이면 임의의 함수 \(g\)와 \(h\)에 대해 \(g(X) \perp\!\!\!\perp h(Y)\)이다.


3.3 변동성

  • 평균절대편차: \(\text{MAD } \overset{def}= E(|X - \mu_X|) = \displaystyle\sum_{x \in S}|x - \mu_X| f_X(x)\).

  • 분산: \(X\)의 분산은 다음과 같이 정의된다

\[ Var(X) \overset{def}= E(|X - \mu_X|)^2 = \displaystyle\sum_{x \in S}(x - \mu_X)^2 f_X(x). \]

  • 관례적으로 다음과 같이 나타낸다: 확률변수 \(X\)의 분산을 \(σ^2_X\).

  • 결과: \(Var(X) = E(X^2) − [E(X)]^2\).

    • 증명:

\[ \begin{align} Var(X) &= E\{[X − E(X)]\}^2 = E\{X^2 − 2XE(X) + [E(X)]^2\} \\ &= E(X^2) − 2E(X)E(X) + [E(X)]^2 = E(X^2) − [E(X)]^2. \end{align} \]

  • 표준편차: \(\sigma \overset{def}= + \sqrt{\sigma^2}\).

  • 균등분포의 분산:

    • 다음과 같이 가정하자: \(X\)의 지지집합은 \(S = \{1, 2, \dots , N\}\) and that 지지집합의 각 값은 같은 확률을 갖는다.
    • 이 상황은 다음과 같이 나타낼 수 있다: \(X ∼ \text{ Discrete Uniform}(1, 2, \dots , N)\). - 이 분포에 대해,

\[ \mu_X = \frac{N + 1}{2} \text{ 그리고 } \sigma^2_X = \frac{(N + 1)(N - 1)}{12}. \]

  • 증명:

\[ \begin{align} E(X) &= \displaystyle\sum_{x \in S} xf_X(x) = \displaystyle\sum_{x = 1}^N x \frac{1}{N} \\ &= \frac{1}{N} \displaystyle\sum_{i = 1}^N i = \bigg( \frac{1}{N} \bigg) \bigg(\frac{N(N + 1)}{2} \bigg) \\ &= \frac{N + 1}{2}. \end{align} \]

      또한,

\[ \begin{align} E(X^2) &= \displaystyle\sum_{x \in S} x^2f_X(x) = \displaystyle\sum_{x = 1}^N x^2 \frac{1}{N} \\ &= \frac{1}{N} \displaystyle\sum_{i = 1}^N i^2 = \bigg( \frac{1}{N} \bigg) \bigg(\frac{N(N + 1)(2N + 1)}{6} \bigg) \\ &= \frac{(N + 1)(2N + 1)}{6}. \end{align} \]

      따라서,

\[ Var(X) = \frac{(N + 1)(2N + 1)}{6} - \bigg( \frac{N + 1}{2} \bigg)^2 = \frac{(N + 1)(N - 1)}{12}. \]

  • 예제: 공정한 주사위를 한 번 던진다. \(X\)를 윗면에 나온 눈의 수라고 하자. 그러면, \(X ∼ \text{ Discrete Uniform}(1, 2, \dots ,)\). 따라서,

\[ E(X) = \frac{7}{2} \text{ 그리고 } Var(X) = \frac{(7)(5)}{12} = 2.9167. \]

  • 평행축 정리: \(c\)를 상수, \(X\)를 확률변수라고 하자 평균 \(\mu_X\) 분산 \(σ^2_x < \infty\).
    • 그러면, \(E(X − c)^2 = \sigma^2_X + (c − \mu)^2\).
    • 다음에 주목하라: \(E(X − c)^2\) 는 \(c\)에 관해 다음일 때 최소화된다: \(c = \mu_X\).
    • 증명: 0을 더하는 기법을 사용한다.
    • Write \(c\) as \(c = \mu_X + (c − \mu_X)\). 따라서,

\[ \begin{align} E(X − c)^2 &= E [(X − \mu_X) − (c − \mu_X)]^2 \\ &= E[(X − \mu_X)^2 − 2(X − \mu_X)(c − \mu_X) + (c − \mu_X)^2] \\ &= E(X − \mu_X)^2 − 2(c − \mu_X)E(X − \mu_X) + E(c − \mu_X)^2 \\ &= \sigma^2_X + 0 + (c − \mu_X)^2 = \sigma^2_X + (c − \mu_X)^2 \end{align} \]

  • 왜 이것을 평행축 정리라고 부르는가? 내 생각에는 평행축이 \(X\)의 확률질량함수 그래프에 그린 두 개의 수직선을 가리키는 것 같다.
    • 하나는 다음 위치에 그려지고: \(x = c\) and one is drawn at \(x = \mu_X\).
  • 다음에 대한 대안적 증명: \(\mu_X\) 는 다음의 최소화점이다: \(g(c) = E(X − c)^2\):
    • 도함수를 취하고 of \(g(c)\) 에 관해 \(c\) and 0으로 두어 임계점을 찾는다:

\[ \begin{align} \frac{d}{d \ c} g(c) &= \frac{d}{d \ c} E(X^2 - 2cX + c^2) \\ &= \frac{d}{d \ c} [E(X^2) - 2c\mu_X + C^2] = -2\mu_X + 2C, \text{ 그리고 } \\ \frac{d \ g(c)}{d \ c} &= 0 \Rightarrow c = \mu_X \end{align} \]

  • 이계도함수 판정을 사용한다 최소화점을 찾았음을 보인다:

\[ \frac{d^2}{(d \ c)^2} g(c) \bigg|_{c = \mu_x} = 2 ＞ 0 \Rightarrow \mu_X \text{ is a minimizer }. \]


3.4 공분산과 상관계수

  • 공분산:

\[ Cov(X, Y) \overset{def}= E[(X - \mu_X)(Y - \mu_Y)]. \]

  • 관례적으로 다음과 같이 나타낸다: \(X\)와 \(Y\) 사이의 공분산을 \(σ_{X,Y}\).

  • 결과: \(E[(X - \mu_X)(Y - \mu_Y)] = E(XY) - E(X)E(Y)\).

    • 증명:

\[ \begin{align} E[(X − \mu_X)(Y − \mu_Y)] &= E [XY − XE(Y) − E(X)Y + E(X)E(Y)] \\ &= E(XY) − E(X)E(Y) − E(X)E(Y) + E(X)E(Y) \\ &= E(XY) − E(X)E(Y). \end{align} \]

  • 예제: \(i=0,\dots,n\) 및 \(j=0,\dots,n\)에 대해 \(f_{X,Y}(i,j)=2(i+2j)/[3n(n+1)^2]\)라고 하자. 그러면 \(E(XY)=n(2n+1)/6\)이고 \(Cov(X,Y)=-(n+2)^2/162\)이다.

  • 결과: \(Cov(a + bX, c + dY) = bdCov(X, Y)\).

  • Special case of above result: \(Var(aX + b) = a^2 Var(X)\).

  • 상관계수: \(Cor(X, Y) \overset{def}= σ_{X,Y}/(σ_Xσ_Y)\).

    • 관례적으로 \(X\)와 \(Y\) 사이의 상관계수를 \(\rho_{X,Y}\)로 나타낸다.

  • 코시-슈바르츠 부등식: \(X\)와 \(Y\)를 두 확률변수라고 하자.

    • 그러면 \(E(X^2)E(Y^2) ≥ [E(XY)]^2\), 단, 기대값들이 존재한다고 가정한다.
    • 증명: \(E(Y − \alpha X)^2 ≥ 0 \text{ 모든 } \alpha\).
    • 이제 최소화하자 에 관해 \(\alpha\).

\[ \frac{\partial E(Y - \alpha X)^2}{\partial \alpha} = 0 \Rightarrow \alpha = \frac{E(XY)}{E(X)^2} \Rightarrow E \bigg[ Y - \frac{E(XY)}{E(X^2)}X \bigg]^2 ≥ 0. \]

  • 정리하면 다음을 얻는다: the Cauchy-Schwartz inequality.

  • 코시-슈바르츠 부등식의 적용: \(X^*\)와 \(Y^*\)가 확률변수이고 필요한 기대값들이 존재하면 코시-슈바르츠 부등식에 의해 \([E(X^*Y^*)]^2 \le E(X^{*2})E(Y^{*2})\)이다.

    • \(X^* = (X-\mu_X)/\sigma_X\), \(Y^*=(Y-\mu_Y)/\sigma_Y\)라고 하자. 그러면,

\[ \begin{align} \bigg\{E \bigg[\frac{(X-\mu_x)(Y-\mu_Y)}{\sigma_X \sigma_Y} \bigg] \bigg\}^2 &≤ E(X^{*2})E(Y^{*2}) \\ &= E \bigg[\frac{(X-\mu_X)^2}{\sigma^2_X} \bigg] E \bigg[\frac{(Y-\mu_Y)^2}{\sigma^2_Y} \bigg] \\ &\Rightarrow \rho^2_{X,Y} ≤ \bigg(\frac{\sigma^2_X}{\sigma^2_X}\bigg)\bigg(\frac{\sigma^2_Y}{\sigma^2_Y}\bigg) = 1 \\ &\Rightarrow \rho_{X,Y} \in [-1. 1]. \end{align} \]

  • 예제: 아주 작은 보험회사를 생각하자.
    • \(X\)를 판매된 보험계약 수, \(Y\)를 발생한 보험청구 수라고 하자.
    • 다음과 같이 가정하자: the joint pmf for \(X\) and \(Y\) is the following:

3.5 확률변수의 합

  • \(X_1,X_2,\dots,X_k\)가 확률변수이고, \(E(X_i)=\mu_i\), \(Var(X_i)=\sigma_i^2\), \(Cov(X_i,X_j)=\sigma_{ij}\)라고 하자.
    • 또한 다음을 가정하자: \(c_1, c_2, \dots , c_k\) are 알려진 상수.
    • \(T = \displaystyle\sum_{i=1}^k c_iX_i\). 그러면,

\[ E(T) = \displaystyle\sum_{i=1}^{k}c_i\mu_i \text{ 그리고 } Var(T) = \displaystyle\sum_{i=1}^k c_i^2 \sigma_i^2 + 2\displaystyle\sum_{i ＜ j}^n c_ic_j\sigma_{ij}. \]

  • 증명: \(E(T)\)에 관한 결과는 자명하다. 분산에 관한 결과를 증명하기 위해 분산의 정의에서 시작한다:

\[ \begin{align} Var(T) &= E[T - E(T)]^2 \\ &= E \Bigg[ \displaystyle\sum_{i=1}^{k}c_iX_i - \displaystyle\sum_{i=1}^{k}c_i\mu_i \Bigg]^2 \\ &= E \Bigg[ \displaystyle\sum_{i=1}^{k}c_i(X_i - \mu_i) \Bigg]^2 \\ &= E \Bigg\{ \Bigg[ \displaystyle\sum_{i=1}^{k}c_i(X_i - \mu_i) \Bigg]\Bigg[ \displaystyle\sum_{j=1}^{k}c_j(X_j - \mu_j) \Bigg] \Bigg\} \\ &= E \Bigg\{ \displaystyle\sum_{i=1}^{k}\displaystyle\sum_{j=1}^{k}c_ic_j(X_i - \mu_i)(X_j - \mu_j) \Bigg\} \\ &= \displaystyle\sum_{i=1}^{k}c_i^2E(X_i - \mu_i)^2 + \displaystyle\sum_{i≠j}c_ic_jE[(X_i-\mu_i)(X_j-\mu_j)] \\ &= \displaystyle\sum_{i=1}^{k}c_i^2\sigma_i^2 + \displaystyle\sum_{i≠j}c_ic_j\sigma_{ij} \\ &= \displaystyle\sum_{i=1}^{k}c_i^2\sigma_i^2 + 2\displaystyle\sum_{i＜j}c_ic_j\sigma_{ij} \text{ 왜냐하면 } \sigma_{ij} = \sigma_{ji}. \end{align} \]

  • 특수한 경우: \(c_i = 1\) 모든 \(i\). 그러면,

\[ Var \Bigg( \displaystyle\sum_{i=1}^{k} X_i \Bigg) = \displaystyle\sum_{i=1}^{k} \sigma_i^2 + 2\displaystyle\sum_{i＜j} \sigma_{ij}. \]

  • 특수한 경우: \(k = 2, c1 = 1, c2 = 1\). 그러면

\[ Var(X_1 + X_2) = \sigma_1^2 + \sigma_2^2 + 2\sigma_1\sigma_2. \]

  • 특수한 경우: \(k = 2, c1 = 1, c2 = −1\). 그러면

\[ Var(X_1 + X_2) = \sigma_1^2 + \sigma_2^2 - 2\sigma_1\sigma_2. \]

  • 특수한 경우: \(c_i = 1\) 모든 \(i\) and 변수들이 쌍별로 비상관이다. 그러면,

\[ Var \Bigg( \displaystyle\sum_{i=1}^{k} X_i \Bigg) = \displaystyle\sum_{i=1}^{k} \sigma_i^2. \]

  • 응용: 크기가 n 복원추출로 평균이 \(\mu_X\) 분산 \(\sigma_X^2\).
    • \(T = \sum_{i=1}^n X_i\) and let \(\bar{X} = T/n\). 그러면

\[ E(T) = n\mu_X, \ Var(T) = n\sigma_X^2, \ E(\bar{X}) = \mu_X, \text{ 그리고 } \ Var(\bar{X}) = \sigma_X^2/n. \]

  • 증명: 확률변수들은 \(iid\).
    • 따라서, \(E(X_i) = \mu_X\) 모든 \(i\), \(Var(X_i) = \sigma_X^2\) 모든 \(i\), and \(Cov(X_i, X_j) = 0\) 모든 \(i ≠ j\). 따라서,

\[ \begin{align} E(T) &= E \Bigg( \displaystyle\sum_{i=1}^{n} X_i \Bigg) = \displaystyle\sum_{i=1}^{n}E(X_i) = n\mu_X \text{ 그리고 } \\ Var(T) &= Var \Bigg( \displaystyle\sum_{i=1}^{n} X_i \Bigg) = \displaystyle\sum_{i=1}^{n}\sigma_X^2 = n\sigma_X^2. \end{align} \]

  • Furthermore, \(\bar{X} = \displaystyle\sum_{i=1}^n X_i\), so. \(c_i = 1/n\) 모든 \(i\) in the formula for \(\bar{X}\).
    • 따라서,

\[ \begin{align} E(\bar{X}) &= \frac{1}{N}E(T) = \mu_X \text{ 그리고 } \\ Var(\bar{X}) &= Var\bigg(\frac{1}{N} T \bigg) = \frac{1}{n^2} Var(T) = \frac{\sigma_X^2}{n}. \end{align} \]

  • 응용: 크기가 \(n\) from the pmf \(f_X (x)\) 기대값이 \(\mu_X\) 분산 \(\sigma_X^2\).
    • \(T = \sum_{i=1}^n X_i\) and let \(\bar{X} = T/n\). 그러면

\[ E(T) = n\mu_X, \ Var(T) = n\sigma_X^2, \ E(\bar{X}) = \mu_X, \text{ 그리고 } \ Var(\bar{X}) = \sigma_X^2/n. \]

            - 증명: 이 상황은 본질적으로 위의 상황과 같다. - 확률변수들은 iid 왜냐하면 다음에서 관측값을 하나 뽑아도 \(f_X(x)\) 확률질량함수가 변하지 않기 때문이다.

  • 응용: 크기가 n 비복원추출로 크기가 \(N\) having mean \(\mu_X\) 분산 \(\sigma_X^2\).
    • \(T = \sum_{i=1}^n X_i\) and let \(\bar{X} = T/n\). 그러면,

\[ \begin{align} E(T) &= n\mu_X, \ Var(T) = n\sigma_X^2 \Bigg[ 1 - \frac{(n-1)}{(N-1)} \Bigg], \\ E(\bar{X}) &= \mu_X, \ Var(\bar{X}) = \frac{\sigma_X^2}{n} \Bigg[ 1 - \frac{(n-1)}{(N-1)} \Bigg]. \end{align} \]

            - 증명: Item 5 on page 33 shows that \(X_1, \dots , X_n\) are exchangeable random variables, even though they are not 독립. 따라서,

\[ \begin{align} E (X_i) &= E(X_1) = \mu_X \text{ for } i = 1, \dots , n; \\ Var(X_i) &= Var(X_1) = \sigma_X^2 \text{ for } i = 1, \dots , n; \text { and } \\ Cov(X_i, X_j) &= Cov(X_1, X_2) = \sigma_{12} \text{ 모든 } i ≠ j. \end{align} \]

  • 다음 값을 찾기 위해 \(\sigma_{12}\), use

\[ Var \Bigg( \displaystyle\sum_{i=1}^{n} X_i \Bigg) = Var(N\mu_X) = 0 \]

      together with exchangeability. 즉,

\[ \begin{align} Var \Bigg( \displaystyle\sum_{i=1}^{n} X_i \Bigg) &= \displaystyle\sum_{i=1}^{n} Var(X_i) + 2\displaystyle\sum_{i＜j}Cov(X_i, X_j) \\ &= N\sigma_X^2 + N(N - 1)\sigma_{12} = 0 \\ &\Rightarrow \sigma_{12} = -\frac{\sigma_X^2}{N-1}. \end{align} \]

      따라서,

\[ \begin{align} E(T) &= \displaystyle\sum_{i=1}^{n} E(X_i) = n\mu_X, \\ E(\bar{X}) &= E \bigg(\frac{1}{n}T \bigg) = \frac{1}{n}E(T) = \mu_X, \\ Var(T) &= Var \bigg( \displaystyle\sum_{i=1}^{n} X_i \bigg) = \displaystyle\sum_{i=1}^{n} Var(X_i) + \displaystyle\sum_{i＜j}Cov(X_i, X_j) \\ &= n\sigma_X^2 + n(n-1)\bigg(- \frac{\sigma_X^2}{N-1} \bigg) = n\sigma_X^2 \bigg[ 1 - \frac{(n-1)}{(N-1)} \bigg], \text{ 그리고 } \\ Var(\bar{X}) &= Var \bigg( \frac{1}{n}T \bigg) = \bigg( \frac{1}{n} \bigg)^2 Var(T) = \frac{\sigma_X^2}{n} \bigg[ 1 - \frac{(n-1)}{(N-1)} \bigg]. \end{align} \]


3.6 확률생성함수

  • 정의: 다음과 같이 가정하자: X is a discrete random variable with support a subset of the natural numbers.
    • 즉, \(S_X \in \{0, 1, 2, \dots , \infty \}\).
    • \(t\)를 실수라고 하자. 그러면 the probability generating function (pgf) of \(X\) is

\[ \eta_X(t) \overset{def}= E(t^X), \]

      여기서 \(t\)는 기대값이 존재할 만큼 절댓값이 충분히 작게 선택된다. \(|t|<1\)이면 기대값은 항상 존재한다.

  • 결과(증명 없음): 확률생성함수 are Unique.
    • 이 결과는 pmf와 pgf 사이에 일대일 대응이 있음을 보여준다.
    • 즉, 각 pmf는 정확히 하나의 pgf와 대응하고, 각 pgf는 정확히 하나의 pmf와 대응한다.
    • 이 결과가 중요한 이유는 pgf를 이용해 pmf를 찾을 수 있기 때문이다.
    • 더 구체적으로, 유일성 결과는 다음을 말한다: if \(Y\) is a random variable with support \(S_Y \in \{0, 1, 2, \dots , \infty \}\) and

\[ E(t_Y) = p_0t^0 + p_1t^1 + \dots + p_kt^k + \cdots, \]

      그러면 \(Y\)의 pmf는 \(f_Y (i) = p_i\) for \(i = 0, 1, \dots , \infty\). 물론, it also is true that if \(Y\) is a random variable with support \(S_Y \in \{0, 1, 2, \dots , \infty \}\) and the pmf of \(Y\) is \(f_Y (i) = p_i\) for \(i = 0, 1, \dots , \infty\); then \(E(t_Y) = p_0t^0 + p_1t^1 + \dots + p_kt^k + \cdots.\)

  • 예제: \(E(t^Y)=.2t^4+.3t^8+.5t^{19}\)일 때 \(Y\)의 pmf를 구하라.
    • 풀이:
\(y\) \(f_Y(y)\)
4 0.2
8 0.3
19 0.5
Sum 1.0
  • 결과: 다음과 같이 가정하자: \(X_1, \dots , X_n\) are 독립.
    • \(i=1,\dots,n\)에 대해 \(X_i\)의 pgf를 \(\eta_{X_i}(t)\)로 나타내자.
    • 만약

\[ U = \displaystyle\sum_{i=1}^n X_i, \text{ 그러면 } \eta_U(t) = \prod_{i=1}^n \eta_{X_i}(t). \]

  • 증명: 독립 확률변수의 함수의 기대값에 관한 결과를 사용한다. 즉,

\[ \begin{align} \eta_U(t) &= E(t^U) = E(t^{\sum_{i=1}^n X_i}) \\ &= E \Bigg(\prod_{i=1}^n t^{X_i} \Bigg) \\ &= \prod_{i=1}^n E(t^{X_i}) = \prod_{i=1}^n \eta X_i(t), \end{align} \]

  • 결과: 다음과 같이 가정하자: \(X_1, \dots , X_n\) are iid.
    • \(i=1,\dots,n\)에 대해 \(X_i\)의 pgf를 \(\eta_X(t)\)로 나타내자. 만약

\[ U = \displaystyle\sum_{i=1}^n X_i, \text{ 그러면 } \eta_U(t) = [\eta_X(t)]^n. \]

  • 증명: 이 결과는 위 결과로부터 바로 따른다.

  • 응용 1: 베르누이 → 이항분포.

    • 다음과 같이 가정하자: \(X_i\) for \(i = 1, \dots , n\) are iid 베르누이 확률변수 각각 성공확률이 \(\theta\).
    • 다음의 분포를 구하라: \(Y = \sum_{i=1} ^n Xi\).
    • 베르누이 확률변수는 다음 지지집합을 갖는 확률변수이다: \(S = \{0, 1\}\).

  • 베르누이 확률변수의 pmf, \(B\), is

\[ f_B(b) = \begin{cases} \theta & \text{ if } b = 1, \\ 1 - \theta & \text{ if } b = 0, \\ 0 & \text{그 외의 경우.} \end{cases} \]

  • 베르누이 확률변수의 pmf 다음과 같이도 쓸 수 있다

\[ f_B(b) = \theta^b(1 - \theta)^{(1 - b)}I_{\{0,1\}}(b). \]

  • 풀이: \(X_i\)들이 각각 성공확률 \(\theta\)를 갖는 iid 베르누이 확률변수이면,

\[ \begin{align} f_{X_i}(x) &= \theta^x(1 - \theta)^{(1 - x)}I_{\{0,1\}}(x) \text{ 그리고 } \\ \eta_{X_i}(t) &= (1 - \theta)t^0 + \theta t^1 = (1- \theta) + \theta t \text{ for } i = 1, \dots, n. \end{align} \]

  • 위 결과를 사용하면, the pmf of \(Y = \sum_{i=1}^n X_i\) is

\[ \eta_Y(t) = [\theta t + (1 - \theta)]^n. \]

  • 이항정리를 사용하면, the pmf of \(Y\) can be written as

\[ \eta_Y(t) = \displaystyle\sum_{i=0}^n \binom{n}{i}(\theta t)^i(1 - \theta)^{(n-i)}. \]

  • 따라서,

\[ f_Y(y) = \binom{n}{y} \theta^y (1 - \theta)^{n-y} \text{ for } y = 0, 1, \dots, n. \]

이 pmf를 이항 pmf라고 한다.

  • 결과: 유용한 전개식: 다음과 같이 가정하자: a 는 다음 범위의 값을 갖는 상수이다 \([−1, 1]\), \(n\) 는 다음을 만족하는 정수 상수이다 \(n ≥ 1\), and \(t\) 는 다음을 만족하는 변수이다 \(t \in (−1, 1)\).
    • \(h(t)\)를 다음과 같이 정의하자

\[ h(t) \overset{def}= (1 - at)^{-n}. \]

      - 그러면,

\[ h(t) = \displaystyle\sum_{r=0}^{\infty} \binom{n+r-1}{r} a^rt^r. \]

  • 증명: \(h(t)\)를 다음 주위에서 테일러 급수로 전개한다: \(t = 0\).
    • 의 처음 몇 개 도함수는 \(h(t)\), 에서 평가하면 \(t = 0\) are

\[ \begin{align} \frac{d}{dt}h(t) &= -n(1 - at)^{-(n+1)}(-1)a, \\ \frac{d}{dt} \bigg|_{t=0} &= na, \\ \frac{d^2}{(dt)^2}h(t) &= -n(n+1)(1-at)^{-(n+1)}(-1)a^2, \\ \frac{d^2}{(dt)^2} \bigg|_{t=0} &= n(n+1)a^2, \\ \frac{d^3}{(dt)^3}h(t) &= -n(n+1)(n+2)(1-at)^{-(n+3)}(-1)a^3, \\ \frac{d^3}{(dt)^3} \bigg|_{t=0} &= n(n+1)(n+2)a^3, \\ \vdots \\ \frac{d^r}{(dt)^r}h(t) &= -n(n+1)(n+2) \dots (n+r-1)(1-at)^{-(n+r)}(-1)a^r, \\ \frac{d^r}{(dt)^r} \bigg|_{t=0} &= n(n+1)(n+2) \dots (n+r-1)a^r. \end{align}\]

  • 따라서, the Taylor series is

\[ \begin{align} h(t) &= \displaystyle\sum_{r=0}^{\infty} \frac{d^r}{(dt)^r} h(t) \bigg|_{t=0} \frac{1}{r!}(t-0)^r \\ &= \displaystyle\sum_{r=0}^{\infty} \binom{n+r-1}{r}a^rt^r. \end{align}\]

  • 비판정법에 의해 이 급수는 수렴한다. 왜냐하면

\[ \lim_{r \rightarrow 0} \frac{\binom{n+r+1-1}{r+1}(at)^{r+1}}{\binom{n+r+-1}{r}(at)^r} = \lim_{r \rightarrow 0} \frac{n+r}{r+1}at = at \text{ 그리고 } |at| ＜ 1. \]

  • 응용 2: 기하분포 → 음이항분포.
    • 다음과 같이 가정하자: \(U_1, U_2, \dots\) is a sequence of iid 베르누이 확률변수, 각각 성공확률이 \(\theta \in (0, 1)\).
    • \(X\)를 첫 번째 성공까지 필요한 베르누이 시행 횟수라고 하자.
    • 예를 들어 \(U_1=1\)이면 \(X=1\)이다. \(U_1=0, U_2=1\)이면 \(X=2\)이다. \(U_1=0, U_2=0,\dots,U_{x-1}=0,U_x=1\)이면 \(X=x\)이다.
    • 확률변수 \(X\)를 기하확률변수라고 하며 그 pmf는

\[ f_X(x) = (1-\theta)^{x-1}\theta I_{\{ 1,2, \dots, \infty \}}(x). \]

  • 이 pmf는 베르누이 확률변수들 사이의 독립성에서 따른다.
    • \(X_1,X_2,\dots,X_n\)이 각각 모수 \(\theta\)를 갖는 i.i.d. 기하확률변수라고 하자. \(Y=\sum_{i=1}^n X_i\)라고 두자.
    • 확률변수 \(Y\)는 모수 \(n\)과 \(\theta\)를 갖는 음이항확률변수라고 한다.
    • 확률변수 \(Y\)는 \(n^{\text{th}}\) 성공.
    • \(Y\)의 pmf는 다음과 같다.

\[ f_Y(y) = \binom{y-1}{y-n} \theta^n (1-\theta)^{y-n} I_{\{n, n+1, \dots, \infty \}}(y). \]

  • 증명: 의 pgf는 \(X_i\) for \(t \in (−1, 1)\) is

\[ \begin{align} \eta_{X_i}(t) &= E(t^{X_i}) = \displaystyle\sum_{x=1}^{\infty}(1-\theta)^{x-1}\theta t^x \\ &= \theta t \displaystyle\sum_{x=1}^{\infty}[(1-\theta)t]^{x-1} = \theta t \displaystyle\sum_{x=1}^{\infty} [(1-\theta)t]^x \\ &= \frac{\theta t}{1 - (1-\theta)t} \text{ 왜냐하면 } |(1-\theta)t| ＜ 1. \end{align} \]

  • 따라서, the pgf of \(Y\) is

\[ \eta_{Y}(t) = \bigg[ \frac{\theta t}{1 - (1-\theta)t} \bigg]^n = (\theta t)^n[1 - (1-\theta)t]^{-n}. \]

  • 위 전개식에서 \(a=1-\theta\)를 사용하면 \(Y\)의 pgf는

\[ \eta_Y(t) = (\theta t)^n \displaystyle\sum_{r=0}^{\infty} \binom{n+r-1}{r} (1-\theta)^r t^r. \]

  • 따라서,

\[ \Pr(Y = n+r) = \binom{n+r-1}{r}\theta^n(1-\theta)^r. \]

  • \(y=n+r\)라고 두면, 따라서 \(r = y − n\) to obtain

\[ f_Y(y) = \binom{y-1}{y-n}(1-\theta)^{y-n}\theta^n I_{\{ n, n+1, \dots, \infty \}}(y). \]

  • 응용 3: 라즐 대즐 게임.
    • 공정한 육면체 주사위 8개를 던진다. \(Y\)를 나온 눈의 합이라고 하자.
    • \(i=1,\dots,8\)에 대해 \(X_i\)를 \(i\)번째 주사위에 나온 눈의 수라고 하자. 총점은 \(Y=\sum_{i=1}^8 X_i\)이다. 목표는 \(Y\)의 pmf를 구하는 것이다.
    • 확률변수 \(X_i\)는 \(S_X=\{1,2,\dots,6\}\)에서 이산균등분포를 따른다.
    • 의 pgf는 \(X_i\) is

\[ \eta_{X_i}(t) = E(t^{X_i}) = \displaystyle\sum_{i=1}^6 t^i \bigg(\frac{1}{6} \bigg) = \bigg(\frac{1}{6} \bigg) \frac{t-t^7}{1-t} = \bigg(\frac{t}{6} \bigg) \frac{1-t^6}{1-t} \]       다음 결과를 사용했다: \(\sum_{i=1}^N a^i = \frac{a-a^{N+1}}{1-a}.\)

      - 의 pgf는 \(Y\) is

\[ \begin{align} \eta_{Y}(t) &= E(t^{Y}) \\ &= E(t^{X_1 + X_2 + \dots + X_8}) \\ &= E(t^{X_1})E(t^{X_2}) \cdots E(t^{X_8}) \\ &= \prod_{i=1}^{8} E(t^{X_i}) \\ &= \bigg( \frac{t}{6} \bigg)^8 \bigg( \frac{1-t^6}{1-t} \bigg)^8, \end{align} \]

      의 상호독립성을 사용했다 \(X_1, \dots , X_n\).

  • 이항정리를 사용하여 다음을 쓴다: \((1 − t^6)^8\) as

\[ (1 − t^6)^8 = (-t^6+1)^8 = \sum_{i=0}^8 \binom{8}{i}(-t^6)^i 1^{8-i} = \sum_{i=0}^8 \binom{8}{i}(-t^6)^i. \]

  • \(|t|<1\)이면, 의 테일러 급수 전개는 \((1 − t)^{−8}\) \(t=0\) 주위에서

\[ \frac{1}{(1-t)^8} = \sum_{r=0}^{\infty} \binom{7+r}{r}t^r \]

      여기서는 항목 7의 결과에서 \(a=1\)을 사용했다.

  • 따라서, the pgf of \(Y\) is

\[ \eta_Y = \bigg( \frac{1}{6} \bigg)^8 \sum_{i=0}^8 \sum_{j=0}^8 \binom{8}{i} (-1)^i \binom{7+j}{j} t^{8+6i+j}. \]

  • 구하기 위해 \(\Pr(Y = y)\), 모든 계수를 합하면 된다 in the pgf for which \(t\) 의 지수가 \(y^{\text{th}}\) 거듭제곱. 즉, 다음을 만족하는 모든 계수를 합한다: \(8 + 6i + j = y\).

  • 예제: \(\Pr(Y=13)\)은 \((i,j)=(0,5)\)에 해당하는 계수와 같다. 왜냐하면 \(6\times0+5+8=13\)이기 때문이다. 즉,

\[ \Pr(Y = 5) = \frac{1}{6^8} \binom{8}{0}(-1)^0 \binom{7+5}{5} = \frac{22}{6^8} \approx 0.00047154. \]

  • 예제: \(\Pr(Y=20)\)은 \((i,j)=(0,12),(1,6),(2,0)\)에 해당하는 계수들을 합하여 구한다. 즉,

\[ \begin{align} \Pr(Y = 20) &= \frac{1}{6^8} \Bigg[ \binom{8}{0}(-1)^0 \binom{7+12}{12} + \binom{8}{1}(-1)^1 \binom{7+6}{6} +\binom{8}{2}(-1)^2 \binom{7+0}{0} \Bigg] \\ &= \frac{1}{6^8} (50388 - 13728 + 28) = \frac{36,688}{6^8} \approx 0.0218431. \end{align} \]
