10  능형회귀추정량과 LASSO 추정량

일반 선형회귀모형에서는 최소제곱법을 이용하여 회귀계수를 추정한다. 그러나 설명변수들 사이의 상관이 매우 강하거나 설명변수의 수가 관측값 수에 비해 많으면 최소제곱추정량이 불안정해질 수 있다. 회귀계수의 표준오차가 커지고, 계수의 부호가 예상과 다르게 바뀌거나, 자료가 조금만 바뀌어도 추정값이 크게 달라질 수 있다.

능형회귀와 LASSO는 이러한 문제를 완화하기 위해 회귀계수의 크기에 벌점(penalty)을 부여하는 방법이다. 이 방법들은 회귀계수를 의도적으로 0에 가깝게 줄이는 대신 추정의 안정성과 예측 성능을 높이고자 한다. 이러한 접근을 규제회귀(regularized regression) 또는 penalized regression이라고 한다.

이 장에서 특히 중요하게 생각해야 할 질문은 다음과 같다.

  1. 왜 일부러 편향된 추정량을 사용하는가?
  2. 회귀계수를 줄이면 어떤 장점이 있는가?
  3. ridge는 왜 계수를 0에 가깝게 만들지만 정확히 0으로 만들지는 않는가?
  4. LASSO는 왜 변수선택 효과를 갖는가?
  5. \(\lambda\)가 커지면 모형은 어떻게 변하는가?
  6. 설명 목적과 예측 목적에서 ridge와 LASSO를 어떻게 선택할 것인가?


10.1 규제회귀의 기본 아이디어

선형회귀모형은 다음과 같이 쓸 수 있다.

\[ \mathbf{Y}=\mathbf{X}\boldsymbol{\beta}+\boldsymbol{\epsilon} \]

최소제곱법은 잔차제곱합을 최소화하는 회귀계수를 찾는다.

\[ RSS(\boldsymbol{\beta})= \sum_{i=1}^{n}(y_i-\beta_0-\sum_{j=1}^{p}x_{ij}\beta_j)^2 \]

그러나 설명변수들 사이에 강한 다중공선성이 있으면 \(\mathbf{X}'\mathbf{X}\)가 거의 특이행렬에 가까워지고, 최소제곱추정량의 분산이 커진다. 이 경우 회귀계수는 자료의 작은 변화에도 크게 흔들릴 수 있다. 규제회귀는 잔차제곱합뿐 아니라 회귀계수의 크기에도 벌점을 부여하여 계수를 안정적으로 추정한다.

일반적으로 규제회귀는 다음 형태의 목적함수를 최소화한다.

\[ RSS(\boldsymbol{\beta})+\lambda \times \text{Penalty}(\boldsymbol{\beta}) \]

여기서 \(\lambda\)는 벌점의 크기를 조절하는 tuning parameter이다.

  • \(\lambda=0\)이면 일반 최소제곱법과 같다.
  • \(\lambda\)가 커질수록 회귀계수는 더 강하게 0에 가까워진다.
  • \(\lambda\)가 너무 작으면 과적합 위험이 있고, 너무 크면 과도하게 단순한 모형이 된다.

따라서 규제회귀에서 핵심은 적절한 \(\lambda\)를 선택하는 것이다.


10.2 능형회귀모형

능형회귀(ridge regression)는 회귀계수 제곱합에 벌점을 주는 방법이다. 절편을 제외한 회귀계수에 대해 다음 목적함수를 최소화한다.

\[ \hat{\boldsymbol{\beta}}^{ridge} = \arg\min_{\boldsymbol{\beta}} \left[ \sum_{i=1}^{n} (y_i-\beta_0-\sum_{j=1}^{p}x_{ij}\beta_j)^2 + \lambda\sum_{j=1}^{p}\beta_j^2 \right] \]

여기서 \(\sum_{j=1}^{p}\beta_j^2\)는 \(L_2\) penalty라고 한다. 이 벌점은 회귀계수가 지나치게 커지는 것을 막는다.

행렬 형태로 쓰면 ridge 추정량은 다음과 같다.

\[ \hat{\boldsymbol{\beta}}^{ridge} = (\mathbf{X}'\mathbf{X}+\lambda \mathbf{I})^{-1} \mathbf{X}'\mathbf{Y} \]

여기서 \(\lambda \mathbf{I}\)가 \(\mathbf{X}'\mathbf{X}\)의 대각선에 더해진다. 이로 인해 \(\mathbf{X}'\mathbf{X}\)가 특이행렬에 가까운 경우에도 역행렬 계산이 안정화된다.

ridge 추정량의 특징

능형회귀추정량은 일반적으로 불편추정량이 아니다. 즉, 기대값이 실제 회귀계수와 정확히 같지 않다. 하지만 분산을 줄일 수 있으므로 평균제곱오차(mean squared error, MSE) 관점에서는 최소제곱추정량보다 더 좋은 성능을 보일 수 있다.

이는 편향-분산 trade-off로 이해할 수 있다.

\[ MSE = Bias^2 + Variance \]

ridge는 약간의 편향을 허용하는 대신 분산을 줄인다. 다중공선성이 심한 상황에서는 분산 감소의 이득이 편향 증가의 손실보다 클 수 있다.

표준화의 필요성

ridge와 LASSO는 회귀계수의 크기에 벌점을 부여한다. 따라서 설명변수들의 단위가 서로 다르면 벌점이 공정하게 적용되지 않는다. 예를 들어 하나의 변수는 kg 단위이고 다른 변수는 g 단위이면, 같은 정보를 담고 있더라도 회귀계수의 크기가 달라진다.

따라서 규제회귀에서는 일반적으로 설명변수를 표준화한 후 모형을 적합한다. glmnet 함수는 기본적으로 설명변수를 표준화한 후 모형을 적합하며, 최종 계수는 원래 척도에 맞게 반환한다.


10.3 LASSO 회귀모형

LASSO(least absolute shrinkage and selection operator)는 회귀계수 절대값의 합에 벌점을 주는 방법이다. 목적함수는 다음과 같다.

\[ \hat{\boldsymbol{\beta}}^{LASSO} = \arg\min_{\boldsymbol{\beta}} \left[ \sum_{i=1}^{n} (y_i-\beta_0-\sum_{j=1}^{p}x_{ij}\beta_j)^2 + \lambda\sum_{j=1}^{p}|\beta_j| \right] \]

여기서 \(\sum_{j=1}^{p}|\beta_j|\)는 \(L_1\) penalty라고 한다. LASSO의 중요한 특징은 일부 회귀계수를 정확히 0으로 만들 수 있다는 점이다. 따라서 LASSO는 회귀계수 축소와 변수선택을 동시에 수행한다.

ridge와 LASSO의 차이

ridge와 LASSO의 차이는 벌점 형태에서 비롯된다.

방법 벌점 계수 축소 변수선택 주로 유용한 상황
Ridge \(\sum \beta_j^2\) 모든 계수를 부드럽게 축소 거의 하지 않음 많은 변수가 조금씩 관련되어 있을 때
LASSO \(\sum |\beta_j|\) 일부 계수를 0으로 축소 가능 소수의 중요한 변수가 있을 때
Elastic net \((1-\alpha)\sum \beta_j^2/2+\alpha\sum|\beta_j|\) ridge와 LASSO의 절충 가능 상관된 변수군이 있을 때

ridge는 상관된 변수들의 계수를 함께 줄이는 경향이 있다. 반면 LASSO는 상관된 변수 중 일부만 선택하고 나머지를 0으로 만들 수 있다. 따라서 강한 상관을 가진 변수들이 여러 개 있는 경우에는 LASSO 결과가 불안정할 수 있으며, 이때 elastic net을 고려할 수 있다.

elastic net

elastic net은 ridge와 LASSO를 결합한 방법이다.

\[ \hat{\boldsymbol{\beta}}^{EN} = \arg\min_{\boldsymbol{\beta}} \left[ RSS(\boldsymbol{\beta}) + \lambda \left\{ (1-\alpha)\frac{1}{2}\sum_{j=1}^{p}\beta_j^2 + \alpha\sum_{j=1}^{p}|\beta_j| \right\} \right] \]

여기서 \(\alpha\)는 ridge와 LASSO 사이의 비중을 조절한다.

  • \(\alpha=0\): ridge
  • \(\alpha=1\): LASSO
  • \(0<\alpha<1\): elastic net


10.4 \(\lambda\) 선택

규제회귀에서 \(\lambda\)는 모형 복잡도를 결정하는 핵심 tuning parameter이다. \(\lambda\)가 작으면 일반 최소제곱모형에 가까워지고, \(\lambda\)가 크면 회귀계수가 강하게 0에 가까워진다. 따라서 적절한 \(\lambda\)를 선택해야 한다.

가장 널리 사용되는 방법은 교차검증(cross-validation)이다. 자료를 여러 fold로 나누고, 각 \(\lambda\) 값에 대해 검증자료에서의 예측오차를 계산한 뒤 평균 예측오차가 가장 작은 \(\lambda\)를 선택한다.

glmnet의 cv.glmnet()은 보통 다음 두 값을 제공한다.

  • lambda.min: 교차검증 오차가 가장 작은 \(\lambda\)
  • lambda.1se: 최소 오차로부터 1 표준오차 이내에 있는 가장 큰 \(\lambda\)

lambda.min은 예측오차를 최소화하는 데 초점을 둔다. lambda.1se는 조금 더 단순하고 안정적인 모형을 선택하려는 기준이다. 강의나 실무 보고서에서는 두 결과를 모두 확인하고, 예측 성능과 모형 해석 가능성을 함께 고려하는 것이 좋다.


10.5 능형트레이스와 계수 경로

ridge와 LASSO에서는 \(\lambda\)가 변할 때 회귀계수가 어떻게 변하는지 확인할 수 있다. 이를 계수 경로(coefficient path)라고 한다. ridge에서는 \(\lambda\)가 증가할수록 계수들이 점진적으로 0에 가까워진다. LASSO에서는 \(\lambda\)가 증가할수록 일부 계수가 정확히 0이 된다.

이러한 그림은 다음을 이해하는 데 도움이 된다.

  1. 어떤 변수가 큰 \(\lambda\)에서도 남아 있는가?
  2. 어떤 변수의 계수가 빠르게 0으로 축소되는가?
  3. 상관된 변수들의 계수가 함께 움직이는가?
  4. 선택된 \(\lambda\)에서 어떤 변수들이 모형에 포함되는가?

다중공선성 확인

아래 함수는 별도 패키지 없이 VIF를 계산한다.

vif_lm <- function(model) {
  X <- model.matrix(model)[, -1, drop = FALSE]
  vif_values <- sapply(seq_len(ncol(X)), function(j) {
    r2 <- summary(lm(X[, j] ~ X[, -j, drop = FALSE]))$r.squared
    1 / (1 - r2)
  })
  names(vif_values) <- colnames(X)
  vif_values
}

MASS를 이용한 ridge 예제

MASS 패키지가 설치되어 있으면 lm.ridge()를 이용하여 ridge trace를 확인할 수 있다.

if (requireNamespace("MASS", quietly = TRUE)) {
  lambda_grid <- seq(0, 0.1, by = 0.001)

  fit_ridge_mass <- MASS::lm.ridge(
    Employed ~ GNP.deflator + GNP + Unemployed + Armed.Forces + Population,
    data = longley,
    lambda = lambda_grid
  )

  matplot(fit_ridge_mass$lambda, t(fit_ridge_mass$coef),
          type = "l",
          xlab = expression(lambda),
          ylab = "Standardized ridge coefficients",
          lty = 1)
  abline(h = 0, lty = 2)

  MASS::select(fit_ridge_mass)
} else {
  message("Package 'MASS' is required for lm.ridge().")
}

10.7 예측 성능 비교 예제

규제회귀는 특히 예측 목적에서 자주 사용된다. 아래 예제에서는 훈련자료와 검증자료를 나누어 OLS, ridge, LASSO의 예측오차를 비교한다. longley 자료는 표본 수가 매우 작으므로 결과는 예시로만 해석해야 한다.

set.seed(2026)

n <- nrow(longley)
test_id <- sample(seq_len(n), size = 4)
train_id <- setdiff(seq_len(n), test_id)

train_dat <- longley[train_id, ]
test_dat <- longley[test_id, ]

fit_ols_train <- lm(
  Employed ~ GNP.deflator + GNP + Unemployed + Armed.Forces + Population,
  data = train_dat
)

pred_ols <- predict(fit_ols_train, newdata = test_dat)
rmse_ols <- sqrt(mean((test_dat$Employed - pred_ols)^2))

rmse_result <- data.frame(
  model = "OLS",
  RMSE = rmse_ols
)

if (requireNamespace("glmnet", quietly = TRUE)) {
  x_train <- model.matrix(
    Employed ~ GNP.deflator + GNP + Unemployed + Armed.Forces + Population,
    data = train_dat
  )[, -1]

  y_train <- train_dat$Employed

  x_test <- model.matrix(
    Employed ~ GNP.deflator + GNP + Unemployed + Armed.Forces + Population,
    data = test_dat
  )[, -1]

  set.seed(2026)
  cv_ridge_train <- glmnet::cv.glmnet(x_train, y_train, alpha = 0, nfolds = 5)
  pred_ridge <- as.numeric(predict(cv_ridge_train, newx = x_test, s = "lambda.min"))
  rmse_ridge <- sqrt(mean((test_dat$Employed - pred_ridge)^2))

  set.seed(2026)
  cv_lasso_train <- glmnet::cv.glmnet(x_train, y_train, alpha = 1, nfolds = 5)
  pred_lasso <- as.numeric(predict(cv_lasso_train, newx = x_test, s = "lambda.min"))
  rmse_lasso <- sqrt(mean((test_dat$Employed - pred_lasso)^2))

  rmse_result <- rbind(
    rmse_result,
    data.frame(model = "Ridge", RMSE = rmse_ridge),
    data.frame(model = "LASSO", RMSE = rmse_lasso)
  )
}

예측오차 비교는 모형 선택의 중요한 기준이 될 수 있다. 그러나 표본 수가 작을 때 한 번의 훈련-검증 분할 결과는 매우 불안정할 수 있다. 실제 분석에서는 반복 교차검증, 외부 검증자료, 또는 부트스트랩 등을 이용하여 예측 성능을 더 안정적으로 평가하는 것이 좋다.


10.8 결과 해석 시 주의점

규제회귀 결과를 해석할 때는 다음을 주의해야 한다.

  1. ridge와 LASSO의 회귀계수는 벌점에 의해 축소된 추정값이다.
  2. LASSO에서 선택된 변수만이 과학적으로 중요하다고 단정해서는 안 된다.
  3. 변수들이 강하게 상관되어 있으면 LASSO는 그중 일부만 선택할 수 있다.
  4. \(\lambda\) 선택은 자료와 교차검증 분할에 따라 달라질 수 있다.
  5. 설명 목적 연구에서는 변수선택 결과보다 연구 설계와 교란변수 보정이 더 중요할 수 있다.
  6. 예측 목적 연구에서는 회귀계수의 p-value보다 검증자료에서의 예측오차가 더 중요하다.
