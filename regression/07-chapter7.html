7  다중회귀분석 예제

이 장은 앞에서 배운 다중회귀분석, 모형비교, 변수선택, 회귀진단을 하나의 자료에 적용하는 예제 장이다. 실제 분석에서는 회귀모형을 한 번 적합하고 끝내는 것이 아니라, 자료 탐색, 모형 적합, 변수선택, 다중공선성 확인, 영향점 진단, 잔차진단, 최종모형 해석의 순서로 분석을 진행한다.

이 장의 분석 흐름은 다음과 같다.

  1. 데이터 구조와 변수 분포 확인
  2. 산점도 행렬을 이용한 변수 간 관계 탐색
  3. 모든 설명변수를 포함한 완전모형 적합
  4. 회귀계수, 결정계수, 수정결정계수 해석
  5. 단계별 변수선택을 이용한 후보모형 설정
  6. VIF를 이용한 다중공선성 진단
  7. Cook의 거리, DFFITS, 지렛대값을 이용한 영향점 진단
  8. 잔차그림과 통계적 검정을 이용한 회귀가정 점검
  9. 최종모형 제안 및 예측

자료의 구조를 확인하는 것은 회귀분석의 첫 단계이다. 반응변수와 설명변수가 모두 수치형인지, 결측값이나 비정상적인 값이 있는지, 변수의 범위가 분석 목적에 적절한지 확인해야 한다. 이 예제에서는 Y를 반응변수로, X1부터 X6까지를 설명변수로 사용한다.

  • 산점도 행렬
pairs(multi)
  • 산점도 행렬을 살펴보면, 반응변수 \(Y\)와 여러 설명변수 사이에 선형적인 관계가 나타나는지 확인할 수 있다. 특히 일부 설명변수는 \(Y\)와 뚜렷한 선형 관계를 보이며, 설명변수들 사이에도 서로 관련성이 존재할 수 있다.

산점도 행렬은 두 가지 목적에서 중요하다. 첫째, 반응변수와 설명변수 사이의 관계가 선형회귀모형으로 설명하기에 적절한지 살펴볼 수 있다. 둘째, 설명변수들 사이의 강한 관련성을 미리 확인하여 다중공선성 가능성을 점검할 수 있다. 따라서 산점도 행렬은 단순한 그림이 아니라 이후 모형 적합과 회귀진단의 방향을 정하는 탐색 단계로 이해해야 한다.

7.2 다중선형회귀분석

  • 6개의 설명변수 \(X\)와 반응변수 \(Y\)와의 다중선형회귀모형

\[ Y_i=\beta_0+\beta_1X_{1i}+\beta_2X_{2i}+\beta_3X_{3i}+\beta_4X_{4i}+\beta_5X_{5i}+\beta_6X_{6i}+\epsilon_i, \,\,\, i=1,2,\cdots, 40 \]

  • 모형을 행렬로 다시 표현하면

\[ \mathbf{Y}=\mathbf{X}\beta+\epsilon \]

  • 여기서

\[ \begin{pmatrix} Y_1\\Y_2\\\vdots\\Y_{40} \end{pmatrix}=\begin{pmatrix}1 & X_{1,1}&X_{1,2}&\cdots&X_{1,6}\\ 1 &X_{2,1}&X_{2,2}&\cdots &X_{2,6}\\ &\vdots & &\vdots &\\ 1&X_{40,1}&X_{40,2}&\cdots&X_{40,6} \end{pmatrix} \begin{pmatrix}\beta_0\\ \beta_1\\ \vdots \\ \beta_6 \end{pmatrix}+\begin{pmatrix} \epsilon_1\\ \epsilon_2 \\ \vdots \\ \epsilon_{40} \end{pmatrix} \]

      여기서 \(\mathbf{Y}\)는 반응변수벡터, \(\mathbf{X}\)는 \(40\times 7\) 설계행렬(design matrix), \(\beta\)는 회귀계수벡터이고 \(\epsilon\)은 오차벡터

  • 완전모형에 대한 최소제곱 추정
fit_full <- lm(Y ~ X1 + X2 + X3 + X4 + X5 + X6, data = multi)

완전모형은 사용 가능한 모든 설명변수를 포함한 모형이다. 완전모형을 먼저 적합하면 각 설명변수의 보정 효과를 확인할 수 있고, 이후 변수선택이나 모형비교의 출발점으로 사용할 수 있다. 다만 완전모형이 항상 최종모형이 되는 것은 아니다. 불필요한 설명변수나 다중공선성이 존재하면 회귀계수의 해석이 불안정해질 수 있다.

  • 따라서 추정된 회귀식은

\[ \hat{Y}=\hat{\beta}_0+\hat{\beta}_1X1+\hat{\beta}_2X2+\hat{\beta}_3X3+\hat{\beta}_4X4+\hat{\beta}_5X5+\hat{\beta}_6X6 \]

  • 추정된 회귀식은 자료에 따라 달라질 수 있으므로, 실제 수치는 summary(fit_full) 결과의 Estimate 값을 이용하여 해석한다.

수정된 \(R^2\)는 설명변수의 개수를 고려하여 모형의 설명력을 평가하는 지표이다. \(R^2\)가 높다는 것은 반응변수의 변동 중 상당 부분이 회귀모형으로 설명된다는 의미이지만, 이것만으로 모형이 적절하다고 결론 내릴 수는 없다. 회귀계수의 해석 가능성, 다중공선성, 영향점, 잔차진단 결과를 함께 확인해야 한다.

7.3 단계별 회귀에 의한 변수 선택

  • 회귀모형에서 종속변수를 설명하기 위한 독립변수들 중에서 어떤 독립변수를 포함시키는 것이 최적의 모형이 되는지를 판단하는 것은 매우 중요한 문제임

  • 단계별 변수선택법에서는 선택 기준에 따라 설명변수를 추가하거나 제거하여 상대적으로 간결한 후보 회귀모형을 설정할 수 있음

fit_full <- lm(Y ~ X1 + X2 + X3 + X4 + X5 + X6, data = multi)

단계별 변수선택은 AIC와 같은 기준을 이용하여 후보모형을 탐색하는 방법이다. 그러나 선택된 모형이 항상 이론적으로 가장 좋은 모형이라는 뜻은 아니다. 최종모형은 변수선택 결과뿐 아니라 변수의 의미, 다중공선성, 영향점, 잔차진단 결과를 함께 고려하여 결정해야 한다.

축소모형의 회귀계수는 네 개의 설명변수를 서로 보정한 후의 효과로 해석한다. 예를 들어 X1의 회귀계수는 X2, X3, X4가 같은 조건에서 X1이 한 단위 증가할 때 Y의 평균이 얼마나 달라지는지를 의미한다.

  • 따라서 축소된 회귀모형은

\[ \hat{Y}=\hat{\beta}_0+\hat{\beta}_1X1+\hat{\beta}_2X2+\hat{\beta}_3X3+\hat{\beta}_4X4 \]

  • 실제 회귀식의 수치는 summary(fit_reduced) 결과에서 확인한다.

축소모형의 수정된 \(R^2\)가 완전모형과 비슷하다면, 더 적은 설명변수로도 반응변수의 변동을 충분히 설명할 수 있음을 의미한다. 이 경우 모형의 간결성과 해석 가능성 측면에서 축소모형이 더 적절할 수 있다.


7.4 다중공선성

  • 다중공선성을 확인하기 위해 분산팽창계수 VIF를 고려함
vif_lm <- function(model) {
  X <- model.matrix(model)[, -1, drop = FALSE]
  vif_values <- sapply(seq_len(ncol(X)), function(j) {
    r2 <- summary(lm(X[, j] ~ X[, -j, drop = FALSE]))$r.squared
    1 / (1 - r2)
  })
  names(vif_values) <- colnames(X)
  vif_values
}

7.5 지렛대점과 이상점

  • 회귀분석 문제의 데이터에서 종종 특이하거나 극단적인 관측값을 볼 수 있음

  • 영향력을 진단하는 방법인 지렛대점, 모자행렬, 잔차들을 이용하여 이상점을 찾아보고자 함

  • 쿡의 거리는 모든 개체를 이용한 예측값 \(\hat{Y}_i\)와 \(i\)번째 관측값을 제외하고 구한 예측값 \(\hat{Y}_{(i)}\)과의 차이에 근거한 통계량으로, 이 값이 클수록 \(i\)번째 관측값은 이상점 혹은 영향점일 가능성이 높음

  • 기준값 1 이상이면 이상점으로 판단될 수 있으며, 영향점의 기준은 \(D>4/n\) 또는 \(D>4/(n-p-1)\)을 이용

  • Cook’s D plot: identify \(D\) values \(>4/(n-p-1)=0.1212\)

p <- length(coef(fit_reduced)) - 1
cutoff <- 4 / (nrow(multi) - p - 1)

7.6 잔차분석

  • 다중선형회귀모형에서 오차항에 대한 선형성, 등분산성, 독립성, 정규성 가정에 대한 검토가 필요함

잔차분석은 최종모형을 제안하기 전 반드시 수행해야 하는 단계이다. 회귀계수의 p-value나 수정결정계수가 좋아 보이더라도 잔차에서 뚜렷한 패턴이 나타나면 모형이 자료의 구조를 충분히 반영하지 못하고 있을 수 있다. 따라서 잔차와 적합값의 관계, Q-Q plot, 등분산성 검정, 독립성 검정을 함께 확인한다.

  • 적합값 vs. 잔차 그림
plot(fit_reduced, which = 1)
plot(fit_reduced, which = 3)

  • 잔차 그림에서는 기본적으로 잔차에 대한 등분산성을 살펴볼 수 있음

  • 그림을 살펴보면 0을 중심으로 랜덤하게 분포되어 보이기는 하지만 관측값 38번, 34번에 의해 수평대의 형태를 약간 벗어난 것으로 보임. 그러나 전반적으로 잔차가 수평대 이내에 놓여 있고 양이나 음의 값이 계통적(systematic)인 경향을 보이지 않고 랜덤하게 나타나고 있으므로 선형성을 대체로 만족한다고 할 수 있음.

  • 편잔차그림을 이용해 다중회귀의 선형성에 대한 검토를 할 수 있음

  • 편잔차그림에서 직선을 살펴보면 선형성을 만족하는 경우의 점선에 가까운 편이므로 모형에 적합된 변수들이 선형성을 크게 벗어나지 않는다고 여겨져 선형모형의 타당성을 뒷받침 함
