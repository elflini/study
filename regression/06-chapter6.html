6  가변수 회귀모형

회귀분석에서는 설명변수가 반드시 연속형일 필요는 없다. 성별, 치료군, 지역, 교육수준, 질병상태처럼 범주로 표현되는 변수도 회귀모형에 포함할 수 있다. 이때 범주형 변수를 그대로 수치처럼 해석하면 안 되며, 기준범주를 정하고 나머지 범주와 비교하는 방식으로 모형을 구성해야 한다. 이를 위해 사용하는 변수가 가변수(dummy variable) 이다.


6.1 이분 가변수 경우

설명변수 \(X\)와 이분 범주형 변수 \(A\)를 포함한 다음의 회귀모형을 생각해보자.

\[ Y=\beta_0+\beta_1A+\beta_2X+\epsilon \]

여기서 \(A\)는 0 또는 1의 값을 갖는 이분 범주형 변수이고, \(X\)는 연속형 설명변수이다. 예를 들어 \(A=0\)은 남자, \(A=1\)은 여자라고 하자. 이 모형은 다음과 같이 범주별 회귀식으로 다시 쓸 수 있다.

\[ Y=\begin{cases} \beta_0+\beta_2X+\epsilon, & A=0 \\ \beta_0+\beta_1+\beta_2X+\epsilon, & A=1 \end{cases} \]

따라서 평균 반응함수는 다음과 같다.

\[ E(Y)=\begin{cases} \beta_0+\beta_2X, & A=0 \\ \beta_0+\beta_1+\beta_2X, & A=1 \end{cases} \]

이 모형에서 \(A=0\)은 기준범주(reference category) 이다. 절편 \(\beta_0\)는 기준범주에서 \(X=0\)일 때의 평균 반응값을 의미한다. \(\beta_1\)은 같은 \(X\) 값을 가진 두 범주 간 평균 차이를 의미한다. \(\beta_2\)는 두 범주에서 공통으로 적용되는 \(X\)의 기울기이다.

따라서 이 모형은 두 범주가 서로 다른 절편을 가지지만, \(X\)에 대한 기울기는 같다고 가정하는 모형이다. 즉, 두 회귀직선은 평행하다.

상호작용항이 없는 모형

상호작용항이 없는 모형은 다음과 같은 상황을 나타낸다.

x <- 1:10
y_group0 <- 2 * x
y_group1 <- 2 * x + 2

plot(x, y_group0, type = "l",
     ylim = range(c(y_group0, y_group1)),
     xlab = "X", ylab = "Expected Y",
     main = "Parallel regression lines")
lines(x, y_group1, lty = 2)
legend("topleft",
       legend = c("A = 0", "A = 1"),
       lty = c(1, 2),
       bty = "n")

두 직선의 기울기는 같고 절편만 다르다. 이 경우 가변수의 회귀계수는 모든 \(X\) 값에서 일정한 집단 간 평균 차이를 의미한다.

상호작용항이 있는 모형

범주에 따라 \(X\)의 효과가 달라질 수 있다면 상호작용항을 포함한다.

\[ Y=\beta_0+\beta_1A+\beta_2X+\beta_{12}AX+\epsilon \]

이분변수 \(A\)에 따라 다시 쓰면 다음과 같다.

\[ Y=\begin{cases} \beta_0+\beta_2X+\epsilon, & A=0 \\ \beta_0+\beta_1+(\beta_2+\beta_{12})X+\epsilon, & A=1 \end{cases} \]

여기서 \(\beta_{12}\)는 \(A=1\)인 집단에서 \(X\)의 기울기가 기준범주에 비해 얼마나 달라지는지를 나타낸다. 즉, \(\beta_{12}\)는 기울기 차이를 의미한다.

x <- 1:10
y_group0 <- 1 * x
y_group1 <- 2 * x - 6

plot(x, y_group0, type = "l",
     ylim = range(c(y_group0, y_group1)),
     xlab = "X", ylab = "Expected Y",
     main = "Regression lines with interaction")
lines(x, y_group1, lty = 2)
legend("topleft",
       legend = c("A = 0", "A = 1"),
       lty = c(1, 2),
       bty = "n")

상호작용항이 있는 모형에서는 두 집단 간 차이가 \(X\)의 값에 따라 달라진다. 따라서 \(\beta_1\)을 단순히 전체적인 집단 차이로 해석하면 안 된다. \(\beta_1\)은 \(X=0\)일 때의 집단 간 차이를 의미하며, 다른 \(X\) 값에서의 집단 차이는 \(\beta_1+\beta_{12}X\)로 계산된다.


6.2 두 개 회귀직선의 비교

그룹별로 회귀직선을 따로 추정한 뒤, 두 회귀직선이 같은지 또는 평행한지 검정할 수 있다. 예를 들어 남성과 여성에 대해 각각 다음과 같은 회귀모형을 적합한다고 하자.

\[ \begin{cases} Y_m=\beta_{0m}+\beta_{1m}X+\epsilon, & Male \\ Y_f=\beta_{0f}+\beta_{1f}X+\epsilon, & Female \end{cases} \]

두 회귀직선을 비교할 때는 다음 두 가지 질문을 구분해야 한다.

  1. 평행성 검정: 두 집단의 기울기가 같은가?
  2. 일치성 검정: 두 집단의 절편과 기울기가 모두 같은가?

평행성은 두 직선의 기울기가 같은지를 보는 것이고, 일치성은 두 직선이 완전히 같은지를 보는 것이다. 두 직선이 일치하면 당연히 평행하지만, 평행하다고 해서 반드시 일치하는 것은 아니다.

회귀직선의 평행성 검정

평행성 검정의 귀무가설은 다음과 같다.

\[ H_0:\beta_{1m}=\beta_{1f} \]

가변수를 이용하여 하나의 모형으로 표현하면 다음과 같다.

\[ Y=\beta_0+\beta_1X+\beta_2Z+\beta_3XZ+\epsilon \]

여기서 \(Z=0\)은 기준집단, \(Z=1\)은 비교집단이다. 평균 반응함수는 다음과 같다.

\[ E(Y)=\begin{cases} \beta_0+\beta_1X, & Z=0 \\ (\beta_0+\beta_2)+(\beta_1+\beta_3)X, & Z=1 \end{cases} \]

따라서 두 회귀직선의 기울기가 같다는 귀무가설은 다음과 같이 표현된다.

\[ H_0:\beta_3=0 \]

즉, 상호작용항의 회귀계수가 0인지 검정하면 평행성 검정을 수행할 수 있다. R에서는 summary()의 t-검정 또는 중첩모형 비교를 위한 anova()를 사용할 수 있다.

회귀직선의 일치성 검정

두 회귀직선이 완전히 같으려면 절편과 기울기가 모두 같아야 한다.

\[ H_0:\beta_{0m}=\beta_{0f},\qquad \beta_{1m}=\beta_{1f} \]

가변수 모형에서는 다음과 같은 완전모형과 축소모형을 비교한다.

완전모형:

\[ Y=\beta_0+\beta_1X+\beta_2Z+\beta_3XZ+\epsilon \]

축소모형:

\[ Y=\beta_0+\beta_1X+\epsilon \]

두 모형의 차이는 \(Z\)와 \(XZ\) 항이 포함되어 있는지 여부이다. 따라서 다음 가설을 부분 F-검정으로 검정한다.

\[ H_0:\beta_2=\beta_3=0 \]

귀무가설을 기각하지 못하면 두 집단을 구분하지 않고 하나의 회귀직선으로 설명해도 충분하다고 볼 수 있다. 반대로 귀무가설을 기각하면 집단에 따라 회귀직선이 다르다고 해석한다.


6.3 다항 가변수 경우

범주가 두 개보다 많은 경우에도 가변수를 사용할 수 있다. 범주가 \(q\)개인 질적 변수를 회귀모형에 포함할 때는 일반적으로 \(q-1\)개의 가변수를 사용한다.

예를 들어 세 개의 범주 \(A=1,2,3\)이 있다고 하자. \(A=3\)을 기준범주로 두면 다음과 같이 두 개의 가변수를 만들 수 있다.

\[ A_1= \begin{cases} 1, & A=1\\ 0, & \text{otherwise} \end{cases} \qquad A_2= \begin{cases} 1, & A=2\\ 0, & \text{otherwise} \end{cases} \]

그러면 회귀모형은 다음과 같이 쓸 수 있다.

\[ Y=\beta_0+\beta_1A_1+\beta_2A_2+\gamma X+\epsilon \]

평균 반응함수는 다음과 같다.

\[ E(Y)=\begin{cases} \beta_0+\beta_1+\gamma X, & A=1 \\ \beta_0+\beta_2+\gamma X, & A=2 \\ \beta_0+\gamma X, & A=3 \end{cases} \]

여기서 기준범주는 \(A=3\)이다. \(\beta_1\)은 \(A=1\)과 \(A=3\)의 평균 차이를 의미하고, \(\beta_2\)는 \(A=2\)와 \(A=3\)의 평균 차이를 의미한다. 두 회귀계수 모두 같은 \(X\) 값을 가진 경우의 차이로 해석한다.

왜 \(q-1\)개의 가변수를 사용하는가?

세 범주에 대해 \(A_1\), \(A_2\), \(A_3\)를 모두 만들고 절편까지 포함하면 다음 관계가 성립한다.

\[ A_1+A_2+A_3=1 \]

그런데 회귀모형에는 이미 절편항이 포함되어 있으므로, 세 가변수의 합은 절편열과 완전히 같은 정보를 갖게 된다. 이 경우 설계행렬의 열들 사이에 완전한 선형종속성이 생기며, 이를 가변수 함정(dummy variable trap) 이라고 한다. 따라서 절편이 있는 회귀모형에서는 범주가 \(q\)개이면 \(q-1\)개의 가변수만 사용해야 한다.

다항 가변수와 상호작용

범주별로 \(X\)의 기울기가 다르다고 생각되면 상호작용항을 포함한다.

\[ Y=\beta_0+\beta_1A_1+\beta_2A_2+\gamma X+\beta_3A_1X+\beta_4A_2X+\epsilon \]

이때 평균 반응함수는 다음과 같다.

\[ E(Y)=\begin{cases} \beta_0+\beta_1+(\gamma+\beta_3)X, & A=1 \\ \beta_0+\beta_2+(\gamma+\beta_4)X, & A=2 \\ \beta_0+\gamma X, & A=3 \end{cases} \]

상호작용항이 포함되면 범주별 기울기가 달라진다. 이 경우 범주 간 차이는 \(X\)의 값에 따라 달라지므로, 단순히 절편 차이만으로 집단 차이를 설명할 수 없다.


6.4 R 활용 가변수 회귀분석

6.4.1 예제 1: 구름 데이터

1975년 미국 플로리다 주에서 구름에 silver iodide 씨앗을 뿌린 후 강수량 증가를 관찰한 실험 자료를 사용한다. 이 자료에는 씨앗을 뿌렸는지 여부(seeding), 구름의 적합도(sne), 구름 형태(echomotion), 강수량(rainfall) 등이 포함되어 있다.

아래 코드는 HSAUR 패키지가 설치되어 있으면 실제 clouds 자료를 사용하고, 설치되어 있지 않으면 렌더링을 위해 유사한 예제 자료를 생성한다.

if (requireNamespace("HSAUR", quietly = TRUE)) {
  data("clouds", package = "HSAUR")
} else {
  set.seed(2026)
  n <- 40
  clouds <- data.frame(
    rainfall = rgamma(n, shape = 3, rate = 0.35),
    seeding = factor(sample(c("no", "yes"), n, replace = TRUE)),
    sne = runif(n, 1, 5),
    echomotion = factor(sample(c("moving", "stationary"), n, replace = TRUE)),
    cloudcover = runif(n, 20, 100),
    prewetness = runif(n, 0, 2)
  )
  clouds$rainfall <- 2 + 1.8 * clouds$sne +
    ifelse(clouds$seeding == "yes", 2.5, 0) +
    ifelse(clouds$echomotion == "stationary", 1.5, 0) +
    rnorm(n, 0, 2)
}

clouds$seeding <- relevel(factor(clouds$seeding), ref = "no")
clouds$echomotion <- relevel(factor(clouds$echomotion), ref = "moving")

6.5 기준범주 변경과 해석

가변수 회귀모형에서 기준범주를 바꾸면 회귀계수의 값과 해석은 달라진다. 하지만 모형의 적합값, 잔차, \(R^2\)는 변하지 않는다. 즉, 기준범주의 변경은 모형 자체를 바꾸는 것이 아니라 비교의 기준을 바꾸는 것이다.

fit_low_ref <- lm(Y ~ level + X, data = twin)

twin$level_high_ref <- relevel(twin$level, ref = "high")
fit_high_ref <- lm(Y ~ level_high_ref + X, data = twin)

기준범주를 바꾸면 어떤 집단과 어떤 집단을 직접 비교하는지가 달라진다. 따라서 연구 질문에서 가장 자연스러운 기준집단을 설정하는 것이 좋다. 예를 들어 치료군 연구에서는 대조군을 기준범주로 두는 것이 일반적이다.
