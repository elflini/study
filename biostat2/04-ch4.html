4  로지스틱 회귀분석

이번 장에서는 로지스틱 회귀(logistic regression)를 단순한 분석 도구가 아니라, 이진 결과변수의 확률을 모형화하는 일반화선형모형(GLM)의 대표 예로 이해한다.

로지스틱 회귀는 다음과 같은 의학 연구 질문에서 가장 자주 사용된다.

  • 흡연자는 비흡연자보다 폐암 발생 odds가 높은가?
  • 나이, 성별, BMI를 조정해도 특정 바이오마커가 질병 발생과 관련되는가?
  • 치료 반응 여부를 기저 특성으로 예측할 수 있는가?
  • 중환자실 입원 환자의 사망 위험을 예측할 수 있는가?
  • 진단모형의 discrimination과 calibration은 적절한가?

로지스틱 회귀의 핵심은 결과변수가 0 또는 1일 때, 사건 발생확률 \(p_i=P(Y_i=1)\) 자체를 직접 선형모형으로 두지 않고, odds의 로그값인 logit을 설명변수들의 선형결합으로 모형화한다는 것이다.

\[\log \left( \frac{p_i}{1-p_i} \right) = \beta_0+\beta_1X_{1i}+\cdots+\beta_pX_{pi}\]

Note핵심 메시지

로지스틱 회귀는 이진 결과변수의 평균, 즉 사건 발생확률을 직접 선형으로 모델링하지 않고, logit 변환된 확률을 선형 예측자와 연결한다.

4.1 이진 결과변수와 베르누이 모형

4.1.1 이진 결과변수

이진 결과변수(binary outcome)는 두 가지 값만 가지는 결과변수이다.

의학 연구 상황 사건 없음, 0 사건 있음, 1
질병 발생 질병 없음 질병 있음
사망 생존 사망
치료 반응 무반응 반응
재입원 재입원 없음 재입원
검사 결과 음성 양성
합병증 합병증 없음 합병증 있음

로지스틱 회귀에서 가장 먼저 확인해야 할 것은 무엇이 1로 코딩되었는가이다. 사건 정의가 바뀌면 OR의 방향도 바뀐다.

Warning사건 코딩 확인

Y=1이 사망인지 생존인지, 반응인지 무반응인지 반드시 확인해야 한다. 같은 회귀계수라도 사건 정의에 따라 해석이 완전히 달라진다.

4.1.2 베르누이 분포

이진 결과변수 \(Y_i\)는 다음처럼 표현할 수 있다.

\[Y_i= \begin{cases} 1, & \text{사건 발생}\\ 0, & \text{사건 없음} \end{cases}\]

각 대상자의 사건 발생확률을 \(p_i\)라고 하면,

\[p_i=P(Y_i=1)\]

이고,

\[Y_i \sim Bernoulli(p_i)\]

이다.

베르누이 확률변수의 기대값은 다음과 같다.

\[E(Y_i)=p_i\]

분산은 다음과 같다.

\[Var(Y_i)=p_i(1-p_i)\]

이 식은 이진 결과변수에서 중요한 의미를 가진다. 분산이 평균 \(p_i\)에 의해 결정되므로, 선형회귀의 등분산성 가정은 자연스럽지 않다.

4.2 왜 선형회귀가 부적절한가?

4.2.1 Linear probability model

이진 결과변수에 일반 선형회귀를 적용하면 다음과 같은 모형이 된다.

\[p_i = E(Y_i|X_i) = \beta_0+\beta_1X_i\]

이를 linear probability model이라고 한다. 이 모형은 해석이 직관적이라는 장점이 있다. \(\beta_1\)은 \(X\)가 1 증가할 때 사건 발생확률이 얼마나 변하는지 의미한다.

하지만 다음 문제가 있다.

  1. 예측확률이 0보다 작거나 1보다 클 수 있다.
  2. 오차분산이 일정하지 않다.
  3. 확률과 설명변수의 관계를 직선으로 가정한다.
  4. 극단 확률 근처에서 부적절한 예측을 할 수 있다.
  5. 베르누이 분포의 평균-분산 관계를 반영하지 못한다.

4.2.2 이분산성 문제

이진 결과변수에서 오차는 다음과 같다.

\[\epsilon_i=Y_i-p_i\]

분산은 다음과 같다.

\[Var(Y_i|X_i)=p_i(1-p_i)\]

이는 \(p_i\)에 따라 달라진다. 예를 들어 \(p_i=0.5\)이면 분산은 0.25로 가장 크고, \(p_i=0.05\) 또는 0.95이면 분산은 작다.

따라서 이진 결과변수에서 오차분산은 본질적으로 일정하지 않다. 로지스틱 회귀는 베르누이 분포와 logit link를 사용하여 이러한 자료 구조를 더 자연스럽게 반영한다.

4.3 확률, odds, logit

4.3.1 확률

확률은 사건이 발생할 가능성이다.

\[p=P(Y=1)\]

확률은 항상 0과 1 사이에 있다.

\[0 \leq p \leq 1\]

예를 들어 질병 발생확률이 0.20이라면 100명 중 약 20명에서 질병이 발생한다는 뜻이다.

4.3.2 Odds

Odds는 사건이 발생할 확률을 사건이 발생하지 않을 확률로 나눈 값이다.

\[Odds= \frac{p}{1-p}\]

예를 들어 \(p=0.20\)이면,

\[Odds= \frac{0.20}{0.80} = 0.25\]

이는 사건이 발생하지 않을 가능성에 비해 발생할 가능성이 0.25배라는 뜻이다.

4.3.3 Odds에서 확률로 변환

Odds를 알면 확률로 다시 바꿀 수 있다.

\[Odds=\frac{p}{1-p}\]

양변에 \((1-p)\)를 곱하면,

\[Odds(1-p)=p\]

\[Odds-Odds \cdot p=p\]

\[Odds=p(1+Odds)\]

따라서,

\[p= \frac{Odds}{1+Odds}\]

예를 들어 odds가 2이면,

\[p= \frac{2}{1+2} = 0.667\]

이다.

4.3.4 Logit 변환

로지스틱 회귀는 odds의 로그값인 logit을 사용한다.

\[logit(p) = \log \left( \frac{p}{1-p} \right)\]

확률 \(p\)는 0과 1 사이에 있지만, logit은 \(-\infty\)부터 \(+\infty\)까지 값을 가질 수 있다. 따라서 logit은 선형 예측자와 연결하기에 적합하다.

4.4 로지스틱 회귀모형

4.4.1 모형식

로지스틱 회귀모형은 다음과 같다.

\[\log \left( \frac{p_i}{1-p_i} \right) = \beta_0+\beta_1X_{1i}+\beta_2X_{2i}+\cdots+\beta_pX_{pi}\]

왼쪽은 사건 발생 odds의 로그값이고, 오른쪽은 설명변수들의 선형결합이다.

간단히 쓰면,

\[logit(p_i)=\eta_i\]

이고,

\[\eta_i=\mathbf{x}_i^\top\boldsymbol{\beta}\]

이다. 여기서 \(\eta_i\)를 linear predictor라고 부른다.

4.4.2 Inverse logit

로지스틱 회귀에서 예측확률을 얻으려면 logit을 다시 확률로 변환해야 한다.

\[\eta_i= \log \left( \frac{p_i}{1-p_i} \right)\]

양변에 지수함수를 취하면,

\[e^{\eta_i} = \frac{p_i}{1-p_i}\]

따라서 odds는 \(e^{\eta_i}\)이다. 확률은 다음과 같다.

\[p_i= \frac{e^{\eta_i}}{1+e^{\eta_i}}\]

동치로 다음처럼 쓸 수 있다.

\[p_i= \frac{1}{1+e^{-\eta_i}}\]

이 함수를 logistic function 또는 inverse logit function이라고 한다.

4.4.3 GLM 관점

로지스틱 회귀는 일반화선형모형(GLM)의 한 예이다.

GLM 구성요소 로지스틱 회귀
결과분포 Bernoulli 또는 Binomial
평균 \(E(Y_i)=p_i\)
link function logit link
선형예측자 \(\eta_i=\mathbf{x}_i^\top\boldsymbol{\beta}\)

즉 로지스틱 회귀는 다음 구조를 가진다.

\[Y_i \sim Bernoulli(p_i)\]

\[logit(p_i)=\mathbf{x}_i^\top\boldsymbol{\beta}\]

4.5 회귀계수와 odds ratio

4.5.1 회귀계수의 의미

단순 로지스틱 회귀를 생각하자.

\[logit(p) = \beta_0+\beta_1X\]

\(X\)가 1 증가하면 log odds는 \(\beta_1\)만큼 증가한다.

\[logit(p|X+1)-logit(p|X)=\beta_1\]

하지만 log odds는 직관적이지 않다. 따라서 보통 회귀계수를 지수화하여 odds ratio로 해석한다.

\[OR=e^{\beta_1}\]

4.5.2 OR 유도

\(X=0\)일 때 odds를 \(Odds_0\)라고 하자.

\[Odds_0=e^{\beta_0}\]

\(X=1\)일 때 odds는 다음과 같다.

\[Odds_1=e^{\beta_0+\beta_1}\]

따라서 odds ratio는 다음이다.

\[OR= \frac{Odds_1}{Odds_0} = \frac{e^{\beta_0+\beta_1}}{e^{\beta_0}} = e^{\beta_1}\]

즉 로지스틱 회귀계수를 지수화하면 OR이 된다.

4.5.3 OR 해석

OR 해석
1 사건 odds 차이 없음
1보다 큼 사건 odds 증가
1보다 작음 사건 odds 감소

예를 들어 \(OR=2.5\)이면 사건 odds가 2.5배라는 뜻이다. 그러나 “위험이 2.5배”라고 말하면 안 된다. OR은 odds의 비율이지 risk의 비율이 아니다.

WarningOR 해석 주의

OR은 odds ratio이지 risk ratio가 아니다. 사건이 드물 때는 OR이 RR과 비슷하지만, 사건이 흔하면 OR은 RR보다 더 극단적으로 보일 수 있다.

4.5.4 설명변수별 OR 해석

4.5.4.1 이진 설명변수

흡연 여부를 다음처럼 코딩한다고 하자.

\[Smoking= \begin{cases} 1, & \text{흡연자}\\ 0, & \text{비흡연자} \end{cases}\]

모형은 다음과 같다.

\[logit(p)=\beta_0+\beta_1Smoking\]

이때 \(e^{\beta_1}\)은 흡연자의 사건 발생 odds가 비흡연자에 비해 몇 배인지를 나타낸다.

예를 들어 \(e^{\beta_1}=2.2\)라면 다음처럼 해석한다.

흡연자는 비흡연자보다 질병 발생 odds가 2.2배 높다.

4.5.4.2 연속형 설명변수

나이를 설명변수로 사용하는 모형을 생각하자.

\[logit(p)=\beta_0+\beta_1Age\]

이때 \(e^{\beta_1}\)은 나이가 1세 증가할 때 사건 발생 odds가 몇 배로 변하는지를 의미한다.

예를 들어 \(e^{\beta_1}=1.04\)라면,

나이가 1세 증가할 때 사건 발생 odds는 1.04배, 즉 약 4% 증가한다.

단위가 작으면 해석을 바꿀 수 있다. 10세 증가당 OR은 다음과 같다.

\[OR_{10-year} = e^{10\beta_1} = (e^{\beta_1})^{10}\]

만약 1세 증가당 OR이 1.04라면,

\[OR_{10-year} = 1.04^{10} = 1.48\]

이다.

4.5.4.3 범주형 설명변수

세 개 이상의 범주를 가진 설명변수는 기준범주를 정하고 더미변수로 표현한다. 예를 들어 BMI 범주가 normal, overweight, obese라고 하자. normal을 기준범주로 두면 다음과 같다.

BMI category Overweight Obese
Normal 0 0
Overweight 1 0
Obese 0 1

모형은 다음과 같다.

\[logit(p) = \beta_0+\beta_1Overweight+\beta_2Obese\]

이때

  • \(e^{\beta_1}\): normal에 비해 overweight의 사건 odds ratio
  • \(e^{\beta_2}\): normal에 비해 obese의 사건 odds ratio

이다.

4.6 Crude OR과 adjusted OR

4.6.1 Crude OR

Crude OR은 다른 변수를 조정하지 않은 OR이다.

\[logit(p)=\beta_0+\beta_1X\]

여기서 \(e^{\beta_1}\)은 \(X\)와 사건 발생의 단순 관련성을 나타낸다.

4.6.2 Adjusted OR

Adjusted OR은 다른 공변량을 함께 포함한 모형에서 얻은 OR이다.

\[logit(p)=\beta_0+\beta_1X+\beta_2Z_1+\beta_3Z_2\]

이때 \(e^{\beta_1}\)은 \(Z_1\), \(Z_2\)가 같은 대상자들 사이에서 \(X\)가 1 증가하거나 \(X=1\)인 경우의 사건 odds ratio이다.

4.6.3 교란 조정

로지스틱 회귀는 교란변수 조정에 자주 사용된다. 예를 들어 흡연과 질병의 관련성을 평가할 때 나이와 성별이 교란변수일 수 있다.

\[logit(p)=\beta_0+\beta_1Smoking+\beta_2Age+\beta_3Female\]

이때 \(e^{\beta_1}\)은 나이와 성별을 조정한 흡연의 OR이다.

Noteadjusted OR의 해석

Adjusted OR은 “다른 변수들을 통계적으로 고정했을 때”의 조건부 odds ratio이다. 이는 전체 집단에서 단순히 관찰되는 crude OR과 다를 수 있다.

4.7 추정과 추론

4.7.1 최대우도법

선형회귀는 최소제곱법으로 계수를 추정하지만, 로지스틱 회귀는 보통 최대우도법(maximum likelihood estimation, MLE)을 사용한다.

각 대상자의 결과가 베르누이 분포를 따른다고 하면 likelihood는 다음과 같다.

\[L(\boldsymbol{\beta}) = \prod_{i=1}^{n} p_i^{Y_i} (1-p_i)^{1-Y_i}\]

여기서

\[p_i= \frac{1}{1+\exp(-\mathbf{x}_i^\top\boldsymbol{\beta})}\]

이다. 최대우도법은 관측된 자료가 가장 그럴듯하게 나타나도록 하는 \(\boldsymbol{\beta}\)를 찾는다.

4.7.2 Wald confidence interval

로지스틱 회귀계수의 95% 신뢰구간은 log odds 척도에서 다음과 같이 계산한다.

\[\hat{\beta}_j \pm 1.96SE(\hat{\beta}_j)\]

OR의 신뢰구간은 양 끝을 지수화하여 얻는다.

\[\left[ \exp\{\hat{\beta}_j-1.96SE(\hat{\beta}_j)\}, \exp\{\hat{\beta}_j+1.96SE(\hat{\beta}_j)\} \right]\]

예를 들어 \(\hat{\beta}=0.70\), \(SE=0.20\)이면 log odds 신뢰구간은 다음과 같다.

\[0.70 \pm 1.96(0.20) = 0.70 \pm 0.392\]

즉,

\[[0.308,1.092]\]

OR 신뢰구간은 다음이다.

\[[\exp(0.308),\exp(1.092)] = [1.36,2.98]\]

4.7.3 가설검정

로지스틱 회귀에서 보통 다음 귀무가설을 검정한다.

\[H_0:\beta_j=0\]

이는 OR 척도에서는 다음과 같다.

\[H_0:OR_j=1\]

Wald 검정통계량은 다음과 같다.

\[z= \frac{\hat{\beta}_j}{SE(\hat{\beta}_j)}\]

p-value가 작으면 해당 설명변수가 사건 발생 odds와 관련되어 있다는 증거로 해석한다. 다만 p-value만으로 효과의 크기나 임상적 중요성을 판단해서는 안 된다.

##로지스틱 회귀의 주요 가정과 문제

4.7.4 독립성

각 관측값이 독립이어야 한다. 같은 환자를 반복 측정했거나 병원별 군집자료라면 일반 로지스틱 회귀의 표준오차가 부적절할 수 있다. 이 경우 GEE, 혼합효과 로지스틱 회귀, cluster-robust standard error 등을 고려한다.

4.7.5 Logit 선형성

연속형 설명변수는 확률 척도에서 선형일 필요가 없다. 로지스틱 회귀의 선형성 가정은 logit 척도에서의 선형성이다.

\[logit(p)=\beta_0+\beta_1X\]

logit 선형성이 의심되면 다음 방법을 고려한다.

방법 설명
다항항 \(X^2\), \(X^3\) 추가
제한적 cubic spline 유연한 비선형 관계 허용
범주화 임상적 cut-off 기반 그룹화
transformation 로그변환 등
부분잔차 확인 functional form 점검

4.7.6 다중공선성

설명변수들 사이의 강한 상관은 회귀계수의 표준오차를 크게 만들고 해석을 불안정하게 할 수 있다. 선형회귀에서와 마찬가지로 VIF를 확인할 수 있다.

다만 로지스틱 회귀에서도 VIF는 설명변수 행렬의 공선성을 보는 것이므로 결과변수 유형과 무관하게 도움이 된다.

4.7.7 사건 수 부족

로지스틱 회귀에서는 전체 표본 수보다 사건 수가 중요하다. 사건 수가 너무 적고 설명변수가 많으면 계수가 불안정하고 과적합 위험이 커진다.

예전에는 변수 하나당 사건 수 10개라는 경험칙이 자주 사용되었다. 그러나 이는 절대적 규칙이 아니며 사건 비율, 효과크기, 공선성, 모형 복잡도에 따라 달라진다.

실무에서는 다음을 고려한다.

  1. 사건 수와 비사건 수가 충분한가?
  2. 설명변수 수가 과도하지 않은가?
  3. 상호작용항이나 spline을 많이 넣지 않았는가?
  4. 내부검증을 했는가?
  5. penalized regression이 필요한가?

4.7.8 Complete separation

Complete separation은 설명변수가 결과를 완벽하게 구분하는 상황이다. 예를 들어 특정 검사값이 일정 기준 이상이면 모든 대상자가 사건 발생이고, 기준 미만이면 모두 사건 없음인 경우이다.

이 경우 최대우도 추정량이 무한대로 발산할 수 있고, 회귀계수와 표준오차가 매우 크게 나타난다. 해결 방법으로는 다음이 있다.

  • 자료 또는 코딩 오류 확인
  • 범주 통합
  • penalized logistic regression
  • Firth logistic regression
  • 더 많은 자료 확보

4.8 예측성능 평가

4.8.1 예측확률

로지스틱 회귀는 각 대상자의 사건 발생확률을 예측한다.

\[\hat{p}_i= \frac{1}{1+\exp(-\hat{\eta}_i)}\]

예측확률은 0과 1 사이의 값을 가지며, 환자의 위험도 추정에 사용할 수 있다. 그러나 예측확률이 높다고 해서 반드시 분류성능이 좋거나 calibration이 좋다는 뜻은 아니다.

4.8.2 Discrimination

Discrimination은 사건이 발생한 사람과 발생하지 않은 사람을 모형이 얼마나 잘 구분하는지를 의미한다. 대표 지표가 ROC curve와 AUC이다.

ROC curve는 여러 cutoff에서 sensitivity와 1-specificity의 관계를 그린 것이다.

AUC는 무작위로 선택한 사건 발생자와 비발생자 한 쌍에서, 모형이 사건 발생자에게 더 높은 예측확률을 부여할 확률로 해석할 수 있다.

AUC 대략적 해석
0.5 무작위와 같음
0.6–0.7 낮은 구분력
0.7–0.8 보통
0.8–0.9 좋음
>0.9 매우 좋음

4.8.3 Calibration

Calibration은 예측확률이 실제 사건율과 얼마나 잘 일치하는지를 의미한다. 예를 들어 어떤 환자군의 예측위험이 평균 20%라면 실제로 약 20%에서 사건이 발생해야 calibration이 좋다고 할 수 있다.

ImportantDiscrimination과 calibration의 차이

AUC가 높아도 calibration이 나쁠 수 있다. 즉 사건 발생자와 비발생자를 잘 구분하더라도, 예측확률의 절대값이 실제 위험도와 맞지 않을 수 있다.

4.9.10 ROC curve와 AUC

패키지를 사용하지 않고 간단한 ROC curve를 그리는 함수를 작성한다.

roc_points <- function(y, p) {
  cutoffs <- sort(unique(p), decreasing = TRUE)

  tpr <- numeric(length(cutoffs))
  fpr <- numeric(length(cutoffs))

  for (i in seq_along(cutoffs)) {
    pred_class <- ifelse(p >= cutoffs[i], 1, 0)

    tp <- sum(pred_class == 1 & y == 1)
    fp <- sum(pred_class == 1 & y == 0)
    fn <- sum(pred_class == 0 & y == 1)
    tn <- sum(pred_class == 0 & y == 0)

    tpr[i] <- tp / (tp + fn)
    fpr[i] <- fp / (fp + tn)
  }

  data.frame(fpr = fpr, tpr = tpr)
}

roc_dat <- roc_points(dat$cvd, dat$pred)

plot(
  roc_dat$fpr,
  roc_dat$tpr,
  type = "l",
  lwd = 2,
  xlab = "False positive rate",
  ylab = "True positive rate",
  main = "ROC curve"
)

abline(0, 1, lty = 2)

AUC는 pROC 패키지가 설치되어 있으면 쉽게 계산할 수 있다.

4.9.14 모형 비교

중첩된 로지스틱 회귀모형은 likelihood ratio test로 비교할 수 있다.

fit_small <- glm(
  cvd ~ smoking + age,
  data = dat,
  family = binomial
)

fit_large <- glm(
  cvd ~ smoking + age + bmi + female,
  data = dat,
  family = binomial
)

anova(
  fit_small,
  fit_large,
  test = "Chisq"
)
