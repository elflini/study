6  GLM: 일반화선형모형

6.1 수업 개요

이번 장에서는 일반화선형모형(GLM, Generalized Linear Model)을 학습한다. 지금까지 심화 과정에서는 선형회귀, ANOVA, 로지스틱 회귀, Poisson 회귀를 다루었다. 겉으로 보기에는 서로 다른 분석법처럼 보이지만, 이들은 모두 GLM이라는 하나의 큰 틀 안에서 이해할 수 있다.

입문 단계에서는 각 모형을 따로 배웠다.

모형 결과변수 대표 효과척도
선형회귀 연속형 결과 평균 차이
로지스틱 회귀 이진 결과 odds ratio
Poisson 회귀 사건 수 또는 발생률 incidence rate ratio

심화 단계에서는 이 모형들을 따로 외우는 것이 아니라, 다음 질문으로 연결한다.

결과변수는 어떤 확률분포를 따르며, 그 평균은 어떤 link function을 통해 설명변수의 선형결합과 연결되는가?

GLM의 핵심은 다음 세 요소이다.

  1. 결과변수의 확률분포
  2. 설명변수의 선형결합
  3. 평균과 선형결합을 연결하는 link function

GLM을 이해하면 다양한 의학 자료 구조에 맞는 모형을 체계적으로 선택할 수 있다. 또한 회귀계수를 어떤 척도에서 해석해야 하는지, 예측값이 어떤 척도로 반환되는지, deviance와 AIC가 무엇을 의미하는지 더 명확히 이해할 수 있다.

Note핵심 메시지

GLM은 결과변수의 분포와 평균 구조를 link function으로 연결하는 회귀모형의 공통 언어이다.

7 GLM이 필요한 이유

7.1 선형회귀의 한계

전통적인 선형회귀는 매우 강력하지만 모든 자료에 적합하지는 않다. 선형회귀의 기본 형태는 다음과 같다.

\[Y_i = \beta_0 + \beta_1X_{1i} + \cdots + \beta_pX_{pi} + \epsilon_i\]

이 모형은 결과변수가 연속형이고, 평균 주변의 오차가 대체로 정규분포를 따르며, 분산이 일정할 때 자연스럽다. 그러나 의학 연구의 결과변수는 항상 연속형이 아니다.

결과변수 유형 예 선형회귀의 문제 적절한 GLM
연속형 혈압, 혈당 대체로 적절 Normal + identity
이진형 사망, 질병 발생 예측확률이 0–1 밖으로 나갈 수 있음 Bernoulli + logit
사건 수 입원 횟수 음수 예측 가능, 분산 구조 부적절 Poisson + log
발생률 person-time당 사건 관찰시간 차이 무시 가능 Poisson + log + offset
양수·비대칭 의료비, 입원기간 정규성 위반, 음수 예측 가능 Gamma + log 등

7.2 GLM의 핵심 아이디어

GLM은 선형회귀를 다음 방향으로 일반화한다.

  1. 결과변수가 반드시 정규분포일 필요가 없다.
  2. 평균을 설명변수의 선형결합과 직접 연결하지 않아도 된다.
  3. 결과변수의 분포에 맞는 평균-분산 관계를 허용한다.
  4. 회귀계수 해석은 link function에 의해 결정된다.

즉 GLM은 다음 질문에 답한다.

\(Y_i\)의 평균 \(\mu_i=E(Y_i)\)를 어떤 척도로 변환하면 설명변수의 선형결합 \(\eta_i\)와 자연스럽게 연결할 수 있는가?

이때 \(\eta_i\)는 linear predictor이다.

7.3 \[\eta_i = \beta_0 + \beta_1X_{1i} + \cdots + \beta_pX_{pi}\]

8 GLM의 세 구성요소

8.1 Random component

Random component는 결과변수 \(Y_i\)가 어떤 확률분포를 따르는지 지정한다. 이는 자료의 확률적 변동 구조를 설명한다.

결과변수 대표 분포
연속형 결과 Normal
이진 결과 Bernoulli 또는 Binomial
사건 수 Poisson
양수·오른쪽 치우침 Gamma
과분산 count Negative binomial

예를 들어 선형회귀에서는 다음을 가정한다.

\[Y_i \sim N(\mu_i,\sigma^2)\]

로지스틱 회귀에서는 다음과 같다.

\[Y_i \sim Bernoulli(p_i)\]

Poisson 회귀에서는 다음과 같다.

\[Y_i \sim Poisson(\mu_i)\]

8.2 Systematic component

Systematic component는 설명변수들의 선형결합이다.

\[\eta_i = \beta_0 + \beta_1X_{1i} + \beta_2X_{2i} + \cdots + \beta_pX_{pi}\]

여기서 \(\eta_i\)는 linear predictor라고 부른다. 선형회귀, 로지스틱 회귀, Poisson 회귀 모두 이 systematic component를 가진다.

행렬로 쓰면 다음과 같다.

\[\boldsymbol{\eta} = \mathbf{X}\boldsymbol{\beta}\]

여기서 \(\mathbf{X}\)는 design matrix이고, \(\boldsymbol{\beta}\)는 회귀계수 벡터이다.

8.3 Link function

Link function은 결과변수 평균과 linear predictor를 연결한다.

\[g(\mu_i)=\eta_i\]

여기서

  • \(g(\cdot)\): link function
  • \(\mu_i=E(Y_i)\): 결과변수의 평균
  • \(\eta_i\): linear predictor

이다.

따라서 GLM의 일반적 형태는 다음과 같다.

\[g(E[Y_i]) = \mathbf{x}_i^\top\boldsymbol{\beta}\]

Tip기억하기

GLM은 “결과변수의 분포”, “설명변수의 선형결합”, “둘을 연결하는 link function”으로 구성된다.

9 대표 GLM 비교

9.1 선형회귀는 GLM이다

선형회귀는 Normal distribution과 identity link를 사용하는 GLM이다.

\[Y_i \sim N(\mu_i,\sigma^2)\]

\[g(\mu_i)=\mu_i\]

따라서,

\[\mu_i = \beta_0+\beta_1X_{1i}+\cdots+\beta_pX_{pi}\]

선형회귀에서 회귀계수는 평균 차이로 해석한다.

9.2 로지스틱 회귀는 GLM이다

로지스틱 회귀는 Bernoulli 또는 Binomial distribution과 logit link를 사용하는 GLM이다.

\[Y_i \sim Bernoulli(p_i)\]

\[g(p_i) = \log \left( \frac{p_i}{1-p_i} \right)\]

따라서,

\[\log \left( \frac{p_i}{1-p_i} \right) = \beta_0+\beta_1X_{1i}+\cdots+\beta_pX_{pi}\]

회귀계수를 지수화하면 odds ratio가 된다.

\[OR=e^{\beta_j}\]

9.3 Poisson 회귀는 GLM이다

Poisson 회귀는 Poisson distribution과 log link를 사용하는 GLM이다.

\[Y_i \sim Poisson(\mu_i)\]

\[g(\mu_i)=\log(\mu_i)\]

따라서,

\[\log(\mu_i) = \beta_0+\beta_1X_{1i}+\cdots+\beta_pX_{pi}\]

회귀계수를 지수화하면 incidence rate ratio가 된다.

\[IRR=e^{\beta_j}\]

9.4 세 가지 GLM 비교표

모형 Random component Link function 평균 구조 효과척도
Linear regression Normal Identity \(\mu_i=\eta_i\) Mean difference
Logistic regression Bernoulli Logit \(\log\{p_i/(1-p_i)\}=\eta_i\) Odds ratio
Poisson regression Poisson Log \(\log(\mu_i)=\eta_i\) IRR

10 Link function의 역할

10.1 왜 link function이 필요한가?

결과변수의 평균은 자료형에 따라 가능한 범위가 다르다.

결과변수 평균의 범위
연속형 정규 결과 \(-\infty < \mu < \infty\)
이진 결과의 확률 \(0 < p < 1\)
사건 수의 기대값 \(\mu > 0\)

선형예측자 \(\eta=\mathbf{x}^\top\boldsymbol{\beta}\)는 실수 전체를 가질 수 있다.

\[-\infty < \eta < \infty\]

따라서 평균의 자연스러운 범위와 선형예측자의 범위를 맞추는 함수가 필요하다. 이것이 link function의 역할이다.

10.2 Identity link

Identity link는 평균을 그대로 linear predictor와 연결한다.

\[g(\mu)=\mu\]

따라서,

\[\mu=\eta\]

이는 선형회귀에서 사용된다. 평균이 실수 전체를 가질 수 있는 연속형 결과변수에 자연스럽다.

10.3 Logit link

Logit link는 확률을 odds의 로그로 변환한다.

\[g(p) = \log \left( \frac{p}{1-p} \right)\]

확률 \(p\)는 0과 1 사이에 있지만 logit은 실수 전체를 가질 수 있다. 따라서 이진 결과변수의 평균인 사건확률을 선형예측자와 연결하기에 적합하다.

Inverse logit은 다음과 같다.

\[p= \frac{1}{1+\exp(-\eta)}\]

10.4 Log link

Log link는 양수 평균을 로그로 변환한다.

\[g(\mu)=\log(\mu)\]

따라서,

\[\mu=\exp(\eta)\]

이는 기대 사건 수나 발생률처럼 양수여야 하는 평균에 적합하다. Poisson regression, negative binomial regression, Gamma regression에서 자주 사용된다.

10.5 Link scale과 response scale

GLM에서는 결과를 두 가지 척도에서 생각해야 한다.

척도 의미 예
Link scale \(g(\mu)\)의 척도 logit, log
Response scale 원래 평균의 척도 확률, 기대 count, 평균 혈압

예를 들어 로지스틱 회귀에서 회귀식은 logit scale에서 선형이다.

\[logit(p)=\beta_0+\beta_1X\]

하지만 확률 scale에서는 S자 곡선이 된다.

Important계수 해석의 핵심

GLM의 회귀계수는 link scale에서의 변화량이다. 따라서 해석할 때는 link function에 맞게 변환해야 한다.

11 Exponential family

11.1 GLM에서 사용하는 분포군

GLM은 일반적으로 exponential family에 속하는 분포를 사용한다. 대표적으로 다음 분포들이 포함된다.

분포 자료 유형 대표 link
Normal 연속형 결과 Identity
Bernoulli/Binomial 이진 또는 비율 Logit
Poisson 사건 수 Log
Gamma 양수·오른쪽 치우침 Log, inverse
Inverse Gaussian 양수·심한 비대칭 inverse squared 등

11.2 평균-분산 관계

GLM에서 분포를 선택한다는 것은 단순히 모양을 고르는 것이 아니라 평균과 분산의 관계를 정하는 것이다.

분포 평균 분산 구조
Normal \(\mu\) \(\sigma^2\)
Bernoulli \(p\) \(p(1-p)\)
Poisson \(\mu\) \(\mu\)
Gamma \(\mu\) \(\phi\mu^2\)

예를 들어 Poisson 분포는 평균이 커지면 분산도 같은 크기로 커진다. Gamma 분포는 평균이 커질수록 분산이 평균의 제곱에 비례하여 커진다.

11.3 Canonical link

일부 link function은 해당 분포의 canonical link이다.

분포 Canonical link
Normal Identity
Bernoulli/Binomial Logit
Poisson Log
Gamma Inverse

Canonical link는 수학적으로 편리한 성질을 가진다. 하지만 항상 canonical link를 사용해야 하는 것은 아니다. 연구질문과 해석 가능성, 예측값의 범위, 모형 적합도를 함께 고려해야 한다.

12 추정과 모형 적합도

12.1 Maximum likelihood

GLM의 회귀계수는 보통 최대우도법(maximum likelihood estimation, MLE)으로 추정한다. 최대우도법은 관측된 자료가 가장 그럴듯하게 나타나도록 하는 모수값을 찾는 방법이다.

로지스틱 회귀와 Poisson 회귀는 일반적으로 닫힌 형태의 해가 없어서 반복 알고리즘을 통해 계수를 추정한다. R의 glm()은 IRLS(iteratively reweighted least squares) 알고리즘을 사용한다.

12.2 Saturated model과 null model

GLM 적합도를 이해하려면 세 가지 모형을 구분하면 좋다.

모형 의미
Saturated model 각 관측값을 완벽하게 맞추는 가장 복잡한 모형
Null model 절편만 포함한 모형
Fitted model 연구자가 지정한 설명변수를 포함한 현재 모형

Saturated model은 이론적 기준점이며, 실제로 해석하려는 모형은 아니다. Deviance는 현재 모형이 saturated model에 비해 얼마나 덜 잘 맞는지를 나타낸다.

12.3 Deviance

Deviance는 현재 모형과 saturated model의 log-likelihood 차이를 기반으로 한다.

\[D = 2\{\ell_{sat}-\ell_{model}\}\]

여기서

  • \(\ell_{sat}\): saturated model의 log-likelihood
  • \(\ell_{model}\): 현재 모형의 log-likelihood

이다.

Deviance가 작을수록 현재 모형이 saturated model에 더 가깝게 자료를 설명한다.

12.4 Null deviance와 residual deviance

glm() 결과에는 보통 null deviance와 residual deviance가 나온다.

12.4.1 Null deviance

Null deviance는 절편만 포함한 모형의 deviance이다. 즉 설명변수를 전혀 사용하지 않았을 때의 부적합 정도이다.

12.4.2 Residual deviance

Residual deviance는 현재 모형의 deviance이다. 설명변수를 포함한 뒤 남아 있는 부적합 정도이다.

만약 residual deviance가 null deviance보다 크게 줄었다면, 설명변수들이 결과변수의 변동을 상당 부분 설명한다는 뜻이다.

12.5 Likelihood ratio test

중첩된 두 GLM을 비교할 때 likelihood ratio test를 사용할 수 있다. 작은 모형을 reduced model, 큰 모형을 full model이라고 하자.

\[H_0: \text{추가된 변수들의 계수는 모두 0}\]

검정통계량은 deviance 차이이다.

\[\Delta D = D_{reduced} - D_{full}\]

이 값은 귀무가설하에서 근사적으로 카이제곱분포를 따른다.

\[\Delta D \sim \chi^2_{df}\]

여기서 자유도는 두 모형의 모수 개수 차이이다.

12.6 AIC

AIC는 Akaike Information Criterion의 약자이며 다음과 같이 정의된다.

\[AIC = -2\ell + 2k\]

여기서

  • \(\ell\): 모형의 log-likelihood
  • \(k\): 추정한 모수의 수

이다. AIC는 모형의 적합도와 복잡도의 균형을 본다.

AIC가 낮은 모형은 같은 자료에서 상대적으로 더 나은 예측적 균형을 가진다고 볼 수 있다. 하지만 AIC가 낮다고 해서 인과적으로 더 올바른 모형이라는 뜻은 아니다.

WarningAIC 해석 주의

AIC는 동일한 결과변수와 동일한 자료에 적합한 모형들 사이에서 비교해야 한다. 서로 다른 자료나 다른 결과변수에 대한 AIC를 직접 비교하면 안 된다.

13 모형 선택과 해석

13.1 통계적 기준과 임상적 기준

모형 선택은 단순히 p-value나 AIC 하나로 결정되지 않는다. 특히 의학 연구에서는 다음을 함께 고려해야 한다.

기준 질문
연구질문 이 모형이 답하려는 질문은 무엇인가?
결과변수 유형 연속형, 이진형, count, rate 중 무엇인가?
분포 가정 평균-분산 관계가 자료에 적절한가?
Link function 계수 해석이 연구질문과 맞는가?
교란 조정 필요한 공변량이 포함되었는가?
예측 목적 calibration, discrimination이 충분한가?
표본 크기 변수 수에 비해 사건 수가 충분한가?
해석 가능성 임상적으로 설명 가능한 모형인가?

13.2 Overfitting

Overfitting은 모형이 훈련자료의 우연한 패턴까지 학습하여 새로운 자료에서 성능이 떨어지는 상황이다. GLM에서도 설명변수를 지나치게 많이 넣거나, 상호작용항과 비선형항을 과도하게 포함하면 overfitting이 발생할 수 있다.

Overfitting을 줄이려면 다음을 고려한다.

  1. 연구질문 기반 변수 선택
  2. 충분한 표본 크기 확보
  3. 변수 수 제한
  4. 내부검증 또는 교차검증
  5. penalized regression
  6. 외부검증

13.3 모형 선택의 실무 흐름

실무에서는 다음 순서로 접근하는 것이 좋다.

  1. 연구질문을 먼저 명확히 한다.
  2. 결과변수 유형을 확인한다.
  3. 결과변수에 적절한 분포를 선택한다.
  4. 평균과 선형예측자를 연결할 link function을 정한다.
  5. 회귀계수의 해석 척도를 명확히 한다.
  6. 진단과 민감도 분석을 수행한다.
  7. 효과크기, 신뢰구간, p-value를 함께 보고한다.
  8. 예측모형이면 예측성능을 별도로 평가한다.

14 GLM의 잔차와 진단

14.1 GLM에서 잔차가 어려운 이유

선형회귀에서는 잔차가 비교적 직관적이다.

\[e_i=Y_i-\hat{Y}_i\]

그러나 GLM에서는 결과변수의 분포와 평균-분산 관계가 달라지므로 잔차의 종류도 여러 가지가 있다.

잔차 의미
Response residual \(Y_i-\hat{\mu}_i\)
Pearson residual 평균-분산 관계로 표준화한 잔차
Deviance residual deviance 기여도를 부호와 함께 표현
Working residual IRLS 알고리즘에서 사용하는 잔차

14.2 Pearson residual

Pearson residual은 다음과 같이 정의된다.

\[r_{P,i} = \frac{Y_i-\hat{\mu}_i}{\sqrt{V(\hat{\mu}_i)}}\]

여기서 \(V(\mu)\)는 분포에 따른 variance function이다.

예를 들어 Poisson에서는

\[V(\mu)=\mu\]

이므로,

\[r_{P,i} = \frac{Y_i-\hat{\mu}_i}{\sqrt{\hat{\mu}_i}}\]

이다.

14.3 Deviance residual

Deviance residual은 각 관측값이 전체 deviance에 기여하는 정도를 나타낸다. 분포마다 공식은 다르지만, 핵심은 다음과 같다.

특정 관측값이 현재 모형에 얼마나 잘 맞지 않는가?

GLM에서는 residuals vs fitted plot, deviance residual plot, Pearson residual plot을 통해 모형 부적합 가능성을 확인한다.

14.4 Poisson overdispersion 진단

Poisson GLM에서는 Pearson residual을 이용해 dispersion ratio를 계산할 수 있다.

\[\hat{\phi} = \frac{ \sum_i r_{P,i}^2 }{ df }\]

값이 1보다 훨씬 크면 overdispersion을 의심한다.

  • \(\hat{\phi}\approx 1\): Poisson dispersion 적절
  • \(\hat{\phi}>1.5\) 또는 2: overdispersion 의심
  • \(\hat{\phi}<1\): underdispersion 가능

이번 실습에서는 하나의 가상 연구자료에서 연속형 결과, 이진 결과, count 결과를 모두 생성하여 GLM의 공통 구조를 확인한다.

set.seed(6060)

n <- 600

age <- rnorm(n, mean = 60, sd = 12)
female <- rbinom(n, size = 1, prob = 0.52)
bmi <- rnorm(n, mean = 25.5, sd = 4)
treatment <- rbinom(n, size = 1, prob = 0.45)
followup <- runif(n, min = 0.5, max = 3.0)

# 연속형 결과: systolic blood pressure
sbp <- 82 + 0.55 * age + 1.20 * bmi - 4.5 * treatment -
  2.0 * female + rnorm(n, 0, 9)

# 이진 결과: cardiovascular event
linpred_bin <- -7.2 + 0.045 * age + 0.08 * bmi - 0.40 * treatment +
  0.35 * female
prob_event <- 1 / (1 + exp(-linpred_bin))
event <- rbinom(n, size = 1, prob = prob_event)

# count 결과: readmission count
log_rate <- -1.5 + 0.025 * age + 0.16 * bmi - 0.35 * treatment +
  0.18 * female
rate <- exp(log_rate)
readmission <- rpois(n, lambda = rate * followup)

dat <- data.frame(
  sbp = sbp,
  event = event,
  readmission = readmission,
  followup = followup,
  age = age,
  female = female,
  bmi = bmi,
  treatment = treatment
)
