10  Cox 회귀분석

이번 장에서는 생존분석에서 가장 널리 사용되는 회귀모형인 Cox proportional hazards model을 학습한다. 지난 장에서는 Kaplan-Meier curve와 log-rank test를 이용해 생존곡선을 추정하고 비교하였다. Kaplan-Meier 방법은 censoring을 고려하여 생존확률을 추정한다는 점에서 매우 유용하지만, 다음 질문에는 충분히 답하기 어렵다.

  • 치료 효과의 크기는 얼마인가?
  • 나이, 성별, 병기 등 교란변수를 조정한 후에도 치료 효과가 있는가?
  • 특정 위험인자가 사건 발생 hazard를 얼마나 증가시키는가?
  • 연속형 설명변수의 효과를 생존자료에서 어떻게 모델링할 것인가?
  • 여러 설명변수를 동시에 고려한 생존분석 결과를 어떻게 해석할 것인가?
  • 비례위험가정이 맞지 않을 때 어떻게 대응할 것인가?

Cox model은 이러한 질문에 답하기 위한 생존분석 회귀모형이다. Cox model의 효과크기는 hazard ratio (HR)로 제시된다. HR은 어떤 그룹 또는 설명변수 수준에서 사건 발생의 순간위험이 기준 그룹에 비해 몇 배인지를 나타낸다.

Cox model의 기본 형태는 다음과 같다.

\[h(t|X) = h_0(t) \exp(\beta_1X_1+\cdots+\beta_pX_p)\]

여기서 \(h_0(t)\)는 baseline hazard이고, \(\exp(\beta_j)\)는 hazard ratio이다. Cox model은 baseline hazard의 구체적인 형태를 가정하지 않으면서 공변량이 hazard를 상대적으로 얼마나 변화시키는지를 추정한다. 이 때문에 Cox model은 semi-parametric model이라고 부른다. 즉, Cox model은 time-to-event outcome에서 설명변수와 hazard의 관계를 모델링하고, 공변량을 조정한 hazard ratio를 추정하는 생존분석 회귀모형이다.

10.1 Cox model이 필요한 이유

10.1.1 Kaplan-Meier와 log-rank의 한계

Kaplan-Meier curve는 그룹별 생존확률을 시각화하는 데 매우 유용하다. Log-rank test는 두 그룹 또는 여러 그룹의 생존곡선이 통계적으로 다른지 검정한다. 하지만 이 두 방법은 회귀모형이 아니기 때문에 다음 한계를 가진다.

방법 장점 한계
Kaplan-Meier 생존확률 시각화, censoring 반영 공변량 조정 어려움
Log-rank test 생존곡선 전체 비교 효과크기 직접 제공하지 않음
Cox model HR 추정, 공변량 조정 가능 비례위험가정 필요

예를 들어 치료군과 대조군의 생존곡선이 다르다고 하자. 이 차이가 치료 때문인지, 치료군의 나이가 더 젊어서인지, 병기가 더 낮아서인지 구분하려면 공변량 조정이 필요하다. Cox model은 생존자료에서 이러한 조정을 수행하는 대표적 방법이다.

10.1.2 연구 질문의 확장

Cox model은 다음 질문에 답한다.

연구 질문 Cox model에서의 표현
치료군의 사건 hazard는 대조군보다 낮은가? treatment HR
나이 증가가 사망 hazard와 관련되는가? age HR
병기를 조정해도 바이오마커가 예후와 관련되는가? adjusted HR
치료효과가 시간에 따라 변하는가? PH assumption, time-varying effect
여러 위험인자를 동시에 고려하면 어떤 변수가 독립적으로 관련되는가? multivariable Cox model

Cox model 결과는 보통 다음처럼 보고한다.

치료군은 대조군에 비해 사망 hazard가 낮았다(adjusted HR 0.72, 95% CI 0.55–0.94).

10.2 Hazard와 hazard ratio

10.2.1 Hazard

Hazard는 특정 시점까지 사건이 발생하지 않은 대상자가 바로 그 시점에 사건을 경험할 순간위험이다.

\[h(t) = \lim_{\Delta t \to 0} \frac{ P(t \leq T < t+\Delta t \mid T \geq t) }{ \Delta t }\]

직관적으로는 다음 질문에 답한다.

지금까지 사건이 없던 사람이 바로 다음 순간 사건을 경험할 위험은 얼마인가?

Hazard는 확률 자체가 아니라 시간 단위당 위험률에 가까운 개념이다. 따라서 0과 1 사이로 제한되지 않는다.

10.2.2 Hazard ratio

Hazard ratio는 두 hazard의 비이다.

\[HR(t)= \frac{h_1(t)}{h_0(t)}\]

비례위험가정이 성립하면 이 비율은 시간에 따라 일정하다고 가정한다.

\[HR(t)=HR\]

해석은 다음과 같다.

HR 해석
1 두 그룹의 hazard가 같음
1보다 큼 분자 그룹의 hazard가 더 높음
1보다 작음 분자 그룹의 hazard가 더 낮음

예를 들어 HR=0.70이면 치료군의 사건 발생 hazard가 대조군의 0.70배라는 뜻이다. 이는 대략 hazard가 30% 낮다는 표현으로 보고할 수 있다.

\[(1-0.70)\times 100\%=30\%\]

10.2.3 HR은 생존확률의 비가 아니다

HR은 특정 시점 생존확률의 비율이 아니다. 또한 median survival time의 비율도 아니다.

예를 들어 HR=0.70이라고 해서 2년 생존확률이 70%라는 뜻도 아니고, 치료군의 생존기간이 대조군보다 30% 길다는 뜻도 아니다. HR은 사건이 아직 발생하지 않은 대상자들 사이에서의 순간 사건위험의 비이다. Hazard ratio는 risk ratio, odds ratio, median survival ratio, survival probability ratio가 아니다. 반드시 hazard의 비율로 해석해야 한다.

10.3 Cox proportional hazards model

10.3.1 기본 모형식

Cox model은 다음과 같이 표현한다.

\[h_i(t) = h_0(t) \exp \left( \beta_1X_{1i} + \beta_2X_{2i} + \cdots + \beta_pX_{pi} \right)\]

여기서

  • \(h_i(t)\): \(i\)번째 대상자의 \(t\)시점 hazard
  • \(h_0(t)\): baseline hazard
  • \(X_{1i},\ldots,X_{pi}\): 설명변수
  • \(\beta_1,\ldots,\beta_p\): 회귀계수

이다.

Cox model은 baseline hazard와 공변량 효과를 곱셈 구조로 결합한다.

\[\text{individual hazard} = \text{baseline hazard} \times \text{covariate multiplier}\]

10.3.2 Baseline hazard

Baseline hazard \(h_0(t)\)는 모든 설명변수가 0일 때의 hazard이다. Cox model의 중요한 특징은 \(h_0(t)\)의 구체적인 형태를 지정하지 않는다는 점이다.

예를 들어 exponential survival model은 hazard가 시간에 따라 일정하다고 가정할 수 있지만, Cox model은 baseline hazard가 시간에 따라 어떻게 변하는지 직접 가정하지 않는다.

이 때문에 Cox model은 다음처럼 불린다.

semi-parametric model

이는 baseline hazard는 비모수적으로 두고, 공변량 효과 \(\beta\)는 모수적으로 추정한다는 뜻이다.

10.3.3 회귀계수와 HR

Cox model에서 회귀계수 \(\beta_j\)는 log hazard ratio이다.

\[\beta_j=\log(HR_j)\]

따라서 회귀계수를 지수화하면 hazard ratio가 된다.

\[HR_j=e^{\beta_j}\]

예를 들어 \(\hat{\beta}=-0.40\)이면,

\[HR=e^{-0.40}=0.67\]

이다. 이는 해당 설명변수가 1 증가하거나 해당 그룹에 속할 때 hazard가 약 33% 낮다는 뜻이다.

10.3.4 Cox model의 로그 형태

양변을 baseline hazard로 나누면 다음과 같다.

\[\frac{h_i(t)}{h_0(t)} = \exp(\mathbf{x}_i^\top\boldsymbol{\beta})\]

양변에 로그를 취하면,

\[\log \left\{ \frac{h_i(t)}{h_0(t)} \right\} = \mathbf{x}_i^\top\boldsymbol{\beta}\]

즉 Cox model은 baseline hazard 대비 상대 hazard의 로그를 설명변수의 선형결합으로 표현한다.

10.4 설명변수별 HR 해석

10.4.1 이진 설명변수

치료 여부를 설명변수로 포함한 Cox model을 생각하자.

\[h_i(t) = h_0(t) \exp(\beta_1 Treatment_i)\]

여기서

  • \(Treatment=0\): 대조군
  • \(Treatment=1\): 치료군

이다. 치료군과 대조군의 hazard ratio는 다음과 같다.

\[HR = \frac{h(t|Treatment=1)}{h(t|Treatment=0)} = e^{\beta_1}\]

예를 들어 \(HR=0.65\)라면 다음처럼 해석한다.

치료군의 사건 발생 hazard는 대조군의 0.65배이다. 즉 치료군의 hazard는 대조군보다 약 35% 낮다.

10.4.2 연속형 설명변수

나이를 설명변수로 포함한 Cox model을 생각하자.

\[h_i(t) = h_0(t) \exp(\beta_1 Age_i)\]

\(e^{\beta_1}\)은 나이가 1세 증가할 때 hazard가 몇 배가 되는지를 의미한다.

예를 들어 \(HR=1.04\)라면 다음처럼 해석한다.

나이가 1세 증가할 때 사건 발생 hazard는 약 4% 증가한다.

나이 10세 증가당 HR은 다음처럼 계산한다.

\[HR_{10-year} = (HR_{1-year})^{10} = e^{10\beta_1}\]

만약 1세 증가당 HR이 1.04라면,

\[HR_{10-year} = 1.04^{10} = 1.48\]

이다.

10.4.3 범주형 설명변수

세 개 이상의 범주를 가진 변수는 기준범주를 정하고 더미변수로 표현한다. 예를 들어 병기가 I, II, III이라고 하자. Stage I을 기준범주로 두면 다음 모형을 쓸 수 있다.

\[h(t) = h_0(t) \exp(\beta_1StageII+\beta_2StageIII)\]

해석은 다음과 같다.

계수 HR 해석
\(\beta_1\) \(e^{\beta_1}\) Stage II vs Stage I
\(\beta_2\) \(e^{\beta_2}\) Stage III vs Stage I

기준범주를 바꾸면 계수와 해석은 달라지지만, 모형이 표현하는 상대 hazard 구조는 같다.

10.5 Crude HR과 adjusted HR

10.5.1 Crude HR

Crude HR은 하나의 설명변수만 포함한 Cox model에서 얻은 HR이다.

\[h_i(t) = h_0(t) \exp(\beta_1Treatment_i)\]

이때 \(e^{\beta_1}\)은 치료군과 대조군의 조정되지 않은 hazard ratio이다.

10.5.2 Adjusted HR

Adjusted HR은 여러 공변량을 함께 포함한 Cox model에서 얻은 HR이다.

\[h_i(t) = h_0(t) \exp( \beta_1Treatment_i + \beta_2Age_i + \beta_3Stage_i )\]

이때 \(e^{\beta_1}\)은 나이와 병기를 조정했을 때 치료군의 hazard가 대조군에 비해 몇 배인지를 나타낸다.

10.5.3 교란 조정

생존자료에서도 교란(confounding)이 발생할 수 있다. 예를 들어 치료군의 생존이 더 좋아 보이는 이유가 실제 치료효과 때문이 아니라 치료군에 초기 병기 환자가 많기 때문일 수 있다.

Cox model은 병기, 나이, 성별, 동반질환 등 교란변수를 함께 포함해 치료효과를 조정할 수 있다.

교란 가능 변수 이유
나이 사망위험과 치료 선택 모두에 관련
병기 예후와 치료 선택에 강한 관련
성능상태 치료 가능성과 생존에 모두 관련
동반질환 사망위험과 치료 선택에 관련
병원 또는 의사 치료 패턴과 예후에 관련

다만 회귀모형에 변수를 넣었다고 해서 교란이 완전히 제거되는 것은 아니다. 측정되지 않은 교란, 변수 측정오차, 비선형 관계, 상호작용이 남아 있을 수 있다.

10.6 Partial likelihood

10.6.1 Cox model은 baseline hazard를 어떻게 피하는가?

Cox model은 baseline hazard \(h_0(t)\)를 직접 지정하지 않는다. 그렇다면 어떻게 \(\beta\)를 추정할 수 있을까?

핵심은 사건이 발생한 시점마다 그 시점의 risk set 안에서 누가 사건을 경험했는가를 비교하는 것이다. Baseline hazard는 같은 사건 시점의 risk set 안에 있는 대상자들에게 공통적으로 작용하므로 상대위험을 비교할 때 상쇄된다.

10.6.2 Partial likelihood의 직관

어떤 사건 시점 \(t_j\)에서 대상자 \(i\)가 사건을 경험했다고 하자. 그 직전 risk set을 \(R(t_j)\)라고 하면, Cox partial likelihood에서 해당 사건이 대상자 \(i\)에게 발생할 조건부 확률은 다음과 같이 표현된다.

\[\frac{ \exp(\mathbf{x}_i^\top\boldsymbol{\beta}) }{ \sum_{\ell \in R(t_j)} \exp(\mathbf{x}_\ell^\top\boldsymbol{\beta}) }\]

모든 사건 시점에 대해 이를 곱하면 partial likelihood가 된다.

\[L(\boldsymbol{\beta}) = \prod_{j} \frac{ \exp(\mathbf{x}_{i_j}^\top\boldsymbol{\beta}) }{ \sum_{\ell \in R(t_j)} \exp(\mathbf{x}_{\ell}^\top\boldsymbol{\beta}) }\]

이 식은 사건이 발생한 사람의 상대위험이 risk set 안의 다른 사람들에 비해 얼마나 큰지를 이용한다.

10.6.3 Ties 처리

실제 자료에서는 여러 대상자가 같은 시간에 사건을 경험할 수 있다. 이를 tied event라고 한다. Cox model에서는 ties를 처리하는 방법이 필요하다.

대표 방법은 다음과 같다.

방법 특징
Breslow 계산 간단, ties가 적을 때 사용 가능
Efron ties가 있을 때 더 정확한 근사, R 기본값
Exact 정확하지만 계산량 큼, 이산 시간 자료에 유용

10.7 Proportional hazards assumption

10.7.1 비례위험가정의 의미

Cox model의 핵심 가정은 비례위험가정(proportional hazards assumption)이다. 이는 두 대상자 또는 두 그룹의 hazard ratio가 시간에 따라 일정하다는 뜻이다.

\[\frac{ h(t|X=1) }{ h(t|X=0) } = e^\beta\]

이 값은 \(t\)에 의존하지 않는다.

비례위험가정이 성립하면 HR 하나로 전체 추적기간 동안의 상대 hazard를 요약할 수 있다. 반대로 비례위험가정이 심하게 깨지면 HR 하나로 효과를 요약하는 것이 부적절할 수 있다.

10.7.2 비례위험가정이 깨질 수 있는 상황

비례위험가정은 다음 상황에서 깨질 수 있다.

  • 치료 효과가 초기에는 크지만 시간이 지나며 감소한다.
  • 수술 직후 단기 위험은 높지만 장기 생존은 좋아진다.
  • 면역치료처럼 초기에 곡선이 겹치다가 나중에 벌어진다.
  • 독성이 초기에 집중되어 있고 이후에는 위험이 낮아진다.
  • 생존곡선이 서로 교차한다.
  • 어떤 바이오마커의 예후 효과가 시간이 지나면서 약해진다.

Kaplan-Meier curve에서 생존곡선이 명확히 교차하면 비례위험가정 위반을 의심할 수 있다. 그러나 곡선이 교차하지 않아도 PH 위반이 있을 수 있으므로 추가 진단이 필요하다.

10.7.3 Log-minus-log plot

Log-minus-log plot은 비례위험가정을 시각적으로 점검하는 방법이다. 그룹별로 다음 값을 그린다.

\[\log\{-\log(\hat{S}(t))\}\]

대략적으로 두 곡선이 평행하면 비례위험가정이 크게 위반되지 않았다고 볼 수 있다.

다만 이 방법은 시각적 판단이므로 주관적일 수 있다. 따라서 Schoenfeld residual 기반 검정과 함께 해석한다.

10.7.4 Schoenfeld residual

Schoenfeld residual은 Cox model에서 각 사건 시점마다 공변량의 관찰값과 risk set에서 기대되는 공변량 값의 차이를 이용한다. 비례위험가정이 맞으면 공변량 효과가 시간에 따라 체계적으로 변하지 않아야 한다.

즉 Schoenfeld residual이 시간과 관련된 패턴을 보이지 않아야 한다.

Schoenfeld residual 분석 결과는 각 변수의 p-value와 global p-value로 나타난다.

해석은 다음과 같다.

결과 해석
p-value가 작지 않음 PH 위반의 명확한 증거가 부족
p-value가 작음 해당 변수의 효과가 시간에 따라 변할 가능성
global p-value 작음 모형 전체에서 PH 위반 가능성

이때, 표본 수가 매우 크면 작은 위반도 유의할 수 있고, 표본 수가 작으면 큰 위반도 검정력이 부족할 수 있다. p-value와 그래프를 함께 해석해야 한다.

10.8 비례위험가정 위반 시 대안

10.8.1 Stratified Cox model

어떤 공변량이 비례위험가정을 위반하지만 그 변수의 HR 자체가 주요 관심이 아니라면 stratified Cox model을 고려할 수 있다. 예를 들어 병기가 PH 가정을 위반하지만 병기는 조정변수일 뿐이고 치료효과가 주요 관심이라면 병기로 층화할 수 있다.

Stratified Cox model은 층마다 서로 다른 baseline hazard를 허용한다.

\[h_k(t|X) = h_{0k}(t) \exp(\beta X)\]

여기서 \(k\)는 층을 나타낸다.

장점은 PH 가정을 위반한 층화변수에 대해 baseline hazard를 다르게 허용할 수 있다는 점이다. 단점은 층화변수 자체의 HR을 추정하지 못한다는 점이다.

10.8.2 Time-dependent effect

관심 변수의 효과가 시간에 따라 변한다면 time-dependent effect를 모형화할 수 있다. 예를 들어 치료효과가 시간에 따라 달라진다면 다음과 같은 항을 포함할 수 있다.

\[h(t|X) = h_0(t) \exp\{\beta_1X+\beta_2X\log(t)\}\]

이 경우 hazard ratio는 시간의 함수가 된다.

\[HR(t)=\exp\{\beta_1+\beta_2\log(t)\}\]

10.8.3 시간 구간별 Cox model

추적기간을 여러 구간으로 나누어 구간별 HR을 추정할 수도 있다.

예를 들어

  • 0–6개월
  • 6–24개월
  • 24개월 이후

처럼 나누어 치료효과를 따로 평가한다. 이 방법은 해석이 직관적이지만, 구간 선택이 사후적으로 이루어지면 bias가 생길 수 있다. 가능하면 임상적 근거를 바탕으로 사전에 구간을 정하는 것이 좋다.

10.8.4 다른 요약 지표

비례위험가정이 심하게 깨지고 생존곡선이 교차한다면 HR 하나로 효과를 요약하기 어려울 수 있다. 이 경우 다음 대안을 고려할 수 있다.

대안 설명
Restricted mean survival time, RMST 특정 시간까지 생존곡선 아래 면적
시간별 생존확률 차이 1년, 3년, 5년 생존율 차이
Landmark analysis 특정 시점 이후 생존을 조건부 분석
Flexible parametric model 시간변화 효과를 유연하게 모형화
Stratified Cox model PH 위반 공변량으로 층화

10.9 Cox model 결과표 해석

10.9.1 기본 결과표

Cox model 결과는 보통 다음과 같이 제시된다.

Variable HR 95% CI p-value
Treatment vs control 0.68 0.51 to 0.91 0.009
Age, per 10 years 1.42 1.18 to 1.71 <0.001
Stage III vs I–II 2.35 1.66 to 3.32 <0.001
Female vs male 0.92 0.68 to 1.25 0.59

해석은 다음과 같다.

  • 나이와 병기를 조정했을 때 치료군의 사건 발생 hazard는 대조군의 0.68배이다.
  • 나이 10세 증가는 사건 hazard 1.42배와 관련된다.
  • Stage III 환자의 hazard는 Stage I–II 환자의 2.35배이다.
  • 성별의 HR은 0.92이나 신뢰구간이 1을 포함하므로 명확한 관련성은 부족하다.

10.9.2 신뢰구간 해석

Cox model에서 HR의 95% 신뢰구간이 1을 포함하지 않으면 일반적으로 0.05 수준에서 통계적으로 유의하다.

예를 들어

\[HR=0.68,\quad 95\% CI: 0.51\text{ to }0.91\]

이면 신뢰구간 전체가 1보다 작으므로 hazard 감소와 관련된다는 증거가 있다.

반대로

\[HR=0.92,\quad 95\% CI: 0.68\text{ to }1.25\]

이면 신뢰구간이 1을 포함하므로 hazard 차이가 없다는 가능성을 배제하기 어렵다.

10.9.3 Cox model과 log-rank test의 관계

두 그룹만 있고 공변량이 없는 Cox model의 score test는 log-rank test와 밀접하게 연결된다. 따라서 단순 그룹 비교에서는 log-rank test와 crude Cox model이 비슷한 결론을 줄 수 있다.

하지만 Cox model은 다음을 추가로 제공한다.

  1. HR이라는 효과크기
  2. 95% 신뢰구간
  3. 공변량 조정
  4. 연속형 변수 포함
  5. 상호작용 평가
  6. 예측 생존곡선

10.10.1 예제 데이터 생성

이번 실습에서는 암 치료 연구를 가정한 생존자료를 생성한다.

set.seed(8080)

n <- 360

treatment <- rbinom(n, size = 1, prob = 0.5)
age <- rnorm(n, mean = 62, sd = 11)
female <- rbinom(n, size = 1, prob = 0.48)

stage <- factor(
  sample(c("I", "II", "III"), size = n, replace = TRUE,
         prob = c(0.35, 0.40, 0.25)),
  levels = c("I", "II", "III")
)

linpred <- -0.55 * treatment +
  0.035 * (age - 60) -
  0.10 * female +
  0.45 * (stage == "II") +
  0.95 * (stage == "III")

baseline_rate <- 0.055

event_time <- rexp(n, rate = baseline_rate * exp(linpred))
censor_time <- runif(n, min = 6, max = 36)

time <- pmin(event_time, censor_time)
status <- as.numeric(event_time <= censor_time)

dat <- data.frame(
  time = time,
  status = status,
  treatment = factor(treatment, levels = c(0, 1),
                     labels = c("Control", "Treatment")),
  age = age,
  female = female,
  stage = stage
)

10.10.12 Time-dependent effect 예시

치료 효과가 시간에 따라 변하는지 평가하는 간단한 방법은 treatment와 시간 함수의 상호작용을 넣는 것이다. cox.zph()가 더 일반적이지만, 다음 코드는 개념 이해용이다.

dat$treat_num <- ifelse(dat$treatment == "Treatment", 1, 0)

fit_td <- coxph(
  Surv(time, status) ~ treat_num + age + female + stage +
    tt(treat_num),
  data = dat,
  tt = function(x, t, ...) x * log(t + 1)
)

10.10.13 예측 생존곡선

Adjusted Cox model을 이용해 특정 공변량 값을 가진 대상자의 예측 생존곡선을 그릴 수 있다.

newdata <- data.frame(
  treatment = factor(c("Control", "Treatment"),
                     levels = levels(dat$treatment)),
  age = c(60, 60),
  female = c(0, 0),
  stage = factor(c("II", "II"), levels = levels(dat$stage))
)

fit_surv_adj <- survfit(
  fit_adj,
  newdata = newdata
)

plot(
  fit_surv_adj,
  col = 1:2,
  lwd = 2,
  xlab = "Time",
  ylab = "Predicted survival probability",
  main = "Adjusted survival curves"
)

legend(
  "bottomleft",
  legend = c("Control", "Treatment"),
  col = 1:2,
  lwd = 2
)
