8  반복측정 분산분석

이번 장에서는 반복측정 분산분석(repeated measures ANOVA)을 학습한다. 지난 장에서는 최종 시점의 연속형 outcome을 baseline 값으로 조정하여 비교하는 ANCOVA를 다루었다. 그러나 실제 임상연구와 의학 연구에서는 한 대상자를 한 번만 측정하는 경우보다 여러 시점에서 반복 측정하는 경우가 매우 많다.

예를 들어 다음과 같은 자료를 생각할 수 있다.

  • 고혈압 환자의 baseline, 4주, 8주, 12주 수축기혈압
  • 당뇨병 환자의 치료 전, 3개월, 6개월, 12개월 HbA1c
  • 수술 후 통증 점수의 1일, 3일, 7일, 14일 변화
  • 항암치료 중 삶의 질 점수의 cycle별 변화
  • 재활치료 전후 여러 시점의 보행거리
  • 백신 접종 후 항체가의 시간별 변화
  • 중환자실 환자의 일별 염증표지자 변화

이러한 자료는 같은 대상자에게서 여러 번 측정되기 때문에 관측값들이 서로 독립이 아니다. 같은 환자의 혈압은 서로 비슷하고, 같은 환자의 통증 점수도 서로 연관된다. 따라서 각 시점의 값을 모두 독립 관측값처럼 취급하면 표준오차와 p-value가 잘못될 수 있다.

반복측정 ANOVA는 다음 질문에 답하는 고전적 방법이다.

  1. 전체적으로 시간에 따라 outcome 평균이 변하는가?
  2. 전체적으로 치료군과 대조군의 평균이 다른가?
  3. 시간에 따른 변화 양상이 치료군과 대조군에서 다른가?

특히 세 번째 질문은 임상적으로 매우 중요하다. 치료군과 대조군이 시간이 지나며 서로 다른 패턴으로 변한다면, 이는 group × time interaction으로 표현된다. 따라서 반복측정 ANOVA는 같은 대상자를 여러 시점에서 측정한 자료에서 시간 효과, 집단 효과, 집단×시간 상호작용을 평가하는 방법이다.

8.1 반복측정 자료의 이해

8.1.1 반복측정 자료란?

반복측정 자료(repeated measures data)는 같은 대상자에게서 같은 outcome을 여러 시점 또는 여러 조건에서 반복해서 측정한 자료이다.

예를 들어 혈압 임상시험에서 각 대상자의 수축기혈압을 baseline, 4주, 8주, 12주에 측정했다면 한 대상자는 네 개의 outcome 값을 가진다.

대상자 치료군 baseline 4주 8주 12주
1 Control 152 148 146 145
2 Control 146 145 144 143
3 Treatment 151 143 138 134
4 Treatment 149 142 136 132

이 자료에서 같은 대상자의 네 값은 서로 독립이 아니다. 대상자 1의 baseline 혈압이 높으면 4주, 8주, 12주 혈압도 상대적으로 높을 가능성이 있다.

8.1.2 Wide format과 long format

반복측정 자료는 두 가지 형식으로 표현할 수 있다.

8.1.2.1 Wide format

Wide format은 한 대상자가 한 행(row)을 차지하고, 각 시점의 outcome이 별도 열(column)로 들어간다.

id group y0 y4 y8 y12
1 Control 152 148 146 145
2 Treatment 150 143 138 135

Wide format은 사람이 보기 쉽고, 전통적 반복측정 ANOVA를 설명할 때 편하다.

8.1.2.2 Long format

Long format은 한 대상자의 각 시점 관측값이 별도 행이 된다.

id group time y
1 Control 0 152
1 Control 4 148
1 Control 8 146
1 Control 12 145
2 Treatment 0 150
2 Treatment 4 143

Long format은 혼합모형, GEE, 그래프 작성과 잘 맞는다.

8.1.3 독립자료 분석이 부적절한 이유

반복측정 자료를 모두 독립 관측값처럼 분석하면 같은 대상자 내 상관을 무시하게 된다. 예를 들어 대상자 100명에게서 4번씩 측정했으므로 400개의 독립 관측값이 있다고 생각하면 실제보다 정보량을 과대평가할 수 있다.

같은 대상자의 반복측정값은 다음 이유로 서로 비슷하다.

  • 개인의 기저 건강상태
  • 유전적 요인
  • 생활습관
  • 질병 중증도
  • 치료 순응도
  • 측정 환경
  • 개인별 반응성

8.2 Within-subject factor와 between-subject factor

8.2.1 Within-subject factor

Within-subject factor는 같은 대상자 안에서 반복되는 조건 또는 시점이다. 반복측정 연구에서 가장 흔한 within-subject factor는 시간이다.

예를 들어

\[Time = 0, 4, 8, 12\text{ weeks}\]

이면 각 대상자는 네 시점에서 측정된다. 시간 효과는 전체 대상자에서 평균 outcome이 시간에 따라 변하는지 평가한다.

8.2.2 Between-subject factor

Between-subject factor는 대상자 사이에서 다른 변수이다. 가장 흔한 예는 치료군이다.

예를 들어

\[Group = \text{Control vs Treatment}\]

이면 각 대상자는 한 그룹에만 속한다. 집단 효과는 모든 시점을 평균적으로 보았을 때 치료군과 대조군의 평균 outcome이 다른지 평가한다.

8.2.3 집단 효과, 시간 효과, 상호작용

반복측정 ANOVA에서 가장 중요한 효과는 세 가지이다.

효과 질문 해석
Group effect 전체적으로 두 군 평균이 다른가? 시점들을 평균했을 때 군 차이
Time effect 전체적으로 시간에 따라 평균이 변하는가? 모든 군을 합쳐 시간 변화
Group × Time interaction 시간 변화 양상이 군별로 다른가? 치료효과의 시간별 차이

임상시험에서는 group effect보다 group × time interaction이 더 관심일 수 있다. 왜냐하면 치료군이 대조군보다 시간이 지나면서 더 많이 개선되는지가 핵심 질문인 경우가 많기 때문이다.

8.3 반복측정 ANOVA 모형의 직관

8.3.1 단일집단 반복측정 ANOVA

한 집단에서 여러 시점의 평균이 같은지 평가한다고 하자. 예를 들어 같은 대상자의 통증 점수를 수술 전, 수술 후 1일, 3일, 7일에 측정했다면 다음 귀무가설을 검정한다.

\[H_0:\mu_1=\mu_2=\mu_3=\mu_4\]

이는 시간 효과가 없다는 가설이다.

8.3.2 두 집단 반복측정 ANOVA

치료군과 대조군이 있고 각 대상자를 여러 시점에서 측정한 경우에는 다음 모형 구조를 생각할 수 있다.

\[Y_{ij} = \mu + \alpha_{g(i)} + \tau_j + (\alpha\tau)_{g(i)j} + s_i + \epsilon_{ij}\]

여기서

  • \(Y_{ij}\): \(i\)번째 대상자의 \(j\)번째 시점 outcome
  • \(\mu\): 전체 평균
  • \(\alpha_{g(i)}\): 집단 효과
  • \(\tau_j\): 시간 효과
  • \((\alpha\tau)_{g(i)j}\): 집단×시간 상호작용
  • \(s_i\): 대상자 효과
  • \(\epsilon_{ij}\): 잔차

이다.

대상자 효과 \(s_i\)는 같은 대상자의 측정값들이 서로 비슷해지는 원인을 반영한다. 고전적 반복측정 ANOVA는 이 대상자 내 상관을 특정한 방식으로 처리한다.

8.3.3 상호작용의 임상적 의미

Group × time interaction은 다음 질문에 답한다.

치료군과 대조군의 시간에 따른 변화 패턴이 다른가?

예를 들어 혈압 연구에서 대조군은 12주 동안 3 mmHg 감소하고 치료군은 15 mmHg 감소했다면, 두 군의 변화 패턴은 다르다. 이는 group × time interaction으로 나타날 수 있다.

상호작용이 유의하면 다음을 추가로 살펴본다.

  1. 어느 시점에서 군 차이가 나타나는가?
  2. baseline 대비 변화량이 어느 시점부터 달라지는가?
  3. 치료효과가 시간이 지날수록 커지는가?
  4. 특정 시점의 차이가 임상적으로 의미 있는가?
  5. 사후비교에서 다중성 보정을 했는가?

8.4 구형성 가정

8.4.1 구형성이란?

반복측정 ANOVA의 중요한 가정 중 하나는 구형성(sphericity)이다. 구형성은 반복측정 시점들 사이의 모든 쌍별 차이의 분산이 같다는 가정이다.

예를 들어 네 시점 \(Y_1, Y_2, Y_3, Y_4\)가 있으면 다음 차이들의 분산이 같아야 한다.

\[Var(Y_1-Y_2) = Var(Y_1-Y_3) = Var(Y_1-Y_4) = Var(Y_2-Y_3) = Var(Y_2-Y_4) = Var(Y_3-Y_4)\]

구형성은 시점 간 상관 구조에 대한 가정이다. 이 가정이 깨지면 반복측정 ANOVA의 F 검정이 지나치게 liberal해질 수 있다. 즉 p-value가 실제보다 작아질 수 있다.

8.4.2 구형성과 compound symmetry

Compound symmetry는 모든 시점의 분산이 같고 모든 시점 쌍의 상관이 같다는 더 강한 가정이다. Compound symmetry가 성립하면 구형성도 성립한다. 하지만 구형성이 성립한다고 해서 반드시 compound symmetry가 성립하는 것은 아니다.

개념 의미 관계
Compound symmetry 모든 분산 동일, 모든 공분산 동일 더 강한 가정
Sphericity 모든 쌍별 차이의 분산 동일 더 약한 가정

실제 longitudinal 자료에서는 가까운 시점끼리 상관이 더 높고 먼 시점끼리 상관이 낮은 경우가 많다. 이런 경우 구형성이 위반될 수 있다.

8.4.3 Mauchly test

Mauchly test는 구형성 가정을 검정한다. 귀무가설은 다음과 같다.

\[H_0:\text{구형성 가정이 성립한다}\]

p-value가 작으면 구형성 위반의 증거가 있다고 해석한다. 다만 Mauchly test는 표본 크기에 민감하다. 표본이 크면 작은 위반도 유의할 수 있고, 표본이 작으면 큰 위반도 놓칠 수 있다.

8.4.4 Greenhouse-Geisser와 Huynh-Feldt 보정

구형성이 위반되면 자유도를 보정하여 F 검정을 더 보수적으로 만든다. 대표적인 보정은 다음과 같다.

보정 특징
Greenhouse-Geisser 더 보수적, 자주 사용
Huynh-Feldt 덜 보수적, epsilon이 클 때 사용
Lower-bound 가장 보수적

Greenhouse-Geisser 보정은 epsilon 값을 이용해 자유도를 줄인다.

\[df^* = \epsilon \times df\]

여기서 \(\epsilon\)은 0과 1 사이 값이다. \(\epsilon\)이 1에 가까우면 구형성 위반이 작고, 작을수록 위반이 크다.

8.5 반복측정 자료 시각화

8.5.1 Profile plot

반복측정 자료 분석에서 가장 먼저 해야 할 일은 그래프를 그리는 것이다. Profile plot은 시간에 따른 군별 평균 변화를 보여준다.

Profile plot에서 확인할 점은 다음과 같다.

  1. 평균이 시간에 따라 증가하는가, 감소하는가?
  2. 두 군의 평균 수준이 전반적으로 다른가?
  3. 두 군의 곡선이 평행한가?
  4. 두 군의 차이가 시간이 지나며 커지는가?
  5. 특정 시점에서 차이가 큰가?
  6. 오차막대가 얼마나 넓은가?
  7. baseline에서 차이가 있는가?

8.5.2 Spaghetti plot

Spaghetti plot은 각 대상자의 개별 궤적을 모두 그린 그림이다. 대상자별 변화 패턴의 다양성을 보여준다.

장점은 다음과 같다.

  • 개인별 변화 패턴 확인
  • 이상치 또는 영향점 확인
  • 중도탈락 패턴 확인
  • 선형 변화가 적절한지 확인
  • 평균만으로 숨겨지는 이질성 확인

단점은 대상자 수가 많으면 복잡해진다는 것이다. 이 경우 일부 표본만 그리거나 투명도를 조절한다.

8.6 사후비교와 다중성

8.6.1 왜 사후비교가 필요한가?

반복측정 ANOVA에서 time effect 또는 group × time interaction이 유의하면, 구체적으로 어느 시점에서 차이가 있는지 알고 싶어진다.

예를 들어 다음 질문이 생긴다.

  • 4주, 8주, 12주 중 어느 시점에서 치료군과 대조군이 다른가?
  • 치료군 안에서 baseline 대비 12주 변화가 유의한가?
  • 대조군 안에서도 시간이 지남에 따라 변화가 있는가?
  • 치료군의 변화량은 어느 시점부터 임상적으로 의미 있는가?

이러한 비교는 여러 개가 되기 쉬우므로 다중성 조정이 필요하다.

8.6.2 사후비교의 예

반복측정 임상시험에서 가능한 사후비교는 다음과 같다.

비교 질문
각 시점의 군간 비교 4주, 8주, 12주에서 치료군과 대조군 차이
군별 시간 비교 치료군에서 baseline vs 12주
변화량의 군간 비교 각 시점의 baseline 대비 변화량 차이
선형 trend 비교 시간이 지날수록 감소 경향이 다른가
특정 contrast 12주 평균이 baseline보다 낮은가

사후비교는 연구 질문과 일치해야 하며, 가능하면 사전에 계획한다.

8.6.3 다중성 보정

여러 비교를 수행하면 1종 오류가 증가한다. 대표적인 보정 방법은 다음과 같다.

방법 특징
Bonferroni 단순하고 보수적
Holm Bonferroni보다 덜 보수적
Tukey 모든 쌍별 비교에 자주 사용
Dunnett 여러 시점 또는 군을 기준군과 비교
FDR 탐색적 분석에서 사용 가능

확증적 임상시험에서 특정 시점 차이가 primary endpoint라면 그 시점 분석을 주 분석으로 사전 지정하고, 나머지 시점은 secondary 또는 exploratory로 해석하는 것이 좋다.

8.7.1 예제 데이터 생성

혈압 임상시험 자료를 생성한다. 대상자들은 대조군 또는 치료군에 무작위배정되고, baseline, 4주, 8주, 12주에 SBP를 측정한다.

set.seed(1111)

n_per_group <- 60
n <- 2 * n_per_group

id <- 1:n

group <- factor(
  rep(c("Control", "Treatment"), each = n_per_group),
  levels = c("Control", "Treatment")
)

time_points <- c(0, 4, 8, 12)

subject_intercept <- rnorm(n, mean = 0, sd = 10)

wide <- data.frame(
  id = id,
  group = group
)

for (tt in time_points) {
  control_mean <- 150 - 0.3 * tt
  treatment_mean <- 150 - 1.3 * tt

  mean_t <- ifelse(group == "Control", control_mean, treatment_mean)

  wide[[paste0("week", tt)]] <- mean_t +
    subject_intercept +
    rnorm(n, mean = 0, sd = 5)
}

8.7.12 구형성 가정과 보정

기본 R만으로 Mauchly test와 Greenhouse-Geisser 보정을 직접 얻는 것은 제한적이다. ez 패키지가 설치되어 있으면 쉽게 확인할 수 있다.

library(ez)

ezANOVA(
  data = long,
  dv = sbp,
  wid = id,
  within = week_factor,
  between = group,
  detailed = TRUE,
  type = 3
)

ezANOVA() 결과에는 Mauchly’s test for sphericity와 Greenhouse-Geisser, Huynh-Feldt 보정 결과가 포함된다.
