6  재표본추출 방법

재표본추출(resampling)은 관측된 자료에서 반복적으로 표본을 다시 구성하고, 각 표본에서 통계량이나 예측모형을 계산하는 방법이다. 대표적인 재표본추출 방법은 교차검증(cross-validation)과 부트스트랩(bootstrap)이다.

  • 교차검증은 모형의 시험오차를 추정하고 모형의 복잡도나 조정모수를 선택하는 데 주로 사용한다.
  • 부트스트랩은 추정량의 표준오차, 편향, 신뢰구간 등을 평가하는 데 주로 사용한다.

재표본추출은 계산량이 크지만 현대의 컴퓨팅 환경에서는 널리 사용할 수 있다.

6.1 훈련오차와 시험오차

훈련자료에서 계산한 평균제곱오차는

\[ \operatorname{MSE}_{\text{train}} =\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat f(x_i))^2 \]

이다. 그러나 우리가 궁금한 값은 새로운 관측치 \((X_0,Y_0)\)에 대한 기대 예측오차

\[ \operatorname{Err}_{\text{test}} =E\{(Y_0-\hat f(X_0))^2\} \]

이다. 모형이 복잡해질수록 훈련오차는 일반적으로 감소하지만 시험오차는 어느 지점 이후 증가할 수 있다. 따라서 모형 선택에는 훈련오차가 아니라 시험오차에 대한 신뢰할 만한 추정치가 필요하다.

6.2 검증자료 접근법

검증자료 접근법(validation set approach)은 관측자료를 훈련집합과 검증집합으로 나눈다.

  1. 훈련집합으로 모형을 적합한다.
  2. 검증집합에서 예측값을 계산한다.
  3. 검증오차를 시험오차의 추정값으로 사용한다.

이 방법은 단순하지만 두 가지 한계가 있다.

  • 자료를 한 번만 분할하므로 분할 결과에 따라 오차 추정값이 크게 달라질 수 있다.
  • 일부 자료만 모형 적합에 사용하므로 전체 자료를 사용했을 때보다 적합된 모형의 성능이 나빠질 수 있다.

6.2.1 자동차 자료 예제

Auto 자료에서 마력(horsepower)으로 연비(mpg)를 예측해 보자.

library(ISLR2)
set.seed(1)

data(Auto)
n <- nrow(Auto)
train_id <- sample(seq_len(n), size = floor(n / 2))

fit_linear <- lm(mpg ~ horsepower, data = Auto, subset = train_id)
pred_linear <- predict(fit_linear, newdata = Auto[-train_id, ])
mean((Auto$mpg[-train_id] - pred_linear)^2)
#> [1] 23.26601

2차 및 3차 다항회귀의 검증오차도 계산할 수 있다.

fit_degree2 <- lm(mpg ~ poly(horsepower, 2), data = Auto, subset = train_id)
fit_degree3 <- lm(mpg ~ poly(horsepower, 3), data = Auto, subset = train_id)

mse_validation <- c(
  first = mean((Auto$mpg[-train_id] - predict(fit_linear, Auto[-train_id, ]))^2),
  second = mean((Auto$mpg[-train_id] - predict(fit_degree2, Auto[-train_id, ]))^2),
  third = mean((Auto$mpg[-train_id] - predict(fit_degree3, Auto[-train_id, ]))^2)
)
mse_validation
#>    first   second    third 
#> 23.26601 18.71646 18.79401

분할을 바꾸면 결과도 달라진다.

validation_mse <- function(seed, degree) {
  set.seed(seed)
  train_id <- sample(seq_len(nrow(Auto)), size = floor(nrow(Auto) / 2))
  fit <- lm(mpg ~ poly(horsepower, degree), data = Auto, subset = train_id)
  mean((Auto$mpg[-train_id] - predict(fit, Auto[-train_id, ]))^2)
}

sapply(1:5, function(s) validation_mse(s, degree = 2))
#> [1] 18.71646 20.43036 17.70254 19.02516 16.79876

6.3 K-겹 교차검증

\(K\)-겹 교차검증(\(K\)-fold cross-validation)은 자료를 크기가 비슷한 \(K\)개의 부분집합으로 나눈다. 각 부분집합을 한 번씩 검증집합으로 사용하고 나머지 \(K-1\)개로 모형을 적합한다.

\(m_k\)를 \(k\)번째 겹의 관측치 수라고 할 때 회귀문제의 교차검증 오차는

\[ CV_{(K)}=\frac{1}{K}\sum_{k=1}^{K}MSE_k \]

또는 관측치 수를 고려하여

\[ CV_{(K)}=\frac{1}{n}\sum_{k=1}^{K}\sum_{i\in C_k} \{y_i-\hat f^{-k}(x_i)\}^2 \]

로 계산한다. 여기서 \(\hat f^{-k}\)는 \(k\)번째 겹을 제외하고 적합한 모형이다.

일반적으로 \(K=5\) 또는 \(K=10\)을 많이 사용한다. 이 값들은 계산량, 편향, 분산 사이에서 좋은 절충을 제공한다.

6.3.1 직접 구현

kfold_mse <- function(data, formula, k = 10, seed = 123) {
  set.seed(seed)
  fold_id <- sample(rep(seq_len(k), length.out = nrow(data)))
  fold_error <- numeric(k)

  for (j in seq_len(k)) {
    fit <- lm(formula, data = data[fold_id != j, , drop = FALSE])
    pred <- predict(fit, newdata = data[fold_id == j, , drop = FALSE])
    y_name <- all.vars(formula)[1]
    actual <- data[fold_id == j, y_name]
    fold_error[j] <- mean((actual - pred)^2)
  }

  mean(fold_error)
}

kfold_mse(Auto, mpg ~ horsepower, k = 10)
#> [1] 24.29607
kfold_mse(Auto, mpg ~ poly(horsepower, 2), k = 10)
#> [1] 19.27857

6.4 LOOCV

휴일관측치 교차검증(leave-one-out cross-validation, LOOCV)은 \(K=n\)인 특별한 경우이다. 한 번에 관측치 하나를 제외하고 나머지 \(n-1\)개로 모형을 적합한다.

\[ CV_{(n)}=\frac{1}{n}\sum_{i=1}^{n} \{y_i-\hat f^{-i}(x_i)\}^2 \]

LOOCV의 장점은 거의 전체 자료로 모형을 적합하므로 시험오차 추정의 편향이 작고, 자료 분할의 무작위성이 없다는 점이다. 단점은 모형을 \(n\)번 적합해야 하며, 각 훈련집합이 매우 비슷해 오차 추정량의 분산이 커질 수 있다는 점이다.

선형회귀에서는 레버리지 \(h_i\)를 이용해 모형을 \(n\)번 다시 적합하지 않고도 LOOCV를 계산할 수 있다.

\[ CV_{(n)}=\frac{1}{n}\sum_{i=1}^{n} \left(\frac{y_i-\hat y_i}{1-h_i}\right)^2 \]

loocv_lm <- function(fit) {
  mean((residuals(fit) / (1 - hatvalues(fit)))^2)
}

loocv_results <- sapply(1:10, function(degree) {
  fit <- lm(mpg ~ poly(horsepower, degree), data = Auto)
  loocv_lm(fit)
})

plot(
  1:10, loocv_results, type = "b", pch = 19,
  xlab = "다항식 차수", ylab = "LOOCV 평균제곱오차"
)
loocv_results
#>  [1] 24.23151 19.24821 19.33498 19.42443 19.03321 18.97864 18.83305 18.96115
#>  [9] 19.06863 19.49093

6.5 편향-분산 절충

LOOCV는 각 반복에서 거의 전체 자료를 사용하므로 시험오차를 다소 낮게 추정하는 편향이 작다. 그러나 훈련집합들이 매우 유사하기 때문에 각 반복의 오차가 강하게 상관되어 전체 추정량의 분산이 커질 수 있다.

반면 5-겹 또는 10-겹 교차검증은 각 훈련집합이 전체 자료보다 작아 약간의 상향 편향이 생길 수 있지만 반복 오차의 상관이 낮아 분산이 줄어든다. 이런 이유로 실제 분석에서는 5-겹 또는 10-겹 교차검증이 흔히 사용된다.

set.seed(2026)
degrees <- 1:10
cv10_results <- sapply(degrees, function(d) {
  kfold_mse(Auto, reformulate(sprintf("poly(horsepower, %d)", d), response = "mpg"), k = 10, seed = 2026)
})

plot(degrees, loocv_results, type = "b", pch = 19,
     ylim = range(c(loocv_results, cv10_results)),
     xlab = "다항식 차수", ylab = "교차검증 오차")
lines(degrees, cv10_results, type = "b", pch = 17, lty = 2)
legend("topright", legend = c("LOOCV", "10-겹 CV"), pch = c(19, 17), lty = c(1, 2))

6.6 분류에서의 교차검증

분류에서는 평균제곱오차 대신 오분류율, 로그손실, AUC 등을 사용할 수 있다. 가장 단순한 오분류율은

\[ CV_{(K)}=\frac{1}{n}\sum_{i=1}^{n}I(y_i\neq\hat y_i) \]

이다. 범주 비율이 불균형할 때는 각 겹에서 범주 비율이 유지되도록 층화 분할(stratified split)을 사용하는 것이 좋다.

set.seed(123)
data(Default)

# 계산 시간을 줄이기 위해 balance와 student만 사용한다.
k <- 5
fold_default <- integer(nrow(Default))
for (lev in levels(Default$default)) {
  id <- which(Default$default == lev)
  fold_default[id] <- sample(rep(seq_len(k), length.out = length(id)))
}

error_default <- numeric(k)
for (j in seq_len(k)) {
  fit <- glm(
    default ~ balance + student,
    data = Default[fold_default != j, ],
    family = binomial
  )
  prob <- predict(fit, newdata = Default[fold_default == j, ], type = "response")
  pred <- factor(ifelse(prob > 0.5, "Yes", "No"), levels = levels(Default$default))
  error_default[j] <- mean(pred != Default$default[fold_default == j])
}

mean(error_default)
#> [1] 0.02700031

정확도만 보면 모든 관측치를 다수 범주로 분류하는 모형이 좋아 보일 수 있다. 희귀 사건 자료에서는 민감도, 특이도, 정밀도, F1 점수, AUC, 확률 보정도 함께 평가해야 한다.

6.7 교차검증의 올바른 사용

교차검증은 전처리와 변수선택을 포함한 전체 분석 절차를 평가해야 한다. 다음과 같은 절차는 잘못된 낙관적 성능을 만든다.

  1. 전체 자료에서 변수를 선택한다.
  2. 선택된 변수만 사용해 교차검증한다.

검증자료의 정보가 변수선택 단계에 이미 유입되었기 때문이다. 올바른 방법은 각 훈련겹 안에서 변수선택, 결측치 대치, 표준화, 조정모수 선택을 수행하고, 해당 훈련겹에서 얻은 규칙을 검증겹에 적용하는 것이다. 여러 단계의 조정모수 선택과 최종 성능평가를 분리하려면 중첩 교차검증(nested cross-validation)을 사용한다.

6.8 부트스트랩

부트스트랩은 원자료에서 복원추출로 크기 \(n\)의 표본을 반복 생성한다. \(b\)번째 부트스트랩 표본에서 계산한 추정량을 \(\hat\alpha^{*b}\)라고 하면 표준오차는

\[ SE_B(\hat\alpha) =\sqrt{\frac{1}{B-1}\sum_{b=1}^{B} \left(\hat\alpha^{*b}-\bar\alpha^*\right)^2} \]

로 추정한다. 여기서

\[ \bar\alpha^*=\frac{1}{B}\sum_{b=1}^{B}\hat\alpha^{*b} \]

이다.

6.8.1 단순 예제

두 자산 \(X\)와 \(Y\)에 투자하는 비율을 정한다고 하자. 포트폴리오 분산을 최소화하는 \(X\)의 투자비율은

\[ \alpha= \frac{\sigma_Y^2-\sigma_{XY}} {\sigma_X^2+\sigma_Y^2-2\sigma_{XY}} \]

이다. 자료에서 분산과 공분산을 추정해 \(\hat\alpha\)를 계산하고 부트스트랩으로 표준오차를 구할 수 있다.

library(ISLR2)
data(Portfolio)

alpha_fn <- function(data, index) {
  x <- data$X[index]
  y <- data$Y[index]
  (var(y) - cov(x, y)) / (var(x) + var(y) - 2 * cov(x, y))
}

alpha_fn(Portfolio, seq_len(nrow(Portfolio)))
#> [1] 0.5758321
set.seed(1)
B <- 1000
boot_alpha <- replicate(B, {
  id <- sample(seq_len(nrow(Portfolio)), replace = TRUE)
  alpha_fn(Portfolio, id)
})

c(
  추정값 = mean(boot_alpha),
  표준오차 = sd(boot_alpha),
  하한 = quantile(boot_alpha, 0.025),
  상한 = quantile(boot_alpha, 0.975)
)
#>     추정값   표준오차  하한.2.5% 상한.97.5% 
#> 0.57409798 0.09299619 0.39604899 0.76158581

부트스트랩은 정규성이나 단순한 해석적 표준오차 공식에 덜 의존한다. 그러나 관측치가 독립이라는 전제가 중요하다. 시계열, 군집자료, 반복측정자료에서는 단순한 개별 관측치 재추출 대신 블록 부트스트랩이나 군집 부트스트랩이 필요하다.

6.9 부트스트랩과 순열검정

부트스트랩은 주로 표본분포와 불확실성을 추정한다. 반면 순열검정(permutation test)은 귀무가설 아래에서 관측 가능한 통계량의 분포를 만든다.

두 집단의 평균 차이를 검정하는 경우, 귀무가설 아래에서는 집단표지가 교환 가능하다고 보고 표지를 무작위로 섞는다. 관측된 통계량보다 극단적인 순열 통계량의 비율을 p값으로 계산한다.

set.seed(123)
x <- rnorm(25, mean = 0)
y <- rnorm(25, mean = 0.6)
observed <- mean(y) - mean(x)

combined <- c(x, y)
n_x <- length(x)
B <- 5000
perm_stat <- replicate(B, {
  permuted <- sample(combined)
  mean(permuted[-seq_len(n_x)]) - mean(permuted[seq_len(n_x)])
})

p_value <- mean(abs(perm_stat) >= abs(observed))
c(관측된_평균차이 = observed, 양측_p값 = p_value)
#> 관측된_평균차이        양측_p값 
#>       0.7354677       0.0076000

6.10 정리

  • 검증자료 접근법은 간단하지만 분할에 따른 변동이 크다.
  • LOOCV는 편향이 작지만 계산량과 분산이 클 수 있다.
  • 5-겹 또는 10-겹 교차검증은 실무에서 좋은 기본 선택이다.
  • 전처리와 변수선택은 반드시 각 훈련겹 내부에서 수행해야 한다.
  • 부트스트랩은 추정량의 표준오차와 신뢰구간을 평가하는 유연한 방법이다.
  • 자료의 의존구조가 있다면 그 구조를 보존하는 재표본추출 설계를 사용해야 한다.
