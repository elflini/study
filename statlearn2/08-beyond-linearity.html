8  선형성을 넘어

선형모형은 해석이 쉽고 안정적이지만 실제 관계가 항상 직선인 것은 아니다. 이 장에서는 선형회귀의 기본 구조를 유지하면서 비선형 관계를 표현하는 방법을 다룬다.

  • 다항회귀(polynomial regression)
  • 계단함수(step function)
  • 회귀 스플라인(regression spline)
  • 평활 스플라인(smoothing spline)
  • 국소회귀(local regression)
  • 일반화가법모형(generalized additive model, GAM)

이 방법들은 설명변수의 변환이나 기저함수(basis function)를 사용하여

\[ f(X)=\beta_0+\sum_{m=1}^{M}\beta_m b_m(X) \]

형태의 모형을 적합한다. \(b_m(X)\)가 주어지면 계수에 대해서는 선형이므로 익숙한 최소제곱법이나 일반화선형모형을 사용할 수 있다.

8.1 다항회귀

단순선형회귀를 \(d\)차 다항식으로 확장하면

\[ y_i=\beta_0+\beta_1x_i+\beta_2x_i^2+\cdots+\beta_dx_i^d+\varepsilon_i \]

가 된다. 모형은 \(x\)에 대해서는 비선형이지만 계수 \(\beta\)에 대해서는 선형이다.

다항식 차수가 커질수록 유연해지지만 경계에서 불안정하게 진동하고 외삽이 위험해질 수 있다. 일반적으로 3차 또는 4차 이상의 고차 다항식은 신중하게 사용해야 한다.

8.1.1 임금 자료 예제

Wage 자료에서 나이와 임금의 관계를 4차 다항식으로 적합한다.

fit_poly4_raw <- lm(wage ~ poly(age, 4, raw = TRUE), data = Wage)
max(abs(fitted(fit_poly4) - fitted(fit_poly4_raw)))
#> [1] 5.818777e-10

다항식 차수는 부분 F 검정, AIC, BIC 또는 교차검증으로 선택할 수 있다.

fit_poly1 <- lm(wage ~ age, data = Wage)
fit_poly2 <- lm(wage ~ poly(age, 2), data = Wage)
fit_poly3 <- lm(wage ~ poly(age, 3), data = Wage)
anova(fit_poly1, fit_poly2, fit_poly3, fit_poly4)

8.2 계단함수

계단함수는 연속형 설명변수를 구간으로 나누고 구간별로 다른 상수를 적합한다. 절단점 \(c_1<\cdots<c_K\)가 있을 때

\[ C_0(X)=I(X<c_1),\quad C_1(X)=I(c_1\le X<c_2),\ldots, C_K(X)=I(c_K\le X) \]

를 만들고

\[ y_i=\beta_0+\beta_1C_1(x_i)+\cdots+\beta_KC_K(x_i)+\varepsilon_i \]

를 적합한다. 한 구간을 기준범주로 두므로 완전한 더미변수 집합 중 하나는 제외한다.

계단함수는 해석이 쉽지만 절단점에서 불연속이고, 구간 경계의 작은 차이가 예측을 크게 바꿀 수 있다.

Wage$age_group <- cut(
  Wage$age,
  breaks = c(18, 30, 40, 50, 60, 80),
  right = FALSE
)
fit_step <- lm(wage ~ age_group, data = Wage)
summary(fit_step)

8.3 조각별 다항식과 스플라인

조각별 다항식(piecewise polynomial)은 설명변수 영역을 여러 구간으로 나누고 각 구간에서 별도의 다항식을 적합한다. 구간 경계를 매듭(knot)이라 한다.

각 구간을 독립적으로 적합하면 매듭에서 함수값이나 기울기가 불연속일 수 있다. 스플라인은 매듭에서 적절한 연속성과 미분가능성을 부여해 부드러운 곡선을 만든다.

8.3.1 선형 스플라인

매듭이 \(\xi\)인 선형 스플라인은 절단된 선형기저

\[ (x-\xi)_+=\begin{cases} x-\xi,&x>\xi\cr 0,&x\le\xi \end{cases} \]

를 사용하여

\[ y_i=\beta_0+\beta_1x_i+\beta_2(x_i-\xi)_++\varepsilon_i \]

로 표현할 수 있다. 함수값은 연속이지만 매듭에서 기울기가 바뀐다.

truncated <- function(x, knot) pmax(x - knot, 0)

fit_linear_spline <- lm(
  wage ~ age + truncated(age, 40) + truncated(age, 55),
  data = Wage
)

pred_linear_spline <- predict(
  fit_linear_spline,
  newdata = data.frame(age = age_grid)
)

plot(Wage$age, Wage$wage, pch = 20, cex = 0.4,
     xlab = "나이", ylab = "임금")
lines(age_grid, pred_linear_spline, lwd = 2)
abline(v = c(40, 55), lty = 3)

8.3.2 3차 회귀 스플라인

3차 스플라인(cubic spline)은 각 구간에서 3차 다항식을 사용하고 매듭에서 함수값, 1차 미분, 2차 미분이 연속이 되도록 제약한다. 매듭이 \(K\)개인 3차 스플라인은 일반적으로 \(K+4\)개의 자유도를 갖는다.

절단 거듭제곱 기저는

\[ 1,x,x^2,x^3,(x-\xi_1)_+^3,\ldots,(x-\xi_K)_+^3 \]

로 표현할 수 있다. 실제 계산에서는 수치적으로 더 안정적인 B-스플라인 기저를 주로 사용한다.

library(splines)

fit_bs <- lm(
  wage ~ bs(age, knots = c(40, 55), degree = 3),
  data = Wage
)
pred_bs <- predict(fit_bs, newdata = data.frame(age = age_grid), se.fit = TRUE)

plot(Wage$age, Wage$wage, pch = 20, cex = 0.4,
     xlab = "나이", ylab = "임금")
lines(age_grid, pred_bs$fit, lwd = 2)
lines(age_grid, pred_bs$fit + 2 * pred_bs$se.fit, lty = 2)
lines(age_grid, pred_bs$fit - 2 * pred_bs$se.fit, lty = 2)
abline(v = c(40, 55), lty = 3)

8.3.3 자연 3차 스플라인

일반 3차 스플라인은 자료의 양 끝에서 분산이 커질 수 있다. 자연 3차 스플라인(natural cubic spline)은 경계 매듭 바깥에서 함수가 선형이 되도록 추가 제약을 둔다. 이 제약은 경계에서 더 안정적인 추정과 외삽을 제공한다.

fit_ns <- lm(wage ~ ns(age, df = 5), data = Wage)
pred_ns <- predict(fit_ns, newdata = data.frame(age = age_grid), se.fit = TRUE)

plot(Wage$age, Wage$wage, pch = 20, cex = 0.4,
     xlab = "나이", ylab = "임금")
lines(age_grid, pred_ns$fit, lwd = 2)
lines(age_grid, pred_ns$fit + 2 * pred_ns$se.fit, lty = 2)
lines(age_grid, pred_ns$fit - 2 * pred_ns$se.fit, lty = 2)

8.3.4 매듭의 위치와 자유도

스플라인의 유연성은 매듭의 수와 위치 또는 자유도에 의해 결정된다.

  • 자료가 많은 영역에는 더 많은 매듭을 둘 수 있다.
  • 실무에서는 설명변수의 분위수를 매듭으로 사용하는 경우가 많다.
  • 매듭을 직접 고르기보다 자유도를 지정하면 함수가 적절한 매듭을 자동으로 배치한다.
  • 자유도는 교차검증이나 정보기준으로 선택한다.
set.seed(123)
K <- 10
fold_id <- sample(rep(1:K, length.out = nrow(Wage)))
df_grid <- 3:10
cv_mse_ns <- numeric(length(df_grid))

for (m in seq_along(df_grid)) {
  fold_mse <- numeric(K)
  for (k in 1:K) {
    fit <- lm(
      wage ~ ns(age, df = df_grid[m]),
      data = Wage[fold_id != k, ]
    )
    pred <- predict(fit, newdata = Wage[fold_id == k, ])
    fold_mse[k] <- mean((Wage$wage[fold_id == k] - pred)^2)
  }
  cv_mse_ns[m] <- mean(fold_mse)
}

data.frame(자유도 = df_grid, CV_MSE = cv_mse_ns)

8.4 평활 스플라인

회귀 스플라인은 매듭과 자유도를 정해야 한다. 평활 스플라인은 모든 고유한 \(x\) 값에 매듭을 둘 수 있을 만큼 매우 유연한 함수 공간에서 다음 목적함수를 최소화한다.

\[ \sum_{i=1}^{n}\{y_i-g(x_i)\}^2 +\lambda\int g''(t)^2\,dt \]

첫 항은 자료 적합도를, 두 번째 항은 곡선의 거칠기를 나타낸다.

  • \(\lambda=0\)이면 자료를 매우 가깝게 통과하는 곡선이 된다.
  • \(\lambda\to\infty\)이면 \(g''(t)=0\)에 가까워져 직선이 된다.

\(\lambda\)는 보통 교차검증 또는 일반화교차검증(GCV)으로 선택한다.

fit_smooth_cv <- smooth.spline(
  x = Wage$age,
  y = Wage$wage,
  cv = TRUE
)
fit_smooth_gcv <- smooth.spline(
  x = Wage$age,
  y = Wage$wage,
  cv = FALSE
)

plot(Wage$age, Wage$wage, pch = 20, cex = 0.35,
     xlab = "나이", ylab = "임금")
lines(fit_smooth_cv, lwd = 2)
lines(fit_smooth_gcv, lwd = 2, lty = 2)
legend("topright", legend = c("CV", "GCV"), lty = c(1, 2), lwd = 2)
c(CV_자유도 = fit_smooth_cv$df, GCV_자유도 = fit_smooth_gcv$df)
#>  CV_자유도 GCV_자유도 
#>   6.794596   6.468299

8.5 국소회귀

국소회귀(local regression)는 예측하고자 하는 점 \(x_0\) 주변의 관측치에 더 큰 가중치를 주어 낮은 차수의 회귀모형을 적합한다.

  1. \(x_0\)에 가까운 관측치 집합을 선택한다.
  2. 거리가 가까울수록 큰 가중치를 부여한다.
  3. 가중최소제곱으로 국소 선형 또는 국소 다항모형을 적합한다.
  4. \(x_0\)에서의 적합값을 계산한다.

span은 각 국소 적합에 사용되는 자료의 비율이다. 작은 span은 더 유연하고, 큰 span은 더 매끄럽다.

fit_loess_small <- loess(wage ~ age, data = Wage, span = 0.35, degree = 2)
fit_loess_large <- loess(wage ~ age, data = Wage, span = 0.70, degree = 2)

plot(Wage$age, Wage$wage, pch = 20, cex = 0.35,
     xlab = "나이", ylab = "임금")
lines(age_grid,
      predict(fit_loess_small, newdata = data.frame(age = age_grid)),
      lwd = 2)
lines(age_grid,
      predict(fit_loess_large, newdata = data.frame(age = age_grid)),
      lwd = 2, lty = 2)
legend("topright", legend = c("span=0.35", "span=0.70"),
       lty = c(1, 2), lwd = 2)

국소회귀는 저차원 문제에서 유연하고 직관적이지만 설명변수의 수가 늘어나면 근방에 충분한 관측치가 없어지는 차원의 저주를 겪는다.

8.6 일반화가법모형

일반화가법모형(generalized additive model, GAM)은 각 설명변수의 효과를 별도의 함수로 더한다.

\[ Y=\beta_0+f_1(X_1)+f_2(X_2)+\cdots+f_p(X_p)+\varepsilon \]

선형항, 범주형 변수, 스플라인 등을 한 모형에 함께 넣을 수 있다. 각 \(f_j\)를 다른 변수를 보정한 부분효과(partial effect)로 시각화할 수 있어 비선형모형 중 비교적 해석 가능성이 높다.

8.6.1 임금 자료의 GAM

나이와 연도는 평활함수로, 교육수준은 범주형 변수로 포함한다.

library(mgcv)

  method = "REML"

GAM에서 각 평활항의 유효자유도(estimated degrees of freedom, edf)가 1에 가까우면 거의 선형효과를 뜻한다. edf가 1보다 크면 비선형성이 있음을 의미한다. 선형모형과 GAM을 비교하여 비선형항의 필요성을 평가할 수 있다.

fit_gam_linear_age <- gam(
  wage ~ s(year, k = 5) + age + education,
  data = Wage,
  method = "REML"
)
anova(fit_gam_linear_age, fit_gam, test = "F")

8.6.2 분류를 위한 GAM

이항 반응변수에서도 연결함수를 사용해 GAM을 적합할 수 있다.

\[ \log\left\{\frac{p(X)}{1-p(X)}\right\} =\beta_0+f_1(X_1)+\cdots+f_p(X_p) \]

고소득 여부를 예측하는 예제를 살펴보자.

Wage$high_wage <- Wage$wage > 250

fit_gam_logit <- gam(
  high_wage ~ s(year, k = 5) + s(age, k = 8) + education,
  data = Wage,

8.7 방법 비교

방법 유연성의 조절 장점 한계
다항회귀 다항식 차수 단순하고 익숙함 경계와 외삽에서 불안정
계단함수 절단점 수와 위치 구간별 해석이 쉬움 불연속적이고 경계에 민감
회귀 스플라인 매듭 또는 자유도 국소적 유연성과 매끄러움 복잡도 선택 필요
평활 스플라인 \(\lambda\) 또는 유효자유도 자동적인 매끄러움 조절 한 설명변수의 효과에 주로 사용
국소회귀 span 강한 국소 적응성 고차원에서 비효율적
GAM 각 평활항의 복잡도 여러 변수의 비선형 효과를 가법적으로 해석 상호작용을 자동으로 포함하지 않음

비선형성을 허용한다고 해서 항상 예측력이 향상되는 것은 아니다. 복잡도는 교차검증으로 선택하고, 자료가 희박한 경계 영역과 외삽에서는 불확실성을 명확히 표시해야 한다.
