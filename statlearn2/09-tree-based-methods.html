9  트리 기반 방법

트리 기반 방법은 설명변수 공간을 여러 영역으로 나누고 각 영역에서 단순한 예측값을 사용한다. 회귀문제에서는 영역 안의 평균을, 분류문제에서는 가장 빈도가 높은 범주 또는 범주별 비율을 예측한다.

트리는 규칙이 명확하고 그림으로 표현하기 쉬워 해석 가능성이 높다. 그러나 하나의 트리는 예측력이 제한되고 자료 변화에 민감할 수 있다. 배깅, 랜덤 포레스트, 부스팅은 많은 트리를 결합하여 이러한 약점을 보완한다.

9.1 의사결정나무의 기본

9.1.1 회귀나무

설명변수 공간을 \(J\)개의 서로 겹치지 않는 영역 \(R_1,\ldots,R_J\)로 나눈다고 하자. 회귀나무는

\[ \hat f(x)=\sum_{j=1}^{J}\hat c_j I(x\in R_j) \]

로 예측한다. 여기서 \(\hat c_j\)는 영역 \(R_j\)에 속한 훈련 관측치의 반응변수 평균이다.

영역은 대개 다음과 같은 이진분할로 만들어진다.

\[ R_1(j,s)=\{X\mid X_j<s\},\qquad R_2(j,s)=\{X\mid X_j\ge s\} \]

변수 \(j\)와 절단점 \(s\)는 두 영역의 잔차제곱합

\[ \sum_{i:x_i\in R_1(j,s)}(y_i-\hat y_{R_1})^2 +\sum_{i:x_i\in R_2(j,s)}(y_i-\hat y_{R_2})^2 \]

이 최소가 되도록 선택한다. 이후 각 영역에서 같은 과정을 재귀적으로 반복한다. 이를 재귀적 이진분할(recursive binary splitting)이라 한다.

9.1.2 야구선수 연봉 예제

Hitters 자료에서 연봉을 예측하는 회귀나무를 적합한다.

library(ISLR2)
library(tree)

data(Hitters)
Hitters_complete <- na.omit(Hitters)

set.seed(1)
train_id <- sample(
  seq_len(nrow(Hitters_complete)),
  size = floor(0.7 * nrow(Hitters_complete))
)
train_hitters <- Hitters_complete[train_id, ]
test_hitters <- Hitters_complete[-train_id, ]

fit_tree_hitters <- tree(Salary ~ ., data = train_hitters)
summary(fit_tree_hitters)
#> 
#> Regression tree:
#> tree(formula = Salary ~ ., data = train_hitters)
#> Variables actually used in tree construction:
#> [1] "CHits"  "Walks"  "CRBI"   "Hits"   "Years"  "RBI"    "CAtBat"
#> Number of terminal nodes:  12 
#> Residual mean deviance:  54460 = 9367000 / 172 
#> Distribution of residuals:
#>    Min. 1st Qu.  Median    Mean 3rd Qu.    Max. 
#> -849.40  -73.50  -17.22    0.00   83.19 1532.00
plot(fit_tree_hitters)
text(fit_tree_hitters, pretty = 0, cex = 0.7)

트리에서 내부 노드(internal node)는 분할 규칙을, 말단 노드(terminal node 또는 leaf)는 최종 예측영역을 나타낸다. 루트 노드는 전체 자료를 포함한다. 위쪽의 분할일수록 더 많은 관측치에 영향을 주므로 일반적으로 중요한 규칙으로 해석한다.

9.1.3 예측

새 관측치는 루트에서 시작해 각 분할 규칙을 따라 말단 노드에 도달한다. 회귀나무에서는 해당 말단 노드의 훈련자료 평균을 예측값으로 사용한다.

pred_tree_hitters <- predict(fit_tree_hitters, newdata = test_hitters)
mse_tree_hitters <- mean((test_hitters$Salary - pred_tree_hitters)^2)
mse_tree_hitters
#> [1] 120663.4

9.2 트리 가지치기

나무를 충분히 크게 성장시키면 훈련자료를 잘 적합하지만 과적합될 수 있다. 반대로 너무 작은 트리는 중요한 구조를 놓칠 수 있다. 일반적인 전략은 다음과 같다.

  1. 먼저 큰 트리 \(T_0\)를 성장시킨다.
  2. 비용-복잡도 가지치기(cost-complexity pruning)로 부분트리 후보를 만든다.
  3. 교차검증으로 최적 복잡도를 선택한다.

비용-복잡도 기준은

\[ \sum_{m=1}^{|T|}\sum_{i:x_i\in R_m}(y_i-\hat y_{R_m})^2 +\alpha|T| \]

이다. \(|T|\)는 말단 노드 수이고 \(\alpha\)는 트리 크기에 대한 벌점이다. \(\alpha\)가 커질수록 작은 트리를 선택한다.

set.seed(2)
cv_hitters <- cv.tree(fit_tree_hitters, FUN = prune.tree)
cv_hitters

#> $dev

#> 
#> $method

plot(cv_hitters$size, cv_hitters$dev, type = "b", pch = 19,
     xlab = "말단 노드 수", ylab = "교차검증 편차")
best_size <- cv_hitters$size[which.min(cv_hitters$dev)]
best_size
#> [1] 4
pruned_tree_hitters <- prune.tree(fit_tree_hitters, best = best_size)
plot(pruned_tree_hitters)
text(pruned_tree_hitters, pretty = 0, cex = 0.8)
pred_pruned_hitters <- predict(pruned_tree_hitters, newdata = test_hitters)

  가지치기트리_MSE = mean((test_hitters$Salary - pred_pruned_hitters)^2)

교차검증 오차가 거의 같은 여러 트리가 있다면 더 작은 트리를 선택하면 해석과 안정성 측면에서 유리하다.

9.3 분류나무

분류나무는 회귀나무와 같은 방식으로 설명변수 공간을 분할하지만, 말단 노드에서 범주별 비율을 추정하고 가장 빈도가 높은 범주를 예측한다.

분류나무를 성장시킬 때 단순 오분류율보다 노드의 순수성(purity)을 민감하게 반영하는 지표를 주로 사용한다.

9.3.1 분류오차율

노드 \(m\)에서 가장 흔한 범주의 비율을 \(\max_k\hat p_{mk}\)라고 하면 분류오차율은

\[ E_m=1-\max_k\hat p_{mk} \]

이다.

9.3.2 지니지수

\[ G_m=\sum_{k=1}^{K}\hat p_{mk}(1-\hat p_{mk}) =1-\sum_{k=1}^{K}\hat p_{mk}^2 \]

한 범주가 대부분을 차지할수록 지니지수는 작아진다.

9.3.3 교차엔트로피 또는 편차

\[ D_m=-\sum_{k=1}^{K}\hat p_{mk}\log(\hat p_{mk}) \]

지니지수와 교차엔트로피는 노드의 범주 비율 변화에 민감하므로 트리 성장 단계에 흔히 사용한다.

9.3.4 자동차 카시트 판매 예제

Carseats 자료에서 판매량이 8보다 큰지를 분류한다.

library(ISLR2)

plot(cv_carseats$size, cv_carseats$dev, type = "b", pch = 19,

  best = best_size_class

pred_pruned_carseats <- predict(
  pruned_tree_carseats,
  newdata = test_carseats,
  type = "class"
)
mean(pred_pruned_carseats == test_carseats$High)
#> [1] 0.7416667

9.4 선형모형과 트리의 비교

선형회귀는

\[ f(X)=\beta_0+\sum_{j=1}^{p}\beta_jX_j \]

처럼 전역적이고 가법적인 구조를 가정한다. 회귀나무는

\[ f(X)=\sum_{m=1}^{M}c_m I(X\in R_m) \]

처럼 영역별 상수함수를 사용한다.

  • 실제 관계가 가법적이고 선형에 가까우면 선형모형이 효율적이다.
  • 변수 사이의 복잡한 상호작용과 임계값 효과가 중요하면 트리가 유리할 수 있다.
  • 단일 트리는 해석하기 쉽지만 예측함수가 계단형이고 분산이 크다.

9.5 배깅

의사결정나무는 자료의 작은 변화에도 분할 구조가 크게 달라질 수 있는 고분산 방법이다. 배깅(bootstrap aggregating)은 부트스트랩 표본마다 큰 트리를 적합하고 예측을 평균하여 분산을 낮춘다.

회귀문제에서 배깅 예측은

\[ \hat f_{bag}(x)=\frac{1}{B}\sum_{b=1}^{B}\hat f^{*b}(x) \]

이다. 분류문제에서는 다수결 또는 범주확률 평균을 사용한다.

library(randomForest)

set.seed(5)
bag_hitters <- randomForest(
  Salary ~ .,
  data = train_hitters,
  mtry = ncol(train_hitters) - 1,
  importance = TRUE,
  ntree = 500
)

pred_bag_hitters <- predict(bag_hitters, newdata = test_hitters)
mean((test_hitters$Salary - pred_bag_hitters)^2)
#> [1] 104626.7

mtry=p로 두면 각 분할에서 모든 설명변수를 후보로 사용하므로 배깅과 같다.

9.5.1 OOB 오차

각 부트스트랩 표본에는 평균적으로 원자료 관측치의 약 63.2%가 한 번 이상 포함된다. 특정 부트스트랩 표본에 포함되지 않은 관측치를 OOB(out-of-bag) 관측치라고 한다.

각 관측치에 대해 그 관측치를 사용하지 않고 만든 트리들의 예측을 평균하면 별도의 검증자료 없이 시험오차를 추정할 수 있다. OOB 오차는 배깅과 랜덤 포레스트에서 교차검증과 비슷한 역할을 한다.

plot(bag_hitters)
tail(bag_hitters$mse)
#> [1] 82440.29 82455.00 82449.95 82449.28 82488.06 82414.76

9.6 랜덤 포레스트

배깅에서는 강한 설명변수가 모든 트리의 상위 분할에 반복적으로 선택될 수 있다. 그 결과 트리들이 서로 비슷해져 예측오차의 상관이 높아진다.

랜덤 포레스트(random forest)는 각 분할에서 전체 \(p\)개 변수가 아니라 무작위로 선택한 \(m\)개 변수만 후보로 고려한다. 이 무작위화는 트리 사이의 상관을 낮추고 평균 예측의 분산을 더 줄인다.

일반적인 기본값은

  • 분류: \(m\approx\sqrt{p}\)
  • 회귀: \(m\approx p/3\)

이다. 실제 값은 OOB 오차나 교차검증으로 조정할 수 있다.

set.seed(6)
rf_hitters <- randomForest(
  Salary ~ .,
  data = train_hitters,
  mtry = floor(sqrt(ncol(train_hitters) - 1)),
  importance = TRUE,
  ntree = 500
)

pred_rf_hitters <- predict(rf_hitters, newdata = test_hitters)
c(
  배깅_MSE = mean((test_hitters$Salary - pred_bag_hitters)^2),
  랜덤포레스트_MSE = mean((test_hitters$Salary - pred_rf_hitters)^2)
)
#>         배깅_MSE 랜덤포레스트_MSE 
#>        104626.74         94312.51

9.6.1 변수 중요도

트리 앙상블은 변수 중요도 지표를 제공한다.

  • 순열 중요도: 특정 변수의 값을 섞었을 때 OOB 오차가 얼마나 증가하는지 측정한다.
  • 불순도 감소 중요도: 해당 변수를 사용한 분할이 RSS, 지니지수 등을 얼마나 감소시켰는지 합산한다.

9.7 부스팅

부스팅(boosting)은 트리를 독립적으로 만든 뒤 평균하는 대신, 이전 모형의 오차를 보완하도록 트리를 순차적으로 추가한다.

회귀 부스팅의 기본 절차는 다음과 같다.

  1. 초기 예측 \(\hat f(x)=0\)과 잔차 \(r_i=y_i\)로 시작한다.
  2. 잔차를 예측하는 작은 트리 \(\hat f_b(x)\)를 적합한다.
  3. \(\hat f(x)\leftarrow\hat f(x)+\lambda\hat f_b(x)\)로 갱신한다.
  4. 잔차 \(r_i\leftarrow r_i-\lambda\hat f_b(x_i)\)를 갱신한다.
  5. 이를 \(B\)번 반복한다.

\(\lambda\)는 학습률(shrinkage parameter)이고, 트리 깊이는 상호작용의 복잡도를 조절한다.

library(gbm)

set.seed(8)
boost_hitters <- gbm(
  Salary ~ .,
  data = train_hitters,
  distribution = "gaussian",
  n.trees = 3000,
  interaction.depth = 2,
  shrinkage = 0.01,
  n.minobsinnode = 10,
  bag.fraction = 0.5,
  verbose = FALSE
)

pred_boost_hitters <- predict(
  boost_hitters,
  newdata = test_hitters,
  n.trees = 3000
)
mean((test_hitters$Salary - pred_boost_hitters)^2)
#> [1] 116339.8

9.7.1 조정모수

부스팅의 주요 조정모수는 다음과 같다.

  • 트리 수 \(B\): 너무 작으면 과소적합, 너무 크면 과적합 가능성이 있다.
  • 학습률 \(\lambda\): 작을수록 더 많은 트리가 필요하지만 일반화 성능이 좋아지는 경우가 많다.
  • 트리 깊이: 1이면 주효과만, 2 이상이면 상호작용을 허용한다.
  • 최소 노드 크기와 표본추출 비율도 모형의 평활도에 영향을 준다.

최적 트리 수는 교차검증으로 선택한다.

9.9 장단점 정리

9.9.1 단일 트리

장점

  • 규칙과 상호작용을 직관적으로 설명할 수 있다.
  • 수치형과 범주형 변수를 함께 처리한다.
  • 단조 변환과 이상치에 비교적 강하다.
  • 변수선택과 상호작용 탐색을 자동으로 수행한다.

단점

  • 예측 정확도가 선형모형이나 앙상블보다 낮을 수 있다.
  • 자료의 작은 변화에 구조가 크게 바뀌는 고분산 방법이다.
  • 회귀 예측이 불연속적인 계단함수이다.

9.9.2 앙상블

  • 배깅과 랜덤 포레스트는 분산을 낮추고 안정성을 높인다.
  • 부스팅은 편향을 줄이면서 복잡한 패턴을 학습한다.
  • 예측력은 높지만 단일 트리보다 해석이 어렵다.
  • 변수 중요도는 인과효과가 아니며 상관된 변수들 사이에서 분산될 수 있다.

트리 기반 모형을 사용할 때에는 예측 성능뿐 아니라 확률 보정, 변수 중요도의 안정성, 부분의존도나 개별조건부기대와 같은 해석 도구를 함께 검토해야 한다.
